rarpd

Claims: 5

rarpd was failing because a space was used instead of a tab between the MAC and hostname. 1 Netbooting Solaris beyond version 2.3 requires modifications and kernel recompilation with rarpd support, but it may not work reliably. 2 Netbooting requires explicitly declaring the netmask for rarpd or bootparamd. 3 Running rarpd interactively can help diagnose RARP requests, and 'not bootable' indicates an issue with the boot configuration. 4 The SPARCstation runs well on an isolated network with a Raspberry Pi server running rarpd and ftpd. 5
