X11 server

Claims: 4 Part of X11

The X11 server in WSL2 runs inside the WSL environment rather than at the Windows level, unlike X410, and is hidden behind the Hyper-V virtual network interface. 1 X11 works between IRIX and Windows with an X11 server on Windows. 2 Conventional X11 applications do not require SGI graphics hardware, and the X11 server's location is specified by the DISPLAY environment variable and can be managed by Xdmcp. 3 The X11 server needs modification for graphics hardware support, while the client side can be built from vanilla MIT X11R4. 4
