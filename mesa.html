Mesa

Claims: 10 Background: 2 claims already covered by Wikipedia, see Blender (software), OpenGL.

Mesa is a high-level language that influenced Java and C++ and was used in the GlobalView environment on Xerox Star/Daybreak machines. 1 It uses procedures as internal processes and supports monitor modules with auto-locking routines using mutexes, and it is similar to Pascal. 23 Mesa is also a graphics driver project that requires OpenGL for efficient modeling, and it may enable running Blender on hardware that does not natively support it, such as HP Visualize cards, potentially allowing use on Linux. 45 LLVMpipe is a software-accelerated fallback graphics driver in Mesa. 6 Mesa removed indexed color support in the late 2000s, and Debian woody (2002) was the last version to provide indexed color visuals for some OpenGL applications. 7 The IP30 may have limited or no Mesa or Xorg support, as indicated by the absence of packages on media-libs/mesa, and there is no mention of an SGI user group on Libera. 8 Porting amdgpu to IRIX kernel would require adding new kernel API to Mesa and possibly writing a queue server and memory allocator. 9 The original February 26.3 ISO had Mesa cross build and KDE issues; X11 required LD_PRELOAD, and Wayland was broken. 10
