pi4d50

Claims: 6 Part of PI

pi4d50 is a Silicon Graphics machine emulated in MAME, though running it produces errors due to missing required files including idprom.bin and nvram, which prevent the machine from running. 1 Irix 3.3 can be installed on pi4d50 with some SCSI errors, but it reaches the install prompt, and earlier versions like IRIX 3.2 might also work, though installation files are uncertain. 2 The pi4d50 network emulation works fine with file transfers and Telnet, and its VME emulation structure provides important feedback for testing. 34 You can add a blank nvram file if pi4d50 complains, though it may need to be overwritten after the first run. 5 The SCSI fixes for pi4d50 do not apply to Personal Iris 4d/25, where proper emulation of the ip4 dma controller was required. 6

Sources

  1. Running MAME for pi4d50 results in errors due to missing required files including idprom.bin, nvram, and others, preventing the machine from running. (user-24f0, 2025-04-14, exchange 93569, check: uncheckable)
  2. Irix 3.3 can be installed on pi4d50 with some SCSI errors, but it reaches the install prompt. Earlier versions like IRIX 3.2 might also work, though installation files are uncertain. (user-ce6b, 2025-02-01, exchange 220352, check: supported)
  3. The pi4d50 network emulation works fine with file transfers and Telnet. (user-ce6b, 2025-02-01, exchange 220353, check: uncheckable)
  4. The VME emulation structure for the pi4d50 network emulation is important feedback for testing. (user-a719, 2025-02-01, exchange 220353, check: uncheckable)
  5. You can add a blank nvram file if it complains for pi4d50 and pi4d70, though it may need to be overwritten after the first run. (user-ce6b, 2025-04-14, exchange 93569, check: uncheckable)
  6. The SCSI fixes for pi4d50 do not apply to Personal Iris 4d/25; proper emulation of the ip4 dma controller was required. (user-a719, 2025-02-04, exchange 93544, check: supported)
