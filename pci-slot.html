PCI slot

Claims: 40 Part of PCI Background: 7 claims already covered by Wikipedia, see PCI-X, PCI Express, Peripheral Component Interconnect, SGI Octane.

Several Sun machines include a PCI slot: the O2 is a toaster-sized machine with many inputs and a PCI slot, the Fuel has one more PCI slot, the Netra has a PCI slot for options like Ethernet, SCSI, or crypto accelerators, Indigos have a PCI slot for gigabit Ethernet, and Crusoe thin clients had a PCI slot for unknown reasons and came with a side cover and right angle adapter. 123456 A PCI slot can be used to add various functionality, such as network connectivity with a 3Com EtherLink III 3C509B-C LAN card or USB 2.0 with a Belkin F5U220 controller, or graphics with a Quantum3D Obsidian2 X-24 3dfx Voodoo2 SLI card, provided it does not share an IRQ with another card. 789 A standard PCI slot typically uses 5 signals for request, grant, interrupt, ID select, and possibly others, and can provide up to 25W, though not all slots in an old computer may support this simultaneously and some NVMe drives require more power. 1011 PCI-X cards cannot be directly used in a PCI slot, PCI-X to PCIe bridge ICs might not work in a 64-bit PCI slot, and O2's 64-bit PCI slot has particularities. 1213 The Xeon Phi is an embedded Linux system that can be used as a many-core processor in a PCI slot, and on the O2 you can swap the R5k for an R10k but you need a different riser to be able to use the PCI slot. 1415 Blowing on a PCI slot might help it work properly. 16
