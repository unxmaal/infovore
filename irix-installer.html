IRIX installer

Claims: 8 Part of IRIX

The IRIX installer is a tool that unpacks files from IRIX installer archives using irixswextract.c. 1 It does not store root and swap information in the partition map but instead uses PROM environment variables. 2 Booting with bootp() loads the IRIX installer. 3 The IRIX installer automatically selects the necessary drivers based on the hardware installed, and the EFS package is more reliable, requiring only one disc for installation. 4 The system may lock up during the IRIX installer after loading tools, possibly related to USB or partition issues. 5 The IRIX installer could be automated to handle different machine types, but it would be a major chore. 6 There is a mirror on GitHub for the IRIX installer. 7
