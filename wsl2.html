WSL2

Claims: 15 Part of WSL

WSL2 runs a Linux kernel in a hyperv session, virtualizing the OS by running Windows in a Hyper-V VM and Linux in a VM. 123 WSL2 can be used to run GUI apps, X11 apps, and shell stuff, using Wayland and a custom Linux GPU device based on a Windows DirectX host GPU. 45 WSL2 can run raw sockets, and the X11 server runs inside the WSL environment behind the Hyper-V virtual network interface rather than at the Windows level. 67 WSL2 can be exported to a tar file and reimported to a separate partition, though this requires the partition to be the main system drive due to warnings. 8 WSL2 has networking issues, including a problematic virtual network switch that may require reinstalling Hyper-V components, and difficulty setting up a static IP associated with a specific NIC. 910 Nested virtualization is not supported by WSL2, especially on AMD CPUs, and ancient kernels lacking Hyper-V guest features will not work in WSL2. 1112
