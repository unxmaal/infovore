static pressure

Claims: 7 Background: 1 claim already covered by Wikipedia, see Computer fan.

The O2 and Octane require fans with high static pressure, with typical values around 40 Pascals, because static pressure is more important than CFM for highly constrained spaces like these. 12 In general, low-noise fans with low static pressure work fine for wide-open cases like a modern PC, but a tight case like an Indy requires higher static pressure to ensure adequate airflow. 3 PCs use CFM ratings for airflow, which does not directly relate to the static pressure used in SGI machines. 4 The O2 PSU fan must have sufficient static pressure to keep the system cool. 5 Noctua fans are an option, but their static pressure (1.0 - 2.37 mmH2O) should be considered, and appropriate fan pin connectors may need to be installed for SGI machines. 67
