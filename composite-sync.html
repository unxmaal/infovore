composite sync

Claims: 5 Part of composite Background: 1 claim already covered by Wikipedia, see Component video.

Composite sync is used by Suns, whereas SGIs use sync on green, and some monitors will not recognize composite or separate sync if composite/separate sync pins are present. 12 Most adapters to VGA are wired for composite sync. 2 The cg3 monitor uses separate sync, unlike earlier Sun composite sync monitors. 3 Newer Ultra cards default to composite sync but can be reset to separate sync, while DVI cards use PC separate sync. 3 Setting the sync to composite sync on the cable resolved a monitor issue that produced weird vertical banding lines with sync on green. 4

Sources

  1. Suns use composite sync, not sync on green, which some monitors won't recognize if composite/separate sync pins are present. (user-7b1c, 2021-11-19, exchange 239444, check: uncheckable)
  2. Most adapters to VGA are wired for composite sync, which is used by Suns but not by SGIs, which use sync on green. (user-03ad, 2023-08-21, exchange 240105, check: uncheckable)
  3. The cg3 monitor uses separate sync, unlike earlier Sun composite sync monitors; newer Ultra cards can be reset to separate sync but default to composite sync; DVI cards are more modern and use PC separate sync. (user-03ad, 2025-09-10, exchange 186728, check: uncheckable)
  4. Setting the sync to Composite Sync on the cable resolved the issue with the monitor, which had weird vertical banding lines with Sync on Green. HV Sync looks better but is still iffy. (user-281e, 2023-10-05, exchange 41297, check: uncheckable)
