ID

Claims: 5

The SCSI ID is likely set by jumpers on the leftmost pins, while the rightmost pins serve other purposes such as the BUSY LED. 1 When only one drive is present, use the ID that hinv shows. 2 The PROM must have an SGI ID, otherwise it will fail. 3
