sed

Claims: 10 Background: 1 claim already covered by Wikipedia, see Perl.

sed is a line editing tool that may require non-POSIX extensions for full functionality, and Perl can provide similar functionality with universal regex and replacement capabilities. 1 The /opt/local/bin/sed binary can be obtained from GNU sources. 2 sed can be used to switch the shebang of a script to use a different interpreter, and global replace with sed can be used for simple domain changes in files. 34 sed throws an error when the first regex is empty, and NetBSD shows a similar error for an empty regex. 56 The regex problem can be mitigated by using nbcompat's reg*() functions, though the bootstrap process does not respect this flag for bmake and sed. 7 sed has a 'Not enough space' error when using the default HPUX tools, and IRIX's startup scripts contain a misbehaving sed command. 89 inst files can have GFXBOARD or MGRAS restrictions that can be overridden with -m GFXBOARD= or -m MGRAS= options or by modifying the files with sed. 10
