IRIX emulator

Claims: 5 Part of IRIX

An IRIX emulator exists, but it runs very slowly, as MAME's implementation is not optimized. 12 For general desktop usage, 3D acceleration is not necessary, so hardware emulation does not provide a speed advantage in the IRIX emulator. 3 To enable CHD support in the IRIX emulator, build with `cargo build --release --features chd`. 4 Building the emulator locally allows for CPU optimization and can avoid license issues with CHD support. 5
