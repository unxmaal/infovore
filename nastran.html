NASTRAN

Claims: 9

NASTRAN, started in the 1970s, was written in FORTRAN IV and had multicore support by 2006; it may have been updated to support GPU compute, but it's unclear if this is part of the original solver. 1 NASTRAN runs on Sun Solaris and allocates memory for the open core and in-memory database, with specific block sizes and I/O operations. 2 The `make -j8` command is used for parallel compilation, and compiling NASTRAN on 8 CPUs is fast. 34 The NASTRAN solver can process small problems very quickly, typically with fewer than 100 elements. 3 NASTRAN can produce graphical output by inserting `PLOT` cards into the input deck, generating `PLT2` files that can be converted into a preferred format using tools like NASPLOT. 5 The plotter utility for NASTRAN was successfully built. 6 To change the machine ID in NASTRAN, modify the `MACH` variable in `mds/btstrp.f`. 7 NASTRAN output shows forces on a single-point constraint for a delta wing with biconvex cross section in Solaris NASTRAN. 8
