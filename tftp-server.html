TFTP server

Claims: 10 Part of TFTP

TFTP servers are used to provide boot images for various SGI systems, including booting a Linux VM via PXE by configuring the TFTP server and setting the PROM to the Linux box's IP. 1 Booting into the installer from the TFTP server works initially but then networking is lost inside the installer or Booterizer crashes. 2 When installing IRIX 6.5.30 using booterizer, setting 'setenv srvaddr {IP of TFTP}' ensures the SGI box knows where to find the TFTP server; otherwise, it may try to contact a server with a blank IP/hostname. 3 The XP214 uses PS/2 keyboards and mice, which are easy to set up with a TFTP server for the boot image; DHCP/BOOTP is optional. 4 bootp() can specify the IP or hostname of the TFTP server, and if omitted, it broadcasts to find a responding server. 5 The Indy uses a network configuration with a TFTP server for booting, and the kernel expects SGI hardware. 6 The Octane would need a router to reach the TFTP server's IP address. 7 To boot from a SATA drive, the kernel must be loaded from another drive first, using a TFTP server for example. 8
