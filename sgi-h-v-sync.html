SGI H/V sync

Claims: 8 Part of SGI

SUN 13W3 to VGA cables can be configured to work with SGI H/V sync using DIP switches, and dipswitch adapters offer options for choosing SoG, C-Sync, or HV-Sync modes. 12 user-3ab2 got h/v sync working on an Indy using a dip switch cable and a 13w3 to VGA adapter. 3 The O2 outputs sync on both the green and horizontal sync lines, which can cause a green tint on monitors that don't filter green sync properly, and the O2 may generate both h/v sync and SoG, confusing monitors. 45 Some Dell monitors get confused with both H/V sync and SoG signals, and snipping sync pins on the VGA cable works around this. 6 If the graphics card isn't outputting the selected sync mode, the display won't receive it. 2

Sources

  1. SUN 13W3->VGA cables can be configured to work with SGI H/V sync using DIP switches. (user-c831, 2020-06-23, exchange 204321, check: uncheckable)

  3. user-3ab2 got h/v sync working on an Indy using a dip switch cable and a 13w3->VGA adapter; see the sgi.sh forum post for details. (user-c831, 2020-05-28, exchange 96937, check: supported)
  4. The O2 outputs sync on both green and horizontal sync (HV) lines, which can cause green tint on monitors that don't filter green sync properly. (user-6afa, 2022-01-17, exchange 24757, check: supported)
  5. The O2 may generate h/v sync and SoG, confusing monitors. (user-37bb, 2024-05-29, exchange 218423, check: supported)
  6. Some Dells get confused with both H/V sync and SoG signal; snipping sync pins on the VGA cable works around this. (user-6afa, 2021-11-28, exchange 22773, check: uncheckable)
