WinUAE

Claims: 11

WinUAE is an open-source Amiga emulator that can be used to create ADFs and bake drive images for real IDE drives. 12 It supports direct drive passthrough, a feature not all UAE versions reliably support, and can mount a drive to transfer files by dragging and dropping, which is easier than transferring files in 800KB fake-floppy chunks. 34 WinUAE can perform better than the real Amiga when properly configured, and is faster for file transfer between a modern PC and an Amiga compared to using a real Amiga. 56 It can emulate AMIX's hardware, and Cloanto, which sells Amiga OS updates, contributes to the open-source emulator. 78
