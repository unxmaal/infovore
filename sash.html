sash

Claims: 48

Sash is a single-file MIPS binary that serves as a command interpreter and shell on the system, linked at 0x80C00000 for 32-bit systems and 0xA800000000C00000 for 64-bit systems. 12 Sash is a PROM with filesystem support that can be loaded from the command monitor to provide additional functionality, and it can read more things and provide a more consistent run environment than the PROMs. 345 Sash is on disk rather than loaded from memory on the board, and the PROM can read sash from a limited number of devices while sash itself can handle more. 67 To load Sash, you call scsi(0)diskrdisk(0)partition/sash from the command monitor, and partition 8 contains sash and presumably the bootloader while partition 0 has the collection of files. 89 The command to boot SASH is boot -f (controller,SCSI ID,partition)sash, and you can boot IRIX by typing boot from the PROM and using ls to list disk contents from SASH. 1011 The SGI VTOC has a pointer to a Sash as a last resort if the root partition is gone, and to boot into sash you can set OSLoader sash and optionally OSLoadFilename /unix to avoid manual loading each time. 1213 Sash can boot without a miniroot or disk attachment, but without a drive it cannot load the miniroot. 1415 Correct sash and kernel versions are crucial, and the base install tools tar from 6.5 does not include sash. 1617 sash is a boot environment on IRIX systems, and the command to boot from CD partition 8 is 'boot -f scsi(0)cdrompartitionsashARCS'. 18 Loading sash works, but loading IDE or kernel fails. 19 sash can boot to ARCS and sash but fails to boot IRIX, and the system failed diagnostics, specifically the Mother Board test, rebooting instead of leaving at a smdk> prompt. 20 The panic happens if you didn't boot into sash first. 21 Resetting account passwords can be done by booting into sash or accessing the drive in another Octane. 22 Recovery from bricking a drive, a risk when modifying the kernel, involves testing with a known good system like Zulu, then using sash to boot a backup kernel. 23 The dd command in SASH fails with a media error when attempting to write to a disk that is format corrupted.
