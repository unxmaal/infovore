root directory

Claims: 3 Part of root

The root directory is the location that must be set for network boot so that Solaris can find the install media, such as "/share/nfs/solaris/Solaris_10/Tools/Boot". 1 To clone a system, the root directory can be archived with tar, a new disk formatted, and the backup restored with untar, which preserves permissions. 2 In IRIX 5.3, the root directory and the /usr directory are separate, with missing space located in /usr. 3

Sources

  1. Setting the root directory for network boot to "/share/nfs/solaris/Solaris_10/Tools/Boot" is necessary for Solaris to find the install media. (user-1361, 2021-03-11, exchange 180583, check: supported)
  2. To clone a system, you can tar up the root directory, format a new disk, and untar the backup, preserving permissions. (user-b1da, 2024-02-01, exchange 177597, check: uncheckable)
  3. In IRIX 5.3, the root directory and /usr directory are separate, with missing space located in /usr. (user-e4e2, 2025-01-05, exchange 86228, check: supported)
