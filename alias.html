Alias

Claims: 72 Background: 2 claims already covered by Wikipedia, see Autodesk Alias, MAC address.

Alias was originally PowerAnimator, then bought out Wavefront, SGI, and Autodesk. 1 SGI sold Alias for 20 million and the acquisition made SGI more prevalent in the industry. 23 Alias going independent and releasing Maya for other platforms contributed to SGI's decline, and getting rid of Alias and MIPS was a mistake. 45 Alias was originally PowerAnimator, and animation features were stripped out to create Maya, leaving Alias Studio Tools for design and modeling. 6 Alias and Photoshop are historically significant software packages, and Jurassic Park was done in Alias and Softimage. 78 Alias switched to ELF in version 5.1, but the licensing mechanism continued to use COFF even in version 6. 910 Alias works in Irix 5.3, but older versions likely do not, and versions below 7 need old hardware and at most IRIX 5.3 for COFF support. 1112 Old software like the 'green' version of Alias was only runnable on a 5.3 system due to its COFF format, and the Alias version running in the picture is from 1993 and is COFF. 1314 Wavefront was advertised as the first commercial computer graphics package a studio could buy turnkey, followed by Alias. 15 Alias modeling tools became strictly modeling after version 9, with VFX and CG artists moving to Maya. 16 Alias removed animation features from PowerAnimator when renaming it to Studio Tools after version 9.x. 17 Alias and Softimage versions are available for download, with detailed version history including mental ray versions. 1819 Alias and possibly SoftImage were available for IRIX 4, and Alias has built-in support for the default IRIX driver in IRIX 6.x. 2021 Alias 7 and above will work on a modern IRIX 6.5 system, and IRIX can install Alias without issues. 2223 Alias 3 through 6 will run well on an Indigo, and the Indigo2 requires Extreme graphics for Alias and not IMPACT. 2425
