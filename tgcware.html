tgcware

Claims: 29

Tgcware is a software repository for IRIX, alongside SGI Freeware, Nekoware, and current repositories, and is one of the better sources for IRIX 5.3 basics. 12 It is a one-person project that is no longer updated, though it remains active on Solaris and provides a better shell experience, though not for older Solaris versions. 345 Tgcware provides separate binary sets for mips1/o32 and mips3/n32, with a mix of outdated and recent packages, and is available for IRIX 5.3, 6.2, and 6.5. 678910 Its builds are hosted on GitHub, with the original also downloadable from MediaFire, and a fork exists for local builds using didbs tools to create tardists. 111213 Installing packages often requires manually installing dependencies, extracting packages individually, and setting LD_LIBRARY_PATH due to non-standard install locations. 141516
