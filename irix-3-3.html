IRIX 3.3

Claims: 35 Part of IRIX Background: 2 claims already covered by Wikipedia, see IRIX.

IRIX 3.3 was a MIPS operating system intended for MIPS that predates the R3K Indigo1, and it was the first version of IRIX to include X11 and NeWS, as well as the first to support VGX. 123456 The installation media is IP12-specific but may boot an IP7, and installs likely came from tape, with newer versions able to use netboot and CDROM drives. 78 The Crimson can only use tape and network for installs with IRIX 3.3, and the PI runs IRIX 3.3. 910 IRIX 3.3 lacks desktop icons, using a workspace manager instead, and does not support 4dwm shell themes. 1112 dbx was available on IRIX 3.3 or earlier, and genimage and genprod are commands for creating installation packages for IRIX 3.3 in native inst format. 131415
