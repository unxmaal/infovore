SE/30

Claims: 46 Background: 5 claims already covered by Wikipedia, see Macintosh SE/30.

The SE/30 is a portable, fast, and cute Macintosh that was competitive with desktop formats when it was affordable. 12 It can handle up to 128MB of RAM, though 128MB can cause garbled screen issues that may require a multimeter to diagnose. 34 A/UX runs on the SE/30 but is sluggish at 16 MHz, and its ROM limitations do not prevent it from running, only affecting RAM addressing. 567 The SE/30 can boot from a 7.5 installer on a zip disk after installing 7.1, and does not require an updated ROM unless running macOS 7.6 or 8, which need a clean 32-bit ROM. 89 It can use a DMA system extension for the National Instruments IEEE-488 (GPIB) board, and can use chained adapters to run a Daystar Turbo 040, an external color monitor card, and Ethernet. 1011 The SE/30 can benefit from modern ROM SIMMs and SCSI2SD upgrades, and can use a 2GB drive. 129 The Macintosh SE/30 features a 68030 processor, significantly upgrading the base SE. 13 This upgrade makes it similar to a miniaturized Macintosh IIx. 13
