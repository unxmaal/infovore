swap

Claims: 10

Swap can be configured on external drive boxes, which can serve swap and /tmp, though such a box may currently serve another purpose. 1 Disabling swap improved performance in 64GB 32-bit machines with hugemem kernels, while running with swap could cause the machine to lock up. 23 Swap is generally better for active use when RAM is low because the CPU is already loaded, allowing it to work on other tasks while waiting for swap transfers, whereas compressing memory would slow things down. 4 8GB swap is standard for a low-powered Linux install, not a period-specific Unix install. 5 The user resized the partition to allocate 2GB for swap on their IRIX system. 6 Swap or VCFestival consignment events are good for buying and selling vintage computing equipment. 7
