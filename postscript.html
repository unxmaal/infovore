PostScript

Claims: 12

PostScript was initially used to standardize display formats for laser printers and later became a system GUI, leading to its eventual deprecation but continued use for 20 years. 1 PostScript runs on an R3000 processor and can effectively handle modern font rendering while remaining CPU-efficient. 23 SGI replaced PostScript with Ghostscript in IRIX 6.5.30, breaking Photoshop compatibility because Photoshop requires an earlier version of PostScript. 456 The .22 version is the last that runs on pre-O2/Octane systems and retains working PostScript, while late versions like .30 have broken PostScript so Photoshop does not work. 7 PostScript can be reinstalled on .30 by loading an applications CD or CD image from a .22 install under inst or Software Manager, since .30 lacks features like PostScript and requires overlays. 8910
