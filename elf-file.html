ELF file

Claims: 5 Part of ELF

  • The .so convention for ELF files may be misleading as it implies an .so is not an executable with a main(), even though ld.so is both an .so and an executable. (user-ecd0, exchange 69212, 2021-02-08; 1 speaker(s), 1 conversation(s))
  • objcopy can convert the ELF file to ihex format, which preserves the data section along with the text section. (user-8307, exchange 18356, 2021-07-11; 1 speaker(s), 1 conversation(s))
  • Quick starting ELF files and reconfiguring the operating system can be done but may not always work. (user-9219, exchange 60004, 2025-10-13; 1 speaker(s), 1 conversation(s))
  • ELF files can be loaded and remapped in IRIX, with preferred load addresses and relocation tables. (user-3e2d, exchange 215919, 2026-03-17; 1 speaker(s), 1 conversation(s))
  • An IRIX ELF file was shared on the software channel, possibly containing game data or debug references. (user-1a5a, exchange 210910, 2024-08-31; 1 speaker(s), 1 conversation(s))
