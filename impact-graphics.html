IMPACT graphics

Claims: 19 Part of Impact

IMPACT graphics is a workstation graphics option that supports hardware texturing, making it the first workstation graphics option capable of this feature. 1 R4K systems typically used pre-IMPACT graphics, while R10K systems used IMPACT graphics, and IMPACT graphics is identified by the color purple, with the exception of some late R8K Indigo2s. 23 The R8K processor was planned to support IMPACT graphics but never fully implemented, making IMPACT-ready R8K machines rare and valuable. 4 IMPACT graphics uses Rambus RAM and connects flat cables to related video I/O boards, with the MGV3 option providing video compression. 567 It limits texturing capabilities, making games like Quake unplayable without modification, and supports a dual head/2 user setup called CADDuo. 89
