NFS

Claims: 199 Background: 14 claims already covered by Wikipedia, see Network File System, File Transfer Protocol, Microsoft Windows, Network booting, XFS.

With IRIX

Linux can natively mount XFS filesystems used by IRIX and serve NFS, unlike macOS Mojave. 1 NFS works well between IRIX and Linux, BSD, and Sun machines, and works better than FTP or USB mass storage for file transfer. 234 NFS can fail on IRIX when updated by RH, requiring a proxy server, and reads larger than 8KB can crash the IRIX kernel, but setting wsize and rsize to 1024 fixes it. 56 NFS works fine on SGI systems from version 6.5.22, but older IRIX NFS does not work on TruNAS Scale. 78 NFS can mount an IRIX machine's homedir, but X11 integration with older SGI X-server is challenging, and the IRIX system can be accessed via telnet with NFS shares mounted. 910 To install software on IRIX, mount ISO images as virtual CD-ROMs and use rsync to copy files, then share the destination directory over NFS for installation, and network install of IRIX on an SGI Indigo 2 is possible using NFS. 1112 NFS requires the directory to be readable by the user that the UID on the IRIX machine maps to on the RHEL machine, and IRIX has a file size limit on NFS that may require the largefiles option, which may have its own limits. 1314 Setting up NFS between IRIX and Windows requires Windows Enterprise or Professional edition, and is cumbersome. 15

With FTP

Networking via NFS or FTP is quicker and easier than setting up serial ports for the Indy. 16 MAME supports networking, including NFS or FTP for file transfer. 17 NFS or FTP can be used to share files with a Win9x machine, though Git on IRIX is a better solution for project files. 18 NFS is considered better than FTP for networked storage. 19 NFS, FTP, or SCP can be used for SGI installs. 20 FTP is useful for transferring files but not for running commands, which requires NFS. 21 FTP, SCP, NFS, or networking in general can transfer files to an SGI Octane without an external CD drive. 22 NFS can transfer files over the network, and FTP is another option for file transfer. 23

General

NFS is a protocol for sharing files between machines, allowing shares to be mounted on other computers to transfer files or integrate remote storage into the local filesystem, including mounting read-write from a subnet. 242526 NFS is supported on a range of systems, including Linux, Mac OS, Windows 10 Pro (via optional features, third-party services, or WSL), and Unix machines, and can be used to back up Unix systems by tarring to NFS and untarring. 2728293031 NFS supports asynchronous writes at the cost of potential data loss, and can offer stateless high availability by moving the IP to a new host and sending a gratuitous ARP. 3233 NFS can have failure modes, including stale mounts that block write calls, failure to recover from network failures, and version conflicts. 343536 NFS permissions require proper domain control setup, with users needing to be the owner of a directory or part of the group that owns it for write access. 3738 NFS is used in various installation and booting contexts, such as netbooting Solaris from a Linux jumpserver, installing IRIX software via NFS, and sharing installation files via booterizer. 3940414243 NFS is a network file sharing protocol that can be used to copy files between systems and share data across machines. 4445 It has been used on a variety of systems, including IRIX, Solaris, HP-UX, FreeBSD, and Linux, and can be added through software installers or network installed. 4647484950 NFS can be mounted without GUI tools by adding entries to /etc/fstab or /etc/vfstab, and system administrators still perform tasks like mounting NFS drives. 515253 NFS performance can be suboptimal, particularly with many small files, and disabling attribute caching with noac can increase IO operations and decrease performance. 545556 NFS hard mount can cause clients to get stuck indefinitely if the server becomes unreachable, while soft mount allows clients to timeout after a number of retries. 5758 NFS can be used to address the problem of expensive disks by using networked storage, and can be exported over NFS from a mountable ISO. 5960 NFS is a protocol for file sharing that dates to the mid-1980s; although it should have been replaced long ago, its benefits often outweigh its downsides. 6162 It is used to share files remotely and for file transfer between machines, and it is a de facto standard for Linux HPC and AI storage. 636465 A plain old Linux server can serve as a NAS, and NFS can be used for file transfer with a Linux server, with the server component being optional and available from the NFS CD without a license. 666768 It is easy to set up, can be used for installing packages, and is used to install software over the network. 6970 It can boot a target by loading the kernel via NFS, a process that involves acquiring an IP address, obtaining a bootloader via TFTP, and booting the kernel via NFS. 7172 Diskless NetBSD can be run from an ND server exposing raw filesystem blocks to the client, with the kernel name passed as an argument. 73 It is used to access filesystems remotely, such as an Octane's filesystem, and shares have worked across SGI, Linux, and Mac systems for easy file movement. 7475 It can be used for managing multiple machines, and automount can be used for non-GUI NFS clients to mount shares when accessed. 7677 NFS is a network protocol that is distinct from SMB/CIFS, SSH, and RSH. 7879 NFS can be used across various vintage Unix machines, but different versions of NFS introduce significant incompatibilities that can prevent proper functionality. 80 NFS should work with older standards but may have compatibility issues with newer servers, and the latest version of Truenas doesn't support older versions of NFS. 8182 NFS can be mounted over IP for software-based disk imaging and can be used to share USB storage on IRIX. 8384 NFS can work with NAT but may require allowing non-privileged ports, and a firewall on the Linux box may need to be configured to allow NFS traffic. 8586 NFS can be configured with -o soft,intr to handle server downtime better. 87 IRIX patches fixed NFS and DNS issues, restoring barrier functionality. NFS can be used for network installation by loading install disks into separate folders, mounting a NAS is an option for netbooting, and xfsdump to an NFS mount followed by a restore can recover files.
