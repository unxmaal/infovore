Debian

Claims: 93 Background: 28 claims already covered by Wikipedia, see Debian, Ubuntu, Extent File System, FreeBSD, Itanium, Remote Shell, SPARC.

Debian is a stable Linux distribution that runs without a graphical interface and sees all attached memory and processors. 123 It is used for servers and shell machines, and some workplaces have switched from Debian to Devuan. 45 Debian is preferred over Ubuntu due to less cruft, and it is used in a full container within modern ChromeOS. 67 Debian removes firmware to accommodate Stallmanites, making it less user-friendly for those who want working hardware. 8 Debian dropped support for old 32-bit MIPS architectures, which may affect running Debian on an Indy. 9 Debian no longer supports PPC64, only ppc64el for Power8+, and only supports back to POWER8 and POWER9 for its official releases. 101112 Debian ran well on IA64 but lost support without propack, and an IA-64 Debian installation does not boot, though IA-32 does. 1314 Debian has unaligned access issues. 15 Debian is a Linux distribution that supports a wide range of hardware configurations, though its compatibility varies depending on the specific system. 1617 It can run on many platforms, including Power9, Talos II, Itanium, PowerPC, MIPS Cobalt machines, and older RS/6000 systems. 1819202122 The main differences between Debian and other distributions such as RHEL, Arch, Slackware, and Alpine lie in the init system, package management, and package selection or configuration. 23 Debian uses systemd as its init system, and it ships with an FTP client. 2425 Stock Debian does not mount EFS by default but can be recompiled to support it. 26 Debian can boot into tty mode by modifying the target in the systemd configuration. 27 Some users find Debian easier to use, while others prefer RHEL and Fedora. 2829 Debian's documentation is consolidated but sometimes hard to navigate. 30 Debian has hardware support issues on some systems, and 3D graphics can be more challenging than 2D graphics. 3132 Debian prior to version 7 didn't include proprietary drivers on installation media, requiring users to add the non-free repository manually. 33 For Linux on MIPS, Debian 7 or 8 might work, or contact Kaloz for recent kernel support on IP35 and possibly Octane. 34 A minimal Debian installation can be done by starting with a netinstall CD, unchecking everything, and then apt-getting what is needed. 35 Debian can support EFS with modprobe efs. 36 rsh is a command that can be a symlink to ssh under alternatives on Debian, and can be installed with rsh-client. 37 Debian transitioned userland time_t to 64-bit for 32-bit programs, which caused issues with broken packages. 38
