IRIX 6.5.7

Claims: 10 Part of IRIX 6.5

Leaked versions of IRIX 6.5.7 exist, along with leaked versions of 6.5.5 and possibly 6.5.17. 1 The 6.5.7 release is available under an NDA. 2 The TAP/TUN driver can be used to bridge network connections in IRIX 6.5.7. 3 Using an .iso of IRIX 6.5.7 is recommended over an .img file for better compatibility with MAME. 4 The PROM for the IP22 contains unused code to play a sample of Doug Cook saying 'it is alive', but the 6.5.7 leak does not include PROM code. 5 The IP26 PROM might support IMPACT, but the /stand from 6.5.7 is incomplete and missing origin stuff, and there is no support for MGRAS in the IP26 PROM source code from the IRIX 6.5.7 leak. 67 IP32's bridge handling is iffy, with 6.5.30 being much better, and 6.5.22 and 6.5.7 sources mention external PCI extension box support but did not test it. 8 A webserver was found running IRIX 6.5.7. 9
