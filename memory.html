memory

Claims: 81 Background: 4 claims already covered by Wikipedia, see Graphics processing unit, Random-access memory, SGI Indigo2, XIO.

Memory compatibility varies by system: a DEC PC may not work with memory from a PWS, and regular non-ECC SD-RAM should be tried for a DEC PC, while registered ECC memory may not work on a board that does not support it. 123 Some systems impose memory limits, such as hardware that cannot use more than 1 GB of memory because internal memory mappings for PCI are hardcoded to work only with 1 GB, and a limit of 1 GB according to a leaked CRIME 1.5 spec that may be preliminary. 45 Certain systems require memory to be added in specific groupings, such as the Indigo2, which requires memory in groups of 4 SIMMs with the closest to the CPU filled first and has 12 SIMM slots, and a motherboard that uses memory in groups of 6. 678 Memory issues can often be resolved by reseating components, as random POD errors can be fixed by reseating memory, an amber light on an SGI system typically indicates a memory or memory slot issue that reseating may resolve, and a missing bank or DIMM would explain complaints about contiguous memory. 9101112
