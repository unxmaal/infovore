QuickBasic

Claims: 5

QuickBasic was a paid product, while QBasic was a cut-down version that shared its compiler and mostly compatible standard libraries. 1 QuickBasic can be converted to C on SGI systems. 2 QuickBasic could be run on SGI systems using SoftWindows, and its applications could be run using SoftWin95. 3 QuickBasic can also be run in SoftWindows on IRIX. 4
