license file

Claims: 11 Part of license

To fix MIPSpro nagging, copy a license file from a Google Groups post into /var/flexlm/license.dat. 1 To run MATLAB v5 on IRIX, place the license file in /usr/local/Matlab/Matlab.R9_v5.1/etc/license.lic and launch with `matlab -sgi -c /usr/local/Matlab/Matlab.R9_v5.1/etc/license.lic` or copy the file to license.dat. 2 MATLAB v6 can be launched by placing the license file in /usr/local/Matlab/Matlab.R13SP1_v6.5/etc/license.lic and simply typing `matlab` in a shell. 3 Editing the license file was necessary to pass the installer for Pro/E v16. 4 The Sun WorkShop Compiler C requires a license file that must include information about the product; the license file must be correctly installed and referenced by the compiler. 5 To set up the drive, use sw_config, apply the date patch, and place the license file in /etc; choose the filesystem type in init.cfg. 6 cpu_id reports the CPUID, matching the license file and ProE utility. 7 The HASP dongle generates an ID code which the software can read, and a matching license file is needed from the provider. 8
