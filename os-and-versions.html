OS and versions

Claims: 31 Part of OS

The binary format changed from COFF in 4.x and earlier to ELF in 5.x, which could still run COFF, and COFF support was dropped in 6.x. 1 The GNU linker does not understand the -n32 option, while the IRIX linker does. 2 Installing IRIX development libraries can result in conflicts that require a new distribution, especially if using the GUI installer. 3 In IRIX 5.3, /usr/local/bin exists but is empty, while /usr/local/lib might be empty as well. 4 types.h is included in package eoe1.sw.unix and can be installed from the IRIX 5.3 distribution CDROM if missing; its full path is /usr/include/sys/types.h. 5 The makefile for FSN on IRIX 5.3 fails due to missing directories, and altering the makefile or using /usr/bin might help. 6 The system was running IRIX 6.5.x with libraries from an older or incompatible patch level, causing unresolvable symbol errors. 7 Resetting the MAC address after booting up can fix boot errors and speed issues on IRIX systems. 8
