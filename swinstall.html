swinstall

Claims: 6

swinstall is a tool used to install software packages on HP-UX systems. To install a package, you download the depot file, gunzip it, and run `swinstall -s /full/path/to/file.depot` as root, where `$PWD` can be used as a shortcut for the current directory. The recommended way to install .depot files is `swinstall -s /path/to/file.depot`, and you can also install depots using commands such as `sw - 123456
