GTK

Claims: 8

GTK is difficult to work with on platforms other than GNU/Linux or a modern BSD. 1 When GTK switched to local font rendering and XRANDR, it broke many applications, though remote X on an SGI was not affected. 2 GTK on IRIX has text shaping issues due to Harfbuzz, which requires a recent compiler, making building with GCC challenging. 3 The anti-aliased font settings in GTK on SGI apps are software rendered and can be turned off, though the exact method is unknown. 4 GTK on IRIX enables the use of many other applications. 5 Running Discord on SGI requires setting up a server with Discord installed and SSH remote X the program; it works on a laptop but fails on the user-5510 with an X window system error, possibly fixed by installing new GTK. 6 Chromium, GTK, and Wine are being ported to Haiku for the next beta release. 7 XFCE aims for a unifying vision with GTK making composited windows easier, though it historically avoided GNOME's desktop-mobile unification. 8
