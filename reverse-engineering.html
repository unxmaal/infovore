reverse engineering

Claims: 8

IDA Pro can be used to reverse engineer binaries, and Ghidra supports MIPS but may have issues with SGI MIPS binaries. 1 Reverse engineering involves understanding software behavior and providing the correct data through emulated hardware, even if the original hardware is not fully reimplemented. 2 Reverse engineering SGI PSUs could provide valuable information for repair and replacement. 3 Documenting the PROM code could help others reverse engineer it. 4 The IRIX 6.5 development set includes unstripped binaries and private headers for debugging user programs, making reverse-engineering more accessible but also exposing proprietary code. 5 Reverse engineering efforts can focus on kernel and user land code of IRIX, with no current plans to include GL code. 6
