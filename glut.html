GLUT

Claims: 26 Background: 4 claims already covered by Wikipedia, see OpenGL.

GLUT is a library that provides a window, a game loop, mouse and keyboard event callbacks, and an idle loop, handling setup and input while OpenGL handles graphics. It allows creating windows, initializing OpenGL, and handling input in a platform-independent way.
