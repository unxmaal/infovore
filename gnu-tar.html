GNU tar

Claims: 17

GNU tar is a tar implementation that can be called gtar or gnutar on IRIX and uses syntax similar to sysv tar. 1 GNU tar can strip the leading '/' when extracting files created with absolute paths, while IRIX tar can preserve it. 23 GNU tar can create relative paths in tar files to avoid tar bombs, and can handle / directories without errors. 45 GNU tar does not automatically detect compression, unlike IRIX tar, and may not warn when creating an empty archive. 67 GNU tar is necessary for the didbs installation process and the Oolite installation, and can be added to pigz.c to build with the latest GNU tar. 8910

Sources

  10. Adding #include <stdint.h> to pigz.c allows it to build with the latest GNU tar. (user-ba81, 2019-02-09, exchange 214737, check: uncheckable)
