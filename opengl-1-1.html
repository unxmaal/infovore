OpenGL 1.1

Claims: 25 Part of OpenGL Background: 14 claims already covered by Wikipedia, see OpenGL, IRIX, SGI Octane.

OpenGL 1.1 is supported by most SGI systems, including the O2 and the Octane with its MXE card, while the Octane/Tezro with VPro and the Indigo2 Extreme support OpenGL 1.2 and 1.0 respectively, with the latter using some OpenGL 1.1 features through extensions. 123 IRIX 6.5 provides OpenGL 1.1, whereas IRIX 6.2 and 5.3 offer only OpenGL 1.0 for textures, and the O2 can use OpenGL 1.1 or lower for its software renderer. 45 OpenGL 1.1 with ARB image extensions is available on the O2 for demo making, and OpenGL 1.1 on the O2 includes TextureObject, which improves texture handling by storing textures on the graphics card and referencing them by a single ID. 67 Visualize FX cards support OpenGL 1.1, while earlier Visualize cards do not, and OpenGL 1.1 with some 1.3 extensions is reported by hinv. 89 OpenGL 1.1 was initially released in 1996, and the OpenGL ICD for 3dfx was released in time for 1999, while Nvidia TNT already had an OpenGL ICD supporting a subset of OpenGL 1.1. 1011 Homeworld is an OpenGL 1.1 game with source code available on GitHub, Minecraft was pure OpenGL 1.1 until version 1.8 with some ARB_occlusion_query calls, and the PC version of the N64 Zelda games requires OpenGL 1.1 for running Zelda 64 on IRIX. 121314 OpenGL 1.1 is a general prerequisite for Minecraft along with Java 5 or newer, LWJGL 2, and 192 MB RAM, and it is required for several ports, with some supporting up to Java 8. 1516 xmame's OpenGL implementation can be adapted from OpenGL 1.2 to 1.1 for the O2, though full speed is achieved with 1.2, and applications still use OpenGL 1.1 with bugs from 25 years ago. 1718
