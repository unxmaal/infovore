memory modules

Claims: 16 Part of memory Background: 1 claim already covered by Wikipedia, see SGI Octane.

The 800's memory modules are expandable, while later 8bits had no internal memory. 1 The Octane with the 030-0887-00x mainboard can use up to 512MB or 1GB memory modules, while later mainboards offer better compatibility with these memory sizes. 2 The MPX brick is an O350 compute node without CPUs but provides up to 8 memory modules through the numalink port. 3 Memory modules from different speeds have different POST results; a 400MHz module fails POST while a US-I/200 does not, and shipping can damage cache heat sinks, leading to POST failures. 4 Indys need a full bank of 4 memory modules or 2 banks of 8 modules to run. 5 Memory errors can occur with mismatched DIMMs or correctable hard memory errors, indicating potential issues with the memory modules themselves or their configuration. 6 The memory modules on G4s can be difficult to unlock due to poor mechanical design, and reseating may be necessary. 7 The O2's memory modules are fragile and require careful reseating. 8
