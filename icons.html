icons

Claims: 8

Old desktops lack icons, Wi-Fi configuration, and sleep functionality. 1 To create icons for CDE, duplicate the image three times, downscale, convert to indexed color with 16 colors, convert back to RGB, and export as .png and .xpm, checking and saving because GIMP may cut away transparency edges. 2 There used to be a repository with SGI icons in SVG format, but it was removed for copyright reasons, and it can now be found at https://web.archive.org/web/20201111180416/https://github.com/n-kremeris/irix-icons-linux. 34 /etc/passwd contains an entry for the demos user, and there is an .icons directory in /usr/demos with relevant files. 5 The O2 has issues with icons not loading, even on the root account. 6 Icons for programs can be referenced in a comment in the shell script starting the program and should be placed in /usr/local/lib/faces. 7 The SGI IRIX 7.1 demo is missing some files like .login, .icons, and .auxchestrc, but can still be used without them. 8
