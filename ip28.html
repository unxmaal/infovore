IP28

Claims: 25

The IP28 is an SGI workstation that can run Linux, for which the Linux kernel was patched to support the IP28 architecture and GCC patches were also required. 1234 The IP28 is unsupported, and none of the IP22 stages are bootable. 5 The L2 controller on the IP28 runs kernel 2.4.7, and an IP28 can run a 2.6 kernel. 67 IP28 boots with an r10k ISO from T/2 SDE Linux but experiences segfaults, and a Gentoo nfsroot image is also available. 8 The IP28 has issues with OpenBSD/sgi, with OpenBSD 7.2 being the version that first showed problems on IP28. 910 OpenBSD/sgi 7.0 - 7.4 works on IP22, IP27, IP28, IP30, and IP32 with specific CPU types. 11 Tape can be used to restore IRIX installations but not to boot versions earlier than 6.2 on IP28. 12 A weak solder joint on the PS/2 socket can cause keyboard issues on an IP28. 13
