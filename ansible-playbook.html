Ansible playbook

Claims: 9 Part of ansible

The Ansible playbook serves as live documentation for the process of building IRIX root. 1 The playbook will not re-extract IRIX root if the yaccpar file exists. 2 Ansible playbook `master_setup.yml` configures an IRIX Octane, but users should review and customize it as needed. 3 The Ansible playbook fetches and installs Nekoware bundles on an IRIX box, using `mkdir -p /usr/nekoware && chmod 755 /usr/nekoware` to create the Nekoware directory. 4 The bootstrap.yml Ansible playbook configures SSHD, ensuring SSHD is running, and can be customized to run specific tasks. 56 To apply changes, run the Ansible playbook and reboot the system. 7
