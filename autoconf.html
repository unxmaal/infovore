autoconf

Claims: 9

Autoconf is a tool used for configuring source code trees, and it performs checks by examining headers and determining the presence of functionality, which is faster than compiling and executing everything. 1 Autoconf has good documentation but is janky and time-consuming to learn. 2 The message about a working Fortran 77 compiler is frequently displayed during autoconf checks. 3 Feeding a preseeded config.cache to autoconf projects can help skip many checks but the process will still be slow, and creating a repository of config.cache outputs for reuse is impractical due to frequent regeneration of configure files. 45 When building with autoconf, setting SHELL and CONFIG_SHELL to a custom path can override hardcoded paths in the build process. 6 The Makefile calls configure and autoconf on its own, ignoring flags from the Spec file, causing issues with linking. 7 The most current versions of autoconf and automake are available, with automake planned to lose IRIX support in version 2.0, and version 2.0.6 uses Autoconf for maintenance. 89
