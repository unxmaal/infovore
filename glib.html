glib

Claims: 14 Background: 2 claims already covered by Wikipedia, see NetSurf.

glib is not glibc and is a different thing. 1 Building glib requires python 3.5, and glibmm and glib versions match on the minor version level. 23 irssi requires glib 2.28, though an older version might work, and UTM requires compiling dependencies including Meson and glib. 45 netsurf is still being developed with issues with glib, and it is built in C# and requires gtk2 or glib. 67 Compiled versions of early GIMP, GIMP extras, freefont, glib, gtk and sane are available for IRIX, starting from version 1.0.0 of GIMP, found on ftp.funet.fi which had a copy from ftp.easysw.com. 8 mpv lacks dependencies on cairo and glib, making it potentially easier to implement on IRIX compared to mplayer. 9 rpmifying the latest glib can introduce the volume manager patch, and glib respects the XDG_DATA_DIRS environment variable if it's exported, but the default value is hardcoded. 1011 user-757f has a lot of cursed dependencies, including glib, iconv, and libffi. 12
