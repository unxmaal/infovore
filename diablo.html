Diablo

Claims: 14 Background: 1 claim already covered by Wikipedia, see DOSBox.

Diablo can run in fullscreen, but resolution scaling is not supported by IRIX X. 1 It runs well on an Octane/400/MXE but at a lower resolution, and requires a 24-bit graphics setting and a sufficient swap file to run without errors. 123 Ports of Diablo have been done recently, and on IRIX DOSBox can be run natively so games like Diablo can be played without emulation. 45 Diablo runs on the devilutionX project on SGI, though the speaker prefers to run the original on a Win9x PC. 6 SoftWindows can run Diablo at full speed on an O2, though it is emulated, while Diablo has issues on Indy or O2 systems and does not run on an Indigo2 due to missing dependencies. 789 Lightwave 3.2 runs on IRIX and has PC backported games like Diablo, with a unique icon set. 10
