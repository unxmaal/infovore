T2 Linux

Claims: 9 Part of T2 Background: 1 claim already covered by Wikipedia, see SGI Octane.

T2 Linux has been successfully used since v6.9-rc1. 1 T2 Linux supports the Dreamcast, though its performance is unknown. 2 ArcticFox has been ported to MIPS platforms running T2 Linux by Rene. 3 T2 Linux requires a minimum PROM version, with 4.43 referenced for SUSE Linux Enterprise Server 9 SP3, though later PROM versions may not be compatible with older SUSE versions. 4 T2 Linux on Octane has abysmal support and lacks hardware acceleration, though it might be possible to run it with a PCI ATI graphics card and hardware acceleration. 56 The Altix is cheaper than MIPS-based systems and can run modern T2 Linux. 7
