4MB SIMMs

Claims: 3

The PI IP6 does not support 4MB SIMMs, and some 4MB SIMMs worked in an IP10 but not in an IP6 or IP4. 1 The PI IP6 requires 1Mb SIMMs instead of 4Mb SIMMs. 2 Some 4MB SIMMs, specifically some Toshiba ones, can be used in an IP6 without triggering the PROM bug, which is not confirmed to affect all IP10 PROM versions. 3

Sources
