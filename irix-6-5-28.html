IRIX 6.5.28

Claims: 8 Part of IRIX 6.5

IRIX 6.5.28 runs on the SGI Octane2 with a R12000 CPU at 400 MHz or a R14000 CPU at 600 MHz, and on the Octane, but has glitches on IP35. 12 It can be used to restore an O2, but an O2 running IRIX 6.5.28 with an old prom version required a manual update and sometimes needed a power cycle to boot. 34 The discs are not .isos but can be burned using tar. 3 The Discreet manual mentions IRIX 6.5.28 for later revisions of the software. 5 An nfs CD for IRIX 6.5 may not work with IRIX 6.5.28, so to install NFS on an IRIX 6.5.28 machine the ONC NFS disc is required, which contains NFSv3 for IRIX 6.3, 6.4, and 6.5. 67 The problem with IRIX 6.5.28 was resolved by reinstalling with 6.5.29; the fix was found on the HPE support site. 8
