O2 PROM

Claims: 10 Part of O2

The O2 PROM supports R4x00 CPUs and references R4K machines, indicating commonality with later models. 12 It sets CPU configuration parameters such as bus speed, core speed, and cache details, and can be flashed externally via USB or serial, configuring the system regardless of power state. 3 The O2 PROM has multiple versions, with the latest being 4.18 and earlier versions found in IRIX 6.3 overlays. 4 SGI's IRIX source code includes O2 PROM source, available up to version 6.5.7. 5 A toolchain exists to dump and reassemble O2 PROM contents, and it can be analyzed using Ghidra to verify details. 67 It compares the CPU COP0 COUNT register to the CRIME fixed 66 MHz CRM_TIME base register, and the math can be wrong for some CPUs. 8
