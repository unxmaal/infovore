Worker

Claims: 7

Worker is a dual-pane file manager for SGI platforms, being a clone of DirectoryOpus (DirOpus), which was popular on the Amiga around 30 years ago. 123 It offers a Dopus-like experience, is very configurable, allows separate left/right actions, and includes a superior Git client with a git gui that feels like an outside app but is useful and functional. 435 It requires many dependencies and cannot be easily packaged as a tarball, is included in RSE (fixed since re-compilation), and is available in the sgug-rse repository for IRIX. 265 It is also available in the bundle at https://packages.mogrix.user-2189.com/bundles/worker-4.12.1-3-irix-bundle.0324261901.run. 7
