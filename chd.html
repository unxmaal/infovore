CHD

Claims: 7 Background: 1 claim already covered by Wikipedia, see MAME.

CHD is MAME's block-compressed drive format, used by the disk image. 1 To use an ISO as a bootable image on IRIX, it must be renamed to ISO or converted to a CHD. 2 Adding a new file to MAME's softlist requires dumping it to BIN+CUE (preferably MODE1/2352), converting it to CHD using chdman, and using the SHA1 to create a new XML entry. 3 Adding Alias3 (PowerAnimator3) or Maya to MAME involves creating CHDs and adding XML entries, with MAME64 validating the softlist. 4 A BSD-licensed version of full CHD support is being developed in Rust, with some performance impact on one codec. 5
