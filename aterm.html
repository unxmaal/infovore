aterm

Claims: 23

aterm is a terminal emulator used on SGI systems. 1 It can have a transparent background, though the sgug aterm does not support this feature. 23 The 'fake' transparency option works with certain command options in aterm, and it can be enabled by recompiling with a patch. 45 aterm requires specific fonts ('k14') to function, and missing these fonts causes the program to fail. 6 Compiling aterm may resolve font issues, and it requires the xorg-x11-fonts-misc package to resolve font errors. 78 aterm works fine with ncurses apps, while other terminals mess them up, but ncurses is not well-supported in winterm, aterm, or other terminals. 910 It checks the SHELL environment variable, falls back to getpwuid, and uses /bin/sh if the shell is not set, with /bin/bash as the last resort. 11 If aterm fails to start, it may be due to environment or PATH setup, or conflicts with nekoware dependencies. 12
