Windows 2000 Pro

Claims: 3 Part of Windows 2000

The VW320 boots into an ARCS bootloader that loads a Windows 2000 Pro installer in a sandboxed window. 1 Windows 2000 Pro can be used for installation, but SGI-specific drivers are needed afterward, and firmware updates, especially for faster CPUs, are required. 2 Windows 2000 Pro has a two-core limit. 3
