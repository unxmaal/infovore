Gentoo

Claims: 66 Background: 19 claims already covered by Wikipedia, see Gentoo Linux, FreeBSD, SGI Altix.

Gentoo can be installed on platforms that other distributions do not support, including unsupported architectures such as IA-64 and Itanium, where it is the only up-to-date and modern Linux distribution, though it is difficult to use and still technically supports IA64 builds despite lacking kernel support. 123456 Gentoo can run on various PowerPC machines, including the G5, Powermac G4, and older R5K O2, though it does not support R10k or 12k O2s and the O2 is generally considered unsuitable, with some users reporting that it needs plentiful RAM and that setting up ALSA and Xorg may be challenging. 7891011 Gentoo can be built on older and odd architectures such as the 733 MHz G4, Pentium 133, Indy, and Ultra 10, but building on these was time-consuming and took a month to become functional, though developing on PowerPC and MIPS architectures was better prioritized in the Linux community in the past. 121314151617 Gentoo can be bootstrapped from any OS by extracting a stage 3 and using emerge, and it has a portage system for upgrades and security fixes, with 90% of the process covered in the handbook. 181920 Gentoo excels at custom installs with fine-grained control and is used for embedded systems to target different hosts and build a userland, as well as for desktops that allow hassle-free migrations, but it can be difficult for new users and struggles with version cherry-picking. 1212210 Gentoo is not more widely supported on SGI machines than OpenBSD, and there is a belief that its stages do not support the IP22 architecture, though it does have a port that is not widespread. 232425 Gentoo is a Linux distribution that provides a binary distribution for new users and a User Repository (GURU) for packages not found in the main repositories. 2627 Portage, Gentoo's package manager, can handle simultaneous compilation of multiple packages by checking dependencies and system resources, compiling packages one at a time in a chroot environment if necessary. 28 The Gentoo distribution kernel project is considered great for users and often fixes bugs, such as those related to SandyBridge and XFS inode sizes. 2930 Gentoo is being tested on SGI boxes to fix packages for MIPS, with plans to dualboot Octane2 with IRIX. 31 Gentoo does not have working IP22 stages, and X support is experimental on other machines except the IP30. 32 The IP30 v6 pro has framebuffer support in Gentoo but also experiences kernel panics. 33 For RISC systems, installing Gentoo requires creating a set of binaries on an AMD64 box using qemu-user, otherwise the installation can take 4-5 days for a 400 MHz G3. 34 To support RISC architectures for Gentoo, one needs exotic hardware like an nbus device. 35
