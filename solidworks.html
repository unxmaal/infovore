SolidWorks

Claims: 60 Background: 2 claims already covered by Wikipedia, see OpenGL, SolidWorks.

SolidWorks is a Windows-only CAD program, originally built for the Windows market starting on NT and Win95, with no confirmed ports to other platforms. 12 SolidWorks has the largest market share in CAD, with ProE being a major player, and became the standard in colleges after 1998 when colleges switched to laptops. 34 SolidWorks has multiple tiers with different features, now called Standard, Pro, and Premium. 5 For SolidWorks, certified drivers and hardware are recommended, with Quadro and Radeon Pro WX cards suggested due to specialized drivers and features like RealView mode. 67 SolidWorks requires OpenGL 3.2 or higher for optimal performance and 1.4 for basic compatibility. 8 CAD software like SolidWorks has tools to automatically create threaded holes, including a hole wizard that provides standard integration. 910 SolidWorks can export CAD files in multiple formats including IGES and STEP, and has good compatibility with AutoCAD. 1112 SolidWorks has had a history of releasing updates that introduce bugs and require multiple service packs to fix. 13 SolidWorks is a CAD application that has had Alpha NT versions and is tightly integrated with Windows APIs, making it difficult to port to other operating systems. 1415 SolidWorks can be run in a Linux virtual machine with dedicated graphics card passthrough, and some users run it in an isolated VM. 1617 SolidWorks 2022 requires OpenGL 3.2 or higher, and 2025 requires OpenGL 4.5 or higher. 18 SolidWorks does compatibility testing and certifies systems and driver versions, but it can have rendering issues with graphics drivers. 1920 SolidWorks can compare CAD files and measure surface deviations, and can open assemblies with SubD features created by PowerSurfacing. 2122 SolidWorks has a decent add-in ecosystem, including integrated SolidCAM which can automatically generate toolpaths. 2324 SolidWorks part files contain compressed archives with models, and CAD models can exceed 1GB, requiring significant RAM to handle larger assemblies. 2526 SolidWorks educational version files are watermarked, and the software can be pirated. 2728
