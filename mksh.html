mksh

Claims: 9 Background: 1 claim already covered by Wikipedia, see Bash (Unix shell).

mksh is 100% compatible with ksh88 and is faster, more actively developed, and fixes some bugs like color processing. 1 There are no syntax incompatibilities, and pretty much every SGI supplied program and most popular software worked with mksh. 2 mksh is a good alternative to /bin/sh for those preferring something other than bash. 3 Switching to mksh improved the performance of a 33 MHz machine significantly, and it is twice as fast as bash at opening up/responding on a 68k, making almost anything much faster. 45 Building bash on IRIX is possible and can be done using a script that spawns mksh, which then downloads and installs bash. 6 irixports provides an example plist for mksh. 7 mksh reads /etc/profile.d/which2.sh even though bash should not read it; this file is likely only for /bin/sh and can be deleted or renamed without ill effects. 8
