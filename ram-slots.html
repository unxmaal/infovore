RAM slots

Claims: 10 Part of RAM Background: 3 claims already covered by Wikipedia, see SGI Indy, SGI Tezro, SPARCstation 20.

Some systems allow odd numbers of RAM slots, such as the Sparcstation 20, which can use a VSIMM to produce amounts like 400 MB from 64 * 6 + 16 slots. 1 Certain CPUs should not use specific slots, such as the R12K, which should avoid the top two RAM slots because it overheats. 2 RAM slots are sometimes located near the PSU, as on the Indy motherboard, where the first bank fills closest to it. 3 Heatsink placement can interfere with RAM slots, as the PM1 heatsink can block one bank of RAM slots while improving cooling. 4 RAM slots have been associated with hardware failures, including an inductor blowing around the RAM slots on a revision D board and laptop RAM slots coming off the board. 56 Some systems add RAM slots to increase capacity, such as the AS255 and AS200 differing by two extra RAM slots and the MPX adding four RAM slots. 78

Sources

  2. The R12K CPU should not use the top two RAM slots as it gets overheated. (user-e872, 2021-07-24, exchange 205290, check: supported)

  4. The PM1 heatsink can be installed in a way that it blocks one bank of RAM slots, but it improves cooling and prevents the PSU from fast-faning. (user-03ad, 2024-02-25, exchange 223728, check: uncheckable)
  5. A revision D board had an inductor blow around the RAM slots. (user-86c4, 2022-08-05, exchange 207481, check: uncheckable)
  6. Laptops have experienced RAM slots coming off the board, requiring a fix with props. (user-0de0, 2026-08-05, exchange 214359, check: uncheckable)
  7. The AS255 and AS200 differ in having two extra RAM slots and using EV45 instead of EV4. (user-6e7b, 2025-07-22, exchange 235713, check: supported)
  8. The MPX adds four RAM slots and 8 GB of RAM, allowing the Tezro to support up to 4 processors and 16 GB of RAM, including NumaLink and a total of 8 PCI slots. (user-e4d0, 2025-10-31, exchange 119478, check: supported)
