XGL

Claims: 15 Background: 3 claims already covered by Wikipedia, see OpenGL, QEMU.

XGL is a proprietary graphics API that served as the interface for the graphics tower and ZX, and was also supported on Creator3D and Elite3D hardware. 123 XGL may be based on PHIGS, as the ZX supported SunPHIGS and potentially XGL, with OpenGL added later. 1 XGL is supported on the ZX but not on Solaris 2.8 after version 2-02, and it requires xview. 345 OpenGL can be translated to XGL using a library that handles the calls, though games may need adaptation for performance issues. 6
