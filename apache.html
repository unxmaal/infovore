Apache

Claims: 5

Apache is used to run network services on a dual CPU PowerPC VME board running AIX. 1 The Sunfire V245 runs Solaris and can serve as a personal www server with Apache, as well as record video using ffmpeg. 2 Older Apache on IRIX has hardening guides, and the idea is to use an nginx proxy for filtering on retro SGI servers, disabling all but GET requests initially. 3 nginx was written to handle connections with worker pools using epoll instead of one thread per connection, while Apache struggled with many threads. 4
