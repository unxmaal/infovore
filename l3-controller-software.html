L3 controller software

Claims: 3 Part of L3 controller

The L3 controller software for SGI systems includes various RPMs for drivers and tools, and can be installed on an early RedHat Linux system. 1 L3 controller software for Linux can emulate the L2 controller and taps into the L1 port on newer systems. 2 The L3 controller software can be obtained from the IST CDROM 3.24 and a blog post, with a download link available. 3
