glibc

Claims: 21 Background: 4 claims already covered by Wikipedia, see Glibc.

glibc is the GNU implementation of the C library. 1 glib is not glibc and is a different thing. 2 cen64 includes sys/cdefs.h, an internal glibc header, and programs should not include it. 3 On Linux, statically linking with glibc requires the same version at runtime as build time. 4 Python is slower on systems using ulibc compared to glibc. 5 glibc security fixes can break shell scripts. 6 RISC-V Linux (kernel 4.20, glibc 2.29) requires a stdlib. 7 The GCC version check for glibc 3.4 or newer incorrectly includes versions 4.0-4.9. 8
