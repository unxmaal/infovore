alternatives

Claims: 4 Background: 1 claim already covered by Wikipedia, see Remote Shell.

alternatives manages multiple packages providing similar functionality via symlinks, and is used to set default applications, like EDITOR. 12 To check if an alternative has been installed, you can use `alternatives --display $NAME`, which prints to stdout if the alternative exists, or `alternatives --list | grep $NAME` to see if anything gets returned. 3 For example, rsh is a command that can be a symlink to ssh under alternatives on Debian, and can be installed with rsh-client. 4
