database

Claims: 6 Background: 1 claim already covered by Wikipedia, see ZFS.

A database can be used to store files, though this is inefficient, and ZFS can instead handle deduplication of files stored as files while managing read caches can be complex. 1 Qt is modular, allowing developers to opt-in or opt-out of specific features like database or OpenGL support. 2 Some things were tried to be abused into being database nodes, though they were less happy. 3
