Lisp

Claims: 25 Background: 6 claims already covered by Wikipedia, see Lisp machine.

Lisp is a programming language and mindset, often used on XL1201 computers which have special hardware acceleration for it. 1 N-World for Irix had a 'Wide Open World' dev toolkit for 3D hacking with Lisp, and N-world is Lisp based. 23 Mirai was programmed in Lisp. 4 C++ adopted lambdas from Lisp. 5 Lisp can generate a list of Levenshtein distances between a search term and a list of items. 6 Lisp is used for non-programming tasks in work environments. 7 There is an actually-usable version of Emacs available, compatible with a 486DX33 and fully implementing Lisp. 8 The G3 can run Lisp, but Allegro Common Lisp is a good dev kit, though it requires a license. 9
