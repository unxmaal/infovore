L2 controller

Claims: 24

The L2 controller is a PowerPC-based system produced by SGI, and it is the only PowerPC system the company ever made. 1 It is the closest SGI product to a GameCube, and it runs Red Hat Linux on kernel 2.4.7. 23 The L2 controller connects via USB to the L1 controller on up to 4 bricks, requiring a 50-pin connector with 48V DC power, which is included when purchasing the controller. 4 It can communicate with L1 controllers through the USB B port or a special kernel module in Linux, and the L3 controller software for Linux can emulate the L2 controller by tapping into the L1 port on newer systems. 567 On the IP28 machine, the L2 controller is integrated and can be accessed via IP and telnet or by setting a static ARP entry. 8 Brick count guidelines recommend using an L2 controller for 2-4 bricks, both the Numalink router and L2 controller for 5-8 bricks, and only the Numalink router for 3-4 bricks. 9 Serial numbers can be stored in the L2 controller or configured using L1 commands, and the controller can boot loop or have booting issues possibly related to voltage or PSU problems. 101112
