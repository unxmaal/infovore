FTP server

Claims: 12 Part of FTP

An FTP server can be installed on an IRIX system to enable file uploads from other machines such as Linux. 1 The FTP server on IRIX uses standard FTP rather than SFTP or FTPS, and requires a user account with a non-blocked password; root login without a password does not work. 23 The FTP server auto-starts with the OS on IRIX, and can be started using the command 'chkconfig ftp on'. 34 The FTP server on IRIX can be accessed to transfer files. 5 Connecting to an FTP server can fail with socket call/connect errors on IRIX while working on Linux. 6 When pinging fails, the ARP table on IRIX should be checked for the FTP server's MAC address, as another host may have the same IP. 7 Uploading from MAME to an FTP server stalls for files larger than about 1 kB, though downloads work fine. 8 A laptop from 2003 can run an FTP server to transfer data to Amigas and Octanes. 9
