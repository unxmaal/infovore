ARCS

Claims: 28 Background: 1 claim already covered by Wikipedia, see MIPS architecture processors.

ARCS is SGI's implementation of the ARC firmware specification, used to support Windows NT on RISC systems. 1 SGI systems used MIPS processors and ARCS firmware. 2 ARCS is a boot loader compatible with SGI MIPS machines, used by the SGI VW 320/540. 3 ARCS is required for booting from SCSI drives, which can be either QLogic or a different QLogic model. 4 SGIs do not need a boot floppy; you boot into ARCS, which is on the system, then install from CD or tape. 5 IRIX requires MIPS architecture or ARCS firmware, as it was never designed to run on x86-based architectures. 6 ARCS prevents more exotic OSes from running on these machines; BSD installation failed. 7 ARCS is believed to handle graphics around the terminal, not the IRIX booting process. 8
