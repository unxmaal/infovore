With Indy

The Indy can run IRIX 5.3, but may crash with newer versions. 1 The Indy is a 4600, 8-bit model with two HDDs, one being 1GB, when running IRIX 5.3. 2 The Indy struggled to run IRIX 5.3 with 16MB of RAM, and SGI upgraded all base models to 32MB shortly after. 3 Installing IRIX 5.3 on an Indy requires a specific tutorial, and issues may arise if the wrong block size is not specified. 4 A 2GB drive was typical for an Indy running IRIX 5.3. 5 IRIX 5.3 was optimized for 64MB of RAM and performed better than 5.1 on an Indy with 32MB. 6 An Indy running IRIX 5.3 can mount an NFS drive from an Octane over the network for software compatibility testing. 7 Forwarding IrisGL from an Indy running IRIX 5.3 to an Octane allows running old COFF IrisGL applications on a more powerful machine. 8

With IRIX 6.2

Installing IRIX 5.3 fails to link the kernel due to issues with the R4000 core, while IRIX 6.2 encounters a segfault at the same stage; this segfault issue is consistent across both IRIX 5.3 and IRIX 6.2 when using the new R4000 core. 910 The MIPS compiler for IRIX 5.3 and early IRIX 6.2 requires patch 1118 to resolve fmul in delay slot warnings when using makerom with the N64 SDK. 11 U64 Drivers exist for 5.3 and 6.2 in available SDKs online. 12 IRIX 5.3 and 6.2 have pre-installed HDD images in MAME, with the IRIX 6.2 image being 446MB and the 5.3 image being 336MB. 1314 Softimage 3D 3.7 is an IRIX version, possibly for IRIX 5.3 or 6.2. 15 Some users recommend using IRIX 6.2, but one can also dual-boot IRIX 5.3 by partitioning the drive. 16 IRIX 5.3 or 6.2 runs well with 64MB of RAM on slow processors, even in console mode. 17 Someone is working on the IDO compiler and linker/assembler utilities for IRIX 5.3 and 6.2 compilers. 18

With Indigo2

The Indigo2 can run IRIX 4.x, but running IRIX 5.3 may require a CPU swap. 19 An r4400 non-impact Indigo2 can run IRIX 5.3, but an r10k/impact Indigo2 needs IRIX 6.2 or higher. 20 IRIX 5.3 can run on an Indigo2, though it is not on the supported OS list. 21 IRIX 5.3 requires a specific version for Indigo2 with 2 Mb cache. 22

General

IRIX 5.3 is a classic SGI UNIX operating system from the 1990s. 2324 It runs on R3K processors and the oldest boxes, and is hosted by winworld. 252627 It supports COFF programs such as Alias3 and Corel Draw demos, and Alias works in IRIX 5.3. 282930 It has a 5.X build for building on mips3, and a DAT tape backup is useful for automated system recovery. 3132 It supports hfs and FAT16 for removable disk drives, and a maximum 8 GB partition size. 3334 IRIX 5.3 used the COFF executable binary format, which was also used by IRIX 5.3 and earlier versions and is not supported in IRIX 6.x. 353637 5.3 was the last version of IRIX that could run 4.x coff executables. 35 The fsn file manager binary for Irix 5.3 or later is broken; only the older COFF version works correctly. 38 A version of the MIPSpro compiler that works with IRIX 5.3 is needed to compile MIPS assembly. 39 GCC 4.x should work with IRIX 5.3. 40 compiling netsurf with mipspro instead of gcc may be necessary for IRIX 5.3. 41 IRIX 5.3 can be installed from a single CD but preinstalled HD images are available for convenience. 42 Installing IRIX 5.3 over the network is possible. 43 IRIX 5.3 is a version of Silicon Graphics' operating system that runs on a range of hardware, including the Indy R4400, Indigo, IP19, A2000, and Indigo2. 444546474849 The system requires RAM, a disk, and NVRAM to run, and a 200 MHz R4000 system with 64 MB of RAM and Extreme graphics runs IRIX 5.3 efficiently. 4549 IRIX 5.3 partitions max out at 8 GB and file sizes at 2 GB, though 300GB drives are not overkill for these systems. 5051 IRIX 5.3 was reported to be more stable than alternatives, though some users experienced system freezes they suspected were due to RAM issues. 5253 IRIX 5.x was probably the first IRIX with a
