ImgBurn

Claims: 10 Background: 1 claim already covered by Wikipedia, see IRIX.

ImgBurn is a regular Windows executable that does not run in WSL. 1 ImgBurn can read and write IRIX disk images on Windows, and can rip and burn images successfully, though it cannot read disc contents. 23 ImgBurn does not support .IMAGE files, which are essentially raw image files, unlike ISO9660, and IRIX install CDs use EFS format. 4 ImgBurn can be used to burn .img files for IRIX installs without adding extra data, and with raw DAO it works for burning CDs. 56 ImgBurn on a Windows machine can be used to create IRIX 6.5.30 bootable CDs for O2s, and can be used to burn tar files to a CD using the ISO to disk option. 78 ImgBurn or similar software is recommended for writing IRIX CDs on Windows due to potential issues with default Windows CD software, and you can attempt to image an SGI machine using imgburn on Windows or Linux. 910
