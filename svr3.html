SVR3

Claims: 9

SVR3 is also known as UNIX v3, and 4D-1 3.0 was based on it. 123 IRIX 4 was based on SVR3. 4 The Intergraph Clipper workstation ran CLIX, an SVR3 operating system, but lacked a C compiler and had limitations such as no long filenames. 5 ESIX is SVR3 and supports exactly 3 ethernet cards, with the 3c505 working for the setup. 6 The 3.7 source tree contains MIPS-specific code and can be compiled as SVR3 or SVR0. 7 The GL2 source code includes ifdefs for Clover and SVR3, and the C libraries are copyrighted by MIPS Technologies, suggesting a transition to a new architecture and operating system. 8 GL2 code was ported to SVR3, which was 4d1-3.0. 1
