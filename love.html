LOVE

Claims: 38

LOVE is a network installation tool for IRIX that can run from IRIX, Linux, or Windows, and is distributed as a single binary that combines bootp, tftp, and rsh functionality. 123 It is provided as a 16785-line C++ source file with no build scripts, and a pre-built Windows executable is also available. 45 The tool must be run with sudo, and it does not include installation media, though IRIX distribution files can be downloaded from a provided link. 678 It is used to connect an SGI to a computer's IP address and can load fx over the network on a second host such as a PC, Mac, or Raspberry Pi. 910 Installation does not require formatting partitions; instead, labels are created and the system boots into the installer. 11 LOVE installs all demos into the system along with the OS, unlike Booterizer, and does not automatically apply patches. 1213 It lacks an entry for IRIX 6.2 in its labels file, but adding the correct lines allows installation from downloaded CDs. 14 Users report it works well for installing IRIX 6.5.22, 6.5.30, and 5.3, and it runs faster than Reanimator when not using a VM. 1516
