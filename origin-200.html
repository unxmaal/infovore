Origin 200

Claims: 111 Background: 5 claims already covered by Wikipedia, see SGI Origin 200, Raspberry Pi, SGI Octane.

With Octane

The O200 is a modular, more expandable version of the Octane, often considered an Octane 1.5, with expandable capabilities. 1234 The Octane is based on the O200 design but lacks the Numalink features, while the Origin 200 is essentially an Octane without graphics that uses Numalink instead. 56 The O200 lacks graphics and is slower than the Octane, and can have two extra processors. 78 The Octane and Origin 200 share the same architecture but are not in the same family, and the Octane uses the same disk sleds as the Origin 200 and 2000, which can handle SCA disks. 910 Octane graphics boards are compatible with O200 systems, and the O200 can take an SSE card but requires sawing into the chassis. 1112 The Origin 200 uses O2000 memory, which is not compatible with the Octane or O2. 13 Rendering was done on 8 Silicon Graphics R10000 processors divided over 2 Octanes and 2 Origin 200 servers. 14

With Origin 2000

The Origin 200 and Origin 2000 differ in size, with the Origin 2000 being larger, and they differ in hardware similarly to how a Fuel and a Fridge differ. 15 The Origin 200 is louder than an O2000 on fastfan. 16 The firmware on Origin 200 models likely restricts communication with Origin 2000 via Craylink due to licensing or hardware incompatibility. 17 The O200 and O2K are similar in hardware, differing mainly in CPU clock speed and physical connection limitations. 18 Onyx2, O200, and O2000 share compatible memory. 19 The RTC battery for O200/O2K/Onyx2 is an ST M48t35-70pc1 and is still available from Farnell/Mouser but has never been seen to run out. 20

General

The Origin 200 is a rare SGI desktop model that is a configuration of an Origin rack with four CPU compute bricks. 2122 It is a cluster that uses Craylink for CPU-to-CPU communication and XIO for peripherals. 2324 The O200 is impractical and is considered the most fragile SGI, with brittle plastics that can snap off or vaporize easily, and it has likely not been moved in 25 years. 25262728 It has graphics issues that prevent it from booting with graphics installed, and although it was never intended to have graphics, it can run Octane cards because it is an Octane. 2930 The O200 is obsolete, uncommon, and was impractical, with users able to add graphics through modifications. 31322533 The Origin 200 is a dual-node system in which the system recognizes the processors in both nodes but only online those of the primary node, and pairs can be connected using Craylink cables, which are expected not to boot without a boot brick. 3435 The Origin 200 supports FDDI, dual gigabit Ethernet, and dual 2Gb FC, and SGI sold Origin200 systems in racks for high-speed networking. 3637 The Origin 200 can be used as a render node, and Digital Domain used Origin 200s for rendering. 3839 The Origin 200 is loud, possibly due to a bug or confusion in fan speed control. 4041
