Windows 98

Claims: 21 Part of Windows Background: 6 claims already covered by Wikipedia, see Windows 98.

Windows 98 is an operating system named 'Windows 98' that can handle up to 1032MB of RAM. 12 It can run Command & Conquer: Red Alert perfectly on a Pentium II with drivers and DirectX, and 3D Studio MAX R2/R3 requires Windows NT 4.0 or Windows 98 to run. 34 However, Windows 98 is not ideal for running 3D Max Studio. 5 It can be installed from the internet using a product key, from hard disk by formatting the disk and copying setup files (with a tool to write the Windows MBR), or via the Windows 98 installer, which does not include certain graphics. 678 Boot issues can be fixed with `fdisk /mbr` or the `fixmbr` tool. 9 Sharing files between a modern Linux machine and a Windows 98 machine is better done with Samba than NFS, though Microsoft SFU might work for NFS. 1011
