miniroot kernel

Claims: 3 Part of miniroot

The miniroot kernel is a flat file with concatenated segments consisting of the files and binaries, and a different miniroot kernel is used for each supported platform. 1 The installer has an option to drop into a shell. 1 Compiling a miniroot kernel for unsupported platforms in IRIX 6.5.30 is possible using platform-specific drivers from 6.5.22. 2 The miniroot kernel complains about no filesystem and panics during diskless boot. 3
