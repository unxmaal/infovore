installer

Claims: 33

The SGI IRIX installer (INST) handles base and overlay packages with dependencies, uses a different miniroot kernel for each supported platform, and is a flat file with concatenated segments consisting of the files and binaries. 12 The installer has an option to drop into the shell, where commands such as mkfs or mkfs_xfs can be run on a disk. 34 The installer should take care of the volume header automatically, as long as it is present on the partition map. 5 The installer can be run in X mode, but a second dtterm can be used to label disks before the installer fails, and the install can also be done in text mode using a serial console when XVR-1200 is unavailable. 67 The installer has a hardcoded NIC list that is not patched, and different installer versions support specific hardware configurations. 89 The IRIX 6.5.22 installer includes exit commands and is chosen for its text rendering system compatibility with older software like Photoshop, while the IRIX 6.5.30 installer can be patched to skip the platform check, though missing platform-specific miniroots cause issues. 1011 You can download IRIX distribution files for the LOVE installer from the provided link, but the installer crashes with a love error when requesting a label or file using a tftp client from a Linux workstation. 1213
