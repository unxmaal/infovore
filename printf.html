printf

Claims: 9

printf is a varargs function with prototype `int printf(const char *s, ...)`, even without including <stdio.h>. It is often used as a debugging method. 12 fprintf prints to a FILE * and its formatting is exactly the same as with regular printf. 3 The IRIX printf function can be buggy with certain formatting arguments, causing unexpected output or crashes. 4 Invalid format characters in printf should not cause a coredump. 5 To print a float with printf in MIPSPro assembly, provide a format string like "value: %f\n" as the first argument and the float value as the second argument. 6 The utf8 library works decently with its own printf. 7 Ultrix lacks a printf binary, requiring alternative methods for output. 8 The `log_write_debug` function, a vararg function similar to `printf`, contains a `jmp rdx` instruction that sometimes points to invalid code, causing a segfault. 9
