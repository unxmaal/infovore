XQuartz

Claims: 10

XQuartz is a precompiled Xorg distribution for Mac OS X, and native macOS has no X server of its own, only XQuartz, which some consider broken. 123 XQuartz integrates X11 apps into Quartz, requiring a nested X server for a full-screen X11 session. 4 XQuartz and xterm were common on Unix workstations, and XQuartz is an option for using XDMCP on a modern-ish Mac. 56 Modern Macs do not ship with XQuartz by default, and XQuartz on M1 Macs has fixed the 2016 bug and possibly other issues. 78 XQuartz on Mac requires a local DISPLAY environment variable to be set before SSHing out for X11 forwarding to work, and running CATIA through XQuartz can be problematic due to true-color colormaps and GLX issues. 910
