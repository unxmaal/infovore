ed

Claims: 9

ed is a minimal line editor that is part of the POSIX standard and is included in standard UNIX utilities for legacy reasons, making it suitable for systems with memory limitations. 1234 Historically, ed was a line editor for paper teletype systems rather than CRT terminals, and was considered obsolete by 1974. 5 The ed utility in IRIX reads files into a buffer for editing, and booting the Crimson required using ed in singleuser mode. 67 The Octane has a vi editor in single user mode, while older SGI systems may only have ed. 8 The 3B system was used to install 5ESS and Wireless MTSO systems, with the AM module being a 3B system running ed. 9
