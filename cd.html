General

CDs usually have a specification of 74 minutes, but 80 minutes is common on CD-Rs. 1 CD and DVD use different lasers. 2 Lightscribe is a technology that works fine for burning CDs and DVDs but not Blu-ray. 3 The manual can be read from the CD or installed to the hard disk. 4 IRIX can be installed using a CD, which is quicker than using virtualization tools on Windows. 5 Putting a CD in a drive is faster than using nested VMs for ISO images. 6 Boot loader can handle HPFS partition schemes by booting from CD and using a partitioner. 7 For IRIX installations, one can boot the miniroot from a CD and then mount a second hard disk with distribution files. 8
