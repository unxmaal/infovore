inst

Claims: 52

INST is a separate operating system from PROM, and it is the IRIX installer that handles base and overlay packages with dependencies. 123 It is invoked from the command line or the software manager, which serve similar purposes, though inst is more advanced and preferred by experienced users. 456 IRIX installer packages are .tardist files, and inst can take a long time to extract them, so extracting them first and then using -f on the folder can be faster. 785 inst may use hashes or IDs to detect if an installation is an upgrade, and it will look for the old install and use it. 910 Running inst requires a certain amount of disk space under /var/tmp or an equivalent directory, and it fails after creating 26 temporary directories when installing multiple tardist packages, suggesting a limit or space issue. 1112 From the inst admin menu, mkfs is available to partition and format the drive, and inst and mkfs are needed to format a drive in some cases. 131415 inst copies a mini filesystem into the swap partition and boots the kernel from there, and the post-install script copies a kernel into the mini-root, sash and ide programs into the drive's volume header, and performs various linking and font tasks. 1617 inst can install multiple patches from a folder, but it requires manual confirmation for each one, and it works well but is a bit of a pain with conflicts. 181920 inst and swmgr are used for software management on SGI IRIX, with inst for console and swmgr for GUI, installing most SGI IRIX packages and parsing tardists; some third-party software is also installable via these tools, which are considered among the best package management tools for Unix systems. 2122 inst cannot install directly from a tar file; it requires a tardist file to be untar'ed into a folder before opening it, and it will untar tardists to a temp directory one at a time. 232425 inst can load selections from a network path specified as an IP address and path combined, and it can be forced to install on an O2 if it is not COFF. 2627 inst can query installed packages, as shown with examples for Alias and DevilutionX. 28
