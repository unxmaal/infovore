GLQuake

Claims: 27 Background: 1 claim already covered by Wikipedia, see Quake (video game).

GLQuake is a modern source port of Quake that requires a workaround to use SDL2 for cross-platform compatibility. 1 It builds but may segfault without much of an error, with the main thread possibly crashing due to stack corruption. 23 On IRIX, glQuake typically needs to run in 24-bit color, though software rendering may not work in that mode, and it may require an earlier version from 1997. 45 Without the required OpenGL patches, GLQuake will need the -fake8 option. 6 The O2 can run GLQuake, but save files can get corrupted, and it has issues with X server crashes and flickering textures. 78
