Claims: 10 Part of SDL

  • MIPS VSTs are not supported by many open source projects, with SDL1 being an exception for dmedia. (user-42cf, exchange 143625, 2020-02-19; 1 speaker(s), 1 conversation(s))
  • SDL1 is a solved problem and could be used with necessary patches. (user-b1da, exchange 215098, 2021-03-13; 1 speaker(s), 1 conversation(s))
  • sdl1 is in nekoware and can be compiled easily. (user-22f9, exchange 86612, 2025-02-11; 1 speaker(s), 1 conversation(s))
  • The SM64 port can build with SDL1 or 2, but the irix bits were incomplete. (user-e4d0, exchange 215789, 2025-08-01; 1 speaker(s), 1 conversation(s))
  • The Makefile for Tyrquake is currently set to build with SDL2, but there are issues with SDL2 on IRIX; forcing SDL1 might resolve these issues. (user-59b9, exchange 69719, 2021-07-01; 1 speaker(s), 1 conversation(s))
  • ioQuake3 compiled with SDL1 works with SGI OpenGL but not SDL2. (user-17cb, exchange 215314, 2022-06-04; 1 speaker(s), 1 conversation(s))
  • The O2 can run an N64 Super Mario binary with SDL1; the source directory is available online. The O2's V12 CPU has good geometry performance but lacks quality. The WIP branch fixes issues with RSE X11 libs and supports R (user-1446, exchange 80002, 2021-10-25; 1 speaker(s), 1 conversation(s))
  • SDL1 works out of box, and SDL2 seems to work too. (+1 similar) (user-42cf, exchange 6798, 2020-03-06 to 2025-05-12; 1 speaker(s), 2 conversation(s))
  • IRIX has SDL1 support. (user-1446, exchange 5301, 2020-01-04; 1 speaker(s), 1 conversation(s))
