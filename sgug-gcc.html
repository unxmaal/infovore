sgug gcc

Claims: 6 Part of SGUG

glxdino.c compiles with the MIPSPro cc and freeware gcc, but not with sgug gcc. 1 When doing development work with SGUG gcc, always use `sgugshell` before running any `config` steps. 2 The MIPSpro compiler builds the game in about 4 minutes, while the SGUG GCC takes about 14 minutes. 3 SGUG gcc had the usual GL issues, but it is possible to work around them with some special treatment in build options. 4 The SimH emulator can run UNIX v4, the first version of UNIX written in C, from a 1970s nine-track tape drive, and it can be compiled with SGUG gcc by changing a lib32 path in the makefile. 5
