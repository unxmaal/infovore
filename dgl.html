DGL

Claims: 3

The Distributed Graphics Library (DGL) is used by IRIX 4.0.x and later to allow GL programs to run remotely. 1 DGL allows other machines/OS to send graphics requests to IRIX, but not vice versa, defining network serialization for request data parameters and feedback. 2 SGI systems can send graphics over a network using DGL to display graphics data from emulated SGIs on real hardware. 3
