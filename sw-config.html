sw_config

Claims: 5

The sw_config tool and related tools are missing from the /usr/discreet/sw folder, and running sw_config results in a segmentation error. 1 The NVMe drive is seen on 2008SP6 but causes segmentation faults with sw_config. 2 sw_config requires a previous setup drive's preferences, which are not found in cfg files and are stored elsewhere. 3 sw_config reports an 'operation starts past end of partition' error when attempting to use an XFS filesystem. 4 To set up the drive, use sw_config, apply the date patch, and place the license file in /etc, choosing the filesystem type in init.cfg; Version 7.6 and 7.7 supported a generic file for storage. 5
