RISC OS

Claims: 31 Background: 4 claims already covered by Wikipedia, see RISC OS, NetSurf, Raspberry Pi.

RISC OS is an operating system that can run on the Raspberry Pi, including on the Pi 1, where it can run Archimedes games and software, and can run on-the-metal on newer Raspberry Pi models. 1234 RISC OS has a unique user interface with iconify in the upper left and destroy in the upper right, and requires drag-and-drop for file operations in its GUI. 56 RISC OS defaults to assuming it is in the UK, and requires paid software. 78 RISC OS never had a large freeware or open-source scene compared to DOS, Windows, and Linux. 9 RISC/OS is a predecessor to IRIX, which is derived from it and is a BSD derivative. 10111213 RISC/OS development was stopped around 1992 when SGI bought MIPS. 14 RISC/OS contains code for multiple architectures including MIPS and R2300, can run on R6000 processors, and used a dynamic linker, possibly rld. 151617 Risc/os is a dual universe system where you can choose between a SysV and a BSD personality. 18
