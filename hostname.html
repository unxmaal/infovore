hostname

Claims: 15

Setting the hostname is required to enable networking in the admin menu, and it is not assigned until the system is booted into IRIX, with hostnames not used at the IP and MAC address level. 12 The hostname can be changed at any time, but changing it after a fresh install or later can break software, cause issues with the desktop or home folder setup, and cause IRIX to throw hostname errors and inetd crashes even when the hostname looks fine and setting it up again does not help. 3456 To change the hostname, update /etc/sys_id, /etc/hosts, and /etc/resolv.conf, then reboot, and sanity checking /etc/sys_id and ensuring the hostname is correct can help with networking issues. 78 Connecting to the network or configuring local hostnames to 127.0.0.1 and/or ::1 can help with these issues, and FlexLM might function better with the correct host name. 910 Examples of hostnames include octane, housefire, Cuddles, and fuzzies. 111213
