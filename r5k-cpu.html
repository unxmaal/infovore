R5K CPU

Claims: 28 Background: 3 claims already covered by Wikipedia, see SGI O2, SGI Indy.

The R5K CPU is used in several SGI systems, including the O2, the Indigo2, the Challenge S, and the Indy. 1234 The O2 can run at 300 MHz with an R5k CPU, and a 180 MHz R5K is the slowest O2 configuration. 52 The R5K CPU is significantly faster than the R4400 in benchmarks, and the R5500 on an R5K CPU runs the BlueSCSI test faster than on an R4K. 67 The R5K CPU can be configured with a 180MHz bitstream that enables external cache and sets the SysAD speed to 90MHz. 8 MIPS4 requires an R5K CPU, and the PelOrion card requires an R5k CPU to function properly. 910 An R5K CPU can hang during early IRIX installation. 11

Sources

  3. The Challenge S is a novelty server with 150 MHz R5k CPU, low power usage, and silent operation. (user-6afa, 2021-03-08, exchange 15235, check: supported)

  5. The O2 can run at 300 MHz with an R5k CPU. (user-8547, 2019-06-07, exchange 1956, check: supported)
  6. The R5K CPU is significantly faster than the R4400, as shown by benchmarks, with a 90-second video decoding time reduced from 39.94 seconds to 26.06 seconds. (user-6afa, 2021-12-23, exchange 221795, check: supported)
  7. The R5500 on an R5K CPU runs the BlueSCSI test at 182 DMIPS, consistently faster than 162 DMIPS on an R4K. (user-e56b, 2026-08-26, exchange 220657, check: supported)
  8. The R5k CPU can be configured with a 180MHz bitstream that enables external cache and sets the SysAD speed to 90MHz. (user-757f, 2026-02-01, exchange 226050, check: supported)
  9. MIPS3 is supported by the mipspro image, but MIPS4 requires an R5K CPU. (user-cd7d, 2026-07-30, exchange 220569, check: supported)
  10. The PelOrion card requires an R5k CPU to function properly; otherwise, an OS upgrade and reconfiguration are necessary. (user-9305, 2026-08-24, exchange 226921, check: supported)
  11. An R5K CPU can hang during early IRIX installation. (user-4c05, 2022-02-15, exchange 221994, check: supported)
