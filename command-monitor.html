command monitor

Claims: 8

The command monitor is a feature found in PROM that can be accessed from the PROM menu. 12 Sun's command monitor is more advanced than SGI's. 3 It can dump the main PROM over serial and run `hinv` to reveal system specifications. 45 It can also load `sash`, which provides additional functionality. 1 To access it, go to option 5 and run `printenv`. 67 It can be used to restore a UNIX backup by running `boot *unix_backup_name*`. 2
