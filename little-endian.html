little endian

Claims: 12 Background: 3 claims already covered by Wikipedia, see Endianness, PlayStation 2.

Little endian makes accessing different sizes of integers from the same memory location simpler compared to big endian, which requires additional steps. 1 On a big endian system, a 16-bit load from address 0x0 gives 0xAABB, while on a little endian system it gives 0x0011. 2 All Alpha OSes were little-endian. 3 RV32I is 32-bit byte addressable and little endian, using only load and store instructions to access memory and registers for arithmetic operations. 4 The PS2 is little-endian. 5 68k machines with little-endian Multibus cards have swapped byte ordering. 6
