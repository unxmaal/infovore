ROM

Claims: 48 Background: 2 claims already covered by Wikipedia, see Programmable ROM, Read-only memory.

When an embedded system's processor is first powered up, it typically loads the program from ROM into RAM and then starts executing from the program counter's address. 1 The ROM is mapped to a fixed location, such as the upper 40KB or a base address like 0xbfc00000, and the reset vector can point to the beginning of the ROM. 234 The ROM can be stored on a chip, on a graphics board, or on a cartridge, and it can be updated by flashing, swapping chips, or replacing the board. 567 The ROM can contain a driver for a PCI video card, a copyright header, or code that runs without memory protection issues. 8910 A bad ROM or startup circuit can cause a machine to do nothing when turned on, and ROM issues can affect RAM addressing. 111213 ROM checksum mismatches can either be ignored if the name matches or cause a VM to stop, and VM software can continue execution even if a ROM is missing. 141516
