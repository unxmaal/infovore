gpubench

Claims: 4

gpubench and gpubench_ogl1 are IRIX N32 binaries requiring OpenGL 1.1 and 1.0, respectively. 1 gpubench requires IRIX 6.5 for textures, but pre-6.5 IRIX 6.x systems can use the N32 binary gpubench_ogl1 renamed to gpubench. 2 An O32 binary is available separately for older IRIX systems, and the gpubench IRIX 5.x O32 binary can be run on IRIX 5.x systems. 23 gpubench can be run on the IRIX 5.3 Personal Iris TG with OpenGL support. 4

Sources

  1. gpubench and gpubench_ogl1 are IRIX N32 binaries requiring OpenGL 1.1 and 1.0 respectively. (user-ce5a, 2019-03-22, exchange 1120, check: supported)
  2. gpubench requires IRIX 6.5 for textures; pre-6.5 IRIX 6.x can use N32 binary 'gpubench_ogl1' renamed to 'gpubench'. O32 binary for older IRIX systems is available separately. (user-ce5a, 2020-11-21, exchange 97903, check: supported)
  3. gpubench IRIX 5.x O32 binary can be run on IRIX 5.x systems. (user-ce5a, 2020-11-21, exchange 97903, check: supported)
  4. gpubench can be run on IRIX 5.3 Personal Iris TG with OpenGL support. (user-c9fb, 2020-11-21, exchange 97903, check: supported)
