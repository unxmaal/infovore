password

Claims: 11

A password in a configuration file is 'hunter2'. 1 The password was moved from an old router to this router when the router was replaced. 2 Running `sgug sudo` shows `assword` instead of `password` due to a typo in the prompt string. 3 `sudo` changes the environment and runs fewer commands with root privileges compared to `su`, and can be configured to not prompt for a password. 4 The system has no password set for the root user. 5 An 8-character password is insecure. 6 The password can be cleared by removing the clock battery, using a jumper, booting with something else to wipe it, or network booting an IRIX installation and chrooting to change it. 789
