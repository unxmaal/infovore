graphics pipeline

Claims: 3 Part of graphics

SGI's competitive advantage came from a graphics pipeline that was not limited to software rastering, in which CPUs, GPUs, and memory bandwidth all played a role. 1 The VB2 is part of the graphics pipeline and forms part of the GPU as the framebuffer and video signal generation hardware. 2 The E10k is a set of CPUs with no graphics pipeline, though it can perform a large CPU render. 3
