libstdc++

Claims: 6

The libgcc and libstdc++ libraries are required on the target for C++ programs. 1 libstdc++ can be enabled in compilertron by removing `--disable-libstdcxx` from `build_gcc.sh`, patching `libstdc++-v3/crossconfig.m4` to include IRIX, and running the patched sources in the Dockerfile. 2 IRIX's GCC uses libstdc++ from the compiler, not the system version. 3 rse 0.0.4 and up should fix a bug in libstdc++ linking order that causes pthread-related segfaults, a known issue since 4.X versions of gcc. 4 Running Make install on Ruby causes a segfault due to a hard-coded file path issue, possibly related to pthreads or libstdc++ linking order. 5 A custom memory request structures (mrqs) bug was fixed after dropping a non-remapped libstdc++ into the bundle directory. 6
