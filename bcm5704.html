BCM5704

Claims: 4

The Altix 350 can use a BCM5704 network card, either in a PCI riser configuration that allows network booting via EFI without requiring IO9 or IO10, or in a PCI module that can also be used alongside a QLA12160 SCSI card. 12 The SCSI controller is a QLogic QLA12160 and the Ethernet controller is a Broadcom BCM5704. 3 BCM5704 network adapters can be purchased from eBay. 4

Sources

  1. An Altix 350 with a PCI riser and a BCM5704 can network boot using EFI, no IO9 or IO10 required. (user-bc5d, 2020-03-08, exchange 75102, check: supported)
  2. A PCI module might be more common and can be used with a QLA12160 SCSI card and a BCM5704 network card. (user-1446, 2020-12-16, exchange 75447, check: uncheckable)
  3. The SCSI controller is a QLogic QLA12160 and the Ethernet controller is a Broadcom BCM5704. (user-59b9, 2020-12-31, exchange 216382, check: uncheckable)
  4. BCM5704 network adapters can be purchased from eBay. (user-ba81, 2021-04-06, exchange 16300, check: uncheckable)
