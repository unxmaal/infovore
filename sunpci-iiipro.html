SunPCi-IIIpro

Claims: 6

The SunPCi-IIIpro card runs Solaris x86 inside a SPARC workstation running Solaris. 1 The card does not require extra cables and can use an Athlon XP-M system with S3 ProSavageDDR graphics. 2 It takes a long time to boot, with the process being mostly silent and potentially hung up on an unspecified issue for minutes. 3 In a Blade 2000, it is slow for Windows apps but better for running Office on SPARC, and it is slow to start and not suitable for production environments. 45
