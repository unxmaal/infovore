4D/20

Claims: 20

It uses the IP6 motherboard, a speed- and cost-reduced re-layout of the IP6 shared with the 4D/25, and is software IP6. 12 It can run IRIX 3, and can install and run IRIX 4.0.5 and 5.3 with some adjustments. 34 It uses a 9-pin serial connector, which shares a protocol with the DB15 and miniDIN 6 connectors used on other SGI systems and can be rewired between them. 5

Sources

  1. 4D/20 and 4D/25 are (software) IP6, 4D/30 and 4D/35 are IP12. See http://www.sgistuff.net/hardware/systems/personal.html (user-86e1, 2023-08-16, exchange 223258, check: supported)
  2. The IP6.5 is a re-layout of the IP6 for speed and cost-reduction, used for both 4D/20 and 4D/25, often underclocked to match the 4D/20's performance. (user-56d4, 2023-09-13, exchange 188557, check: supported)
  3. The 4D/20 can run IRIX 3. (user-59b9, 2021-09-16, exchange 205552, check: supported)
  4. 4D/20 and 4D/25 can install and run IRIX 4.0.5 and 5.3 with some adjustments. (user-a719, 2023-07-25, exchange 93228, check: supported)
  5. The DB15 connector is used on deskside SGI systems, while 4D/20 and 4D/25 use 9-pin connectors, and Onyx and Indigo use miniDIN 6; all use the same protocol and can be re wired between each other. (user-b1da, 2024-07-03, exchange 189202, check: supported)
