4dwm

Claims: 38 Background: 3 claims already covered by Wikipedia, see IRIX.

4DWM is the window manager component of the IRIX Interactive Desktop, normally used on Silicon Graphics workstations running IRIX. 1 It is an X11 window manager that uses overlay layers for its functionality. 2 4DWM can be started by running /var/X11/xdm/Xsession on an SGI X server, and it can also be run via X11 forwarding to give an IRIX feel on an old Linux box. 34 NeWS, used by SGI before X11, influenced the look and feel of 4DWM. 5 The SGI file manager requires 4DWM to be running to show icons on the desktop. 6 There are free and commercial versions of a Linux desktop environment modeled after 4DWM. 7
