250 MHz CPU

Claims: 6

Installing a 250 MHz R4400K CPU requires installing IRIX 5.3 on a 200 MHz PIMM, applying a patch, and swapping in the 250 MHz CPU. 1 The 250 MHz CPU with 2 MB cache is incompatible with the original IRIX 5.3 disc. 2 IRIX 4.0.5H can install and run on a 250 MHz CPU without issues, except for IMPACT graphics, which are incompatible. 3 There was a bug or issue with the 250 MHz CPU, though 250 MHz CPUs have never caused issues for the author. 45 A machine with a 250 MHz CPU can be configured with low-impact graphics and 128 MB of RAM. 6
