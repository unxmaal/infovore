C++98

Claims: 6 Background: 1 claim already covered by Wikipedia, see Open64.

MIPSpro and C++98 are used for retro demo engine stuff, with GCC preferred for porting due to widespread compatibility. 1 MIPSpro supports C++98 with some extras, while the latest GCC follows the current standard. 2 aCC did not support C++ standards beyond C++98. 3 cctype is available since C++98; www.cppreference.com lists when C++ features were added. 4 ifstream can be used the same way in C++98 and C++17, with uniform initialization being added in C++11 and C++14. 5 The C++98 standard requires a space between adjacent '>' delimiters in nested template argument lists, a restriction lifted in C++11. 6
