Pidgin

Claims: 13

Pidgin works on IRIX, but nekoware's version is not very stable, though the latest version can be compiled, and it still has the same issue after re-installing sgug-rse. 1234 Pidgin supports libpurple, which allows connecting to Discord and other protocols, and it can connect to IRC and other protocols via protocol modules. 56 The purple-discord module for Pidgin has been in the repo for at least three years. 7 Pidgin works with SSL and provides a bump in day-to-day usability for IM, though it does not backfill history like Discord, and it has limited SSL support for IRC. 89 Pidgin has theme settings/plugins for darkening the interface, but it only shows messages if they're DMs or pings. 1011 For Pidgin, one must copy the link and manually add a new server rather than using xdg-open to open files with the appropriate application. 12
