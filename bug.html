bug

Claims: 10

Kernels newer than 4.14 have a bug where PCI devices do not work. 1 The bug occurs when an application requests a 24-bit buffer but the system returns an 8-bit buffer, leading to data corruption. 2 A simple OpenGL program can reproduce a bug by toggling between starting long polygons from Z=-0.01 and Z=0; the Z=value is shown top-left. 3 A working set exists but is unusable due to a bug. 4 Xsgi has a bug in WRMASK generation that affects real hardware; an ugly workaround fixes it. 5
