rx2600

Claims: 15

The HP RX2600 is a well-designed machine that is extremely reliable, so if it behaves differently, there may be broken hardware. 12 It originally ran Debian and can boot to EFI, load modules with both Debian and upstream kernels, and use non-ECC DDR-SDRAM, though registered ECC is more common for smaller Itanium systems. 345 The original RX2600 can have up to 1.5GHz Madison 6MB single core CPUs, and the RP3440, possibly R3410, and RP4440 CPUs could also be installed. 67 It lacks an AGP slot, unlike the zx6000, which came after it historically; both machines use redundant PSUs plugged in from the front and are rarely found with broken mainboards. 8910 The CDs contain installation materials for HP-UX that should work on the ZX2000/6000/RX2600, and Windows Server 2003 SP2 with hardware acceleration runs OpenGL games well on an RX2600. 11 The RX2600 logs fatal errors indicating scratch RAM issues, memory errors, and a CPU that fails to initialize, suggesting multiple potential points of failure. 12 The PSUs of the rx2620, rx2600, zx6000, and rx2660 may not actively ventilate in standby, potentially leading to overheating over time if connected to mains without running. 13
