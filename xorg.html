Xorg

Claims: 27 Background: 3 claims already covered by Wikipedia, see Wayland (protocol), X Window System, XFree86.

X11 is the windowing system layer in Unix or Linux, built on top of a command prompt base system; Xorg is an open source X11 implementation; KDE is a desktop environment that includes a window manager and other tools. 1 XFree86's license change led to most development effort moving to X.Org, causing XFree86 to become less active. 2 Xsun was the display server for SPARC systems, but Xorg and XFree86 supported x86 systems. 3 Xorg can run on SPARC Solaris with certain XVR cards, but it requires additional setup and is not shipped with Solaris 11. 4 Xorg can start without a mouse if the 'AllowMouseOpenFail' option is set, but Xsun does not have this by default. 5 Xorg crashes on Debian 5 due to known kernel bugs in that range. 6 Debian 7 can run Xorg with a more recent kernel, but initial configuration issues may lock the system. 7 The PowerMac G5 can experience random freezes when running Xorg under FreeBSD. 8
