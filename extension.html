  • An MVP should have up-to-date basic tools and extensions, be easy for new users to install/use, and run without performance issues or serious bugs. (user-22f9, exchange 67252, 2019-06-20; 1 speaker(s), 1 conversation(s))
  • There is enough information available to write device drivers and extensions for SGI systems. (user-c831, exchange 95826, 2019-11-25; 1 speaker(s), 1 conversation(s))
  • DNF or Dandified yum is the next generation version of yum. It roughly maintains CLI compatibility with yum and defines a strict API for extensions and plugins. (user-f229, exchange 11782, 2020-10-26; 1 speaker(s), 1 conversation(s))
  • Compiling a TyrQuake binary requires the `-Wl,--allow-shlib-undefined` linker flag to resolve undefined references to SGI extensions, and the binary runs after applying this flag. (user-59b9, exchange 69692, 2021-06-27; 1 speaker(s), 1 conversation(s))
  • The official header forces the caller to check the availability of the extension before querying it. (user-af19, exchange 30060, 2022-06-15; 1 speaker(s), 1 conversation(s))
  • The GL_HP_occlusion_test extension is a bounding box checker. There is no similar extension on IRIX, and `glCullFace()` is not a substitute for it. `glCullFace()` is used to delete faces with a specific winding order. (user-b1da, exchange 30058, 2022-06-15; 1 speaker(s), 1 conversation(s))
  • The A4000 can run as a Hackintosh with Fusion 3.2, but AppleShare causes a hard crash; disable it. Booting with extensions off requires the right Shift key. (user-baf6, exchange 152424, 2022-05-23; 1 speaker(s), 1 conversation(s))
  • The SGI acts as the X client, expecting extensions from the X server, which can vary between implementations. (user-d903, exchange 216871, 2019-12-26; 1 speaker(s), 1 conversation(s))
