PiSCSI

Claims: 7

PiSCSI is a Linux SCSI target emulator. 1 It is too slow to capture Wide SCSI and is narrow, but DB25 connectors are suitable for low-speed devices like PiSCSI. 23 An Amiga can run virtual disks over PiSCSI and render graphics on an ARM processor to display on the Amiga. 4 The series 400 bootloader can access a MAME-emulated DN3500 SAU directory and a SCSI hard drive through PiSCSI, but requires a domain keyboard for commands beyond MD, and a domain keyboard emulator is in progress. 5 There are AmigaOS drivers for the DaynaPort SCSI Ethernet, and it supports BluesCSI and PiSCSI Ethernet emulation. 6 The PiSCSI can be used for CD installs via a web UI. 7
