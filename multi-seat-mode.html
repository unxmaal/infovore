multi-seat mode

Claims: 3

Multi-seat mode requires additional monitors, keyboards, mice, and Base Graphics I/O cards for a multipipe Onyx2 system. 1 In multi-seat mode, multiple simultaneous users have exclusive control over an InfiniteReality2 graphics pipeline, unlike a deskside Onyx2 which only supports shared access. 2 The CADduo manual states that sound is not supported in multi-seat mode. 3

Sources
