Renderman Artist Tools

Claims: 5 Part of RenderMan

RenderMan Artist Tools was an addon for Maya. 1 The Mayaman version of Entropy works on an IRIX Octane with dual 400 MHz CPUs for rendering, but the official RenderMan Artist Tools did not run in Maya 4.0 on IRIX. 2 The RenderMan Artist Tools for Iris 4D might be for Alias or PowerAnimator, given the 1996 date and the need for an Iris Indigo. 3 The RenderMan Artist Tools license for Octane in Maya 4 should say 'SGI OK' and 'MtoR' OK to be a license host. 4 RenderMan Artist Tools for Houdini provided a plugin framework for custom shaders that could be easily integrated, unlike the more complex, proprietary setups used in early RenderMan for 3D data outputs and command line. 5
