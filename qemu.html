QEMU

Claims: 79 Background: 20 claims already covered by Wikipedia, see QEMU.

QEMU is a free and open source emulator that can boot HP-UX, AIX, and Linux for their respective CPUs, and supports AIX, VMS, and HP-UX for tinkering. 1234 QEMU can emulate MIPS, but not all SGI systems boot IRIX, and some targets like alpha do not work well. 567 QEMU can run IRIX user space binaries, allowing binary execution but not direct hardware access, and can run MIPS IRIX apps on x86 from source. 891011 QEMU can run x86 Windows on a SPARC chip, but running Windows 10 in vanilla QEMU is not recommended. 1213 QEMU is slow, and x86 emulation on POWER is at least 10x slower than native. 1415 QEMU is not designed for graphical stuff, and its SPARC emulation for NeXTSTEP is broken. 1617 QEMU can be compiled under IRIX emulation and builds natively on arm64. 1819 QEMU without KVM is only good for different architectures or really old OSes. 20 QEMU is a complex emulator that requires thorough testing, and its closest approach to automatic emulation involves minimal setup. 2122 QEMU emulates only what is required for a target and translates everything else, using a JIT that can offer better performance and scalability. 2324 QEMU can emulate systems with a PROM, including hardware components such as SCSI controllers and Ethernet, and can emulate 603 and 604 PowerPC processors, though PowerPC emulation may be slow. 2526 QEMU can run MIPS NT, but the mouse pointer eventually goes out of control and requires a keyboard reboot, and it cannot run the mips1 uname binary from the HD2 image. 2728 NeWS 1.1 can be run inside QEMU, but there is no emulator for the Personal IRIS or IRIS 4D yet, and the 'white-on-white' bug is specific to IRIS and has a fix in QEMU. 2930 System mode in QEMU does not have the ability to do GL acceleration. 31
