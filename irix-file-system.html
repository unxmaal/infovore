IRIX file system

Claims: 7 Part of IRIX Background: 2 claims already covered by Wikipedia, see XFS.

The IRIX file system can resize partitions, though complex layouts may require manual deletion of partitions. 1 XFS corruption on the IRIX filesystem can hide data in lost+found. 2 Due to expensive storage, the IRIX file system allowed running root, user, and home directories from different locations, sometimes with root local or remote and home on a server. 3
