Xsession

Claims: 5

On Windows, VcXsrv can act as an X server and PuTTY as an SSH client to run an X session on an SGI, using /var/X11/xdm/Xsession to start a graphical session. 1 You can force X to start in truecolor by modifying the Xsession or Xserver or one of those xdm scripts. 2 To replace the default desktop, you change /usr/X11/xdm/Xsession, which changes just the UI. 34 The SGI provided media player that plays AIFF files can cause X session sluggishness on the Octane; killing Xsgi fixes it. 5
