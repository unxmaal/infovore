IRIX 6.5.23

Claims: 4 Part of IRIX 6.5

IRIX 6.5.23 is part of the IRIX 6.5 series, which supports compiling drivers outside of the kernel and supports various hardware. 1 In IRIX 6.5.23, running in 15-bit visual instead of the default 8-bit or 24-bit visual enables antialiased icons. 2 The x_eoe.sw.Artifex_fonts package is available for multiple versions of IRIX, from 6.5.23 to 6.5.30. 3 To restore corrupted files, use swmgr to reinstall the impacted product, either from the single user command line or while IRIX is running. 4

Sources

  1. IRIX drivers can be compiled outside of the kernel, with kernel versions 6.5.23 to 6.5.27 supporting various hardware. (user-8b3c, 2020-05-30, exchange 216937, check: supported)
  2. In IRIX 6.5.23, running in 15-bit visual instead of the default 8-bit or 24-bit visual enables antialiased icons. (user-6afa, 2021-03-15, exchange 69264, check: supported)
  3. x_eoe.sw.Artifex_fonts is available for multiple versions of IRIX, from 6.5.23 to 6.5.30. (user-e4d0, 2024-12-13, exchange 86081, check: supported)
  4. To restore corrupted files, use swmgr to reinstall the impacted product, either from the single user command line or while IRIX is running. (user-c831, 2025-02-06, exchange 114563, check: uncheckable)
