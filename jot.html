Jot

Claims: 10

Jot is a text file editor for IRIX that uses ASCII and Unix line endings. 1 It is a simpler editor compared to nedit, which is more sophisticated. 2 The `jot` command is a wrapper for `nedit` that translates command-line arguments for compatibility. 3 Nedit can display on regular X terminals, while the original `jot` could not. 4 Jot icon and binary exist in IRIX 6.5.30, but launching Jot fails. 5 Jot is completely borked on an IRIX 5.3 install. 6
