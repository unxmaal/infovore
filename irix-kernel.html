IRIX kernel

Claims: 13 Part of IRIX

The IRIX kernel has contributions from SGI and AT&T, with some Sun code in NFS. 1 The IRIX kernel can be rebuilt, and miniroots are necessary for unsupported platforms, with rebuilding for an unsupported platform involving transferring kernel bits from a supported system. 23 The IRIX kernel can be loaded from a TFTP server, an old Zulu, or a CD with EFS filesystem. 4 The IRIX kernel disables PS2 ports on IO6 unless a media daughter card is present. 5 The IRIX kernel has a brain-dead way to find SCSI controllers, requiring a hack for NVMe controllers; typically, systems look at /hw/scsi_ctlr instead of /hw/ql/2. 6 You would need a PCI bridge driver and PCI layer compiled into the IRIX kernel. 7 Porting amdgpu to IRIX kernel would require adding new kernel API to Mesa and possibly writing a queue server and memory allocator. 8
