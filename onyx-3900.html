Onyx 3900

Claims: 3 Part of Onyx

SGI maintained IRIX binary compatibility, allowing the same binary to run on machines ranging from an Indy up to a 1000 CPU Onyx 3900. 1 The blue Fuel was a prototype loaner from SGI used for porting software to an Onyx 3900, kept after SGI's bankruptcy and orphaned. 2
