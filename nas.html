NAS

Claims: 19 Background: 1 claim already covered by Wikipedia, see Network booting.

A NAS is useful for storage and can be invaluable for storing data, including IRIX data, SGI software, and other files. 123 It is more practical to use a NAS or similar NFS file server than to configure an SGI as an NFS server. 4 A NAS is functional and compatible with SGI systems. 5 NFS is a viable option for sharing a NAS, including for read-only shares with retro machines and for netbooting, though NFS does not work with the user's Octane to their NAS. 678 A NAS can be built from various hardware, including a Power8 system, a ZFS pool, or low-budget used equipment, and can be configured in RAIDZ2 with hot spares. 9101112 A NAS can be used for a range of networked tasks, such as serving media, supporting video editing, and hosting web servers or Docker containers. 1314
