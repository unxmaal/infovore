busybox

Claims: 6

Busybox provides reduced-footprint utilities packaged in a single statically-linked binary, as used by Damn Small Linux bootdisks. 1 Alpine Linux runs Busybox instead of GNU utilities, alongside musl. 2 The T31_ZX has a RISC-V core used mostly for video, can run little-endian, and has been tested with Busybox and Slackware 15. 3 The busy box can be used to console in and start an IRIX prompt. 4
