Quadra 610

Claims: 5 Part of Quadra

The Quadra 610 can boot A/UX, making it usable as a Unix box despite being a 68k machine. 12 It can run A/UX with a 68040 upgrade, and it has a full 040 CPU if marked as such, otherwise an LC040 that can be upgraded. 34 A/UX machines can be found, with the Quadra 610 being more affordable, though finding one with a full 040 CPU can be difficult. 5
