R2000A

Claims: 12

The R2000A is an R3000 core in an R2000-compatible package, with the R3000 adding multiprocessor support while the instruction set remains unchanged. 12 The R2000 and R3000 use different packages, with the R2000A being a variant. 3 SGI reports the R2000A/R3000 processor together. 4 IP numbers on SGI workstations designate the CPU board and platform, with higher numbers generally indicating newer or more powerful hardware. 5 The DECstation 2100 is a 12MHz R2000A, while the 3100 is a 16.67MHz version that is slightly faster but has abysmal graphics and a buggy Unix. 6 The MAME project defines device types for the MIPS R2000, R2000A, R3000, R3000A, R3041, R3051, R3052, R3052E, R3071, R3081, and SONYPS2_IOP. 7
