POWER9

Claims: 27 Part of POWER Background: 2 claims already covered by Wikipedia, see POWER9.

POWER9 is a CPU architecture implemented by IBM, with Raptor Computing using IBM's POWER9 implementation to sell POWER9 workstations a few years ago. 12 POWER9 hardware is very expensive, with AMD's POWER9 CPU costing around $2.8k per chip plus board overhead, and Raptor hardware with a dual socket board and cheapest CPU costing $2600. 34 POWER9 machines run both IBM i and other operating systems, including Debian, Ubuntu, Void, Arch Linux, and AIX. 5678 POWER9 is bi-endian and can execute up to 4 instructions per cycle with SMT4, allowing 1, 2, or 4 threads per core. 910 POWER9 is underpowered relative to modern hardware and underpowered per watt, with the fastest 3 supercomputers currently running A64FX, POWER9, and POWER9. 111213 The Power9 has numerous compatibility issues and failures, including bad RAM, motherboard damage, and CPU failures, and compatibility can be difficult since a lot needs building from source. 147
