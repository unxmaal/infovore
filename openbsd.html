OpenBSD

Claims: 140 Background: 11 claims already covered by Wikipedia, see OpenBSD, FreeBSD, NetBSD, VAX.

OpenBSD runs well on a range of architectures, including Ultra 60, MacPPC, 486-class CPUs such as the StrongARM in Soekris boxes, Dell T710 servers, Sun Blade 1000, and the U80 with 4x450 MHz CPUs and 2GB RAM. 123456 It also runs on the Indy with a rebirthed port, the SparcStation IPX, and SPARCs, though it may not be the best choice for SPARC hardware. 78910 OpenBSD has dropped support for several architectures, including SPARC32, MIPS, SGI/mips, and VMS (around version 5.8). 111213 It is adding PowerPC P8 or newer LE support (ppc64), and is considered better than NetBSD on x86, ppc, and arm, though it is slow on Alpha. 141516 OpenBSD is generally preferred over NetBSD and is considered more stable than NetBSD for GUI use, though some users prefer FreeBSD for its features. 171819 It is regarded as a nice networking OS, and is used on public-facing servers and work testboxes. 2021 OpenBSD lacks package management, requiring use of ports, and generally boots from the install CD. 2223 It has good man pages, uses doas, and its X is not setuid by default for security reasons. 242517 OpenBSD runs on a wide range of hardware, including VAX, NVAX, PPC, SPARC, and Ultra-10 systems, and can be installed on very low-end hardware such as a 33MHz R3000 with 32MB. 262728293031 OpenBSD dropped the mips/sgi port because no one volunteered to maintain it, though MIPS support was later resurrected with cavium support. 323334 SPARC support may be dropped soon, and hardware acceleration is not supported in OpenBSD versions greater than 6.7. 3536 OpenBSD provides binary packages but lacks modern browsers, and may have had more modern software support. 3735 OpenBSD is simple, while DragonflyBSD uses a Hybrid kernel and has the HAMMER filesystem. 38 OpenBSD is open, free, and current software (kernel and userland) for SGI machines. 39 OpenBSD supports the IP22 kernel, maintained by user-6e7b since 2021, though it is not well-supported on IP22. 4041 OpenBSD stopped supporting the sgi platform in 2021. 42 OpenBSD can be installed manually using commands like dksc(0,2,8)sashARCS or booted from an .iso file using dksc(x,y,z)sashARCS. 4344 The CD ISO is a minimal installer that sets up networking and grabs file sets for OpenBSD remotely. 45 An SGI Octane can run OpenBSD. 46 OpenBSD is used for firewalls and mail servers. 47 OpenBSD can be installed on SGI hardware through several methods, including building a root filesystem with NFSRB2 or unpacking the sets yourself, with older versions of OpenBSD sets available on the FTP server at ftp.eu.openbsd.org while the main server only carries the latest ones. 48 The OpenBSD boot process for SGI machines involves determining IP via BOOTP/DHCP, loading a kernel via TFTP, starting the kernel, determining IP again, asking Bootparamd for root and swap paths, and mounting root via NFS. 49 Switching to OpenBSD can make many SGI systems work out of the box, and OpenBSD can boot to a glass console if configured in PROM. 5051 OpenBSD can run on IRIX IRIS systems using an IP22 kernel with a custom loader, with ramdisk kernels up to 7.4 usable to boot and install OpenBSD. 5253 OpenBSD talks to the WD SCSI controller via PIO port instead of DMA, using a base address from the documentation that differs from what PROM and IRIX use, and the driver has issues with emulated controllers. 5455 OpenBSD requires a special read of ASR with CIP=0 after SELECT, which is incompatible with IRIX's behavior of not reading ASR and expecting an interrupt. 56 OpenBSD hasn't managed to have everything under one license yet. 57
