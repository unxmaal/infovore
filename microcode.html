microcode

Claims: 10

Microcode is typically undocumented, similar to proprietary drivers. 1 The functionality provided by microcode cannot be copyrighted, but the code itself can be. 2 The microcode starts with a branch table for commands, making it easier to identify branch address fields. 3 Uploading new microcode to SGI graphics subsystems is possible but risky and requires extensive reverse engineering, as detailed documentation is scarce. 4 The GR2 microcode is complex and high-level, making 3D implementation difficult. 5 SGI/IRIX ships microcode for the VICE's BSP/MSP programmable systems for each supported VICE codec. 6
