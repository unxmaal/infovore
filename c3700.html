C3700

Claims: 6 Part of C

The C3700 is a modified C3600 that can run HP-UX 11.0 but not 11i, requiring a system board and possibly CPU replacement. 1 The C3700 can dual-boot HP-UX 11.1 and Linux/BSD. 2 The PROM of the C3700 has an autoboot feature that can be disabled to choose the boot path. 3 The C3700 supports HP-UX and has GPUs, and a PCI Radeon 7500 might work for graphics. 45
