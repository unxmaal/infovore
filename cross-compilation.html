cross-compilation

Claims: 5

Cross-compilation can be challenging due to packages expecting to run tools they've just compiled and those that use build tooling not supporting cross-compilation. 1 This difficulty is especially evident with SBCL, which is written in Common Lisp, and with CLisp, where the inconsistency in binary naming between binutils and GCC can cause issues. 23 Cross-compilation from x86 to MIPS was challenging early on, with GCC providing subpar results compared to native compilation. 4 user-2189's compilertron is a Docker container that can be used for cross-compilation with distcc on an IRIX box. 5
