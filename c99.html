C99

Claims: 16 Part of C Background: 2 claims already covered by Wikipedia, see IRIX, Open64.

MIPSpro is an older SGI compiler that supports C89 and is fast but may lack full C99 support, having been K&R before becoming ANSI C and then stopping at C99. 12 MIPSpro supports many C99 features but some constructs can cause it to crash, and it supports at least C99 and possibly C95. 34 Variable attributes in C99 are implemented via macros that control compiler behavior. 5 The declaration int xyz[]; is officially supported in C99 and MIPSpro, whereas int xyz0; was a GCC-ism before C99. 6 Microsoft used an array declaration at the end of bitmap header structs in early Windows SDKs, before C99. 7 The isnan function is defined in math.h in C99. 8 The stdint.h header is required for C99 compilers but may be optional for C89 compilers on IRIX, and upgrading the compiler to C99 is recommended for future compatibility. 9 Compiling GCC on HP-UX with a C99 compiler may fail due to bootstrap comparison errors, so a C89 compiler should be used instead. 10
