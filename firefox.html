Firefox

Claims: 21 Background: 6 claims already covered by Wikipedia, see Firefox, File Transfer Protocol, NetSurf.

Firefox is a popular browser on SGI systems, though it is not the only option, as Netsurf is also available. 12 The last official Mozilla suite for IRIX was Mozilla 1.7 before it became Firefox, and earlier builds of Phoenix (now called Firebird, now called Firefox) released official IRIX builds. 34 Firefox and Netsurf run on IRIX via MAME emulation, though with known issues, and there is a rendering issue with Seamonkey and Firefox on IRIX where software rendering in Cairo/GDK is problematic, making them slow and unresponsive. 56 Compiling Python 2.7 is necessary for Firefox builds on IRIX, and it requires some adjustments to the Makefile. 7 nekoware has some old firefox builds. 8 Neither SGI nor Sun receives new Firefox support. 9
