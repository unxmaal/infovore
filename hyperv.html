HyperV

Claims: 10 Background: 1 claim already covered by Wikipedia, see Video games and Linux.

Hyper-V is a type 1 hypervisor that works similarly to the Hyper-V desktop on Windows Server. 1 Hyper-V only runs modern supported operating systems, and even then there may be limits; for example, Hyper-V does not run Windows XP. 2 Hyper-V has worse emulated hardware support and lacks native device mapping, such as USB devices. 3 VirtualBox can use Hyper-V when it is enabled on the host, which can cause memory issues in VMs, and must use Hyper-V to access hardware virtualization features when Hyper-V is enabled. 45 WSL2 virtualizes the entire OS, running Hyper-V and then Windows in a VM and Linux in a VM. 6 Ish is mostly Linux running in Hyper-V, but there is some special integration stuff. 7
