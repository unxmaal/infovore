neofetch

Claims: 9 Background: 1 claim already covered by Wikipedia, see Bash (Unix shell).

neofetch is a bash script that works with bash 3.whatever. 1 It queries a database and probes system data, and can appear minimal while requiring a modern system. 2 It can take a long time to run, especially on older systems like the O2, due to slower hardware such as SCSI hard drives. 3 There are patches for neofetch to improve the SGI cube logo, and to make it correctly detect the DE and GPU on Solaris/SPARC. 45 Xming passes the host GPU as the device, affecting neofetch queries. 6 Disabling threading might help with neofetch on QuickTransit-emulated IRIX by running 'cpuconfig threads off' before neofetch. 7 The SGUG neofetch works fine. 8 Some applications like cowsay, cowthink, and neofetch return 'not found' errors, possibly due to path length issues. 9
