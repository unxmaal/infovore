GemRB

Claims: 7

GemRB is a game engine that has been ported to IRIX, where it can run Baldur's Gate, though with color issues, while Quake did not run and Maya had limited success. 1 It can be compiled from source on IRIX according to the INSTALL file, which lists modest requirements, though porting the latest release resulted in a core dump or bus error. 23 GemRB boots but crashes early in Baldur's Gate, an issue that may be resolved with specific dependencies. 4 GemRB can run games under QuickTransit along with DevilutionX, though it does not work well in that environment. 56 Software like DevilutionX and GemRB has been ported to IRIX, alongside functional ports of Doom and Quake, with SGUG's RSE project regularly bringing new software. 7
