General

VMS stands for Virtual Memory System. 1 It can run on Alpha machines, with all Alpha models except very few able to run VMS. 2 It can also be run on the DEC Multia, though this is tricky and challenging because the Multia was intended to run Alpha Windows NT or tru64 rather than VMS. 3456 It can be run on x86 architectures, which use only two privilege levels, and the original x86 compiler toolchain was a cross compiler. 78 It can be run on Itanium (ia64) systems, where only HP or Itanium 1 systems can run VMS. 910 It can be run on QEMU, which supports VMS alongside AIX and HP-UX for tinkering. 11 It implements memory protection by setting a secret out-of-band bit, and only the OS can craft pointers in VMS. 1213 It uses a unique command structure with verbs and nouns, has POSIX functions, and its filesystem and permission control are effective and flexible. 141516 VMS is an operating system that has been supported on a variety of hardware, including older systems and IA64 machines, where version 8.4 is currently supported. 1718 A planned x86-64 port of VMS exists for Half-Life 3, and TECO, the editor included with VMS, may be included in the x64 port. 1920 VMS is not descended from Windows NT, and the Windows NT kernel is not based on VMS. 21 VMS expects interactive usage, unlike many mainframe operating systems. 22 VMS software can be divided between the pre- and post-CD eras, with CD-based software being easy to find and tape-based software being hit and miss. 23 VMS is available on x86 systems through the hobbyist program for Alpha or IA64 systems, with alternative licensing options existing for x86. 242526 VMS licensing is specific to machine size, with concurrent user licenses available for different types of machines. 27 For VMS, running one script provides the necessary licenses. 28 DEC/Compaq published the whole VMS documentation on CD in HTML format. 29 Commercial or open source software for VMS is hard to find, especially since VAX/VMS 5. 30 The Software Product Library CDs contain interesting applications for VMS, with compilers and developer tools available, including DECSET. 31 VMS versions depend on hardware release and CPU model. 32 DECWindows requires a VMS version greater than 5.X to function properly. 33
