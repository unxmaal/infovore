installation

Claims: 17

IRIX installation can be performed using a network install server or CD images, and some support discs are bootable and can start an install, supporting all hardware available up to that point. 12 A CD image can be dd'd to a hard drive and used for installation, requiring minor adjustments to /dev symlinks, and installing from a second hard disk with the installation distributions onboard can be faster and more efficient. 34 Serial installation is not a standard method; typically, ethernet or CD is used, and while there is a flag to set text mode, a mouse and keyboard usually default to graphical output. 5 To customize an IRIX installation, click 'customize installation' to see available packages, and for a fresh IRIX 6.5 installation, use the `relocate` option in `inst`. 67 The installation can be done in about half an hour, and specific conflict resolution at the end of the video is recommended for installation. 89 You can start an installation and use the admin menu to start a shell to edit /etc/passwd, and disabling the DRC during IRIX 5.3 installation can avoid annoying issues. 1011 IRIX installation can retain previous settings, potentially causing issues later, and the system reports initialization not complete and resets, possibly due to an incomplete IRIX installation. 1213
