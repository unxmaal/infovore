PS2 TOOL

Claims: 4 Part of PS2

The PS2 TOOL is a development system with a Linux-based PC and a PS2 console, using the PC to simulate a network-attached PS2. 1 The PS2 Tool requires a CR2032 battery, and if the battery is dead, it will not boot until a keyboard and monitor are connected to the SBC, but replacing the battery is only worthwhile if you plan to boot it frequently. 2 The SBC-side hard disk of the PS2 tool has failed, indicated by a non-lit 'TOOL' light which should be amber during startup and green when ready. 3
