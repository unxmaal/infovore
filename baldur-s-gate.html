Baldur's Gate

Claims: 8 Background: 1 claim already covered by Wikipedia, see SGI Octane.

The Baldur's Gate series was ported to IRIX, with recent ports of Baldur's Gate and Diablo available for SGI systems. 12 Baldur's Gate and Diablo ran on early P90 SGI systems with basic graphics on Windows 95, but games like Baldur's Gate and Diablo run slower on SGIs because the code is not optimized for SGI hardware. 34 GemRB allowed running Baldur's Gate, but with color issues, and it boots but crashes early, with issues that may be resolved with specific dependencies. 56
