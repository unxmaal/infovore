x86 hardware

Claims: 4 Part of x86

BSD variants can run on x86 hardware. 1 A slab lookalike with the fastest x86 hardware that can run NS/OS on the metal could be a good project. 2 x86 hardware for OpenSTEP is similar to optimal hardware for OS/2 Warp 4, including Socket 7 CPU, ISA soundcard, IDE hard drive, PS/2 keyboard and mouse, and AGP or Matrox graphics. 3 Running UNIX on an Amiga or Mac is possible but inferior to running it on x86 hardware. 4
