Mozilla

Claims: 16

Mozilla can be installed on IRIX 6.5, where the default installation on later versions includes Chatzilla. 1 The IRIX freeware d2 set can resolve dependencies for Mozilla without causing conflicts, though 6.5.30 includes extra disks for Mozilla and Java that can cause installation conflicts, which is why 6.5.22 is generally preferred. 23 Web browsing on IRIX is limited and not as straightforward as on modern systems, and compatibility with some SGI programs is not guaranteed. 45 Dillo is faster than Mozilla on IRIX. 6 Running Mozilla over X forwarding can crash when resized, and bus errors are actually SIGSEV errors that may be accompanied by issues such as missing X libraries. 78 On HP-UX, Mozilla returns a bus error that is actually a SIGSEV and can be fixed with a patch. 910 Mozilla works on the box, and the O2's performance is suitable for everyday programs such as Firebird, Pan, Mozilla, and Open Office. 1112 768MB of RAM was adequate for running Mozilla with many tabs open. 13
