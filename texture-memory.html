texture memory

Claims: 15

Texture memory capacities vary across hardware: the RM8-16 has 16 megabytes and is limited in performance, the V6 has 8 MB of texture memory, the O2 has as much texture memory as its system RAM, and the DG5 has 256 MB of texture memory per RM10 board. 1234 Some systems lack texture memory or have it in limited amounts, such as the elite3d-m6, which has hardware texturing but no texture memory, and the O2, whose texture memory is limited by its allocation of about half the video RAM after system buffers. 536 Texture memory is considered valuable, with some buyers willing to purchase hardware that includes it, and its absence has been described as a significant weakness. 78910 Texture memory in SGI systems is non-additive, unlike frame buffer memory, and IMPACT systems use non-additive memory with performance benefits. 11
