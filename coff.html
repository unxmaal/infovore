COFF

Claims: 24 Background: 1 claim already covered by Wikipedia, see IRIX.

COFF was the executable binary format used by IRIX 5.3 and earlier, and is not supported in IRIX 6.x. 1 The 4D1-4.x release uses COFF and does not support shared objects; some core libraries were shared but without relocation or dynamic linking. 2 The a.out format was superseded by COFF and then ELF. 3 MIPS4 CPUs cannot run COFF software. 4 A 6.5 system can run o32 and n32/n64 binaries, but not ancient COFF binaries from IRIX 4.x. 5 COFF was used for executables in the SPEC95 suite. 6
