system password

Claims: 5

The system password was introduced to prevent unauthorized use of MULIC tapes but was later removed due to hardware configuration changes. 1 The system password can be set with a jumper on the board. 2 PowerPC as/400s have a system password that prevents the OS from running if the hardware configuration is changed too much, which can be unbricked by IBM. 3 PowerPC machines can run in eval mode for 70 days without an OS license, and there is a rumor about a system password after 255 reinstallation attempts. 4
