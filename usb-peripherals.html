USB peripherals

Claims: 3 Part of USB

PS/2 KVMs are generally more reliable for USB peripherals. 1 To resolve issues with USB peripherals not being recognized at the Irix login prompt, connect to the machine via Telnet and remove the /etc/ioconfig.conf file, then reboot the system with the USB peripherals connected. 2 The Pi shares the data bus for Ethernet with USB peripherals via a hub chip, which could cause network issues at 10 Mbit/s. 3
