stty

Claims: 4

stty is a command used to configure terminal settings, including control characters such as the interrupt character and the erase (backspace) character. 123 It can set the interrupt character for the current session, for example to Ctrl-V Ctrl-C. 1 The effect of changing the erase character depends on the environment: setting erase to ^H makes backspace work correctly in Winterm, while in Aterm it makes backspace return ^H, and using 'stty erase ^?' on Windows PowerShell causes backspace to stop working while it works on Linux SSH, suggesting a Windows-specific issue. 42
