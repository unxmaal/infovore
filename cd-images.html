CD images

Claims: 6 Part of CD Background: 1 claim already covered by Wikipedia, see OpenGL.

The `inst` installer can read CD images, folders on the network, or local discs. 1 To install IRIX, you can use a network install server or CD images, and the Reanimator guide on GitHub provides instructions. 2 For IRIX software installation, CD images can be mounted in Linux and their contents FTPed to the IRIX system. 3 OpenGL and GL 3.2 Version 4.1 for AIX is available on CD images from tenox's server. 4 The BlueSCSI lacks a button to switch CD images, making it inconvenient for installing SGI systems. 5 An app supports toolbox transfers, adjusting wifi networks, and swapping CD images. 6
