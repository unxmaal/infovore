Softimage 3.9.2

Claims: 3 Part of Softimage

Softimage 3.9.2 was released in 2000, while the later version 4.0 was released in 2002, and the two are distinct versions. 1 The installer for Softimage 3.9.2 does not include FlexLM licensing tools by default, so they must be installed manually. 2 Softimage 3.9.2 can be installed on an Octane2, but FlexLM installation can fail on another machine using the same tgz file. 3

Sources

  1. Softimage 3.9.2 and 4.0 are different versions; 3.9.2 came out in 2000 and 4.0 in 2002. (user-8547, 2021-09-12, exchange 217242, check: supported)
  2. The installer for Softimage 3.9.2 does not include FlexLM licensing tools by default, requiring manual installation. (user-3758, 2024-04-10, exchange 218361, check: supported)
  3. Installing SoftImage 3.9.2 on an Octane2 works, but FlexLM installation fails on another machine with the same tgz file. (user-3758, 2024-04-10, exchange 84939, check: supported)
