Sorbet Leopard

Claims: 9 Part of Sorbet

Sorbet Leopard is a PowerPC Mac version of the operating system that can be installed only on PowerPC Macs, not on a Core 2 Duo Mac mini. 1 It feels solid and is similar to the Mac OS X version of SGUG-RSE. 2 Sorbet Leopard runs well on a maxed out 12-inch PowerBook G4 and on a dual G5 PowerMac. 34 It improves web browsing significantly compared to Leopard. 5 It has a built-in PowerPC app store with all updates included, which serves as a one-stop shop for freeware to improve OS compatibility with modern computing needs. 67 It can be automated using a script that performs rsync and rebuilds kernel caches. 8 The 12-inch PowerBook running Sorbet Leopard can compile LLVM and GCC with a fan control utility, keeping temperatures around 66C. 9
