WSL

Claims: 16 Background: 2 claims already covered by Wikipedia, see Quake (video game), VMware.

Microsoft supported Linux on Windows through WSL, which is containerized, and is described as a Linux kernel running on Windows rather than a kernel in the traditional sense. 12 WSL is included in LTSC on 1809. 3 WSL has enabled some users to give up and just use Linux on servers, and running Booterizer on WSL is painful, with backup and reformatting a PC as a Linux box recommended for future use. 45 WSL has limitations, including inability to open sockets or raw sockets, permissions issues due to Windows, and the DX API may rely on some parts from Windows still. 678 WSL has enabled some functionality, such as running QEMU-IRIX for IRIX binary execution and running Quake with pulse or portaudio sound support. 910
