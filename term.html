TERM

Claims: 5

The `TERM` environment variable specifies the terminal type, and common safe values include `xterm`, `ANSI`, and `vt220` [,]. 12 It can be set using commands such as `export TERM=ANSI` or `setenv TERM=xterm` [,]. 13 Setting `TERM` in files like `.login`, `.profile`, or `.cshrc` also allows configuration of other environment variables such as `MANPATH` and `EDITOR` []. 4 Terminal emulators may display line drawing characters correctly on some terminal types but fail when run within `screen`, even if `$TERM` is set to `vt100` or `vt102` []. 5
