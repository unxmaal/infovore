POWER7

Claims: 9 Part of POWER

POWER7 is a single-die design, as are Power8 and Power9, whereas the UltraSPARC IIIi and Alpha EV5 are delidded. 1 POWER7 has 8 cores at 4GHz. 2 The Power7 uses CGMT, which involves flushing a pipeline entirely to switch between threads for long events like L2 misses. 3 POWER 6/7/8/9 run both IBM i and other operating systems. 4 CentOS still supports POWER7 because it is forked from RHEL, which has always supported big endian before little endian modes were a thing. 5 POWER7 is being deprecated in the next AIX release (7.3) and can be found at somewhat cheaper prices. 6 There are tools to extract and install firmware on Seagate ES2 drives, but they only work on POWER7 machines. 7
