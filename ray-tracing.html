ray tracing

Claims: 5 Background: 1 claim already covered by Wikipedia, see Blender (software).

SGI never made any hardware that specifically accelerated raytracing, though it did produce the Render Drive, a ray tracing graphics appliance from the late 90s with ASICs that supported RenderMan or the Maya API but was finicky. 12 Enabling ray tracing in Blender can improve the output quality. 3 Wave Race 64 has a PC port with Ray Tracing available on GitHub. 4
