RaSCSI

Claims: 65

With BlueSCSI

BlueSCSI is based on RaSCSI and is a SCSI emulator for the IIgs that can use the same images as RaSCSI, assuming you have a SCSI card in the IIgs. 12 The BlueSCSI uses a Bluepill STM32 microcontroller and is cheaper than the RASCSI, which is the most versatile, while BlueSCSI is the cheapest and ZuluSCSI/SD2SCSI is the fastest. 3 BlueSCSI and RaSCSI share core SCSI signaling but differ in their environments, and the RASCSI can use a BlueSCSI for SCSI emulation. 45 The BlueSCSI and RASCSI firmware fixes disk utility and apple-branded disks issues, improving compatibility. 6 There are preinstalled and blank images available for Rascsi/BlueSCSI at https://github.com/erichelgeson/BlueSCSI/wiki/Usage#premade-images. 7

General

RaSCSI is an open source project that runs on a Raspberry Pi and emulates SCSI devices, including drives, CDs, and SCSI Ethernet. 8910 It was designed for x68000 machines but can potentially turn a Raspberry Pi into a SCSI drive in SGI machines. 11 RaSCSI supports multiple drive emulation, CD emulation, SCSI Ethernet, hot-swappable SCSI drives via Raspberry Pi USB ports, and can mount an ISO file from the web as a CD via HTTP. 91210 RaSCSI speeds are capped at 1MB/sec due to GPIO limitations, though it can achieve speeds up to 4MB/s on an Atari Falcon. 131415 RaSCSI's main bottleneck is likely CPU speed, and it could be used for SCSI-to-iSCSI conversion due to its more powerful architecture. 1617 RaSCSI allows swapping between different IRIX versions on the same machine by hot swapping the boot disk, and it is the only known solution for IRIX multiboot besides manually switching out hard drives or SD cards. 1819 RaSCSI can be managed with an Android app and can be purchased from a tindie option on the Github page. 2021 RaSCSI is a SCSI drive emulator built on a Raspberry Pi that is cheaper than a SCSI2SD and can also emulate a SCSI Ethernet adapter for classic Macs and a SCSI display adapter for video output. 22 It can emulate multiple device types, offers a fully configurable web interface accessible from the host machine, and provides a one-click installation of netatalk. 2324 It can be ported to various platforms, including Pine64, with some work, and acts as a pass-through for iSCSI. 2526 It provides Ethernet functionality for systems without native Ethernet support, and with a SCSI disk emulator like RaSCSI you can swap disk images easily. 2728 It is the easiest for CD image handling with a web interface, providing a minimal web page for local system connections when changing images. 29 It gets about 1.5MB/sec, compared to SD2SCSI v6 at close to 10MB/sec and ZuluSCSI at 4-5MB/sec. 30 CD drive emulation in RaSCSI causes random read errors with Mac drivers, and it can cause hardware failures on SS10's SCSI bus due to a metal part pressing on a 5V trace, leading to SCSI bus parity errors and inability to boot from the internal hard drive. 3132
