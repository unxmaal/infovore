KVM/Qemu

Claims: 3 Background: 1 claim already covered by Wikipedia, see VirtualBox.

KVM/Qemu supports bridged networking mode, though it is more complex to set up than Virtualbox, which also offers bridged mode. 1 KVM/Qemu is suitable for running modern operating systems such as Windows, Linux, or BSD. 2 The Windows Phone emulator runs on KVM/Qemu but not on Virtualbox, which supports USB passthrough for flash mode. 3
