font

Claims: 11

A font is a bitmap that does not store color information, so the color can be selected by passing a uniform to the shader. 1 The font is TTF and matches the Origin 350 style logos. 2 A font can be placed in ROM by writing a script that generates the tables and waveforms and produces C code that yields the corresponding data. 3 Rosegarden encounters font and Petal library errors when run as root, and fails with a calloc error when run as a non-root user. 4 The console display and font are nice, possibly leading to using it solely in console mode. 5
