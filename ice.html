ICE

Claims: 7

The SGI ICE uses the SGI Compression Library (CL) for acceleration, and its binary files are raw and difficult to disassemble. 1 The RSP and ICE are 95% identical; the main difference is ICE includes 8-bit and 16-bit versions of instructions, has larger instruction memory, and access to all of RAM. 2 Programming the ICE on SGI systems is similar to N64 programming, and to interface with the ICE, decode it manually and create your own library. 34 The ICE can be used with OpenGL via SGI's MIPS processors, and there's potential to drive it directly on Irix with new vector code, as shown by the Linux libvice project for O2. 5 An assembler exists for MIPS consoles like N64 RSP and targets VICE, which could theoretically be used to run ICE code on actual hardware, though its use on SGI systems is unclear. 6
