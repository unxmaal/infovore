PA-RISC

Claims: 54 Background: 3 claims already covered by Wikipedia, see NeXTSTEP, Pkgsrc, QEMU.

With HP

HP replaced PA-RISC with IA-64, similar to how DEC replaced VAX with Alpha. 1 HP-UX has PA-RISC emulation built-in, and the Itanium could run PA-RISC code via HP-UX, which was generally fast, though not as efficient as native PA-RISC. 23 There should be a PA-RISC to IA64 translation layer baked in HP-UX. 4 Old GE portable ultrasound devices run HP-UX on PA-RISC. 5 Patran 2006 R1 is available for HP-UX on both parisc and itanium architectures. 6

General

PA-RISC is a RISC architecture that was declared a dead-end by the 21st century and was intended to be replaced by IA64/Itanium, which was given a planned lifetime of 18 years, 3 months, and 4 days. 7 PA-RISC has two ABIs, with the 64-bit one being very different and only supported by HP-UX, and it does not officially support 64-bit executables except for the kernel. 89 PA-RISC has vector extensions that might be useful for optimization. 10 LLVM has a MIPS backend but not a PA-RISC backend, though Ghidra supports PA-RISC and Radare2 has some PA-RISC support. 111213 IDA might support PA-RISC assembly, but disassemblers for the platform are limited, especially for IA-64, and runtime assessment is challenging. 14 NeXTSTEP was ported to multiple architectures including PA-RISC, and it requires special RAM for HP9000 systems, with 64MB recommended and a 2GB disk image suggested for SCSI emulation. 1516 The Macintosh Application Environment was available for SPARC and PA-RISC but not for IRIX. 17 gcc 9.x can be built on PA-RISC HP-UX 11i v1, and pkgsrc on PA-RISC can be ported successfully. 1819
