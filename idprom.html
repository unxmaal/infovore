IDPROM

Claims: 11

Programming the PowerPC G5's IDPROM took longer than expected but is straightforward once understood, and the IDPROM can be reprogrammed with the process working as intended. 12 Resetting the ID PROM and using 'reset-all' can simulate a power-on reset, but it only works for one boot, while setting the IDPROM checksum by calculating XOR-checksums for entered values and writing them to specific addresses can resolve IDPROM issues if set correctly. 34 The IDPROM can be fixed from the OF command line, and the firmware may then be upgraded. 5 The machine reports as a SPARCstation 5 with a 170 MHz TurboSPARC processor but has an invalid IDPROM, and booting an SGI machine with a bad idprom is typically painful, often throwing errors and causing issues with hard drive recognition. 67 To open the ID PROM, submerge the board in boiling water and use a flat screwdriver or chisel to remove the resin, and a broken IDProm pin can be fixed by using a new socket with a wire for the damaged pin and soldering the pin to the IDProm. 89 NetBSD will likely boot without a valid idprom. 10
