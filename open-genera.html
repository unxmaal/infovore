Open Genera

Claims: 7

OpenGenera is an emulator for the Genera OS, which normally runs on Lisp machines, and it is not open source. 1 OpenGenera is the VLM and can be run on Linux using source code that was leaked a long time ago. 2 Tru64 has software including OpenGenera and can run it, with Tru64 5.1 as a possible base version, though the latest version runs fine. 345 Open Genera requires a patch from the archive.org link and runs on old OSF systems but not Tru64. 56 Digital UNIX works fine on DS10s and can work with Open Genera. 7
