Softimage

Claims: 75 Background: 2 claims already covered by Wikipedia, see Softimage (company).

Alias3 and Softimage are important software for CGI, used in movies like Jurassic Park and South Park. 1 Jurassic Park was done in Alias and Softimage. 2 Softimage runs in a discrete system environment, metaphorically treating itself as a system rather than a program. 3 Softimage and some Nichimen 3D suites are available for IRIX, but the Nichimen suites are unstable due to a Y2K issue. 4 Most IRIX software doesn't take up much space, with Softimage fitting on an Indy with 300-400MB. 5 The Softimage renderer works but mental ray does not work with their copy of Softimage. 6 The IRIX versions of Softimage aren't going away, so there's time to get better with it. 7 Old versions of Softimage, IrisGL, and other software were distributed on tape and manual binders. 8 SoftImage was a 3D software product available on SGI systems running IRIX, with early versions predating a switch to NT. 910 Versions 3.7 through 3.9 are covered by available licenses, which likely won't work for 2.66, and pre-flexlm versions (2.66 and earlier, possibly also 3.0) allow an 'any' hostid. 1112 SoftImage 2.66 from 1994 is available for download, and the 2.61 and 2.62 packages include more software than 2.66, such as older versions of Liberty Paint, Toonz, and Eddie. 131415 SoftImage can be difficult to set up, especially in later versions, and requires the Relations.rsrc file in the correct directory to run. 1617 It requires an Rsrc directory in /usr/softimage/Creative, copying it there allows the application to start up, and on IRIX 6.5.30m it requires setting LD_LIBRARYN32_PATH to find its N32 libraries. 1819 SoftImage can generate new databases if existing ones are missing or invalid, and 2.66 is prone to crashes, but basic operations can be performed. 2021 SoftImage was a legacy product after 3.8, with XSI as its successor, and is still considered more functional than the latest Autodesk products. 2223
