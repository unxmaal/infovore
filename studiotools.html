StudioTools

Claims: 9

StudioTools is a product supported by Alias, along with CATIA and SolidWorks. 1 Alias PowerAnimator was essentially StudioTools with some animation modules, and Alias removed animation features from PowerAnimator when renaming it to Studio Tools after version 9.x. 23 PowerAnimator was used for industrial design and overlaps with StudioTools, with feature sets depending on license type. 4 StudioTools versions 9.5, 11, and 13, as well as Maya 6.5, can run on Windows 10, and StudioTools 13 is downloadable for IRIX. 56 Alias made high-quality promotional videos for Studio Tools in the early 2000s. 7 A script exists to list Maya environment variables, possibly adaptable to older versions or StudioTools. 8
