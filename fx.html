fx

Claims: 54

fx is a tool used to partition and set the partition map on SGI disks. 12 The fx command only labels the drive and creates a disklabel rather than a filesystem, so mkfs must be used to create a filesystem. 34 fx always performs low-level formatting, which is why it is not recommended for formatting and should never be used to format a drive. 56 The auto command in fx performs a butterfly test and disk initialization, though it is not required for installation and can be skipped. 78 fx was mainly designed for SCSI and ESDI drives. 9 The FX, along with the Series E, EX, MPX100, Risc PC, Risc PC Plus, MVME160X, 260X, 360X, 460X, Atlas, Ultra, and Ultra Plus, runs AIX. 10 fx can be run from PROM or an IRIX install on an Octane2, and booted from a CD using 'boot -f dkscsash' then 'boot -f dksc/stand/fx.ARCS -x'. 1112 Running fx from the OS shell works, but 'ls dksc' fails with an EFS read error, while running it from the SCSI disk caused a panic. 1314 The 'format' feature of FX tries to perform a low-level format which can cause issues, and SCSI drives should not be formatted with FX. 1516 Partitioning the drive in FX can bypass the hard disk image file on the SD card and write directly to the SD card in RAW mode, which results in no logs. 17 fx can be used to clone an XFS drive on an Octane2 by repartitioning and formatting, then using xfsdump and xfsrestore to copy the data and manually transferring header files, and Irix can be installed from a hard drive using sash and fx, partitioning, and copying miniroot. 1819
