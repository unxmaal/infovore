RPi

Claims: 9

The RPi can be accessed via a single node modem pool. 1 booterizer has a rpi version with a downloadable image. 2 The RPi method involves fetching an image, writing it to an SD card, and starting the RPi; it does not support user-defined template variables. 3 Reanimator is a distro that can upload content to an RPi server via SMB and FTP, and read/write from an SGI via NFS or for network installation. 4 Minitel was a French pre-internet service from the 80's that ran on France Télécom's telephone service, think very early dialup, server-based, people have made Minitel servers using RPis that can be connected to. 5 Setting the IP in ansible/roles/rpi_setup/templates/*dhcpd* allows the RPI to connect to an SGI without manual intervention. 6 IoT Core uses the Pi bootloader. 7 There is an issue with freeglut on RPi with texturing enabled. 8
