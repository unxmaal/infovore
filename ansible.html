ansible

Claims: 37 Background: 6 claims already covered by Wikipedia, see Ansible (software).

Ansible is an automation tool that can run commands locally or remotely via SSH, and can manage standard Unix sysadmin tasks such as setting the timezone and configuring SGI systems once SSH is available on the target host. 123 It can run puppet, and can be used together with puppet. 45 Ansible is good for running on many machines but is not great for showing output in real time. 6 To run a task only if a variable is true, use the 'when' keyword in the task definition. 7 Ansible can trigger other tools, and terraform can trigger ansible. 8 Booterizer uses Vagrant and Ansible to create a virtual machine and provision an SGI system, using Ansible for post-install configuration. 910 Booterizer will not work on IRIX, and all booter versions require specific versions of ruby, ansible, and vagrant, with BigSur being incompatible. 1112 Booterizer does not require ansible to be installed on the host OS. 13
