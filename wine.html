Wine

Claims: 19 Background: 1 claim already covered by Wikipedia, see Video games and Linux.

Wine is a compatibility layer that runs Windows applications without inherent speed loss. It provides a hybrid userspace for running Windows software on Linux, though it has compatibility issues for low-level hardware access. Wine covers most APIs from that era well, with some bugs and edge cases remaining. 123 Wine has tools like DXVK to handle DirectX, and Vulkan works on both Windows and Linux. Microsoft has not made a version of DirectX for Linux on the metal, so users must use Wine's DirectX compatibility layer or dxvk instead. 45 Wine is used to run games, installers, and applications such as Adobe software, which is not well-supported on Linux and can be problematic. Progress Quest runs on Windows, Linux, and Mac OS through Wine. 6789 Wine can emulate Windows better than Windows itself in some cases, and works better than Windows sometimes for certain tasks. user-5510 runs x86 binaries on PowerPC using Wine. 101112 Wine is based on by ReactOS, which may not run all Windows software. A new OS would need a Rosetta2 layer for compatibility with Linux and Windows through Wine. Wine is being ported to Haiku for the next beta release, along with Chromium and GTK. It would be possible to port Wine to IRIX and compile Windows software for MIPS-be. 13141516
