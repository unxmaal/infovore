git

Claims: 31 Background: 5 claims already covered by Wikipedia, see Git, GitHub, Heartbleed.

Git is a complex package with many components and dependencies, making it difficult for beginners. 1 The git stage took a long time, with a large repository taking over half an hour to checkout on a decent laptop. 2 Resolving deltas in a Git repository happens locally. 3 Git rebase can squash multiple commits into one, and force-pushing is required if commits have already been pushed to GitHub. 4 git rebase pops your commits off, puts new from remote, and plays yours on top, giving you a chance to resolve conflicts, but doesn't overwrite the remote history. 5 git blame shows the last person who edited a specific line in a specific file. 6 git commit —amend —no-edit can be used to fix a typo in the commit message without editing the message itself. 7 You can use git reset to unstage changes, then commit again and force push to clean commit history. 8
