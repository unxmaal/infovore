Eclipse

Claims: 7

Eclipse was bundled with early versions of Alias and is a COFF binary requiring SGI 5.3 or earlier. 1 The Eclipse graphics use Raster Engines, not Reality Engines, and the PI's graphics board is a GR1.2 with four RE2 chips capable of hardware bitplane operations. 23 The Eclipse was one of the few machines to use a MIPS Technologies chip, specifically an ECL chip. 4 The 4D/30 and 4D/35 used either Eclipse or Express graphics systems. 5 In emulation, Eclipse graphics are close to working, unlike GR1, LG1, and Newport graphics, which have only partial emulation. 6 Eclipse always stayed a demo version when a license code was entered. 7
