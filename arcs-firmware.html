ARCS firmware

Claims: 10 Part of ARCS

The ARCS firmware is used by the 320 and 540 'classic' Visual Workstations, which also use SGI custom chips. 1 SGI Visual Workstations use ARCS firmware but run PIIIs in little endian mode, making them a hybrid. 2 The Pi400 can use ARCS firmware. 3 When using ARCS firmware, you cannot boot beyond Windows 2000 because the firmware limits it. 4 There is no VM that supports Cobalt or ARCS firmware. 5 An AlphaStation 255/300 runs Windows NT and uses ARCS firmware. 6 The PROM chip is on the bottom of the mainboard, and desoldering it allows for modifying the ARCS firmware. 7 The ARCS BIOS is expected to save and restore the MIPS coprocessor state and handle exceptions over to the ARCS firmware, which NetBSD may not be doing. 8
