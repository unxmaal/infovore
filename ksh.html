ksh

Claims: 8

ksh is preinstalled on many commercial UNIX systems and serves as the default shell for new users and for old application compatibility. 1 ksh supports shell history, which can be configured via the HISTFILE variable, and arrow keys can be enabled with `set -o emacs`. 23 In ksh, the equivalent command to export for setting environment variables is setenv. 4 On IRIX 6.5.30, /sbin/sh is ksh88 in bourne compatibility mode, which behaves differently from ksh and rksh when invoked as sh; setting _XPG to 1 fixes the issue, and mksh is being used as an alternative. 5 An alternative shell like ksh can be used for configure scripts to work around issues with /bin/sh. 6
