Xserve

Claims: 23

The Xserve was part of the Apple ecosystem, alongside the PowerMac server models, though these were not widely seen in the wild. 1 The Xserve could be configured with multiple drive bays and offered a Cluster Node option that did not include video. 23 It lacked onboard audio and had video capabilities similar to PC servers used for management purposes. 4 The Xserve was loud and difficult to install and manage, and its BMC-based thermal management starts late in the boot process and defaults to a worst-case assumption. 56 MDD and Xserve models can have failing power supplies that are difficult to replace, and the Xserve can run NFS but consumes high power. 78 The Xserve can run Gentoo Linux and OpenBSD PPC, install Mac OS X through TDM using an install image, and the 5,1 models had better CPU support than the last Xserve generations. 91011
