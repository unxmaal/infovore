PiStorm

Claims: 13

PiStorm is a low-cost, community-driven project based on a Raspberry Pi 3/4, running an ARM CPU and an Amiga emulator. 1 PiStorm can be used in an Amiga with CPU expansion slots; it supports a 1200 with a 100MHz 060 CPU. 2 PiStorm with Musashi uses Amiga chipsets for graphics and sound, and only the processor is replaced with a modern one. 3 The PiStorm board emulates an Atari CPU and ET4000 graphics card, passing through the ST-Shifer for HDMI output if desired, with ST-RAM on the physical motherboard and fast-ram on the Pi. 4 The PiStorm can optionally support networking, HDD, RTG graphics, RAM expansion, USB mouse, and similar features to standard Amiga firmware. 5 The PiStorm has ongoing work on extended graphics output. 6 PiStorm is currently beta software with significant compatibility issues expected to be resolved soon. 7
