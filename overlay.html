overlay

Claims: 25 Background: 2 claims already covered by Wikipedia, see Framebuffer, Kernel (operating system).

The term overlay appears in several IRIX 6.5.22 contexts. During installation, conflicts can arise with specific overlay and foundation discs, and starting over with a simpler list of discs can resolve these issues. 1 The first step to format a hard drive is to insert overlay 1, enter prom monitor, and type in `boot -f dksc(X,Y,8)sash64`. 2 Logging into IRIX 6.5.22 with Overlay may result in a console-only login with missing desktop items; using `toolchest &` can help recover some functionality. 3 Propack 3SP6 is RedHat 3AS with an SGI overlay, intended for larger Altix systems, lacking graphics support for Prisms. 4 nsd is part of the Overlay for IRIX 6.5 upgrades. 5 An mpeg decoder can inject video stream into overlay via feature connector. 6 Starting IRIS emulator with overlay=true for scsi.1 creates scsi1.raw.overlay, but changes are lost on subsequent starts. 7 A card includes DACs, framebuffer, and overlay. 8
