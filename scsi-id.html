SCSI ID

Claims: 32 Part of SCSI

The SCSI ID of a drive can be set using jumpers on the PCB, white pins, or by shorting specific pins, and these methods are used to avoid ID conflicts, especially for the boot drive which should be ID 1. 12345 SGI drives often default to SCSI ID 0, which can cause conflicts, and most SGI systems boot from SCSI ID 1 by default. 67 On SGIs, the SCSI controller is #0 rather than #7, and the SCSI ID is often set based on the physical slot the drive occupies, with the first slot getting ID 1 as the regular boot disk. 489 Pre-SCA SGI systems often made setting the SCSI ID easy or automatic, and the SCA bus can set the SCSI ID, though this is not implemented by default and slot swapping changes the drive ID instead of the image filename. 1011 The interposer board defines the SCSI ID, power, and other functions rather than the direct SCA ribbon, and the CD-ROM drive's SCSI ID is typically hardcoded per slot but can sometimes be changed using jumpers on the drive or the SCA adapter. 1213 On the O2, changing the SCSI ID is done through a PROM variable, and the CD-ROM's SCSI ID might need to be changed if ID 3 is incorrect. 1415 For the BlueSCSI, the SCSI ID is set by filename, and it can be jumpered for ID 1 and placed in any bay to work. 1617 The Zulu Control Board can handle multiple images for the same SCSI ID. 18
