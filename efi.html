EFI

Claims: 18

EFI is used by the Prism and the Altix A350 c-brick, which boots to EFI with specific partition details when made bootable via a SCSI-PCI adapter and external disk or netboot. 12 The startup sequence is primarily serial until EFI, and the Altix EFI recognizes an SSD with NTFS but cannot read it. 34 The Altix EFI bootloader in the SGI Altix350 netboot process uses an EFI loader to request DHCP, which points to a TFTP server for the next server, which can be any program, including an OS kernel loader like ELILO. 5 Deskside prism outputs analog at EFI by default, and a VGA adapter is needed for DVI output. 6 EFI should recognize the CD as an IO brick for it to work, and booting Linux might help identify issues. 7
