boot command

Claims: 3 Part of boot Background: 1 claim already covered by Wikipedia, see Bootstrap Protocol.

The boot command can be used to boot from a network using bootp. 1 The command to boot from a specific partition is `boot -f dksc(0,4,7)stand/fx.64`. 2 To restore a UNIX backup, boot to the command monitor from the PROM menu and use the command `boot *unix_backup_name*`. 3
