curl

Claims: 22 Background: 2 claims already covered by Wikipedia, see Wget.

`curl` is a tool used for downloading files and testing web apps, and it is commonly used for HTTP functionality, though some software such as dillo uses its own HTTP library implementation and is not dependent on curl. 123 curl uses CA certificates and most software uses curl, but it can use the --no-check-certificate or -k option to bypass SSL checks. 45 curl from 2014 supports TLS versions 1.2 and 1.1, but not TLS-1.3, and SSL3 is deprecated for security reasons. 6 curl is required for installing pip but was not found, and using curl instead of env can bypass certain behaviors, allowing for dependency bootstrapping. 17 curl requires specific library versions and paths; on IRIX 6.5, it expects libz in /usr/lib32, but installs in /usr/lib cause issues. 8 curl fails with 'unsupported SSL protocol version' when connecting to AWS API-GW, and the -k option does not help. 9 curl can be used to upload files, such as with `curl -F'file=@image.png' https://0x0.st`, which uploads image.png to 0x0.st and returns the URL. 10
