hinv

Claims: 46

hinv stands for hardware inventory and provides hardware inventory information about a system. 123 It can be run from the PROM or from IRIX, with the IRIX version providing more comprehensive information. 4567 The command reports hardware configuration including RAM installed, CPU count, processor type, memory size, and controller versions. 89 It can distinguish between graphics cards such as XL24 and XZ, list dual processor systems, and check for an RE2.1 CPU or jumper setting. 101112 hinv determines clockspeed and CPU configuration through system configuration rather than measuring it directly, and reports R5000 for RM5200 chips. 1314 The -v option lists PCI cards, and the -m option gives exact part numbers, though this option is not available in all versions. 151617 The hinv source code distinguishes between reality and InfReality graphics. 18 The digital video board shows red stripes on input/output and no longer appears in hinv. 19 The FDDI board requires installing FDDIXPress software, rebuilding the kernel, and rebooting; it appears in hinv and can be configured in /etc/config/netif.options. 20 Basic IR support is sufficient for hinv to be happy. 21
