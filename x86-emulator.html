x86 emulator

Claims: 5 Part of x86

An x86 emulator has been used to run 32-bit software on ARM laptops, thanks to Aaron Giles's x86 emulator. 1 NT on Alpha had an x86 emulator. 2 The IP35 shipped with FireGL, R300 or R300-based cards, and may run an x86 emulator if it initializes the card, as AtomBIOS wasn't available at that time. 3 An x86 emulator for the N64 would likely not work well. 4
