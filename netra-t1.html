Netra t1

Claims: 5 Part of Netra

The Netra t1 is a fairly small Sun server that is not horribly loud. 1 It uses a SCSI backplane and does not support IDE hard drives natively, requiring an external SCSI CD-ROM for installation. 2 The Netra t1 contains a U5/U10 IDE controller, similar to those in cheaper Suns, where it was used only for optional CD-ROMs. 3 A Netra t1 with an UltraSPARC-IIi CPU can run OpenBSD 7.4. 4 Library and kernel re-linking on a Netra t1 adds several minutes on boot. 5
