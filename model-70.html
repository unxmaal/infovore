Model 70

Claims: 7 Part of model

The Model 70 loses or corrupts its configuration between power cycles. 1 OS/2 2.1 is not compatible with the McIDE disk controller on the Model 70, as the installer makes BIOS calls that the system cannot handle and there is no existing driver to support it. 2 PC-DOS 7 can be installed on the Model 70 with a McIDE and BlueLightning CPU upgrade using a Zip disk. 3 The Model 95 PSU failed, and the Model 70 now does not POST. 4 The Model 70 works with the joystick port, but the Model 95 has configuration disk conflicts. 5 The Ultimedia sound card would be useful in a Model 70 where SCSI and normal bays are not available, though it might block a neighboring slot. 6 The Model 70 with Warp 3 does not work well with the McIDE adapter, and the WPS GUI is better suited for the lower resolution display. 7
