Makefile

Claims: 42 Background: 4 claims already covered by Wikipedia, see Make (software).

Make is a utility that runs commands from a Makefile, and install is a stock command within a Makefile. 1 Running 'make' on a file named 'Makefile' results in errors because 'make' is a command, not a file. 2 Makefiles should avoid shell commands and aim for compatibility with smake. 3 A Makefile can specify compiler and linker paths for building, as demonstrated by compiling a simple hello world program. 4 A Makefile can build a shared library called libimbuf.so, including a rule that depends on make_convert to generate a header file called convert_arrays.h, which is then used to compile libimbuf.a. 56 The Makefile for the N64 emulator uses GNU make syntax and requires the N64 SDK, which defines OBJECTS among other things. 7 The default makefile builds for 32bit, so a 32bit toolchain and libraries are required, otherwise it fails. 8 The makefile uses cc, which should not be overridden by gcc if cc is a link to gcc in the path. 9
