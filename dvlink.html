DVLink

Claims: 15 Background: 1 claim already covered by Wikipedia, see FireWire.

DVLink is a FireWire interface for importing and exporting digital video to decks and camcorders, and it is available only for the O2. 123 The LSB12V23 works with DVLink on an O2, and a Sony DVCam can be used with an O2 via DVLink. 43 ieee1394tree, which shows connected devices, is included in the DVLink package for the O2. 5 FireWire can be used to connect a SCSI CD drive, but DVLink does not support FireWire storage devices. 6 The dmedia package can work with the DVLink package, but it requires modifying system libraries and has reliability issues. 7 A 270 MHz processor struggles with DVLink due to its 90 MHz system bus speed, while a 300 MHz processor handles it better. 8
