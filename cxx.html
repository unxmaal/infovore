CXX

Claims: 4

Configure scripts and makefiles use environment variables such as CC, CXX, and LD to determine which compiler to use, but not all packages respect these variables, especially for cross-compilation. 1 For autoconf packages, setting environment variables like CC, CXX, CPPFLAGS, CFLAGS, LDFLAGS, CXXFLAGS, PERL, SHELL, SHELL_PATH, LD_LIBRARYN32_PATH, and PKG_CONFIG_PATH can help configure scripts. 2 Setting CXX instead of GCC is necessary for configuring packages with pkgsrc. 3 The environment variables CXX, LD_LIBRARY_PATH, and CC can cause issues with linking curses libraries. 4
