WebForce

Claims: 4

WebForce was a web authoring and serving product created by SGI from its Indy computer. 1 It was a software package included in some SGI Indy models, such as a server version that included a webserver. 2 The software was written in C++ and was originally intended for Solaris before SGI adapted it for IRIX. 3 The Studio Badge was likely part of a bundle with WebForce plus Photoshop, Illustrator, and Premiere, similar to the O2 bundle. 4
