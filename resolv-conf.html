resolv.conf

Claims: 7

The resolv.conf file is a Unix file used for name resolution, alongside nsswitch.conf, and may be relevant when NIS is configured on old machines. 1 On IRIX, the file must be named exactly 'resolv.conf' to be recognized, and /etc/resolv.conf should contain a domain entry for DNS resolution. 23 HP-UX requires a resolv.conf for desktop login, and IRIX 6.5.12m can run without nsd while nslookup still works with /etc/resolv.conf. 45 To support older software, a link can be created by running `rm /usr/etc/resolv.conf` followed by `ln -s /etc/resolv.conf /usr/etc/resolv.conf`, ensuring the resolver configuration is accessible. 6 A name resolution problem can be caused by the machine not knowing its own name, so hosts, nsswitch.conf, and resolv.conf should be checked. 7
