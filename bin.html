.bin

Claims: 7

The .bin and .hqx files need to be unencoded on the Mac side to be usable. 1 The .bin, .u3, and .zm82 files are binary compiled code without an ELF header, so a disassembler would be needed to work with them. 2 Binaries go in bin, statically linked in sbin. 3 The /bin directory on IRIX systems contains executables for various architectures, including pdp11, vax, 68000, and m68k, which may be used in scripts to determine the architecture. 4 The IRIX kernel does not care about the contents of /bin or /sbin; it just runs init and halts when init exits. 5 You can find the screensavers in the xscreensaver directory or the bin directory; running them individually on an O2 may fail. 6
