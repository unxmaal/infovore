mkheaders

Claims: 4

The mkheaders tool is used to fix pthread errors during the configuration and build of software like Emacs and Beecrypt on IRIX systems. 1 To run mkheaders, edit it to replace references to bash with the local path to bash, as the package is cross-compiled and the location of bash is unknown at compile time. 2 mkheaders only changes which include files are processed and does not change file paths or libraries. 3
