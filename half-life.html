Half-Life

Claims: 13

Half-Life's worlds are fully texture mapped, and Quake 2 is equal-ish to Half-Life in graphics and texturing. 12 The Atari Falcon can render Quake 2, 3, and Half-Life maps using its DSP as a graphics accelerator. 3 Half-Life on the Dreamcast has poor controls. 4 The VW 320 can run Half-Life well due to OpenGL support, while Intergraph cards are incompatible with OpenGL for games like Half-Life and dual P6DNFPros require additional power for stability. 56 An 8-CPU O350 can build the Half-Life port relatively quickly, though it encounters an isnan issue that needs to be worked around, and the initial work to get the game to build on IRIX was done in 2022-2023 but the fix for unaligned access handlers may have reintroduced a bug. 78 Half-Life server for IRIX starts and loads the map but has issues with unknown files, and compiling the game on an Octane can take a significant amount of time. 910 The Dual socket motherboard supports running Half-Life, and the game has texture support issues that can be fixed by exporting the background at the correct resolution, though it may have bugs like the Gman appearing on the tram and the tram door not opening. 1112 Server 2003 runs on bare metal of an IA64 system and is usable, with Half-Life running fairly well and IDA Pro being quite usable. 13
