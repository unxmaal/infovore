netboot

Claims: 16

NetBoot works on new world Macs with Ethernet but not on old world Macs, and was removed from later Intel Macs. 12 NetBoot can be used for wake-on-LAN or distcc on old machines, and firmware updates can be netbooted instead of using floppies or discs. 34 A netboot solution for IRIX network installs could be useful regardless of architecture, and one might netboot a graphical installer program with pure X for a minimal IRIX installation. 56 A Fuel can netboot the IRIX kernel and has an SSD with the whole filesystem, which an Octane cannot do. 7 An O350 can netboot from a supported NIC to pull the current PROM and upgrade it. 8 SPARC netboot uses RARP instead of DHCP and loads a kernel by converting the IP address to hex, which the Solaris install server script handles. 9 A SunOS install can netboot using https://github.com/halfmanhalftaco/sunboot, but the instructions assume you already have at least one Sun running. 1011 Most xterms can netboot, you can boot off local storage on some, and server-side netboot is challenging in practice. 12
