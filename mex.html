MEX

Claims: 15 Background: 4 claims already covered by Wikipedia, see NeWS, IRIS GL, Kernel (operating system).

MEX was an in-house SGI window system that preceded NeWS. 1 It was available on early 4D1 versions and could run on the GL2-W until 4D1-3.x, but was not native to IRIX 3. 2 MEX was baked into the GL-2 kernel and MAX/4sight, and SGI used it until 1988 before switching to NeWS in 1991 and then to X. 34 The 4D1 up to 2.2 used Mex, while 3+ used Max. 5 MEX supported full 8-bit color, which was revolutionary for high-end graphics in the mid-80s. 6 The source code for MEX is available online, including in IRIX 3.7, which contains the full source code for IRIS GL, test programs, and MEX. 78
