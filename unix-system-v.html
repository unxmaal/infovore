UNIX System V

Claims: 4 Part of Unix Background: 1 claim already covered by Wikipedia, see IRIX.

IRIX shares much of its guts with UNIX System V. 1 UNIX System V's main codebase was 500,000 lines of code in 1985. 2 A book from 1991 (with revisions from 1993) was made using a DEC VAX 8550 running UNIX System V, Release 2. 3 Prior to GL1, SGI Unix System V or Iris Workstation Software Distribution was used, with v kernel terminals coexisting with early wsd/gl1 OS for a few months. 4
