IO3B

Claims: 11

The IO3B is a bridge that connects VME to PowerPath, and it works in both PowerSeries and Crimson systems. 123 It uses an AMD WD33C93A SCSI chip, which has a quirk possibly fixed in newer versions, and it works with Zulu SCSI. 45 An IO3B can connect both drive bays to separate SCSI channels, unlike an IO2 that requires a jumper to link all bays to one chain. 6 The IP17 CPU board requires the last revision of the IO board, which is the IO3B, though the IO3B will also work with older CPU boards. 7 Applying Deoxit Gold to the backplane connector can reduce insertion force and fix crushed pins, but requires careful handling to avoid overspray. 8

Sources

  1. The Onyx supports the IO3B, which is very capable for a deskside system. (user-8b3c, 2021-06-21, exchange 99372, check: supported)
  2. The IO2/IO3/IO3B bridge VME to PowerPath, and the GM board bridges PowerPath to graphics. Both have massive connectors. (user-86e1, 2023-10-25, exchange 188710, check: uncheckable)
  3. Crimson uses sash.IP17, fx.IP17 firmware and has half the PROM on the CPU board and half on the IO board; the IO3B works in both PowerSeries and Crimson. (user-86e1, 2024-04-15, exchange 45606, check: supported)
  4. The IO3 and IO3B controllers use different WD33C93A chips, with IO3B using AMD chips which have a quirk, possibly fixed in newer versions. (user-86e1, 2024-12-03, exchange 189341, check: uncheckable)
  5. The Zulu SCSI works on the IO3b. (user-c9fb, 2024-12-03, exchange 241253, check: uncheckable)
  6. An IO3 or IO3B can connect both drive bays to separate SCSI channels, while an IO2 with a single channel requires a jumper to connect all bays to one chain. (user-86e1, 2024-11-28, exchange 189334, check: uncheckable)
  7. The IP17 CPU board requires the last revision of the IO board (IO3B), but the IO3B will work with older CPU boards, and both graphics boards and chassis are the same. (user-86e1, 2025-05-06, exchange 225028, check: uncheckable)
  8. Applying Deoxit Gold to the backplane connector of an IO3B can reduce insertion force and fix crushed pins, but requires careful handling to avoid overspray. (user-86e1, 2023-10-27, exchange 241116, check: uncheckable)
