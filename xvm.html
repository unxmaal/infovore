XVM

Claims: 10

XLV was the old volume management system on IRIX, replaced by XVM, which is the GUI successor to xlv. 12 Both xlv and xvm are similar RAID tools; xvm adds a GUI and can set up RAID volumes on remote hosts. 34 RAID in IRIX required licensed software such as XLV or XVM, though XVM ships with IRIX and does not require a license for IRIX 6.5.30. 56 XVM RAID volumes are created using a GUI with manual stripe configuration. 7 RAID 5 and higher do not have parity calculation overhead when using XVM. 8 One user set up a slice RAID using XVM but did not see the expected performance increase. 9
