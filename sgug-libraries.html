sgug libraries

Claims: 4 Part of SGUG

SGUG libraries can be added to the library search path in csh/tcsh to avoid conflicts, and they might overlap with system libraries, as evidenced by a conflict with libXm. 12 SGUG-rse does not overwrite libraries, and SGUG libraries are placed at the end of the library search path outside of sgugshell, which is preferred for SGUG tasks. 3 It is recommended to avoid SGUG libraries and use IRIX native ones instead, starting by removing SDL2 from Homeworld SDL. 4
