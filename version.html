version

Claims: 22 Background: 1 claim already covered by Wikipedia, see OpenGL.

The command /usr/java2/bin32/java -version works to check the Java version. 1 IRIX Java reached version 1.4 but not 1.5. 2 The firmware update can fail if the version does not match the device hardware, requiring a force install. 3 IRIX's VFS is version 1.2 or 3. 4 IRIX uses FLEXlm in FLEXlm v4 compatibility mode even if later versions shipped with FLEXlm v6, v8 or v9.2 libraries. 5
