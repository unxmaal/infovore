IRIX CDs

Claims: 9 Part of IRIX Background: 1 claim already covered by Wikipedia, see Extent File System.

IRIX CDs are formatted with the EFS file system rather than ISO9660. 123 Rips of IRIX CDs often use the .efs extension, though some use .iso. 4 On Linux, IRIX CDs can be ripped using the command `safecopy -b 512 /dev/sr0 812-0688-006_IRIX_6.3_required_patches_september_1997.efs`. 5 On Windows, CDBurnerXP can write IRIX CDs reliably with settings used for 6.5.30, and ImgBurn or similar software is recommended due to potential issues with default Windows CD software. 67 IRIX CDs can be read on modern machines using the EFS file system with the loop device. 8
