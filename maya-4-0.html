Maya 4.0

Claims: 12 Part of Maya

Maya 4.0 can use Renderman through Mayaman on IRIX, which requires setup of ENV variables and starting lmgrd in the entropy/etc directory before sourcing mayaman.env and launching Maya from the same terminal. 12 The Mayaman version of Entropy works on an IRIX Octane with dual 400 MHz CPUs, and Maya 4.0 with Mayaman and Entropy or BMRT can run early Renderman on an Octane. 34 The official Renderman Artist Tools did not run in Maya 4.0 on IRIX, though RAT 5.0 in Maya 4.0 works but requires manual steps to start the license server. 35 RAT 5.0 for Maya 4.0 can be run on Windows XP but not licensed on IRIX, and Pixard-Crypt can modify license.dat files to indicate expiration status, though its exact use and compatibility with RAT 5.5 for Maya 4.0 on IRIX is unclear. 67 Maya 4.0 is the latest version needed for most features, with Maya 5.0 for IK rigging and 6.5 for Bonus Tools and Marking Menu workflows. 8 Maya 4.0 had fur and nCloth, but fluid effects were added in 4.5, and Maya 4.0 and later have the feature of holding W, E, or R for gimble switching. 910
