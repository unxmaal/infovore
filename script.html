script

Claims: 20

Scripts can be installed manually and enable services, such as openSSD on bootup, which requires manual installation of the script and key generation and uploads keys to putin.com by default. 1 Scripts can resolve technical issues, such as renaming ld and creating a script to transform -Wl,-R to +b, or renaming files based on a sed expression with options for dry run and interactive confirmation. 23 Scripts can clone drives, including running './clone 2' as root for a SCSI ID 2 disk, cloning XFS drives by labeling and partitioning the new disk, and existing scripts may be lost with better ones encouraged. 456 The first line of a script should point to a modern shell like ksh, bash, or zsh. 7 Scripts can automatically extract tar.gz files into folders and keep the originals, though they delete the tar.gz files by default. 8 The script function is present in the latest shipping version of ep, but the default script is embedded as an ASCII string in the binary, having previously been included separately. 910 The original ElectroPaint software used a script from the original interface with sliders and other controls, older versions had more complex or different scripts, and ElectroPaint can still call external scripts. 111213 Scripts can manage the glass console without needing to replace batteries frequently, recover files from a damaged DLT tape by reading 512-byte sectors and filling gaps with zeros (a slow method), and remove sgidev_bridge, replacing it with the nick of the person typing via NFS and WeeChat. 141516
