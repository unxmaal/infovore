fx.64

Claims: 4 Part of fx

The fx.64 utility formats disks for IRIX versions, with 6.5.30 being the latest safe version for compatibility and 6.5.22 also an option. 1 The Indigo2 Impact can use fx.64. 2 To install fx.64 from the network, run bootp() from the command monitor with the target's IP, and the system will retrieve it from the specified location. 3 Booterizer does not support using fx.ARCS on an Octane, so fx.64 should be used instead. 4
