rsync

Claims: 15

rsync is a file transfer tool that is considered better than rcp or ftp for data exchange, especially when SSH is too slow on old hardware. 12 It can be interrupted and resumed, which is useful for copying entire drives. 3 rsync is used for backups, often together with cron. 4 On IRIX, rsync is part of the RCS package in the default IRIX 6.5.30, though it was not available on the PowerServer 530. 56 It is used on IRIX to copy files, move /usr to an external disk, and move files to servers via scripts. 789 It can also deploy a Gentoo-based system across multiple machines and copy directory trees to NFS shares. 1011
