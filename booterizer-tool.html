booterizer tool

Claims: 3 Part of Booterizer Background: 1 claim already covered by Wikipedia, see Bootstrap Protocol.

The booterizer tool can boot the O2+ and install IRIX without a CD, formatting the drive and loading selections. 12 It can set the hostname during the boot process via BootP. 3 Booting requires editing the /etc/hosts, /etc/dhcp/dhcpd.conf, and /irix/.rhosts files, and a serial cable. 1

Sources

  1. The O2+ can be booted using a custom booterizer tool, which formats the drive and loads selections; it requires editing `/etc/hosts`, `/etc/dhcp/dhcpd.conf`, and `/irix/.rhosts` files, and a serial cable for booting. (user-bc5d, 2019-10-11, exchange 76892, check: supported)
  2. The Booterizer tool can be used to install IRIX without a CD. (user-848e, 2020-01-15, exchange 5463, check: uncheckable)
  3. The booterizer tool can set the hostname during the boot process via BootP. (user-f229, 2021-12-12, exchange 206057, check: uncheckable)
