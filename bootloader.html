bootloader

Claims: 14 Background: 1 claim already covered by Wikipedia, see BIOS.

A bootloader loads into RAM and then loads the kernel, which can be done using NFS. 12 Bootloaders can be customized or rebuilt, for example in response to BIOS updates or for hardware system updates. 34 Bootloaders can be used to boot from various media, including floppies, CDs, and hard drives, and can handle different partition schemes such as HPFS. 56 Bootloaders can bypass ROM-imposed kernel size limits and allow non-100% correct CPU emulation. 78 Bootloaders can encounter problems, such as failing to recognize the hard drive after an OS install, misconfiguring during filesystem installation, or failing to boot due to insufficient swap space. 91011
