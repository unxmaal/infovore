GF2

Claims: 5

The GF2 is a second-generation graphics hardware system used in SGI 68020-based machines, released in 1985-86, and it ran the newest OS from December 1987. 1 The GF2 is similar in principle of operation to the SGI Clover1 (G), which features a custom flat shading processor and two sets of matrix GEs running in parallel. 2 Schematics for some IRIS boards are available, but not for the GF2. 3 The IRISes run Unisys Unix on m68k processors with specialized graphics hardware. 4 The Athlon system with the GF2 is significantly faster than the K6-2 system in actual games, even though the K6-2 system is still fast for a Super Socket 7 system. 5
