ppc64el

Claims: 4 Part of PPC Background: 2 claims already covered by Wikipedia, see OpenGL, PowerPC.

The PowerPC CPU architecture uses the short form PPC, with variants including PPC, PPCel, PPC64, and PPC64EL. 1 Debian does not support ppc64, only ppc64el for Power8+, which is rarely used. 2 NVIDIA drivers for PPC64el have issues like memory clock bugs and blackscreens. 3 CUDA for ppc64el exists but there is no known userland implementation of OpenGL or Vulkan from NVIDIA for ppc64el Linux. 4
