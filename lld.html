lld

Claims: 6

lld is not fully compatible with GNU ld but can be adapted using regex. 1 FreeBSD uses lld for x64/POWER/ARM64 instead of binutils. 2 Modern linkers like gold or lld only look in specified libraries and differ in handling undefined symbols of dependent libraries. 3 The mips and lld owners need to be consulted for acceptable ways to implement certain features. 4 rld requires code conforming to the IRIX ABI, and lld can be configured to emit such code. 5 The linker lld uses less memory than GNU ld for linking. 6
