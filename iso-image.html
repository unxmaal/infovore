ISO image

Claims: 9 Part of ISO

  • Burning to a CD is straightforward, but using ISO images directly is less convenient. (user-d903, exchange 78770, 2020-10-02; 1 speaker(s), 1 conversation(s))
  • Physical access to the machine was unavailable for a period, causing issues with mounting ISO images as a virtual CD ROM to install RPG packages. (user-b1da, exchange 176389, 2022-10-03; 1 speaker(s), 1 conversation(s))
  • SLES 9 SP4 for ia64 is available as ISO images created on May 18, 2012, and can be accessed via the provided links. (user-03ad, exchange 216526, 2025-01-17; 1 speaker(s), 1 conversation(s))
  • Alternatively, raw tar on CD images can also work. (user-7b1c, exchange 220150, 2020-04-23; 1 speaker(s), 1 conversation(s))
  • IRIX lacks loopback support for ISOs, requiring physical burning for use. (user-6afa, exchange 78770, 2020-10-02; 1 speaker(s), 1 conversation(s))
  • To get software into an emulated Indy, create an ISO image and enable Rock Ridge extensions. (user-7b1c, exchange 220150, 2020-04-23; 1 speaker(s), 1 conversation(s))
  • The `mount` command supports loopback mounting of ISO images in IRIX 6.5, using `mount -o loop <filename>.iso /<path>`. However, Pop!_OS does not support mounting ZFS, and XFS support in Pop!_OS may be incomplete. (user-59b9, exchange 10996, 2020-09-13; 1 speaker(s), 1 conversation(s))
  • Putting a CD in a drive is faster than using nested VMs for ISO images. (user-f229, exchange 3721, 2019-10-01; 1 speaker(s), 1 conversation(s))
  • To install software on IRIX, mount ISO images as virtual CD-ROMs and use rsync to copy files, then share the destination directory over NFS for installation. (user-c831, exchange 79346, 2021-05-19; 1 speaker(s), 1 conversation(s))
