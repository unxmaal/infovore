Alpha firmware

Claims: 4

SRM is the Alpha firmware used for Unix/VMS, while ARC is the version used for Windows, and some Alphas could only run Windows. 1 The Alpha firmware can recognize Windows 10, but this may cause issues during booting. 2 Alpha firmware is practically a hobby operating system that is multiuser and multitasking, with a bourne-style shell complete with pipes and I/O redirection. 3 Alpha firmware has `grep`, and its `ps` command lists all the running processes. 4
