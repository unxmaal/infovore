Red Hat 6.2

Claims: 6 Part of Red Hat

Red Hat 6.2 ISOs are available for SPARC and Alpha. 1 Red Hat 6.2 was used to run L1/L2 software on weird rack-mounted SGIs via USB ports. 2 To connect an SGI machine via USB, it emulates an L2 controller; it requires Red Hat 6.2, not RHEL 6.2, and might work on Altix if the L1 controllers are similar. 3 Running Red Hat 6.2 on an SGI 230 would be interesting, though an L2 system controller is expensive and can be emulated through L3 software. 4 The L3 USB Drivers haven't been updated to work on modern Linux; older versions like RedHat 6.2 are required. 5 The L3 software is a pain in the ass, I only ever got it to work correctly on an old Pentium III box with Red Hat 6.2 on it. 6
