ffmpeg

Claims: 27 Background: 9 claims already covered by Wikipedia, see FFmpeg.

ffmpeg is a tool that can convert .mp4 files to SGI RGB format for use in SGI discreet programs, including for use in Flame on an SGI. 1234 It can also convert iPhone video to a format readable by SGI systems, and IRIX can create QuickTime movies that can be used as input for ffmpeg. 56 ffmpeg can play video files and runs on IRIX, and can record screen output if ported to IRIX using command-line options for size, frame rate, and X11 input. 78 Alias renders images in a format compatible with Discreet, which can be exported as TIF files for use with ffmpeg to create an MP4 video. 9 YTP+ is a graphical shell that uses JavaFX, FFmpeg, and ImageMagick. 10 ffmpeg version 4.1.4 is built with gcc 8.2.0 and specific configuration options, and build scripts for ffmpeg were bash-specific and caused issues. 1112 ffmpeg may require setting LD_LIBRARYN32_PATH and can be unpacked at root to create /opt/local/ffmpeg. 13 MJPEG videos lack audio and ffmpeg struggles to handle them, and FFMPEG has issues with hardware-accelerated MPEG decoding on older systems. 1415
