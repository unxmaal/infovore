AlphaBIOS

Claims: 14

AlphaBIOS is a firmware environment used on some DEC Alpha machines, including the DS10, which supports it for running configuration tools and Windows on the 466MHz version but not on the 617MHz version. 12 Some Alphas were delivered with Adaptecs, requiring AlphaBIOS and NT. 1 The PALcode and firmware are specific to the machine; EV4 machines like the Alphastation 200 use ARC, while EV5 machines use AlphaBIOS, and EV5 machines do not support ARC firmware. 3 Formatting drives requires initial setup in AlphaBIOS, with system partition creation necessary, and Windows setup handles the rest; this procedure has been consistent since the Alpha's inception. 4 AlphaBIOS works best with ANSI terminal mode, and SRM supports any VT greater than 100, so AlphaBIOS is not ideal for serial consoles. 5 AlphaBIOS requires a functioning RTC battery to run the ECU, an ARCS/AlphaBIOS program, while SRM is less sensitive to a dead RTC battery. 678 An original Dallas DS1287 produces beeps and fails to initialize the AlphaBIOS, and the AlphaBIOS hangs on display of 'Arc Firmware Loaded' with a new Dallas battery. 910 If RAM is bad, the system may not chime and will sit with an amber light, and some machines default to AlphaBIOS when their battery runs out. 1112
