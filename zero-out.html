zero out

Claims: 3

To zero out a disk, run /exercise in fx with write only enabled, select the entire disk range, and zero out the entire disk, which can take a while but ensures the disk is cleared. 1 Creating a new label before exiting fx is recommended. 1 For 300GB disks, using /exercise in fx to zero out the disk is not recommended. 2 Zeroing the first few MB of a disk can make it appear fresh. 3

Sources
