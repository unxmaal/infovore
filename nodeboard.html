nodeboard

Claims: 31 Background: 2 claims already covered by Wikipedia, see SGI Onyx2, SGI Origin 2000.

A nodeboard is a four-processor ip53 flavor of the Origin2000/Onyx2 systems, containing two CPUs and memory. 12 The node board plugs directly into the interface 'I/O' board via two megarray connectors, and there is no interposer. 34 The server has a node board, an interface board, and a PCI board. 5 A single nodeboard can be tested to determine whether the issue lies with the backplane/router or the nodeboard itself. 6 Reseating routers or the nodeboard does nothing, and a spare 400MHz nodeboard can be used to replace faulty hardware. 78 The node board is not useful by itself, and a node board with plastic damage but no hardware issues can be a decent price for a turnkey IRIX system with a good amount of RAM. 910
