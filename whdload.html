WHDload

Claims: 13

wHDLoad can virtualize older operating systems to run games that are incompatible with the current system's hardware. 1 WHDLoad requires all games to be loaded into RAM, which can be a problem for games with many floppies, and it often needs more than 2mb of RAM, depending on the game. 23 WHDLoad won't work if any TCP/IP stack is active, and can be fixed by commenting out the stack entries in C:WHDLoad-Startup to stop the internet upon booting and using a script to re-enable it. 4 Disk images can be transferred to an A500 and written to floppy using WHDload or Gotek, and original floppies or converted ipf images can be used with WHDload for installation. 56 WHDLoad can be used with preinstalled packs or installing from a folder of adf images to make the Gotek less necessary if file transfer is fast. 7 WHDLoad works fine when the files are on an FFS drive. 8 The A1200 can run AGA-only games and AGA-enhanced versions; SC2k is an example, and an A1200 with 4MB RAM and an internal IDE-CF drive can play almost every Amiga game with WHDLoad. 9 The A1200 requires correct A500 kickstart for whdload to work. 10
