xlv

Claims: 16

xlv is a command-line software RAID utility on IRIX, and xvm is its GUI successor that adds a graphical interface and can set up RAID volumes on remote hosts; both tools can coexist on the same system. 123 XLV is the older volume management system on IRIX, replaced by XVM, and RAID in IRIX required licensed software such as XLV or XVM. 45 The XLV supports SCSI drives in a stripe configuration, and XLV on Sun systems was similar to Veritas software in functionality. 67 XVM can be used to import XLV volumes. 8 xlv setups for /usr can use separate disks or logical volumes, but xlv requires licenses, and you can mount /usr on an xlv while using a different disk for the swap partition. 910 To grow the root file system onto another disk, you can use xlv to create a logical volume, unmount the root, make the new disk a volume, remount, and grow the filesystem, a process that requires a miniroot or another IRIX. 11 To extend a volume with XFS, you need to use xlv or clone the disk and rebuild the volume header, and xfsdump and xfsrestore preserve attributes and are recommended for copying data between disks. 12 xlv should be on one of the base 6.5 CDs, and on newer IRIX, xvm should also be installed after installing from original CDs and overlays. 133
