shell

Claims: 29 Background: 2 claims already covered by Wikipedia, see Bash (Unix shell).

A shell is a command line interface, and different shells provide different features and can extend functionality through scripts. 1 Environment variables like PATH are part of the shell. 2 Shell scripts in profile.d are loaded by any shell. 3 The built-in shell does not support repeating commands or arrow keys; bash does. 4 When using 'sudo', the shell used might differ from the user's shell, leading to different environment variable sourcing. 5 When building with autoconf, setting SHELL and CONFIG_SHELL to a custom path can override hardcoded paths in the build process. 6 CONFIG_SHELL and SHELL environment variables can be set to resolve the issue. 7 Placing the env stuff in a separate file and sourcing it after spawning the shell works. 8
