OS version

Claims: 8 Part of OS

The booterizer defect can cause the mipspro install to mis-identify the OS version, which may cause the MIPSpro installation process on IRIX systems to install incorrect packages due to the OS version not being known during installation, requiring manual intervention after the first reboot. 12 The OS version affects performance; it is less noticeable in 7.x but becomes more significant in 8.x due to increased PPC native code. 3 IRIX version can be checked by looking for specific files or directories related to the OS version. 4
