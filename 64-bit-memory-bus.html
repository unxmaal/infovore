64-bit memory bus

Claims: 3 Part of 64-bit

The 64-bit memory bus is used by the NVIDIA TNT2 graphics card. 1 The SGI Indy uses a 64-bit memory bus for 8-bit graphics and a 192-bit memory bus for 24-bit graphics, with no performance hit for additional colors. 2 The SGI O2 can use 64-bit memory bus components, with early models featuring CRIME chips that can run memory at 100 MHz, though the O2 cannot detect the speed of the RAM modules. 3
