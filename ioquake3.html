ioquake3

Claims: 20 Background: 2 claims already covered by Wikipedia, see Id Tech 3, Quake III Arena.

ioquake3 is the open-source port of Quake 3. 1 Building ioquake3 requires a high CMake version, likely above 3.14, which is not supported by IRIX. 2 ioquake3 has a MIPS target, possibly for SPARC but unsure for MIPS. 3 Porting ioquake3 to run natively on MIPS would require a code generator update or replacement, and porting ioquake3 to MIPS would be a significant project. 45 The QVM interpreter in ioquake3 is a performance bottleneck on SGI systems. 6 Using ioquake3 on SGI systems may not fully utilize the CPU and graphics capabilities. 7 ioquake3 is too modern for IRIX use, suggesting nekoware patches might be necessary for compatibility. 8 ioquake3 is a good base for IRIX port but needs GL fixes. 9
