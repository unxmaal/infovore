NFSv3

Claims: 13 Background: 1 claim already covered by Wikipedia, see IRIX.

NFSv3 is an older version of NFS that is less friendly than NFSv4 for modern OSes. 1 NFSv3 requires rpcbind, and the server listens on TCP only. 2 NFSv3 only works on UDP, which is turned off by default in many Linux distributions including RHEL. 3 Netbooting Solaris from Linux requires setting RPCNFSDOPTS to include NFSv2, NFSv3, and NFSv4 in /etc/default/nfs-kernel-server. 4 Solaris 10 supports NFSv3 and NFSv4. 5 To install NFS on an IRIX 6.5.28 machine, the ONC NFS disc is required, which contains NFSv3 for IRIX 6.3, 6.4, and 6.5. 6 IRIX 6.2 with the 12/1999 patch set is functionally equivalent to IRIX 6.5.6 for NFSv3. 7 IRIX 5.3 supports NFSv3. 8
