little-endian mode

Claims: 7

The PowerPC 32-bit CPU can run in little endian mode, and several operating systems use it. 1 MIPS NT requires specific firmware and runs in little endian mode, which SGI systems cannot do. 2 SGI VWS use ARCS firmware but run PIIIs in little endian mode, making them a hybrid. 3 POWER8 supports true little-endian mode, allowing software previously incompatible due to endianness to run. 4 The R4K Indigo PROM can be set to little-endian mode, and the Indigo HAL and video driver have appeared in NT 3 pre-releases. 5 Switching an O2 to little-endian mode requires replacing the config bitstream ROM on the CPU module, making it incompatible with booting both IRIX and NT without swapping parts. 6 The Indigo2 supports little-endian mode, but it's unclear if it was ever shipped in actual hardware. 7
