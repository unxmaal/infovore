Linux server

Claims: 5 Part of Linux Background: 1 claim already covered by Wikipedia, see Network File System.

A Linux server can provide NFS and NIS to systems such as SGIs, FreeBSD, IRIX, Solaris, and HP-UX. 1 A plain old Linux server can be used as a NAS, and NFS is a viable option for read-only shares, especially for retro machines. 2 Network file transfer can use NFS with a Linux server. 3
