With MIPSpro

They do not mix well together, and mixing their object code can cause link-time failures due to differences in name mangling, exceptions, optimisations, DWARF info interpretation, and long double size. 1234 GCC is generally preferred for porting modern software because it is easier to port, its bugs get fixed, and it has widespread compatibility. 567 MIPSpro can significantly improve performance over GCC for certain applications, and it supports C++98 with some extras, while the latest GCC follows the current standard. 89 MIPSpro is SGI's own compiler, and it is used for building certain packages such as the kernel, while GCC is used for others. 1011 Fceux is an NES emulator that can run on IRIX using either MIPSpro or GCC. 12 Building with MIPSpro can fail due to memory corruption issues during PNG loading, while building with GCC works but requires modifying the GNUmakefile to link with -laudio and -lpthread. 13

With IRIX

GCC support for IRIX has been available in various versions, with gcc 4.7.4 officially supporting IRIX and being a good choice for compiling X applications, while the last version supporting IRIX falls between gcc 3.x and very early 4.x. 141516 Porting GCC to IRIX involves porting the C library, and the build process requires specific flags and sysroot setup to compile C++ programs, including handling of __restrict and linking against crt1.o and libstdc++, with IRIX's GCC using libstdc++ from the compiler rather than the system version. 171819 A copy step copies part of the IRIX system root to the cross build host to allow GCC to access system headers and create fixed versions during the build process. 14 GCC's va_list type traditionally uses void* on all platforms but IRIX, where it uses char* to play nice, causing type incompatibilities during merging. 20 GCC on IRIX requires math.h to build emacs, which must include NAN and INFINITY. 21 In IRIX ports, you can set the GCC version in the port script to 4.7.4 or 8.2.0; the default is 4.7.4 if not specified. 22 A GCC-only IRIX compatibility library can include standard functions like getopt_long, asprintf, and fnmatch with FNM_CASEFOLD support. 23 IRIX executables built with GCC may or may not link against libgcc depending on the code. 24
