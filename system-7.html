System 7

Claims: 20 Background: 4 claims already covered by Wikipedia, see A/UX, IMac G3, System 7, Unix.

System 7 is a classic Mac OS that preceded the need for replacement by later Macintosh operating systems, and it was required to run A/UX, a Unix-like operating system in which System 7 runs as a process. 123 A/UX can be booted by starting a specific System 7 partition, switching to Unix, and then booting System 7 again. 4 Boot techniques for System 7 included using LILO to load the kernel and manipulate CPU registers to boot Linux, and running system7 emulation in UNIX while AUX handled hardware booting. 56 Apple believed an alliance with IBM would merge A/UX, AIX, and System 7, scaling Macintosh application execution from Mac desktops to IBM's RS/6000 systems. 7 System 7 can open multiple applications, though performance degrades, and it works well with enough RAM and minimal extensions. 89 System 7 runs on a range of machines, including the Mac SE (slowly, without an MMU), the Mac Color Classic with a Performa 550 motherboard, the iMac G3 (via CHRP remnants), and someone ran it on an NSpire CX CAS. 10111213 Some machines have limitations, such as the LC's video issues and system freezes if left on too long, though it can boot System 7 from floppies. 14 Dual monitor support in System 7 works well with the IIfx or Q950, and MacOS through System 7 was the only OS to look good in monochrome. 1516
