7-Zip

Claims: 12

7-Zip is a fun benchmark because you can run it on anything and its results are consistent across systems. 1 7-Zip on Windows supports formats including 7z, zip, rar, tar, and lha. 2 7-Zip's LZMA compression is solid, but Ultra compression does not leverage all CPU cores. 3 The 7-Zip command can benchmark decompression speeds on an S822l system with 160 CPU threads and 130520 MB of RAM. 4 The 7-Zip benchmark on a T1000 with 32 CPUs shows better performance using all threads for both compressing and decompressing. 5 7-Zip 24.08 for arm64 supports multi-threaded and single-threaded compression/decompression with specified dictionary sizes and reports performance metrics including speed, usage, and MIPS ratings. 6 The SS20 with two 150 MHz HyperSPARC processors running NetBSD 9.3 can compress and decompress data using 7-Zip, achieving speeds and MIPS ratings as shown. 7 Different versions of 7-Zip can yield varying performance results on the same machine. 8
