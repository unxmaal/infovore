browservice

Claims: 6

browservice is a tool for talking to servers with modern TLS that uses JavaScript on the client to capture keystrokes, supports http/s, streams YouTube, and is faster than some alternatives. 1 It handles HTML rendering and pipes pre-digested data to the host system, working well with an HTML->PNG pipeline but potentially doable in Flash. 2 browservice raises the minimum browser requirements but is a good addition to the toolbox and is perfect for older machines, though it can be slow compared to Netsurf. 34 Turning down image quality helps with browservice on older machines, especially for video, and it chugs on pre-1997 sites unless JPEG quality is drastically reduced. 52 Connecting between IRIX and a VNC server can be a way to test browservice functionality. 6
