DIMM slot

Claims: 5 Part of DIMM

  • A dual socket system can support 12 DIMM slots per CPU, allowing for high RAM capacities or faster speeds by using fewer DIMMs. (user-b1da, exchange 95882, 2019-12-02; 1 speaker(s), 1 conversation(s))
  • One of the first two DIMM slots is bad, and using only slots 3 and 4 resolves memory errors. (user-9860, exchange 101132, 2021-12-08; 1 speaker(s), 1 conversation(s))
  • Cleaning DIMM slots and reseating can improve RAM compatibility, and issues like RAM arrangement can cause system instability. (user-9219, exchange 225608, 2025-10-25; 1 speaker(s), 1 conversation(s))
  • One of my 400Mhz nodes has an issue with a DIMM slot; cleaning might be needed or a new board. (user-2a3c, exchange 199892, 2026-02-07; 1 speaker(s), 1 conversation(s))
  • The Ultra 5 has 2 bad DIMM slots that don't show up in the system, limiting usable RAM to 256MB. (user-95db, exchange 239401, 2021-09-15; 1 speaker(s), 1 conversation(s))
