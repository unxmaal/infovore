paging

Claims: 3

Paging is complex but nicer than segmentation. 1 Almost all kernel data can be paged out on IRIX, which is more extensive than on Linux, using complex code and data structures to manage this. 2 Modern systems with more RAM page out less frequently. 2 An alternative approach reserves all VM RAM so that once memory pages are used, there is no waiting for allocation or paging. 3
