PS2 SDK

Claims: 5 Part of PS2

The PS2 SDK has been leaked multiple times and can be found on disk images, and the ps2sdk should run on any Linux. 12 The original PS2 SDK from Sony is available as a Windows installer for use with ProDG or CodeWarrior, but it also includes Linux toolchain binaries that can be transferred to a Linux host by copying c:\usr\local\sce. 3 The TOOL unit can be used standalone from a host x86 machine running the PS2 SDK, needing a working IDE drive with Red Hat Linux and debugging/management suite installed. 4 The Linux kit documentation is a subset of the PS2 SDK and the homebrew SDK is comparable to the official one. 5
