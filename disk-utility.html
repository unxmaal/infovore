disk utility

Claims: 5 Part of disk

Disk Utility repairs permissions on Mac OS X because old binary packaging did not always respect proper file permissions. 1 Restoring an image using Disk Utility works with Leopard but not Tiger, and enabling compression and read-only in the dmg file fixes the issue in Tiger Disk Utility. 2 The BlueSCSI and RASCSI firmware fixes disk utility and apple-branded disks issues, improving compatibility. 3 Partitioning and formatting the SSD was difficult, requiring the use of the disk utility on the OSX install disk. 4 The disk utility in OS X was able to repair a disk error that OS9 could not resolve. 5
