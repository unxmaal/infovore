make

Claims: 16 Background: 1 claim already covered by Wikipedia, see Make (software).

Make is a tool that reads makefiles and runs commands based on the makefile's instructions, which can be used for automating various tasks such as generating HTML from Markdown. 1 Make is a utility that runs commands from a Makefile, and install is a stock command within a Makefile. 2 Make is a build system from the 1970s, which lacks modern features. 3 Make provides a simpler mechanism for building based on dependencies and commands, and is more liberating as it can adapt to native quirks on new platforms without requiring complex dependencies. 45 The /usr/bin/make is likely a symlink to /sbin/make, and gmake is a symlink to make. 67 Running 'make' on a file named 'Makefile' results in errors because 'make' is a command, not a file. 8 The configure script in the NTP project re-runs configure when make is run, which can overwrite manual edits to makefiles. 9 make can get stuck 'entering directory' on an SGI, even if tests are not written or commented out. 10
