Windows 9x

Claims: 7 Part of Windows

The Willem is a ROM burner compatible with Windows 9x and up, including XP, and can be used with a parallel port or a breakout board. 1 It is the latest affordable solution for Amiga kickstarts. 1 Rarely, you might encounter issues with Windows 9x on AMD CPUs, but this is due to a bug on first-gen Ryzen systems. 2 The SunPCi board can run Windows 9x and possibly NT, but it can also run on a PC. 3 The IDE for the CPLD requires an MS DOS prompt and works with Windows 9x/NT4/NT5, possibly NT3.51, and uses CUPL for programming. 4 PCs had a password prompt on Windows 9x that could be bypassed by pressing cancel, leading to an admin desktop. 5 NT4 was great; it was shitty for games but more stable than 9x. 6 It supports DOS, Windows 3.x, 9x, NT, OS/2, MacOS and some Unix. 7
