SoftWindows

Claims: 41 Background: 3 claims already covered by Wikipedia, see SoftPC, IBM AIX.

SoftWindows is a virtual PC solution for SPARC systems, alongside SunPC/SunPCi, RealPC, and bochs, that allows Windows and DOS software to run on SGI hardware. 12 It largely emulates the CPU but natively implements most Windows/BIOS calls, allowing Windows software to run without full emulation. 3 SoftWindows can run Windows on IRIX systems, performing comparably to the host system, and can run DOS applications like 3DStudio, TrueSpace, and Photoshop on IRIX. 42 TrueSpace versions 1 through 6 run in SoftWindows, and 3D Studio DOS version runs well on older SoftWindows versions. 56 However, 3D Studio MAX and Softimage require NT and do not work in SoftWindows. 7 SoftWindows can run PowerPoint, Turbo Pascal, and Soldworks versions 96, 99, and 2000 on SGI systems. 8910 It can run Tomb Raider but it is unplayable, and DOSBox is much slower than SoftWindows for running games. 1112 SoftWindows speed benefited from precompiled Windows binaries for the target RISC architecture, making it feel fast on RISC systems but slower on newer PowerPC systems. 13
