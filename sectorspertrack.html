SectorsPerTrack

Claims: 3

SectorsPerTrack is a setting for an HDD in zuluscsi that can be adjusted together with HeadsPerCylinder for compatibility, as the Zuluscsi.ini file includes settings for SCSI devices and problems can often be fixed this way. 12 A default value is SectorsPerTrack = 54 with HeadsPerCylinder = 15, while setting SectorsPerTrack to 248 and HeadsPerCylinder to 19 allows formatting within Solaris. 13

Sources
