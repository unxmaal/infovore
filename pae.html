PAE

Claims: 6

Physical Address Extension (PAE) was used in the late 32-bit era for x86 processors and was available before Itanium was sidelined. 12 PAE allows a system to use more than 4GB of RAM in 4GB blocks, but a single process can't use more than 4GB. 3 PAE on a 32-bit chip can't usefully address 1TB of RAM; it can only provide 4GB chunks per process, requiring real 64-bit addressing for larger memory use. 4 It fixes PAE to allow 128 GB RAM on 32-bit systems and has a 64-bit version. 5 If the machine will/can never have more RAM, and you can select non-PAE I'd do that. 6
