root filesystem

Claims: 7 Part of root

The df -h output shows a root filesystem of 279G with 9.6G used, alongside an NFS mount of 5.4T with 2.0T used. 1 Reseating the hard drive fixed a boot issue but led to a fatal error on the root filesystem. 2 Copying a root filesystem between machines can be done by restoring its backup, which is easier than reinstalling everything. 3 Diskless booting involves copying a miniroot to a swap partition and mounting it as root, requiring a kernel capable of mounting the root filesystem, with the PROM environment able to specify the root path. 4 A setup with the root filesystem on a spinny disk and the rest on an NVMe drive is possible, and the root filesystem can reside on one drive while others remain unused. 56
