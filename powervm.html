PowerVM

Claims: 8

PowerVM runs on IBM Power systems, where it is executed in the system firmware and allows running multiple operating systems on the same hardware by default. 12 AIX requires PowerVM to run on modern Power hardware, even when it is not exposed to the user, and it can coexist with Linux in PowerVM. 3 AIX 7.1 and Linux can run on the machine, but PowerVM itself cannot. 4 PowerVM activation codes are required to enable certain features, and missing features can render the system incomplete. 5 The ESS site can be used to check for PowerVM and IBM i keys by entering the model and serial number, but the CoD codes and IBM i licensing tool outputs can sometimes be inconsistent. 6
