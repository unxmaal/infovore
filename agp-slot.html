AGP slot

Claims: 6 Part of AGP

The rx2600 lacks an AGP slot, but the zx6000 has one, and it is an IO board that can be easily replaced. 1 Prism systems will panic and enter POD mode if AGP slot #2 is populated but not #1. 2 The AMD64 version of VMS is unlikely to use the AGP slot in PCI mode. 3
