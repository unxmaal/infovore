With VAX

The VMS operating system (OpenVMS) can run on VAX and Alpha systems, with efforts to support it on AMD64 architecture. 1 VAX binaries were translated to Alpha using software tools, and mixed architecture clusters are supported with VAX and Alpha. 23 WordPerfect for VMS was available for both VAX and Alpha. 4 On Alpha, CDE is a port like that found on 90s Unix, while on VAX it is more basic and requires additional software. 5 OpenVMS 8.4 on Alpha has stricter password requirements than VAX. 6

General

DEC developed the Alpha processor, which was based on NT (itself derived from Mica) and became the fastest CPU of its time, achieving about 500 MIPS in floating point tests. 789 The DEC Alpha is a RISC architecture that HP ended up with alongside PA-RISC, and Compaq inherited Alpha and Tru64 Unix from Digital Equipment in 1998 before HP consolidated lines and discontinued Alpha/Tru64 and PA-RISC in favor of HP-UX on Itanium. 1011 OpenVMS 9 can run on Alpha, and the DECstation build is likely a mislabel, though there is a build of IRIX 3.x for the MIPS DECStation. 121314 Alpha can run a variety of operating systems, including Linux, Windows NT, and Lisp Machine OS such as Genera on Tru64. 151617181920 Switching between Unix and NT on Alpha is difficult because Unix runs on SRM firmware while NT requires ARC, and some Alpha systems have both while others have only one. 2122 Some Alpha CPUs may fail, and Alpha thermal tape can degrade and cause overheating, which can be fixed with thermal paste. 2324 DEC's Alpha was a 64-bit RISC architecture optimized for raw performance, considered by some to be a favorite RISC design and better than Itanium, though it could get very hot to maintain that performance. 2526272829 Alpha was far ahead of the competition on floating-point for technical computing for quite a while, and was fast enough that DEC could compile VAX assembly code to it, emulate a whole bunch of VAXisms in PALcode, and still be much faster than the VAX. 3031 The FX!32 binary translator made NT on Alpha the fastest way to run i386 programs for some years, and NT 4.0 Terminal Server with FX32 allowed concurrent RDP access to x86 apps on an Alpha. 3233 DEC put a lot of work into making its systems cross-arch, such as compiling VAX asm to Alpha/IA64, and the Alpha and IA64 architectures are still using the GEM IR. 3435 Ultrix/DECchip AXp runs on Alpha processors, and DEC did not have a generic cabinet of the VAX era like those beige half racks with a front door. 3637 Red Hat 7.2 Alpha was a version of Red Hat Linux for Alpha processors, available from Compaq but not Red Hat's CDN, and was the first and only version to work properly on some AlphaServer models. 3839 BSD and Linux work relatively well on Alpha, Power and IA64, and SIMH can emulate an Alpha processor. 4041 DEC produced a range of systems including the DECstation, VAXstation 4000, and Alpha AXP, which used TURBOchannel, 3W3 video, and the same keyboard/mouse after an adapter. 42 The best DEC ran MIPS; Personal DecStation 5000s used MIPS processors; Alphas followed. 43 VMScluster on Alpha and Itanium can handle shared storage via FC. 44 OpenVMS 8.x and 9.x are limited to Alpha/IA64 processors, and there's now an AMD64 version but it's less known. 45 The x86 VMS license is available through the hobbyist program for Alpha or IA64 systems. 46 First Linux machine permanently running was RedHat 4.2 for DEC Alpha (Multia). 47 An Alpha running NetBSD had incredible uptimes. 48 DEC used the VR319 monochrome monitor with VAXstations and DECstations. 49 DEC Alpha ran on a variety of platforms, including the PC164, LX164, 500au, and Dec Personal Workstation sd550, and Windows NT was available for it as well as for MIPS, SPARC, PPC, and other architectures. 50515253 Digital UNIX was the most popular operating system on Alpha in the late 90s, with OpenVMS second, and VMS 8.4 was the only VSI-produced release for Alpha and Itanium. 545556 DEC manufactured hard disks and released eXcursion for MIPS, but it did not use Itanium CPUs, having been acquired by Compaq before Itanium was developed. 575859 Alpha hardware remains popular among retro enthusiasts, though it is a dead platform, and community licenses are not available for Alpha or Integrity. 6061 HP, IBM, Sun, and DEC are listed together as related entities. 62 IBM and DEC were strictly enterprise or NT. 63 NT on Alpha at least had an x86 emulator. 64
