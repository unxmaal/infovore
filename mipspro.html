MIPSpro

Claims: 178 Background: 7 claims already covered by Wikipedia, see Open64, CMake, Distcc, IRIX.

With GCC

GCC and MIPSpro do not mix well together, and mixing their object code can cause link-time failures. 12345 GCC is generally easier to port with, its bugs get fixed, and it produces faster and smaller binaries for modern code, while MIPSpro can improve performance for certain applications. 678 Performance comparisons vary, with some benchmarks favoring GCC, others favoring MIPSpro in floating point, and some showing no difference. 9101112 GCC is preferred for porting due to widespread compatibility, while MIPSpro is used for retro demo engine stuff and C++98. 1314 MIPSpro was SGI's own compiler, and modern usage has transitioned to GCC and now to clang/LLVM. 15 Fceux is an NES emulator that can run on IRIX using either MIPSpro or GCC. 16 Building with MIPSpro can fail due to memory corruption issues during PNG loading, while building with GCC works but requires modifying the GNUmakefile to link with -laudio and -lpthread. 17 It has been a long time since anyone built anything on IRIX, GCC, or MIPSpro. 18

With IRIX

MIPSpro is used to compile a variety of software on IRIX, including GNU grep, prboom, Dosbox, Quake, SDL-based projects, HomeworldSDL-IRIX, OpenJDK 8, and ag. 192021222324252627 Building with MIPSpro on IRIX can require workarounds such as defining _XOPEN_SOURCE=500, adding a pragma pack, autoreconfiguring configure and makefiles, and applying patches. 19202825 MIPSpro is one of the only exceptions to the rule that almost nothing gets installed into /opt on IRIX. 29 SGI (now HPE) does not offer MIPSpro and IRIX licenses for hobbyists due to the small market size. 30

General

MIPSpro is an older SGI compiler that supports C89 and is fast but may lack full C99 support. 31 It supports many C99 features, though some constructs can cause it to crash, and it supports C++99. 3233 The MIPSpro environment includes specific flags and library paths for compiling MIPS-based software. 34 The mipspro and GNU toolchains do not get along well for certain checks, and some fixes for libc and headers can be enabled via CFLAGS to improve compatibility. 3536 MIPSpro has a license nag screen that can be fixed with a wiki page. 37 MIPSpro is Silicon Graphics' commercial compiler suite for IRIX development, available alongside GCC binaries. 3839 The compiler was K&R before becoming ANSI C, then stopped at C99, which was not widely supported as MIPSpro ended development. 4041 MIPSpro is not faster, better, or more efficient than modern GCC, and its optimization can randomly break things, such as in the bash bug where $(command) tries to execute ommand instead of command. 4243 It has issues with certain var-arg macros and optimization flags, its error messages can be unhelpful, and reducing optimization levels can resolve some problems. 4445 MIPSpro supports C99 and C++03, and c99 mode can be turned on for compatibility with newer C99 features and standards. 4647 The only version probably worth using is 7.4.4, with 7.3 requiring 1.2 and 7.4 requiring 1.3. 4849 MIPSpro is a compiler suite that was distributed on SGI hardware and supported at least C95 and possibly C99. 5051 It includes a debugger (dbx) and a C frontend that is required for compiling. 525354 It supports 64-bit code compilation via the N64 flag, though later versions dropped N64 support. 55 It offers OpenMP pragmas, including support for older OpenMP versions. 5657 SGI licenses MIPSpro through FLEXlm, using the same vendor daemon and keygen as other SGI products. 58 MIPSpro can be used on IRIX and potentially on Linux via QEMU MIPS user mode. 59
