OpenGL 1.2

Claims: 11 Part of OpenGL

SGI hardware supported OpenGL 1.2 at most, with the VPro implementing it and the O2 supporting only 1.1 in hardware. 123 The O2 implements OpenGL 1.2 features along with some SGI-specific extensions, making it effectively OpenGL 1.2 compatible. 4 The Onyx4 supports OpenGL 1.2 and possibly AGP Radeon cards, but not OpenGL ES, which is optional for Qt4. 5 Several MAME implementations require OpenGL 1.2, including glmame 0.78, the SDL IRIX version 0.149, and xmame, which achieves full speed with 1.2. 678 MAME runs faster on the VPro than on the O2 due to OpenGL 1.2 support. 6 Someone ported a game to OpenGL 1.2 but found it not fun. 9 A user is working on adapting FPU tests from their IRIX repository and considering developing a DEQP-like tool for OpenGL 1.2 compatibility. 10
