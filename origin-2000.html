Origin 2000

Claims: 112 Background: 7 claims already covered by Wikipedia, see SGI Origin 2000, SGI Onyx2, SGI Octane, Silicon Graphics.

With Onyx2

The Onyx2 is based on the Origin 2000, which was a Cray design SGI acquired in the nineties. 1 The compute module for the Onyx2 is basically an O2k, and the Onyx2 adds a graphics module above the O2000 processor module. 23 The SGI Origin 2000 and Onyx2 used the same drive sleds as the Octane. 4 The Origin 2000 and Onyx2 power supplies are the same. 5 The IO9 motherboard is the same as used in the Onyx2 and O2k. 6 Onyx2/Origin2000 RAM is color-coded. 7 The destination kit for Onyx2 and O2k includes installation discs, serial cables, a microphone, speakers, a mouse, some books, and other items. 8

General

The Origin 2000 is a large system, bigger than the Origin 200, and is an IP27. 910 It uses NUMAlink for processor and memory interconnect, which limits bandwidth for more than two sockets. 11 It can use up to 8 ports across 2 slots with 2 routers, and two routers may be needed to connect a second O2K or for massively parallel systems. 121314 It can run an Mgras or Mardi Gras XIO card for graphics support, and a RAD4C-KM card works in it. 151617 It can be tricked to install an SE card, and it is suitable as a large IRIX compile server for software development. 1819 It weighs between 200 and 250 pounds without skins, generates more heat than the ChallengeL, and can be powered from a wall socket. 202122 ILM's old render farm used only Origin 2000 systems, and in the early 90s SGI workstations were often used with high CPU power headless systems for frame rendering. 2324 The Origin 2000 (O2K) uses a hypercube topology, with the O2000 using XIO to interconnect nodes in a brick and K-TOWN cards for interconnect between graphics and compute chassis. 252627 The backplane connects nodeboards, but for more than two cards a router card is needed, and a null router can act as a wire connecting two nodes. 28 An Origin2000 deskside can hold two router boards but typically has room for only one, and a null router is standard. 29 The O2000 requires a 208-240V input for optimal performance with four CPU boards, but can run on 120V with reduced capability, and running on 208-240V can reduce I^2*R power losses. 3031 The Origin2000 can support multiple SI/SE graphics cards beyond the XIO slots, with up to four graphics pipes, and can be configured with multiple CADduo PCI cards and IO6-G for multi-user CAD workstations. 323334 The O200 and O2K are similar in hardware, differing mainly in CPU clock speed and physical connection limitations. 35 A single CPU O2K is a real hardware option, not ideal but not a big deal either. 36 SCA is a wide SCSI connector used in O2, Octane, and O2K, but SCA disks do not fit in Indigo2 sleds. 37 An O2k has physical debug switches. 38 o2k doesn't have vpro driver source. 39
