cdrecord

Claims: 7

cdrecord is a CD burning tool that is part of app-cdr/cdrtools in Gentoo, where it works on Solaris 8 and Red Hat 9, and is also available in opencsw despite being shipped along with Solaris. 12 It can also be used on IRIX, where schilytools contains tools like cdrecord and mkisofs, and it works on SCO and would likely work on IRIX. 34 cdrecord can burn CDs on an Indigo2, and xfburn in Linux can reliably write CDs using cdrecord or cdrdao. 56 Passing a CD drive to a VM can be used as a workaround for CD burning issues. 7
