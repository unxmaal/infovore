IRIX 3

Claims: 22 Part of IRIX Background: 1 claim already covered by Wikipedia, see IRIX.

IRIX 3 was System V Release 3, while IRIX 4 and 5 were System V Release 3 and Release 4, respectively, with SVR4 introducing ELF. 1 The main change from IRIX 3 to 4 was that X11 became the default desktop. 2 X in IRIX 3 was optional until 3.1G, and GLX did not exist until IRIX 4. 3 IRIX 3 does not have tcsh or ksh93; it has csh which lacks autocomplete. 4 The swdists for IRIX 3 are uncompressed and in CPIO format, and the IRIS 3.7 source code contains gendist-related source code. 5 The X header files and dev libraries for IRIX 3 are not publicly available. 6 IRIX 3 came with Alias software but required Wavefront Advanced Visualizer, which is available as shared files. 7 Alias for IRIX 3 was available but may not install on IRIX 4.0.5. 8
