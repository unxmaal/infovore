System/36

Claims: 9

The IBM System/36 is a minicomputer that can run on an AT-like case but requires an AT to boot and a specific card, making it difficult to use without those components. 1 The System/36 has no licensing, so as long as media can be found for a specific machine it should work, though there are many different versions of even identical model numbers that must be checked. 2 The System/36 had a software piracy scene with the VASP widely distributed. 3 SSP for System/36 has different versions for hardware revisions and is personalized, and the System/36 and System/34 run different, incompatible versions of SSP. 45 The System/36 had a Whitesmiths C compiler, now open source. 6
