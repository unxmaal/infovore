root drive

Claims: 5 Part of root

The root drive is used for booting and contains a standard layout with partition 8 as the volume header. 12 Sash is a minimal shell that acts as the bootloader for the IRIX kernel, and PROM typically contains environment variables pointing to the volume. 2 The root drive and a usrroot drive are used for different purposes in IRIX, and splitting the filesystem over multiple disks is a preference for certain setups. 3 To repartition and set up a root drive, use the main menu options r for repartition, root drive, and l for label. 4 The root drive, used for booting, has bad blocks indicated by write errors, but a live backup exists. 1
