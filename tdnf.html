tdnf

Claims: 31 Background: 1 claim already covered by Wikipedia, see XMMS.

tdnf is a package manager for TARDIST-based systems that automatically handles dependencies, and it is used to install the base system on SGUG-RSE instead of extracting the entire repository. 12 tdnf installs GPG-signed packages, imports the GPG key into rpmdb, and understands $release and $arch variables for multi-arch packages, but has issues with http paths. 34 tdnf can install a wide range of packages, including Motif versions of Netsurf, Icebreaker, chocolate-doom, flx-locate, flx-joyride, Dune II, and SDL2, from online, S3, or local repositories. 56789101112 tdnf update checks for updates and may update existing packages, but does not download and install all available updates at once. 13 tdnf search can list the same package multiple times if there are duplicate repositories configured, and repo priority can control which repo tdnf downloads from. 1415 There are known issues with tdnf, including segfaulting when downloading packages, a leftover sudo process consuming CPU, and packages such as XMMS, dosbox, and SDL_image being added to SGUG-RSE but not yet available via tdnf. 1617181920 tdnf may be broken and upgrading to the latest version on the repository may fix issues, and it could allow building and packaging 32-bit and 64-bit MIPS3 and MIPS4 packages. 212223
