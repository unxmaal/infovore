XFree86

Claims: 26 Background: 7 claims already covered by Wikipedia, see XFree86, Xsgi, Xterm.

XFree86 existed before Linux and was used for ATI card drivers on SGI systems, and the SGI X implementation is based on X11R6, with some models using XFree86 from around 2000. 12 XFree86's license change led to most development effort moving to X.Org, causing XFree86 to become less active, though most of the drivers were still in XFree86. 34 XFree86 is used on various SGI systems, including the Onyx4, which uses XFree86 and lacks IRIS GL support, leading to compatibility issues with many applications. 56 XFree86 has support for some Impact variants, and users were able to drive a display with a GeForce4 MX440 in an Origin 200 through XFree86. 78 Radeon cards require binary patches to XFree86 and have hardcoded paths in the executable, and there are issues with the XFree86 server for graphics hardware paths, which are hardcoded. 910 DG/UX had support for standard GPUs like the ATI 3D Rage Pro through XFree86, and the PCI Rage XL can run XFree86 at 640x480 but has timing issues and uses the vesa driver. 1112 To force XFree86 to start without a mouse, set `AllowMouseOpenFail true` in the configuration. 13
