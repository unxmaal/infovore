CLI

Claims: 6 Background: 1 claim already covered by Wikipedia, see XMMS.

The CLI is enjoyable for coding. 1 The System Info, warnings/faults, and L1/L2 logs are available in the CLI but not implemented on the LCD. 2 The CLI has eject and inject commands, which may require loading libraries beforehand and whose use during an install while in Sash is uncertain, though using them on an O2 can be kinder to the drive. 3 xmms is a recommended audio player for IRIX, and mikmod can play mod files, though it is CLI only. 4 Mounting CDs in IRIX 4 can be challenging, especially with the GUI doing nothing and the CLI complaining about block devices, as the filesystem uses 512-byte sectors. 5 Only the CLI can create new EFS ISOs as part of rusty-backup. 6
