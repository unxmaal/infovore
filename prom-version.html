PROM version

Claims: 5 Part of PROM

An O2 running IRIX 6.5.28 with an old PROM version required a manual update and sometimes needed a power cycle to boot. 1 The current PROM version is 4.0, which is not the latest. 2 The PROM version should support all boxes, but the frontplane might fail. 3 T2 Linux requires a minimum PROM version, with 4.43 referenced for SUSE Linux Enterprise Server 9 SP3, though later PROM versions may not be compatible with older SUSE versions. 4
