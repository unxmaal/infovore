Venix

Claims: 3

Venix is an operating system for SGI machines, alongside Xenix and Coherent. 1 Venix runs on an 8086, whereas AIX requires a 386. 2 Some implementations, including Venix and Xenix, write to the RTC and read back to check for Y2K compatibility, which could fail and damage CMOS RAM on some clones. 3

Sources

  1. Xenix, Coherent, and Venix are operating systems for SGI machines. (user-42cf, 2021-11-04, exchange 74204, check: uncheckable)
  2. Xenix, Coherent, Venix, PC/IX, Minix (V1.2), QNX, Singlix, ELKS, and Proolix run on an 8086; AIX requires a 386; Posixified and networked systems need a 386. (user-237d, 2021-11-05, exchange 216117, check: supported)
  3. Some implementations write to the RTC and read back to check for Y2K compatibility, and Venix or Xenix did this, which could fail and damage CMOS RAM on some clones. (user-cb4c, 2020-09-16, exchange 216095, check: uncheckable)
