OpenGL 1.0

Claims: 9 Part of OpenGL Background: 4 claims already covered by Wikipedia, see IRIX, OpenGL.

OpenGL 1.0 was available on several SGI platforms, including the INDY (natively), the Indigo2 Extreme (with some OpenGL 1.1 features available through extensions), and the Octane (which had the closest to OpenGL 1.0 hardware implementation). 123 On IRIX, OpenGL 1.0 was available on IRIX 5.3 (including via TG (GR1.2/5) on the TT), while IRIX 6.2/5.3 supported only OpenGL 1.0 for textures and IRIX 6.5 shipped with OpenGL 1.1. 45 freeglut requires GLX 1.3 and OpenGL 1.0 fallbacks to build on IRIX 5.3, and can fall back to the old glXChooseVisual/glXCreateContext API instead of the GLXFBconfig one. 6 In OpenGL 1.0, display list implementations in drivers handled caching, but it did not work well, and texturing was handled using glTexImage with per-texture display lists recommended for switching textures. 78 The INDY supports OpenGL 1.0 natively, but some demos may exhibit flicker due to buffering issues. 1
