Radeon HD3450

Claims: 3 Part of Radeon

The Radeon HD3450 uses the radeon driver but experiences slow performance due to software rendering, indicating issues with DRI and DRI2, possibly related to version mismatches in xorg-xserver-video-ati and libdrm. 1 It requires fbdev/vesa drivers for a desktop and has sluggish performance, with no IA-64 fglrx driver available so radeon driver support is lacking. 2 An Altix 350 can be modified to run recent Linux kernels and enable PCI 3D acceleration. 3
