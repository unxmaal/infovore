M3000

Claims: 4

The M3000 is a Sun server that cost about $30k, compared with about $60k for a V240 and about $15k for a T2000. 1 The M3000 uses the same sleds as other Sun drives from that era, with part numbers like SEWX3C11Z-P-N-540-7991 and 541-0239. 2 The machine reports two drives when there is only one, causing SCSI bus reset errors and parity errors. 3 The m3000 can be reset to factory mode by removing the snapshot, and its root password can be cracked in the firmware update rootfs to access the system. 4
