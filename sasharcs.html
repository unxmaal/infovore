sashARCS

Claims: 5

sashARCS is used by the Indigo2 R4000 and the O2, but not by the R8000 or R10000. 12 The `sa` file is in the mkboottape format and can be used for installation, though booting from tape is no longer supported. 3 It contains files such as `sash64`, `sashARCS`, and `mr` with sizes 266000, 342532, and 19200000. 3 Running a built driver as an executable ELF binary from sashARCS may work, but exiting back to the Command Monitor with hinv giving different results is more challenging. 4 The O2 has a compatibility issue with sashARCS, indicated by a drive detection error. 5
