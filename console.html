console

Claims: 33

The console starts the conversation and the controller/accessory responds based on the request using the Joybus protocol, which is similar to that used on the Gamecube with a few new commands. 1 Setting 'console=g' enables graphics on install, while 'console=d' uses the first serial port for console. 23 The console color can change to blue for unknown reasons. 4 To run a.out in the IRIX console, use `./a.out`. 5 The 64Drive update supports playing the game on a console. 6 You can download VMU saves from the internet using the Planetweb browser on the console. 7 This part, with a matching HP part number, is used in various Onyx servers and is called a 'SYSTEM CONTROLLER ASSY L2' or a 'Console' in some contexts. 8 Running swmgr from the csh shell accessed via Console should set the PATH correctly. 9
