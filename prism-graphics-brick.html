Prism graphics brick

Claims: 4 Part of Prism

The Prism graphics brick requires a base IO node and has two AGP slots, but no PCI slots. 12 It uses a different interface board than a basic Altix, though this board is not necessary to make a graphics brick. 3 ALE3 is the interface for the Prism graphics brick, and Xfree86 is not GPU accelerated on it. 4
