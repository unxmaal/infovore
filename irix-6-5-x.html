IRIX 6.5.x

Claims: 22 Part of IRIX Background: 3 claims already covered by Wikipedia, see IRIX.

SGUG-RSE is intended for IRIX 6.5.x. 1 IRIX 6.5.x supports the XFS file system, which supports 8 exbibytes. 2 IRIX 6.5.x supports the 32-bit ABI used by the Indy and O2, which are 64-bit systems. 3 The Solid Impact can run IRIX 6.5.x with N32 MIPS-IV ELF executables. 4 Cellular IRIX 6.4 was a separate special version for Onyx/Origin etc., with the SMP changes present in 6.5.x. 5 Every version of 6.5.x is now installable, with the exception of 6.5.1. 6 Installing from an Applications disc that does not match the 6.5.x point release may cause issues. 7 IRIX 6.5.x needs more resources; versions up to 6.5.10 work better on R5k CPUs. 8
