XDMCP

Claims: 17

XDMCP is a protocol that allows X11 applications to connect to a remote X server, with the server's location specified by the DISPLAY environment variable and managed by XDMCP. 1 Remote X desktop sessions require XDMCP and an X server started with the '-query' option. 2 Xterminals use BOOTP to configure themselves, TFTP to obtain firmware, and XDMCP to find a login host, running X11 from there. 3 XDMCP is enabled by default on IRIX, requiring no additional configuration for basic functionality. 4 XDMCP has been disabled in modern Linux distributions to prevent remote X11, which is unencrypted and potentially harmful. 5 XDMCP from vcxsrv works without additional configuration, and XQuartz is the option for using XDMCP on a modern Mac. 67
