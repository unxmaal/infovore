Xsgi

Claims: 30 Background: 2 claims already covered by Wikipedia, see Xsgi.

XSGI is a display server that supports both OpenGL and GL on SGI hardware, though it does not support running another X server and can only be used as a second monitor or for framebuffer with no 2D functions. 12 It is considered superior to Xsun and XFree86, and is the only good X for the Prism. 345 The Xorg client libraries are compatible with XSGI and allow building newer software. 67 XSGI defaults to 8-bit color depth for most windows, which can provide a speed boost, though not all OpenGL features are fully supported by irisgl wrappers. 8 It does not default to 24-bit color; applications must request it, requiring a settings update. 9 XSGI does not like it if CWBackPixel | CWBorderPixel aren't set when creating a window. 10 It has a bug in WRMASK generation that affects real hardware, and an ugly workaround fixes it. 11 xset can disable screen blanking using XSetScreenSaver and XSetDisplaySaver commands, and modern xset works on XSGI. 12
