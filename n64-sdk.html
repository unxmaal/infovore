N64 SDK

Claims: 9 Part of N64 Background: 1 claim already covered by Wikipedia, see SGI O2.

The full N64 SDK from the time is available on Shane's Indy for loading code files. 1 The N64 development tools can run on an Octane or O2 with IRIX, but compatibility with the SDK depends on the IRIX version and the N64 board's CPU, and debugging and 3D modeling functions may not work. 2 N64 development moved to PCs by the time IRIX 6.5 was released in June 1998, so compatibility with the N64 SDK is uncertain, and compatibility issues exist for IRIX 6.5 and possibly 6.4. 34 The N64 SDK can work on most SGI systems from 1996. 4 The N64 SDK was made to be Linux compatible and included compiled *.obj and *.h files for the iQue, a 3rd party product based in China. 5 The Makefile for the N64 emulator uses GNU make syntax and requires the N64 SDK, which defines OBJECTS among other things. 6 The O2 can run MIPSPro compiler and has an N64 SDK with an emulator, and the N64 SDK on O2 can compile sample programs. 78 The Indy can run N-World, dev tools, and the N64 SDK. 9
