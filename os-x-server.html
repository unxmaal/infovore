OS X Server

Claims: 4 Part of OS X

OS X Server was preceded by Rhapsody dr1 and dr2, which had x86 support before the OS X Server release, though with limited hardware support. 1 The Apple Macintosh G3 server ran a newer version of OS X Server, though the speaker did not have the username or password. 2 Installing a new CD drive may have caused issues booting OS X Server from CD, possibly due to compatibility problems, with a possible fix related to drive settings or firmware. 3 Using a separate case-sensitive HFS+ volume might be a better option for reading UFS disks on a Mac, and there have been issues with OS X Server and NFS. 4
