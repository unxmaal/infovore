R5000 O2

Claims: 3 Part of R5000

The R5000 O2 is less performant than a 400 MHz R12000 O2 with the same amount of RAM, which is a good configuration. 1 An R5000 O2 with 256 MB of RAM is a limited configuration for development work. 2 Compiling in 2025 with NetBSD on an R5000 O2 with 64 MB of RAM results in frequent swapping. 3

Sources

  1. A 400 MHz R12000 O2 with sufficient RAM is a good configuration; R5000 O2s with the same RAM are less performant. (user-8de9, 2022-01-21, exchange 24944, check: supported)
  2. An R5000 O2 with 256 MB of RAM is a limited configuration for development work. (user-95db, 2022-01-21, exchange 24944, check: supported)
  3. Compiling in 2025 with NetBSD on an R5000 O2 with 64MB RAM results in frequent swapping. (user-231e, 2025-12-27, exchange 61097, check: supported)
