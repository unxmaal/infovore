BSD

Claims: 71 Background: 8 claims already covered by Wikipedia, see Video games and Linux, Berkeley Software Distribution, Oracle Solaris, Unix, XFS.

With Linux

Linux and BSD are both used across a wide range of hardware, including x86 systems, Alpha, Power, IA64, and SPARC machines, with each offering strong hardware support in different cases. 1234 Both operating systems can be installed on SGI systems, though IRIX remains the only OS that can fully utilize that hardware. 5 Linux and BSD are needed to perform certain tasks such as burning EFS disk images, installing IRIX via netboot, and setting up net install servers. 678 Both systems support software such as Xash3D and have historically included packages like olvwm. 910 BSD has existed for a long time but has not gained as much traction as Linux. 11

General

BSD is a form of Unix. 12 The distinction between System V and BSD was more about marketing and licensing than technical differences, as both borrowed heavily from each other. 1314 BSD originated as an attempt to avoid AT&T's Unix license fee, though legal issues ended up costing more. 15 BSD is not binary compatible with the 4.4 version from the 80s, and its early multi-platform support had a very old core with significant changes coming after the Tahoe port. 1617 BSD has been ported to a wide range of hardware, including HP 680x0 workstations, Ultra 60, SGI systems, the IBM Model 43P-270, and the PlayStation. 1819202122 Apple has leveraged BSD to bootstrap OS X and other devices, running a Unix-based system with a BSD userland and open-sourcing some BSD components. 232425 BSD is a kernel whose name is bsd, not boot. 26 BSD runs on MIPS but not optimally. 27 In DMA handling, IRIX sets up DMA and sends the command, while BSD sends the command and lets the device handle DMA setup. 28
