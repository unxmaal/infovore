Atari Falcon

Claims: 17 Part of Atari

The Atari Falcon was released in 1992 and features built-in DSP along with an add-on 8-channel box for audio IO. 12 It can run a full Unix-like OS with TOS compatibility, allowing multitasking of Atari and Unix apps, and FreeMiNT can be installed on Atari Falcon machines. 34 The Atari Falcon can render Quake2, 3, and Half-Life maps using its DSP as a graphics accelerator, and it renders in Quads, similar to the NV1 and Saturn. 56 It can run Doom with enhanced features including real-time MIDI music and animated textures, and GIMP runs in true colour on an Atari Falcon. 78 RaSCSI can achieve speeds up to 4mb/s on an Atari Falcon, which is close to the Falcon's theoretical maximum. 9 Dml created Apex Media, a graphics and animation package for the Atari Falcon released in 1994, which was showcased on a computer/gaming show. 10
