UAE

Claims: 9

UAE is an emulator that can run Amiga software, including Amiga drive images and 68k programs. 12 UAE can emulate an Amiga inside an Amiga using a PC card. 3 MorphOS provides good UAE integration for games and includes a browser, though it is not WebKit. 4 AmigaOS 4 used UAE to run 68k programs, similar to running Classic on an OSX system. 2 UAE runs full speed on higher-end SGI machines, though early versions could not emulate A500 speed with audio on a PMMX233, and performance worsened with complexity. 56 UAE has been run on systems such as the SGI Indigo, and there have been efforts to recompile it and create an easy installer that injects the IndyEmu files into the system. 789
