Xlib

Claims: 8

Xlib is a library used for window creation and management, and there is a book from 1993 on XLib programming. 1 Xlib uses the icon_pixmap field in the XWMHints struct to specify the icon for a minimized window. 2 Xlib documentation and tutorials for Motif and CDE are available online. 3 Before 1993, SGI used IRISGL instead of Xlib for window creation, and IRISGL manuals mention a 'mixed model' for combining Xlib and IRISGL. 4 Xlib is important for debugging OpenGL programs on IRIX. 5 X programs had issues with different versions of xlib in sgugshell.sh mode in previous versions. 6 Xlib can be used to manage a GL window as the screensaver by finding the XID of the window and using Xlib functions to modify its properties, making it fullscreen and borderless. 7 Genera runs on Linux or OSF/1, but OSF/1 has issues with Xlib calls, so X forwarding is often used. 8
