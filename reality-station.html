Reality Station

Claims: 3 Part of Reality

Sirius Video is available for POWER Onyx, Onyx, and Reality Station graphics workstations, and can be used in POWER CHALLENGE and CHALLENGE server configurations for video server capabilities. 1 The Reality Station was a specific SKU of the Onyx with a single CPU but full RE2 graphics subsystem, and its firmware could be modified to support four processors. 2 The RealityStation has a single CPU; the Challenge has a screw in the backplane that restricts CPU slots, which can be removed with pliers; a system controller board check determines the number of CPUs. 3
