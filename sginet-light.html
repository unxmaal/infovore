sginet-light

Claims: 7

sginet-light can be added to the system list on sginet. 1 It works offline and even on IRIX 4, and does not require any dependencies, while sginet requires -lcurl -ljson-c -lncurses -lform -lpanel. 23 You can register an SGI machine without an internet connection by downloading the 'sginet light' version, printing the JSON payload, copying it to an internet-connected machine, and pasting it into the registration form. 4 sginet-light generates the hinv payload for registering on the sginet website but does not report uptime and online status. 5 sginet-light for IRIX 5.3 uses a simple socket operation to connect to a local nginx proxy and report uptime via HTTP. 6 It can be used to check hardware information by finding the necessary calls. 7
