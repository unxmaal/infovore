router

Claims: 30 Background: 3 claims already covered by Wikipedia, see Router (computing).

A router is a networking device that may contain dual 450 MHz PPC750 processors and can be the cause of network connectivity problems, including when a device cannot be seen by the router or reach the internet. 123 The O350 has only external bays, with 2 per brick except for the router, and supports only one router, as two routers halt boot with an invalid configuration. 45 An O2000 NUMA system can show different hub and router counts depending on its configuration, and each router brick requires 4 bricks. 67 An Onyx2 rackmount configuration consists of an Onyx2 brick with an O2K for compute, and linking it to other systems requires a router, which an Onyx2 deskside lacks. 8 A router can improve Numalink speed but is not necessary for connections, and it connects to L2 or L3 controllers over USB rather than L1. 910 The router has an internal USB hub for connecting bricks, and SGI provided external hubs for bricks without built-in USB. 11 You can send commands to bricks you are not physically connected to using a router, but it works for some ports (odd numbered ones), and you can use '* version' to see which bricks respond. 12 A router's connected devices list can show assigned IPs, and the L1 can be accessed via a serial link to enter router comms mode, allowing flashing the L1 without booting into IRIX. 1314
