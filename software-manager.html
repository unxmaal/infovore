software manager

Claims: 20 Part of software

Software Manager is a tool for installing software on IRIX, serving a purpose similar to the `inst` command. 12 It does not recognize tarballs for installation, and tardists are specific to IRIX software that should be installed through the Software Manager without manual extraction. 34 You can mount a CD on a directory and use that directory as a source, or load a .22 application CD/image to cherry-pick what you want, and double-clicking the CD icon opens the Software Manager. 567 The Software Manager in IRIX lacks a combined repository for resolving dependencies like modern package managers, requiring manual addition of tardists, and it may complain about conflicts that need other distributions to resolve. 89 In SGI IRIX 6.5.22, enabling preferences -> rules in Software Manager allows installing old software without conflicts. 10 The command 'inst remove neko*' can be used to remove all neko_* files using the Software Manager. 11
