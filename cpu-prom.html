CPU PROM

Claims: 4 Part of CPU

The CPU PROM boots the CPU board, checks hardware, and determines next steps, while the IO PROM accesses I/O devices. 12 For SMP SGIs, the IO4 PROM and CPU PROM are separate, with each CPU having its own CPU PROM and the IO PROM handling booting from a device. 1 The CPU PROM sets configuration flags such as clock multiplier and cache enabling. 3 The IO3 and IP7 PROMs are EPROMs that must match the CPU PROM revisions. 4 Onyx systems have a system controller for CPU board coordination. 2
