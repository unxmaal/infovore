Classic Mac OS

Claims: 23 Part of Classic Background: 3 claims already covered by Wikipedia, see Classic Mac OS, Mac OS 9, System 7.

Classic Mac OS lacked memory protection, which could make it flaky and require unusual restarts. 12 It did not support symmetric multiprocessing because of cooperative multitasking, though it supported asymmetric multiprocessing with the Power Mac 9600. 34 Classic Mac OS had no command line and no built-in system profiler, so hardware details had to be checked manually. 56 It could use FireWire, USB, and SATA combo cards with compatible firmware, but USB and FireWire support was unreliable. 789 It could run on machines such as the IIfx, Daystar Genesis MP, and MDD towers, and supported Glide wrappers and QuickDraw 3D RAVE in some games. 10111213 Classic Mac OS was considered outdated around the time Mac OS 7 was released, and OS 9 was reportedly less temperamental and easier to keep running. 141516 Macs running Classic Mac OS natively had performance capped relative to PCs and required tradeoffs such as ADB peripherals and floppy disk types. 17 Mac OS X shares no technological relation or shared codebase with pre-10.0 Classic Mac OS. 18
