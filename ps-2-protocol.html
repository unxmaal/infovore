PS/2 protocol

Claims: 4 Background: 1 claim already covered by Wikipedia, see USB.

The HP PA-8200 CPU is used in the HP RISC systems, and the system initializes the GPU but does not display the console if no keyboard is detected, using PS/2 protocol. 1 PS2 extenders should not interfere with PS2 protocol if they are passive, with a native length of up to 25m. 2 PS/2 protocol can be transported over USB using a USB HID interface. 3 The O2 controller requires software to set bits for PS/2 protocol; the MACE docs include the System Verilog for the block. 4
