kernel

Claims: 67 Background: 7 claims already covered by Wikipedia, see Kernel (operating system), QEMU.

A kernel is binary code loaded at an offset, where the instruction pointer jumps there. 1 The kernel is primarily compiled with MIPSPro, with GCC used for a small portion. 2 Compiling the kernel can take days, as the kernel compile on the G4PB itself took 1.5 days. 34 A kernel with a working set of 64K is considered heavy. 5 The kernel might have oopsed, and it can detect issues with time or date. 67 The kernel on AIX is located at /unix, which is a symbolic link to the appropriate kernel file depending on the system configuration. 8 The kernel is the core component that must be correctly configured and loaded for a system to boot, though it can be a tedious task to set up, especially for older hardware. 9 Correct sash and kernel versions are crucial, as some install media may lack a kernel for a given platform. 10 Formatting and repartitioning the drive is necessary to load the correct kernel, otherwise it panics. 11 The PROM only needs the kernel in a format it can understand to boot, whether via TFTP or a tiny XFS SCSI partition. 12 The kernel name is bsd, not boot. 13 The kernel determines IP addresses via RARP on SGI machines, as evidenced by entries in /etc/ethers on DNS, DHCP, and Bootparams servers. 14 Several systems require recompiling the kernel: Irix recompiles its kernel for each unique hardware set, A/UX requires recompiling after installation, and enabling NFSv2 and v3 requires recompiling the kernel. 151617 The SGI kernel sources include 1980s era code with some ANSI rewritten sections. 18
