MaXX Desktop

Claims: 4 Part of MaXX

MaXX Desktop is a tweaked Motif environment with Rox-Filer integration and is not related to CDE. 1 The MaXX Desktop project is closed source and is not updated frequently, limiting its compatibility with vintage UNIX hardware. 2 The MaXX Desktop installer script is provided as a binary for x64 systems. 3 MaXX Desktop can emulate IRIX, but it is slow and not as fast as QEMU. 4
