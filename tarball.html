tarball

Claims: 9

A tarball is a file format used for distributing software, which can be done through a standalone build with mipspro, adding to irixports, or simply tarballing the software. 1 TACO can be used to mount and convert SGI EFS images to a regular tarball, and the tardist format can be treated as a tarball for extraction. 23 ISO files contain filesystem overhead and additional data, making them larger than tarballs, but preserving disc images is a reason to use ISO files over tarballs. 45
