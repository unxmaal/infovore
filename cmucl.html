CMUCL

Claims: 7

CMUCL is a Common Lisp implementation that has IRIX support, including through sigcontext, and requires specific binaries for IRIX 6.5 that may not work on all systems due to differences in installed libraries. 1234 CMUCL is actively developed but has a complex build process involving bootstrapping, whereas SBCL, a Lisp implementation derived from CMUCL, has a simpler bootstrap build system. 56 For POSIX/Irix signals, defining the OS context as the signal context rather than the user context is suggested, as seen in CMUCL. 7
