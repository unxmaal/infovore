TrueNAS

Claims: 9 Background: 1 claim already covered by Wikipedia, see ZFS.

TrueNAS runs on ZFS. 1 TrueNAS with bhyve can run FreeBSD 13 in VMs, supporting services like Kerberos. 2 Both NFS and SMB are used on a TrueNAS server for different shares, with NFS being less secure than SMB but still used due to the home network context. 34 The latest version of TrueNAS doesn't support older versions of NFS, but 6.5.30 still works with TrueNAS Scale and with IRIX, though earlier NFS versions may cause version mismatch issues. 56 Local copies are convenient for accessing retro software and can be run on a NAS using TrueNAS, which works well with retro machines. 78 Explorer can hang when copying files by drag and drop from a TrueNAS share to an XP machine, but works fine via a mapped drive. 9
