OpenGL applications

Claims: 5 Part of OpenGL

OpenGL applications communicate using the standard X communications mechanism rather than DGL. 1 Indirect rendering can be enabled with +glx to run OpenGL applications remotely on an SGI. 2 Xephyr does not support GLX, which is required for running OpenGL applications from an SGI box. 3 To run OpenGL applications on a system with a custom OpenGL library, copy the .so file to a new directory, set LD_LIBRARY_PATH to use the custom library, and ensure the string in the .so file is of the correct length. 4
