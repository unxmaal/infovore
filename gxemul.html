gxemul

Claims: 12

gxemul is a buggy, reverse-engineered emulator that works well enough to run Ultrix and OSF/1, including running Ultrix quite nicely apart from a broken tape implementation. 12 SGI's IRIX ran on non-SGI platforms such as the MIPS Decstation, and GXemul has good Decstation support. 3 gxemul's hardware implementation is based on NetBSD drivers. 4 Running GXemul with specific arguments, such as -v -E sgi -e ip32 -C RM5200 with a 0xbfc00000:ip32prom.rev4.18.bin file, allows emulating an IP32 PROM, and using incompatible CPU/PROM versions can result in a black screen and frozen emulation. 56 The -Q flag makes gxemul use the provided PROM. 7 gxemul allowed single stepping through code in 2018. 8 gxemul does not actively develop and lacks IRIX support, but it is being worked on to run NetBSD over NFS. 910 QEMU and GXemul both run reasonably well, even on slow hosts. 11
