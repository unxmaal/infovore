passwd file

Claims: 6 Part of passwd

The passwd file can be edited to disable login capability, for example by setting the password field to :: and removing :* or :<hash> to clean it up. 12 To change the passwd file, one can use vi to edit and save it, then reboot into IRIX, or boot an install CD or access the file by mounting a second hard drive from another SGI. 34 Minirooting an Onyx2 allows copying the /etc/passwd file for cracking with tools like John the Ripper. 5 The passwd file was corrupted in a certain way, and nobody was root. 6
