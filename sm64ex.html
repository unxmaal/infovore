sm64ex

Claims: 6

sm64ex provides the OpenGL renderer for running Super Mario 64 on IRIX. 1 The OpenGL renderer in sm64ex needs to be downgraded to version 1.1 for compatibility with older hardware like Octanes, though its OpenGL 1.3 renderer could be ported to IRIX. 23 Compiling sm64ex requires the latest RSE and SDL, which can be found in nekoware or RSE. 4 sm64ex runs well on an Octane with MXE, but the compiled version on the O2 is slow, runs fine on other systems, and can be optimized. 56
