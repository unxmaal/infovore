linker

Claims: 9 Background: 1 claim already covered by Wikipedia, see Compiler.

The linker combines binary segments such as CODE, TEXT, DATA, BSS, and RODATA, and decides their locations. 1 When compiling, if functions are called but not included, the compiler generates object files assuming the functions are defined elsewhere, but the linker will fail if those definitions are not provided. 2 The linker requires specific constructors to be defined to avoid undefined references. 3 The linker needs to look in a specific directory for libraries, and the path must be specified. 4 The error message indicates that the linker is unable to find a library called -limbuf. 5 To resolve a debugging artifact path, tell the linker to ignore unresolved symbols in object files or all unresolved symbols. 6
