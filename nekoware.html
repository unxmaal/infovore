nekoware

Claims: 136 Background: 3 claims already covered by Wikipedia, see Bash (Unix shell), Id Tech 3.

With IRIX

Nekoware was a collection of ports for SGI systems, particularly IRIX, coordinated on a forum which is now defunct, leaving the remaining resources disorganized, with efforts to re-establish nekoware happening on [incomplete source]. 1 It is used for fixing and building software with MIPSpro on IRIX. 2 Nekoware offers a range of applications, including the Sylpheed v3 email client, the rxvt terminal (suggested as an alternative to the problematic IRIX xterm), OpenAL, OpenAL, and a version of TightVNC that includes Xvnc for IRIX. 3456 It also provides audio-related software, such as newer audio file players alongside IRIX's built-in CD player and older audio players, as well as TiMidity++, which adds MIDI support that IRIX does not install by default. 78 Games can be run on IRIX through compiled SNES emulators such as SNES9x, which is available in Nekoware. 9

With sgug-rse

SGUG-RSE is a project for installing software on IRIX, using RPMs for software packages, and it succeeded nekoware, which had itself replaced the freeware package that SGI was maintaining early on. 101112 The Indy runs IRIX 6.2, which has more software than 6.0 and 6.1, but it lacks Nekoware and SGUG-RSE, and it can also run IRIX 5.3 due to its limited RAM, but it likewise lacks Nekoware and SGUG-RSE. 1314 user-d903 promised user-f229 to push updates to booterizer for sgug-rse to eliminate nekoware. 15 dosbox is in SGUG-RSE but not available via tdnf, so users should use the one from nekoware that works with SDL1.x, and minicom can be found on nekoware or sgug-rse. 1617 Installing 'man' from SGUG RSE or nekoware can cause formatting issues and converter errors, rendering manpages unusable, so users may need to revert to the default manpages. 18 The package search tool can find software in nekoware, sgug-rse, and sgi-freeware, and is available in the sginet-client CLI. 19

General

Nekoware is a collection of software primarily for MIPS III processors, and is the most recent comprehensive archive, followed by tgcware and then SGI Freeware. 2021 It is primarily for MIPS III processors and uses the Mipspro toolchain. 2022 Nekoware ended around 2012, but some still use it for building ports, and it has things ported that are as new as 2015. 2324 The Nekoware repository was divided into /current, /beta, and /development, with precompiled tardists in /current and uncompiled code in /beta or /development. 25 Nekoware packages can be found on mirror.rqsall.com/nekoware. 26 The `current.ion` file is a URL pointing to the descript.ion file for the current branch of Nekoware. 27 Nekoware mirrors contain a newer version of bzip2 that can be installed with 'inst' or 'swmgr'. 28 Nekoware has some old firefox builds, and firefox 3 from nekoware supports gopher. 2930 Nekoware is a software distribution for SGI (IRIX) systems that started in late 2004, likely taking over from SGI's official freeware distribution as that collection died off. 313233 It is mirrored at ftp.irix.host (HTTP) and was backed up as a 50GB dump from the Internet Archive. 3435 Packages are installed to /usr/nekoware/bin, which must be added to the PATH environment variable, and installation is slower than RPMs. 363738 Packages often included source codes and patch files, with better packages offering them as optional installs, though the organization was arbitrary. 3940 Nekoware ports are built for mips4, which excludes R4k systems that can still run IRIX 6.5. 41 Nekoware provides old packages, some with outdated updates, including Firefox 3, ioquake3, and PrBoom+. 424344 Nekoware, freeware, RSE, and custom compiles can coexist on a system, though nekoware and rse repositories are incompatible. 4546 Nekoware auto-updated on DINA until 2014 or 2015, then stopped, and the SGI community lacks a clear plan for replacing it. 4748 Nekoware is community support for SGI after commercial development ceased, and it was the most up-to-date package before nekochan went dark. 4950 The entire nekoware collection can be downloaded from https://4dwm.com/Software/Files/nekoware.tar.gz, and backups are available at http://mirror.rqsall.com/nekoware/. 5152 6.5.21+ includes more robust libc features like strl-family functions and VA_copy, required for Nekoware, and 6.5.22 is the minimum supported version for nekoware and sgug. 5354 To use nekoware on IRIX 6.5.x, setenv _RLDN32_LIST /usr/lib32/libm.so:DEFAULT before running inst. 55 The command line installation method for Nekoware is reliable and avoids GUI issues. 56 Programs installed with Nekoware may not appear in the icon catalog depending on the packager's actions. 57 The latest nekoware for MIPS3 does not include bash or other GNU utilities. 58 Compiling with -I/usr/nekoware/include -L/usr/nekoware/lib and -I/usr/sgug/include -L/usr/sgug/lib32 allows linking to nekoware and sgug libraries. 59
