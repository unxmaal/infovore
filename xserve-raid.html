Xserve RAID

Claims: 6 Part of Xserve

The Apple Xserve RAID uses Fibre Channel drives made by LSI and can be configured for either loop topology or switched fabric, with the switched fabric being more common in modern setups. 12 The Xserve RAID can expose LUNs over Fibre Channel, and SGI can create XFS filesystems directly on those LUNs. 3 Using an Xserve RAID with Fibre Channel for storage is overly complicated to set up for multiple system access, and running CXFS on an Xserve RAID requires complex setup and can lead to system lockups under load. 45
