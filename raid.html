RAID

Claims: 13

For performance, an ideal RAID setup used separate partitions for /, /var, and /usr, with /usr as a raided partition for redundancy. 1 RAID was designed for spinning rust drives that have very different failure modes than NVMe drives. 2 A server using RAID and tapes experienced a failure just before a backup, with the system disk no longer booting and the system disk backup missing. 3 BIOS updates can reset RAID configuration, causing boot issues. 4 The Maximus V Gene motherboard handles RAID, which Windows presents as a single storage device. 5 Single disks didn't transfer at ATA133, but two on one channel could max it out with Bigfoot drives in RAID. 6 NetApp creates a filesystem (WAFL) on top of RAID on whatever disks you put in an aggregate, and you make a volume that can be a filesystem for NAS, or you create a LUN in a volume and then present the LUN via iSCSI or FC. 7 The IO Processor handles RAID and write caching for DASDs, and can expand an array while the system is running. 8
