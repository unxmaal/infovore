Reanimator

Claims: 43

Reanimator is a distro that can upload content to an RPi server via SMB and FTP, and read/write from an SGI via NFS or for network installation. 1 It runs on a Raspberry Pi, can be run headless, and requires a network setup. 234 Reanimator has netboot support and can network boot for testing configurations. 56 It can be installed via network or external drive, and is available on GitHub, though the actual disk images are hosted on MEGA. 78 The Reanimator image is hosted on OneDrive. 9 It is a turnkey appliance image, unlike LOVE which provides full source code. 10 Reanimator can install IRIX reliably across different versions, and can install IRIX seamlessly on an Octane, though menu commands are still needed. 1112 It can remove the root password. 13 Reanimator is a Raspberry Pi-based tool for installing operating systems on most SGI systems. 14 It can be used to netboot an Indigo2. 15 Reanimator worked for deploying to an I2 without needing a functioning CD drive. 16
