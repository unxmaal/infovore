C89

Claims: 7 Part of C Background: 1 claim already covered by Wikipedia, see Open64.

C89 is supported by older compilers such as MIPSpro, an SGI compiler that is fast but may lack full C99 support. 1 Using a C89 compiler can offer portability benefits, as C89 codebases can be compiled with ancient compilers. 2 However, C89 compilers can cause build failures, such as ./configure failing with c89, and compiling GCC on HP-UX with a C99 compiler may fail due to bootstrap comparison errors, in which case a C89 compiler should be used instead. 34 The stdint.h header is required for C99 compilers but may be optional for C89 compilers on IRIX, and upgrading to a C99 compiler is recommended for future compatibility. 5 C89 code can avoid the need for a modern compiler by using ifdefs for sized integer types. 6
