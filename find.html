find

Claims: 5

`find` is one of two Unix outliers (along with `dd`) that have unique syntax and capabilities. 1 It can execute commands on found files using `-exec`, which is useful for searching code repositories. 2 Correctly matching filenames requires the use of `-name` or `-iname`. 3 To find executable files, you can use `find -type f -executable`. 4 To find all ELF files in a directory, use `find -print0 | xargs -0 -n5 file | grep ELF`, which processes filenames with spaces safely in batches. 5
