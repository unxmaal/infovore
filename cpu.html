CPU

Claims: 191 Background: 23 claims already covered by Wikipedia, see Central processing unit, Graphics processing unit, SGI Octane, SGI O2.

With O2

The O2 is a single-CPU machine that also uses RAM, and its CPU is a 1-wire device on the O2 riser. 123 The O2 and O2+ have similar cases and CPUs, with the O2+ having a higher revision motherboard and possibly a serial controller improvement. 4 The O2 can use an R12000 CPU running at 400 MHz, and it can achieve 50+ MB/s reads with 4K request sizes; CPUs up to 800 MHz existed at the SGI labs, and you can swap in a 600 MHz model or faster. 567 Overclocking an O2 CPU to 600 MHz was common, often requiring specific parts and adjustments to the system bus. 8 Removing the PCI riser and replacing the CPU can be done on an O2 without issues, though the hostid may need to be changed with sysid, and an O2 can boot and run with a new CPU, SCSI2SD, and SD card. 910 O2 systems received CPU and graphics upgrades during their operational lifespan, but upgrading the CPU can drastically affect graphics output. 1112 O2 video output issues can be caused by a faulty CPU, resulting in solid colors and system hangs, and faulty CPUs can cause issues even if they work intermittently. 1314 The O2 can have an issue with the CPU not being seated properly, causing amber light symptoms, and it can red light due to issues with the power supply, CPU, or other components like the PIMM or MRE. 1516

With RAM

The differences between Sun Lunchboxes are primarily in CPU and RAM type, with some models having Ethernet jacks instead of AUI. 17 The U2 improved significantly over the U1 with better CPU options, more RAM, faster disks, and 24-bit accelerated graphics without sacrificing a RAM slot. 18 The first-gen RS/6000s shipped with a default RAM size of 16MB and ran at approximately 25MHz. 19 The system is currently without RAM and CPU, effectively having 0 MHz CPU and 0 GB RAM, and the 0 CPU configuration has no RAM and no HEART. 2021 The CPU and RAM were loose, and the CPU was unscrewed. 22 Reseating RAM and CPU can resolve lockups and other issues, but reseating the CPU and RAM may not resolve all issues, so inspecting the board for dead custom chips is a next step. 2324 Replacing the CPU, RAM, NVRAM, etc. was necessary to get an SGI working, and replacing the DC-DC board, RAM, CPU, and components like the CGA and battery backplane did not resolve the idle hang issue. 2526 A TLB Refill Exception on a Fuel is likely related to RAM issues, but since swapping RAM did not help, it may be a CPU or motherboard fault, and reseating the CPU and using contact cleaner might resolve it. 27

General

A CPU must have a certain number of transistors and be able to process data to be considered a CPU. 28 Understanding a CPU at the transistor level is crucial for accurate emulation, especially for hardware with undocumented quirks. 29 The CPU is emulated through an interpreter, and OS flexibility allows for non-100% correct CPU emulation, with some self-tests potentially breaking but fixable. 3031 The first step in designing a CPU is to design the ALU and then write it to an FPGA. 32 The CPU is attached to other hardware containing game data, and various boards connect it to fast peripherals, such as the Moto 56k DSP board and the system bus board. 333435 The CPU can be manually set to different clock speeds, such as 250 MHz for an R10k or 333 MHz for the PSP's MIPS R4k, and the initialization code in PROM sets up multipliers and other parameters affecting its effective clock speed. 363738 The CPU may also be limited by the mainboard, though any 2x600 CPU works, and a CPU with 65W TDP draws up to 80W. 3940 The CPU may experience issues such as not responding, being faulty, or having voltage problems, which can sometimes be resolved by replacing the CPU, cleaning and repasting it, or power cycling. 41424344 Reseating the CPU can resolve issues related to dust accumulation or poor contact between the CPU, mainboard, and GPU, and can sometimes resolve other system issues. 454647 If a CPU installed in an SGI system is not compatible, the system may have issues and may need the PROM flashed. 48 The VME bridge hangs off the CPU directly, similar to being parallel to the Sbus. 49 The Octane supports a variety of CPU, IO, and graphics options, with dual-CPU and MXI/MXE recommended for optimal performance, and V10 or V12 CPUs are suggested for the Octane2. 5051 The Crusoe offered usable performance with less power, possibly due to architectural design and IBM's new 5+ layer copper process fab. 52 A CPU can draw significantly more power when installed than when not installed, and a short circuit on the CPU can cause a power supply to overload. 53 The CPU draws 120 watts, so it is likely dead, and may show no activity beyond a clock signal, in which case a replacement CPU should be tried. 5455 A CPU with a single pulse on power up and one more on soft shutdown might be fried, and a CPU may have a 36 ohm VCC/GND short. 5657 The CPU pins may be corroded, but the tantalums tested good out of circuit. 58 Reseating and swapping CPUs did not resolve the issue, suggesting a possible dead motherboard. 59 A G5 Quad's CPU can fail due to thermal shock and may require reballing, and the CPU is not socketed with an integrated GPU, requiring a motherboard upgrade to replace it. 6061 The CPU under the heatsink can reach over 80 degrees Celsius, and heat from the CPU may cause minor warping of the board, affecting contact. 6263
