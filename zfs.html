ZFS

Claims: 80 Background: 45 claims already covered by Wikipedia, see ZFS, FreeBSD, Oracle Solaris.

ZFS is a file system used for storage that offers data integrity features such as end-to-end checksumming with regular scrubbing, a multiple-copies feature for corruption protection on a single disk, and mechanisms to avoid the write hole by ensuring data integrity during writes. 1234 ZFS avoids the write hole by updating blocks on disk and then updating filesystem info only after the blocks are on disk, ensuring data integrity in case of power loss. 35 ZFS is used on Solaris, which is actively developed, and is also available on FreeBSD and other systems, with TrueNAS running on ZFS. 6789 Solaris 10 ZFS pools are compatible with OpenZFS. 10 ZFS is not mainlined in Linux because Linus Torvalds does not want it, though Canonical shipped in-kernel ZFS on Ubuntu server 20.04 despite licensing issues. 1112 ZFS requires a fixed number of disks at setup, with easy migration to larger disks but not resizing the pool, and adding disks requires creating a new vdev or pool rather than incrementally adding to an existing vdev. 131415 ZFS allows replacing a disk with a larger one but not a smaller one, and does not support mixed sizes in the same vdevs for striped pools. 1617 ZFS can use 5 disks with RAIDZ2 for Z2 and 6 disks for Z3, providing 4x usable capacity with 2 disk redundancy. 18 ZFS is a resilient file system that is reliable and easy to manage, but not necessarily fast out of the box, requiring substantial RAM for optimal performance (2GB is barely sufficient, while 8GB is recommended, and more is better) and workload-specific tuning (tuning variables are similar across platforms). 1920212223 ZFS is optimized for systems with 32GB of RAM or more, and running it requires investing in an entire node that can run ZFS and specifically cannot run VMware. 2425 ZFS is not backwards or cross-platform compatible, and migrating off ZFS or to Linux-ZFS causes pain due to the rebase from OpenSolaris to ZOL leaving FreeBSD in a bad situation. 2627 ZFS is interoperable between Solaris and FreeBSD with careful pool version management, and ZFS on Linux can do encrypted snapshot-based incremental backups. 2829 ZFS is preferred over hardware RAID controllers that abstract drive access, and compression can speed up disk operations by saving disk bandwidth, which is more scarce than CPU. 3031 ZFS setup is simpler than UFS because ZFS does not require partitioning the disk, and Truenas Scale is easy to use for managing storage with ZFS. 3233 ZFS is used for large file writes and occasional random access, with patterns similar to surveillance video storage, and is reliable for data integrity and can be used for backups between servers or tape. 3435 ZFS is still notable today, and Sun's ZFS was not a disaster when new. 3637
