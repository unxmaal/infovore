1MB RAM

Claims: 6 Background: 1 claim already covered by Wikipedia, see Amiga.

Several machines have 1MB RAM: the Apple IIe Platinum, an Atari ST, the Amiga (which has a 68000 CPU and an OS in ROM), and the Contel/CADO/VERSYSS Tiger ATS-8e (which has a 39MB HDD and an Intel 80186 CPU, released in 1985). 1234 Every Mac with 1MB RAM or more can run OS 7. 5 Running OS 7 with 1MB RAM is like running Windows Vista on a P6 Celeron. 6
