directory opus

Claims: 4 Part of directory

Worker is a file manager for SGI platforms, succeeding DirectoryOpus or DirOpus, which was popular on Amiga 30 years ago. 1 It requires many dependencies and cannot be easily packaged as a tarball. 1 For many tasks, Directory Opus is more efficient than command-line tools alone. 2 Directory Opus has buttons on the bottom that take up too much space. 3 It looks ancient enough for IRIX. 4
