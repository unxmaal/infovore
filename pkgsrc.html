pkgsrc

Claims: 65 Background: 12 claims already covered by Wikipedia, see Pkgsrc, NetBSD, VAX, Wget.

pkgsrc is a source-based package framework that ships source code and works across multiple supported systems, including NetBSD, IRIX, Solaris, HP-UX, VAX, FreeBSD, and Tribblix. 123456 It is considered the shortest path to compiling modern, current open-source packages on IRIX, and it can be pulled from https://github.com/sgidevnet/pkgsrc for building software. 178 pkgsrc traditionally aimed to support OSes other than NetBSD and used to have working cross-compilation support, though it can also be used to cross-compile via a cross-compiler VM. 9106 The process for installing pkgsrc involves installing a working version of GCC, extracting pkgsrc to /usr/pkgsrc, running pkgsrc's bootstrap, and then installing libgetopt. 11 The pkgsrc bootstrap process works with a plain installation of gcc 8.2.0, requiring only CC and CXX environment variables set to point to the gcc and g++ executables. 1213 pkgsrc's bootstrap script makes incorrect assumptions and shoves them into global settings, and it requires a properly set LD_LIBRARY_PATH or LD_LIBRARYN32_PATH to compile. 1415 pkgsrc is complex and has failed to compile packages properly on IRIX, with libtool being a main blocker. 1617 pkgsrc's libtool needs fixing to correctly place compiled objects during builds, as libtool fails to copy bins from lib/ to the directory where it's putting stuff for packaging in pkgsrc. 1819 pkgsrc is a cross-platform port system originally from NetBSD and works with OpenBSD, Linux, FreeBSD, and Solaris. 20 pkgsrc source code is typically stored in /usr/pkgsrc, but can be mounted elsewhere for more space. 21 Using CVS to check out pkgsrc is slow initially, but tarballs are faster. 22 A proper GNU environment is recommended before working with pkgsrc. 23 The README for pkgsrc lists a specific GCC binary to use. 24 pkgsrc does not support multilib, but you can use `--abi` for GCC. 25 You can compile your own packages from pkgsrc, and there's a good chance it will work. 26 pkgsrc has deviated quite a bit from what it was back in the day. 27
