command

Claims: 8

The syntax to send a command to a specific brick is `<brick id>: <command>`, for example `001c01-L1>001v02: dsp 1 test`, and the space between the colon and command can be tricky. 1 Some commands may not be valid in a given install, such as `xfs_fsr`. 2 `tar -tf <filename>` lists the contents of a file without extracting it. 3 SCSI commands can be sent, as seen in messages reporting `Sending SCSI command` sequences. 4 Using caps lock as control on Linux and command on Mac can help with learning new keyboard bindings. 5 A stand fx can encounter an aborted command due to a message reject error and a warning about failing to open the scsi device. 6
