Nekoware packages

Claims: 6 Part of nekoware

Nekoware packages are commonly installed using an installer, and the installation process requires running commands as root using *su*. 12 A script called nekodeps.pl must be edited to point at the repository for installing Nekoware packages. 3 One approach involves using a shell script to untar Nekoware packages into a separate folder and pointing swmgr at that folder to auto-resolve dependencies. 4 A backup of Nekoware packages shared by user-8547 with Raion contained directories such as contrib, mips3, and obsolete. 5 curl or wget for IRIX 5.3 may be found in old Nekoware packages or on CDROMs, but accessing them requires resolving dependencies. 6
