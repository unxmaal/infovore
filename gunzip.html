gunzip

Claims: 6

gunzip cannot handle multi-entry .Z files; use uncompress for SGI systems. 1 To install software in .tgz format on IRIX, first use gunzip to decompress it to .tar, then tar -xvf to extract it. 2 IRIX's tar did not support built-in gzip decompression, so the method gunzip -c <archive> | tar -xvf - extracts a gzip file and then extracts its contents without damaging the original file. 3 gunzip is needed to decompress .tardist files on IRIX 5.3. 4 gunzip is not found in IRIX 5.3 installed from burned CD 812-0323-001, and while installing gunzip failed previously, zcat is available as a workaround. 56
