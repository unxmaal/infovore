Unix kernel

Claims: 8 Part of Unix Background: 1 claim already covered by Wikipedia, see SATA.

The Unix kernel must be loaded from somewhere before booting, and it can be started from SCSI and handed over to SATA or loaded over the network. 12 Loading 'unix' over the network loads drivers to access the disks on a PCI-X SATA card. 3 The IRIX kernel does not share code with the regular Unix kernel, though older Unixes had shared libraries for low-level routines like terminal I/O and simple drivers, which reduced code duplication over time. 4 A Unix kernel for Z80 machines with 64kb RAM uses the upper 32kb for itself and swaps the lower 32kb to disk during task switches, making it thrash. 5 The MachTen 2.3 ISO contains Unix files, including a Unix kernel, but the 68k version runs more 'real' Unix as it takes over the Mac rather than running as a process. 6 Rebooting from a backed-up Unix kernel allows the system to reconfigure itself during boot, leaving a new unix.install behind, but the apps may not work correctly. 7
