3dxsrv

Claims: 3

The 3Dconnexion X driver (3dxsrv) communicates with applications via X ClientMessages and requires the motif UI to function. 1 There are two ways to use a 6dof device on IRIX: as an Xinput device with built-in IRIX drivers, or with 3dxsrv, which sends input through a custom XClientMessage protocol. 2 spacemice require the 3dxsrv or spacenavd driver, while spaceballs should work with xinput. 3
