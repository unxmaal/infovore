autoconfig

Claims: 3

autoconfig is a command that recompiles the kernel, as invoked with the -vf flag. 1 After a kernel update, autoconfig can fail during linking due to missing NFSv3-related symbols, which prevents CDs from being mounted. 2 An O2 running IRIX 6.5.22 can kernel panic at boot after issuing an autoconfig command, a problem fixed by upgrading to 6.5.30. 3

Sources

  2. After a kernel update, CDs cannot be mounted due to autoconfig failing from missing NFSv3-related symbols during linking. (user-1fc3, 2023-05-29, exchange 93159, check: uncheckable)
  3. The O2 running IRIX 6.5.22 can kernel panic at boot after issuing an autoconfig command, which was fixed by upgrading to 6.5.30. (user-8547, 2024-03-15, exchange 218326, check: supported)
