Fortran

Claims: 13 Background: 1 claim already covered by Wikipedia, see IRIS GL.

Fortran is a compiled language designed for scientific computing, and it produces the fastest programs of any compiled language for high performance number crunching, being stable and high performance. 12 It is a scientific language, in the way that Cobol is for business. 3 The PathScale EKOPath compiler and gcc both offered Fortran compilers, with gcc having done so for a long time. 45 The Fortran syntax for ending a program can be `end` or `end program`, but the latter may cause errors, so `end` should be used with 6 spaces before it. 6 Fortran has been used for high performance computing tasks such as fluid dynamics simulations and geo simulations. 78
