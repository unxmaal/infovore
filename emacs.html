emacs

Claims: 55 Background: 14 claims already covered by Wikipedia, see Emacs.

Emacs is a text editor for Unix systems that can run tutorials when started, and it was ported to IRIX. 12 Emacs is available in irixports as version 24.5.1, and IRIX also has a built-in text editor named nedit. 3 Emacs can be built with various configuration options, including Motif or GTK3 as the GUI (with Motif generally running better), XPM support, and libXm. 456 Building Emacs on IRIX requires patches for certain versions, such as changing %td to %d in make-docfile.c, and may need additional fixes for proper compilation and functionality. 7 GCC on IRIX requires math.h to build Emacs, which must include NAN and INFINITY, and the mkheaders tool is used to fix pthread errors during configuration and build. 89 Emacs regenerates .c files as part of the build process. 10 Emacs can use libtiff and libjpeg for displaying images, such as in web pages viewed with w3. 11 Emacs can be used for more involved tasks than simple editing, and since everything is in elisp you can basically get whatever you want running no matter what platform you're on. 1213 Emacs is often used for programming and can have many files open at once, up to 50-100. 14 Emacs and Neovim can be used as IDEs, supporting features like go to declaration and find references. 15 Emacs runs on Linux and a Lenovo laptop. 16 The first version of Emacs was actually just a funky configuration for TECO. 17 There is an actually-usable version of Emacs available, compatible with a 486DX33 and fully implementing lisp. 18
