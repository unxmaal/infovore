clientip

Claims: 3

The O2 booterizer sets the host IP for the VM and the client IP for the SGI, allowing users to configure static IPs on their network. 1 The instructions for booterizer tell you to set the clientip to 192.168.1.x, which you should change later. 2 To connect to an Octane via booterizer, use the command monitor to set the netaddr to the clientip configured in Booterizer's settings.yml, then boot into the partitioning utility with `bootp():/6.5.22/Overlay/disc1/`. 3
