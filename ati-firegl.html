ATI FireGL

Claims: 4 Part of ATI

The Onyx4 is a high-performance SGI system that uses ATI FireGL cards, offering performance up to 12x faster than the V12 Pro, though it is incompatible with IrisGL and requires a different X Windows configuration, and it supports DVI outputs for high-resolution use. 1 The RAM on r300/r350 based ATI FireGL cards can cause artifacting, which can be fixed by reflowing the RAM or the main chip. 2 A quad CPU C8000 with ATI FireGL X1 or X3 can provide performance comparable to Tezro. 3
