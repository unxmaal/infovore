24-bit color

Claims: 11

IRIX supports any image format listed by imgformats, but requires 24-bit color enabled, starting from version 6.5.22. 1 The VSIMM on an SS20 provides native 24-bit color on the motherboard framebuffer. 2 Quake on IRIX may have issues with 24-bit color, and glQuake typically needs to run in 24-bit color, though software rendering may not work in that mode. 34 XWindow creation requires specific properties for 24-bit color; otherwise, 8-bit color is used. 5 A V6 cannot run 24-bit color due to insufficient framebuffer memory for 24-bit visuals, requiring a resolution reduction or fixing the code. 6 The ZX board in the SS10 is a great 2D board with accelerated 24-bit color and LUT palettized 8-bit Windows support. 7 Xsgi does not default to 24-bit color; applications must request it, requiring a settings update. 8 The original Clover1 graphics supported 24-bit color. 9

  8. Xsgi does not default to 24-bit color; applications must request it, requiring a settings update. (user-e872, 2024-12-14, exchange 218646, check: supported)
  9. The original Clover1 graphics supported 24-bit color. (user-86e1, 2025-07-06, exchange 225245, check: supported)
