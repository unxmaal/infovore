mount

Claims: 19

The mount command mounts an image file with a specific file system type, and it supports loopback mounting of ISO images in IRIX 6.5. 12 To mount an EFS formatted ISO on IRIX, use: mount -o loop,ro -t efs your_disc_image.iso /your/mount/point. 3 The 'mount' command with the 'efs' type is used to mount ISO files. 4 The command to mount an XFS image is `sudo mount -t xfs xfs.img /mnt/xfsimage`. 5 mount can show NFS version information. 6 The bg option for mount retries in the background, while fg retries in the foreground and blocks further processing until complete. 7
