Ethernet controller

Claims: 6 Part of Ethernet

The Ethernet controller is a Broadcom BCM5704, while the SCSI controller is a QLogic QLA12160. 1 The chip supports 10/100Mb, but the physical interface appears as 10Mb-only because a transceiver on the back connects via a cable to the I/O board half. 2 The Indy's Ethernet controller tops out at 8Mb/sec sustained, which is effectively wire speed for 10Mb Ethernet. 3 A single-stepped 6502 can be used with an Ethernet controller. 4 Transferring files to a Windows 98 machine required burning CD-Rs until an Ethernet controller was installed. 5
