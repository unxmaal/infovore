SSH

Claims: 55 Background: 13 claims already covered by Wikipedia, see Secure Shell, Remote Shell, X Window System.

SSH is an old-school remote access protocol that provides a terminal session on the remote machine. 1 It can be used for login, copying files, and remote access with X11 forwarding. 2341 The command 'ssh -Y' enables trusted X11 forwarding for remote graphical sessions. 56 X11 forwarding over SSH can be slow due to crypto overhead, so X11 compression should be enabled. 78 SSH has been ported to various systems, including IRIX, A/UX, and 68k Macs, and can serve as an alternative to IRC clients or telnet/RSH. 9101112 SSH can encounter issues such as client or configuration errors, timeouts during cloning, and failures caused by VirtualBox kernel module problems. 131415 SSH can create tunnels to forward connections to specified ports, and can be used with the -R option to create a remote port that redirects to a port on the firewall. 1617 ssh and rsh use stdin/stdout to pipe commands, allowing remote execution of dd, tar, or xfsdump, and xfsdump output can be piped to ssh or rsh for remote backup execution. 1819 NFS, SSH, and RSH are different network protocols. 20 ssh can be a symlink to rsh under alternatives on Debian, and rsh can be installed with rsh-client. 21 Irix 6.5.2x supports ssh, scp, and git. 22 TLS and SSH key management is resource-intensive on NetBSD. 23 The R4600PC-100 has telnet but not SSH, and its SSH daemon is slow and may time out during key negotiation. 24 Connecting to the MCP server can be done via SSH for IRIX 6.5/6.2 or using a TCP/inetd/TCP wrappers method for IRIX 5.3, and netcat on Windows, macOS, or Linux. 25
