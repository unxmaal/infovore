X forwarding

Claims: 13 Part of X

Remote access to IRIX can be achieved via SSH and X forwarding, with period-accurate remote desktop software existing but not used by the speaker, and Windows users able to use Xmanager 6 for remote access. 1 X forwarding can be set up by launching the desktop app over ssh -X, and X11 compression should be enabled for SSH X forwarding, with some clients requiring it to be specified. 23 ssh -Y works perfectly for X forwarding from IRIX to macOS, and X forwarding is possible with SSH and can be faster than MAME. 45 X forwarding can cause image corruption on the IRIX side, but Netscape renders fine, and this is not unique to the user. 6 X forwarding requires Xming and PuTTY, with Xming installed and X forwarding enabled in PuTTY, and setting the DISPLAY variable to the IP address of the Windows computer. 7 X forwarding can cause image corruption on the IRIX side, but Netscape renders fine, and this is not unique to the user. 6 Running a modern browser on a Raspberry Pi 0 and X-forwarding it to an O2 was slow and janky. 8 Underclocking the Indy's CPU can improve interactivity, and disabling the graphics adapter can enhance performance through X forwarding. 9
