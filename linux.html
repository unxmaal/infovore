With IRIX

Linux and IRIX are both UNIX-based systems, so they share a similar file folder structure, though there are differences such as IRIX storing user home directories in /usr/people/<user> and the root user's home in /usr/people/root, whereas Linux typically uses /home/<user> and /. 123 Linux cannot run on the same hardware as IRIX, but one can cross-compile packages on a Linux host for an IRIX machine, use a Linux VM to compile IRIX code with GNU tools, or mount IRIX CD images in Linux and transfer the contents to IRIX for installation. 4567 Linux can natively mount XFS filesystems used by IRIX, read XFS Jaz drives formatted on IRIX (though 64-bit timestamps may cause issues), and mount SGI-format ISO files using the EFS kernel module to share via NFS. 891011 NFS works between IRIX and Linux, and IRIX cannot mount loopback devices such as images while Linux with the EFS kernel module can. 1213 Various software runs on both Linux and IRIX, including CMake, Cosmo-format support via Cinepaint and GIMP, Blender, Electrogig, and the Wumbo codebase. 141516171819 Linux and IRIX share similarities in tools such as the esd audio server, chkconfig flags, and CLOCK_SGI_CYCLE for hardware counters, and IRIX can be installed from Linux using TFTP. 20212223 Linux and IRIX share software in both directions: IRIX features were ported to Linux distros, and Linux software such as the 4DWM window manager was ported to IRIX, though nothing surpassed 4DWM in quality. 242526 SCSI support overlaps between the systems, with IRIX SCSI code portable to Linux requiring mainly Makefile and SCSI API adjustments, though Linux checks whether a SCSI CD drive is writable before allowing read-write access. 2728 XFS support in modern Linux depends on the OS version, being able to mount late IRIX XFS but not early versions like IRIX 5.3, and the older Linux software accepted keys from the old IRIX keygen. 2930 Linux was often chosen over IRIX due to cost, and an IRIX UI for Linux called IRIX for Linux exists. 3132

With SGI

XFS was included in Linux due to SGI's Itanium efforts for HPC customers. 33 Linux benefited greatly from SGI's contributions, including a huge amount of kernel work to get Linux to run on more than one CPU and then scale to hundreds. 3435 Sgi open sourced a lot of their software when moving to Linux. 36 NFS shares worked across SGI, Linux, and Mac systems for easy file movement. 37 Mistika is a version of jaleo with a different UI, available for SGI and Linux. 38 Linux was being pushed in the visual workstation days, so it never happened on SGI, and although SGI ported Linux, it didn't gain much traction. 3940 The SGI community had extreme Linux hate, despite Linux servers becoming popular. 41 HP now uses the SGI moniker for supercomputers running x86 CPUs with Linux distributions. 42

With BSD

Linux and BSD are both used across a wide range of hardware, including Alpha, Power, IA64, and SPARC systems, with BSD sometimes offering better hardware support in certain cases and Linux in others. 43444546 Both kernels provide Big Endian PowerPC support, and both are needed to burn EFS disk images. 4748 Xash3D supports Linux and BSD, and some older Linux and BSD distributions included olvwm, though without additional tools like the file manager, cmdtool, and workman. 4950 Linux supported XFS due to SGI's code contributions, while BSD implemented its own version, likely less feature-complete. 51 BSD has been around for a long time but hasn't gained as much traction as Linux. 52
