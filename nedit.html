nedit

Claims: 24 Background: 2 claims already covered by Wikipedia, see NEdit.

nedit is a text editor available on IRIX, where it is built in and works well, and it is also used on other systems such as Solaris and macOS. 123 It is a point-and-click editor with syntax highlighting, line numbers, and compilation features, and it can also be used as a GUI text editor or IDE alongside tools like Metrowerks Codewarrior. 45 It supports search and replace, hotkeys for some actions, and can be opened from a non-sgi-nurbs shell and displayed on regular X terminals. 6789 It can be configured through settings such as setting EDITOR and VISUAL to nedit, and setting NEdit*useSchemes: false in .Xdefaults to prevent it from using schemes. 1011 It is included in misc-5.3-files.iso along with tools such as unzip, bzip2, gimp, and netscape, and a comparison of anti-aliased fonts in nedit is available. 1213 It is more sophisticated than the simpler editor jot, which is a wrapper for nedit that translates command-line arguments for compatibility and could not display on regular X terminals. 141516
