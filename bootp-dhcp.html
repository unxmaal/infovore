BOOTP/DHCP

Claims: 3

The netboot process described in the Jurassic NL manual uses PXE, which combines BOOTP/DHCP and TFTP, and can be set up using HTTP for the rootfs, which is slightly easier to set up than NFS. 1 The OpenBSD boot process for SGI machines involves determining IP via BOOTP/DHCP, loading a kernel via TFTP, kernel starting, determining IP, asking Bootparamd for root and swap paths, and mounting root via NFS. 2 In /etc/bootparams, root and swap paths are specified using NFS. 3
