fm

Claims: 4

fm is a program that has been crashing on the system, producing a corefile, and is associated with 4dwm, iconcatalog, and clogin, which have also been crashing. 1 Running fm from a terminal might give clues about installation issues, though a reboot did not help, and a Cineon installation caused problems. 2 The find command can list modified files, and tcsh requires different syntax for output redirection. 2 A ~/.icons/login.icon that is a TIFF file causes crashes in fm, xdm, and imgview. 3 If the PSU is not working, the system board might be the issue, and reseating the CPU and using deoxit can help. 4
