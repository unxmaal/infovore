freeglut

Claims: 13 Background: 2 claims already covered by Wikipedia, see CMake, OpenGL.

FreeGLUT wraps OpenGL calls into utility functions for multiple platforms, allowing platform-independent window creation, OpenGL initialization, and input handling. 1 It can be compiled on IRIX 5, IRIX 6, Windows, and Linux, and builds and works on IRIX 5.x and up. 23 On IRIX 5.3, freeglut requires GLX 1.3 and OpenGL 1.0 fallbacks and can use the old glXChooseVisual/glXCreateContext API instead of the GLXFBconfig one, and it can be compiled as a shared library but requires cmake 3.1, which may not be available on IRIX. 45 It can be installed on Solaris 2.8 with Java. 6 On Linux (tested on arm64 Raspberry Pi), there is an issue with drawing text when texturing is enabled, which is resolved by disabling texture mapping before rendering text. 78
