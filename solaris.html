Solaris

Claims: 376 Background: 24 claims already covered by Wikipedia, see Oracle Solaris, ZFS, Adobe Photoshop, HP OpenMail, OpenGL, X86-64.

With IRIX

Blender, neofetch, and Mousepad were all available on IRIX and Solaris, and WordPerfect worked on both systems as well. 1234 pkgsrc may need to be addressed when installing software on both Solaris and IRIX, and tgcware is still active on Solaris but not updated for IRIX. 56 Ctrl-H and Ctrl-W can be used as backspace keys in console environments like IRIX and Solaris, and Barrier can trap out to OF on both by sending a break on the serial console. 78 Both Solaris and IRIX generally install X11 by default and boot into it when a display and keyboard are connected, and both are reasonably complete without missing weird pieces. 910 Solaris has a more recent branch and more features than IRIX, and is more widely supported, though IRIX is considered cleaner, better documented, and more user-friendly. 1112131415 Solaris uses /usr/ccs as its C compilation system and devfsadm for autoconfiguration, whereas IRIX lacks both /usr/ccs and pmap and controls autoconfiguration via /etc/autoconfig. 161718 IRIX is compatible with Solaris and the BSDs but not with AIX or HP-UX, and both were among the UNIX-like operating systems available alongside HP-UX, AIX, A/UX, and others. 1920 Solaris and IRIX were among the Unix packages available on the Wayback Machine, alongside DEC, M86k, and HP-UX. 21 Both Solaris and IRIX lack terminal emulators, and both exhibit demo limitations such as horizontal lines in renders. 2223 IRIX has a different internal structure than GNU/Linux, with a distinct scheduler and closer similarities to Solaris. 24 Solaris included developer tools and libraries in the base system, while IRIX required additional software such as IDO. 25 All major Unix workstations, including Solaris and IRIX, were 64-bit capable by 1999, unlike PCs and Macs. 26 People chose Linux over IRIX and Solaris due to cost. 27

With AIX

Solaris and AIX are commercial Unix operating systems that remain in use, with both still offered through certifications as the last two commercial Unix vendors standing. 28 AIX is considered more challenging than Solaris. 29 Several systems supported both operating systems: the HP Workstation could install HPUX, Solaris, and AIX, and the RS/6000 type 7248 supports AIX, NT, Solaris, and OS/2. 3031 Some software existed on both Solaris and AIX, including software on SunOS and Solaris, and WP was ported to Solaris and AIX among other systems. 3233 The HP SureStore magneto-optical library used 5.2GB MO discs and was used with AIX before being converted to Solaris, and swapping over NFS was supported by both SunOS, Solaris, and AIX. 3435 Both systems were used in operational contexts, with support operations run on Solaris and RTC requiring a move to AIX, and DISA STIG guides for Solaris can be adapted for AIX. 3637

With Linux

SPARC hardware is transitioning to support Linux over Solaris, and Fujitsu pivoted to the A64FX due to Solaris winding down and Linux having poor SPARC support. 3839 Solaris was more advanced than Linux or BSD at one time and was a first-class citizen for many OSS projects in the late 90s, but its support has declined with Oracle's focus on x86 systems. 4041 Solaris is not buggy compared to Linux, though it misses some GNU additions, and Linux accepts most random PCI hardware that Solaris does not. 4243 SPARC can run Solaris, Linux, or BSD, and a Solaris/Windows/Linux emergency CD saved the day. 4445

General

Solaris is a Unix operating system that has been ported to multiple architectures, including x86 (starting with version 2.4), Itanium, AMD64, and SPARC, and it runs on systems such as the Ultra 45, V1280, and T3-1 (which supports Solaris 11.3 but not later versions). 464748495051 The system is known for being predictable and stable, and it uses the ZFS file system, which is available without requiring FreeBSD. 525354 Development of Solaris continues through Alan Coopersmith after the Sun-Oracle merger, though Oracle has discontinued official development and its future has been impacted by decisions such as dropping Solaris 12 in favor of an update stream for version 11. 555657 Installation involves entering network information, and on Solaris versions before 10, root's shell must be set to /sbin/sh to avoid issues with the shell not being executable, a problem fixed in version 10. 5859 A variety of software has run on Solaris, including MATLAB, Maple, CATIA, CATIA 5, Blender 2.53, Internet Explorer, MAME, and GCG, and most open-source software of the era compiled on Solaris without changes. 6061626364656667 Solaris supports a range of hardware, including the SunPCI co-processor card (which runs a PC environment inside Solaris and can run Windows NT), and various graphics cards such as ATI Rage XL, Mach64, Radeon 7000, and NVIDIA drivers. 68697071 Solaris boots similarly to Macs and RS/6000s, uses a deterministic and sticky device numbering system, and offers documentation that can be scattered and poorly documented. 727374 Solaris is a Unix operating system that Sun Microsystems made a significant effort to open up, having licensed from AT&T rights equivalent to ownership of System V, which other SysV derivatives did not have. 7576 Solaris had an x86 release as early as Solaris 2.1, and a standard install of Solaris 2.5.1 with patches was used on a machine in the late 90s for a decade. 7778 Solaris uses SysV init, has logical volume management, and uses a convention like 'c0t3d1s3' for disk naming, which can be cumbersome when moving disks. 798081 Solaris does not show unconfigured devices, but they can be configured with 'ifconfig hmeX plumb' and 'ifconfig leX plumb'. 82 Zones in Solaris can emulate different environments including Solaris 8, 9, or 10, and Linux, and can use branded zones for additional functionality. 83 Oracle added and maintained a port of GNOME for Solaris, and Nvidia still develops graphical drivers for Solaris, including x64 Quadro drivers due to NASA's use. 848586 Oracle hasn't shipped a machine with a GPU since the Ultra45, and keeping newer Solaris versions around is less hassle due to active support, whereas older OS releases like SunOS are no longer maintained. 8788 SunOS and Solaris less than 10 are considered abandonware and no one cares about their distribution. 89 Solaris is a SysV-derived operating system that was POSIX certified, though the certification list is no longer maintained. 9091 Solaris uses the pkgadd package installer, with package names formatted like SUNWwhatever (e.g., SUNWdt for desktop). 92 System overview and hardware diagnosis can be performed using commands such as prtconf, prtdiag, dev / ls, and fbconfig. 9394 Oracle now delivers Solaris updates through SRUs. 95 Solaris can run CAD software such as BRL-CAD and Cadence FlexLM, though licensing may be an issue. 9697 ZFS pools can be shared between Solaris and FreeBSD with careful pool version management. 98 Solaris x86 and the open-source initiative beginning with version 8 contributed to its longevity. 99 Solaris is a Unix operating system that ran on platforms including SPARCstations, HP-UX, IBM RS/6000 AIX, SGI, and Siemens Nixdorf machines, and was available for applications such as WordPerfect 6.0, Informix, CATIA v5, Pro/E, and Win16 applications. 100101102103104 Solaris supported SMP better than SunOS 4, though CPU performance remained poor, and it could be cross-compiled using gcc/clang and Sun Studio. 105106 Apple considered running Mac OS on Solaris using SVR4 (2.5.1 or 2.6), similar to A/UX, and also considered using Solaris on PowerPC. 107108 Solaris can host Mac environments with a potential X11-based toolkit, though this is uncertain. 109 Solaris uses /etc/fstab instead of /etc/vfstab, and uses a RAM disk for /tmp, which can lead to issues if /tmp fills up. 110111 Solaris can do IP multipathing, but it is fiddly, and it can be cross-compiled using gcc/clang and Sun Studio. 112106 Solaris boot time can be long, around 35 minutes, and the Ultra 10 requires OBP firmware to boot Solaris. 113114 A bad RAM stick can prevent a Solaris installer from booting, and booting Solaris in single user mode may allow formatting the second IDE drive. 115116 Solaris is a Unix operating system, with Solaris 2.0 through Solaris 9 forming one related family, while Solaris 10 is considered a departure from that lineage. 117 Software available on Solaris includes Alias StudioTools 9.5, SolidWorks, CATIA and ICEM Surf, Catia V5 R9, Cadence VLSI layout designer, Photoshop, and Cisco IOS running as a userspace process. 118119120121122123124 Graphics libraries on Solaris include GL, which was included starting around version 2.5.1 or 2.6 with U1E/U2, and SunPHIGS, which was relevant until OpenGL was added to Solaris/SunOS in Solaris 8 and later. 125126 Building software on Solaris can be difficult, often requiring code modifications such as patches for Blender, type casts for GCC char/char* mismatches, NO_INET_NTOP and NO_INET_PTON flags for git, and the use of -L and -R instead of LD_LIBRARY_PATH. 127128129130131 Solaris versions before 10 had significant issues with USB mass storage and hot-plugging, could fail to boot or mount partitions if CSW packages were removed, and could become unstable after networking changes. 132133134 Administrative tasks on Solaris include network installation via setup_install_server and add_install_client, Jumpstart installation over the network, tape drive reconfiguration involving device file removal, and flashing the LSI 1064 SAS/SATA controller with raidctl. 135136137138 Other Solaris characteristics include Xsun being a poorly designed default X server, the move to GNOME being considered a mistake, the machine type variable needing to be set to avoid weird behavior, and the / partition being limited to 2GB in 32-bit Solaris. 139140141142 Solaris was installed on the machine, and Sun offered it across a wide range of machines, from the SPARCcenter 2000 to the SPARCclassic, with the latter running Solaris 2 on 16MB of RAM being particularly challenging. 143144 Solaris matured around 1993-1994 and had advantages over Slowlaris, and support is committed to until at least 2035, though it may be cut short. 145146 Subversions of Solaris, such as the 2.6 release 5/98, are just patches, and Solaris is one of the operating systems where running an unsupported release is not advisable. 147148 Solaris installs are easier and can work reliably with defaults, and there is an update server for software updates. 149150 Setting up networking in Solaris is done via editing config files in vi through the terminal, and the route command can be used to add network routes. 151152 Solaris 10 supports nfsv3 and nfsv4, and most almost-modern Suns can drive the serial port up to 57kbit with Solaris. 153154 Solaris can run GL2 demos and diagnostics because it is POSIX compliant, and Photoshop 3 runs easily on Solaris. 155156 Solaris can have issues with GNU-linked software, requiring emergency mode with statically linked tools to fix, and it has a statically linked ls and ln. 157158 Solaris is a Unix-based operating system that runs on SPARC and UltraSPARC hardware, including Sunblade, Blade 100/150, and Ultra5/10 machines, though it is also available on other systems. 159160161162163 Using Solaris requires learning basic Unix tools and configuration such as sudo and the shell. 164 Solaris can be stripped of unneeded services for better performance, and Tribblix is a Solaris-based distribution for SPARC systems. 165166 Several applications run on Solaris, limit and can show port 111 when running nmap. 172173 Solaris is a commercial Unix system that has existed since 1992 on x86, and it was one of the best commercial Unix systems. 174 SunOS and early Solaris versions had applications like MATLAB, FrameMaker, SoftWindows, and MAE. 175 Solaris was not compatible with older Sun machines, and many users were unhappy with the switch from BSD to SysVr4. FMA. 178 gcc 5.x is the latest pre-packaged version for Solaris but gcc supported Solaris up to version 9. 179
