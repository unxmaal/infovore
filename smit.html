SMIT

Claims: 5 Background: 3 claims already covered by Wikipedia, see IBM AIX.

SMIT (also called smit or smitty) is a menu-based vendor tool for Unix systems, specifically AIX. 123 It can be used to install packages and hardware drivers. 24 SMIT can display or output the commands it runs, which is useful for later manual use. 235
