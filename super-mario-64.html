Super Mario 64

Claims: 10 Background: 1 claim already covered by Wikipedia, see Video games and Linux.

Super Mario 64 didn't start development until September 1994, so a July 1994 SGI test must have been early. 1 A decompiled version of Super Mario 64 was released, allowing recreation of the original source code with debug symbols and low optimization, making it identical to the source seen by the original programmers, so the full source code for Super Mario 64 is available. 23 Linux can be made to look like IRIX 5 or IRIX 6, potentially for Super Mario 64 compatibility, with sm64ex providing the OpenGL renderer for running Super Mario 64 on IRIX. 45 Commenting out texture-related OpenGL calls can make Super Mario 64 run texture-less. 6 Most of Super Mario 64's textures came from a Japanese photo library CD, and the environment map for Metal Mario is the flower image, which can be found online. 7 demo.elf contains code related to Super Mario 64, possibly from a beta version with references to Moto. 8 Closing some software sets the system sound to 8kbps, affecting games like Quake2 and Super Mario 64. 9 Super Mario 64 on an O2 or Octane would be a cool thing. 10
