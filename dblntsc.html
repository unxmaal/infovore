dblntsc

Claims: 3

Setting the display to 704x480 requires the dblntsc executable to be in the monitor prefs drawer, and missing this can prevent a full screen display. 1 The overscan.prefs patch is supposed to fix the limited resolution available, but it is not working for the dblntsc mode. 2 Setting the monitor mode to dblntsc and saving it can change the resolution, but the newer version of Workbench might have broken the monitor driver. 3
