EISA card

Claims: 7 Part of EISA

The Indigo2 and I2 can accept an EISA card, though EISA performance was not optimal on the Indigo2. 12 An EISA card from Phobos is a 3Com card that limits data transfer to about 7MB/s. 34 You can implement a PCI root complex as an EISA card using an FPGA, though it would require the chipset to support such contraptions. 5

Sources

  1. The Indigo2 had a SCSI option but it was HVD SCSI, similar to that found on Challenge/Onyx systems, and an EISA card, though EISA performance was not optimal. (user-86e1, 2024-05-13, exchange 111252, check: supported)
  2. The I2 can accept an EISA card. (user-07ed, 2024-06-20, exchange 238668, check: uncheckable)
  3. The EISA card limits data transfer to about 7MB/s and the Phobos card can reach 100Mbit without affecting system load. (user-86e1, 2026-03-13, exchange 200387, check: supported)
  4. An EISA card from Phobos is a 3Com card. (user-616d, 2026-09-18, exchange 214674, check: supported)
  5. You can implement a PCI root complex as an EISA card using an FPGA, though it would require the chipset to support such contraptions. This was done with an FPGA and an AMD GPU via a serial EXI link, though the IP license (user-3e2d, 2026-03-18, exchange 226244, check: uncheckable)
