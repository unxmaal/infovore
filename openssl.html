OpenSSL

Claims: 32 Background: 6 claims already covered by Wikipedia, see Heartbleed, OpenSSH.

OpenSSL is a widely used cryptographic library that can be used as an alternative to nss/nspr in rpm. 1 OpenSSL can be compiled on a variety of platforms, though the process is not always straightforward. 234 Building OpenSSL on IRIX can involve several issues, including 'Arg list too long' errors, library not found errors, and problems with irixports and RSE. 356789 OpenSSL is often built alongside other tools such as OpenSSH, curl, bash, and GCC. 1011 didbs releases include OpenSSL and OpenSSH, though they lack date/timestamp and version info for dependencies. 12131410 Newer versions of OpenSSL can resolve SSL/TLS errors in some applications. 1516 Older versions of OpenSSL can cause problems, such as preventing connections to modern services. 1718

Sources

  1. rpm can use openssl instead of nss/nspr (user-f229, 2019-09-30, exchange 214860, check: uncheckable)
  2. OpenSSL compiles flawlessly on Indy. (user-637b, 2019-05-12, exchange 1669, check: supported)
  3. Compiling openssl can cause issues; SGI 7.9 is compiled against OnRex's version. (user-b4f4, 2019-08-20, exchange 214828, check: supported)
  4. compiling openssl on an HP PA-RISC 1.1 can be difficult. (user-ab99, 2023-02-01, exchange 35756, check: supported)
  5. building openssl with `irix64-mips4-gcc` requires increasing `ncargs` using `systune ncargs 131072` to avoid 'Arg list too long' errors. (user-f229, 2019-11-05, exchange 214880, check: supported)
  6. irixports has issues with openssl, requiring modifications or a different approach. (user-d903, 2019-11-07, exchange 214883, check: uncheckable)
  7. when building OpenSSL on IRIX, relinking with the required rpath can fix library not found errors; makefile modifications can achieve this without a full clean build. (user-c831, 2020-02-14, exchange 204143, check: uncheckable)
  8. OpenSSL issues persist in rse, affecting git and sshd, requiring a fix. (user-f229, 2020-06-18, exchange 68735, check: uncheckable)
  9. Building Git on IRIX without RSE is difficult and can involve issues with OpenSSL and curl. (user-ae4b, 2025-04-30, exchange 56263, check: uncheckable)
  10. Didbs includes both OpenSSL and OpenSSH. (user-2189, 2019-12-22, exchange 68229, check: uncheckable)
  11. I compiled OpenSSL, OpenSSH, binutils, bash, GCC, and some other stuff. (user-5510, 2023-08-04, exchange 39503, check: uncheckable)
  12. didbs releases lack date/timestamp and version info for dependencies, requiring full rebuilds when updating packages like openssl. Distributing the .installed tree could help, but git clones might still force a fullbuild (user-2d09, 2019-10-07, exchange 68016, check: uncheckable)
  13. We're using recent openssl libraries in didbs. (user-d903, 2019-11-07, exchange 68105, check: uncheckable)
  14. last didbs release was openssl 1.1.1a, next release will be 1.1.1d. (user-2d09, 2019-11-07, exchange 68105, check: supported)
  15. xephem 4.1.0 requires sslv23_client_method, indicating compatibility issues with older OpenSSL versions. (user-a4dd, 2023-02-20, exchange 83026, check: supported)
  16. ClassiCube's SSL/TLS error can be resolved by using a newer OpenSSL, as suggested by sgug-rse. (user-23f2, 2025-05-10, exchange 56471, check: uncheckable)
  17. Firefox3 won't compile with the latest OpenSSL; you need to get to Firefox 20 before you get TLS 1.2 support, and it's not trivial to add it in to an older Firefox release. (user-22f9, 2019-02-09, exchange 522, check: supported)
  18. Neko Pidgin uses an old version of OpenSSL and gnutls, preventing connection to modern services and is also buggy; libpurple in nekoware is the source of these issues. (user-e0a4, 2020-01-18, exchange 68285, check: uncheckable)
