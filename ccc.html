CCC

Claims: 3

Carbon Copy Cloner (CCC) is a cloning program that appears to be required for creating Sorbet restore images, though it is unclear whether a specific version has always been required. 12 The version of CCC needed for Sorbet restore images is now payware and has changed, requiring the use of an older version that will not run on current operating systems but still works with an older Mac mini running Tiger. 1 Cloning the system disk using CCC is straightforward once the SSD is partitioned and formatted. 3

Sources

  1. The CCC software required for Sorbet restore images is now payware and has changed, necessitating the use of an older version that won't run on current OSes, but it still works with an older Mac mini running Tiger. (user-03ad, 2022-11-26, exchange 231951, check: uncheckable)
  2. CCC seems to be a requirement for Sorbet restore images, but it's unclear if a specific version is needed or if it has always been required. (user-d903, 2022-11-26, exchange 231951, check: uncheckable)
  3. Cloning the system disk using CCC is straightforward once the SSD is partitioned and formatted. (user-59df, 2024-04-17, exchange 232226, check: uncheckable)
