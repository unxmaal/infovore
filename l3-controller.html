L3 controller

Claims: 7 Part of L3

The L3 controller can be used via software or an actual L2 controller. 1 SGI sold the VW as an L3 controller, though it was expensive. 2 The L3 controller ran on an x86 box (such as the SGI 1400L) and can be easily run in a VM using x86 PC hardware, with its software running under VMware or VirtualBox with some configuration. 345 The L3 controller software comes with compiled executables for ancient kernels. 6 The fuels l1 USB-B port can connect to an L2 or L3 controller. 7
