Compilertron

Claims: 13

Compilertron is a cross-compiler setup for IRIX, available as a Docker container or a vagrant virtual machine, and can be used for cross-compilation with distcc on an IRIX box. 123 It generates native code using a C runtime for operating system-specific tasks, with existing backends for IRIX and big-endian MIPS. 4 Compilertron acts as a distcc server for IRIX hosts, using the host's linker for linking and, by default, GCC's libstdc++ for compiled binaries. 5 It runs distcc in a container to speed up builds on IRIX by about 10x, though the IRIX box still does much of the work, and the backoff period can be disabled with `export DISTCC_BACKOFF_PERIOD=0`. 67 Building Compilertron requires a significant amount of disk space, but 75GB should be sufficient as it is a virtual machine that can be provisioned with additional storage if needed. 8 Enabling libstdc++ in Compilertron requires removing `--disable-libstdcxx` from `build_gcc.sh`, patching `libstdc++-v3/crossconfig.m4` to include IRIX, and running the patched sources in the Dockerfile. 9
