Sun Type 5 keyboard

Claims: 5 Part of Sun

The Sun Type 5 keyboard is more comfortable than the Type 6 and nicer than some generic Dell/Hp rubber dome keyboards. 1 There are Sun->USB converters that allow using a Type 5 keyboard on machines with USB, including Blade 100, Blade 2000, and PC. 2
