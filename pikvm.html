PiKVM

Claims: 9

PiKVM v4 takes HDMI input for video and uses a single USB-C to USB-A connection as a joint USB keyboard and mouse output to the computer, along with an 8P8C port for ATX power/reset switches and LED status. 12 PiKVM hardware can support up to 1920x1200x60Hz, but older models may be limited to 1920x1200x24Hz. 3 A Fuel can be connected to a PiKVM using DVI-to-HDMI converters, and the Belkin Omniview might be an option for a PiKVM to Tezro/Fuel connection. 45 PiKVM sends a UDP stream of pointer data to the SGI machine, which then moves the mouse, and a C program running on IRIX takes these UDP messages to move the mouse but does not handle clicks. 67 There is a hack to make a Tezro mouse work with PiKVM via IRIX UDP, and one user achieved full absolute mouse control via PiKVM with 1920x1200 60fps by upgrading to a 4 CPU with custom hackery. 89
