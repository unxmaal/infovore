.cshrc

Claims: 8

The .cshrc file is a configuration file for the C shell, and it is hidden and should be in the root of the user directory. 12 The .login file is a login script that does various things, while the .profile file is run if the shell is /bin/sh or possibly bash. 2 Adding a 'stty rows 25 cols 80' line to .login, .profile, or .cshrc sets the terminal size, and setting TERM, MANPATH, EDITOR, and BROWSER in these files configures the environment. 3 To run 'cad', you need to set the PATH variable to include /usr/local/srd/cad/bin and /usr/local/srd/cad/options. 4 The TERM variable can be set in aterm with 'TERM=xterm' in the shell or by editing the .cshrc file. 5 You can check .profile, .bashrc, or .cshrc to set PATH, and modify the current shell session to test the change. 6 Setting paths in .cshrc can cause duplication, so paths should be set with setenv instead. 7 Deleting login scripts and .cshrc will result in them being recreated upon logout/login. 8
