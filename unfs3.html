unfs3

Claims: 7

unfs3 is a userspace NFS server, though it is described as NFSv2 in one source and NFSv3 in others. 12 It can be used as a small NFS server on a Raspberry Pi. 1 Unfs3 on a Raspberry Pi works well with IRIX. 3 The Indy emulator supports NFS file sharing using unfs3, setting up a local share that can be mounted from IRIX from the gateway. 4 Shared directories can be configured in iris.toml to start unfs3 on localhost and NAT NFS to this instance, allowing the NFS server to be mounted from 192.168.0.1. 5 The NFS hack using unfs3 has been tested with Linux. 6 UNFS3 can serve host-specific files/directories under the same root filesystem using directory naming conventions. 7
