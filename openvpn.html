OpenVPN

Claims: 10

OpenVPN is a VPN software package that installs a TAP adapter (via the TAP/TUN driver) for use in networking setups. 123 The TAP/TUN driver can be installed separately from OpenVPN and can coexist with other VPN software. 4 Networking in MAME can be set up by installing OpenVPN and the TAP adapter, then bridging the TAP adapter with the LAN/WiFi connection. 53 Networking in Irix emulation requires bridging a TAP adapter to the local network connection and configuring IP addresses, with FTP usable via a Windows FTP server. 67 On Windows, the OpenVPN TAP adapter can be set to an address such as 10.0.0.2, with the guest (Indy) given a corresponding address such as 10.0.0.3. 8 OpenVPN 2.5 does not bridge the TAP adapter with the Ethernet connection on Windows 11, whereas 2.4.12 with Internet Connection Sharing works, and updates of Windows 10 or 11 may require fixes. 16

Sources

  1. OpenVPN 2.5 does not bridge TAP adapter with Ethernet connection on Windows 11, but 2.4.12 with Internet Connection Sharing works. (user-ce6b, 2022-12-30, exchange 220252, check: supported)
  2. The TAP/TUN driver with OpenVPN allows network adapter selection in Mame on an Indy. (user-a719, 2020-03-16, exchange 220142, check: supported)
  3. Install Open VPN in Windows to get a TAP adapter for networking in Mame. (user-ce6b, 2024-03-14, exchange 220321, check: uncheckable)
  4. The taptun driver can be installed separately from OpenVPN, and it can coexist with other VPN software. The host side of the tap adapter is typically configured as 192.168.137.1, and the guest as 192.168.137.2. IPRouting (user-a719, 2024-03-20, exchange 93357, check: supported)
  5. To set up networking in MAME, install OpenVPN and the TAP adapter, then bridge the TAP adapter with your LAN/Wifi (for Win 10). (user-ce6b, 2020-09-15, exchange 92637, check: supported)
  6. Network setup in Irix emulation using OpenVPN requires bridging a TAP adapter to the local network connection, but updates of Windows 10 or 11 may require fixes. (user-ce6b, 2022-12-29, exchange 220249, check: supported)
  7. Irix 5.3 networking can be set up by bridging a TAP adapter with a network adapter on Windows, using OpenVPN, and configuring IP addresses. FTP can be used with a Windows FTP server. (user-ce6b, 2023-06-15, exchange 93195, check: supported)
  8. On Windows, set OpenVPN Tap adapter to 10.0.0.2 and inside Irix setup give the Indy 10.0.0.3 for network communication; enable the network adapter inside Mame via scr lock and network menus; OpenVPN 2.6 works well for I2 (user-ce6b, 2025-04-12, exchange 220366, check: supported)
