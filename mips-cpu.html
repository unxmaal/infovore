MIPS CPU

Claims: 34 Part of MIPS Background: 6 claims already covered by Wikipedia, see MIPS architecture, Field-programmable gate array, IRIX.

The MIPS CPU is used in a variety of systems, including the Cobalt Qube2, the Nintendo 64, the SGI systems, the DECsystem 5400 and 5500, and the PlayStation 2. 12345 A MIPS CPU cannot run x86/x64 software directly, and the architecture is different from other systems, which affects emulation. 23 Each MIPS CPU can handle two threads. 6 The MIPS CPU has a PLL that can be set to different values, and the PROM contents determine the CPU's clock speed and cache configuration. 7 A hardware TLB exists but is managed in software by the MIPS CPU. 8 Building a computer around a MIPS CPU is possible with modern tools and software, and an FPGA can be used to roll your own MIPS CPU. 910 The emulation of the MIPS CPU can run at less than 300 MHz. 11 MIPS CPU was licensable, though MIPS as a company is now working on RISC-V. 12
