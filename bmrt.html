BMRT

Claims: 12

BMRT is a raytracing tool that is fully compliant with the RenderMan Interface Specification, developed by LG as a ray tracing implementation of that interface. 123 It was originally a one-man raytracer for the RenderMan interface, distinct from PRMan, which is the original Reyes renderer based on micropolygons. 1 BMRT is a software tool for IRIX available at https://www.cc.gatech.edu/scivis/userguide/resources/software/bmrt.html. 4 It can be used with Softimage and Maya, though finding compatible software was difficult, and running it through Mayaman works. 56 BMRT can be run with the MayaMan interface, which was the first Rman engine the speaker used when they figured out how to get MayaMan working. 7 It was used in 'Bugs Life' to trace the refraction of a bottle in the grasshopper's hideout. 8 RAT can be configured to use BMRT for raytracing, but it is not a full replacement for Entropy. 9
