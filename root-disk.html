root disk

Claims: 5 Part of root

IRIX requires a second disk to boot in single user mode and then allows mounting the root disk to edit the /etc/passwd file. 1 The PI on an SGI should not be restarted while a RASCSI device is serving as the root disk, as the SGI will kernel panic. 2 The system complains about the root disk and a PCI controller, suggesting issues with the disk or a non-standard configuration, and powering down and swapping disks can help diagnose the problem. 3 Cloning a root disk can be done directly to blue SCSI following Mapleson's guide. 4 A disk labeled as such is likely a Seagate disk and probably used as a root disk. 5
