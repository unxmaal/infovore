CLOCK_MONOTONIC

Claims: 3

CLOCK_MONOTONIC is a clock used for monotonic time. 1 IRIX does not have CLOCK_MONOTONIC. 12 On IRIX, CLOCK_SGI_CYCLE can be used as an equivalent clock with 64 bits and 800ns resolution on ip35 systems. 2 CLOCK_SGI_CYCLE is not fully compatible with CLOCK_MONOTONIC, but glib tests pass with CLOCK_SGI_CYCLE. 3

Sources

  1. IRIX does not have the CLOCK_MONOTONIC, which is needed for monotonic time. (user-9860, 2021-11-21, exchange 215228, check: uncheckable)
  2. IRIX does not support `CLOCK_MONOTONIC`, but `CLOCK_SGI_CYCLE` can be used as an equivalent clock with 64 bits and 800ns resolution on ip35 systems. (user-9860, 2022-12-24, exchange 70616, check: supported)
  3. CLOCK_SGI_CYCLE is not fully compatible with CLOCK_MONOTONIC, but glib tests pass with CLOCK_SGI_CYCLE. (user-42cf, 2021-05-30, exchange 215161, check: uncheckable)
