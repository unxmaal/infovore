Marmelade

Claims: 6

Marmelade is an Apple Music client written in C with Motif widgets and a Node.JS backend using Chromium, but it is being transitioned to use the host's default browser. 1 It uses MaXX shared libraries for ViewKit implementation and is porting SGI Motif Extensions. 23 It currently only tests on Linux but should work on any UNIX-like system, including IRIX with a modern Node.JS stack. 4 It has UTF-8 support for text now and has a screenshot and is almost in a usable state. 56
