Graphics Tower

Claims: 3 Part of graphics

The Graphics Tower is a 24-bit accelerated 3D graphics system that connects to the SS1+ through a single-width SBus interface card. 1 It is the high-end SBus graphics solution for SGI, using an interface card in the machine and an external 3 board. 12 The graphics tower was VME based. 3 It is known to be slow as a console frame buffer and is not supported in newer Solaris versions or machines. 12
