DS1742W

Claims: 6

The DS1742W, used in Fuel, Tezro, and O350 systems, is no longer manufactured by Dallas or Maxim, and does not contain a Dallas chip. 12 The DS12887 can be used as a replacement for the DS1742W in an SGI, though it may be a gamble. 3 A GitHub repository provides instructions for adapting a DS1744WP to a DS1742W, using an adapter board that reroutes traces and pulls some address pins high to accommodate the wider address space of the DS1744W. 45 The DS1742W can be re-initialized using the DS1220 option to flash an image from an existing chip, even if the clock registers are not recognized. 6
