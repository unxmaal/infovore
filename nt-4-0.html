NT 4.0

Claims: 14 Part of NT

NT 4.0 ran on a variety of hardware platforms, including a Motorola AT board with a PowerPC 604 CPU, which could also run AIX or a specific version of Solaris, and a PowerPC 601-based RS/6000 40p, which required the NT 4.0 version of Windows for PowerPC. 12 NT 4.0 was also available for Alpha systems, where NT/Alpha ran on Alphaserver 4000s but lacked native software, while NT 4.0 on Intellistations was more powerful, and the Raptor Reflex was an Alpha workstation exclusively built for NT 4.0. 34 NT 4.0 Terminal Server with FX32 allowed concurrent RDP access to x86 apps on an Alpha, and Cygwin could be installed on an NT 4.0 box to improve quality-of-life. 56 The DEC version of the operating system was intended for NT 4.0, but no evidence of its use exists, and the DEC 5.0 release was more commonly used, especially in Hollywood by ILM, which also used it alongside Octanes. 7
