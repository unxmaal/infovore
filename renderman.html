RenderMan

Claims: 32

RenderMan is a Reyes renderer based on micropolygons that implements the shading language and can be used via command line to render RIB/text files. 12 Pixar owns RenderMan and requires a license for use, even if you have a copy of the software. 3 RenderMan was primarily used inside Maya for prepackaged setups, and its licenses for IRIX are no longer sold and may be too old for modern systems. 45 RenderMan can be used in IRIX with MayaMan in Maya 4.0, requiring setup of ENV variables and the correct license server. 67 RenderMan for Macintosh can generate geometry, unlike some versions for Windows which only support rendering files. 8 Other RenderMan-compliant engines include BMRT, Entropy, 3Delight, and Softman, while RAT is a RenderMan plugin for Alias and Maya software. 29101112
