minicom

Claims: 12 Background: 1 claim already covered by Wikipedia, see Gentoo Linux.

Tools like minicom and pppd can be used to manage serial modems on an SGI. 1 Minicom can be run from a VM with serial port passthrough, and Gentoo users can use cu, tio, or minicom for serial connections. 23 To use minicom, one should turn on the computer before entering it. 4 Serial terminals like minicom can lock up when attempting to send a break during powerup to enter the OpenBoot prompt on systems like Ultra1. 5 Minicom set to hardware flow control was causing issues with the serial line for OBP; switching to software flow control resolved it. 6 cu and minicom cannot send to the Iris serial console without proper flow control settings. 7 The Startech USB-serial adaptor works with Linux serial terminal programs but required a different program than Minicom to function correctly. 8 There are no matching packages for minicom on the available repositories. 9
