vertex colors

Claims: 4

Blender appends vertex colors at the end of each vertex line, using only RGB with no alpha channel. 1 Vertex colors can add extra depth to 3D models, especially in games. 2 Some models can be optimized by grayscaling textures and using vertex colors for coloration. 3 Vertex colors can reduce draw calls by swapping out color data without changing textures. 4
