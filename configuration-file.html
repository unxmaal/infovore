configuration file

Claims: 5 Part of configuration

The Grease Weasel requires a configuration file specifying cylinder, head, track, sector, and bit-per-sector values to convert raw flux images to a normal binary format for SGI disks. 1 The zuluSCSI configuration file includes options to reduce disk speed. 2
