VM

Claims: 30 Background: 2 claims already covered by Wikipedia, see VM (operating system).

A VM can be customized to run IRIX, and running `vagrant provision` repeatedly ensures the VM has the crosscompiler and IRIX headers installed in /opt/gcc and /opt/binutils. 12 The VM setup is complete hardware-wise, but there are issues with the OS install process. 3 Provisioning fails with a playbook missing error even though the VM can access the internet and download files, and the DHCP server configuration is missing a subnet declaration and the VM can't resolve its own hostname. 45 The S3 mirror for booterizer should work if networking is properly set up on the VM; otherwise, 'vagrant provision' or 'vagrant destroy' followed by 'vagrant provision' can fix it. 6 You don't really need a lot of RAM to run the VM, just make sure that a fair bit of that RAM is free, and you also probably want a lot of disk space free, ~20GB. 78 At least 16GB of storage is recommended for the VM. 9 You can't overclock a VM. 10
