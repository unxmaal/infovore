4D1

Claims: 6 Background: 1 claim already covered by Wikipedia, see Kernel (operating system).

The WinWorld 4D1 is a version of the 4D35 without boot sashes. 1 The 4D1 up to 2.2 and 4D1 3+ used different kernels; 2.2 had Mex and 3+ had Max. 2 GL2 and 4D1 both originated from AT&T UNIX releases, with GL2 incorporating additional UniSoft 68K platform code and SGI graphics, while 4D1 also includes RISC/os code. 3 The GL2-3.7 source code is available, though it was internally called 4d1 and is from the early 3.0 era. 4 Installing IRIX 3.0 on a 4D1 is difficult, often requiring special drivers and hardware like an IP6 board, which can be expensive. 5
