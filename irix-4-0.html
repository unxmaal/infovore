IRIX 4.0

Claims: 11 Part of IRIX 4 Background: 1 claim already covered by Wikipedia, see OpenGL.

IRIX 4.0 is a version of the UNIX operating system that does not support ELF executables and became the point at which OpenGL became available. 12 Source code from around the IRIX 4.0 period is available, showing it as an independent branch of UNIX without shared libraries or the NeWS desktop. 3 SGI's unified memory architecture, associated with this era, allowed manipulation of extremely large 2D images for the time, with applications in military mapping. 4
