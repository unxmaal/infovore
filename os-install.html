OS install

Claims: 5 Part of OS

An Octane OS install can last a long time, so reinstalling is unnecessary. 1 The 4D/35 support tape has to be installed in a very specific order when doing the OS install and re-installed whenever you do patches or anything OS-related. 2 The likelihood of wedging an OS install influences hard disk choice, and U60 running SOL8 is unlikely to wedge the OS install. 34
