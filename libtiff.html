libtiff

Claims: 5

Emacs can use libtiff and libjpeg for displaying images, such as in web pages viewed with `w3`. 1 libtiff has issues with GCC due to a missing 'client_data' member in JPEG structs, and these issues remain unresolved, so headers should be checked. 23 For gijoe, the include directory for libtiff is set in CPPFLAGS, and the library directory is set in LDFLAGS and LD_LIBRARYN32_PATH. 4 libtiff, libjpg, and libpng should have packages and build against recent versions. 5
