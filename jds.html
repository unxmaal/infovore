JDS

Claims: 3

JDS is a GNOME 2.0-based desktop that uses xscreensaver or gnome-screensaver, and it depends on X but is a separate package. 12 Installing JDS drivers may require a reconfiguration (boot -r, devfsadm, or touch /reconfigure && init 6) after ensuring X is installed. 1 Solaris 9 can run on a minimum-spec SS4, but this is not recommended because JDS is a memory hog. 3
