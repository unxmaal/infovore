zmodem

Claims: 4

Zmodem is a file transfer protocol usable over serial connections, though a terminal program that supports zmodem is required (for example, System 6 needs such a program, and extraputty might support it). 12 Some terminal programs support zmodem file transfers, including mrxvt, which also supports xmodem. 3 Zmodem transfers from the SGI/Mame using 'sz' stall on files larger than 1024 bytes. 4

Sources
