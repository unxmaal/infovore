OBP

Claims: 19

On older machines the OBP is not flashable and requires burning an EPROM, while upgrading on a Blade 2500 requires desoldering the EPROM chip and manually flashing a newer version. 12 The Ultra 5 requires setting the write protect jumper to write allow for an OBP upgrade, and a poor soldering job can leave the OBP non-functional. 34 An onboard SCSI controller issue can cause boot failures that are resolved by updating the OBP, and a dictionary overflow from a failing SCSI controller can prevent the machine from booting. 52 OBP defaults to console on serial if no keyboard is present, but does not recognize USB keyboards in pre-Blade-100 systems, and a keyboard and mouse are needed for the X server to start. 67 OBP can be accessed without a display or keyboard, and it has stock default environment variables, so the machine should start without the NVRAM, though it will likely complain. 8910 To update the OBP you need to specify the boot device and, if necessary, the devalias or filepath, and set the cdrom ID to 6 for OBP to find it. 1112 Setting diag-switch? true in the OBP and resetting passes diagnostics except for NVRAM issues, and Jumpstart can be used even with a broken Ethernet address if the network address is set in OBP before booting. 1314
