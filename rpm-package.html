Claims: 10 Part of RPM

  • A pure Python package installed with --user works, but RPM packages have similar pathing problems. (user-e872, exchange 69092, 2020-10-30; 1 speaker(s), 1 conversation(s))
  • There is an error downloading a specific RPM package with code 1622. (user-9860, exchange 215236, 2021-12-03; 1 speaker(s), 1 conversation(s))
  • sgug-rse installation requires running 'sgugshell' and installing RPM packages with 'tdnf'. (user-7973, exchange 32354, 2022-08-28; 1 speaker(s), 1 conversation(s))
  • T2 PROM updates are available via RPM packages. (user-e872, exchange 216627, 2026-05-27; 1 speaker(s), 1 conversation(s))
  • Ideally, scripts should be placed in a noarch rpm package. (user-b1da, exchange 83315, 2023-04-10; 1 speaker(s), 1 conversation(s))
  • To achieve 100% build repeatability on IRIX, they used RPM packages, which they settled on after trying NetBSD pkgsrc and Dan's Perl scripts. (user-42cf, exchange 80934, 2022-02-09; 1 speaker(s), 1 conversation(s))
  • Windows can be used to create a local repository for RPM packages by pulling them and installing createrepo. (user-f229, exchange 69431, 2021-04-13; 1 speaker(s), 1 conversation(s))
  • To get a compatible Linux system, you need an aptitude or RPM package system, X11, and all the frameworks. (user-1361, exchange 27163, 2022-03-12; 1 speaker(s), 1 conversation(s))
  • KDE 1.1.1 has more RPM packages than 1.1. (user-e5dd, exchange 74891, 2026-07-26; 1 speaker(s), 1 conversation(s))
  • AIX has its own first party RPM packages; there were also open source Bulle/Atos packages. (user-b1da, exchange 41748, 2023-10-25; 1 speaker(s), 1 conversation(s))
