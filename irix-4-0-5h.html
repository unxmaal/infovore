IRIX 4.0.5H

Claims: 10 Part of IRIX

IRIX 4.0.5H dropped IP6 and IP12 support. 1 IRIX 4.0.5F and 4.0.5H have limited hardware support. 2 The IP7 boots into install mode but lacks a /unix kernel, requiring a re-installation or assistance. 3 IRIX 4.0.5H and XL graphics were released around the same time, and the Indigo2 with XL graphics can run IRIX 4.0.5H. 4 IRIX 4.0.5H can install and run on a 250MHz CPU without issues, except for IMPACT graphics, which are incompatible. 5 The R4K Indigos can run IRIX 4.0.5H, which is fast on a 200 MHz R4400, while IRIX 5 is more sluggish but provides access to more software or easier-to-find software. 67 The IRIX 4.0.5H distribution includes several tools and environments, and the IRIX Maintenance 4.0.5H disc can upgrade these tools to the same version. 8 Two versions of IRIX 4.0.5H are listed for the Indigo2 with specific hardware configurations, and a 'Maintenance' version is also mentioned. 9

Sources

  1. IRIX 4.0.5H dropped IP6 and IP12 support. (user-f573, 2020-06-16, exchange 216949, check: supported)
  2. IRIX 4.0.5F and 4.0.5H have limited hardware support. (user-b1da, 2023-08-17, exchange 209068, check: supported)
  3. The IP7 boots into install mode but lacks a /unix kernel, requiring a re-installation or assistance. (user-f229, 2022-02-18, exchange 241005, check: uncheckable)
  4. IRIX 4.0.5H and XL graphics were released around the same time, and the Indigo2 with XL graphics can run IRIX 4.0.5H. (user-ce6b, 2022-02-18, exchange 241005, check: supported)
  5. IRIX 4.0.5H can install and run on a 250MHz CPU without issues, except for IMPACT graphics, which are incompatible. (user-8547, 2024-04-12, exchange 210229, check: supported)
  6. The R4K Indigos can run IRIX 4.0.5H, which is plenty zippy, while IRIX 5 is more sluggish but provides access to more software or easier-to-find software. (user-56d4, 2024-06-15, exchange 210508, check: supported)
  7. The Indigo2 R4K Extreme runs IRIX 4.0.5H, which is fast on a 200 MHz R4400 because IRIX 4 already runs fine on R3K systems. (user-86e1, 2026-01-15, exchange 219404, check: supported)
  8. The IRIX 4.0.5H distribution includes several tools and environments, and the IRIX Maintenance 4.0.5H disc can upgrade these tools to the same version. (user-86e1, 2024-09-11, exchange 218545, check: supported)
  9. Two versions of IRIX 4.0.5H are listed for the Indigo2 with specific hardware configurations. A 'Maintenance' version is also mentioned but its details are not provided. (user-281e, 2024-09-11, exchange 85691, check: supported)
