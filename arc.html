ARC

Claims: 10 Background: 1 claim already covered by Wikipedia, see Video games and Linux.

ARC is a firmware used on Alpha systems, alongside SRM, which is the Alpha firmware for Unix/VMS while ARC is for Windows; some Alphas could only run Windows. 1 Linux could later be run under ARC on some Alphas, though it can be run on ARC but doesn't like it. 23 The Intergraph Multia can boot into both SRM and ARC, but requires an EV5 class CPU for ARC. 45 Intergraph video cards were used in Alpha PWS 500au machines, which booted to ARC. 6 Nobody ever shipped R3000 machines with ARC, as the PROM was basically just written by the NT team for development. 7 ARC over a serial console is fully functional on an AlphaServer DS20, but slow and not smart about terminal use, and ARC might be the issue with serial output on AlphaBIOS. 89
