Odyssey diagnostics

Claims: 3 Part of Odyssey

The Odyssey diagnostics may only work with a specific CD that came with the Fuel and not on an Octane Odyssey card. 1 They can be run with the command `./run.pl 1 -all` for a full test. 2 To run them, boot into IDE or IRIX; in PROM, use `printenv`, though issues include a screenless system and the ability to run only PROM commands. 3
