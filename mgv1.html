MGV1

Claims: 3

The MGV1 is a tape drive board that works with the Impact graphics boardset, and it is the same function as FHV1, which works with the Extreme graphics boardset. 1 For Video Decompression on an Indigo 2 with an Impact R10K, the MGV1 should be used. 2 The MGV1 is a basic tape drive board that is missing some chips and the internal ribbon cable connector for combining with the IMPACT compression card. 3

Sources
