Toolchest

Claims: 13

Toolchest is a component of the IRIX desktop that covers most dock features, and can be oriented horizontally or vertically depending on a setting. 12 It requires a NeWS server to run, which may be available via emulation on Windows or Sun systems. 3 Adding items to Toolchest involves editing a text config file, which can be automated but requires fuzzy/regex logic. 4 The .auxchestrc file customizes Toolchest for better usability and is available on GitHub, along with dot files that include settings for toolchest orientation. 56 The Open Remote Directory tool can open a remote FTP directory by specifying the user, host, and remote directory. 7 Toolchest's desktop logout does not go to the system logout, and launching an application that produces no response can be diagnosed by running it from the command line. 89
