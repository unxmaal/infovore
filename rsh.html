rsh

Claims: 21 Background: 4 claims already covered by Wikipedia, see Remote Shell, Secure Shell.

rsh is an IP-dependent protocol with strict security checks based on hostname and IP, using .rhosts files for authentication via rshd. 123 It can be used as an alternative to SSH for remote command execution, piping commands through stdin/stdout. 456 rsh is available on Debian, where it can be a symlink to ssh under alternatives and installed with rsh-client. 7 Network installs of IRIX use rsh and tftp, relying on bootp and DNS for hostname resolution, with mismatched hostnames and IPs causing issues. 8910 Setting up these services can be done on a virtual machine from a Windows laptop, and Love simplifies bootp, tftp, and rsh into a single NAT-friendly binary. 1112 The services may need guest access configured on the server, and older systems may have rsh, chargen, and finger turned on by default. 1314 xfsdump output can be piped to rsh for remote backup execution. 1516 The IRIX MCP server can use rsh or SSH as its transport and has no dependencies. 17
