EPROM chip

Claims: 3 Part of EPROM

The boot PROM contains the initial screens and is stored in an EPROM chip. 1 Upgrading the OBP on a Blade 2500 requires desoldering the EPROM chip and manually flashing a newer version, which can cause a dictionary overflow if the onboard SCSI controller fails, preventing the machine from booting. 2 Swapping the EPROM chip on an RX580 with a modified one can enable boot screen support in a Mac, but it may not work in a standard PC or Hackintosh. 3
