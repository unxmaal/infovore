AS/400

Claims: 53 Background: 4 claims already covered by Wikipedia, see IBM AS/400.

The AS/400 runs OS/400, also known as IBM i or i5/OS, and is not a mainframe. 12 It uses a bytecode-based, architecture-independent instruction set and runs on PowerPC with proprietary tagged memory extensions. 34 The AS/400 is compatible with System/38, minus a few things, and its firmware is based on the System/38 architecture. 567 Early beige CISC AS/400s use MULIC licensing, split between a Model Unique Licensed Internal Code tape and an OS/400 tape, while black PowerPC AS/400s use LIC licensing, unified with OS/400 and specific to machine serial number and processor class. 89 The AS/400 machines no longer use specific hardware since 2008; they are IBM POWER machines now. 10 IBM i is emulated as 'as/400 or series i' on Power systems, but not the newer releases on real AS/400 hardware. 11 The IBM AS/400 runs OS/400, a capable operating system supporting multiple users, remote login, and networking. 12 The AS/400 uses a single level store architecture. 13 The AS/400 software had a custom source control system with a deep hierarchy and thousands of options. 14 SNA setup on an AS/400 is useful for multiple AS/400s. 15 The IBM AS/400 uses 32 MB SIMMs. 16 Domino R5 on AS/400 was used with two PII-400MHz servers and 512MB each, handling close to 500 users. 17 The AS/400 had service processor issues that led to a power failure after initial assembly. 18 MPE/ix is more like a midrange system, comparable to IBM's AS/400. 19
