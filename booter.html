Booter

Claims: 8 Background: 1 claim already covered by Wikipedia, see Debian.

  • A booter is a program that you can boot. (+1 similar) (user-1361, exchange 7509, 2020-04-15; 2 speaker(s), 1 conversation(s))
  • booter can be used for booting 5.3 but not for all forks (user-f229, exchange 77155, 2020-04-23; 1 speaker(s), 1 conversation(s))
  • Booter issues can cause directory structure problems with 6.5.22 downloads. (user-f229, exchange 35918, 2023-02-06; 1 speaker(s), 1 conversation(s))
  • Booter can install MIPSpro by editing /irix/selections and uncommenting development options, then rebooting; a math.c issue requires re-patching. (user-f229, exchange 77184, 2020-06-02; 1 speaker(s), 1 conversation(s))
  • Booter can be configured to use a specified path for installation via NFS, such as 192.168.251.10:/files/sgi/installers/6.5.30, which will be mounted and used for installation. (user-f229, exchange 3716, 2019-10-01; 1 speaker(s), 1 conversation(s))
  • The Raspberry Pi version of booter can run on a phone battery extender, and SGI systems are typically on UPS's for reliability. (user-8b3c, exchange 216698, 2020-03-07; 1 speaker(s), 1 conversation(s))
