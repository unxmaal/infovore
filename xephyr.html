Xephyr

Claims: 8

Xephyr is a tool to nest an X server and serves as a full X server alternative to xnest, offering fewer bugs and missing features. 12 Xephyr has more features than Xnest, including OpenGL support. 3 However, Xephyr does not support GLX, which is required for running OpenGL applications from an SGI box, and it is not displaying OpenGL output. 45 Xephyr can display OpenGL output if configured correctly, by setting LIBGL_ALWAYS_INDIRECT=1 to enable True Color, or by starting a full X server at a second virtual console from Linux. 67 Running two X servers with separate screens requires a fullscreen Xephyr/Xnest on :0.1 for proper XDMCP connection. 8
