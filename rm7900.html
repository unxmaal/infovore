RM7900

Claims: 18

The RM7900 is a MIPS CPU based on the E9000 core, offering pin-compatible upgrades from 5000 and 7000 core products. 12 It is pin-compatible with the RM7000 but has a different core architecture and lacks L3 cache pins, so it is not a fully drop-in replacement. 3 The RM7900 has external cache, unlike the RM7965, which lacks L3 cache and is not pin compatible with the RM7900. 45 The O2's ip32PROM requires specific CPU chip registers and data values to boot, with different requirements for the RM7900 compared to the RM7000, so the system PROM must be patched for RM7900 compatibility. 67 The O2 can run with the RM7900 at 1 GHz, but this is challenging without significant effort, and Verilog models for the O2 and RM7900 are needed for accurate emulation. 89 The RM7900 was used in high-end networking gear, while the RM7065 was used in industrial equipment, and both chips are rare and expensive on eBay. 10 The only reliable source for RM7900 chips is the Momentum Ocelot-C SBC, though some compact PCI single board computers and Galileo Technology evaluation boards also used RM7900 CPUs. 111213
