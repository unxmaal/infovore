TFTP

Claims: 37 Background: 3 claims already covered by Wikipedia, see Debian, File Transfer Protocol, Trivial File Transfer Protocol.

TFTP is commonly used alongside other network services such as BOOTP, DHCP, RARP, BOOTPARAM, NFS, and rsh to enable netbooting and remote installation of various operating systems. 12345678910 TFTP is used to load boot images, kernels, initrd, and firmware over the network, often as part of a multi-step process that includes acquiring an IP address and mounting a root filesystem. 111213147815161710 Some bootloaders, such as ELILO and EFI loaders, request a TFTP server to obtain the next boot component, which can be an OS kernel. 1118 Several tools and systems rely on TFTP for network installation, including booterizer, Love, IRIXboot, Jumpstart, and the miniroot installer. 1920211522 TFTP can be used through Linux, including in virtual machines, and can serve as an alternative when Wi-Fi does not work. 22324 TFTP lacks login functionality and is considered old, and file transfers over TFTP can be slower than over FTP. 2524 TFTP issues can arise from configuration problems such as missing or inaccessible directories, port range settings, and service state, which may be resolved by restarting the service or adjusting settings. 262728
