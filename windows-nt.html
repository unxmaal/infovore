Windows NT

Claims: 50 Part of Windows Background: 8 claims already covered by Wikipedia, see Windows NT, DMA attack, PC game, Windows 2000.

Windows NT was originally named NT OS/2, a year before Windows NT, according to a 2001 presentation slide by Mark Lucovsky. 1 Windows NT used to run on MIPS, Alpha, and a bunch of other architectures. 2 Windows NT on Alpha is 32-bit. 3 WinNT's loader could switch endianness on MIPS machines whose firmware started them out big endian, like the unreleased SGI Indigo port. 4 Microsoft tried to port Windows NT to SGI computers in the 90s. 5 ARCS was SGI's implementation of the ARC firmware specification to support Windows NT on RISC systems. 6 The Indigo can run Windows NT with some drivers and firmware modifications. 7 The O2 does not support Windows NT. 8 The CAD world moved to Windows starting with the Pentium Pro and Windows NT in the mid-90s. 9 The Digital Personal Workstation product family, comprised of Celebris XL Pentium models and Alpha XL models, is targeted at the rapidly expanding market of Windows NT based workstations. 10 SGI did not transition to Itanium and Windows NT. 11 Renderman 3.9.2 in Maya 4.0 can crash with memory errors on Windows NT but works on the Octane. 12 The Windows NT version of Pixar Renderman is RAT 4.1b for Maya 2.5. 13 Softimage 3.01 for Windows NT is available for download. 14
