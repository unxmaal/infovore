QLogic

Claims: 7

QLogic HBAs support target mode from Linux, which is available on only a handful of HBAs notably including QLogic. 1 QLogic 4Gb FC quad-port cards can scale back to 1Gb FC for use in an Octane or O2, and OpenVMS can boot from the QLogic. 23 If a card uses an Adaptec, LSI, or QLogic chip it should be fine, though the O2 only lists some Adaptec cards, not QLogic. 45 QLogic never released technical manuals for their FC products, so drivers for any of it are a huge pain. 6
