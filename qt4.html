Qt4

Claims: 5 Part of Qt

Qt4 is used by applications such as Mumble and PokerTH, the latter requiring an older Qt4-based version to run on vintage systems like those from SGI, with source code available on GitHub. 12 Qt4 can build in software rendering mode or in OpenGL mode, though the latter may cause problems. 34 Qt4 provides good performance, while GTK2 and GTK3 have limitations on lower-end hardware. 5

Sources

  1. Mumble 1.2 may be doable on IRIX using GCC 4.7.x, as it is a Qt4 application. (user-22f9, 2019-04-16, exchange 1386, check: supported)
  2. PokerTH requires an older version still using Qt4 to run on vintage systems like those from SGI; the source code is available on GitHub at the provided link. (user-7973, 2026-02-14, exchange 89690, check: uncheckable)
  3. qt4 builds in software rendering mode (user-b7c4, 2019-08-13, exchange 67743, check: uncheckable)
  4. qt4 builds in opengl mode but weird bad things happen (user-b7c4, 2019-08-13, exchange 67743, check: uncheckable)
  5. QT4 provides good performance, while GTK2 and GTK3 have limitations on lower-end hardware; RSE improves GTK3 performance but still has issues. (user-22f9, 2025-01-13, exchange 52323, check: uncheckable)
