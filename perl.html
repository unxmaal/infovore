Perl

Claims: 25 Background: 4 claims already covered by Wikipedia, see Perl.

Perl is a programming language that can provide universal regex and replacement capabilities similar to sed, and is considered better for replacing shell, awk, and sed, though its flexible syntax can lead to dirty code. 12 Perl is commonly used in system administration, with examples including fixing CGI scripts, editing /etc/passwd, and potentially running Munin with RRDTool. 345 Perl is used to build other software, as wget requires it to build its manpage and test suite, and Qt lists Perl among its minimum system requirements. 67 Perl has notoriously poor build systems, and building it can be time-consuming, taking 22 to 28 hours on older hardware such as a Sun IPC under RedHat 4.2. 891011 Building Perl can encounter various problems, including failures on broken compilers/shells, hangs during the miniperl stage, memory issues during brk/sbrk operations, and compiler-specific issues such as endless loops. 12131415 Multiple Perl versions are available on some systems, such as 5.8.8 from /opt and 5.10.2 from /usr/local, and Perl binaries are available for platforms like IRIX. 1617
