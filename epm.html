epm

Claims: 13

EPM is a Python script that acts as a frontend to IRIX packaging tools, which are cumbersome to use directly, and it generates software and patch distributions in various formats from a list of files. 12 epm can produce tardists, which are IRIX-compatible distributions, and irixports with epm can build and package software into tardist, with spec.py handling package specifications. 34 epm only works on IRIX, though spec.py and epm are tools that run on Linux, and compiling epm for IRIX generated warnings but completed without error. 567 epm is simple, small, and flexible, and has not failed the speaker yet, unlike pkgsrc, which has not succeeded for the speaker. 89 epm doesn't handle dependencies properly and can't identify them for the user, so automating swpkg is smarter than using epm for dependency management. 1011
