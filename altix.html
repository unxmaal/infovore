Altix

Claims: 112 Background: 6 claims already covered by Wikipedia, see SGI Altix, QuickTransit.

The Altix is an Intel Itanium (IA-64) system that is more common than Prisms, and Altix machines can run IA-64 versions of Windows. 123 The Altix uses NUMALink, with white NUMALink cables that can yellow over time due to an unknown process, and it requires a base compute module and NUMALink for system boot. 45 The Altix has an IDE DVD drive, and an IDE to SATA adapter could be used for it. 67 The Altix has a SATA backplane, and the Numalink Think backplanes are compatible with Altix and Rack Tezros backplanes. 89 The IO10 is the boot controller board for the Altix, and it is similar to the IO9 but uses SATA instead of SCSI. 10 The Altix can run IA-64 versions of Windows, and VMs allow for easy setup of specialized environments like SLES11 for an Altix install server. 211 The overall Altix experience is poor, with kernels 4.19 and up not booting and earlier 4.X kernels possibly failing due to ATI card issues. 1213 The Altix maps graphics memory in an unusual way that causes driver issues and crashes with 3D acceleration, and Debian may fare better with the radeon driver. 1415 The Altix was an Itanium server, while the Prism was a workstation. 16 The original Altix was the rack Prism, which is technically also an Altix because it does not run independently, similar to an Onyx4. 1718 Altix systems can run various Linux distributions, with SLES or RHEL recommended, and IA64 Linux works on them. 1920 Some versions of SLES IA64 were supported by the Linux kernel for Altix, but Altix support code was removed from the kernel about two years ago, making it compatible with most IA64 distributions. 2122 The Altix is a blade server with multiple CPUs, disks, and PCI slots, and it uses a bootloader to load the kernel, possibly ELILO. 2324 Graphics on the Altix are limited to AGP, and it can use PCI cards for 2D acceleration, though FireGL cards require custom firmware and may not work with the EFI console. 2526 2D graphics worked well on an Altix with a card supported by the Debian radeon driver, but 3D was more challenging, and the Altix is unstable with GeForce GPUs, requiring a 3.3v PCI graphics card. 2728 QuickTransit 1.2 was the final version for SGI Altix in 2006, bundled with SGI ProPack and SUSE Linux Enterprise Server for Itanium systems, and it works on SLES on an Altix but not on RHEL, possibly due to processor incompatibility. 2930 The Altix and O350 share design elements but are distinct machines. 31 The Altix machine has 4 CPUs, with only 3 ever used, two pegged at 100% and one fluctuating between 80% and 100%. 32 The small Altix configurations run in a circle. 33 The Altix was used for running the information system database at the university 20 years ago. 34 A ready-to-go T2-26.6 ISO for Altix with PCI-E GPU support is available. 35 Prism graphics support is being developed for modern Linux on SGI Altix. 36 The Prism graphics brick has a different interface board than a basic Altix, but it's not necessary to make a graphics brick. 37 The driver disables DMA, and it's unclear if DMA ever worked on the Altix. 38
