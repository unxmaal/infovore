R4400 CPU

Claims: 21 Part of R4400 Background: 1 claim already covered by Wikipedia, see SGI Indy.

The first Indy had a 100 MHz R4400 CPU, and the Onyx used a 200 MHz R4400 CPU. 12 The Indigo2 Extreme was available with R4400 CPUs at 200 MHz or 250 MHz. 345 The R4400 CPU can run IRIX versions ranging from 4.0.5 to 6.5.22. 678 The R4400 CPU can be upgraded to different parts, with the MC and SC versions sharing the same pinout. 910 The R4400 CPU was used in many Impact systems, likely more than those with R10000 CPUs. 11

Sources

  1. The first Indy had a 100 MHz R4400 CPU; 180 MHz was an R5000. (user-237d, 2022-02-16, exchange 220214, check: supported)
  2. The Onyx uses a 200 MHz R4400 CPU. (user-03ad, 2023-08-26, exchange 108503, check: supported)
  3. The Indigo2 Extreme with a 250 MHz r4400 CPU was considered a piece of garbage but is now highly valued for running 5.3 era programs. (user-8547, 2022-01-05, exchange 101435, check: supported)
  4. An Indigo2 Extreme has a 200 MHz R4400 CPU with 2 MB cache and 384 MB RAM. (user-8de9, 2025-03-03, exchange 54881, check: supported)
  5. An Indigo2 Extreme has a 250 MHz R4400 CPU. (user-24f0, 2025-03-03, exchange 54881, check: supported)
  6. The Indigo2 can run IRIX 4.0.5 on an R4400 CPU. (user-f229, 2022-02-09, exchange 240989, check: supported)
  7. The i2 Extreme has a 3 board sandwiched graphics card and can run from IRIX 4.0.5 to 6.5.22 with an R4400 CPU at 200 MHz or less. (user-8de9, 2022-03-28, exchange 233992, check: supported)
  8. The Indy can come with R4400 CPU and includes documentation and IRIX 6.5 media. (user-e532, 2025-09-21, exchange 118713, check: supported)
  9. The R4400 CPU can be upgraded to different parts; the sticker might have fallen off. (user-86e1, 2023-10-28, exchange 241118, check: supported)
  10. The R4400 CPU's MC and SC versions have the same pinout and can potentially be upgraded to run at higher speeds, but require changes to the crystal oscillator and EEPROM configuration. (user-b57f, 2024-07-12, exchange 210646, check: supported)
  11. The R4400 CPU was used in many Impact systems, likely more than those with R10000 CPUs due to the latter's late availability. (user-1a5a, 2025-08-25, exchange 58589, check: supported)
