assembler

Claims: 8

The assembler is GNU version 2.16.1 targeting m68k-hp-hpux9.00. 1 The assembler ships with the system but requires a script to call and lacks good documentation except for a third-party book. 2 The -r4300_mul flag tells the assembler to use R4300 multiplication instructions, and the -Xcpluscomm flag enables C++ comments. 34 The assembler for the RCP/RDP instructions can be extended with additional support if needed, though the configuration file is somewhat cryptic and no recompilation is required. 5 The assembler pads the section to a 4-byte boundary, but --no-pad-sections isn't available in the mips-linux-gnu-as used; using it might cause ROM matching issues. 6 The Fast3D source code compilation process involves using an assembler that may differ from the original, suggesting potential compatibility issues. 7
