vi

Claims: 18

vi is a text editor used to navigate and edit files in UNIX systems, and it is almost mandatory on UNIX variants, though some older SGI systems may only have ed in single user mode. 123 It requires learning a few basic commands such as 'shift-G' to go to the end of the file and 'number + G' to go to a specific line, and basic vi includes multiple registers. 14 vi and vim are command-line text editors, and some variant of vi or ed is likely to be available on any system an IT professional needs to manage. 5 vi is used in classrooms as an example of poor application design. 6 Compiling nvi provides better handling of long lines than the system vi, and running a vi clone on a MicroVAX was achieved. 78 vi on IRIX 6.5.22 has unresolvable symbols in its binary, and root can override read-only file status in vi by appending ! to the write command. 910
