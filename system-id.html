system ID

Claims: 3

The system ID is stored in an EEPROM located on a little blue IDC connector next to the power, which also holds the MAC address and connects to the front panel. 1 The system ID can be changed at bootup, which is useful for transferring a drive between systems. 2 Changing the system ID is not done by modifying a file but by starting a background process, which indicates missing applications. 3

Sources
