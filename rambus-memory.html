Rambus memory

Claims: 3 Part of RAMBUS

A Dual Socket 603 box with Rambus memory was found, and a Pentium 3 system can benefit from Rambus memory, though Rambus boards are hard to find. 12 Rambus memory was used in the framebuffer of Indigo2 Impact cards, was patented and expensive, but was not problematic in practice. 3
