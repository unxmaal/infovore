boot process

Claims: 9 Part of boot

The boot process is similar to Intel's stock server boot process, and it can reboot and run INST with a new selections file pointing to an NFS share for MIPSpro stuff. 12 Booting IRIX from a CD involves inserting the disc, running `boot cdrom`, and answering language questions, and the process is straightforward. 3 The boot process for IRIX can be documented using modern tools even if older documentation exists. 4 The Octane boots the PET system when diagnostics fail and attempts to boot over serial at 9600 8N1 with no flow control and no parity, and the boot process can be observed through serial communication. 5 user-2a24 redid the boot process and it works, but the workaround limits the boot process to specific SCSI drives. 67 A dead battery can prolong the boot process as the system probes and configures every possible device. 8
