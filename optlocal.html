optlocal

Claims: 3

The optlocal package contains a variety of precompiled tools such as OpenSSL, curl, and bash, which can otherwise be compiled manually. 1 The latest 8.2.0 build requires /opt/local to be locally mounted on an Octane because it is NFS-backed. 2 The git in the optlocal for the Octane requires correct X resources to function properly, as missing or incorrect X resources cause segfaults and UI issues. 3
