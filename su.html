su

Claims: 4

su switches to root privileges and can be used to run commands as root, such as creating and chowning /usr/didbs, untarring didbs.tar there, and installing Nekoware packages. 12 sudo changes the environment and runs fewer commands with root privileges compared to su, and can be configured to not prompt for a password. 3 Switching to root with su instead of sudo might resolve library loading issues for sginet -u. 4

Sources

  1. IRIX installation requires `su` to create and chown /usr/didbs, then untar didbs.tar there. (user-f229, 2020-01-01, exchange 77049, check: supported)
  2. To install Nekoware packages, run commands as root using *su*. (user-59b9, 2023-10-11, exchange 41412, check: uncheckable)
  3. sudo changes the environment and runs fewer commands with root privileges compared to su, and can be configured to not prompt for a password. (user-9860, 2022-01-19, exchange 215280, check: uncheckable)
  4. Switching to root with 'su' instead of 'sudo' might resolve library loading issues for 'sginet -u'. (user-fa69, 2026-09-06, exchange 73853, check: uncheckable)
