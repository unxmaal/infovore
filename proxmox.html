Proxmox

Claims: 14

Proxmox is a modern hypervisor that uses KVM and LXC containers and can handle hardware RAID, JBOD, or ZFS storage. 123 Proxmox can export ZFS over iSCSI for shared storage and VM migrations. 4 Proxmox exposes a specific feature set of a virtual CPU to the guest OS, which can be set to emulate older CPUs like Pentium 4. 5 Proxmox can be run on various hardware, including 2U HPE servers and 2019 Mac Pros. 67 ESXi VMs do not boot in Proxmox due to different emulated machines and drivers, requiring learning about quiescing and live backups. 8
