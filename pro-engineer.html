Pro/ENGINEER

Claims: 24

Pro/ENGINEER is a parametric CAD program that ran on a variety of vintage SGI platforms, including IRIX, the 4D/35, the O2, and the Indigo, with version 1 running exclusively on SGI systems bundled with specific hardware. 123456 Beyond SGI, Pro/ENGINEER was also available on AIX, Solaris, MIPS Windows NT, and Linux (only the WF1 version, which was later dropped), and it could run on up to 4GB of RAM on IRIX n64. 7891011 The software uses a complex configuration system built from multiple text files, including the primary config.pro, menu_def.pro, and config.win, with toolbar settings stored in a file in the user's home directory. 121314 Pro/ENGINEER's help is available as an install option located in /opt/ptc/prohelp, though it is based on unreliable HTML files with important information instead found in PDF collections. 1516 It could export the STL format up to WF2, though IRIX lacked slicers requiring transfer to another computer, and models could be converted to DXF for printing. 1718 Performance depends on hardware, with an r5000 with xz processor running faster than an xl processor, and SPECapc benchmarks are available for comparison. 1920 Library disks and media for Pro/ENGINEER, including versions up to wf2, remain available at online archives. 2122
