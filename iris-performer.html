IRIS Performer

Claims: 4 Part of IRIS

IRIS Performer is a rendering library, and OpenGL Performer is a version of IRIS Performer that may be an older version or have compatibility issues; it can be found with the file name performer_eoe.sw32.common_performer. 1 The Atlantis demo fails on XFS file systems due to old IRIS Performer libraries, so mounting an EFS volume and setting PFTMPDIR is required. 2 The 'Iris Performer' demo has visual elements and lighting that differ from those under IRIX. 3 There is an SGI hat, an SGI/Cray research poster, an IRIS Performer T-shirt, and an SGI mousepad. 4
