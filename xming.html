Xming

Claims: 8

Xming is a Windows X11 server that works well, though period-accurate software packages exist but are hard to recommend. 1 It can be used for X forwarding with PuTTY, which requires Xming to be installed, X forwarding enabled in PuTTY, and the DISPLAY variable set to the IP address of the Windows computer. 23 Xming can run on Windows NT 4.0 embedded with limited disk space, suitable for an environment like a Compaq EVO T30. 4 Xming passes the host GPU as the device, affecting neofetch queries. 5 Xming has a specific font path setting that may need to be configured, and regenerating fonts.dir might be necessary to ensure fonts are visible to the X server. 6
