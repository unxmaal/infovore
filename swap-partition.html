swap partition

Claims: 7 Part of swap

With a fresh drive, going to (r)epartition and choosing (ro)ot creates a basic root partition and swap partition without additional configuration, after which backing out and exiting writes the changes. 1 The miniroot boots from the swap partition if IRIX has not yet used it for swap, and an issue may arise from PROM settings pointing to the wrong partition as root, which is partition 0 by SGI's standard. 2 An error message indicating the swap partition is not valid likely means the disk has not been partitioned, and the issue appears to be with the swap partition since manually booting with specific kernel options resolves the error. 34 To recover data, the 'exercise' feature can be used with specific parameters on the drive, though it may overwrite the swap partition. 5 You can mount /usr on an xlv and use a different disk for the swap partition. 6 Diskless booting involves copying a miniroot to a swap partition and mounting it as root, requiring a kernel capable of mounting the root filesystem, with the PROM environment able to specify the root path. 7
