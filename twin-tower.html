Twin Tower

Claims: 4

The Twin Tower is an early Deskside model with the PSU and hard drives in the smaller tower and the RAM, CPU, and GFX in the larger tower. 1 The Twin Tower is a little bigger than Crimson and Onyx1, which are the same size. 2 The RE set on a Twin Tower requires a valid DG2 EEPROM for proper initialization, as invalid EEPROMs cause boot failures and X initialization panics. 3 The 4d/50 model is a twin tower. 4

Sources

  2. Crimson and Onyx1 are the same size, while the Twin Tower is a little bigger. (user-0251, 2020-09-17, exchange 97542, check: supported)
  3. The RE set on a Twin Tower requires a valid DG2 EEPROM for proper initialization; invalid EEPROMs cause boot failures and X initialization panics. (user-c9fb, 2020-12-16, exchange 98035, check: uncheckable)
  4. The 4d/50 model is a twin tower. (user-2d40, 2022-02-06, exchange 101978, check: supported)
