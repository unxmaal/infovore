J5600

Claims: 16

The HP J5600 is a PA-RISC machine that can run with dual 552 MHz PA-RISC CPUs. 1 Although no build is available for PA-RISC, which is required for the HP J5600, the J5600 can be ported and set up for PA-RISC/HP-UX. 23 The J5600 has an SSH server that can be accessed via PowerShell but not Git Bash due to differing key exchange methods. 4 The J5600 can recognize a Logitech G502 mouse as a keyboard, causing it to switch to serial output, but still function as a mouse, and using a gaming mouse with an old UNIX system like the J5600 can cause it to be recognized as a keyboard. 56 The J5600 switches to serial output if it detects an invalid keyboard device, which can be caused by plugging in a Logitech G502 mouse. 7 The Logitech G520 works with an HP J5600 in HP-UX. 8 The J5600 has frequent segfaults and bus errors when running proprietary software. 9 The J5600 has a network bug preventing Minecraft server connection, requiring a kernel patch, so the Minecraft server can run on a J5600 with Java 6 on PA-RISC HP-UX 11.11, but networking may require a fix. 1011
