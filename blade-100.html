Blade 100

Claims: 34

The Sun Blade 100 is an entry-level Sun workstation from the early 2000s, priced at $999 when it launched. 12 It uses conventional PC parts, including a PC-style CPU socket and an ATX power supply. 345 It has an IDE controller that supports ATA66 (UDMA66) mode with dual ATA66 channels, and it can use SATA drives with an IDE adapter, though not all IDE drives work. 678 It can use up to 2 GB of RAM, but individual memory modules may require thorough testing. 9 It uses a standard 34-pin floppy drive interface and supports SCSI. 1011 It has OBP version 4, and early models had a sleep/wake function glitch that was fixed in later models. 1213 It requires a patch to recognize a non-Sun USB keyboard, and it can use Sun->USB converters with a Type 5 keyboard. 1415 Solaris 10 can be installed on it via a netboot server, though Solaris can be challenging to work with. 1617
