loop device

Claims: 5

Loop devices under Linux can read SGI partition tables and XFS filesystems. 1 You can create a loop device from a partitioned disk image and mount it with 'mount -t efs /dev/loop /mountpoint'. 2 To mount an IRIX CD image on Linux, use the command `mount irix-disc.iso /mnt/cdrom -t efs -o loop,ro`. 3 IRIX CDs can be read on modern machines using the efs file system with the loop device. 4 The command to mount an efs image as a loop device is useful. 5
