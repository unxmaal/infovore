sudo

Claims: 19

Sudo is a command that executes a command as a different user, typically root, to perform administrative tasks, and sudo -i opens a root shell. 12 Sudo can be configured to change the timeout and other settings, and it can be configured to not prompt for a password. 34 Sudo changes the environment and runs fewer commands with root privileges compared to su. 4 Sudo is not included with the OS. 5 The touch ID MacBook can be used for sudo with a fingerprint. 6
