X protocol

Claims: 4 Part of X

VNc allows any client that supports VNc to access the entire desktop, but X protocol offers more functionality, though neither X protocol nor VNc provides good graphics acceleration or 3D frame rates. 1 GL over X protocol with rendering on the local machine is simple and meshes well with the X window system. 2 Changing a window to override-redirect after mapping won't notify the WM to release it; it has to be done before mapping. 3 SDL2 should not pass invalid attributes to XCreateWindow, which can cause a BadMatch error; debugging involves checking the X protocol for valid arguments and testing each suspect value in SDL2's code. 4
