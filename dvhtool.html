dvhtool

Claims: 4

dvhtool is a tool for manipulating the SGI IRIX volume header, allowing files to be extracted and written to it. 1 Running `dvhtool -v get sash sash /dev/rdsk/dks0d1vh` and `dvhtool -v get ide ide /dev/rdsk/dks0d1vh` extracts volume headers from an O2 running IRIX 6.5.30, creating files named sash and ide in the current directory. 2 Autobooting can be achieved by placing ARCLoad in the volume header using dvhtool, with config and kernel files located on a /boot partition. 3 To recover from forgetting to add `sash` to the drive volume header, use booterizer with PROM option 4 to boot, mount the real root, and use dvhtool to add `sash`, then reboot for a successful SSH boot. 4
