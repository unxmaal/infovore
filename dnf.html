dnf

Claims: 11

DNF or Dandified yum is the next generation version of yum, roughly maintaining CLI compatibility with yum and defining a strict API for extensions and plugins. 1 DNF installs prebuilt packages from the internet, avoiding manual dependency resolution and building. 2 DNF has larger dependencies than yum, including bash and python3-dnf, and requires additional python packages that haven't been ported yet. 3 A minimal dnf for (mostly) Docker containers uses libdnf and hence does not require Python. 4 The RSE repository contains over 1000 packages, including foundational software and GUI applications, all packaged in RPM format with DNF for dependency management. 5
