malloc

Claims: 5

malloc always returns blocks with a minimum guaranteed alignment, regardless of what is being allocated. 1 Checking the return value of malloc is important to avoid undefined behavior, so reusable infrastructure should always check the result and provide logging callbacks or custom malloc routines. 23 mmap might have weird limitations on IRIX, so malloc should be used instead of mmap. 4 memGrowthAllocate fails with an error raised by mmap, which is used instead of malloc for heap allocation, possibly due to not linking with libc. 5
