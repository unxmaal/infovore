m68k

Claims: 7 Background: 1 claim already covered by Wikipedia, see Video games and Linux.

m68k has been used across a range of operating systems and hardware platforms. 1234567 Unix variants running on m68k include HP-UX, which can be booted and installed in terminal mode, Unisys Unix on IRIS systems with specialized graphics hardware, and SunOS 4.1.1 on a 3/470. 157 VxWorks 5.5.1 was the latest version supporting m68k on SGI systems, ending end-of-life in 2018. 2 Linux supports m68k along with Alpha, 486, SuperH, arc, PA-RISC, and Itanium architectures, but not 386. 4 GNOME 1, written in C, can probably be run on m68k, with the slowest box capable of Linux likely being a 68020. 3 The Sega Genesis board includes an M68K processor alongside a Z80 and a bespoke video subsystem. 6 The SPARC architecture had a minor advantage over m68k in real-world applications early on, but ultimately proved to be the better choice. 7
