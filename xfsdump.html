xfsdump

Claims: 41 Background: 3 claims already covered by Wikipedia, see XFS.

It backs up only used space, which can save disk space, and is used for incremental backups. 12 xfsdump requires specifying the source filesystem and a session label, and can output to a file or device with -f, or to standard output with - when -f is omitted. 34 It can be used to copy data over a network by piping output to ssh, rsh, or netcat, or by writing to an NFS mount or share. 5678 xfsdump can be used to back up data to a local file or NFS share for later transfer, and to dump an SGI drive to a file for network transfer. 910 It is used to move filesystems such as /usr to an external disk, and to clone XFS drives, though it is not suitable for imaging an entire disk. 111213 xfsdump does not ignore NFS mounts by default and can be used from a chroot shell. 1415
