mrxvt

Claims: 19

mrxvt is recommended for terminal use because it supports tabs, customizable scrollbars, and file transfers via xmodem and zmodem, covering most terminal use cases. 123 Setting TERM=rxvt is considered best for mrxvt, and adding a rxvt terminfo file allows using native term capabilities with mrxvt in IRIX. 45 Building mrxvt can fail for various reasons, including the configure script failing to locate compilers even when 'which' finds them, missing libmpc, and the need to edit the hidden .port.sh file to replace /opt/local/bin with $didbs/bin in the PATH. 678 Patching mrxvt to use %ld instead of %d for pid_t can resolve issues with large PIDs. 9 Some users report problems with mrxvt, including color issues caused by setting termguicolors in .vimrc, rendering and text corruption issues that can be fixed by resizing the window, and issues with nethack. 10111213 Other issues include needing to add stty bindings to .sgug_bashrc to use Ctrl-C in sgugshell, setting the TERM variable to 'iris-ansi' to display window borders, and a backspaceKey setting which is ^H. 141516
