Rhapsody

Claims: 12

Rhapsody was a UNIX-like developer release of Mac OS X that was not itself UNIX and ran on x86 and some Macs, including PowerMacs and G3s. 12 It had x86 support before the OS X Server release, with limited hardware support, and the first Mac OS X Server was technically Rhapsody rather than Darwin. 34 Quake II was released for and runs on Rhapsody. 56 Rhapsody is technically still the OS X application in question. 7
