DFU mode

Claims: 3

DFU mode is a device firmware update mode that provides elevated recovery mode access and read-write privileges over the whole system. 1 It is used when the existing OS is not booting the device. 2 In DFU mode, firmware updates overwrite the partitions for OS and apps, and a signed update is required to boot. 3
