htop

Claims: 5

htop is available on IRIX, though it does not support that platform and exhibits some display inconsistencies for CPU load on supported SGI hardware, remaining usable for compiling userlands on an Octane with dual R12K CPUs. 12 It should be run under sgugshell to ensure it can find the libraries. 3 A yum/tdnf repo has been created containing htop alongside sginet, gkrellm, and findutils locate with full text search. 4 htop segfaults on some machines and probably needs the TERM variable adjusted. 5
