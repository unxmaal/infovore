X

Claims: 35 Background: 2 claims already covered by Wikipedia, see IRIX, Video games and Linux.

X has been used through many computing eras and is flexible. 1 The first version of X on IRIX is 3.3, making it more portable for writing applications. 23 The SGI X implementation is based on X11R6, with some models using XFree86 from around 2000. 4 X uses tokenized OpenGL calls to minimize network traffic, especially for texture objects and display lists. 5 center-click-paste is an X feature available on most Unix systems using X. 6 Unsupported hardware can prevent X from working. 7 Old X tends to have issues with VMware's generic SVGA Adapter, causing 'no screens found' errors; changing the video driver or bit depth may help. 8 X doesn't support XRANDR but xorg client libs have fallbacks. 9
