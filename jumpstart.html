Jumpstart

Claims: 4

Jumpstart allows netbooting Solaris by responding to client addresses via /etc/hosts and /etc/ethers, tftping the kernel, and checking a custom config file for installation. 1 It uses TFTP to load data over the network, with ARP/RARP for connection establishment. 2 Jumpstart can install Solaris over the network on a T1000, showing package installation details. 3 It can be used even with a broken Ethernet address if the network address is set in OBP before booting. 4
