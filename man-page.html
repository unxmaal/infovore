man page

Claims: 6

  • reading manpages is useful for understanding commands across different UNIX systems. (user-37ee, exchange 11225, 2020-09-28; 1 speaker(s), 1 conversation(s))
  • There were tools for creating a tardist with selectable install sections for the main install, manpages, dev libraries, source, etc. The build version could be iterated, showing up as an update for a previous install. (user-d903, exchange 217302, 2021-11-14; 1 speaker(s), 1 conversation(s))
  • The setgfx man page describes options for outputting SoG and sync bits; the default often includes SoG. (user-9860, exchange 205868, 2021-11-09; 1 speaker(s), 1 conversation(s))
  • The `man` command on IRIX treats some manpages as pre-formatted 'cat' entries and others as unformatted nroff source, even if `MANFMTCMD` is set, and only processes nroff if the file is not compressed. (user-f190, exchange 219415, 2026-01-19; 1 speaker(s), 1 conversation(s))
  • IRIX ships manpages in catman format, which is difficult to parse. (user-6c80, exchange 219414, 2026-01-18; 1 speaker(s), 1 conversation(s))
  • IRIX does not have a `dladdr()` but instead provides source code in the manpage to implement it. (user-42cf, exchange 66942, 2019-01-05; 1 speaker(s), 1 conversation(s))
