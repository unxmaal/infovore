Xnest

Claims: 7

Xnest is a client for remote X on Linux, while Xmanager 6 is recommended for Windows. 1 Xephyr is a full X server alternative to Xnest that offers fewer bugs and more features, including OpenGL support. 23 Xnest can be used to run two X servers, but they cannot coordinate inputs, and it can also create a headless desktop session over TCP. 45 Running two X servers with separate screens requires a fullscreen Xephyr/Xnest on :0.1 for a proper XDMCP connection. 6 Using Xnest with :1 -query ip.of.the.box no longer works for connecting to IRIX via XDMCP. 7
