Mach

Claims: 8 Background: 1 claim already covered by Wikipedia, see NeXTSTEP.

Mach descends from a kernel called 'Accent' that ran on PERQ workstations. 1 Mach is not UNIX; it uses the mach-o file format for executables, unlike Tru64/OSF1 which uses COFF. 2 Tru64 is Mach under the hood, but its userland is straight SVR4 with the admin tools and package/licensing system from Ultrix. 3 NextStep is a generation 1 user-space kernel based on Mach, not a true Unix. 4 Unixes generally cannot swap out kernel code and data, though Mach can but infrequently uses it. 5 Mach does not support multiprocessing; it will not work with dual-CPU SPARC or x86 machines, though some dual x86 systems have been reported to work. 6 Mach is going to give LLVM a go later this year. 7
