OHCI

Claims: 4

OHCI is a USB 1.1 chipset that is mostly hardware-based, requiring a driver similar to a SCSI card. 12 This hardware-based approach contrasts with UHCI, EHCI, xHCI, and VHCI chipsets, which are software-based. 3 IRIX supports OHCI chipsets for both USB and FireWire. 2 MacOS versions before 9.x used the same OHCI chipset strategy as IRIX. 4

Sources

  1. OHCI is USB 1.1 only, but supports USB Keyboard/Mouse, and PS/2 sets are harder to find and less reliable. (user-8b3c, 2020-01-28, exchange 5744, check: supported)
  2. IRIX supports OHCI chipsets for USB and FireWire, which is a mostly Hardware-based implementation requiring a driver similar to a SCSI card. (user-8b3c, 2020-05-30, exchange 216937, check: uncheckable)
  3. IRIX's decision to support USB and Firewire is based on Hardware vs Software implementation, with OHCI chipsets being mostly Hardware-based and UHCI, EHCI, xHCI, VHCI, chipsets being Software-based. (user-8b3c, 2020-05-30, exchange 216937, check: uncheckable)
  4. MacOS < 9.x used the same OHCI chipset strategy as IRIX. (user-8b3c, 2020-05-30, exchange 216937, check: supported)
