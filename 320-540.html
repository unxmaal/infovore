320/540

Claims: 5

The 320/540 are different architectures from the 230/330/530, which were PCs with nVidia graphics marketed as VPro as part of a lawsuit with nVidia. 1 The 320/540 are Intel processor successors using SGI-designed Cobl architecture with an Intel CPU, but they are not PC compatible. 213 These systems start up looking like a MIPS system, and you can run some Linux distros on them. 45
