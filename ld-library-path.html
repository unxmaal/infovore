LD_LIBRARY_PATH

Claims: 11

LD_LIBRARY_PATH (and/or LD_LIBRARYN32_PATH) is an environment variable that can be set to add library paths used to specify library directories. 12 The order of directories in LD_LIBRARY_PATH matters, with /usr/lib32 first potentially causing older libraries to be used first. 3 Setting LD_LIBRARY_PATH and LD_LIBRARYN32_PATH to /usr/lib32 and specific library paths ensures correct library resolution for 32-bit binaries. 4 LD_LIBRARY_PATH is needed on IRIX to find libraries, including when ./configure does not find the ncurses library. 567 LD_LIBRARY_PATH may be required when programs install to non-standard locations, and it can be set via scripts or adjusted in ELF binaries with tools like chrpath, which have limitations. 28 LD_LIBRARY_PATH can cause issues with linking curses libraries, and it can be set to run SDL games or via the crle command to modify the runpath in the executable. 910
