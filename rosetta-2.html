Rosetta 2

Claims: 6 Part of Rosetta

Rosetta 2 is Apple's emulation software that provides support for Intel-based Mac apps, allowing an ARM Mac to run x86 applications. 12 An M1 MacBook Pro can run x86 applications through Rosetta 2 with decent performance. 3 Rosetta 2 can build both x86 and ARM binaries, allowing an ARM Mac to cover both architectures. 1 Rosetta 2 is probably not as good as original Rosetta due to differences between PPC and x86 architectures and the need for workarounds to emulate x86 properly. 4 A new OS would need a Rosetta 2 layer for compatibility with Linux and Windows through Wine. 5
