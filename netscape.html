Netscape

Claims: 27

Netscape was a web browser available on multiple platforms, including IRIX, HP-UX, and the Powerbase 180, where it could be found in the applications directory or came pre-installed. 123 On IRIX, Netscape installation sometimes required workarounds, such as creating a realroot directory to address a license manager issue, and standalone releases were available on firmware CDs, some without encryption. 45 Netscape could create lock files in the root home directory during a root login, and deleting these files could resolve issues with the browser crashing or failing to use the disk cache, global history, or personal certificates. 678 Netscape had various technical issues, including crashes caused by incorrect MPEG-1 video dimensions, image corruption during X forwarding, and problems with gzipped VRML files. 91011 Netscape was used to view VRML demos, could install the Cosmo Player for that purpose, and had a nagware feature that added default bookmarks on upgrades. 121314
