MGRAS

Claims: 22 Background: 1 claim already covered by Wikipedia, see SGI Octane.

The MGRAS is a graphics card that supports certain resolutions and configurations, but has VRAM limitations that prevent it from performing certain GL operations at 1920x1080 24bpp. 1 On vPro hardware it performs color space conversion on the CPU, while on MGRAS it uses the color matrix extension. 2 inst files can have GFXBOARD or MGRAS restrictions that can be overridden with -m GFXBOARD= or -m MGRAS= options or by modifying the files with sed. 3 The maximum pixel clock for MGRAS is 160MHz, which is lower than the required for 1920x1200 resolution. 4 An Octane can support VPRO and MGRAS, but only one will work correctly; multiple SE heads can be used, but an Octane accepts only three. 5 Mixing MGRAS and VPro graphics in the same machine can cause compatibility issues. 6 Textures can appear as rainbows or be invisible, affecting gameplay, which may be due to insufficient texture RAM on MGRAS, which has only 4 MB. 7 MGRAS offers options for V12+DCD without a breakout box. 8
