Maya

Claims: 122 Background: 3 claims already covered by Wikipedia, see Autodesk Maya.

Maya is a 3D software that succeeded Wavefront, the previous best 3D software for SGI systems, and took over the animation role previously held by Alias Studio Tools and PowerAnimator. 123 Maya runs on PowerPC and was sold commercially on Linux, and may still be available there. 45 Maya is not a 64-bit application and has a 2 GB memory buffer limit even on systems with more RAM, running on 32-bit machines such as the O2. 67 Maya requires a proper 3-button mouse, and IRIX 6.5 requires at least 512 MB of RAM for it. 89 Maya is expensive, and IRIX software often requires node-locked licenses based on hardware details and serial that can be costly, especially for older titles like Maya. 1011 Maya can be installed on various SGI machines, including the Indigo2 R10K (Maya 2.5), the V6, and the Octane, though the base Octane is not suitable for demanding tasks like running Maya. 121314 Maya installation may have issues, possibly related to licensing configuration, and reinstalling commercial software like Maya requires the license.dat file. 1516 Alias, originally PowerAnimator, was stripped of animation features to create Maya, and Alias going independent and releasing Maya for other platforms contributed to SGI's decline. 317 Maya was ported to Linux from IRIX, along with XFS and some clustering software, as well as Discreet software. 18 Maya is a 32-bit application. 19 Maya supports distributed rendering through a feature called Dispatcher, with configuration instructions included in the installation. 20 RenderMan artist tools was an addon for Maya, and RenderMan was primarily used inside Maya for prepackaged setups. 2122 SoftImage or Maya are commonly used for animations, and they were pushing Maya for the animation stuff after v9. 2324 Maya has a 30-day free trial and an indie license costing $300 a year, which allows projects valued at up to $100,000 or for solo users making less than $100k a year in revenue. 2526 Autodesk no longer holds Wavefront's IP, which was destroyed upon acquisition, with focus on Maya. 27 Maya is an Alias and Wavefront product that is no longer actively supported by Autodesk but may still be relevant, and it is not available for hosting. 2829 Maya 4.5 and 4 are not available on IA. 30 The O2 can run TAV with various versions of Maya installed, and it runs IRIX 6.5.30. 31 Some Alias3-era UX elements persist in Maya. 32 Maya has both a Software Render and Mental Ray render engines; Paint FX procedural textures work in both, but some textures may not render correctly in one engine without conversion. 33 Mental Ray in Maya is not fully compatible with all Maya features like Maya Fur, PaintFX, and Particle shading. 34 Hypershade is Maya's shader builder, allowing users to drag and drop materials and textures in a node-based hierarchy without typing in a text editor. 35 Modern Maya UV tools are more advanced than those in Maya 6.5. 36 The modeling marking menu in Maya 6.5 had an add-on called Bonus Tools, which became standard in Maya 7. 37 CGI overtook 2D animation in studios with a copy of Maya after 2004. 38
