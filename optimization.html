optimization

Claims: 9

Optimization can cause compiler bugs that break programs, such as readline 8.0 requiring -O1 with mipspro and possibly -O0 if optimization fails, and Bash failing on MIPS Pro by losing the first character of the command line. 12 Optimizing MIPS code can be difficult, as interleaving int and fp ops required effort that led to compiler trust, and C compilers usually do not produce direct translations. 34 Optimization is sometimes required, as compiling kernel modules needs it, and it can reduce build size, as shown by the Irix image dropping from 28M to 2.2M. 56 Optimization has downsides, including diminishing returns where effort for small gains increases, and it can obscure disassembly, making analysis difficult. 78
