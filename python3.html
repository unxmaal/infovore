python3

Claims: 10 Part of Python

python3 is a Python 3 implementation that can be installed by downloading a specific torrent and following certain steps, and Crash Course is an environment script needed for it. 1 There are patches for Python2 and some for Python3 on IRIX. 2 The Makefile includes paths for Python3 and libraries like -lsocket, -lnsl, -intl, -ldl, and -lm. 3 Running `python3 test.py` results in a bus error and core dump. 4 python3 is required to build libdnf. 5 python3 is not available on retro machines (normally). 6 python3 runs on modern machines to serve an http daemon which can be accessed from retro machines using 'get'. 7 mplayer 1.4 can play YouTube videos on an SGI Octane2 with Python3 and netsurf. 8
