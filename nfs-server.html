NFS server

Claims: 20 Part of NFS Background: 4 claims already covered by Wikipedia, see File server, Network File System.

NFS server is used for sharing files between machines, which can simplify file moving and serves as another method for copying files. 123 An SGI can be configured as an NFS server, but it is more practical to have a NAS or similar dedicated NFS file server. 4 An NFS server should be available on your network for the SGI to connect to via NFS, and NFS works well for sharing files between an IRIX machine and an NFS server. 56 The QNAP and Qube can be used as NFS servers, and the bootpd server must correctly provide information for the NFS server to function for network booting. 789 NFS hard mount can cause clients to get stuck indefinitely if the NFS server becomes unreachable. 10 Setting up an NFS server on macOS Mojave is easy, though the NFS server on a G4 Mini has okay reliability but can cause kernel panics. 1112
