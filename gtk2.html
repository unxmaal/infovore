gtk2

Claims: 12 Background: 4 claims already covered by Wikipedia, see NetSurf, GIMP.

gtk2 is a GUI toolkit that netsurf can use as a frontend, though netsurf is built in C# and requires gtk2 or glib to run. 1 gtk2 can be made to work, and gdk-pixbuf2 was resolved to get gtk2 working. 2 Building GTK2 requires dependencies like pango, cairo, freetype, and glib, along with GNU make and m4. 3 gtk2 is faster than gtk3, though there is no proof of this. 4 netsurf supports multiple frontends including GTK2, GTK3, RiscOS, raw framebuffer, and a motif front end which is being developed and may be shippable. 5 The Motif netsurf frontend is slower than the GTK2 frontend. 6 To change the font in netsurf's window menus, edit the default font in ~/.config and the CSS file in ~/.themes, and modify the gtk2 config in the home directory. 7
