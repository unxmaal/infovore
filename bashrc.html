.bashrc

Claims: 16

.bashrc is a file used by bash to set up configurations, and it is saved in the home directory. 12 It runs every terminal session and every time a new window is opened, so it is used for permanent environment variable changes. 13 Login shells run .profile and non-login shells run .bashrc, and sourcing .bashrc from .profile ensures it runs for both. 4 It can be used to add directories to PATH, such as exporting PATH=/opt/local/bin:$PATH, and to set aliases. 567 The prompt in .bashrc can show the current branch and be updated with any command in the window. 8 It is not always run depending on how the client requests a shell, and Bash does not load it when using winterm. 910
