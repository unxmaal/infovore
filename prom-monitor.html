PROM monitor

Claims: 11 Part of PROM

The PROM monitor on Unix boxes, especially Suns, offers high-quality graphics from boot. 1 To access the PROM monitor, hit escape when booting and type 'ide' to run the diagnostics suite. 2 The PROM Monitor prints its version with 'BE' for big-endian and 'LE' for little-endian architectures. 3 Updating the hardware inventory in the PROM monitor can resolve issues with new or re-enabled components. 4 The error is likely due to the eaddr not being set in prom monitor; setting 'setenv monitor h' or 'setenv -f eaddr 08:00:69:12:34:56' should resolve it, and 'printenv' can be used to check the eaddr. 56 If the machine POSTed and displayed the PROM monitor, the motherboard might still be salvageable. 7
