xfsrestore

Claims: 14 Background: 2 claims already covered by Wikipedia, see XFS.

xfsrestore is used by the network-based IRIX install system, which can be run on any computer with the VM starting included. 1 xfsrestore can restore the contents of an IRIX xfsdump onto a Linux XFS disk. 2 xfsrestore can restore contents into a new directory. 3

Sources
