GPU passthrough

Claims: 3 Part of GPU

GPU passthrough allows a user to run Windows in a VM using KVM. 1 Running multiple VMs on a single GPU requires specific configurations that many cards do not support, and NVIDIA may block it on certain models. 2 CentOS 8 can be used as a base for GPU passthrough with KVM, though NVIDIA may require blacklisting consumer GPUs. 3
