FTP

Claims: 86 Background: 19 claims already covered by Wikipedia, see File Transfer Protocol, Wget, Network File System.

With IRIX

IRIX runs several outdated and insecure services by default, including telnet and ftp, and FTP is installed by default on IRIX. 12 IRIX can establish FTP connections between different systems, and the ftp client in IRIX is 'ftp'; it works in the console and can be used with Netscape for a visual view. 34 The `ftp` command is part of the stock functionality on IRIX, and Irix comes with an FTP program called FTP in the terminal. 56 FTP on IRIX can be used for software installation, such as mounting CD images in Linux and FTPing the contents to the IRIX system, and can be set up using a guide from a Linux box, logging in and downloading files. 78 The man page for the IRIX `ftp` command is available at https://nixdoc.net/man-pages/IRIX/man1/ftp.1.html, and FTP on IRIX IRIS does not support passive mode. 910

With NFS

Networking via FTP or NFS is quicker and easier than setting up serial ports for the Indy. 11 MAME supports networking, including NFS or FTP for file transfer. 12 NFS or FTP can be used to share files with a Win9x machine, but Git on IRIX is a better solution for project files. 13 NFS is better than FTP for networked storage. 14 NFS, FTP, or SCP can be used for SGI installs. 15 FTP is useful for transferring files but not for running commands; NFS is needed for that. 16 FTP, SCP, NFS, or networking in general can be used to transfer files to an SGI Octane without an external CD drive. 17 NFS can be used to transfer files over the network, and FTP is another option for file transfer. 18

General

FTP is a standard method for transferring files, operating similarly across Unix, BSD, Linux, and Windows systems, and is commonly used to transfer files between Unix systems. 19202122 FTP can be used via the command line, and the command is available by default in some installations but may need to be installed on others, such as Debian. 19232425 FTP establishes a separate TCP connection for data and supports both ASCII and binary modes, with binary mode being necessary to avoid corruption when transferring certain files. 26272829 FTP can be used to transfer files between various systems, including older computers without reliable USB or FireWire support, and as an alternative when NFS installation fails. 3031323334 FTP is considered outdated, less secure than HTTPS, and is being phased out, as Firefox stopped supporting it, though it remains desired for backwards compatibility. 35363738 FTP is a file transfer protocol that can be used alongside other tools such as ftp, rcp, and sz/rz to move data between systems, including transferring files between Alpha and x86 workstations and between IRIX machines. 394041 FTP can transfer files without needing an HDD in an Indy, and can be used to access systems configured with an IP address, as well as to mount directories such as the home directory of an Indy. 424344 FTP works for file transfer in IRIX 6.5 because it supports passive mode, but not in IRIX 5.3, where passive connections are unsupported and manual configuration is required due to NAT and passive mode issues. 45464748 FTP passive mode works in IRIX 6.5 but is slow for large transfers, and FTP will not work if there is no local space to write out the whole file. 4945 FTP does not support uploading folders directly, and excessive network activity, particularly with FTP, can crash the network interface, requiring a reboot to recover. 5051 FTP can be set up easily with a single command, and documentation and Unix resources can help with setting it up. 5253
