root

Claims: 17

Accessing utmp with certain privileges could allow an escalation to root, demonstrated by writing a garbage timestamp to run arbitrary code as root on the next login. 1 Running as root can expose systems to security risks, even if the system is not connected to the internet. 2 sudo executes a command as a different user, typically root, to perform administrative tasks. 3 It is advised not to use root directly except to make yourself a regular user account. 4 Multiple passwd names with UID 0 have been used. 5 IRIX places the root user's home directory in /usr/people/root, unlike Linux which places it in /. 6 The IRIX file system allowed running root, user, and home directories from different locations, sometimes with root being local or remote, and home on a server, due to expensive storage. 7 Root having its home directory as root is a superficially sensible but inconvenient and dumb practice. 8
