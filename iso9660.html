ISO9660

Claims: 13 Part of ISO

IRIX can read ISO9660 DVDs, though UDF support is uncertain, and ISO9660 is supported with optional Joliet and Rock Ridge extensions, though it may fail with Joliet. 123 ISO9660 support was added to SGI systems through a hack to NFS. 4 The sector size on SGI CDs is 512 bytes, and on ISO9660 it is 4096 bytes. 5 The `mount` command requires the `-t iso9660` option and `-o loop` option to be correctly placed, and to mount a CD-ROM, use 'mount -t iso9660 /dev/scsi/sc0d5l0 /mntpnt', with the device possibly on SCSI 3-6. 67 You can mount ISO9660 files but not `img` files as a loop device in IRIX, so loopback mounting the ISO on a Linux machine and then copying it works. 89 efsextract works with ISO9660 discs but not all MIPS Magnum discs, with bugs including stack corruption when buffer size is not 512 bytes. 10 The term 'iso' can be ambiguous, referring to either ISO9660 or EFS-formatted CD image dumps, and Irix install CDs use EFS format. 1112 The Solaris 2.6 ISO is an ISO 9660 filesystem. 13
