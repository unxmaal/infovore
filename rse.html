RSE

Claims: 79 Background: 2 claims already covered by Wikipedia, see CMake, Heartbleed.

RSE is an rpm-based project providing basic IRIX packages and enabling porting of new software. 1 It runs well on newer versions of IRIX and is biased towards 6.5.30. 23 It can be installed by reading the README.md on github. 4 The IRIX Catalogue can launch RSE packages. 5 It includes cmake, which is available on IRIX. 6 RSE 0.0.7beta 'Miss Moneypenny' adds 154 new packages and 1124 binary RPMs. 7 RSE (RPM Software Environment) is based on FC31 and uses RPM for package management, packaged as an RPM. 891011 SGI used existing tools like RPM to create tardist packages rather than reinventing the wheel, though tardist itself was not used for RSE due to untarring time and lack of lifespan. 1213 The RSE approach using RPM gains the entire source tree of fc.31 and allows for building relevant software packages for IRIX. 8 Contributors to RSE explain their decisions openly and encourage interaction with the code. 14 There are issues building GL programs against RSE right now, including a specific invocation required to get OpenGL packages built with the GNU tools in RSE to link with OpenGL properly. 1516 The newer libXext in RSE conflicts with IRIX's version due to SGI-specific callbacks, requiring linker flag adjustments, and adding a x11.pc pkg-config definition and including xrender headers can fix most X extension issues in RSE. 1718 An Octane can take multiple days to compile software for RSE. 19 RSE does not exist for 5.3. 20
