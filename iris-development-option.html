iris development option

Claims: 4 Part of IRIS

The iris development option (IDO) is required to build MEX on IRIX 4.0 and to provide the system headers and libraries needed when installing GCC separately. 12 The IDO is specifically needed for version 5.3. 3 The iris development option was the main compiler for most games, and version 7.4.4m lacks the mul-mul bug fix. 4

Sources

  1. Building MEX on IRIX 4.0 is possible with iris development option. (user-9528, 2022-02-28, exchange 188245, check: supported)
  2. GCC can be installed separately, but system headers and libraries require the IRIS Development Option. (user-21b8, 2024-06-09, exchange 215508, check: uncheckable)
  3. You need the IDO = iris development option specifically for 5.3. (user-03ad, 2024-12-02, exchange 215593, check: supported)
