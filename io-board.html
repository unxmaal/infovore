IO board

Claims: 14

The IO board is a simple, open-source breakout board that you can plug a Compute Module into. 1 The I/O board for the original PS1 is a two-board set. 2 The i/o board has built-in fiber. 3 The Compute Engine has specific part numbers for its I/O Board, CPU, CPU (Aux. RAM Boards), and RAM Controller. 4 The IO board is unique between the v880 and v890, but the fire plane is identical between US-III/IV/IV+. 5 The NPE-300 requires an I/O board for anything below an NPE-G1; a single FE I/O board works with a PA-4T, PA-2FE, and ATM on a Cisco DSLAM. 6 The MAC address is hard-coded on the IO board, not stored in the Dallas chip. 7
