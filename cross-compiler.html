cross-compiler

Claims: 10 Background: 1 claim already covered by Wikipedia, see LLVM.

Binutils is built to produce output for the target system by the cross-compiler. 1 To use a cross-compiler, set environment variables like CC and CXX to point to the cross-compiler binaries. 2 Running `vagrant provision` repeatedly ensures the VM has the crosscompiler and Irix headers installed in /opt/gcc and /opt/binutils. 3 Cross compiler support was alive but the cross compiler did not work fully. 4 The GCC way of describing compilation targets changed significantly between versions 4.x and 5.3, with 5.3 being more challenging to support with a cross-compiler, while LLVM is easier to use as a code generation backend. 5 A cross compiler can be built using a script in the irix directory of the llvm14-irix branch. 6 A cross-compiler for IRIX can build x86 binaries. 7 If you're asking about missing libraries and header files, it should be enough to copy them from your SGI machine to the PC's sysroot directory in the cross-compiler, though some libraries may need to be added manually. 8
