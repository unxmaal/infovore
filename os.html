OS

Claims: 51 Background: 1 claim already covered by Wikipedia, see ZFS.

An OS is not a monolith; different libraries and subsystems handle different capabilities, and bits of the OS can be built individually. 12 Some OSes use persistent virtual memory and include a built-in RDBMS. 3 NT kernel-based OSes could fully load the kernel for a performance boost around 512MB of RAM, and recompiling the OS with modern optimization techniques can improve performance. 45 Some OSes are finely tuned to their hardware with specific drivers, and some can be booted off a USB stick on a modern laptop. 67 Some OSes have a universal compatibility layer for hardware calls that should work similarly to other Unix systems. 8 Some specific graphics cards allow an AMD-based iMac to handle Metal with a patched OS, and the OS lagged behind in support for hardware capabilities but caught up with vendor support for drivers. 910 The output device can be configured differently in OF and the OS, affecting where messages are displayed. 11 The CADR Lisp machine emulator runs on Windows and shows a different approach to modern OS and Lisp. 12 The OS is a desktop environment that requires a compiler and a lot of free time to be useful. 13 The graphics don't work well on any machine except the Indy; other machines can run firmware but fail with the OS, and a serial console can be used for installation and running the OS. 14 Bootstrapping an SGI workstation involves pointing it at the .ini file for the desired OS and the disk image. 15 IRIX uses FLEXlm in FLEXlm v4 compatibility mode even if later versions shipped with FLEXlm v6, v8 or v9.2 libraries. 16 Video output may require the system to be in the OS; serial output issues may be hardware related. 17 The OS only supports one keyboard layout and it can't be changed, it's hardcoded in the kernel. 18 When setting up an Amiga emulator, one must buy the ROMs and OS, though these can be obtained elsewhere. 19
