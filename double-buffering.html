double buffering

Claims: 7 Background: 2 claims already covered by Wikipedia, see Framebuffer, OpenGL.

Double buffering renders to a back buffer and swaps it with the front buffer, which prevents flicker. 1 It is used to ensure the screen is updated correctly, though it can be avoided using glFinish() and glFlush(), which is not ideal for performance. 2 On modern systems it can work without vsync, but on older systems like IRIX it can cause flicker. 3 Without double buffering there is no buffer to vsync, so disabling it can eliminate vsync-related flicker. 4 With an 8 bytes/pixel framebuffer, 24-bit color cannot be combined with a zbuffer and double buffering, while 16 bytes/pixel allows quad-buffer and z-buffer with 10-bit color. 5
