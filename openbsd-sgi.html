OpenBSD/sgi

Claims: 16

OpenBSD/sgi is officially discontinued since 2021, though it runs in 64-bit mode and boots multi-user on supported systems. 12 OpenBSD/sgi 7.0-7.4 works on IP22, IP27, IP28, IP30, and IP32 with specific CPU types, while OpenBSD/sgi 7.9 works on Octane2, Indigo², and R4600 Indy. 34 All graphics options but the IP27 Kona frame buffer should be supported, on which the kernel will be limited to serial console operation. 2 The IP28 has issues with OpenBSD/sgi, and it detects 256 MiB of RAM when only 128 MiB are configured, causing GIO timeouts. 56 The OpenBSD/sgi network boot process uses DHCP for IP assignment, TFTP for the boot image, and Bootparamd for file system and swap partition information. 7 The OpenBSD/sgi driver for the wd33c93a SCSI controller has a bug where it does not clear low bits of TLB entries for 16k pages, causing confusion in the tlbmap layer. 8
