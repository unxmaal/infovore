xsetmon

Claims: 12

xsetmon is a control panel for video output options, available via /usr/gfx/xsetmon, and can be used after logging in. 123 It can change the resolution IRIX runs at, set the default startup resolution when run as root (saving the setting in the user's dot files), and apply gamma settings without a GUI at login by configuring it in .sgisession. 456 Framebuffer settings in xsetmon can impact the visual modes reported by glxinfo, such as the bit depth and doublebuffering. 7 Resolutions between 109Mhz and 193Mhz won't work on v6/v8 systems and will be ignored by xsetmon, and the 1920x1080 resolution is not available in xsetmon, so users may need to use setmon directly. 89 A monitor that doesn't properly filter SoG signals may cause green coloration that can't be fixed with software, but using a VGA adapter on the first port can make the monitor compatible with SoG. 410 Using a VFO file created with xsetmon can result in graphical corruption due to incorrect microcode. 11
