IRIS GL

Claims: 71 Part of IRIS Background: 15 claims already covered by Wikipedia, see IRIS GL, OpenGL, IRIX.

With Onyx4

The Onyx4 is a high-performance SGI system using ATI FireGL cards (up to 12x faster than the V12 Pro), with DVI outputs for high resolution, programmable shaders, and lower power consumption. 12 The Onyx4 does not support IRIS GL. 34567289 It uses XFree86, which leads to compatibility issues with many applications, and a third-party tool for Linux exists but is not from SGI. 46 Because it cannot run IRIS GL, the Onyx4 lacks full 4DWM features and vector icons, and few demos work. 28 The Onyx4 is useful for running IRIX software and using CAVE-type systems, but has compatibility issues with some software. 9 mediarecord is an IRIS GL application and does not work on the Onyx4. 10

General

IRIS GL is a low-level, immediate-mode graphics library that is SGI-specific and less portable than OpenGL, though it is simpler and faster, offering better performance on low-end hardware and maximum compatibility with all system versions. 11121314 IRIS GL uses IGLOO for translation and is hardware-accelerated, with the OpenGL API available on older hardware but with limitations. 1516 IRIS GL was used in end-user software such as VizServer and OpenTransit, and was mission-critical for custom software like early PowerAnimator and Explorer. 1718 IRIS GL supported features including display lists (since version 1.0), texture mapping, backface culling, and texture objects, which were added to fix a problem with texture state caching assumed in display lists. 192021 SGI ported IRIS GL support to their later chips, and all IRIX systems can use IRIS GL except for Onyx 4 systems, while all configurations of the Indigo2 support it except for the server/headless ones. 222324 Before 1993, SGI used IRIS GL instead of Xlib for window creation, and IRIS GL manuals mention a 'mixed model' for combining Xlib and IRIS GL. 25 The original IRIS GL code is being used to bring back the full original software, with IRIX 3.7 including full source code for IRIS GL, test programs, and MEX, making it complete; the goal is to port IRIS GL and incrementally upgrade it on a desktop. 2627 ProE had an IRIS GL-based menu system that took years to implement on Windows. 28 The O2 does not support IRIS GL extensions despite supporting SGIX equivalents. 29 ep was a demo for a larger IrisGL program with scripts and sliders and mentions dial I/O. 30 Fuel does not run programs in COFF format and likely does not support IRIS GL. 31
