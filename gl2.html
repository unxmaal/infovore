GL2

Claims: 21 Part of GL Background: 2 claims already covered by Wikipedia, see SGI IRIS.

GL2 is the 68k operating system used by IRIS 2000/3000 machines, and it is the name of the IRIX operating system, with versions like 4d1-2.0. 123 GL2 and 4D1 both originated from AT&T UNIX releases, with GL2 incorporating additional UniSoft 68K platform code and SGI graphics, while 4D1 also includes RISC/os code. 4 GL2 systems ran GL1 and GL2, which are probably like SVR2 or SVR3, but not SVR4, and possibly SVR1 or System III, and GL2 code was ported to SVR3, which was 4d1-3.0. 56 The SGI documentation uses 'IRIX' to refer to early versions, including GL2, which can cause confusion with version numbers. 7 GL2 source code is available on GitHub, and information about GL2 is minimal and can be found on specific websites. 8910 http://bitsavers.trailing-edge.com/pdf/sun/NeWS/The_NeWS_Book_1989.pdf details the porting process of NeWS to GL2/4D1, Chapter 9, section 3, page 189. 11
