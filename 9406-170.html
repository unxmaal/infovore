9406-170

Claims: 5

The 9406-170 has yellow panels for the Domino server promotion. 1 It can be used for IRC client development but faced issues, including difficulty mounting ISO images as a virtual CD ROM to install RPG packages when physical access to the machine was unavailable for a period. 23 Without an expansion chassis, it uses a single 120V plug; with the expansion chassis, it uses two 120V plugs. 4 Replacing a battery requires removing a card bracket, which involves taking out long cards and four screws, but can be challenging. 5
