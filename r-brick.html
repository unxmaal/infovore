R-brick

Claims: 13

The R-brick is used with L-serials and requires 48V, whereas the Numalink router used with M-serials runs on 110/240V. 1 The R-brick requires serial number changes for use with O300s/O350s, and can be configured to support M-serials with a documented procedure involving a Dallas chip from a Fuel. 23 Updating firmware on an R-brick requires a RHEL7 VM and specific tools. 4 The R-brick's L1 can be brought up and the router type can be changed using `help`, but it requires a security key. 5 It is possible to change an R-brick from a 6-port to an 8-port configuration, but it may require downgrading firmware and could result in errors or 'carnage'. 6 Beyond two C-Bricks, each additional C-Brick requires an R-Brick per rack. 7 An Origin 350s with R-brick can run Debian 13 and control multiple nodes via NUMALINK. 8 The serial or Ethernet port on the R-brick motherboard does not work. 9
