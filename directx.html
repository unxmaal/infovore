DirectX

Claims: 13

DirectX is a set of graphics APIs that became messy before it stabilized. 1 The Source engine requires DirectX, and Source 2007 requires a shader model that is too new. 2 Windows 98 with drivers and DirectX can make C&C Red Alert run perfectly on a P II. 3 The video card of the Alpha system supports DirectX and OpenGL, making it more flexible than other boards tested, though its motherboard does not work. 4 The Visual Workstation is x86 NT and lacks DirectX support, making gaming difficult. 5 NT4 does not support newer DirectX versions, so OpenGL is the best option for testing games, but finding compatible games is difficult. 6 Special applications, such as DCS and Adobe products, pose a barrier to running SGI systems on Linux due to reliance on DirectX and subscription models. 7 A DirectX driver for Linux allows the Linux kernel to communicate with Windows DirectX for accelerated 3D, but not for Linux apps to use the DirectX API directly. 8
