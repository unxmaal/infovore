XTIDE

Claims: 5

XTIDE is relevant when examining a machine with an 8-bit bus. 1 The machine can be booted using an XT-IDE to install DOS. 2 Flashing the XTIDE to point to 80h instead of 81h can swap the primary and secondary boot devices. 3 Flashing XTIDE and setting the appropriate partition as active can restore booting for an IDE drive that does not boot initially. 4 The BIOS can be extended to full 64kb and XTIDE added instead of patching the HDD table. 5
