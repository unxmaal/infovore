gmake install

Claims: 3 Part of gmake

The multi-aterm can be installed using `gmake install`, or by manually copying the .so files from the build/.libs directory to your lib dir. 1 The files a port will install can be determined by either running a dry run of `gmake install` or by installing to a dummy prefix. 2 `gmake install DESTDIR=/some/absolute/staging/path` is used for creating binary packages. 3
