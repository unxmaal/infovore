L2 cache

Claims: 16 Part of L2

The L2 cache can be optional ROM. 1 The G3 233 is pathetically slow without L2 cache, and it is possible to improve the L2 cache as well as increase the clock speed, which will make a big difference to the performance of some applications. 23 The SuperSPARC has no L2 cache, 2k data cache, and 4k instruction cache. 4 Z15 has 8MB L2 cache per core, 256MB L3 cache, 5.2GHz clock speed, and 12 cores. 5 The system planar, processor, and L2 cache passed testing without issues. 6 Write buffers are the ASICS labeled 'WB5'. 7 L1 cache and L2 cache both require data and tag RAM, and L2 cache for 1M of data requires 128K of tag data, provided by 4 Paradigm PDM41252 chips. 7 The IP17 CPU has 64 KB of L1 cache and 1 MB of L2 cache, with the L2 cache composed of 8 128K x 8bit SRAMs and 2 16K x 4bit SRAMs per bank, while 'hinv' reports 64 KB of cache because the L1 cache is not included. 8
