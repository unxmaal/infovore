mplayer

Claims: 47 Background: 9 claims already covered by Wikipedia, see MPlayer.

MPlayer supports text output as an alternative to graphical output, and can play a sequence of images without re-encoding. 12 MPlayer requires a number of libraries, some of which can be disabled or ported individually, and the package is available in the ports.sgi.sh repository. 34 Building MPlayer on IRIX can be challenging, often resulting in crashes, and may involve using a precompiled binary with the necessary libraries. 56 MPlayer has an optimized colorspace conversion plugin that can reduce decoding time by 10-25%, and can use different video output options for SGI, such as sgi and sgi:drawpixels. 78 MPlayer can decode MJPEG on IRIX, and can access raw devices but may not support UDF on IRIX, though ISO9660 is supported. 910 MPlayer is in a beta state and can be found in DrMadison's latest versions, though it requires further optimization. 11 mplayer can be used for video playback on IRIX, and it links against DVD libraries so it can play DVDs. 1213 mplayer and mpg123 can play SHOUTcast streams if given the stream link. 14 Multithreading in mplayer does not significantly benefit playback, as the codecs run single-threaded. 15 mplayer is relatively simple to run with tunables off, but is outdated. 16 mpv lacks dependencies on cairo and glib, making it potentially easier to implement on IRIX compared to mplayer, and the vo stuff in mplayer is portable to mpv. 1718
