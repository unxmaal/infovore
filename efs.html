EFS

Claims: 69 Background: 15 claims already covered by Wikipedia, see Extent File System, XFS, IRIX.

EFS is a file system used by SGI systems, with IRIX CDs and most SGI discs formatted in this format. 123 You can mount EFS images using a loopback device with the 'efs' file system type, for example: mount -o loop -t efs your_image.iso /your/mount/point. 456 EFS support works for reading on some Linux distributions, though stock Debian does not mount EFS by default and may need recompilation. 78 EFS cannot be booted directly, as the PROM will fail to load /unix from the root slice. 9 EFS is the file system used by IRIX, not XFS. 10 IRIX 5.2 uses EFS by default. 11 EFS has a 2 GB file size limit and an 8 GB volume size limit, though it can support 8 gigabyte volumes across larger drives if the controller supports it. 1213 EFS in IRIX uses multiple allocation groups to allow contention-free multi-CPU file system operations. 14 EFS is considered inferior to FAT32 and is not scalable to an entire OS level. 15 EFS can be mounted in Linux, but not written to, and can be supported via modprobe efs. 1617 The Arch kernel package does not build the EFS module, and the userspace tools for EFS don't work. 1819 OPUS supports EFS filesystems for making and fscking EFS ISOs or hard disks. 20
