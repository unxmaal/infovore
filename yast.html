YaST

Claims: 5 Background: 1 claim already covered by Wikipedia, see OpenGL.

YaST is a tool in SLES for autoconfiguring the system, but it frequently makes mistakes that require manual intervention. 1 YaST can probe the cards and obtain the correct configuration, but something overrides it with an incorrect configuration each time. 2 Singleuser mode allows YaST to save the configuration, which is in use in init 3 and init 5 even if there is no X server running. 3 The Prism supports OpenGL 1.3 but not 2.0, and the drivers do not interface well with YaST, causing issues. 4 YaST lies about the X3 GPUs, which are fully accelerated and working properly with the proprietary SGI Magic™, while SaX can configure the resolution correctly. 5
