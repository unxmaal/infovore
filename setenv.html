setenv

Claims: 19

setenv is a command used to change environment variables, while printenv displays the current environment settings. 1 setenv uses the syntax `setenv label value` rather than the syntax used by export. 2 For example, `setenv TERM=xterm` sets the terminal type to xterm, and `setenv DEBUG 1` provides boot-time debug information. 34 The command `setenv -f eaddr` sets the MAC address and is specific to the SGI Indy, where it may not work on other systems. 56 setenv can be used from PROM to manage environment variables, and the boot tune can be changed using setenv under printenv. 78 Some settings do not persist across reboots, and the `-p` argument for setenv never worked on some machines, where `setenv x y`, `printenv`, and `init` are used instead to keep settings alive. 910
