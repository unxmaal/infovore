DHCP server

Claims: 8 Part of DHCP Background: 1 claim already covered by Wikipedia, see Bootstrap Protocol.

On a fresh IRIX Pi image, the DHCP server fails to load, and the eth0 configuration does not take effect. 1 The DHCP server configuration is missing a subnet declaration, and the VM cannot resolve its own hostname. 2 Disabling predictable network names fixes the interface name issue but does not resolve the DHCP server failure. 3 The DHCP server's lease does not include routes. 4 Network installers need to run on a network segment or subnet without another DHCP server running. 5 A Linux box running a DHCP server can cause conflicts, and disabling it can help. 6
