dd

Claims: 50 Background: 3 claims already covered by Wikipedia, see Dd (Unix).

dd is a Unix utility that copies data bit by bit, regardless of the file system, and is used to create disk images, copy boot sectors and boot headers, and convert files to ASCII. 123456 dd can image a disk by copying it to storage, and the resulting image can be restored by copying it back to the target drive. 789 dd can create disk images of specified size using the 'bs' and 'count' options, and images can be stored on an NFS share. 1011 dd can be used to image various systems, including IRIX, HP-UX, DYNIX/ptx, and Raspberry Pi, and can dump PROM contents via /dev/mem on IRIX. 1213141516 dd can copy CDs and EFS media, though safecopy is preferred for EFS media, and artificial bad sectors may cause dd to fail. 1718 dd can erase an IRIX HDD to check for bad sectors, but filesystem-level handling of bad sectors is not done by dd, so tar or xfsdump may be preferable for backups. 1920 dd can move a system install between disks, though LVM, partition table fixes, or additional steps may be required. 122122 Running dd on a running root filesystem may not create a consistent image, and the caffeinate command can prevent macOS from sleeping during dd operations. 2324 dd can create disk images over the network using NFS or FTP, and using a larger block size can speed up this process. 252627 dd can also be used to write to rdsk device files via NFS shares, and to copy a disk image to a device with a progress bar. 2829 dd can write /dev/zero to a file for a filesystem performance test. 30
