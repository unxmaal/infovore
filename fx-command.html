fx command

Claims: 9 Part of fx

The `fx` command can automatically label, format, and layout the disk for IRIX, and it can format a drive for use with SGI systems, including a provision command within `fx` that can automatically set up the drive. 12 The `fx` command only re-partitions and does not handle filesystems; `mkfs` is needed to create a new filesystem. 3 To use the `fx` command for formatting, one should accept all defaults. 4 In LOVE, the `fx` command does not require formatting partitions; instead, create labels and boot into the installer. 5 The IRIX `fx` command indicates the disk is partitioned and suggests it may have bad blocks, despite the capacity appearing correct, and the disk reports no bad blocks after an exercise. 6 The `dsk` command is not recognized, but is what the `fx` command is attempting to access; the drive may be incompatible or faulty. 7
