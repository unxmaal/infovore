IRIX version

Claims: 32 Part of IRIX Background: 4 claims already covered by Wikipedia, see IRIX, SGI Indigo, SGI O2.

The uname command can report the specific IRIX version being used, though coreutils installs its own 'uname' which can conflict with the IRIX version. 12 IRIX doesn't know its version post-installation until after you reboot, causing confusion when installing development software due to math errors. 3 The IRIX version to use depends on the intended use; N64 developers use 5.3, but 6.5 is recommended for most cases, and 6.5.0 has been built as a debug version. 45 The IRIX version can affect performance on Indigo systems, and the Indy works well with IRIX versions from 1993 to 1996-97. 67 The SUN license and IRIX version are incompatible, preventing the CATIA v4 key from working, but the IRIX version does not require a license separate from the Windows software. 89 The osd_cd_read function is implemented differently for various operating systems, with the IRIX version needing to be written based on IRIX syscalls. 10 Booterizer expects the IRIX version in the irix/ symlink, which may not be updated automatically. 11 IRIX recognizes Zips as Zips, but this might depend on the IRIX version, as icons are specific. 12
