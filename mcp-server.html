MCP server

Claims: 3 Background: 1 claim already covered by Wikipedia, see Secure Shell.

The MCP server can use inst to install software on the local machine, but it currently lacks a way to run a serial console to another machine. 1 An MCP server on IRIX is useful for basic commands and man pages without full command line tools. 2 The MCP server can use RSH for local command execution, but SSH is recommended for security reasons. 3
