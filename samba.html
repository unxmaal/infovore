Samba

Claims: 11

Samba is a file-sharing service that can be virtualized with StarWind and installed on lightweight base distributions such as Alpine or Ubuntu, where it must be manually configured along with other necessary services. 123 It can share a filesystem via CIFS and NFS, re-share NFS to handle UID mismatches, and provide NFS-like functionality on Windows, though this is more complex than FTP. 456 It is considered a better option for sharing files between a modern Linux machine and a Windows 98 machine than NFS. 7 Older systems such as Win3.11/DOS can use Samba with SMB1 enabled, while Warp 3 Connect and Warp 4 did not reliably network with it. 89 Samba is described as insecure, and Samba V3.0 for IRIX 6.5 costs $300. 1011
