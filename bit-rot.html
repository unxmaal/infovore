bit rot

Claims: 3

Bit rot is when software that hasn't been handled in a long time loses critical data because the file system or file media has reached its useful lifespan. 1 Windows XP and earlier versions are prone to bit rot and require frequent reinstallation. 2 Bit rot is also a possibility in the BIOS. 3
