XFS directory structure v2

Claims: 3 Part of XFS

XFS directory structure v2 support was removed in Kernel 3.17 and is not supported on modern Linux. 12 It works on some systems due to a quirk rather than a feature, and should not be relied upon because it risks file system corruption. 2 An old version of Linux is needed to support XFS directory structure v2. 3
