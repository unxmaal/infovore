cc

Claims: 19

The cc command is a binary pass/fail requirement for UNIX compatibility. 1 Configure scripts and makefiles use environment variables like CC, CXX, and LD to determine which compiler to use, but not all packages respect these variables, especially for cross-compilation. 2 For autoconf packages, setting environment variables like CC, CXX, CPPFLAGS, CFLAGS, LDFLAGS, CXXFLAGS, PERL, SHELL, SHELL_PATH, LD_LIBRARYN32_PATH, and PKG_CONFIG_PATH can help configure scripts. 3 The environment variables CXX, LD_LIBRARY_PATH, and CC can cause issues with linking curses libraries. 4 The cc command uses the system's default linker, while gcc expects binutils ld. 5 The compilers cc and cpp are in the license file. 6
