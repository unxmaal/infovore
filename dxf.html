DXF

Claims: 5

DXF was created to allow file exchange between different AutoCAD versions on different platforms. 1 It was originally intended for interchange between different versions of AutoCAD, but due to political wrangling, it became a de facto standard despite not being a true CAD-interchange standard, leading to mixed. 2 Pro/Engineer for IRIX can convert models to DXF for printing. 3 The hole wizard in SolidWorks has issues with sketches becoming separated from the feature in the tree and problems with DXF export. 4 It supports a .inc format and likely requires conversion to DXF before use with POV-Ray, which can handle it with later versions. 5
