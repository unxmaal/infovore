iQue

Claims: 3

The iQue is a 3rd party product based in China, and the N64 SDK was made to be Linux compatible, including compiled *.obj and *.h files for it. 1 The iQue source code is not original Nintendo code from 1994 but is close, containing bits of the N64 code provided by Nintendo around 2002-2003. 2 The 2.0K SDK for iQue is a bin/cue file that can be extracted from an ISO. 3
