macOS

Claims: 147 Background: 28 claims already covered by Wikipedia, see MacOS, A/UX, ARM architecture family, Emacs, IRIX, Mac OS 9, Macintosh SE/30, Video games and Linux, VirtualBox.

With Windows

macOS is a competitor to Windows but comes with hardware limitations and higher costs. 1 You can use GRUB to boot macOS alongside Windows, and the Mac can run macOS and Windows via Boot Camp, though it is not a speed demon. 23 macOS is more hackable and open than Windows. 4

General

macOS is a commercial Unix-based operating system that is open source at the kernel level and was at one point certified Unix. 567 It is proprietary to Apple, expensive, and locked to Apple hardware, with development requiring a license from Apple unlike Windows or GNU/Linux. 89 Apple is moving towards ARM processors in its Macs, with plans to unify its operating systems and development environments. 10 macOS has used Unix line endings for 20 years and supports NFS for file sharing. 1112 Apple's support span for macOS is shorter than that of Windows and Linux vendors. 13 Darwin is rarely used instead of macOS. 14 macOS has an extern table for subsystem pointers, index 1 containing xpc_global_data with a bootstrap pipe pointer for sending messages to launchd, which fails with EIO. 15 On macOS, the display server is part of user space while GPU drivers have been in kernel space since version 10.0. 1617 emacs is easy to get on macOS. 18 OSX builds require 10.12 or later, while the latest usable hacked macOS on modern MacBooks is 10.11. 19 Mac OS has never crashed for the speaker, from System 6 to Mac OS 11. 20 Bluetooth devices can have pairing issues, especially with macOS. 21 Apple is reverse engineering graphics drivers by logging calls to the subsystems from macOS. 22 macOS is a certified Unix operating system, though it requires configuration to be fully Unix-like. 23 It integrates with Apple's ecosystem, including Find My, though it can have some app integration glitches. 24 Current versions on Apple Silicon include Rosetta for running Intel binaries, though it can be complex to use. 25 macOS can dynamically share RAM and VRAM with the GPU and can run AI models on a MacBook without draining the battery. 2627 It can create .DS_Store files that may cause fragmentation on SD cards. 28 The yearly update cycle for macOS and iOS has hurt Apple's quality control by always looking for something to change to justify a new release. 29 Current macOS notifications about iCloud being full and updates that can't be turned off or ignored are a problem. 30 macOS drops the minor version number for marketing purposes. 31 The SmartBarHide tool allows configuring per-display visibility of the menu bar on macOS. 32 Most users run macOS on their SGI systems and Linux on the backend, as NVIDIA graphics became more prevalent. 33
