VPro

Claims: 150 Background: 17 claims already covered by Wikipedia, see SGI Octane, OpenGL, SGI O2, Video games and Linux.

With Octane

The VPRO is an ultimate graphics system available for the Octane and ip35, and it is a logical upgrade path from V8, though it is less mature than the Impact solution, which is more reliable but runs very hot. 123 Upgrading an Octane to VPro turns it into an Octane2, which has Xbow 1.4, a later power supply, and a later 'heart' board for 8GiB support, while the upgrade itself requires patching the OS to 6.5.30. 456 The Octane2 came with a 1.4 backplane and VPro, while late Octane1 models could also use 1.4 backplanes but came with MGRAS, and a 2x400 MHz Octane2 with VPro usually has a V10 CPU. 78 VPro, Octane, Tezro, O350, and Onyx2 use VBOB, and the Octane and Tezro/Fuel share a common lineage but have different graphics solutions. 93 The VPro lacks the needed interface for the Octane personal video board, and some Octane demos will not install on VPro and only on Impact, requiring overriding. 1011 Swapping VPro and Impact graphics on Octanes requires a kernel rebuild but still boots via serial console, and the console may spam error messages during the demo. 1213 The main port of the VPro goes into analogue mode during boot, so DCD outputs can enable two-head mode on an Octane, but the 13w3 connector on an Octane's VPro is somewhat unreliable and may require wiggling to make proper contact. 1415 The red light on an Octane2 with VPro turns off after tests pass, and an Octane V12 with dual VPro carrier can start up but has graphical glitches early in the PROM. 1617

General

VPro can be installed in an Origin 350, where it makes the machine an Onyx350, and it can also be installed in a Tezro. 181920 VPro sits on the XBridge in the Fuel, and MXI/MXE and all VPro boards can drive 1920x1200 resolution. 2122 VPro machines have acceleration options, and SGI VPro can render to a different buffer using OpenGL functions like glXCreatePbuffer. 2324 Some things do not play nice with VPro, requiring MXE, and a few IMPACT demos will not run on VPro. 2526 The VPro splits its video RAM between the software and the framebuffer, and can control the amount of VRAM allocated for the framebuffer and textures. 2728 The DCD card is a rare daughtercard for the VPro that can enable dual head, and it is difficult to find and expensive. 29 The Origin 350 is compatible only with VPro or IR4 PCI graphics cards. 30 The VPro has driver bugs, especially with Quake3 rendering, which do not appear on MGRAS hardware, and some software is still not compatible with VPro. 3132 The VPro chokes when a polygon's Z coordinate is exactly 0, showing the polygon only when the coordinate is slightly above or below 0. 33 VPro systems use microcode, and some VPro features, like fragment lighting, have optimized code paths. 3435 VPro is great for ported software, but IRIX-native software tends to run better on IMPACT/MGRAS. 36 The first generation of vPro consists of the v6 and V8, while the v10 and v12 are the second generation with twice the performance. 37 SGI hardware did not support OpenGL 1.3, providing at most 1.2 for vPro. 38 The VPro is a single-chip, fixed-function architecture similar to contemporary Nvidia graphics cards, and supports VBOs through GL_ARB_vertex_buffer_object for efficient storage of vertex data in GPU-accessible SDRAM. 3940 The VPro has design flaws affecting OpenGL programs, and its performance issues were difficult to work around. 4142 The VPro worked well for CAD software, but some software was only certified for MXE, not VPro. 4344 The VPro has DVI ports, which appeared after the Octane2, and Onyx4 and VPro both use DVI. 4546
