SGI RGB format

Claims: 8 Part of SGI Background: 1 claim already covered by Wikipedia, see FFmpeg.

SGI uses the RGB format, which is a vector graphics format specific to SGI systems. 12 To convert .mp4 files to SGI RGB format for use in SGI software, ffmpeg can be used with specific parameters, and it can be compiled for mips3 to convert .mp4 videos to .rgb format for use in SGI discreet programs, though it runs slowly on an O2. 34 The default profile picture in IRIX should be in rgb format and no larger than 100x100 pixels, while login images should be in SGI RGB format and at least 100x100 pixels. 56 The SGI RGB format may benefit rendering with fewer colors, achieving up to 350 particles with good framerate, and might be better for editing standard definition on an O2 than SGI's default format. 78
