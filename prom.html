PROM

Claims: 190 Background: 2 claims already covered by Wikipedia, see Programmable ROM, QEMU.

With IRIX

The PROM provides limited hardware support, often just enough to detect, configure, and install IRIX. 1 Booting IRIX from the PROM is slow and unusable, and to boot it, type 'boot' from the PROM, using 'ls' from SASH to list disk contents. 23 The PROM's HINV might report differently in IRIX, and 'hinv' should show the graphics device at least at the PROM level, though 'hinv -c graphics' may show no graphics devices in IRIX. 456 There is a way to force the flash of the PROM from within IRIX, but there is a danger to doing this, as you could brick your system. 7 The root password for IRIX is separate from the PROM password. 8 Networking setup with IRIX involves editing many text files, and even then, basic networking requires setting a hostname and understanding prom. 9

General

The initialization code in PROM sets up multipliers and other parameters for the CPU, affecting its effective clock speed. 10 There is a nvram setting to always use the serial console even with keyboard and video; hitting esc gets you into the PROM. 11 Installing IRIX 6.5.30 updates the PROM; firmware files are on the IRIX CD; Apple does the same for newer MacBooks. 12 If a system is unresponsive, commands like 'enableall', 'update', and 'reset' in the PROM might help. 13 The setenv command requires editing the PROM with a hex editor for Indigo2. 14 Editing the PROM with a hex editor is required to update the MAC address on an Indigo2. 15 You can get a whole motherboard with V11 prom from Mashek for around $150, which is comparable to or cheaper than getting just the prom from Ian. 16 The PROM is firmware executed from ROM, using RAM only for an execution stack, and it is the code that SGI R4k processors boot to. 1718 It can be operated entirely by keyboard using number keys to navigate options, and a mouse is not needed until booting into IRIX. 19 The PROM can run hinv, and it can boot from an external drive by setting the BootDevice environment variable to dksc(x,y,z). 2021 sash is a PROM with filesystem support, and the PROM auto-boot command is setenv auto-boot? true. 2223 The PROM's ARP response reveals the MAC address, which is useful for identifying SGI machines like the Indigo and 4D, and the location of the PROM that holds the Ethernet address can cause problems when swapping mainboards back and forth. 2425 You can change the MAC address in the PROM if you are on IP22, but there are scripts that do it temporarily in IRIX. 26 The PROM sees two CPUs, while the 4d1 3.x sees only one CPU. 27 Updating the PROM to the latest version for an O2 changed the HINV display of VICE from DX to TRE. 28 The PROM is the low-level firmware that starts up SGI machines, presenting a message box that allows interaction and distinguishing itself from the PC BIOS with an emphasis on reliability. 2930 It is physically composed of four EPROMs and does not support loadable drivers. 3132 The SGI platform uses both prom and small prom versions, which may differ in features such as the version of sash. 33 The PROM can read sash from a limited number of devices, while sash itself can handle more. 34 It can access the environment variables, which are stored on the hard disk and need to be initialized, and it can reset them with the resetenv command. 3536 It can dump itself over serial by specifying a start address and size and using a kermit script, and it can restart a machine on power-on reset to prevent certain boot issues. 3738 The SGI platform uses prom and small prom versions, which may differ in features such as the version of sash. 33 PROM on SGI systems functions as a mini IRIX kernel with limited APIs, and it is read twice during system startup. 394041 The PROM contains interrupt vectors (ip2), the FPGA bitstream baked into CPU configuration (ORCA FPGA, R10k/R12k modules), and a clock multiplier value used to generate the core clock from the module's clock generator. 424344 Boot depends on the PROM understanding the kernel format (via TFTP or a small XFS SCSI partition) and requiring an SGI ID, a minimum PROM version (newer than July 1994 for XZ), and a valid SCSI chain. 454647 PROM can be manipulated through console commands (e.g., 'enableall', 'apply', 'console=G', poke/peek, 'init', 'string'), and secondary PROM chips can be added and selected during boot (Octane) or switched via console command. 4849505152 PROM corruption can be recovered (documented O2 methods, rebuilding from source with recovered headers), and various hardware issues require PROM updates or adjustments (Teton -004, IP7 IO3 upgrade, O2 R12000 VCORE/straps, Indy endianness EEPROM reprogramming). 535455565758 PROM settings can be configured using environment variables. 5960 The -p argument for setenv never worked on their machines, so 'setenv x y', 'printenv', and 'init' should be used to soft reboot the PROM and keep settings alive. 61 The O2 emulator requires steps to add NVMe support and fix the PROM. 62 Resetting the environment from PROM can resolve issues with an aging disk. 63
