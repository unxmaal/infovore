initramfs

Claims: 3 Background: 1 claim already covered by Wikipedia, see QEMU.

To boot a system with QEMU, you need both a kernel and an initramfs file, and Grub needs to be able to load the kernel and initramfs from a bootable partition. 12 Initramfs is an initial RAM filesystem that might have filesystem repair tools, but generally you need a rescue system like Mint. 3
