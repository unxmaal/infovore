Solaris 11.3

Claims: 9 Part of Solaris 11

Solaris 11.3 is the last version of Solaris for SPARC and is end-of-life next year, but it is supported for two more years by Oracle. 12 Solaris 11.3 installation on F20 cards may fail due to a PS0 fault on the SAS disk. 3 The T5140 has outdated ILOM firmware and an 11.3 Solaris install, with no support for newer versions. 4 Since running Solaris 11.3 without a support contract, one can freeze updates to avoid failures when using the release publisher in pkg. 5 user-2eb4 had to change a download URL to get Solaris 11.3 instead of 11.4. 6 The SPARC T2000 supports Solaris 11.3 and can be configured with an offline repository and LDom Manager for hypervisor usage. 7 My T3-1 ran Solaris 11.3 as a file server until a power issue fried the motherboard. 8 Barrier stopped working after DNS issues were resolved, preventing network file sharing. 9
