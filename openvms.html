OpenVMS

Claims: 54 Background: 6 claims already covered by Wikipedia, see OpenVMS, VAX, VAXstation.

OpenVMS is still in active production use and outlasted its previous platforms. 1 It can run on VAX and Alpha processors, including emulated VAX systems. 23 It is the standard OS for a VAXstation. 4 It is designed to be immune to certain exploits. 5 Its calendar supports time computations up to 31-JUL-31086 02:48:05.47. 6 It has been updated to support non-server hardware like SATA drives. 7 It includes limited software and requires licensing for additional software, especially on VAX and Alpha systems. 8 IA-64 systems from Japanese and HP can run OpenVMS in addition to other operating systems, while SGI IA-64 systems are limited to Windows, outdated GNU/Linux distributions, and a few other operating systems. 9 Itanium machines ran Tru64 or OpenVMS, and Itanium was used primarily by universities and 3-letter agencies, running several operating systems including OpenVMS, HP-UX, Windows, GNU/Linux, and possibly NetBSD and HelenOS. 1011 SRM can boot from the network depending on the OS to install, but OpenVMS needs to be installed from CD. 12 OpenVMS requires licenses to function fully, but can be installed without licenses, in which case it lacks functionality. 1314 Software compiled for OpenVMS on VAX can be difficult to use if the developer is no longer available. 15 VSI will stop letting people install OpenVMS freely. 16
