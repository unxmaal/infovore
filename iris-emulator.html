IRIS emulator

Claims: 6 Part of IRIS

The IRIS emulator is written in Rust and can be run by installing Rust and executing `cargo run --release` in the emulator directory. 1 Starting the emulator with overlay=true for scsi.1 creates scsi1.raw.overlay, but changes are lost on subsequent starts. 2 When running on an Altix, the emulator has a frame rate of 1-3 seconds per frame and takes 2-3 hours to boot. 3 Performance improvements might be achievable through better scheduling and optimizations in the LLVM backend, or through hardware acceleration. 45 3dcad now supports Japanese text through a reimplementation using the IRIS emulator, with issues in EUC conversion. 6
