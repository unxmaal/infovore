rpath

Claims: 12

RPATH is an ELF attribute that can be added to an executable or shared object to specify a search path for libraries, as determined by checking the ELF header, even if the IRIX runtime loader does not natively support it. 1 Setting RPATH in binaries can avoid the need to modify LD_LIBRARY_PATH to run them. 2 The problem with rpath is related to $ORIGIN not being expanded. 3 Changing the rpath at install time can break static builds. 4 The software sets the rpath during 'make install', requiring manual removal and installation to /usr/local/ for package building. 5 buildpkg may handle rpath differently from standalone builds, potentially causing issues with LD_LIBRARYN32_PATH. 6 The project at https://github.com/danielhams/didbsng is self-hosting and aims to provide the infrastructure for repeatable builds, addressing issues with rpath and system library conflicts. 7
