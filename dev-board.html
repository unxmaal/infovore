dev board

Claims: 5

The Dev board was a GIO device in the SGI Indy that contained a complete Nintendo 64 console. 1 It has two revisions: Rev1 uses HW1 silicon with an RDP bug workaround (a BOWTIE_VAL macro), an AI max DMA length of 32k, and a larger physical die, while Rev2 uses HW2 silicon with no significant differences from retail. 2 The dev board can run standalone with a DC jack and HDMI, and someone played Densha de Go on it. 3 You cannot play the game on an Indy without the dev board; you have to use an emulator on a Windows/Mac machine. 4 A dev board with an N64 was made for an SGI Tezro, but the IRIX driver side was never finished. 5
