EFS filesystem

Claims: 13 Part of EFS Background: 1 claim already covered by Wikipedia, see IRIX.

EFS is an older Unix filesystem, similar to XFS, that can be used as storage for disk images and mounts on Linux. 12 It supports filesystem sizes up to 8 GB, and for larger drives multiple 8 GB EFS filesystems can be created. 3 IRIX 5.3 uses the EFS filesystem, which on the Indigo2 maxes out at approximately 7GB despite larger disk sizes. 45 The img and iso files are the same, differing only in name due to the use of the EFS file system. 6 To create an EFS filesystem image from an IRIX CD, use dd with appropriate options, and to mount an SGI-format ISO file in IRIX you may need to use a Linux box to mount the ISO as a block device using the efs file system and then share it via NFS. 78 Ultra64 demos require the EFS filesystem on an Onyx, and Softimage 3.7 works on an emulated Indy with IRIX 5.3 and an EFS filesystem using FlexLM installation. 910 Softimage licensing works but may have issues on an Indigo2 R4400 250 MHz with Extreme and IRIX 5.3 EFS filesystem. 11
