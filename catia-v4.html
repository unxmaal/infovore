CATIA v4

Claims: 30 Part of CATIA

CATIA V4 is a CAD program released in 1993 that only ever ran on UNIX platforms, using an X11/Motif interface and a CSG solid body modeling approach similar to V3. 12 It uses an entirely different geometry engine from V5, which re-implements V4 geometry. 3 CATIA V4 is considered disappointing compared to V5. 4 It had a mainframe version up until 2000, and support for V4 stopped around 2011. 56 Versions of CATIA V4 existed for IRIX, Solaris, AIX, and the 5080, and it can be installed on workstations such as the Octane, O2, and Indigo2. 7891011 CATIA V4 supports Buttons and Dials on both IBM and SGI workstations, though the SpaceMouse was used but not widely adopted by artists. 12 It does not have a loft function; instead, surface bodies connecting two profiles along guide curves can be created using spline geometry. 13 It requires command line input for parameters after selecting actions from the menu, and has separate licenses for STEP and IGES support. 1415
