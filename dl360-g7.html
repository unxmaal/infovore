DL360 G7

Claims: 8

The DL360 G7 is a Dell server that runs OmniOS with a ZFS pool, which requires additional SSDs for storage. 1 The iDRAC on the DL360 G7 has compatibility issues with certain HBAs and weak CPUs. 2 The Dell remote console for the DL360 G7 requires a one-time Java download and works with Internet Explorer but not modern browsers. 3 The DL360 G7 runs a Windows 10 VM for testing untrusted software and a Folding@Home server, and also hosts an Ubuntu VM used as a file server. 45 The HP DL360 G7 has issues with RAM and ESXi VMs shutting down without rebooting, and ESXi7 requires a kernel flag to install on the dl360g7. 67 A Dell R620 and dl360g7 are not named beyond a simple hostname. 8
