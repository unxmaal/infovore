didbs

Claims: 63 Background: 2 claims already covered by Wikipedia, see OpenSSH, SGI O2.

didbs is a tool that automates the build of IRIX development tooling from base IRIX and development tools, using MIPSPro except for gcc-related tooling, and is not a general porting system or elegant. 12 It can build a `.tardist` for base platform tools without packaging them, and prebuilt versions are available on forums as torrent files that can be downloaded and untarred. 345 didbs supports MIPS3 and can install single packages, though shuffling packages to the front of the compilation order breaks the package testing abilities inside didbs. 678 The gcc9 in didbs is built using a chain of earlier gcc versions, and gcc compilation time varies with the version of gcc and the release version of didbs. 910 didbs is being updated to use the correct 'lib32' style library directories and specific 'mips4' and 'mips3' releases, and irixports is being worked on by lbdm and will include gcc compilers as part of didbs releases. 1112 didbs 0.1.8 requires systune ncargs 131072 and an existing compatible release linked at /usr/didbs/current to run bootstrap, and extracting didbs under the home directory breaks -rpath entries, which placing it in /usr/didbs/0_1_8_etc fixes. 1314 Didbs is a software package for bootstrapping a system into a usable development setup, providing the most current set of basic tools together with a GCC9 binary and other tools for IRIX development. 151617 It includes OpenSSL, OpenSSH, and GNU screen (the latter not in the default set), and is available as a large .tar file via torrent, with the latest version being the 0.1.9 Xmas release. 15181920 The name can be interpreted as 'dans irix development bootstrapper', and the program saves time setting up a fresh IRIX installation. 2122 didbs may have newer libraries than the system binaries expect to see, though this is not the case on a 6.5.30 install with didbs 1.5. 2324 It is part of a hierarchy of didbs > irixports > Nekoware, and can be pulled in or used via a 'didbs' branch added to the irixports repo, though this might overwrite or double download existing files. 2526 didbs has been around for a while and may be deprecated in favor of sgug-rse. 27
