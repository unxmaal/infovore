libtool

Claims: 19 Background: 1 claim already covered by Wikipedia, see GNU Debugger.

libtool is a generic library support script that hides the complexity of using shared libraries behind a consistent, portable interface. It is a 12k line bash script that handles library linking and other things for platform-agnostic systems, with special handling for dependencies and shims, and is a main blocker for pkgsrc on IRIX. 12 libtool solves a very precise problem, which is 'how do we set up a compiler environment for ANY system type in this list of systems?'. 3 The build process uses libtool to determine dependencies, scans headers, and links temporary object files with gcc; errors occur after the header scan step. libtool can produce errors like 'Illegal option -- .' and its verbose mode can be accessed with 'export V=1'. 45 libtool is a main blocker for pkgsrc on IRIX. pkgsrc's libtool needs fixing to correctly place compiled objects during builds. 26 libtool is case-sensitive; in tcsh, use setenv LIBTOOL `which libtool`; in bash, use export LIBTOOL=`which libtool`. 7 GDB can be run on a binary from within the build tree of an autotools project using 'libtool --mode=execute gdb'. 8
