HAL

Claims: 12

HAL is a component of the Windows NT operating system, which is preemptive and benefits from HAL support for greater system stability. 1 HALs have been created for various platforms, including Alpha NT 3.51 Server, which can be found at http://mirror.rqsall.com/misc/alpha/hal1000pv351b.zip. 2 Creating a HAL for Windows XP may be easier than building the entire project, and existing HALs from NT4 can be ported. 3 An R4K Indigo/Indigo2 could potentially run Windows with a custom HAL, and the Indigo 1 has partial code for a HAL in NT 3.5. 45 The NT port for SGI machines is based on new HAL and drivers, but Microsoft's removal of HAL support for SGI's architecture limited its ability to run Windows. 67 9X had no HAL, and drivers took many liberties, leading to BSODs when they did not respect memory boundaries. 8
