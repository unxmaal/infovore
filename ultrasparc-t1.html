UltraSPARC T1

Claims: 3 Background: 1 claim already covered by Wikipedia, see SPARC.

The UltraSPARC T1 is a processor used in some Sun servers. 1 The T1000 is an UltraSPARC T1 that was slow, especially for data movement, with poor memory bandwidth compared to the V210/240. 2 SPARC and OpenSPARC are distinct; OpenSPARC is Sun's free release of the UltraSPARC T1 and T2 Verilog, allowing free development of SPARC-compliant processors, though using trademarks requires paid membership. 3
