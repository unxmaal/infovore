admin menu

Claims: 6

From the 'inst' system, the admin menu can be used to run `mkfs` to partition and format a drive. 1 Setting the hostname is required to enable networking in the admin menu. 2 Opening the 'UNIX console' from the Admin menu opens the blue winterm instead of the gray term. 3 The admin menu can be used to start a shell to edit /etc/passwd during an installation. 4 The installer, admin menu, and a shell can be used to install on a new disk while using the old one for other purposes. 5
