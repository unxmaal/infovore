OpenGL

Claims: 184 Background: 78 claims already covered by Wikipedia, see OpenGL, IRIS GL, IRIX, Silicon Graphics, Blender (software), Xsgi.

OpenGL originated from AIX and was implemented in hardware. 12 OpenGL and SDL are the respective ports for Linux and Win9x, and the Linux port uses OpenGL. 34 Shaders began as an OpenGL 1.4 extension and became part of the core in OpenGL 2.0, so it is theoretically possible to use shaders on an Onyx4, which supports OpenGL 1.4 and was planned to support 2.0. 56 Texture dimensions must be powers of two, which is common in OpenGL and OpenGL ES, but padding can be used for non-compliant cases. 7 OpenGL supports z-buffering in every version, and the drawing order only matters for alpha blending. 89 Glide is a low-level version of OpenGL, similar to Vulkan in 1998, and 3dfx took OpenGL, removed unnecessary parts for gaming, and created Glide. 1011 Vulkan is preferred over OpenGL. 12 OpenGL support was added through patches, and OpenGL on Linux would not have existed without Mark Kilgaard's work. 1314 OpenGL on SGI systems was limited to versions 1.1 and 1.2, while OpenGL on IRIX 5.3 was early. 1516 X used tokenized OpenGL calls to minimize network traffic, especially for texture objects and display lists. 17 Double buffering issues can cause flickering in OpenGL rendering without explicit vsync support, and adjusting the swap interval can affect rendering output. 18 OpenGL applications use the GPU framebuffer and are composited separately, with specific OpenGL calls affecting the bus bandwidth. 19 Using common OpenGL APIs ensured Quake 3 would work on most hardware, and Performer software should run on any Windows computer with OpenGL capability. 2021 Video players can use glDrawBuffers or textures to draw video, with glDrawBuffers being faster on older hardware. 22 The OpenGL extension for render targets is GL_EXT_framebuffer_object. 23 OpenGL is a graphics library with multiple layers of helpers for creating graphics programs, and its predecessor, the IRIX Graphics Library (GL), led to modern OpenGL and GLUT. 2425 An ex-Cray engineer was a lead coder on the GL project that became OpenGL. 26 OpenGL can be used with Solaris on Creator or Elite cards for better performance, and Suns can support decent OpenGL. 2728 OpenGL and XGL are related, as OpenGL can be translated to XGL with a library that handles the calls, though games may need adaptation for performance issues. 29 Xsgi supports both OpenGL and GL on SGI hardware, while Onyx4 uses XFree86 which does not support GL. 30 With an X server running on a GL-capable system, remote OpenGL over GLX works great. 31 OpenGL has a color mask that lets you render to just the red or blue channels, which is useful for red/blue stereo glasses, and the glasses can be used with OpenGL for at least one mode. 3233 OpenGL rendering is possible with the right setup, and /dev/opengl is provided by a driver on the host for translating OpenGL calls. 3435 OpenGL performs well on the hardware, but it assumes certain things about the underlying hardware and is not portable, which is why it was developed. 3637 OpenGL became available around IRIX 4.0, and IRIS Inventor CD is OpenGL rather than IRIS GL. 3839 Iris Explorer was used for scientific visualization and continued to receive support in later versions using OpenGL. 40 Performer supports OpenGL on SGI hardware but does not fully implement all texture extensions. 41 FreeGLUT wraps OpenGL calls into utility functions for multiple platforms, allowing window creation, OpenGL initialization, and input handling in a platform-independent way, while OpenGL itself does the graphics. 4243 OpenGL can render 2D as if it were 3D. 44 For UI elements, using nearest sampling is recommended, especially when multiple UI icons are packed in a single texture. 45 IRIX does not support non-power-of-two textures in OpenGL, requiring textures to be rounded up to the nearest power of two when creating them. 46
