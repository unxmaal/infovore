MaXX

Claims: 12

MaXX is a user environment for Linux that recreates the IRIX desktop, mimicking its actual appearance. 12 It runs on an ersatz SGI window manager for Linux called MAXX, which relies on Rox for desktop icons and file management, though Rox is abandoned. 34 The project is incomplete, and although it has a new desktop release, that release is closed source and not available for T2. 56 MaXX works fine on Linux, testing best on Debian and CentOS, and can also run on FreeBSD. 78 MAXX will build on Solaris, though this is avoided for GTK app compatibility, and it uses MaXX shared libraries for the ViewKit implementation. 910
