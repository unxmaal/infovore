Performer

Claims: 10 Background: 1 claim already covered by Wikipedia, see OpenGL.

Performer is a package that shares its name with Inventor. 1 For the best performance, Performer should be used as the engine/scenegraph. 2 Performer supports OpenGL on SGI hardware but does not fully implement all texture extensions, and it has a limitation that textures must be powers of 2. 34 Performer 3.2.4 is the last IRIX release and includes pfCity. 5 Performer 3.2.2 for Windows and 3.2.4 for IA64 Linux are available in Propack 4. 6 Windows 2000 had a Performer port that ran only on SGI hardware. 7
