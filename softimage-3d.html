SOFTIMAGE 3D

Claims: 15 Part of Softimage

SOFTIMAGE 3D is available in versions for both IRIX (such as 3.7, possibly for IRIX 5.3 or 6.2) and Windows (requiring Windows 2000 or XP to run properly). 12 SOFTIMAGE 3D can use either Iris GL or OpenGL, with the library files softGraphicGL and softGraphicOGL being ELF 32-bit MSB shared objects, MIPS, N32 MIPS-III version 1 (SYSV), dynamically linked, with debug_info, and not stripped. 3 Softimage 3D requires a single-channel display for 1920x1080 resolution, otherwise it defaults to 1280x1024, and changing the VFO dynamically is not supported without logging out and back in. 4 To run Softimage 3D, install version 4.0 and place the keygen license in /usr/Softimage//Flexlm/licenses/sofitimage.lice, removing 'SOFTIMAGE' from 'DAEMON SOFTIMAGE SOFTIMAGE' in the license template. 5 SOFTIMAGE 3D license files must have backslashes followed by a hard return rather than a space, must not contain spaces in the wrong places, and incorrectly wrapped lines can cause issues. 678 Rebooting is required after correcting SOFTIMAGE 3D license files. 9 Animal Logic's Softman allows Softimage 3D to render to Renderman, though no one has a working copy with documentation. 10 The Alias and Softimage 3D software versions have detailed version history including mental ray versions. 11
