image file

Claims: 8 Part of image

OS 9 and OS X did not recognize a .image file, and changing the extension to .iso is not recommended. 1 Emulating a ZIP drive is easy but involves handling the image file with care, as advanced OSes may hang if the drive is not present. 2 To use an SD card as a zip drive, you either write directly to it (SD2SCSI) or use an image file since the SD card has its own filesystem. 3
