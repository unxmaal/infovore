Quake 3

Claims: 36 Part of Quake Background: 2 claims already covered by Wikipedia, see Quake III Arena.

ioquake3 is the open-source port of Quake 3, while the original IRIX port predates the GPL release of Quake 3 and only has binary versions available. 12 Quake 3 is G3 minimum and requires 3D acceleration, and software rendering was common up to Quake 3. 34 Quake 3 requires significant texture RAM, even on older hardware like Voodoo1, and the V6 and V10 have limited texture memory, which affects performance in Quake 3. 56 Quake 3 performs better on Pentium 4s than on other CPUs. 7 The 350mhz Blueberry iMac G3, the 700+mhz iMac G3, and a trayloader G3 can run Quake 3. 8910 The G4 Digital Audio with OS 9.2.2 and Rage 128 can run Quake 3 but displays a grey screen with a movable mouse cursor. 11 The V12 gets about 30fps on Quake 3 in most configurations due to IRIXisms that cap FPS at half the monitor refresh rate, and there is no significant difference in performance between V8 and V12 for games like Quake and Quake 3. 1213 The O2 can run Quake 3, but performance is better on a V12. 14
