boot floppy

Claims: 4 Part of boot

Porting current software to IRIX typically involves setting correct preprocessor flags, working around missing or broken features, and using a boot floppy that could write to the front panel display. 1 A drive can be imaged off a SunIPX system using only an OpenBSD boot floppy, built-in tools, and an ethernet cable connected to a ThinkPad. 2 To boot from a floppy on a Sun Sparcstation, use `boot fd` or `b fd(0,0,0)` in older modes, and possibly `boot floppy` in newer ones. 3
