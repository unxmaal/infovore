telnet

Claims: 36 Background: 3 claims already covered by Wikipedia, see Telnet, Secure Shell.

Telnet is a protocol used to access terminal sessions remotely, and it relies on more than just TCP—it uses a specific protocol of its own. 12 Telnet is commonly used as an alternative to SSH, alongside services like RSH, and can be used to log in to machines, mount NFS shares, and transfer files via FTP. 34567 Telnet is built-in on many systems and can be used to access a wide range of hardware, from old DECstations and Atari systems to modern serial servers and power management boxes. 8910111213 Telnet is often enabled by default on systems like IRIX, which runs several outdated and insecure services, and it can be exploited through brute forcing or targeted attacks. 14151617 Telnet can be affected by network and DNS issues, and it may lock up or drop connections, though it can still work over Ethernet when properly configured. 181920212223 Telnet is not suitable for all transport purposes, such as MCP transport, because it is an interactive terminal protocol that could corrupt other data streams. 24
