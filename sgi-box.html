SGI box

Claims: 19 Part of SGI

The SGI box must facilitate ARP requests in order to receive an IP from DHCP and requires re-provisioning to successfully download FX or start an install. 12 Installing an ssh client and server is the first priority, and adding your id_rsa.pub to ~/.ssh/authorized_keys enables tab autocompletion for scp commands that looks up the path on the remote machine each time. 34
