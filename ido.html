IDO

Claims: 12

IDO (IRIS Development Option) is an older compiler suite for IRIX 5.3, and it is specifically required for IRIX 5.3. 12 IDO is needed for IRIX 6.2 in some cases, and it is required for using the IRIX 5.3xfs filesystem with specific patches. 34 IDO is used to compile Vis5D 4.3 on IRIX 5.3, and the scsiha source code is available as sample source code in the irix_dev.gifts.scsi subsystem as part of IDO. 56 IDO runs perfectly fine on qemu, and qemu-irix was designed for running user space applications that don't touch the hardware, specifically for IDO, the IRIX 5.3 compiler. 78 A DAT tape backup is useful for automated system recovery on an Indigo with IRIX 5.3 and IDO, and properly lettered install, IDO, NFS, and matching maintenance CDs are needed. 910 Solaris included developer tools and libraries in the base system, while IRIX required additional software like IDO. 11
