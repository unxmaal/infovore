multipipe

Claims: 7

Multipipe refers to using two or more graphics cards on a single X server. 1 The Compositor connects via USB, but multipipe drives it. 2 The Onyx4 can be set up for multipipe but lacks full compatibility. 3 Multipipe is not supported by VPROs on an Octane. 4 Multipipe doesn't support the Indigo magic desktop. 5 Multi-pipe on an Octane does not use normal Xsgi, leading to desktop issues, some software not working, and a louder machine. 6 The CBOB can start automatically with the system and supports multipipe from GL. 7
