PowerMac

Claims: 15

openboot was written in FORTH and is used on many PowerMac computers and some Sun systems; it includes DHCP configuration in FORTH source code available on GitHub. 1 The PowerMac can access a remote optical drive in target mode and can be used as a render farm for network rendering via Vue, which requires a serial number for the addon. 23 Rhapsody DR2 can boot on a PowerMac, though the firewire disk did not work, requiring booting from USB. 45 Flipping the endianness switch from big to little on a PowerMac can break the system, requiring a backup of the firmware beforehand. 6 The PowerPC card turns a 68K Mac into a slow Power Mac, costing around $350. 7
