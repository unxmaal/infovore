showconfig

Claims: 3

The 'showconfig' command provides bootup information, and 'swap=dks0d1s1' should work but causes SCSI errors, while 'boot=dks0d1s0' works without errors. 1 To use showconfig, add it as an argument to sash, like 'setenv showconfig istrue'. 2 The 'showconfig' flag is set within the 'main' function, and there's no way to set it before running 'main', so the only way to print the CPU revision is to patch the kernel binary. 3
