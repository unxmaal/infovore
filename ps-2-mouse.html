PS/2 mouse

Claims: 14 Background: 3 claims already covered by Wikipedia, see PS/2 port, USB.

The USB keyboard and mouse spec includes backwards compatibility with PS/2, and the adapters used for this are 'dumb' and wired straight through. 1 A PS/2 mouse can be plugged into a USB computer, and it can also be plugged into a USB hub without USB ports using a caddy design. 23 The O2 uses standard VGA, PS/2 mouse, and PS/2 keyboard. 4 A PS/2 mouse is compatible with the Indigo and Onyx, though an IRIS Indigo and Onyx mouse is not PS/2. 5 The Indigo mouse uses a shorter cable than the PS/2 mouse, typically around 50-60cm. 6 To start working with SGI systems, you need a null modem serial cable, PS/2 keyboard and mouse, and a SoG VGA display, preferably multisync. 7 Plugging a PS/2 mouse into an SGI machine can blow up a capacitor inside. 8 The PS/2 mouse can have issues with the PS/2 port, sometimes only working in certain parts of the boot process and stopping after X starts, and can be fixed by restarting the graphics server. 9
