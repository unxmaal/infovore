nginx

Claims: 6

nginx was written to handle connections with worker pools using epoll instead of one thread per connection, while Apache struggled with many threads. 1 nginx supports reloads and can be used as an alternative to haproxy for load balancing. 2 When building nginx, you can specify the location of the pcre source to compile and link it statically, avoiding the `libgcc_s.so.1` dependency. 3 NGINX + FreeBSD + MyBB + PHP-FPM is efficient, using about 2 megabytes per request. 4 The sginet-light-http can communicate directly with a local nginx and includes an init.d daemon script. 5 The idea is to use an nginx proxy for filtering on retro SGI servers; older Apache on IRIX has hardening guides; disable all but GET requests initially. 6
