shared library

Claims: 11

Using a shared library implies sharing it between programs, so storing it locally without sharing is redundant. 1 To build a shared library, you need to compile the source files as position-independent code and link them with -shared, and optionally -soname. 2 At runtime, the loader uses the latest ABI-compatible shared library, so when a library breaks the ABI you increment the major version number, and when adding new entry points without breaking the ABI you increment the minor version. 3
