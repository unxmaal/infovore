Mac OS 7.6

Claims: 3 Part of Mac

Mac OS 7.6 can be run on a Power Mac G3, which has built-in PS/2 and VGA ports. 1 Mac OS 7.6 does not make much use of dual CPUs, and the only SMP application included is the Mandelbrot demo from DayStar. 2 The Q610 runs acceptably fast but not great, while the Q950 provides a very good experience, especially with a 10k spinning disk. 3 The Q950 can triple-boot A/UX 3.1.1, Mac OS 7.6, and Mac OS 8. 3
