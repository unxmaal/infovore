eoe.sw.base

Claims: 6

eoe.sw.base conflicts arise with NFS files from booterizer installation, NFS 5.3, and incompatible software versions such as irix_dev.sw.headers (1274627335) with eoe.sw.base (1289434520). 123 RapidApp 1.1 requires a newer version of eoe.sw.base than is compatible with IRIX 6.5.30, so upgrading RapidApp or eoe.sw.base may be necessary. 4 When encountering a package conflict with eoe.sw.base, you usually just need to load the overlays, which include patches for things on the NFS disks to make them compatible with changes in 6.5.x. 5

Sources

  1. the NFS files from booterizer installation give version conflicts with eoe.sw.base. (user-d166, 2019-09-10, exchange 216834, check: uncheckable)
  2. NFS 5.3 cannot be installed due to compatibility issues with eoe.sw.base. (user-d2ef, 2023-05-25, exchange 38212, check: supported)
  3. Incompatible versions of software can prevent installation, such as irix_dev.sw.headers (1274627335) with eoe.sw.base (1289434520). (user-231e, 2026-05-01, exchange 90563, check: supported)
  4. RapidApp 1.1 requires a newer version of eoe.sw.base than is compatible with IRIX 6.5.30; upgrading RapidApp or eoe.sw.base may be necessary. (user-3a92, 2023-05-04, exchange 218031, check: supported)
  5. Any time you run into a package conflict with eoe.sw.base, you usually just need to load the overlays. The overlays included patches for things that are on the NFS disks to make them compatible with changes in 6.5.x, (user-d903, 2022-09-12, exchange 217691, check: supported)
