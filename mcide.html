McIDE

Claims: 7

McIDE is a new build primarily for CF cards and based on the XT-IDE BIOS, and it is not widely compatible with other MCA IDE cards. 1 The XT-IDE BIOS on the McIDE is not well-suited for operating systems beyond DOS. 2 On an IBM MCA system, the 'fdisk /mbr' command is necessary to set the boot record on a DOS HDD, and manual intervention is required to boot from a floppy if not specified. 3 PC-DOS 7 can be installed on the Model 70 with a McIDE and BlueLightning CPU upgrade using a Zip disk. 4 OS/2 3.x has issues with the McIDE, even when installed with floppies. 5 The PS/2 55SX with XGA-2, Sound Blaster, and McIDE is a satisfactory setup, while the Model 80 is preferred but has foam issues. 6 Built-in IDE on Lacuna is not as fast as McIDE. 7
