X11 forwarding

Claims: 14 Part of X11

X11 forwarding is a function of the X window server that allows accessing a remote machine from a local system, though it can be very slow, especially with crypto overhead. 123 It requires a running X11 server on the local system, works if the local DISPLAY is set to the correct value and ssh -Y is used to propagate it through the tunnel, and does not require a graphics system, needing only a CPU, RAM, Ethernet, and motherboard. 145 It can be smooth and reliable for work, was used to run applications over long distances with a record of 5625 kilometers, and made some distros usable on the altix, though support was limited. 678 Running games over X11 forwarding on an SGI workstation tends to result in an interactive slideshow, while running 4Dwm via X11 forwarding can give an Irix feel on an old Linux box. 910 Configuration can be tricky with incomplete documentation, and an alternative is using 'xhost +', which bypasses authentication but is less secure. 1112
