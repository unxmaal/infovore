permissions

Claims: 5

Permissions can be a source of administration issues, and using `chown -R` as root can break file ownership and permissions, causing issues like IRIX install failures. 12 Best practices include ensuring permissions are sane as part of general system security measures such as using sane passwords, not running unnecessary services, and blocking ads. 3 xfsdump creates a backup of the filesystem itself, including permissions and ownership. 4 Some users consider permissions and users to be unnecessary on their own computer. 5
