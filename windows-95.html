Windows 95

Claims: 28 Part of Windows Background: 3 claims already covered by Wikipedia, see Windows 95.

Windows 95 was considered modern Windows at the time of SoftWindows95's release, and it borrowed enough from other operating systems that most modern GUI expectations were present. 12 Windows 95 ran on as little as 8 MB of RAM, using 20.1 MB of memory at startup, and some 486 systems shipped with Windows 95 and 16 MB. 345 Windows 95 was released before RTM and had stability issues, leading to frequent reinstallation, with the 9x branch being particularly unstable compared to early NT. 6 Windows 95 has a monochrome display mode and was the first OpenGL many users encountered on a PC. 78 Installing Windows 95 from a floppy disk was possible but not recommended, and floppy disks could fail spontaneously during installation. 910 Windows 95 can be installed on a barebones DOS system disk by copying install files from the CD and booting the installer, or by running the full install on another system and copying SYSTEM.1ST to SYSTEM.DAT. 11 Windows 95 can be installed over the FreeBSD SCSI target framework by booting from an emulated ISO image, though this requires ongoing FreeBSD work to support Adaptec cards. 12 Windows 95 can be networked with NetWare, though this is slow and has issues, and a NetBoot EPROM can network boot Windows 95, though it is interrupted by a text-mode login prompt and does not properly shut down. 1314
