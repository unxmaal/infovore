libexslt

Claims: 3

To disable the XML module in BRL-CAD, set the CMake variable BRLCAD_BUNDLED_LIBS to AUTO, install libxml, libexslt, and libxslt, and clean the build directory before re-running CMake. 1 Libxml 2.6.27 and libxslt 1.1.20 have ports in tgcware, but libexslt does not, though it may be included in libxslt. 2 The rse and didbs repositories contain the libxslt, libexslt, and libxml2 libraries, and you can get the patches from there. 3
