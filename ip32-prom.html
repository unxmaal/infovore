IP32 PROM

Claims: 5 Part of IP32

The O2's ip32PROM requires specific CPU chip registers and data values to boot correctly, with different requirements for the RM7900 compared to the RM7000 chip, necessitating modifications for RM7900 compatibility. 1 The ip32PROM code in the leaked IRIX source code is incomplete, missing common definitions and rules. 2 Running GXemul with specific arguments allows emulating an IP32 PROM, though using incompatible CPU/PROM versions can result in a black screen and frozen emulation. 3 The IP32 PROM version V2.3 executes cleanly with ./gxemul -E sgi -e ip32 -C R5000 -Q 0xbfc00000:0x100:IP32PROM-v2. 4 The code in version 4.3 of the IP32PROM has a potential overflow issue due to the size of the evbuf variable, which is defined as 64 strings of 20 bytes each, causing corruption when the segment size is exceeded. 5
