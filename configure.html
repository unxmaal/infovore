configure

Claims: 15

configure is a shell script generated by gnu autotools from configure.in, and it is entirely singlethreaded. 12 Editing configure.in and regenerating configure is the best fix, though removing specific lines can also work, and the scripts can be complex and hard to. 1 You typically tweak flags before running configure to include the right headers/libraries without editing makefiles, and the command displays the srcdir variable. 34 Using the $CC environment variable may not override ./configure detection of /usr/bin/cc, and there might be a flag like --with-libtiff=/usr/local when headers are in /usr/local but not /usr/local/include. 56 If configure cannot find something despite specifying the location via --with-something=/somepath or CFLAGS=-I/somewhere LDFLAGS=-L/somewhere, you must look at config.log to see why it did not find them. 7 The shell script fails to exec the as command if the AS_FOR_TARGET environment variable is not set correctly before running configure, and sanity checks that ls works and that a newly created file has a newer timestamp than configure itself. 89 Some packages may run configure in a subdir, and make clean might run subdir/configure if clean depends on subdir/Makefile. 10 The Makefile calls configure and autoconf on its own, ignoring flags from the Spec file, causing issues with linking. 11
