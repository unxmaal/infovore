scsicontrol

Claims: 5

The `scsicontrol` command can retrieve temperature data from SCSI drives, returning the current temperature in Celsius using the subcode `0x1`. 1 The command works on an O2 once the correct character is used, but the drive does not support the log page. 2 The command fails on the user's Challenge S due to a character issue, and `scsicontrol -l /dev/scsi/sc0d2l0` fails on their O2 with the error 'logsense cmd to get list of logsense pages fails'. 34 The system can automount the CDDA filesystem correctly with the right software, and issues may be resolved by using a scsicontrol program or fixing the installation. 5
