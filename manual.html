manual

Claims: 24 Background: 2 claims already covered by Wikipedia, see BIOS, SGI Indigo2.

The manual can be read from the CD or installed to the hard disk. 1 A now available high-quality manual is community-sourced, provided by the voron dev team/community. 2 The manual can be followed to configure the Mach64 graphics board on an Ultra 10, using `show-displays` to find the correct nvalias magic string, then setting `output-device` and enabling `use-nvramrc` via OpenBoot commands. 3 Page 42 of the manual shows the g-brick midplane, and page 122 shows the L1 system controller's location in the g-brick. 4 The BIOS does not recognize something the manual mentions. 5 To use the cu command, install eoe2.sw.uucp and refer to the manual for details. 6 The manual suggests the system can be powered independently of a CPCI backplane, which is useful. 7 When installing, follow the manual at https://irix7.com/techpubs/007-3819-004.pdf. 8
