CHD files

Claims: 6 Part of CHD

CHD files are like HDF files of a working IRIX install. 1 An OS that can read the SGI partition map and mount the efs partitions is needed to access .chd files. 2 CHD files contain a filesystem that can be extracted using chdman; the extracted files can be burned or used with tools like efs2tar. 3 `chdman info -i <filename.chd>` gives the SHA hash for a CHD file, which is in the softlist. 4 Using `mame64 <system> <softwarelist entry>` works for MAME; CHD files need to be obtained from somewhere first. 5 There are places to get CHD files for different IRIX versions and bios files, and I have them on my FTP server. 6
