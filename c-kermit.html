C-Kermit

Claims: 8

C-Kermit is a serial communications tool that is theoretically portable to anything Unix-like, though it has a bit of a learning curve. 1 It can make connections to other instances of itself, send and receive variables and files, and run programs. 2 C-Kermit's scripting language has been used for automating a bunch of things, including automating device consoles and dumping ROMs. 345 C-Kermit scripts can automatically connect to free USB serial devices, and the project is collecting build results for C-Kermit 10. 6 The machine is used occasionally to check C-Kermit builds on Solaris 10. 7
