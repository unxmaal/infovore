CPU board

Claims: 24 Part of CPU Background: 1 claim already covered by Wikipedia, see Motherboard.

The system has a CPU board, RAM board, floppy board, and a video board. 1 The CPU board has 8 x 32-bit memory slots, and addresses 0xbc000000 to 0xbfffffff are reserved for the CPU board while 0xb0000000 to 0xbbffffff are for system hardware. 23 The CPU board part number is Intel A13798-202. 4 The 745i and 748i have the same CPU board but differ in size and VME slot availability. 5 The CPU board for an IP is a tiny board in a VME carrier, and a second IP7 CPU board can be added even if the CPU frequencies differ, as long as PROMs match. 67 An Octane's CPU board uses capacitors, including electrolytic ones, which can be replaced with more heat-resistant types like poly caps or organic compound SMD caps. 8 The battery is on the CPU board, and care is needed when inserting it, especially with the original battery. 9 A loose CPU board on an O2 can cause stability issues, which can be resolved by reseating the board. 10
