sgug-rse

Claims: 92

With nekoware

SGUG-RSE is a project for installing software on IRIX, succeeding nekoware, which had replaced SGI's freeware package. 12 SGUG-RSE uses RPMs for software packages, whereas nekoware is the work of many people (some newer but much outdated, with dependencies harder to figure out) and tgcware is one person's work that is not updated but has dependencies in one place. 3 The package search tool can find software in nekoware, sgug-rse, and sgi-freeware, and is available in the sginet-client CLI. 4 Some software is available through multiple sources: dosbox is in SGUG-RSE but not available via tdnf (users should use the nekoware version that works with SDL1.x), and minicom can be found on nekoware or sgug-rse. 56 Installing 'man' from SGUG RSE or nekoware can cause formatting issues and converter errors, rendering manpages unusable, so users may need to revert to the default manpages. 7 user-d903 promised user-f229 to push updates to booterizer for sgug-rse to eliminate nekoware. 8

General

SGUG-RSE is an RPM-based distribution for IRIX 6.5 that provides modern packages and compilers, including GCC 9.2.0, so that a GNU compiler suite can be used instead of MIPSpro. 9101112 It consists of Fedora Core 31 SRPMs that have been lightly modified to build and function on IRIX 6.5.30, plus Dan's IRIX Compatibility Library (DICL), and any SRPM could serve as a base. 1314 The project is most active in its wip branch, and its spec files can be found in the sgug-rse-wip GitHub repository. 1516 It has a stable build with many packages available, though it may have some glitches. 1718 SGUG-RSE is a repository of software for IRIX 6.5.x, built with modern bash and gcc. 192021 Installation involves extracting archives under /usr as root, adding /usr/sgug/bin to your path, and launching sgugshell, which is required to use the packages. 222324 The installation directory /usr/sgug should not be modified outside of itself, and sgug-rse is used only when needed rather than added to shell startup files by default. 2526 The repository includes Barrier, netsurf-motif, Worker, XMMS, and SDL2 version 2.0.12 with patches. 27282930 SGUG-RSE uploads HINV data to a website and optionally counts uptime. 31 The SGUG-RSE project relates to compiling the IRIX-dev branch, which should work on an Octane2 if a binary is available. 32
