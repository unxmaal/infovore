IRIX 6.5.5

Claims: 7 Part of IRIX 6.5 Background: 2 claims already covered by Wikipedia, see XFS.

Leaked versions of IRIX 6.5.5, 6.5.7, and possibly 6.5.17 exist on the web, along with available kernel sources for 6.5.5 and 6.5.17. 12 The IRIX 6.5.5 source tree contains both 'feature' and 'maintenance' branches. 3 IRIX 6.5.5 introduced XFS v2, which became the default filesystem in IRIX 6.5.14. 45 Linux support for XFS was removed by SGI before v3, so current Linux cannot read IRIX XFS filesystems. 6 The IRIX 6.5.5 and 6.5.17 kernel modules and drivers share an identical basic architecture. 7
