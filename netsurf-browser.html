Netsurf browser

Claims: 6 Part of Netsurf

The Netsurf browser runs on the Octane2 and performs better than expected, though it may have issues with mobile sites due to CSS selector support limitations. 1 It can be configured with specific command-line options to improve responsiveness, such as disabling advertisements and incremental reflow, and turning off JavaScript. 2 Smooth scrolling requires clicking on a non-text area, and most keyboard shortcuts work, including zooming, but there is no reload shortcut. 34 The GL build renders everything twice to avoid issues with redrawing, and the Motif GUI version can be installed with the command `sudo /usr/sgug/bin/tdnf install netsurf-motif`. 56
