sector size

Claims: 4

The SCSI controller on the IRIX machine supports up to 4 billion sectors with C/H/S 16-bit/8-bit/8-bit addressing, and the sector size is a factor. 1 The sector size on SGI CDs is 512 bytes, while on ISO9660 it is 4096 bytes. 2 When ripping EFS media, `safecopy` should be used instead of `dd`, with the proper sector size set. 3 The Multia wants to change the sector size dynamically when booting from optical devices. 4

Sources

  2. The sector size on SGI CDs is 512 bytes, and on ISO9660 it is 4096 bytes. (user-bc5d, 2020-07-05, exchange 216716, check: supported)
