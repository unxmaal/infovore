SBCL

Claims: 11

SBCL is a Common Lisp implementation derived from CMUCL, which had IRIX support through sigcontext. 12 SBCL's MIPS backend is complete, and it already has Linux-MIPS support. 3 Porting SBCL to IRIX involves defining struct sigcontext as os_context_t, creating IRIX-specific platform files, and understanding IRIX/POSIX/MIPS. 45 The port is considered trivial because the underlying compiler works on IRIX and supports big endian MIPS, and would take about an hour. 67 SBCL has a simpler bootstrap build system than CMUCL, though cross-compilation can be challenging, especially with SBCL being written in Common Lisp. 89 Porting SBCL to IRIX may result in a fork if the main project does not accept the patch. 10
