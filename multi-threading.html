multi-threading

Claims: 4 Background: 1 claim already covered by Wikipedia, see IRIX.

The project builds on IRIX and includes a growing widget library, a network library, multithreading, and display to textures. 1 On Windows NT, symmetric multiprocessing could improve overall system responsiveness even for applications not explicitly supporting multithreading. 2 Using multiple OpenGL contexts together with multithreading might help with performance. 3 povray 3.8 runs on IRIX with multithreading using 16 CPUs. 4
