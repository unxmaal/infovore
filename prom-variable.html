PROM variable

Claims: 4 Part of PROM

  • You need to set a PROM variable with the address (`setenv netaddr 192.168.1.100` for example). Your Linux box will need a static address (e.g. `192.168.1.101`), then they should see each other. (user-0bb7, exchange 225462, 2025-09-20; 1 speaker(s), 1 conversation(s))
  • The O2 has a prom variable, but it does nothing on some systems. (user-231e, exchange 200093, 2026-02-21; 1 speaker(s), 1 conversation(s))
  • The SCSI2SD allows installing multiple versions of IRIX on a single system by setting prom variables and using different device IDs. (user-e4d0, exchange 19034, 2021-08-06; 1 speaker(s), 1 conversation(s))
  • Dual booting two IRIX versions from separate root partitions is possible by changing PROM variables. (user-22f9, exchange 2805, 2019-07-29; 1 speaker(s), 1 conversation(s))
