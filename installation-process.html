installation process

Claims: 7 Part of installation

The installation process on an Octane involves rebooting. 1 The IRIX 3.3.2 installation process involves booting into a standalone shell and using commands to install the system from a network server, requiring specific files and folder structures to be in place. 2 The IRIX installation process requires formatting the drive and adding repositories, followed by running specific commands. 3 The OS/2 installation process is complex and requires multiple diskettes and a CD, with careful partitioning and multiple reboots. 4 Fucking up an IRIX installation is a common occurrence, and the problem with installing IRIX is not always an issue with the installation process itself. 56
