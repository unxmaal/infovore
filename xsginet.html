xsginet

Claims: 4

xsginet is a client that allows taking screenshots and uploading them to sginet.user-7973.io for use in Discord on IRIX. 1 xsginet requires the Motif library, which can be found in the sgug package or the IRIX package. 2 If the sgug Motif is not available, install the sgug motif using tdnf. 2 netsurf-motif ran on the indigo2 without sgug motif, but xsginet did not. 3 Running 'rpm -i' as root or with sudo did not install the latest xsginet, and 'xsginet -u' did not update the software. 4
