Atari ST

Claims: 31 Background: 4 claims already covered by Wikipedia, see Atari ST.

The Atari ST is a home computer that came with a logo, GUI, and ST BASIC, and runs a version of GEMDOS that can run C code without significant slowdowns compared to the 6502. 123 The Atari ST has 1MB of RAM, a 1.79MHz CPU, 256 on-screen colors, and 4-channel sound. 41 The Atari ST operating system, TOS, is user-friendly and includes features like an auto folder for autoloading programs and accessories, and the OS in ROM provides speed benefits by not needing to load most of the OS off disk. 56 The Atari ST is well known for MIDI sequencing, with some people breaking out the ol' Atari ST specifically for a rock-solid MIDI sequencer, and some Cubase and eMagic software would run on an Atari ST. 789 All Atari STs should have MIDI, with the 520 having an external power supply and the 1040 having an internal one. 10 The Atari ST can be upgraded with a blitter and 68010 CPU, and the Motorola 68010 CPU is pin-compatible with the 68000 but not binary-compatible. 1112 The Atari ST used coax for RGB signals, but the STe added 15-pin ports, and ACSI is SCSI-lite used for backwards compatibility with different hard drive types, especially the Mega STE. 1314 The Atari STs had an issue with the sockets pushing chips out after heating/cooling, and power supplies and CRT monitors are the main issues for old Atari STs, with some power supplies being unreliable and upgradable. 1516
