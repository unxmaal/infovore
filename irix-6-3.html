IRIX 6.3

Claims: 46 Part of IRIX Background: 10 claims already covered by Wikipedia, see SGI O2, IRIX, SGI Indy.

IRIX 6.3 was a platform-specific release exclusive to the O2 architecture, launched in 1996 as a stopgap before the O2's full release. 1234 It was followed by IRIX 6.5 in 1998, and SGI did not invest much in 6.3 after that. 1 IRIX 6.5.30 is recommended for most machines, as 6.3 may have compatibility issues. 5 IRIX 6.3 can have issues with a black screen on an R12K O2. 6 Alias/Wavefront on IRIX 6.3 can cause a complete system failure if installed, even if flexlm is disabled. 7 IRIX 6.3 requires the -003 CD to install a fresh copy, and it has fewer installation disks than 6.5. 89 A fresh install of IRIX 6.3 can have package conflicts, but one set of IRIX 6.3 discs avoids them. 1011 To install IRIX 6.3, boot from a late patch CD, install the base system, then swap the patch CD back in and install relevant patches. 12
