GFXBOARD

Claims: 6

The GFXBOARD=MGRAS option should be placed as the first argument to the inst command, like 'inst -m GFXBOARD=MGRAS -f /cdrom/dist'. 1 inst files can have GFXBOARD or MGRAS restrictions that can be overridden with -m GFXBOARD= or -m MGRAS= options or by modifying the files with sed, and a ruby inst clone is available for Linux at https://github.com/irixxxx/. 2 The installation process for demos can be bypassed using the -m GFXBOARD= option with the inst command. 3 Unplugging the GFX board resolves the issue, indicating it's a graphics board problem. 4 Mekton requires correct GFXBOARD entries in demos.idb for proper functioning; missing entries cause texture problems, and VPro's fallback to RealityEngine breaks texture rendering in older software. 5 The user's Indigo 2 with IRIX 6.5.22 does not have the correct GFX board to run the Buttonfly demo from the 'Silicon Graphics General and Platform Demos 6.5.12' disc set. 6
