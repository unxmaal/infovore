Homeworld

Claims: 12 Background: 1 claim already covered by Wikipedia, see OpenGL.

Homeworld was released in September 1999, during the Voodoo 3 era, which was not as advanced as the TNT2 era. 1 The Homeworld source code is available on GitHub and is an OpenGL 1.1 game. 2 Homeworld now compiles and runs on Linux, but it needed some changes to build properly; it does not pick up the --enable-x86_64 option correctly, requiring an override in the configure script. 3 Homeworld requires SDL2 with GL enabled, and it uses SDL2 for audio, which may involve IRIX AL in the background. 4 The SDL1.2 version of Homeworld can be used for compatibility with GL, but sound parsing is skipped due to a current stuck point in loading the GL world without a debugger. 5 Homeworld can be run with a custom binary that requires unreleased SDL2+GL packages; it supports window resizing but crashes on game missions and lacks sound. 6 The 'Adagio for strings' theme plays when starting a new game of Homeworld, with a buffer size of 256 samples; increasing to 4096 samples improves audio performance. 7 Running `homeworld` may result in a bus error and core dump due to issues with setting gunbindings. 8
