diskless booting

Claims: 3

Diskless booting involves copying a miniroot to a swap partition and mounting it as root, which requires a kernel capable of mounting the root filesystem, and the PROM environment can specify the root path. 1 NetBSD diskless booting requires specifying the correct file to TFTP, similar to SunOS 4.x where the file name includes the Sun's IP in hexadecimal. 2 433T supports diskless booting over Ethernet using an emulated dn3500 server. 3
