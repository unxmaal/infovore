cp

Claims: 5

In IRIX, cp -R does not copy dot files, so 'cp -R .*' should be used to copy all dot files. 1 IRIX cp does not support verbose mode. 2 IRIX cp has predictable behavior and prevents foul-ups. 3 cp and mv differ regarding trailing slashes in source paths: cp does not copy the source directory itself if there is no trailing slash, while mv moves the entire contents including the directory itself. 4
