screensaver

Claims: 10

The IRIX screensaver menu binary is /usr/sbin/screensaver, with a manpage named ssaver. 1 A screensaver could show system activity and memory usage. 2 Locking is handled by xlock, which requires haven or the actual screensaver to support it. 3 The mechanism can do anything to identify windows and allows any GL program to be a screensaver. 4 SGI has a screensaver where cubes roll down stairs but it runs at 5 FPS, and the Falls screensaver is known to be very slow. 56 Disabling the screensaver on an Octane requires a different approach than using XDisableScreenSaver, XResetScreenSaver, or XGet/SetScreenSaver. 7
