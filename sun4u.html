Sun4u

Claims: 6 Part of Sun Background: 1 claim already covered by Wikipedia, see Oracle Solaris.

The sun4u architecture can run Solaris 10, and Tribblix runs on any sun4u system, including the Ultra 1. 12 OPENSTEP 4.2 will not run on sun4u, and Sun Studio 12 will not run on US-II and later sun4u systems. 34 The IIi represents an upgrade from the sun4m architecture to sun4u, a change not favored for altering the machine's architecture. 5 Java Desktop was shipped as the default on all sun4u hardware, including the Ultra 5. 6
