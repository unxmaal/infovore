SGI asset tag

Claims: 3 Part of SGI

An SGI asset tag indicates ownership, as evidenced by a bar code reading 'property of sgi' on an Indigo1 system for sale in YYC. 1 The Sun asset tag has no additional value if its serial number matches that of an identical machine without it. 2 The asset tag indicates ownership, suggesting this Indy was likely owned by SGI. 3

Sources

  2. The Sun asset tag has no additional value if the serial number is the same as an identical machine without it. (user-c831, 2026-02-03, exchange 240790, check: uncheckable)
