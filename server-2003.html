Server 2003

Claims: 4 Part of server

Server 2003 can be used for Appletalk file serving, either on its own or with Server 2000 running the Appletalk protocol and routing, but this requires legacy features to be re-enabled. 12 Server 2003 can use x86 drivers for an Audigy sound card, though they may not work. 3 Server 2003 runs on the bare metal of an IA64 system and is usable, with Half-Life running fairly well and IDA Pro being quite usable. 4
