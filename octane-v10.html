Octane V10

Claims: 6 Part of Octane

An Octane V10 with 256MB of RAM has a working GPU, while another Octane V10 has a dead GPU but still works in an IP17. 12 Quake3 is playable on an Octane V10. 3 The Octane V10 requires a bracket for the DCD, while the IP35 can use the VPro bracket. 4 On an Octane V10, Rosegarden felt a bit choppy on user input but was responsive in output, with a default response rate of 200ms that could be improved with -burn mode, which uses more resources but renders in real time. 5 The Octane V10 requires 128MB RAM if the board doesn't have K4S643232 memory chips, and VRAM can be replaced with higher capacity RAM chips. 6
