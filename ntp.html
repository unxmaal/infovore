NTP

Claims: 9

NTP runs on boot time before anything that checks dates, so it can handle time issues. 1 Compiling NTP requires running configure twice, and NTP 4.2.8p13 fails with an undeclared PATH_MAX error, which can be fixed by defining PATH_MAX to 4096; subdir configure scripts in NTP do not share results, leading to redundant configuration steps. 23 There have been NTP ports before; this one is neko_openntpd-3.9p1. 4 ESXi and Windows VM should synchronize their clocks using NTP; ESXi uses UTC by default. 5 An Indy's clock being off is likely due to an old DALLAS chip and can be corrected with NTP; an NTP server might not be available immediately after a cold boot, leading to clock issues. 67
