tardist

Claims: 54

A tardist is a tar archive packaged inside the IRIX `inst` format, and its file structure typically includes license, install, readme, remove, and sw files. 12 Tardist files can be created using tools such as EPM, irixports with EPM (with spec.py handling package specifications), nekoware, and tgcware scripts, and can contain selectable install sections for the main install, manpages, dev libraries, and source. 3456 Tardist packages built with DIDBS GCC work on other IRIX machines, and tardist files can be installed on IRIX by following specific installation steps. 78 The `inst` command requires a tardist file to be untarred into a folder before opening it, and it can fail after creating 26 temporary directories when installing multiple tardist packages, a problem resolved by extracting files manually. 910 The software manager on IRIX has trouble reading tardist files, and the swmgr tool cannot open certain tardist files, reporting them as 'bad'. 1112 The swmgr tool can download .tardist files over the web to /tmp, and gunzip is needed to decompress .tardist files on IRIX 5.3. 1314 Tardist files can contain source code and patch files, though their inclusion was arbitrary among developers, and better nekoware packages included source and patches as optional installs. 1516
