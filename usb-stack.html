USB stack

Claims: 4 Part of USB

The USB stack in Octanes relies solely on IP35 hardware, which leads to compatibility issues with USB devices. 1 The SGI USB stack on their systems is a partial implementation, supporting keyboard, mouse, and possibly a sound card. 2 Developing a USB stack and FAT32 filesystem is challenging but doable. 3 A user has old IRIX source code that is not booting and is willing to help with questions and contribute code, especially for a USB stack. 4
