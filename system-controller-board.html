system controller board

Claims: 3 Part of system controller

The system controller board is located next to the power regulator boards on the rear side of the backplane and contains components that sense voltages and fan operation. 1 The RealityStation has a single CPU, while the Challenge has a screw in the backplane that restricts CPU slots and can be removed with pliers. 2 A system controller board check determines the number of CPUs, and the Challenge system controller board restricts more slots, requiring a new board for multiple CPUs. 23 The Challenge DM was likely a marketing strategy to keep the warranty. 3
