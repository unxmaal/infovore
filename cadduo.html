CADduo

Claims: 23

The CADDuo is a PCI card that enables a second workstation off a single multi-CPU Octane, providing a dual-head/2-user setup under the IMPACT graphics. 123 The CADduo uses the same chip as the system board and requires configuring the X server for two seats, typically with two heads, though it is not a supported configuration. 4 Multiple CADduos can work together, each displaying an independent X environment, but four causes a fault on IRIX startup. 5 The CADduo manual states that sound is not supported in multi-seat mode. 6 An Octane with a CADduo could run a multi-player MUD or Unix demo with multiple serial terminals. 7 The CADduo is similar to the O2k, and a CADDUO can be used on an O2k. 89
