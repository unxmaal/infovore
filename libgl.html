libGL

Claims: 4

libGL is the library that interfaces with OpenGL drivers, not glx. 1 The `libGL` library contains code specific to the graphics architecture, with a platform-specific version on the O2 linked to `/usr/gfx/arch/IP32CRM32/libGL.so`. 2 libGL loads with dlopen and calls XSGISetSpecialDestroyHandler, which requires linking with a specific X-related library. 3 Linking both `libGL` and `libGLcore` is a GCC issue. 4
