Indigo Magic Desktop

Claims: 5 Part of Indigo

Indigo Magic Desktop can run on Solaris, and Solaris's installer can run on IRIX. 1 Mex lasted from ~1984 to 1993, with the last vestiges of Max/Mex removed when the Indigo Magic Desktop came out in IRIX 5. 2 The 'go' command is needed to install the IndigoMagic desktop. 3 Multipipe doesn't support the Indigo magic desktop. 4 The Indigo magic desktop was renamed to the IRIX interactive desktop in version 6.5. 5
