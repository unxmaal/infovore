GX1

Claims: 3 Part of GX

The GX1 is a GPU core used in the Wii and Wii U consoles, and it copies data from its frame buffer to the R700-based GX2 GPU core for display output using a hardware copy engine. 12 The GX1 GPU core in the Wii and Wii U can be improved for video output quality using the evwii plugin with the Aroma environment on a Wii U. 1 Intergraph's GX1 workstation is not worth over $250, as its hardware can be obtained for less. 3
