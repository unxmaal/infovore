TCP

Claims: 6 Background: 1 claim already covered by Wikipedia, see Network File System.

TCP is used for Internet communication by MacTCP. 1 NFS typically uses TCP by default but can use UDP, and TCP is generally slower for NFS. 23 NFSv3 and older use dynamic ports while NFSv4 uses port 2049, and NFS servers may require clients to use secure ports below 1024, which NAT may translate to high-numbered ports. 3 NFSv3 requires rpcbind, and the server may listen on TCP only. 4 Setting localhost:0.0 forces GLX through TCP instead of direct rendering. 5 The DeskStation was a render box that used networking, specifically TCP, and was connected to an Amiga over thinnet. 6
