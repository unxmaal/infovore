libX11

Claims: 4

Some Python dependencies may require building additional libraries such as libX11. 1 libX11 is part of the X distribution and may require paths such as /usr/X11R7/include. 2 A proposed .pc file intended to avoid libX11 includes -I/usr/include -L/usr/lib32 -lX11, but remains ambiguous about where to pick up libX11 when an RPATH is set. 3 Linking an OpenGL app against libX11 and libXext can cause crashes, whereas omitting them allows the app to work. 4

Sources

  1. python dependencies can require building additional libraries like libX11. (user-2d09, 2020-04-30, exchange 68597, check: uncheckable)
  2. libX11 is part of the X distribution and may require /usr/X11R7/include or similar paths. (user-7b1c, 2022-11-08, exchange 239887, check: uncheckable)
  3. The proposed .pc file for avoiding libX11 includes -I/usr/include -L/usr/lib32 -lX11, but remains ambiguous about where to pick libX11 if an RPATH is set. (user-22f9, 2025-02-20, exchange 224637, check: uncheckable)
  4. Linking an OpenGL app against `libX11` and `libXext` can cause crashes, but omitting them allows the app to work. (user-8780, 2025-10-05, exchange 215824, check: supported)
