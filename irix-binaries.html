IRIX binaries

Claims: 5 Part of IRIX

Compilertron aims to produce IRIX binaries with minimal effort, rather than to serve as a development tool for GCC. 1 QEMU-IRIX cannot run IRIX binaries on a Linux system. 2 The SVx is registered as an e_machine format (number 73) in the ELF specification but is not used by IRIX binaries, which instead use MIPS (number 8), suggesting it might have been a CPU architecture in development. 3 IRIX binaries that don't use graphics hardware can't run on non-SGI hardware. 4 Ghidra can be used to reverse engineer IRIX binaries, with documentation available in mogrix/rules. 5
