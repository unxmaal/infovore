SCSI CD-ROM

Claims: 10 Part of SCSI Background: 1 claim already covered by Wikipedia, see SGI Indigo2.

A SCSI CD-ROM is necessary for certain Linux installations and is mandatory for old Unix systems. 12 External SCSI CD-ROMs and external HDD enclosures are nice to have but not necessary. 3 Any SCSI CD-ROM which supports full parity should be ok, such as the TEAC 532S, the Toshiba range up to the 40X 6401B, the NEC 3010A, or various CDRWs such as the Yamaha 8/4/24, 8/8/24 or 16/10/40. 4 The O2 is quiet, small, and has a built-in SCSI CD-ROM. 5 A SCSI CD-ROM will fit a SCSI DVD drive into an Indigo2. 6 The Tezro requires install media to set up network storage, which can be done from a SCSI CD-ROM. 7
