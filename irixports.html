irixports

Claims: 35 Background: 1 claim already covered by Wikipedia, see Heartbleed.

irixports is the official package system for IRIX, being developed by the Silicon Graphics user group. 12 It is a simple ports system meant to be used with epm for packaging, similar to OpenBSD or FreeBSD ports rather than their package managers. 3 irixports can build things in a specified directory, track installed versions, and is the basis for creating package binaries. 4 It handles dependencies by specifying them in the format 'depends="depend1 depend2 depend3"'. 5 irixports now allows choosing between gcc 4.7.4 and 8.2.0 with a gccversion variable, bootstrapped for both versions. 67 It can package IRIX software but currently lacks port scripts and doesn't package anything. 8 irixports will need work if packaging is intended. 9
