System Manager

Claims: 7

System Manager is a component of IRIX that displays information about the system in use, including charming pictures depicting the system in older IRIX versions. 1 System Manager will not start in the root account. 2 hinv and System Manager should indicate that the internal SCSI is keyed upside-down, though this is not certain. 3 System Manager on IRIX may fail to print CPUs if there are more than a certain number. 4 Setting sys_id and hosts to match the hostname 'lotus' fixes an error in System Manager. 5 A script toggles the default gateway on and off to allow internet access while using System Manager, resolving the need to change network settings manually. 6 The system is attempting to read block 0 but encounters an issue with memcpy in usb_command, possibly due to a null pointer or uninitialized data structures. 7
