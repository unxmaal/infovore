CD drive

Claims: 53 Part of CD

Real Indy units are picky about CD drive compatibility, and modding an Indy to fit a CD drive is rare. 12 Pre-8 Mac OS versions require an Apple CD drive or specific extensions, while later versions can use non-Apple SCSI CD drives. 3 The CD drive is an ancient 2x drive. 4 From L1, running `* pwr up` accesses the EFI shell where you can use a CD drive for OS installs. 5 Version 6.5.30 does not come with many demos beyond basic video test files, so an earlier version's apps CD can be used; they are installed using a CD drive and software manager, and the process does not require overlays. 6 A CD drive works fine but is picky about CDRs, except one brand. 7 The CD drive on the machine may be IDE-compatible but could have issues with ATAPI drives; SCSI or USB CD drives might work as alternatives. 8 The front internal speaker and CD drive playback audio are fine, but the line level type port out back is problematic. 9 Installing the base 5.3 version from CD results in constant SCSI bus errors, which are resolved by removing the CD drive. 10 The machine crashes when loading the kernel with the CD drive and PCI cards plugged in. 11 On IRIX 4.0.5, the install creates folders for /CDROM, /CDROM2, etc., but does not mount EFS CDs. 12
