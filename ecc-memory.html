ECC memory

Claims: 7

ECC memory adds an extra chip for error correction, but may not be used if the board does not have the necessary traces, and in SGI systems it is typically handled by the memory controller, requiring only the addition of extra data lines. 12 Intel did not require Xeon CPUs for ECC memory initially. 3 ECC memory is not necessary unless the system requires it, and registered RAM is often ECC since it is commonly used in servers. 4 ECC memory is needed for compatibility, but some machines do not support it. 56
