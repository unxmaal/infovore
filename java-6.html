Java 6

Claims: 7 Part of Java

Java 6 can be installed on PPC macOS Tiger via a developer preview available on Macintosh Garden, and on Leopard through a software update. 1 Java 6 is sufficient for running Minecraft on SPARC 10, and the newest precompiled version for Solaris 10u8 is Java 6, while Java 7 requires Solaris 10u9. 23 The Minecraft server can run on a J5600 with Java 6 on PA-RISC HP-UX 11.11, but networking may require a fix. 4 Minecraft 1.4.7 and FTB Ultimate run on Java 6, but Tekkit Classic does not because it targets Java 7. 5 Java 6 is the most likely candidate for a port, as OpenJDK 6 exists. 6 Java 6 requires Java 5 or 6 to compile and was never ported to IRIX. 7
