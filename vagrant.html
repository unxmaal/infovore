Vagrant

Claims: 44 Background: 4 claims already covered by Wikipedia, see Vagrant (software), VirtualBox.

Vagrant ships virtual machine configurations as code and keeps base disk images immutable, but has issues with Ruby code quality and error handling. 1 It uses a system of plugins that must be installed manually, and the newest version may resolve plugin installation issues. 23 Vagrant requires hardware virtualization and can run on Windows, though it is not officially tested there. 45 Cross-compilation can be done using any OS that runs Vagrant, including Windows. 6 Booterizer creates a virtual machine using Vagrant and Ansible to set up and provision an SGI system, with Ansible relying on Vagrant to map variables read from settings.yml and a distro yml before provisioning. 78 Vagrant can be used to wrap the xfsdump command for automation. 9 The Vagrant build was failing even in 2020. 10 Using the `vagrant-guest_ansible` plugin breaks things and is unnecessary for setting up Ansible on a Pi VM with Vagrant. 11 Vagrant can pull a newer VM with minimal changes, but keyring issues may arise due to archive key updates. 12 The Vagrant version of the solution is generally reliable once it works. 13
