exFAT

Claims: 9 Background: 1 claim already covered by Wikipedia, see SD card.

ExFAT has historically had poor support, notably lacking a Linux kernel driver for a long time, until a kernel driver was added in kernel 5.7, following Microsoft making the specification public in 2019 for Linux support. 123 Unlike FAT32, which has a 4GB file size limit, exFAT can handle files up to 128PB. 4 Reformatting an SD card as exFAT should work on a PC or Mac, though it may require checking logs for issues. 5 ExFAT performance on Mac is inefficient. 6
