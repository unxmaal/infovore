IP27

Claims: 8 Part of IP

The IP27 is a processor architecture used across several SGI systems, including the IP31 board, which contains five 350 MHz and two 400 MHz IP27 processors, each with R12000 CPUs and R12010 FPGAs, for a total of 8448 Mbytes of main memory. 1 IP27 processors are available in 350 MHz, 400 MHz, 300 MHz, and 250 MHz variants. 2 The IP31 is a hardware-only system that runs IP27 software. 3 The IP27 uses the SN0 architecture, whereas the similar ip35 uses SN1. 4 The QEMU SGI port supports ip2x systems, and because ip27 and ip35 are similar, a Linux port can run on both. 5 OpenBSD/sgi 7.0-7.4 supports the IP27, and the O2K Programmers Reference explains the IP27 memory map. 67
