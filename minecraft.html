Minecraft

Claims: 45 Background: 9 claims already covered by Wikipedia, see Minecraft, OpenGL, Video games and Linux.

Minecraft is the best-selling game of all time and uses OpenGL, relying on Java 5 or newer, OpenGL 1.1 support, LWJGL 2, and 192 MB RAM as general prerequisites. 12 The game can run on a wide range of systems, including Linux, Android, Windows 95, SPARC-Solaris, the Pi, the Personal IRIS, and various SGI platforms such as the Altix, Indigo2, and Altix350. 3456789 It can also run on IA64 under HP-UX with JDK8, on a J5600 with Java 6 on PA-RISC HP-UX 11.11, and on Solaris, though it does not run on an Octane. 1011121314 Performance varies by platform and version, with older versions sometimes running more easily than newer ones, and software rendering possible on 2D hardware though it may not function properly. 9151617 The game's code is described as poorly written with feature creep, its multiplayer server has significant memory leaks from version 1.12 onwards, and it can write garbage data into saves under certain crash conditions. 181920 Microsoft requires a Microsoft account for both the Java and Bedrock versions, and made a separate version for the Xbox 360 before acquiring the game. 2122 Minecraft versions 1.12 and up require Java 8. 23 Minecraft can run on IA64 Linux with radeon 3D acceleration, and can run on OpenGL 1.x. 2425 Minecraft can reach 100% CPU usage on one core if render distance is set to maximum. 26 Older Minecraft versions are lighter and may run better on older hardware. 27
