/etc/shadow

Claims: 4

/etc/shadow is a file that stores password hashes, which are moved out of /etc/passwd on some systems to lock down the shadow file and prevent users from seeing them. 12 The file is optional on IRIX, and a shell script can check for its existence and enable password shadowing if it does not exist. 13 If /etc/shadow becomes a binary file, it can be fixed by booting into install media, editing /etc/passwd, and running pwconv. 4

Sources

  1. /etc/shadow is optional (on IRIX); on some systems, the password hashes are moved out of /etc/passwd and put in /etc/shadow instead, to lock down the shadow file (user-6c80, 2024-08-31, exchange 210911, check: uncheckable)
  2. moving password hashes to /etc/shadow prevents users from seeing them. (user-1629, 2024-11-21, exchange 50728, check: uncheckable)
  3. A shell script can check for the existence of /etc/shadow and enable password shadowing if it doesn't exist. (user-6dfb, 2024-11-22, exchange 211310, check: uncheckable)
  4. If /etc/shadow becomes a binary file, it can be fixed by booting into install media, editing /etc/passwd, and running pwconv. (user-bba0, 2024-07-15, exchange 210656, check: uncheckable)
