With Linux

IRIX is based on UNIX, so it shares a file folder structure with Linux, though there are differences such as IRIX storing user home directories in /usr/people/<user> and the root user's home in /usr/people/root, whereas Linux typically uses /home/<user> and /. 123 Linux does not run on the same hardware as IRIX, but one can cross-compile packages on a Linux host for an IRIX machine, use a Linux VM to compile IRIX code with GNU tools, or install IRIX from IRIX, Linux, or Windows using TFTP. 456 Linux can natively mount XFS filesystems used by IRIX and serve NFS, and can mount CD images to FTP their contents to an IRIX system for installation. 78 Linux can mount SGI-format ISO files using the efs file system and share them via NFS, and IRIX can mount loopback devices using the EFS kernel module. 910 NFS generally works between IRIX and Linux, though IRIX has issues mounting NFS volumes from RHEL. 1112 Linux does not understand IRIX's concept of slices, and XFS Jaz drives formatted on IRIX are readable in Linux, though Linux may use 64-bit timestamps that IRIX cannot handle. 1314 Several software packages support both IRIX and Linux, including Wumbo, Electrogig, Blender, Cinepaint, GIMP, and CMake. 1516171819 Some IRIX features work similarly to Linux, such as chkconfig flags and the esd audio server, while CLOCK_SGI_CYCLE enables low overhead hardware With SGI

IRIX was the operating system that ran on SGI hardware; every SGI machine before the Itanium ran IRIX, and an SGI can run IRIX. 293031 SGI announced QuickTransit's first availability in October 2004 on its Prism visualization systems, which used QuickTransit to run IRIX applications on Itanium 2 processors and Linux. 32 The SGI Prism manual incorrectly shows 'welcome to IRIX' screens on monitors, suggesting either unfulfilled plans to port IRIX to IA64 or reusing existing graphics. 33 SGI missed two opportunities to port IRIX off MIPS. 34 SGI's IRIX ran on non-SGI platforms like the MIPS Decstation, and GXemul has good Decstation support. 35 SGI's IRIX trademark is used in the pharmaceutical and medical field, and trademarking IRIX and the Cube Bug could be an option. 36 SGI (now HPE) does not offer MIPSpro and IRIX licenses for hobbyists due to the small market size. 37 Most companies that made the software and that you would have to contact to get the activation keys are long since out of business or not servicing IRIX/SGI, and licenses were usually not transferable. 38 SGI developed the SGI image format library, which shipped with IRIX and provided standard image loading, saving, and processing capabilities. 39 SGI's IRIX did not support a 64-bit ABI until the R8000 series. 40 SGI, IRIX, and related software are considered important for historical preservation. 41

With Solaris

Blender, WordPerfect, and CATIA were available on these systems, with CATIA v4 found for IRIX but not v5, which was released for AIX and Solaris. 424344 The Quake source includes ports for UNIX distributions such as IRIX and Solaris, alongside a generic X11 port and the original DOS VGA port. 45 Solaris is generally considered more widely supported, more recent, and more feature-rich than IRIX, though IRIX is regarded as cleaner, better documented, and more user-friendly. 46474849 Both systems install X11 by default and boot into it when compatible graphics hardware and a display are connected, with Solaris offering more installer assistance than IRIX. 5051 Solaris and IRIX both lack terminal emulators, and both exhibit demo limitations such as horizontal lines in renders. 5253 IRIX has a distinct internal structure with its own scheduler, showing closer similarities to Solaris than to GNU/Linux. 54 Solaris included developer tools and libraries in the base system, whereas IRIX required additional software such as IDO. 55 All major Unix workstations, including Solaris and IRIX, were 64-bit capable by 1999, unlike PCs and Macs. 56

With O2

With GCC

GCC ports for IRIX allow setting the compiler version in the port script, with 4.7.4 as the default and 8.2.0 also available. 95 GCC 4.7.4 officially supports IRIX and is considered a good choice for compiling X applications. 96 The last version of GCC supporting IRIX is between gcc 3.x and very early 4.x. 97 GCC dropped 5.3 support before 6.x support, affecting IRIX compatibility. 98 The GCC 9.2 and 14.2 patches for IRIX have been rebased. 99 GCC on IRIX uses libstdc++ from the compiler rather than the system version. 100 IRIX executables built with GCC may or may not link against libgcc depending on the code. 101 The build script for GCC on IRIX requires specific flags and sysroot setup to compile C++ programs, including handling of __restrict and linking against crt1.o and libstdc++. 102

With Windows

Windows can run on IRIX systems through SoftWindows, which performs comparably to the host system, and IRIX can also be installed from Windows using the LOVE tool after editing the LABELS.WIN.TXT file and setting network settings. 112113 X11 works between IRIX and Windows with an X11 server on Windows, allowing clients such as smirc to run on IRIX while drawing on Windows. 114115 haneWIN NFS for Windows works with IRIX, and Synergy allows a Windows keyboard and mouse to treat an IRIX computer as an extension of the desktop over the network. 116117 Alias Studio tools were available on multiple platforms including Windows and IRIX, while some software such as Mirai 1.1 exists for Windows but not IRIX. 118119 IRIX influences how users interact with other operating systems, such as right-clicking the title bar to close windows and double-clicking on the blank spot of the file browser to go back in Windows. 120

With Indy

The SGI Indy is a low-end machine whose base RAM requirements were raised because a new release of IRIX would not run on the original minimum configuration. 121122 The Indy's R5K processor runs IRIX, and it can run IRIX 5.3 at 400 MHz, though newer versions may crash. 123124 Emulators such as QEMU can run an older version of IRIX on an emulated Indy, and an IRIX install can also be booted on an SGI Indy using a modern *NIX. 125126 Installing IRIX on the Indy can be automated, and it requires running a command in the boot PROM before installation. 127128 The Indy is slow at building packages on IRIX, and IRIX was not designed with corner-cutting in mind, so its base requirements were already challenging at the Indy's price point. 129130

With MAME

MAME provides support for IRIX emulation, though it is imperfect and 2D only, emulating only an R4k Indy and some version of a Personal IRIS 4D/25. 131132 MAME is considered the best emulator for IRIX, but performance is limited, running at about 1/3 speed and being less accurate than QEMU. 133134135 The MAME indy target is currently the only way to emulate IRIX, though it runs at about 1/3 speed and may not be great for development purposes. 134 Disabling CPU overclock in MAME can improve IRIX emulation performance. 136 The files needed for emulating IRIX on MAME can be found linked from a Pinned post on the IRIXNet wiki. 137 Firefox and Netsurf run on IRIX via MAME emulation, though with known issues. 138

With NFS

NFS is required on IRIX for tasks that cannot mount ISOs directly, and it works better than FTP or USB mass storage for file transfer needs. 139140141 NFS works fine on SGI systems from version 6.5.22, and IRIX installs the FTP server with ONCS NFS. 142143 NFS can fail on IRIX when updated by RH, requiring a proxy server, and older IRIX NFS does not work on TruNAS Scale. 144145 NFS reads larger than 8KB crash the IRIX kernel, but setting wsize and rsize to 1024 fixes it, and IRIX has a file size limit on NFS that may require the largefiles option, which may have its own limits. 146147 NFS requires the directory to be readable by the user that the UID on the IRIX machine maps to on the RHEL machine. 148 NFS can mount an IRIX machine's homedir, but X11 integration with older SGI X-server is challenging, and the IRIX system can be accessed via telnet with NFS shares mounted. 149150 To install software on IRIX, mount ISO images as virtual CD-ROMs and use rsync to copy files, then share the destination directory over NFS for installation, and network install of IRIX on an SGI Indigo 2 is possible using NFS. 151152 Setting up NFS between IRIX and Windows requires Windows Enterprise or Professional edition, and is cumbersome. 153

With PROM

The PROM provides limited hardware support, often just enough to detect, configure, and install IRIX, and booting IRIX from the PROM is slow and unusable. 168169 To boot IRIX, type 'boot' from the PROM, and from SASH use 'ls' to list disk contents. 170 The PROM's HINV might report differently in IRIX, and 'hinv' should show the graphics device at least at the PROM level, though 'hinv -c graphics' may show no graphics devices in IRIX. 171172173 There is a way to force the flash of the PROM from within IRIX, but there is a danger to doing this, as you could brick your system. 174 The root password for IRIX is separate from the PROM password. 175 Networking setup in IRIX involves editing many text files, and even then, basic networking requires setting a hostname and understanding PROM. 176

With Indigo2

With FTP

IRIX runs several outdated and insecure services by default, including telnet and ftp, and FTP is installed by default on IRIX. 186187 IRIX can establish FTP connections between different systems, and the ftp client in IRIX is 'ftp'; it works in the console and can be used with Netscape for a visual view. 188189 The `ftp` command is part of the stock functionality on IRIX, and the man page for the IRIX `ftp` command is available at https://nixdoc.net/man-pages/IRIX/man1/ftp.1.html. 190191 FTP on IRIX can be set up using a guide from a Linux box, logging in and downloading files, and FTP on IRIX IRIS does not support passive mode. 192193

With Firewire
