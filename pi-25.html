PI 25

Claims: 4 Part of PI

MAME can run Irix 4 through Indigo2 emulation or PI/25 emulation, possibly only in terminal mode, and should run at full speed or faster for the PI/25. 1 The PI 25 has SCSI errors when installing Irix 3.2, which do not occur with the Professional Iris, and the IRIX 3.3.2 kernel has SCSI issues with the PI 25 in MAME, likely due to unemulated SCSI commands/functions required by IRIX 3.3.2 but not IRIX 4. 23 The 'strobe' tests fail in MAME for the Eclipse graphics in the PI/25, with expected and actual values differing by 4 bytes. 4

Sources

  2. IRIX 3.3.2 kernel has SCSI issues with PI 25 in MAME, likely due to unemulated SCSI commands/functions required by IRIX 3.3.2 but not IRIX 4. (user-ce6b, 2023-07-18, exchange 208962, check: supported)
  3. The PI 25 has SCSI errors when installing Irix 3.2, which do not occur with the Professional Iris. (user-ce6b, 2024-03-27, exchange 93359, check: supported)
  4. The 'strobe' tests fail in MAME for the Eclipse graphics in the PI/25, with expected and actual values differing by 4 bytes. (user-ce6b, 2025-11-01, exchange 220379, check: supported)
