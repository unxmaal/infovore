MIPSpro 7.4

Claims: 10 Part of MIPSpro

MIPSpro 7.4 was the last version of MIPSpro. 1 It requires the IRIX Development Foundation 1.3, and installing additional development foundation and libraries packages is recommended when using MIPSpro 7.4. 23 For older IRIX 6.5, MIPSpro 7.4 requires 812-0924-002: Compiler Execution Environment 7.4, whose CD contains runtime libraries for the MIPSpro 7.4 compilers on IRIX 6.5.x systems, including dist_modules for modules installation and notes on compatibility with IRIX 6.5.19. 45 MIPSpro 7.4 requires a license key to compile, and newer versions refuse to compile without it. 6 It is incompatible with GNU tools in the path. 7
