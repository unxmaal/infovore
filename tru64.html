Tru64

Claims: 69 Background: 2 claims already covered by Wikipedia, see Tru64 UNIX.

Tru64 is a Unix variant available on Alpha systems, where it is the preferred operating system, and it is one of several names for the same operating system alongside OSF/1 and Digital UNIX. 123 Tru64 runs on the DEC Multia, which was intended to run Alpha Windows NT or Tru64 rather than VMS, and the Multia runs Tru64 perfectly with a compatible version. 4567 Tru64 can also run on other Alpha machines, which may boot VMS or Tru64, and some DEC/Compaq Unix workstations use ARC in the BIOS, flipping between ARC and BIOS for Tru64 or NT. 89 Tru64 is Mach under the hood, with userland based on SVR4 and admin tools and package/licensing systems from Ultrix. 10 Tru64 supports the ADFS advanced file system, DEC GPUs and Radeon 7500, and the 4D60T graphics card, which may come with the system-supplied X server. 111213 Tru64 has software including Opengenera, and it can run Genera, with obtaining an Alpha being easier than a real Lisp machine. 1415 Tru64 has a GCC build available for development, and its compilers are available. 1617 Tru64 can be obtained from tenox.pdp-11.ru or winworldpc, and it is available on archive.org alongside Ultrix, OSF/1, and Digital UNIX. 1819 Tru64 is a DEC operating system that runs on AlphaServers, PWS machines, and other hardware such as the DS15, es40, PC164 mainboard, and G3. 202122232425 Tru64 can be installed from a CD or from the network using DEC's remote installation services (ris). 2627 Tru64 can coexist with OpenVMS and NT on the same hardware, though it cannot coexist with Windows 2000 on a single PWS machine. 252829 Tru64 is available at specific URLs for patches, software, and media, and 5.1B-6 was the last version, beyond which there were only patch sets. 3031 Genera runs on top of Tru64, while Open Genera runs on old OSF systems but not Tru64. 3233
