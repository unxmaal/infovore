SDL2

Claims: 53 Background: 2 claims already covered by Wikipedia, see Simple DirectMedia Layer.

SDL2 is a library that adds accelerated 2D rendering and handles audio, and it is used for sound and controls in sm64ex. 123 SDL2 is available from nekoware and SGUG RSE, repositories of software for IRIX, and there is a nekoware port for IRIX. 456 SDL2 can be made to work on IRIX with a bit of work, possibly involving adding back IRIX-specific details like dynamic library loading, and requires aconf/config hacking to support IRIX as a target. 78 The makefile for SDL2 in nekoware may require OS type detection for IRIX, and adding IRIX support could be simple or challenging, depending on the existing code. 9 There is work in progress on an SDL2 port, but it is not ready yet, and the SDL2 patches are merged to the wipnonautomated branch, but are not yet available in a usable form. 1011 SDL2 can be compiled manually but faced circular dependency issues, and recompiling SDL2 with the unsetenv fix can encounter a strings.h error. 1213 A patch for SDL2 can cause an O2 to reboot, and SpaceCadetPinball compiled on IRIX with SDL2 but segfaults due to missing RANDR extension. 1415 The SDL2 implementation in user-42cf's setup is more stable and allows changing display settings without shutting down the game. 16 The SDL2 package is available in the online repo and can be installed via tdnf, with version 2.0.12 mentioned. 17 The SGUG-RSE SDL2 version is 2.0.12 with patches and builds without errors with --enable-video-opengl. 18 The SDL2 package may require the khrplatform patch, which is part of a mesa GL package. 19 The SGUG-RSE SDL2 does not support GL, so games such as wipEout and Homeworld require compiling your own SDL2 with GL enabled. 202122 A test GL app works with SDL2 when compiled with the specified X11 linking changes, and the drmadison SDL2 rpm with working GL support is functional. 2324 SDL2 should not pass invalid attributes to XCreateWindow, which can cause a BadMatch error, and the build system uses pkg-config so editing SDL2's .pc file and setting flags according to the test program's proper flags could help. 2526 Chocolate Doom uses SDL2 with GL for blitting but can still be pixellated, and the SGI port offers a point-and-click install. 2728 In SDL2, the keyboard works without adjustment on an O2. 29
