machine type

Claims: 3 Part of machine

The hostid and machine type are written using 'c!' commands at specific addresses, with the ethernet address written to subsequent addresses. 1 The first two numbers indicate the machine type, and the hostid and MAC address are often noted on the NVRAM chip for newer machines. 2 The hostid and Ethernet address can be reprogrammed, and the machine type may need to be set to avoid various problems, which may require programming a MAC address and hostid. 32
