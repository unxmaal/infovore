Ghostscript

Claims: 11

Ghostscript is an interpreter that defines its own data types, including packed and unpacked references to avoid unaligned memory accesses which can cause bus errors. 1 Adobe PostScript fonts were better than the ones provided by Ghostscript. 2 SGI replaced PostScript with Ghostscript in IRIX 6.5.30, breaking Photoshop compatibility. 3 Photoshop requires an earlier version of PostScript, which was removed in IRIX 6.5.x and replaced with Ghostscript, causing compatibility issues. 4 Adobe Illustrator requires PostScript support, available on IRIX 6.5.22 discs, to function properly; later versions use Ghostscript which can break compatibility. 5 The PostScript vs Ghostscript choice breaks Adobe software. 6
