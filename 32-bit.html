32-bit

Claims: 19 Background: 1 claim already covered by Wikipedia, see Windows NT.

On IRIX 4, time_t, const long, and int are 32-bit, and the system date will wrap back to 1/1/70 in 2038. 1 IRIX 4 is 32-bit only and predates 64-bit designs. 2 The O2's _MIPS_SZLONG is 32, explaining issues with 64-bit integers. 3 The latest draft of the CPU is a 32-bit RISC-V based processor running at 128 MHz with 16 MB of RAM, 8 MB of EPROM, IDE support, a video output resolution of 640x480, and PS/2 for keyboard. 4 The SS20 is 32-bit, and the O2 is a 32-bit machine while the R10K is a 64-bit CPU. 56 Windows NT on Alpha is 32-bit. 7 There are 32-bit PCI-X cards. 8 The WDC W65C832 is a 32-bit microprocessor compatible with 6500-series predecessors, offering pin-to-pin compatibility with 16-bit devices and software switchable 8-bit, 16-bit, or native 32-bit modes. 9
