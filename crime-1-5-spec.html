CRIME 1.5 spec

Claims: 3 Part of CRIME

The CRIME 1.5 spec reserves an entire gigabyte of address space. 1 It limits SGI modules to 128MB per module. 2 A leaked version of the CRIME 1.5 spec sets 1GB as the memory limit, though this may be preliminary. 3

Sources

  3. 1GB is the limit for memory according to leaked CRIME 1.5 spec, which may be preliminary. (user-757f, 2026-02-18, exchange 226106, check: supported)
