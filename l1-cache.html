L1 cache

Claims: 15 Part of L1

The IP17 CPU contains 64 KB of L1 cache and 1 MB of L2 cache, with the L2 cache composed of 8 128K x 8bit SRAMs and 2 16K x 4bit SRAMs per bank, while 'hinv' reports 64 KB of cache because the L1 cache is not included. 1 The Dallas chip on the PCI board is for the L1 cache. 2 The L1 cache never comes up if the Dallas chip is dead, and if the NVRAM is not written to, the L1 cache may not come up. 34 A flat Dallas chip prevents L1 cache, but power cycling can make it work, and the PSU requires multiple power cycles to start the L1 cache. 56 The system needs to be powered up, down, and up again for the L1 cache to start. 7 If the L1 cache comes up, it will have no NVRAM settings and will report as a ---c---. 8 A bad PSU can cause I2C issues severe enough to affect L1 cache functionality; this can be debugged by checking PSU and env chips; fixes may involve replacement. 9 The Altix 350 can overheat if the L1 cache is running without fans. 10
