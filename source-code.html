source code

Claims: 14

Some old tools and programs may have lost their source code, and some individuals have destroyed source code tapes on advice. 12 Partial IRIX source code is available on GitHub, though the ip32PROM code in the leaked IRIX source code is incomplete, missing common definitions and rules. 34 SGI does not have the rights to distribute the source code due to third-party code, and the available version lacks some released apps such as the motif file manager and motif preferences app. 5 The source code is available on GitHub and includes changes to make it compile, but packaging for SGI systems using tardist or RPM is challenging. 6 Viewperf 6.1 for Windows 95 is available as a Windows 95 binary and source code for IRIX, though datasets are not included in the IRIX source package and must be extracted from the Windows version. 7 The source code for GL / Inventor demos is on the CDs. 8 The save/load menu in SM64 has source code available on GitHub, and there are about 6-7 games with available source code, at least two of which can be recompiled into working cart images. 910 Custom tools can be used to decompile to source code and then QEMU can be used to verify that it recompiles to an identical binary. 11
