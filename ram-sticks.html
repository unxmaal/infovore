RAM sticks

Claims: 8 Part of RAM

To isolate a faulty component, reseat the CPU module and try different pairs of matching RAM sticks in the first two banks, comparing memory errors to identify the problematic part. 1 The Indy may refuse to boot with certain RAM sticks due to dirty contacts, and reseating can resolve the issue. 2 The O2 requires RAM sticks to be in pairs and can be unstable, requiring multiple reseats of the CPU module or RAM sticks to start working again. 34 Dual RAM sticks from different SCSI RAID cards can be used for IRIX. 5 Some RAM sticks have yellow and purple markings, an R5000PC CPU, and a Phobos G100 card. 6 The O350 brick uses 1GB RAM sticks. 7 SDZ reverse-engineered the RAM sticks for the Indigo1. 8
