chkconfig

Claims: 5

chkconfig is a command-line tool used to list the current state of daemons and to start them. 1 It can be used to manage NFS services, and there are instructions for enabling the NFS client on Windows 10. 2 On IRIX, chkconfig flags work similarly to Linux; they can be checked with /sbin/chkconfig and set with chkconfig -f, and IS_ON is a variable used in scripts to check flags. 3 To check if DHCP is configured to start automatically on the O2, use 'chkconfig | grep autoconfig'; for Ethernet link issues, check /var/adm/SYSLOG for 'no carrier' messages after unplugging the cable. 4 To enable or disable specific services using chkconfig, one needs to create a service script in /etc/init.d and a symlink in /etc/rc2.d with the S99 prefix, and a config file in /var/config with 'on' or 'off'. 5
