m4

Claims: 3

m4 is used as a configuration tool by ctwm, allowing different settings based on window size and host name, along with loading different key bindings. 1 Early versions of IRIX might have used m4, along with flex or yacc, to convert BASIC to C before compiling. 2 To compile growisofs, one may need to generate a makefile with m4, add specific flags, and compile manually. 3

Sources

  1. `ctwm` can use M4 for configuration, allowing different settings based on window size and host name. It can load different key bindings and has been slightly patched for specific font usage on workspace buttons. (user-42cf, 2025-04-29, exchange 216236, check: supported)
  2. Early versions of IRIX might have used m4, flex, or yacc to convert BASIC to C before compiling. (user-c831, 2025-05-26, exchange 212537, check: uncheckable)
  3. To compile growisofs, one may need to generate a makefile with `m4`, add specific flags, and compile manually. (user-f190, 2026-02-06, exchange 73097, check: supported)
