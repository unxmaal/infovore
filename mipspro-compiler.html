MIPSpro compiler

Claims: 14 Part of MIPSpro Background: 2 claims already covered by Wikipedia, see IRIX, SGI O2.

The compiler has multiple optimizer bugs and crashes (segfaults) on certain C99 constructs, such as in-place defined linked lists, which can be worked around by defining inner parts separately before the problematic scope. 12 It works best with -O1 optimization, as higher levels can cause issues. 3 It can be used to compile MIPS assembly, and a version that works with IRIX 5.3 is needed for this purpose. 4 The MIPSpro compiler for IRIX 6.5.30 can be installed manually to avoid conflicts by skipping certain steps and checking specific patches, and Hello World works with C and C++ but demos require further configuration. 5 It is not compatible with all tools, as gmake produces a 'missing separator' error when used with it, and openjpeg 2.3.0 has a 9% test suite pass rate with the MIPSpro compiler but a 99% pass rate with GCC. 67
