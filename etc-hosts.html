/etc/hosts

Claims: 12

On IRIX systems, /etc/hosts is a file that must be correctly configured with the machine's IP and hostname, alongside /etc/sys_id, to establish network access and avoid losing networking when the system name is changed. 123 On HP-UX, /etc/hosts is a directory rather than a file, and it may contain junk that resolves the hostname to an invalid IP address, which can prevent CDE from starting on HP-UX 11.31. 45 On Solaris, adding an entry for the hostname in /etc/hosts, along with setting up DNS, can resolve hostname errors. 6 For network booting, the Ethernet address and corresponding hostname must be added to /etc/ethers and /etc/hosts, respectively, as with the Sun E450. 7 The hostname should have an entry in /etc/hosts to resolve object server issues, with /etc/resolv.d configured to prioritize /etc/hosts for resolution order. 8 Network connections in /etc/hosts can be edited using vi. 9
