Softimage 3.7

Claims: 8 Part of Softimage

Softimage 3.7 is an application dated in 1998 that uses COFF. 12 It can run on IRIX 6.5 with a valid license, on the O2, and may work with Irix 5.3 on an EFS volume. 345 It also works on an emulated Indy with IRIX 5.3 and an EFS filesystem using a FlexLM installation. 6 Setting the custom license path is necessary even if the license file is at the default location on IRIX 5.3. 7 The installer may error with an unexpected parenthesis message on the first line. 8
