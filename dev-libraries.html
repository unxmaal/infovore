Dev Libraries

Claims: 3

Tools existed for creating a tardist with selectable install sections for the main install, manpages, dev libraries, source, etc., and the build version could be iterated, showing up as an update for a previous install. 1 To compile C, you need MipsPRO C Compiler 7.4, Dev Foundation 1.3 (2002), and Dev Libraries 2002. 2 Install Mips PRO, Dev Foundation 1.3, and Dev Libraries 2002 in that order. 3
