Alias 3

Claims: 18 Part of Alias

Alias3 and Softimage are important software for CGI, used in movies like Jurassic Park and South Park. 1 Alias3 and Alias6 are IRIX 5.3 only, with Alias 3 being COFF only and requiring a system running at most IRIX 5.3. 23 Alias 3 is PowerAnimator 4, runs COFF binaries compatible with IRIX 5.3, requires pre-impact graphics, and does not work with later IRIX versions. 4 Alias 3 is primarily a curve modeler with limited polygon modeling tools. 5 Alias 3 runs on a Personal Iris or possibly an Indigo, depending on the latest version of IRIX supported, and the R4400 CPU in an Indigo2 can run Alias3, which is not available on R10K Solid Impact. 67 Alias3 had little publicly available documentation or training materials. 8
