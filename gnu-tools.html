GNU tools

Claims: 6 Part of GNU

The .gnu.attributes section in executables is recognized by newer GNU tools but not by IRIX tools, causing crashes. 1 GNU tools can be used to compile IRIX code, for example by using a Linux VM. 2 The GNU tools' approach of requiring sudo and special handling of the root directory can be seen as making users bow and scrape before the computer. 3 Some tests were cross-compiled with GNU tools on GNU/Linux. 4 There is a specific invocation required to get OpenGL packages built with the GNU tools in RSE to link with OpenGL properly. 5 The alignment warnings are a known linker bug with GNU tools, and the last error requires special linker flags for compiling OpenGL code. 6
