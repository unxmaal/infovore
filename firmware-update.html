firmware update

Claims: 9 Part of firmware

The Dell PowerEdge PSU firmware update can brick the system, rendering it worthless except for some components. 1 The firmware update can fail if the version does not match the device hardware, requiring a force install. 2 The firmware update for the T1000 may not change the warning and low fan rpm thresholds from 2240 and 1920 rpm due to a known issue with SP passing incorrect minspeed values for tachometers. 3 The O2 can be modified to run a 600 MHz CPU with a firmware update, which involves burning a specific PROM image. 4 The firmware update and extended fuse change enable automatic reset and brown-out detection on the microcontroller, and these changes can be applied using avrdude with the appropriate parameters. 5
