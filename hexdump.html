hexdump

Claims: 7

The `efs` module is used to loopback mount archive files; it has an ELF header at offset 0x200 and can be analyzed with `file`, `hexdump`, and `readelf` commands. 1 hexdump can be used to display the binary format of executable files. 2 The newer version of hexdump can be found on GitHub. 3 IRIX lacks a built-in hexdump; one can compile hexedit from GitHub. 4 IRIX can use 'od -x' as an alternative to hexdump. 5 'od' dumps in octal; use '-x' for hex words, but offsets remain octal; hexdump dumps in hex bytes, requiring byteswap on non-native platforms. 6 The hexdump command on IRIX lacks the -v option, but the output difference compared to Linux is the same. 7
