Red Hat 7.2

Claims: 4 Part of Red Hat

Red Hat 7.2 was not officially released for the Alpha architecture. 1 The AlphaPC 164SX can run Red Hat 7.2 using an external SCSI CD-ROM, but not an IDE one initially, requiring text mode installation and working with the TGA graphics card after installation. 2 Tru64 support was added, allowing Red Hat 7.2 to work and fixing timer issues, while SCSI flaws were also addressed. 3 Lilo can be difficult to use, especially for running L3 software on Red Hat 7.2. 4
