IrisVision

Claims: 25 Background: 3 claims already covered by Wikipedia, see IrisVision, IRIS GL.

The IrisVision is a 3D viewing program that comes with the PC/MCA GL set and had two versions, one of which is an ISA card for the O2. 123 The IrisVision hardware uses HQ1 chips for instruction fetching and Weitek 32-bit floating point data paths, but lacks hardware support for certain high-end IrisGL features such as texture mapping, alpha blending, accumulation, and stencil buffers. 45 The Raster Video card is one half of the IrisVision, an 8-bit frame buffer card that, when paired with a 24-bit buffer, forms a type 5 microchannel adapter, with all desktop PS/2s able to fit only the 8-bit version while servers can use the 24-bit boards. 67 The MCA version of the IrisVision was designed to run in both IBM RS/6000 and IBM PS/2 computers, requires a 32-bit MCA slot with a higher watt power supply for array models, and needs an FDDI EISA card. 8910 The IrisVision is not OpenGL capable, has drivers for AutoCAD, and can run from IRIX 4.x to 6.5.22 as a demo. 111213 The MCA version has limited software support, especially for DOS applications, and IrisVision is supported in AIX 3.2 but was dropped in AIX 4. 1415
