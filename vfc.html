vfc

Claims: 13

The `vfc` command is part of the vfc package, which is included in the IRIX distribution but not installed by default. 12345 It is available on the foundation CDs and the applications disc for IRIX 6.4, but not on the IRIX 6.5.30 Overlays. 24 The `vfc` program sets flags passed to `cpp` and can be used to create custom .sdb files for IMPACT graphics by setting specific pre-compiler options. 16 It can build VFOs, but cannot do so if the pixel clock exceeds a predefined limit. 75 The VFC can achieve a 1280x1024 resolution at 85Hz, provided the pixel clock does not exceed 144MHz, and can likely support 4k resolution. 89 The VFC documentation describes user-defined variables and explains that blanking, though not visible, is necessary for compatibility with CRT displays, consuming up to 25% of a video frame. 10

Sources

  1. The `vfc` command can be used to set flags that are passed to `cpp`. (user-42cf, 2019-03-01, exchange 833, check: supported)
  2. VFC is on the IRIX install media but not installed by default; it requires both the 6.5.x overlay and the foundation CDs. (user-6afa, 2022-04-30, exchange 217577, check: supported)
  3. vfc is not installed by default on SGI machines; it can be found on foundation discs but is not included by default. (user-e4d0, 2024-05-30, exchange 111420, check: uncheckable)
  4. The `vfc` program is part of the vfc package and is not installed by default on IRIX 6.5.30 Overlays; it is available on the applications disc for IRIX 6.4. (user-6c80, 2024-06-06, exchange 218437, check: supported)
  5. The tool 'vfc' for creating VFO files is included in the IRIX distribution. (user-ae4b, 2025-05-23, exchange 225107, check: uncheckable)
  6. To create a custom .sdb file for IMPACT graphics using VFC, one must set specific pre-compiler options. (user-bba0, 2024-06-13, exchange 46848, check: uncheckable)
  7. The vfc cannot build VFOs if the pixel clock exceeds a predefined limit. (user-42cf, 2021-12-27, exchange 215274, check: uncheckable)
  8. The VFC can achieve a 1280x1024 resolution at 85Hz, but the pixel clock must not exceed 144MHz; otherwise, porch issues may occur. (user-5fa2, 2020-09-09, exchange 10937, check: supported)
  9. The VFC can likely support 4k resolution; a user connected two singlelink DVIs from an IBM T221 to achieve 2160p on a DCD. (user-22f9, 2025-02-17, exchange 54387, check: supported)
  10. The VFC documentation describes user-defined variables and explains that blanking, though not visible, is necessary for compatibility with CRT displays, consuming up to 25% of a video frame. (user-42cf, 2025-04-15, exchange 116088, check: supported)
