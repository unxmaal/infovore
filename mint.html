Mint

Claims: 17 Background: 2 claims already covered by Wikipedia, see Amiga, Ubuntu.

MiNT is a Unix-like operating system for Atari systems that provides modern hardware support, a point-and-click GUI capable of running Atari programs, and is somewhat compatible with both UNIX and TOS. 12 It runs on Atari systems such as the Atari TT and is a preemptive version of TOS for Atari STs. 34 MiNT is still being developed and is a stable OS with available patches for old versions. 52 Software support is recommended for RAM upgrades on STs, and MiNT is recommended for such configurations. 6 Accelerating an Amiga allows running MiNT and Linux, which is useful for development and running certain software. 7
