zerovm

Claims: 3

Aurxenon's project aims to make a version of GCC 13 for IRIX as a prerequisite for a zerovm. 1 The plan involves making a GCC 13 for IRIX as a prerequisite for a zerovm to run OpenJDK 8, which requires modifications to OpenJDK 8's non-java portions, all C++ 03 and c99, on MIPSPro. 2 A gcc fork with readded old/nonexistent targets like sparcv9/x86_64-sun-solaris2.10 and alpha-unknown-elf can be used for cross compiling ZeroVM. 3
