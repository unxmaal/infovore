OpenSSH

Claims: 29 Background: 5 claims already covered by Wikipedia, see OpenSSH.

OpenSSH is available for IRIX through several sources, including the SGI freeware distribution, Nekoware, and SGUG-RSE, and is also included in the didbs package set. 1234 The IRIX version of OpenSSH is statically compiled for mips3, has no dependencies, installs to /usr/nekoware by default, and works on older machines. 567 OpenSSH works on IRIX 6.5 systems, and basic SSH features can be installed from SGI Freeware, Nekoware, or SGUG-RSE. 84 The RSE version of OpenSSH does not include init scripts, and SGUG's openssh also lacks startup scripts. 91011 OpenSSH no longer fully supports ancient Unix systems, and there are no modern openssh packages in .tardist format. 1213
