wget

Claims: 26 Background: 6 claims already covered by Wikipedia, see Wget, Pkgsrc.

wget is available on IRIX for downloading files, and packages including wget are hosted by user-42cf, which also provides standalone applications and static binaries for IRIX such as openssh. 12 wget can be installed through pkgsrc, which will use the wget in your PATH whether installed with pkgsrc or built externally, and pkgsrc may offer configuration overrides or be set to use an external dependency for wget. 3456 wget requires Perl to build its manpage and test suite, and GNU tar and wget are necessary for the didbs installation process. 78 wget and git do not compile on macOS Leopard, and compiling wget on the SPARCClassic takes a long time. 910 wget can use the --no-check-certificate or -k option to bypass SSL checks, and updating wget to the latest version fixes a bug where it sends a truncated Host header, which gets denied. 1112 dillo uses its own HTTP library implementation and wget is not a dependency, with curl being more commonly used for HTTP libraries. 13
