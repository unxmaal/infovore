jumper

Claims: 25

The Q950 can run A/UX and has a key just to turn it on; its SCSI HDD self-terminates if the jumper is not set correctly. 1 The O2 has a power-on issue that requires setting an always-on jumper and may benefit from a firmware patch, though the latter is uncertain. 2 The system password can be cleared either with a jumper or by removing the clock battery, and a jumper on the board can also be used to set the system password. 34 The jumper near the memory banks, not the one in front, is used to clear the PROM and may affect power-on. 5 The CPMS jumper, when plugged in, prevents the power supply units from powering up unless the UPS is active; disconnecting the jumper allows the system to power up directly from the PSU. 6 Setting the 512 byte block issue on DVD drives can be done with a jumper. 7 The 'Motor start' jumper controls disk spin-up timing, defaulting to spin-up on command. 'Spindle Sync' is disabled by default unless a jumper enables it. 8 Unplugging the jumper fixed the issue. 9
