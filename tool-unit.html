TOOL unit

Claims: 3 Part of tool

The TOOL unit contains an x86 single-board computer and a PCI card that can run PS2 software for debugging. 1 Retail PS2 ROMs will not work in the TOOL unit. 2 The TOOL unit can be used standalone from a host x86 machine running the PS2 SDK, requiring a working IDE drive with Red Hat Linux and a debugging/management suite installed. 3
