qemu-irix

Claims: 22

QEMU-IRIX is a binary-level virtualization layer that emulates the MIPS r4k CPU by binary translation and translates IRIX system calls to Linux system calls, allowing individual IRIX binaries to run but not a full system. 1234 It does not fully emulate SGI hardware, emulating running things in IRIX rather than an SGI machine. 56 It is headless and cannot access hardware directly, though it can talk to a remote X server and run some X11 programs, but not all hardware-accelerated graphics. 789 It supports building 32-bit MIPS binaries using the n32 ABI and does not automatically enable 64-bit mode with -march. 10 Its compatibility is not great and requires an IRIX rootfs, and it works on WSL, allowing IRIX binary execution on a gaming PC. 1112 It is designed for running user space applications that don't touch the hardware, specifically for IDO, the IRIX 5.3 compiler, and is better for running command-line binaries quickly. 1314
