XRANDR

Claims: 4

XRANDR is a command rather than a library, so installing the library does not install the command. 1 In later versions, xrandr extends basic multi-screen functionality to include screen positioning and allows combining screens into a virtual display. 2 X does not support XRANDR, but xorg client libs have fallbacks. 3 When GTK moved to local font rendering and XRANDR, it broke a whole bunch of stuff, whereas remote X on an SGI was no problem. 4
