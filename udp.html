UDP

Claims: 9 Background: 1 claim already covered by Wikipedia, see Network File System.

UDP is used by StarCraft for online play on port 6112, alongside TCP/IP. 1 NFS typically uses TCP by default but can use UDP, and NFSv3 and older versions use dynamic ports. 2 NFSv3 only works on UDP, which is turned off by default in many Linux distributions including RHEL. 3 To use old-style NFS over UDP, configure the Linux NFS server with options like rw, sync, no_root_squash, and no_subtree_check, then restart the NFS service. 4 TCP is generally slower for NFS, though it may have had issues with UDP in the past. 5 The PikVM sends a UDP stream of pointer data to the SGI machine to move the mouse. 6 The PelOrion rendering engine can switch the WanXL card to UDP for data input, and the PelOrion card can be used via deframer and UDP or the fire_str command. 78

  6. The PikVM sends a UDP stream of pointer data to the SGI machine, which then moves the mouse. (user-1171, 2026-08-03, exchange 124586, check: uncheckable)

  8. To use the PelOrion card, you can either use deframer and UDP or the fire_str command, which involves database-style calls. (user-9305, 2026-08-24, exchange 226921, check: uncheckable)
