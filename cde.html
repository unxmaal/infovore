CDE

Claims: 76 Background: 8 claims already covered by Wikipedia, see Common Desktop Environment, FreeBSD, Oracle Solaris.

CDE is a desktop environment that runs on a wide range of Unix-like systems, including Solaris, HP-UX, AIX, IRIX, FreeBSD, OpenBSD, and OpenVMS (the latter via Remote OpenVMSAnywhere). 123456789 CDE was widely used, though it was not available on SGI systems and was considered a regression relative to Sun's later Java Desktop. 10311 CDE has been packaged by Red Hat and is available through package managers such as FreeBSD's pkg. 212 CDE features configurable keybindings, but it lacks a task manager or task bar, requiring users to iconify and reopen applications. 1314 CDE action icons are 16-color XPM files that must be provided in three sizes: 48x48, 32x32, and 16x16. 15 To create CDE icons, images are downscaled to the required sizes, converted to 16 colors, and exported as XPM, with care needed to preserve transparency. 161718 CDE boots if the Xservers file lacks explicit depth and class settings, defaulting to an 8-bit desktop. 19 CDE is an open-source desktop environment that uses ROX-filer or pcmanfm as its file manager, and it is available for Linux. 2021 CDE can be built with Clang on FreeBSD and OpenBSD, with OpenBSD possibly distributing a recent build of Clang as a viable alternative to GCC. 222324 CDE runs on a range of platforms, including Solaris 10, Solaris 8, Solaris 9, Solaris 2.4, IRIX, OpenBSD, FreeBSD, and the Alpha and VAX series, though its performance varies by platform and software version. 2526272829303132333435 CDE is often considered clunky and is frequently replaced by alternatives such as WindowMaker, GNOME, XFCE, 4DWM, or OpenWindows. 36373831394041 CDE can be customized to minimize the bottom bar, use virtual desktops with middle-click, save the desktop layout by logging out, and open the same windows on login. 424344 Xlib documentation and tutorials for Motif and CDE are available online, and instructions for changing graphics resolution and colors can be found there as well. 4546
