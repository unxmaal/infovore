Graphics_SGI

Claims: 3

Graphics_SGI is a mod that can be removed from an Onyx3, though doing so may affect texture compatibility on systems with lower texture memory amounts and non-24-bit color; removal results in non-functional textures whether the mod is present or absent. 1 Graphics_SGI can serve as an example for fixing the GL1 file to handle pixel formats. 2 The mod converts BGRA to RGBA before passing the data to glTexImage2D. 3
