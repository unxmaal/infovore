Red Hat Linux

Claims: 10 Part of Red Hat Background: 2 claims already covered by Wikipedia, see Digital Equipment Corporation, SGI Altix.

Some versions of Red Hat Linux were used on SGI systems, including the Altix system, which runs on RedHat Linux. 12 The L3 controller software for SGI systems includes various RPMs for drivers and tools, and can be installed on an early RedHat Linux system. 3 L3 is a software package that runs under a few versions of Red Hat Linux old enough to be archaeological findings. 4 The L2 controller is part 013-4637-001, runs Red Hat Linux, lacks the L2 screen port, and is used with Altix systems rather than Origin. 5 RM7900 CPUs can run under Red Hat Linux and Wind River VXWorks. 6
