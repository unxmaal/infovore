binutils

Claims: 39

Binutils is a collection of utilities used for compilers, assemblers, linkers, and debuggers. It is designed to produce output for the target system by the cross-compiler. The package contains binaries such as addr2line, ar, as, c++filt, ld, nm, objcopy, objdump, ranlib, readelf, size, strings, and strip. 123 Binutils is built to produce output for the target system by the cross-compiler. It is designed to produce output for the target system by the cross-compiler. 2 GNU binutils did not work well on IRIX until around the time IRIX stopped being supported. Cross-compiling an IRIX environment requires an older version of binutils that can build on FreeBSD 10.x or earlier due to license issues with GPLv3. 45 Binaries built with newer binutils may produce attributes IRIX rld cannot handle, leading to stack corruption. The porting guide for IRIX software suggests using IRIX's ld because binutils doesn't support necessary ABIs. 67 Binutils should be used with the latest gcc8 build, not IRIX as or ld. They used the latest binutils to create working binaries. 89 Using newer GCC with old binutils can cause issues, as demonstrated by OpenBSD's experience. Issues with newer GCC and binutils often involve file format mismatches or unrecognized keywords. 1011 Binutils can cause issues with flags like -X, which AR may not recognize, even with official tools. The inconsistency in binary naming between binutils and GCC can cause issues in cross-compilation, as seen with CLisp. 1213 Building binutils with aCC and +DD64 on an IA-64 system results in errors due to misaligned access and integer conversion issues, and the build fails due to an #error directive about undetected architecture endianess. 14
