hinv command

Claims: 6 Part of hinv

The hinv command provides hardware inventory in the command monitor. 1 It can be used to check the presence of a drive, though a drive may not appear in current attempts. 23 The second head on an Octane can be enabled via the hinv command. 4 The command can also check CPU speed without removing the module, which is bolted to the mainboard and risks bending pins if taken out. 5
