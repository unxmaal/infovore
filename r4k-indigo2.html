R4K Indigo2

Claims: 7

The R4K Indigo2 ran IRIX and could run AutoCAD, with 200 and 250 MHz being common speeds for Impact configurations. 12 IRIX 6.5.13 runs slowly on an R4k Indigo2 even at 200MHz, and the R4k Indigo2 is slower than an IP22 running IRIX 5.3. 34 A user's R4K Indigo2 had a non-working 4GB HDD that was 'resurrected' into a zombie HDD, allowing it to boot to IRIX 5.3 and run MRI software, but it eventually broke again. 5 Using a disk from an R4K Indigo2 in an R10K Indigo2 won't work and won't be detected, while bluescsi v2 works on r4k Indigo2. 67

Sources

  1. AutoCAD existed for IRIX and could run on R4K Indigo2's and the like. (user-b7c4, 2019-10-31, exchange 4058, check: supported)
  2. Impact was a regular option for R4K Indigo2s; 200 and 250 MHz are common speeds. (user-03ad, 2025-04-12, exchange 116055, check: supported)
  3. IRIX 6.5.13 runs slowly on an R4k Indigo2 even at 200MHz. (user-56d4, 2023-01-09, exchange 222784, check: supported)
  4. The R4k Indigo2 is slower than an IP22 running IRIX 5.3. (user-24f0, 2024-06-30, exchange 47304, check: supported)
  5. The user's R4K Indigo2 has a non-working 4GB HDD that was 'resurrected' into a zombie HDD, allowing it to boot to IRIX 5.3 and run MRI software, but eventually broke again. The user backed up the entire disk to a PC and, (user-b57f, 2023-04-28, exchange 218014, check: supported)
  6. Using a disk from an R4K Indigo2 in an R10K Indigo2 won't work and won't be detected. (user-86e1, 2024-02-21, exchange 110413, check: supported)
  7. bluescsi v2 works on r12k O2 and r4k Indigo2; requires a clock-delay option on O2 to avoid write errors, which may have been fixed. (user-17cb, 2025-05-17, exchange 56611, check: supported)
