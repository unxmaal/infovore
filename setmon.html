setmon

Claims: 12

setmon is a command to configure monitor settings, and it is included in the eoe package. 12 The setmon man page details board types for SGI systems, especially for RealityEngine and InfiniteReality graphics. 3 To change the monitor resolution on IRIX, use 'setmon -x new_res' followed by 'stopgrfx; startgrfx' to apply the change, or use 'setmon -x' to set the display mode interactively without changing the default. 45 setmon may not persist across reboots in IRIX 5.3, and there is no xsetmon equivalent in IRIX 5.3. 2 The 1920x1080 resolution is not available in xsetmon, so users may need to use setmon directly. 6 On an Indy with 8-bit graphics, setmon can set the resolution to 1280x1024_72, but the resolution is not stored when using ./setmon -x 1280x1024_72. 7
