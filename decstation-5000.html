DECstation 5000

Claims: 5

The DECstation 5000 uses a MIPS CPU, whereas the DEC 3000 is an Alpha machine with turbo-channel. 1 It shares the same CPU as a MicroVAX. 2 4.4BSD boots on a DECstation 5000. 3 The ADU used a DECstation 5000 as a front-end, with Alpha boards connected to its bus. 4 The DB15 port for the keyboard and mouse is serial rather than DB9, using an Lk201 or Lk401 style splitter cable compatible with the DECstation 5000 and some VAXstation 4000. 5
