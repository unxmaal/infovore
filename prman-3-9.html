Prman 3.9

Claims: 6 Part of PRMan

Prman 3.9 is from the Maya 4 and RAT 4.5 era. 1 It is fast in scanline rendering on a modest O2, and using it for fast Reyes rendering allows for quick animation with soft shadows. 23 To render in Maya, set the RMANTREE and PATH environment variables, run 'source mayaman.env', and start Maya; MayaMan provides a plugin for translating Maya data to Rib. 4 In Houdini, Prman 3.9 can be properly set up to work with correct ENV variables, though shader design is more challenging than in MayaMan, and when properly configured it runs animations faster than Mantra. 5 It can render with live subD from Houdini 6.5 using deep shadow maps, with a 15-second delay for initial setup. 6
