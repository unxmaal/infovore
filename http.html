HTTP

Claims: 8 Background: 1 claim already covered by Wikipedia, see Wget.

For non-login websites, an http->https proxy will work, but for anything that enforces HSTS or secure cookies, it won't. 1 The netboot process described in the Jurassic NL manual uses PXE, which combines BOOTP/DHCP and TFTP, and can be set up using HTTP for the rootfs, which is slightly easier to set up than NFS. 2 FTP is built in and can be used for file transfers without needing curl or wget, but HTTP is necessary for web browsing compatibility, and server control might be redundant with web browsers. 3 HTTP may fail if a hostname is not set on the server. 4 Brute forcing an old Linux box with telnet can be difficult; consider checking for other services like HTTP which might be easier to crack. 5 The configuration interface is clunky and only supports plain HTTP, but allows SSH to a serial console. It runs PPC Linux internally. 6 inst/swmgr can be configured to use HTTP for package downloads, but it's unreliable and slow with many packages. 7 To start the installation, netboot the LOVE installer over TFTP and load the second stage file and install media over HTTP; DHCP needs TFTP parameters set; patch 'mod_install.sh' and 'mod_palo.sh' before rebooting to use 8
