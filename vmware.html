VMware

Claims: 30 Background: 6 claims already covered by Wikipedia, see VMware, InfiniBand, VirtualBox.

VMware was used for virtualization before hardware-assisted virtualization instructions were available. 1 VMware supports Infiniband for improved storage performance with RAID5 SSD arrays, and virtual booting is possible with InfiniBand using VMware. 23 VMware supports CPU hot-add for VMs. 4 VMware displays CPU free cycles in MHz, adding up the megahertz of multiple CPUs to represent the total compute power of a cluster or resource pool. 56 VMware can pass an NVDIMM to a VM or treat it as a datastore to run a VM from it. 7 VMware can attach multiple SCSI controllers to a VM, and Solaris recognizes them, even if they don't exist in reality. 8 VMware supports various CPUs including some embedded Xeon and AMD Zen, and can use a PCIe SAS HBA for SAS drives. 9 VMware does not support all Windows guest OS versions, but ancient versions of Windows Server can still run on it. 10
