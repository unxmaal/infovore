ISO

Claims: 39

ISO is a format name, not an acronym for ISO9660. 1 An ISO is an archive copy that ensures all content is included, unlike a .tar file which may lack some files or have modifications. 2 ISO files contain filesystem overhead and additional data, making them larger than tarballs. 3 Preserving disc images is a reason to use ISO files over tarballs. 4 ISOs aren't useless; you can mount them and access the contents with any Linux distro or IRIX, and net installs from ISOs work fine. 5 Loopback mounting an ISO and exporting over NFS is a reliable method for accessing files without breaking hardware, even on slow networks. 6 Loop mounting the ISO on Linux worked for installing the OS. 7 user-a079 has used ISO installs through Zulu's CDROM emulation for SGIs with no issues. 8
