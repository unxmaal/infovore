Weechat

Claims: 5

The Mogrix TDNF is a separate entity from the SGUG TDNF, with its own repository file location, and Weechat installation requires adding the /opt/mogrix-apps/bin directory to the PATH and adjusting permissions to allow user read. 1 The Weechat configuration file is located at ~/.config/weechat/weechat.conf. 2 Weechat uses ncurses and requires proper UTF-8 support to render box-drawing characters correctly; aterm and mrxvt issues are related to font configuration. 3 Deleting the .config/weechat directory and reinstalling WeeChat may not resolve issues with unresolvable symbols in plugins. 4 The script removes sgidev_bridge and replaces it with the nick of the person typing; it can be easily added to a machine using NFS to place it on the HDD, then pasted into WeeChat. 5
