XL graphics

Claims: 8 Part of XL

Indy and Indigo2 offer XL graphics as a low-end option, using the same chips but different board layouts. 1 XL graphics can have 32 window contexts with different pixel formats. 2 Indigo2 with XL graphics can run IRIX 4.0.5H, which was released around the same time as XL graphics. 3 The XL graphics may not be compatible with IRIX 4, and the CD 812-0251-002 contains a patch for XL graphics that is only for IRIX 5.1. 45
