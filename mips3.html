MIPS3

Claims: 34 Part of MIPS Background: 1 claim already covered by Wikipedia, see FFmpeg.

MIPS3 is a 64-bit processor architecture, and MIPS3 software runs on MIPS4 CPUs such as the R5K. 123 The R4k CPU is MIPS-3, and MIPS3 is supported by the mipspro image. 45 MIPS3 software can be obtained from specific sources or compiled, and there is a MIPS3 version available for various programs. 67 Software built for MIPS3 includes FFmpeg, OpenSSH, mplayer, and ScummVM, though some have limitations such as slow performance on an O2 or support for fewer formats. 891011 Compatibility issues exist, such as postinstall scripts failing due to missing files, and Blender 2.41 gives a segmentation fault on an Indigo2 R4000. 1213 Emulation of MIPS3 in MAME is less complete than the r4000 code, and NetBSD on MIPS3 has issues with the EntryHi register and the ADDU instruction. 141516

  9. The OpenSSH version available for IRIX is statically compiled for mips3 and works on older machines; it is a recent test release but still functional. (user-b4f4, 2019-12-09, exchange 214900, check: uncheckable)
  10. There is an mplayer build for MIPS3 that doesn't require external libraries but supports fewer formats. (user-6afa, 2021-12-15, exchange 70122, check: uncheckable)

  13. Has anyone managed to get the MIPS-3 version of Blender up and running? Version 2.41 gives a segmentation fault and core dumps on an Indigo2 R4000. (user-59df, 2021-11-07, exchange 217284, check: supported)
  14. The TLB in the mips3 and drc code is slightly less complete/accurate than that in r4000.cpp; the r4000.cpp code can run Windows NT whereas the mips3 code cannot. (user-a719, 2026-01-19, exchange 93687, check: supported)
  15. NetBSD on a MIPS3 machine has issues with the EntryHi register not limiting values, leading to potential TLB programming skips and incorrect instruction emulation, especially for 32-bit signed branches. (user-231e, 2026-01-21, exchange 93717, check: supported)
  16. The MIPS3 ADDU instruction requires sign-extension in 32-bit mode, and some arithmetic operations are incorrect without it. (user-231e, 2026-01-21, exchange 93718, check: supported)
