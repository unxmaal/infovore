Dillo

Claims: 29 Background: 4 claims already covered by Wikipedia, see Dillo.

Dillo is a lightweight browser that works very fast but lacks in rendering. 12 It uses its own HTTP library implementation, so wget is not a dependency, and it can handle TLS with proper SSL and SNI. 34 Dillo can run on IRIX, where it is faster than Mozilla and is a good alternative for web browsing in IRIX 6.5, though compatibility with IRIX sites can be an issue. 567 It is available on the porting channel and may be in an IRIXports release soon, with ports that have worked for some users. 89 Dillo with PolarSSL is the only browser currently on IRIX that can handle modern encryption algorithms, and using newer SSL libraries allows it to work where the original system curl does not. 1011 It can be built with specific compiler flags, and using inline functions instead of variadic macros could allow building Dillo with Mipspro. 1213 Dillo browser patches have been upstreamed and development is restarting. 14
