LD_LIBRARYN32_PATH

Claims: 18

LD_LIBRARY_PATH and/or LD_LIBRARYN32_PATH can be used to specify library directories. 1 For dynamic linking, LD_LIBRARYN32_PATH should include 32-bit library directories in a specific order so the compiler and ld can find and select the correct libraries. 234 Setting LD_LIBRARYN32_PATH to include paths such as /usr/lib32 and specific library paths ensures correct library resolution for 32-bit binaries. 5 If shared libraries are expected in a specific directory, LD_LIBRARYN32_PATH must be set accordingly for the software to use the correct versions. 6 The build process, buildpkg, and scripts may override LD_LIBRARYN32_PATH, potentially causing issues, and specifying library paths with -L and using -rpath can fix incorrect library selection. 7849 Wrapping the binary with a launcher script to set LD_LIBRARYN32_PATH is a viable solution if modifying the library search path directly is not possible. 10
