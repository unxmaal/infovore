IPX

Claims: 41

The Sun IPX is a small machine (smaller than a shoebox) that contains 128MB of RAM, which is half the maximum RAM of the SparcClassic. 123 It has a tgx graphics card (not a tgx+), an SBus slot, a supplementary power connector, and a DIN8 port. 456 The IPX can run SunOS 4 (including SunOS 4.1.4) and Solaris 2.6, and it can be brought online. 78910 It can be network installed using NFS, can copy files to an NFS share, and can run NFS-backed directories. 111213 The IPX can run applications such as irssi, slrn, mutt, UMN gopherd, DNS, mail, and ipfilter, and is considered suitable as an IPX gopher server. 14151617 The IPX requires a modded or replaced timekeeper to boot, and its NVRAM battery can prevent it from booting. 181920 The onboard cgsix graphics can be problematic, but the soldered-in card cannot be easily replaced with an SBus card chip. 212223
