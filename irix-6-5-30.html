IRIX 6.5.30

Claims: 219 Part of IRIX 6.5 Background: 7 claims already covered by Wikipedia, see IRIX, SGI O2, GNU Debugger.

With IRIX 6.5.22

The Booterizer image contains IRIX 6.5.30 and 6.5.22 and requires a 64GB SD card. 1 IRIX 6.5.30 is for the R5k Indy, 6.5.22 for the R4600 Indy, and 5.3 for the R4600 Indy. 2 IRIX 6.5.22 and 6.5.30 are compatible, with 6.5.30 adding FireWire and USB support. 3 The differences between IRIX 6.5.30 and 6.5.22 are minor, with 6.5.30 dropping MIPS3 support. 4 IRIX 6.5.22 and 6.5.30 irixports is fully tested. 5 Booterizer can install IRIX 6.5.22 and 6.5.30 with MIPSPro revel tools and Workshop ProDev suite, requiring a license for the compiler front ends and Workshop tools. 6 Hosting IRIX 6.5.22 and 6.5.30 costs about $40 for at least 3 years. 7

With O2

The SGI O2 can run IRIX 6.5.30 without patches, and it works fine; it runs IRIX 6.5.30 as a 64-bit system. 89 A typical configuration uses 1024MB of RAM and a R12000 CPU at 400 MHz, though an O2 running IRIX 6.5.30 on a 300 MHz r5k can be much slower than 6.5.11. 1011 The O2 can boot using fx and tftpd over 10/100 Ethernet, but booting IRIX 6.5.30 with bootp() causes kernel panics. 12 The MAME SGI O2 can boot IRIX 6.5.30 at 1280x1024/60Hz with tweaked boot processes, and its emulation runs MIPS IV and can support IRIX 6.5.30. 1314 The O2 can run TAV with various versions of Maya installed, and it runs IRIX 6.5.30. 15 SoftImage/Avid Marquee 2.0 is not compatible with O2 running IRIX 6.5.30; it works on I2IMPACT. 16 The SGI O2 running IRIX 6.5.30 has a bash shell, and attempting to install bashtop fails due to missing dependencies. 17 Enabling FAM to monitor the filesystem locally can resolve CPU issues at boot on an O2 running IRIX 6.5.30 with NFS exports. 18

General

IRIX 6.5.30 was the final version of IRIX. 19 It has known critical security vulnerabilities and a password limit of 8 characters. 2021 It is recommended for most machines, while 6.3 is a stopgap release for O2 launch that may have compatibility issues. 22 The O2 can run IRIX 6.5.30, even though support for Indigo2s and older was dropped after 6.5.22. 23 However, the O2k cannot run it due to initialization and suattr errors. 24 IRIX 6.5.30 is installed with three overlays and two app CDs. 25 To install IRIX 6.5.30, boot from 6.5.30 overlay 1 and load all 6.5 foundation and overlay discs from 6.5.1 to 6.5.30. 26 The IRIX 6.5.30 installer can be patched to skip platform check, but missing platform-specific miniroots cause issues. 27 Compiling a miniroot kernel for unsupported platforms in IRIX 6.5.30 is possible with platform-specific drivers from 6.5.22. 28 The IRIX installation medium contains all necessary files to compile a kernel for the platform, and the sysgen directory contains Makefiles that provide information on kernel compilation. 2930 The patched version of the sa file is available at http://sudenluola.org/irix, named kalakukko.bin. 31 When installing IRIX 6.5.30 using booterizer, setting 'setenv srvaddr {IP of TFTP}' ensures the SGI box knows where to find the TFTP server; otherwise, it may try to contact a server with a blank IP/hostname. 32 netbooting can use a standard ethernet cable to a modern SGI running an OS like IRIX 6.5.30. 33 IRIX 6.5.30 is a version of the IRIX operating system that can be installed on various SGI machines, including the IP35, Origin 200, O200, and Indigo. 343536 The installation process involves loading the overlays, companion CDs, and base system CDs in a specific order, and requires 10 CDs including specific overlays, applications, and libraries. 373839 The miniroot and install tools are in overlays 1, and the XVM raid/partition manager is included in eoe.sw.xvm on overlays disc 1. 4041 IRIX 6.5.30 added OpenGL support and has USB support, but removes a few small things. 4243 The source code for IRIX 6.5.30 was kept in a lockbox. 44 For IRIX 6.5.30, patches are necessary to avoid crashes during the weekly xfs_far job. 45 There are random instabilities in the R5K DRC, and headers from a working IRIX 6.5.30 install are being archived. 46 After copying miniroot and starting the kernel, the Tezro reboots when trying to boot IRIX 6.5.30. 47
