TLB exception

Claims: 4 Part of TLB

A TLB exception either indicates hardware issues such as with memory or CPU, or that instructions are being decoded for the wrong operating system. Running the install with console G mode can result in a TLB exception. MAME breaks when encountering a TLB exception with an address of 0x80000000, and stepping through the exception handling shows a sequence of kernel functions. 123
