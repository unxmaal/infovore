UNIX v7

Claims: 7 Part of Unix Background: 1 claim already covered by Wikipedia, see IRIX.

UNIX v7 runs on a PDP-11 in production, and the PDP-11/34 requires at least 60K of memory to run UNIX V5, V6, or V7, while the 11/34c can run UNIX V5, V6, or V7. 123 UNIX V7 can load standalone programs like mkfs from fixed locations on tape. 4 The UNIX v7 file system is used by IRIX, and original XENIX was a port of UNIX v7 that had limitations compared to UNIX. 56 Other OSs based on CP/M, iRMX86, and UNIX v7 exist. 7
