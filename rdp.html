RDP

Claims: 11

The RDP in the Ultra64/N64 is a custom, hardwired ASIC (not a general-purpose processor that runs instructions from memory), and it was a prototype still in an experimental phase at the time. 123 The N64 GPU consists of the RSP and RDP chips and uses custom display list calls, which are complex and require learning. 456 The RDP can be offloaded to a separate thread or GPU, and a proper vr4300i emulation without JIT interpreting is possible by offloading cp0 and cp1 to their own thread. 7 The BSP can be used as an RDP command parser, streaming data from main memory with DMA and processing display lists, though it requires CPU intervention for CRIME rasterizer interaction. 8 The GPU for RDP and RSP might struggle with complex and varied tasks. 9 NT 4.0 Terminal Server with FX32 allowed concurrent RDP (Remote Desktop) access to x86 apps on an Alpha, and Terminal Server requires RDP to be enabled. 1011
