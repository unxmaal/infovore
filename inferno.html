Inferno

Claims: 11

Inferno is a system that can run on the JavaStation, IRIX, Unixware, Octane, and possibly Tezro machines. 12345 There is an ISO of Inferno with premade binaries for IRIX, and Limbo can run on IRIX because Inferno can run there. 23 The Unixware port of Inferno from Lucent should run on Unixware, but it is poorly maintained. 4 Inferno is also the name of a high-end editing tool that was part of the Xaos Tools suite alongside Newtek Aura (now TVPaint), and it was the primary package with a 3D tracker before Flame took over on faster hardware. 67 Inferno from the 90's included 12 bit floating point. 8
