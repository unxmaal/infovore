disklabel

Claims: 13

The SGI disklabel limits partition sizes to 32-bit block counts, suggesting a maximum partition size of 2TB, though a 4TB drive might work with careful partitioning. 12 disklabel and format-type utilities use blocks because disks are sold by size but are internally divided into blocks. 3 Overwriting the disklabel on the system disk can lead to data loss and system instability. 4 The SGI disklabel is not understood by Linux, which can cause issues with mounting SGI disks. 5 Reading SGI filesystems like EFS and XFS can be complicated due to disklabel and filesystem issues. 6 The Solaris installer requires a disk label to create a new partition layout, and will remove existing partitions if one is not present. 7 The format utility's command-line mode can create a Sun disklabel, necessary for partitioning a blank disk. 8
