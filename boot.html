boot

Claims: 23

Some machines can boot after a reboot, with occasional read errors that can be retried, and one user reports that their machine boots. 12 Bootability varies by hardware: an O300 can boot for real with a 95% chance of success, an Octane with a front plane failure cannot boot and shows only fan operation, and an O2 fails to boot when SCSI drives are plugged in but boots once the drive is unplugged. 345 TT unix SRV4 can only boot via SCSI or Thunder IDE, and the disk needs to have a boot sector and be set active to boot. 67 The system tries to boot even if no keyboard is detected, but without a keyboard you won't get graphics during boot, though you should still see boot messages and a console, and it may not display video output. 89 Boot problems include failing to boot past the x-mouse cursor, a kernel panic on a fresh install caused by a failed hard drive, and the error 'get_chimera_type: elsc_cbrick_type_get(0) failed status = -112' during boot, which can be resolved by powering down and then back up. 101112 You can use Rufus to write an image to a USB to boot and backup the hard disk. 13 Formatting and mounting the partition as /boot is the correct procedure, and the system unmounts /boot before running the 'is there a new kernel' part of the shutdown script, so one may need to manually copy /unix.install to /boot/unix. 1415
