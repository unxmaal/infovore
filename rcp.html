RCP

Claims: 11 Background: 1 claim already covered by Wikipedia, see Silicon Graphics.

The RCP likely does not have debug features, but the RSP has some debug bits in the Status Register $c4. 1 The RCP in the N64 runs a MIPS R4k series core and uses SGI UMA. 2 The N64's CPU has no DMA, because the RCP has to do it. 3 The Nintendo 64 is difficult to overclock due to the RCP being a bottleneck. 4 SGI had a lucrative project with the Nintendo 64's RCP. 5 The dev board has two revisions: Rev1 uses HW1 silicon with RCP, has a BOWTIE_VAL macro for a RDP bug, AI max DMA length of 32k, larger physical die, and Rev2 uses HW2 silicon with no significant differences from retail. 6 The O2 CRM chipset is more similar to the RCP, and the O2 is the only mid-to-late 90s SGI graphics system without Imaging ops built into the base hardware like CRM or IR. 7
