IP12

Claims: 24

The IP12 is an SGI workstation CPU board and platform, with IP numbers designating the CPU board and platform and higher numbers generally indicating newer or more powerful hardware. 1 The IP12 system uses an R4k CPU and proprietary memory boards, unlike the IP6 which uses standard 30-pin SIMMs. 23 An IP12 board has 12 x 1MB SIMMs and many IO pins, some of which may be for NTSC output or video tape recording for Alias renders. 45 The IP12 system uses an R4k CPU and proprietary memory boards, unlike the IP6 which uses standard 30-pin SIMMs. 23 The Elan graphics board exists for the IP12 (4D/30, 4D/35) but requires some impossible to find adapter boards. 6 A top-spec IP12 (4d/35) is performance-wise equivalent to a top-spec R3K Indigo, differing only in the inclusion of Gio32 on the Indigo and VME on the PI. 7
