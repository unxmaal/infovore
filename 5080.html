5080

Claims: 11

The IBM 5080 is a graphics system designed for CAD on mainframes, and its graphical workstations can be attached to RS/6000s and S/370s. 12 It is a high-performance display system that retained compatibility with the 3250, which was descended from the 2250 for the System/360. 34 The 5080 supports buttons and dials via serial port or microchannel adapter for graphics input, and it can do raster graphics, though CATIA V3 typically shows a blue background. 56 There is a software emulator for the 5080, with references to AIX and Windows versions, an NT 5080 emulator, and a floppy version for AIX/RT 2.2.1. 78 CATIA v4 for the 5080 required a channel controller for network access, unlike other networked systems. 9
