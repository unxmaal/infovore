IRIX 6.2

Claims: 137 Part of IRIX Background: 8 claims already covered by Wikipedia, see IRIX, SGI Indy, XFS.

With IRIX 5.3

When using the new R4000 core, IRIX 5.3 fails to link the kernel during installation due to issues with the R4000 core, while IRIX 6.2 encounters a segfault at the same stage, and this segfault issue is consistent across both IRIX 5.3 and IRIX 6.2. 12 The MIPS compiler for IRIX 5.3 and early IRIX 6.2 requires patch 1118 to resolve fmul in delay slot warnings when using makerom with the N64 SDK. 3 U64 Drivers exist for 5.3 and 6.2 in available sdks online. 4 IRIX 5.3 and 6.2 have pre-installed HDD images in MAME, with the MAME image for IRIX 6.2 being 446MB and for 5.3 being 336MB. 56 Some users recommend using IRIX 6.2, but one can also dual-boot IRIX 5.3 by partitioning the drive. 7 IRIX 5.3 or 6.2 runs well with 64MB of RAM on slow processors, even in console mode. 8

With IRIX 6.5

IRIX 6.2 and 6.5 can be slow, but Profile Guided Optimization can significantly improve performance when used with Link Time Optimization, especially on IRIX 6.2 and 6.5. 910 IRIX 6.5 has OpenGL 1.1, while 6.2 has only OpenGL 1.0 for textures. 11 IRIX 6.5 had issues with demo executables and strange errors, while 6.2 had missing executables for most demos. 12 The SGI SDK for N64 development is compatible with IRIX 6.5 but works best on 6.2 or 6.3. 13 The Onyx can run an SGI IRIX 6.2 drive and keep an SGI IRIX 6.5 install for swapping between, without Vigra. 14 Weatherstar software runs on 6.2 or 6.3, not 6.5. 15 6.2 with POSIX threads + patches is a fine platform unless you want to run some commercial software that requires 6.5. 16 XFS disks formatted in IRIX 6.5 may not mount in IRIX 6.2 due to format changes. 17

General

IRIX 6.2 is a 64-bit release supporting multiple SGI systems, including the Indigo2 and the Indy. 1819 It has more software than IRIX 6.0 and 6.1, but lacks Nekoware and SGUG-RSE. 20 The top-end IRIS Crimson configuration includes a R4400 CPU at 150MHz, 1MB L2 cache, 256MB RAM, a 7.2GB hard drive, and RealityEngine graphics. 21 R3K support was not dropped until IRIX 6.2, and it is considered a good option for machines with 128 MB or less RAM. 2223 It lacks full C99 support and does not support modern crypto standards. 2425 Software release 6.2 had limited support and many bugs, and patches can cause CD-ROM drive errors. 2627 It uses a combined (MxN) implementation strategy with sprocs and user-level context switching for local threads via NSPR. 28 With the 12/1999 patch set, it is functionally equivalent to IRIX 6.5.6 for NFS v3. 29 IRIX 6.2 is an all-platforms release, similar to IRIX 6.0, whereas IRIX 6.3 was platform-specific for O2 systems. 3031 IRIX 6.2 runs on the Indigo2, and it used to run on the Indigo. 32 The Indigo2 IMPACT 10000 (IMPACT) version of IRIX 6.2 includes MIPSpro 7.3 and the IRIS Development Option 7.1, and it is the latest version of IRIX 6.2. 3334 IRIX 6.2 did not run on Indigo2 R10K systems initially, as a later version was required. 35 The Indy with a R4600 runs IRIX 6.2 but does not save the resolution, requiring manual adjustment which can cause display issues. 36 The Power Indigo2 runs IRIX 6.2 and not 5.3. 37 The R8000 runs IRIX 6.2, and ATLAS optimized for it performs on par with SGI's own implementation. 38 The 4DDN kernel component is limited to systems supported by IRIX 6.2, specifically IP17 to IP26. 39 AppleTalk Software (Xinet) has an activation that varies by version and may be limited to IRIX 6.2. 40
