snes9x

Claims: 5 Part of SNES

SNES games can be run on IRIX using compiled SNES emulators, such as SNES9x, which is available in Nekoware. 1 snes9x has an IRIX port. 2 The snes9x core and CPU clock boosting made the emulator stable for Final Fantasy VI on SNES. 3 snes9x is mostly complete but lacks a sound backend. 4 One user's O2 R12000 does not run Snes9x. 5
