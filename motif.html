Motif

Claims: 38 Background: 7 claims already covered by Wikipedia, see Motif (software), NetSurf, Emacs.

Motif is a C library, and libXm corresponds to it. 12 It is a usable GUI API with a C API and minimal overhead, requiring direct calls to the X toolkit, which makes it difficult to run without X. 34 Motif and its surrounding X clients are free software and can be installed on any UNIX system. 5 It is the most native UI toolkit on IRIX and similar systems, and AIX 3 comes with Motif as a default environment. 67 Old Iris and SGML widgets were reused in Motif, leading to different naming schemes. 8 Motif can provide SGI's look through hints that are ignored by other environments. 9 It has a notebook widget that can be styled differently and was used for dialogue boxes. 1011 For a raster editor in Motif, you can use OpenGL with the GL widget GLwDrawingArea or draw in memory and update a Pixmap. 12
