Raspberry Pi

Claims: 66 Background: 13 claims already covered by Wikipedia, see Raspberry Pi, Amiga, Gentoo Linux, Quake II.

The Raspberry Pi is a small single-board computer that uses SD cards for booting and has limited RAM and a limited GPU. 123 It has 27 GPIO pins and no built-in RTC chip, so it cannot function without internet connectivity due to the lack of a battery-backed RTC. 456 To write an image to a Raspberry Pi, use dd on Unix or balenaEtcher and Win32DiskImager on Windows. 7 Booterizer is a tool for creating bootable images for the Raspberry Pi with minimal user input, and it can run IRIX with a 10GB image that can be downloaded. 89 Booterizer can configure network settings for the Raspberry Pi to connect to an SGI over Ethernet, using 192.168.1.x which may require additional static routes. 1011 RaSCSI is a SCSI drive emulator that uses a Raspberry Pi, which is cheaper than a SCSI2SD and can also emulate a SCSI Ethernet adapter for classic Macs and a SCSI display adapter for video output. 12 The Raspberry Pi can be used for a variety of purposes, including as an instant camera with motion installed, as a proxy server for IRIX, and to improve security and privacy for home automation. 131415 The Raspberry Pi is a British, ARM-based device considered a modern continuation of the BBC microcomputer series, and it can run Acorn's Risc OS. 1617 It can emulate MIPS and VAX machines, though the MIPS emulation in MAME is buggy and uses more CPU than necessary. 18 The Raspberry Pi can program hardware, competing with the J-Link, and its RP2040 runs fast with the latest firmware and proper setup. 1920 It can serve as a versatile server without NAT using wired Ethernet and a switch setup. 21 It can be used to install IRIX on SGI systems, with methods including a booterizer and the Reanimator tool, and it can run Reanimator headless. 22232425 Network installs can be done with a Raspberry Pi server running rarpd and ftpd on an isolated network, and using pre-made OS images simplifies the process. 2627 Installing IRIX is complex, but a Raspberry Pi can be used with the Reanimator guide for a straightforward process. 28 The Pocket Reform offers CPU cards for various architectures, including Raspberry Pi, in a compact form factor. 29
