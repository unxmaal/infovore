type 5

Claims: 4

Old Sun keyboards from type 3 to type 5 are interchangeable, with type 3 needing an adapter due to its DB15 connector. 1 The SGI LK201 is a step down from the Type 5 and not as nice as the later Type 7. 2 The keyboard type 5 is incompatible with type 222, which may indicate a faulty ROM in the IPC. 3 A 13w3 to VGA adapter has been used, but not a Sun Type 5 to PS/2 converter. 4
