Multia

Claims: 52 Background: 4 claims already covered by Wikipedia, see DEC Multia, Digital Equipment Corporation, SCSI.

The DEC Multia is an Alpha-based system that can run Tru64, Digital UNIX, Windows NT, VMS, and Linux. 1234567891011 It was intended to run Alpha Windows NT or Tru64 rather than VMS, and running VMS on it is challenging and tricky. 71213 The Multia has SCSI and IDE connections, PCMCIA slots, and two PCMCIA slots. 141511 It can be used as a desktop and a firewall, with RedHat 4.2 and 5.x working on it. 10161718 The Multia can test SCSI emulators, and the BlueSCSI F4 can be used as a CD-ROM for it. 19202122 The F-series chips in the Multia overheat and degrade over time, and it may require additional RAM. 2324 The Multia can fail due to a common memory chip issue, and its power connector can melt and brown. 2526 The Multia was intended for volume sales with special software for managing a fleet running NT 3.5x. 27 The Multia has an infamous design flaw with thermals, specifically a hot regulator on the bottom of the mainboard. 282930 Multia motherboards have a heatsink needed for the chip on the underside, and the fan's thermister should be cut. 31 Multias can't run Windows at all; NT 4 doesn't have drivers because the system is too new, and W2k Beta has drivers in a separate disk but it bluescreens trying to install. 32 Multias can run NT and VMS, though it is not clear how to license VMS now. 33
