Dropbear

Claims: 5 Background: 1 claim already covered by Wikipedia, see OpenSSH.

Dropbear is a lightweight SSH client that can run on the O2. 1 It uses libtommath and libtommcrypt for its libraries. 2 Using Dropbear instead of OpenSSH can improve speed when tunneling X over SSH. 3 Dropbear does not include scp by default and does not provide an SFTP server. 45
