distcc

Claims: 42 Background: 16 claims already covered by Wikipedia, see Distcc.

distcc is a tool that distributes compilation tasks to other hosts, potentially offloading preprocessing and linking work to reduce load on the local machine, though it does not distribute configure scripts. 123 It can be configured to start a daemon, but this is not done by default, and it works well with rpmbuild. 45 It can be used with the Gentoo build system, though experience with it is limited. 6 It can significantly speed up compilation compared to parallel make, even with a modern laptop or old laptop as a slave, and can halve build time for GCC on a powerful machine. 789 It can utilize faster CPUs, a PC, or a Talos PPC workstation for compilation, and can leverage modern external hardware for faster compile speeds. 1011 It can be used for cross-compilation on multiple Indys and with volunteer SGI hardware. 1213 It is available via a Docker image for improved performance on SGI systems, and can send compilation tasks to a Linux Docker container. 1415 It runs on multiple platforms including amiga, DOS, NES, Genesis, and an amiga-powered arcade machine. 16 distcc relies on GCC features and cross-compiling capabilities. 17 A Sunfreeware package for Solaris 2.6 is available for distcc. 18
