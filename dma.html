DMA

Claims: 20 Background: 1 claim already covered by Wikipedia, see DMA attack.

DMA (direct memory access) allows peripherals to transfer data directly to and from main memory without going through the CPU. The 68k Macintosh has DMA, unlike the software. 1 SCSI had advantages like DMA, bus mastering, daisy chaining, robustness, standards compliance, external device expansion, and features like tagged command queuing. 2 The ST video chip is DMA-based, with an 8 MHz 68000 CPU, DRAM, and AY-3 compatible sound. 3 The motherboard DMA for SCSI is a 16-entry table, not a single register. 4 The O2 ICE uses DMA to fetch data from main memory to process vertices, and later models likely do the same. 5 The BSP can be used as an RDP command parser, streaming data from main memory with DMA and processing display lists, though it requires CPU intervention for CRIME rasterizer interaction. 6 The driver disables DMA, and it's unclear if DMA ever worked on the Altix. 7
