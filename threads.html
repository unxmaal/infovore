threads

Claims: 5

Threads share most state with processes but have distinct program counters and stacks, and under Linux they are treated as processes by the scheduler while the relationship between user-level threads and the kernel differs under IRIX. 1 SMP emulation can potentially run emulated CPUs as separate threads on separate cores, which might result in a better experience. 2 Threads were not useful for games when CPUs had only one core. 3 A full stack developer should understand sockets, select, and threads for I/O operations. 4 Assuming that an entire rack is running on a dual proc server with enough threads, you'd only need as much space as the O300 takes but with triple the emulated CPU's. 5
