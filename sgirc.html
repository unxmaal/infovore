sgirc

Claims: 13

sgirc is an IRC client written by its author, available on GitHub, and described as an alpha but good IRC client for the Macintosh/SGI. 1234 sgirc supports multiple sets of server settings, nick, password, and Discord bridge settings through a connection dialog, where the 'Save' option stores server settings. 563 sgirc's chat window now supports resizing channel and name widths, and its highlighting feature copies text in the X11 way. 78 sgirc's command line options are currently disabled due to changes in how server settings are stored. 9 sgirc does not yet support IRC over SSL but could add simple SSL support without cert verification. 10 Building sgirc requires mbedtls and SGI-specific tools, and it can be built with mipspro or GCC. 11
