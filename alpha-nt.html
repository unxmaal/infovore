Alpha NT

Claims: 9

Quake 1 can be ported to Alpha NT using Visual C++ 6, but the Win32 port depends on i386 assembly which impacts performance, and the Alpha has a basic 2D card, making 3D performance poor. 1 The x86 version did not run under Alpha NT or FX32, returning an error message. 2 There are native Alpha NT applications like Word and Excel, as well as development tools such as Visual C++ and Visual Basic. 3 The Alpha NT operating system includes a web browser, with Altavista as the default homepage. 4 The RRD45 CDROM is a generic SCSI drive that can do 512k per sector and can be replaced with any SGI compatible SCSI drive. 5 Newer PWS can boot from an IDE CDROM, but VMS requires a SCSI CDROM. 5 Alpha NT lacks USB support, but Alpha 2000 should have it; drivers may require third-party installation. 6 Unigraphics supported Alpha/NT for VMS until 1998, with Digital UNIX and NT Alpha support continuing for a while. 7
