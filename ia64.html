IA64

Claims: 83 Background: 2 claims already covered by Wikipedia, see Linux kernel, Video games and Linux.

With HP

HP-UX for IA-64 supports user-level virtualization. 1 HP-UX is considered a decent choice for IA64, though CDE can be problematic and PA2.0 CPUs provide full 64-bit support. 2 HP 9000 containers for HP-UX on ia64 are available for download as part of the general SRP package from HPE, but not all versions are supported, and they are also available from tenox.pdp-11.ru. 34 There should be a PA-RISC to IA64 translation layer baked in HP-UX. 5

General

IA64 is a VLIW architecture that was abandoned in 1999 in favor of RISC ports. 6 The architecture was marked as orphaned in the Linux kernel. 7 Debian dropped ia64 support, and GCC has dropped ia64 support in its last release. 89 Gentoo is the only up-to-date distro for IA-64, though it is difficult to use and lacks kernel support. 1011 The compilers for IA-64 included Intel for Windows and Linux, Microsoft Visual C++ for Windows, GCC for Linux/FreeBSD/HP-UX, aCC for HP-UX, and Open64 for Linux. 12 There is no known LLVM/Clang support for IA64. 13 OpenVMS 8.x and 9.x are limited to Alpha/IA64 processors, and there's now an AMD64 version but it's less known. 14 The x86 VMS license is available through the hobbyist program for Alpha or IA64 systems. 15 Building modern software on IA64 is difficult, as gcc cannot be built on HP-UX 11.23 ia64 and building the Linux kernel can result in an internal compiler error even with a cross toolchain. 1617 The main patch set to re-enable ia64 for Linux 6.7 is available on GitHub. 18 SUSE 9 on IA64 is supported by the SLES 9 SP3 installer kernel, with kernel sources available in the CD6 ISO. 1920 Intel compilers on IA64 produced faster code than gcc. 21 The file system is not compatible with IA64 systems due to different firmware requirements. 22 CPU speed impacts software performance based on compiler optimizations; SGI's Berkeley architecture has a register window system that limits visible registers per cycle; IA64 and MIPS, Alpha, PowerPC, ARM are Stanford RISC. 23
