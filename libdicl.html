libdicl

Claims: 6

libdicl adds base library features that Linux has but Irix lacks, aiming for desktop app compatibility. It provides `getopt_long` and `htole16`, which is a no-op on SGI MIPS. 123 It can be used by including the libdicl implementation via `CPPFLAGS` and `LDFLAGS`, or by adding the include and linking against it, though `configure` might still require tweaking. 2 Exporting specific flags and running meson and ninja allows building libdicl outside of an RPM, but it fails with a memrchr call in the gl directory. 4 Bootstrapping SGI packages with clang is difficult due to libgcc and libdicl dependencies clashing, making it hard to mix gcc- and clang-built shared libraries. 5 Version 0.0.4update1 includes a libdicl upgrade and dependencies, and builds rpms available at https://github.com/sgidevnet/sgug-rse/releases/tag/v0.0.4betaupgrade1. 6

Sources

  1. libdicl adds base library additions Linux has but Irix lacks, aiming for desktop app compatibility. (user-e872, 2024-08-12, exchange 215544, check: uncheckable)
  2. To use `getopt_long`, you can include the `libdicl` implementation in your project via `CPPFLAGS` and `LDFLAGS`, or by adding the `libdicl` include and linking against it, though `configure` might still require tweaking. (user-2d09, 2020-02-06, exchange 68338, check: supported)
  3. `htole16` is implemented as a no-op on SGI MIPS, use `libdicl` for cross-platform compatibility. (user-1446, 2020-04-25, exchange 214964, check: supported)
  4. exporting specific flags and running meson and ninja allows building libdicl outside of an RPM, but it fails with a memrchr call in the gl directory; the order of includes or other factors might be the issue. (user-e872, 2021-07-29, exchange 215194, check: uncheckable)
  5. Bootstrapping SGI packages with clang is difficult due to libgcc and libdicl dependencies clashing, making it hard to mix gcc- and clang-built shared libraries. (user-9860, 2023-05-23, exchange 215381, check: uncheckable)
  6. 0.0.4update1 is a version that includes a libdicl upgrade and dependencies, and builds rpms available at https://github.com/sgidevnet/sgug-rse/releases/tag/v0.0.4betaupgrade1. (user-2d09, 2020-02-28, exchange 92217, check: uncheckable)
