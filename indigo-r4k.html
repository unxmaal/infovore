Indigo R4k

Claims: 10 Part of Indigo

The Indigo R4k is a single CPU R10k system, and with the Elan board it consumes 140W, while the Octane with ESSI and SI consumes ~335W. 1 The Elan board in an Indigo R4K has 4 GE chips and includes a mainboard, Z Buffer, VRAM, and an output board. 2 Indigo2 and Indy RAM are the same as the RAM used in Indigo R4k. 3 The R4000-type systems, including the Indigo R4K, Indy, and Indigo2, allow the host to read and rewrite the EEPROM content. 4 IRIX 5.3 has SSD-like speed on an Indigo R4k, which can launch and run programs quickly and well, but may encounter network-related errors if it tries to access networked objects. 56 The Indigo R4k power supply uses a 90mm Elina Fan MDA 120925 LB, which is 12VDC and draws 110 mA. 7 The Indigo R4k does not accept 32MB FPM Parity SIMMs in any combination of 4, requiring original RAM for stability. 8 An Indigo R4k with Control Data skins was around $250, and there is a $2000 indigo r4k on eBay. 910
