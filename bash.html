bash

Claims: 82 Background: 21 claims already covered by Wikipedia, see Bash (Unix shell), FFmpeg, Tcsh.

Bash can be installed from /usr/nekoware/bin/bash, /opt/local/bin/bash, or by linking the bash binary, and it can also be built from source using a script that spawns mksh to download and install it.
