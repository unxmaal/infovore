CRIME

Claims: 5

CRIME is a GPU with SIMD instructions in the O2, which includes a watchdog called McGriff. 1 CRIME has 3 tiled TLBs holding 64 entries each, and for 32-bit pixels each tile is 128x128, with framebuffer dimensions not needing to be aligned to tile boundaries but requiring an integral number of tiles. 2 CRIME has a 144-bit bus running at 133 MHz internally, which is converted to a 288-bit 66 MHz bus for memory. 3 CRIME can do a 162 MHz pixel clock, which was spotted on the spec as a frequency of least error for the PLL. 4 Inter IC bus signals can be labeled using signal timing diagrams, even if there is no pinout, by numbering them 'CRIME, EVIL, MACE' 1, 2, 3, etc. 5

Sources

  1. The O2 has a GPU with SIMD instructions, named Crime, which includes a watchdog called McGriff. (user-8b3c, 2019-12-01, exchange 214897, check: supported)
  2. CRIME has 3 tiled TLBs holding 64 entries each, and for 32-bit pixels, each tile is 128x128, with framebuffer dimensions not needing to be aligned to tile boundaries but requiring an integral number of tiles. A 1920x1024 (user-8780, 2025-05-24, exchange 117061, check: supported)
  3. CRIME has a 144-bit bus running at 133 MHz internally, which is converted to a 288-bit 66 MHz bus for memory. (user-757f, 2026-01-24, exchange 121132, check: supported)
  4. CRIME can do 162 MHz pixel clock just fine - spotted it on the spec as a frequency of least error for the PLL and had to try. (user-42cf, 2025-05-18, exchange 225070, check: supported)
  5. You could label inter IC bus signals using signal timing diagrams, even if there's no pinout, by numbering them 'CRIME, EVIL, MACE' 1,2,3, etc. (user-4f7c, 2026-02-18, exchange 121579, check: supported)
