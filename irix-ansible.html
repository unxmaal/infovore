irix_ansible

Claims: 44 Background: 1 claim already covered by Wikipedia, see Comparison of open-source configuration management software.

irix_ansible is a collection of known good configuration methods for IRIX that automates installation and system configuration. 123 It installs wget, python, and openssh, starts sshd, installs nekodeps and base packages, performs security hardening, and deploys network setup via ansible tasks. 14 The project is hosted on GitHub, with instructions at https://github.com/unxmaal/irix_ansible. 56 It runs on a modern box and provisions a target box, and can be used with Booterizer, which resets IRIX development environments to reduce the risk of system changes. 789 The setup uses a vault system with two passwords, one in group_vars/default/vault.yml and one in ~/.vault_pass.txt, to encrypt and decrypt configuration files. 1011 It can rebuild a system from bare metal in about 30 minutes, and Booterizer and irix_ansible together allow reprovisioning in about 30-45 minutes. 1213 The documentation is difficult, and pinning the ansible version can help. 14 irix_ansible may fail to install certain packages due to timeouts, but manual intervention can resolve the issue. 1516 The irix_ansible script requires copying .bashrc to .bash_profile for bash to pick it up. 17
