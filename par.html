par

Claims: 5 Background: 1 claim already covered by Wikipedia, see GNU Debugger.

par is the IRIX equivalent of strace, which is not the same as on other systems. 12 par can be used to trace system calls and file operations, such as identifying library opens and tracking down issues. 34 It can be used alongside gdb for debugging binaries, and the fx command is simpler for resizing partitions compared to Linux. 35

Sources

  1. IRIX strace is not the same as on other systems; use par instead. (user-42cf, 2019-05-26, exchange 77857, check: uncheckable)
  2. The IRIX equivalent of strace is called par. (user-21b8, 2024-06-10, exchange 71352, check: uncheckable)
  3. debugging a binary in IRIX using gdb involves running the program, making breakpoints, and using commands like 'b' to set them; 'par' can show system calls. (user-2189, 2020-06-13, exchange 68686, check: uncheckable)
  4. par can be used to trace file operations, as shown with `par -rsSSQQ -s` and `par -SS -s` to identify library opens, and examples like `par -rsSSQQ fm | grep -i tiff` to track down issues. (user-8547, 2022-03-17, exchange 81287, check: supported)
  5. The `fx` command is simpler for resizing partitions compared to Linux, requiring just `par` and `ro`. (user-f229, 2021-09-08, exchange 79813, check: supported)
