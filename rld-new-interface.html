_rld_new_interface

Claims: 5

`_rld_new_interface` is an internal interface used by the IRIX runtime linker (`rld`) for functionality such as `dladdr`, and it is loaded at runtime by `rld`, so the symbol exists even if it is not present at link time. 12 The interface allows the runtime linker to handle missing symbols at application launch time. 3 Building git on IRIX_ports requires resolving undefined references to `_rld_new_interface` when using /opt/local/openssl. 4 A `_rld_new_interface` warning indicates issues with linking abicalls files with non-abicalls files. 5
