4.19 kernel

Claims: 3

The 4.19 kernel has issues with the Altix system, similar to earlier versions. 1 A 4.19 kernel can boot an SGI system into /bin/sh but may require device nodes to be populated in /dev. 2 The 4.19 kernel has a DMA issue that prevents the SCSI controller and network card from requesting memory, crashing the boot process. 3
