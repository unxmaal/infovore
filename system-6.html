System 6

Claims: 8

System 6 is a Mac OS version that would not boot on 128k Macs due to Macintosh System software limits. 1 System 6 was the first Mac OS version to support multitasking. 2 A/UX is its own OS that can run System 6 programs in compatibility mode. 3 The Diimo is the only Power Mac SE/30 model that works with A/UX, and a 040 CPU breaks compatibility with System 6. 4 System 6 requires a terminal program that supports zmodem for file transfers. 5
