Lotus Notes

Claims: 3

Lotus Notes is a system that can be set up using a 70-day eval license for Lotus Domino on OS/400 media. 1 There was no IRIX version of Lotus Notes, but versions existed for other UNIX systems and a Linux client. 2 Domino is the server side of Lotus Notes, extending email with a database engine optimized for text and allowing client applications for business purposes. 3
