POSIX

Claims: 19 Background: 2 claims already covered by Wikipedia, see IRIX, Unix.

POSIX is a standard that defines a set of system calls, libraries, and user tools for UNIX systems. 1 POSIX is a subset of UNIX and can be implemented in any operating system. 2 POSIX certification requires paying to be tested, and passing the certification test suite can be difficult. 34 Several operating systems have achieved POSIX compliance or certification, including XNU, NT 4, macOS, Solaris, IRIX 6.5, and NonStop. 56789 Some systems enhance POSIX compatibility by importing functions from other libraries, such as GNU standard library functions. 10 Certain functions are POSIX but not standard C library functions, such as getline, while others like stpcpy were added to POSIX later. 1112 POSIX includes tools such as cksum, which is specified in IEEE Std 1003.2-1992. 13
