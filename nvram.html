NVRAM

Claims: 79

NVRAM is a small amount of memory that retains data without power, and its battery failure can cause power circuitry issues and unrecognized hardware. 1 Many systems require a working NVRAM to boot; otherwise, they will not turn on, and some machines will not POST without a live NVRAM. 23 NVRAM failure can cause systems to hang during boot, perform an extended POST, or display no video output, as experienced with the Ultra 2 and Ultra 60. 4567 The MAC address is stored in NVRAM and, if lost, needs to be repaired and reprogrammed to allow the network to function. 8 A new NVRAM chip is needed if the current one is corrupted, and it can be replaced by copying a valid configuration from another machine. 910 Fixing NVRAM issues is a good first step when machines fail to boot, and reprogramming the NVRAM can be done using a documented procedure. 1112 NVRAM stores system settings and variables, including the machine type, ethernet (MAC) address, boot parameters, time, and audio volume on SGI machines. 13141516 A dead or invalid NVRAM can cause a range of problems, including POST beep codes without video, garbage serial output, SCSI errors, failure to detect hard drives, L1 cache failing to initialize, and system errors being interpreted as various weird faults. 17181920 The OBP has defaults for the environment, so machines should generally still start without NVRAM, though they may complain, default to diag-switch as true, or cause a network boot. 212223 Fixing NVRAM often involves reprogramming it, since a replacement chip loses all information; the host ID or a valid MAC address can be used for the address's last digits, and checksum errors may not be resolved by enableall/resetenv. 142425 NVRAM is managed by chips such as the Dallas DS1687 and ST DS1685, which handle L1 controller operations and system variables, and may be backed by a battery or coin cell. 262728 NVRAM can be replaced on various systems, sometimes by swapping a battery or chip, and some replacements are preferred over universal processor-based ones. 2930
