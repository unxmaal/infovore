Indigo2 Extreme

Claims: 18 Part of Indigo2 Background: 1 claim already covered by Wikipedia, see OpenGL.

The Indigo2 Extreme is a reliable system favored for engineering use, and it can run the entire SGI software library alongside an Octane. 123 It has a 200 MHz R4400 CPU with 2 MB cache and 384 MB RAM, or a 250 MHz R4400 CPU, and supports OpenGL 1.0 with some OpenGL 1.1 features through extensions. 456 It can run ProE release 17 very fast, faster than input commands and mouse movement, and it does not support hardware texturing, making it difficult to run textured models efficiently. 789 It has no TRAM, which limits its use for image editing, and it does not come with Cosmo Compress. 101
