Windows NT 4

Claims: 7 Part of Windows NT

Windows NT 4 can boot from a FAT16 partition on the HP Vectra 5/90 Series 3. 1 It dual boots Red Hat and Windows NT 4 and performs well as servers. 2 Visual workstations only support Windows NT 4 and Windows 2000, and the VW320 supports Windows NT 4 and 2000, but specific builds that can boot from ARCS are required. 34 The only operating systems worth using on an Alpha are Windows NT 4 or the Windows 2000 beta with graphics card drivers. 5 An organization used Windows NT 4 for Active Directory until 2009, upgrading to Windows Server 2008 R1 on a 1.8 GHz Pentium 4 with 512 MB RAM. 6 Existing HALs from NT 4 can be ported, and creating a HAL for Windows XP might be easier than building the entire project. 7
