DRC

Claims: 7

Networking was working both pre-DRC and after 0.241, but not in versions before 0.228. A gfx regression in 0.213 prevents drawing grid in Softimage; use 0.212 instead. For non-DRC with networking, use 0.240. 1 IRIX 6.5 can now boot consistently in DRC emulation, though stability requires further testing. 2 Running Irix 5.3 with DRC using an AMD 5800X processor increases mame benchmark speed by 81.76% to 54.55% without DRC, offering a 50% speedup. 3 Disabling the DRC during IRIX 5.3 installation can avoid annoying issues. 4 The TLB in the mips3 and drc code is slightly less complete/accurate than that in r4000.cpp; the r4000.cpp code can run Windows NT whereas the mips3 code cannot. 5 Signed comparisons for branch instructions should be validated before merging code changes. 6 the DRC has diverged quite a bit from the one that was in there for arm64be; will put some more cycles into it. 7
