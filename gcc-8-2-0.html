gcc 8.2.0

Claims: 14 Part of GCC Background: 1 claim already covered by Wikipedia, see FFmpeg.

GCC 8.2.0 can compile C and C++ on IRIX 6.5, and a crosscompiler setup for IRIX is available with GCC 8.2.0 together with binutils including a linker. 12 irixports allows choosing between GCC 4.7.4 and 8.2.0 with a gccversion variable, bootstrapped for both versions, and the pkgsrc bootstrap process works with a plain installation of GCC 8.2.0, requiring only the CC and CXX environment variables to be set to point to the gcc and g++ executables. 34 GCC 8.2.0 has known failures with C++, but the amount of failing C++ tests is less than expected, and it prints colorful error messages. 56 GCC 8.2.0 has issues with NaN and INFINITY, even with -std=c99, producing non-helpful error messages, and with -Werror it generates many warnings with older source. 78 When compiling xz with GCC 8.2.0, the configure script might pick up a local definition of getopt_long from a header file, leading to compilation errors. 9

Sources

  4. irixports now allows choosing between gcc 4.7.4 and 8.2.0 with a gccversion variable, bootstrapped for both versions. (user-ba81, 2019-06-17, exchange 214762, check: supported)
  5. The amount of failing C++ tests in GCC 8.2.0 is less than expected. (user-42cf, 2019-01-09, exchange 203644, check: supported)

  7. GCC 8.2.0 has issues with NaN and INFINITY, even with -std=c99, producing non-helpful error messages. (user-637b, 2019-03-17, exchange 1054, check: supported)
  8. gcc 8.2.0 with -Werror generates many warnings with older source. (user-42cf, 2019-07-16, exchange 67502, check: supported)
  9. when compiling xz with gcc 8.2.0, the configure script might pick up a local definition of `getopt_long` from a header file, leading to compilation errors. (user-2d09, 2019-09-05, exchange 67848, check: supported)
