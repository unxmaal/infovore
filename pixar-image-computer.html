Pixar Image Computer

Claims: 6

The Pixar Image Computer was a framebuffer/image accelerator designed for high-end visualization, including MRI, physics, and animation, prioritizing speed over the features of more general-purpose systems. 123 It required a connection to a UNIX system for operation, running software through a host like a Sun or SGI machine. 4 It could also connect directly to a host computer without an OS, loading only a bootloader and code to bring up the software interface, then piping data directly into it. 5 It was used by Pixar for rendering and interfacing with a Symbolics Lisp machine. 3 The CS-12 is a rebranded or modified variant of SGI's server hardware used for render farms or Pixar Image Computer-type tasks. 6
