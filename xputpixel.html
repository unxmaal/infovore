XPutPixel

Claims: 5

XPutPixel is slow, and calling it windowWidth * windowHeight times is not optimal for performance. 1 To optimize plotting pixels in a loop, use an XImage and fill a pixel buffer directly. 23 Plotting to a buffer by iterating a pointer can be more efficient than using XPutPixel repeatedly. 4 XShmPutImage can be used to fill a buffer directly, which can be faster than XPutPixel, especially for large images. 5
