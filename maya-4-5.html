Maya 4.5

Claims: 11 Part of Maya

Maya 4.5 was available for IRIX and is useful for PS2 development, though it is not freely mirrored online. 1 It runs in VirtualBox on Windows XP with OpenGL acceleration, runs well on their VW, and is more snappy even on older CPUs. 234 It has a good feature set and works with IRIX, but may not support fur with prman 3.9. 4 Maya 4.0 had fur and nCloth, but fluid effects were added in 4.5. 5 Mayaman version 1.1.8 runs in Maya 4 and 4.5 because it has the .so files to match. 6 To run Mayaman in Maya 4.0 or 4.5, start lmgrd in the entropy/etc directory, source mayaman.env in the Mayaman directory, and launch Maya from the same terminal. 7 The AW.dat file for Maya 4.5 requires generation of host ID numbers rather than just search and replace, and the keygen should replace 'HOSTID=lmhostid' with the actual lmhostid value. 89 swmgr kept complaining about a Maya 4.5 installation file being corrupt, but burning it to a CD fixed the issue. 10
