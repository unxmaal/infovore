libsodium

Claims: 3

libsodium was able to build and run its testsuite with similar results on both gcc8 and gcc4 on IRIX. 1 Compiling libsodium with gmake check can fail, and adding -D_POSIX_SOURCE=500 sometimes helps. 2 The library uses SSE/AVX intrinsics which are not available on MIPS, causing missing symbols when built with mipspro. 3 The gcc build includes fallbacks for these intrinsics, but still fails tests. 3
