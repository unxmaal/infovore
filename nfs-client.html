NFS client

Claims: 9 Part of NFS

The NFS client is included in the base install and ready to use without any additional installation on IRIX 6.x systems, including version 6.5.22. 12345 On IRIX 3.x, the NFS client is installed as part of the eoe install. 6 Setting up an NFS client in IRIX is easy. 7 The native NFS client on Windows 10/11 Pro works with IRIX, requiring the anonymous user ID and group ID to be set to 0/0 for root access. 8 The NFS client was attempting to use UDP, which the server does not support. 9
