Target mode

Claims: 3 Part of TARGET

Target mode is supported on a handful of HBAs, notably Qlogic. 1 The TiBook G4 supports target mode for data recovery. 2 Password recovery for target mode might involve guessing the /dev/tty* entry and using DirectoryServices commands like `dscl -f /Volumes/G5_Disk/blah localonly ...`, though it may be too new for this approach. 3
