_XSGISetSpecialDestroyHandler

Claims: 6

libGL loads with dlopen and calls _XSGISetSpecialDestroyHandler, which requires linking with a specific X-related library. 1 The issue is due to a missing symbol _XSGISetSpecialDestroyHandler in libXext from SGUG RSE, which is present in the version from Irix. 2 The function _XSGISetSpecialDestroyHandler is private API and not publicly available, and its expected signature can be found in a header file. 34 The callback set by _XSGISetSpecialDestroyHandler may not be called until the application quits. 5 It is possible to generate a C file with this function doing nothing or returning 0, but expect issues with OpenGL context management. 6
