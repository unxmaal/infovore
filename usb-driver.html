USB driver

Claims: 7 Part of USB

The USB driver code is now in the public domain. 1 To build the USB driver, you need mips 7.4 gcc, bash, and a 64-bit or 32-bit kernel, and the driver crashes the kernel if something goes wrong. 2 The driver enumerates USB devices but doesn't perform other functions. 2 To make progress on a USB driver, start by getting it to build reliably and fix errors one by one, committing changes. 3 Writing a USB driver for IRIX requires implementing the entire USB stack and exposing block devices. 4 The USB driver supports the xfs file system and allows reading and writing to USB sticks, but the fat32 driver from user-3e2d does not mount fat32 USB sticks. 5
