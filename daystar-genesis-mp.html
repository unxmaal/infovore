Daystar Genesis MP

Claims: 7

The Daystar Genesis MP is a multi-CPU machine that supports symmetric multiprocessing, though full utilization of the second processor requires programmer intervention. 12 Its motherboard is essentially a 9500 with a custom ROM, allowing the use of any compatible CPU module, and it features a superior case design compared to the 9500's Quadra case. 34 It can run with the CDROM as a lower SCSI ID while booting from the HDD. 5 Classic MacOS can run on the machine, though with limited support for the second processor, and Linux can potentially run on it using bootx. 67
