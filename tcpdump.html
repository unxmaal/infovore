tcpdump

Claims: 4

tcpdump is a tool used to view network traffic between devices, and installing it (or Wireshark) on a device such as a Raspberry Pi can help diagnose network issues, including confirming network booting by checking whether a machine downloads the loader and kernel. 123 tcpdump can be used to filter ARP traffic or exclude SSH traffic. 1 In one observed case, tcpdump captured a machine receiving the full bootloader, then receiving a binary piece generated by RIS that includes the hostname, after which the machine sent a MOP packet containing the hostname but received no response. 4
