GNU ld

Claims: 10

GNU ld is a linker that is not fully compatible with lld, but lld can be adapted to work with it using regex. 1 Unlike GNU ld, IRIX ld requires that symbol references be resolved before they are called, which can be wasteful. 2 When linking MIPS code, symbols must be referenced before they are linked, and using GNU ld requires caution with mixing object files from different compilers, with known issues on IRIX. 3 Using gcc and GNU ld can resolve compilation issues with ncurses, and the 'undefined reference' issue with GNU ld can be resolved using the -Wl,<flag> argument. 45 The GNU ld on an IRIX Octane workstation generates a ROM binary that is 100% garbage when converting sm64.u.elf to sm64.u.bin, but this issue is due to problems with IRIX libraries, not GNU ld. 67 The system linker is preferable to GNU ld on IRIX, but GNU ld should work, and the native linker may not be compatible with GNU ld on IRIX, but it's possible to get it to work with the right RPMs. 8910

  7. The IRIX ld issue is due to problems with IRIX libraries, not GNU ld. (user-1446, 2020-09-28, exchange 11220, check: uncheckable)
