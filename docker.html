Docker

Claims: 17

Docker is a form of OS-level virtualization similar to Solaris zones, functioning as a kernel-level process jail with a layered filesystem, and it is not meant to be a VM but can work at a small scale. 123 It is better to run one process per container, such as a separate container for the web server and app. 2 Docker can run on any system that supports it, enabling tasks such as running Genera (an emulator for Symbolics Lisp Machines) and performing hand computation tasks on an IRIX box. 45 Docker is not available on IRIX, but distcc can be set up with a Docker container for the compiler to compile on IRIX. 67 The DGX from Nvidia provides a minimal Linux install and certified Docker instances. 8 socat behaves differently when run inside Docker compared to outside, specifically sending RST packets inside and FIN packets outside, and missing data frames. 9 Bootp would not work with Docker's networking stack, and the same issue occurs when using host-only networking mode with Docker. 1011 Setting a Docker container's network mode to host can allow bootstrapping SGI from it, and the SGI-L2-Docker project provides a way to run L2 software in a Docker container. 1213
