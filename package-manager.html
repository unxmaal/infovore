package manager

Claims: 9 Part of package Background: 1 claim already covered by Wikipedia, see NetBSD.

Irxports is a package manager that builds from scratch and can handle uninstalls and dependency management. 1 NetBSD has a package manager that can be bootstrapped to other platforms. 2 Adding new community repositories to the package manager does not make it a new OS version; it's just the current OS with additional packages. 3 Native packages are preferred over snap/flatpak, source installation, barfing binaries into /usr/local or /opt, and mixing distro packages. 4 Inst is the easiest package manager for any old unix os. 5
