SCSI port

Claims: 7 Part of SCSI

The Wallstreet 2 had a SCSI port and a floppy drive, useful for interacting with older Macs, which were removed in the Lombard. 1 Any machine with a SCSI port capable of running Linux can clone SCA drives. 2 The SCSI ID 6 may not be compatible with the rear SCSI port, causing the error. 3 The SCSI port for the Fuel hard disks is above the top slot on the right, and a 9-pin serial cable can be connected to it and hooked to a Terminal with settings 38400/8/N/1 to access L1 by typing commands like `env off`, `help`, and `pwr u`. 45
