PATH

Claims: 24 Background: 1 claim already covered by Wikipedia, see Bash (Unix shell).

Environment variables like PATH are part of the shell. 1 PATH can be set in csh using 'setenv PATH /whatever/path' and in bash using 'export PATH=/whatever/path'. 2 PATH can be set in .profile, .bashrc, or .cshrc, and the current shell session should be modified to test the change. 3 Some shells have a rehash command that affects PATH and may take measurable time to execute. 4 Adding PATH=${PATH}:/opt/bin in the user's .login file can result in /opt/bin being added twice if the PATH variable is already set, leading to duplication in the final PATH. 5 Adding paths universally can cause issues with internal startup scripts, and root's shell should not have funky replacements for standard system utils in its PATH to avoid flummoxing init scripts. 67
