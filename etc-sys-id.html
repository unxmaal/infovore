/etc/sys_id

Claims: 4

The file /etc/sys_id stores the system name used in console commands, such as those created by EZSetup. 1 Changing the system name requires updating /etc/sys_id and /etc/hosts to avoid losing networking. 1 To set up an IRIX Octane for network access, /etc/hosts and /etc/sys_id must be correctly configured with the Octane's IP and hostname, then the network service restarted. 2 To change the hostname, update /etc/sys_id, /etc/hosts, and /etc/resolv.conf, then reboot. 3 Sanity checking /etc/sys_id and ensuring the hostname is correct can help with networking issues. 4
