Tiger

Claims: 24

Tiger is a version of Mac OS X for PowerPC hardware that supports Classic mode, WPA2, and Tenfourfox, and can run OS 9 software on some machines. 12 Tiger is generally considered faster and less resource-intensive than Leopard on PPC machines, with some users reporting it as the best-performing version alongside Cheetah and Puma having issues. 34567 Tiger performs well on G3s and early G4s with sufficient memory, runs fine on G4 Minis with half a gig of RAM, and can boot in 2 seconds on the G4 Cube. 879 Tiger is less resource-intensive than Leopard, though some applications such as Blender and Wings3D run slower or require prerequisites not available in Tiger. 41011 PPC packages are still being made for Tiger or Leopard, and Tiger brew requires Leopard as a minimum for many packages. 1213 The 'Mac OS X for PPC' page on The Garden lists all versions, including a 4-CD set for Tiger, and the Tiger installer can be launched from Panther but the CD cannot be booted from OpenFirmware. 1415 Restoring an image using Disk Utility works with Leopard but not Tiger, though enabling compression and read-only in the dmg file fixes the issue in Tiger Disk Utility. 16 VirtualBox emulates Intel-based systems, so anything before Tiger won't work due to architecture, and running Tiger or better is preferred for software selection and performance. 1718
