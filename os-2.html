OS/2

Claims: 57 Background: 3 claims already covered by Wikipedia, see OS/2.

OS/2 expects the 386 segmentation and ring model to work. 1 Microsoft approached IBM about licensing OS/2 under the Windows name, but IBM declined. 2 OS/2 supports basic Windows applications, Indeo video compression, and SciTech's Display Doctor, but not Direct3D. 345 OS/2 requires a boot manager for MCA systems and may not recognize MCA IDE cards by name, though it should treat them like other IDE controllers from the era. 67 The second OEM release of OS/2 was by an unknown company, with the first by Zenith Datasystems. 8 JFS was used in OS/2 between versions 4 and 4.52. 9 OS/2's installation process is complex, requiring multiple diskettes and a CD, with careful partitioning and multiple reboots, and it can be remarkably brittle. 1011 OS/2's server components are difficult to configure, making it less ideal for server roles, and it can be difficult to install even on compatible hardware. 1213 OS/2's boot manager can be used for dual booting with other operating systems, and it can support multiprocessors, though a version supporting SMP is needed to make it faster. 1415 OS/2 can be networked using NetWare without special editions or add-on products, and a 32-bit multithreaded OS/2 console application can call 16-bit NetBIOS APIs. 1617 OS/2 has been used on some single-purpose devices like PBXs, and ATM's still run OS/2, though Microsoft's actions affected its market share. 1819 The O&G sector can provide old OS/2 install sets including FactoryLink installers, and the BAR-97 has a P1 CPU running at 100 MHz and runs OS/2. 2021 Setting the base to vga instead of xga can resolve display issues with OS/2, and OS/2 does not support LAT theoretically since the 90s. 2223
