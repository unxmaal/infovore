AIX

Claims: 170 Background: 29 claims already covered by Wikipedia, see IBM AIX, QEMU, A/UX, OpenGL, Oracle Solaris, VirtualBox.

With Solaris

AIX, Solaris, HP-UX, and IRIX are all hybrid Unix systems that are not 'pure' SysV or BSD. 1 AIX is more challenging than Solaris, and it seems to be missing weird pieces the way Solaris and IRIX are not. 234 AIX, Solaris, and IRIX could run on non-special hardware, and all major Unix workstations including these were 64-bit capable by 1999. 56 Swapping over NFS was supported by Solaris and AIX, along with SunOS, IRIX, Ultrix, and HP-UX. 7 AIX and Solaris are among the Unix versions used for various software, and both are still offered with certifications by IBM and Sun respectively as the last two commercial Unix vendors. 8910

General

AIX is one of the surviving commercial UNIX systems, still actively supported with IBM still producing POWER chips. 1112 AIX runs on IBM hardware, including pSeries, Power5, Power6, and System i machines. 1314 AIX can also be run on non-IBM hardware, such as PowerPC systems like the Q950, ANS, Talos II, and Motorola AT boards, as well as on PS/2 systems requiring a 386 or better. 1516171819 AIX can be run in a VM on x86 PCs or via QEMU, but only with a serial console. 201721 AIX has its own kernel located at /unix, with userland derived from BSD, and it still ships an X server. 222324 AIX is reliable but difficult to use, with a menu-based system called smit or smitty for installing packages. 2526 AIX is a version of UNIX that is tightly integrated with the hardware and is managed through CLI-based utilities such as smitty, which provides terminal and text console administration and can output commands. 272829 AIX runs on PowerPC and Power chips, and on modern POWER hardware it requires PowerVM, which allows it to coexist with Linux. 3031 IBM is still developing AIX and has released version 7.3, which includes the pigz command and zlibNX library for Power9 and Power10 servers. 3233 AIX can also be run on IA-64 hardware, and there is a software emulator for the 5080 with references to AIX and Windows versions. 3435 AIX was written in PL/I. 36 AIX is a Unix operating system that continues to be supported by IBM, even as most other commercial Unix systems have declined. 37 AIX has its own first-party package management, including first-party RPM packages, as well as open-source Bulle/Atos packages. 38 AIX has long-standing support for GCC, with version 13.2 remaining supported on 5.3L, and PowerPC support is still present in GCC versions. 3940 AIX provides first-party support for most things important enough to have on the system, and building software on 5L should not be too difficult. 41 AIX includes the SMIT tool, which can display the commands it is running, and offers smitty as part of its interface. 4243 AIX is noted for its install process, package management, and robust disk and filesystem features. 43 AIX has very nice device enumeration. 44 AIX `ld` and `ar` require specific flags to work correctly. 45 AIX is a Unix operating system that runs on IBM's RISC hardware and POWER processors, and it requires this IBM hardware for use. 4647 AIX is not based on sysIII/sysV, and it uses rpm for package management. 4849 AIX can be installed from a CD, which IBM made easy, and it can also be installed from an empty hard drive using a BlueSCSI emulator to emulate the CD drive in about 30 minutes. 5051 AIX can import volume groups using the System Management Interface Tool (SMIT), even for complex setups involving multiple disks and volume groups. 52 AIX backups use mksysb, which can be done with alt_disk, and for backing up an AIX disk, install it on a system with alt_disk support, then use mksysb to create a bootable backup. 5354 AIX allows resetting the root password via a secure method if the hardware is recent; otherwise, booting from a CD is an alternative. 55 Setting IPs is straightforward on AIX with Mobaxterm or xming. 56 AFS provides centralized file sharing and user control similar to Windows AD Domain on AIX. 57
