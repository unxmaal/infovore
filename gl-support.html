GL support

Claims: 8 Part of GL

The SGI RX2620 has a VGA output, but Runelite may fall back to software rendering due to lack of GL support. 1 Dual graphics can provide better GL support but is quirky and not recommended. 2 GZDoom requires modern GL support, which IRIX lacks. 3 The SDL2 libs from SGUG-RSE lack GL support, so an SDL2 package specifically built with GL support enabled is needed for running SDL2-GL tests and Homeworld-SDL. 45 Building SDL2 with GL support is necessary for certain SDL2-GL tests and Homeworld-SDL, and the package includes GL support and may have additional debug printouts. 6 SDL2 2.0.14 with GL support was compiled based off the work of user-22f9, with fixes and porting, and will be improved in nekoware. 7 The game wipEout can be downloaded and run on IRIX using SDL2 with GL support, which is not supported by the SDL2 from the SGUG-RSE repo. 8
