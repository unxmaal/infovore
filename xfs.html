XFS

Claims: 139 Background: 68 claims already covered by Wikipedia, see XFS, IRIX, ZFS, Autodesk Maya, OpenGL.

XFS can handle large hard drives and files exceeding 8 GB, supporting up to 1 TB on 32-bit systems and unlimited sizes on 64-bit systems, though the 1 TB limit is due to PROM limitations rather than XFS itself. 123 XFS supports timestamps from December 1901 to July 2486, a feature not enabled by default for backwards compatibility. 4 XFS was adopted on Linux, providing robust filesystem features that made Linux more viable for business use, and it remains the default root filesystem on some enterprise distributions such as RedHat. 5678 XFS is not multi-writer by itself but was one of the first filesystems with clustering support, and it is considered good for performance. 91011 XFS can be mounted on Linux and WSL1, and it can be tagged as xfs in GPT/MBR partitions or SGI disklabels using fdisk. 12131415 XFS can format DVD-RAM discs as XFS, UDF, or EFS on IRIX 6.5.22 and up, and xfsdump and xfsrestore preserve attributes for copying data between disks. 1617 XFS is limited by the disk label format to 32-bit sector values, and some software behaves oddly with XFS, causing demo failures. 1819 XFS is a filesystem developed by SGI, and it was ported to Linux from IRIX along with some clustering software, Maya, and Discreet software. 2021 XFS is supported in IRIX 6.5.22, which can handle up to about 8 exbibytes with XFS. 2223 XFS is typically formatted with 4k block sizes. 24 Red Hat uses XFS and LVM instead of btrfs, and RH 7.x used XFS in production. 2526 Redhat uses clustered XFS, which may lose some legacy support but is favored by commercial software. 27 XFS will not be dropped from Linux as it is one of the best file systems for the Linux kernel. 28 XFS has issues with large disk sizes on specific Intel CPUs from Sandybridge and earlier, and the Gentoo distribution kernel project often fixes bugs, such as those related to SandyBridge and XFS inode sizes. 2930 XFS support was removed in 10-CURRENT because it lacked the required locking improvements to keep up with VFS changes, making it a read-only hack for data migration. 31 XFS can handle large amounts of storage. 32 Formatting time is not significant with XFS or modern Linux filesystems. 33 XFS changes the on-disk format, so disks formatted in IRIX 6.5 may not mount in IRIX 6.2, and the miniroot of the original install CDROM cannot read the installed system disk. 3435 To clone an XFS drive on an Octane2, use fx to repartition and format, then xfsdump and xfsrestore to copy the data, and manually transfer header files. 36 XFS on LVM can be backed up with xfsdump. 37 Rendering to XFS is possible if the disk is fast enough, though XFS is the raw Jaleo format. 3839
