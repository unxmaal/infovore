netaddr

Claims: 5

The netaddr is a PROM environment variable that must be set to match the local network settings and a specific IP address, though the rationale is not always explained. 12 To connect to an Octane via booterizer, the netaddr is set to the clientip configured in Booterizer's settings.yml, then the machine is booted into the partitioning utility with `bootp():/6.5.22/Overlay/disc1/`. 3 To boot an IRIX machine via bootp, the netaddr is set to the server IP and specific commands are run. 4 The netaddr is only used during ARCS boot and is ignored by IRIX once it boots, which can lead to potential IP address conflicts. 5

Sources

  1. Booterizer instructs you to set the netaddr to match your local network settings and a specific IP address, but doesn't explain the rationale. (user-17cb, 2019-12-31, exchange 77040, check: uncheckable)
  2. You need to set a PROM variable with the address (`setenv netaddr 192.168.1.100` for example). Your Linux box will need a static address (e.g. `192.168.1.101`), then they should see each other. (user-0bb7, 2025-09-20, exchange 225462, check: supported)
  3. To connect to an Octane via booterizer, use the command monitor to set the netaddr to the clientip configured in Booterizer's settings.yml, then boot into the partitioning utility with `bootp():/6.5.22/Overlay/disc1/`. (user-9849, 2020-06-15, exchange 9060, check: supported)
  4. To boot an IRIX machine via bootp, set `netaddr` to the server IP and run specific commands. (user-6dfb, 2024-11-21, exchange 50682, check: supported)
  5. The `netaddr` setting in the PROM environment variables is only used during ARCS boot, and is ignored by IRIX once it boots, leading to potential IP address conflicts. (user-baf6, 2026-09-21, exchange 214696, check: supported)
