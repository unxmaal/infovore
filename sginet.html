sginet

Claims: 18

SGInet is a service that supports machine listing, software search, an online updater, screenshot uploading, and reports uptime and online status on an opt-in basis. 1 The sgi.db file contains package information from all SGI discs and can be used to seed SGInet's package search function, though SGInet's software search does not include IRIX install media. 23 SGInet can be integrated with an Algolia indexer for search functionality, and sginet-light can be added to the system list on sginet. 45 The command to take a screenshot in IRIX is scrsave or sginet, which uploads to the cloud as a PNG. 6 sginet can be upgraded to show uptime and has an integrated updater in newer versions. 7 The command to update SGINet is 'sginet -u', run as root. 89 sginet-light does not require any dependencies and is offline, while sginet requires -lcurl -ljson-c -lncurses -lform -lpanel. 10 The sginet client version V20260318-1105-CLI includes an option --renamesystem to change the host name listed on sginet.user-7973.io, but it does not work with sginet-lite. 11
