GNU/Linux

Claims: 16

GNU/Linux is the preferred way to write the term, which is the RHS name for gnu/linux with all 'gs' dropped. 12 GNU/Linux on commodity IBM-compatible hardware outcompeted SGI systems over time, and eventually replaced commercial UNIX on big iron systems where Windows NT did not fully do so. 34 GNU/Linux is available for IA-64, including on SGI IA-64 systems, which are limited to Windows, outdated GNU/Linux distributions, and a few other operating systems. 56 SGI hardware can run OpenGL programs on IRIX, GNU/Linux, and Windows with minimal changes, and Open Scene Graph is a C++ and OpenGL library running on multiple operating systems including Windows, macOS, GNU/Linux, IRIX, Solaris, HP-UX, AIX, and FreeBSD. 78 GNU/Linux has a different internal structure from IRIX, with a distinct scheduler and closer similarities to Solaris. 9 Many GNU/Linux distributions can be leniently considered UNIX-compatible if they can install a C compiler without extra hurdles. 10
