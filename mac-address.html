MAC address

Claims: 39 Part of Mac Background: 2 claims already covered by Wikipedia, see MAC address.

The MAC address is stored in various hardware components depending on the system, including non-volatile RAM, a Dallas chip, an EEPROM, the frontplane, the PCI riser, the ethernet riser, or the IO board, and it is linked to the case rather than the CPU board. 123456789 The MAC address can be programmable, and reprogramming it was an undocumented feature, though editing the PROM with a hex editor is required to update it on an Indigo2. 10811 The MAC address is used as a unique identifier for the system, appearing in the PROM's ARP response and serving as the lmhostid in IRIX, where it is also used to bypass node lock licenses. 121368 The MAC address may need to be reset or set manually in situations such as installing IRIX, when the PROM battery dies, when the address is corrupted or lost, or when spoofing is necessary for installation. 14151617 An invalid or incorrect MAC address can cause problems, including system crashes, error popups, the system failing to recognize itself, the router ignoring the address, or the system booting into diag-switch? true mode. 181920212223
