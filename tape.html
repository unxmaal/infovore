tape

Claims: 34 Background: 2 claims already covered by Wikipedia, see Floppy disk, Tape drive.

Tape has been used as a boot and installation medium for various systems, including the Personal Iris (which can boot from tape and displays a NeWS login screen), IRIX (versions 5.3 and 6.2 supported tape installations, and 4D1/IRIX 3.x was available only on tape, not CD), MSDOS (bootstrapping is possible, as done for the 5150), and other operating systems via tape-supporting installers. 1234567 Tape is preferred by some for storage because physical media like tape is manufactured to precise tolerances and can handle abuse, whereas analog tape has a shorter lifespan due to manufacturing and storage conditions. 89 LTO won the tape war against AIT, and digital tape is still used for archiving, though tape usage is largely obsolete with only some XDCAM/Professional Disc hardware still in use. 101112 Tape can suffer from hardware and media problems, such as `tar` encountering input/output errors when reading from tape, old 3M DC6150 cartridges whose belts snap and whose capstan rollers can melt, and VMS software on tape being harder to find than software on CDs. 131415
