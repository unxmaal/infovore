Booterizer

Claims: 170 Background: 2 claims already covered by Wikipedia, see Ansible (software), SGI O2.

With IRIX

Booterizer is a tool to install IRIX, recommended for IRIX installations on SGI systems. 12 It can install IRIX on an Octane and possibly an Indy. 3 It simplifies installation by automating DHCP, TFTP, and rhosts setup and fetching install media, generating the selections file. 4 It can also install IRIX by copying files from a virtual machine to the SGI and using the selections file to uncomment and install specific packages, such as mipspro. 5 It can be used to install IRIX on a Raspberry Pi, which is surprisingly simple. 67 It can be used to install IRIX, along with LOVE and Reanimator. 8

General

The Booterizer project, which moves irixboot, is designed to make IRIX development environments easy to reset by providing a fresh base install of IRIX 6.5 and reducing the risk of system changes.
