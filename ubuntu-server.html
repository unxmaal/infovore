Ubuntu Server

Claims: 5 Part of Ubuntu

Ubuntu Server is one of the alternatives to Raspbian for the Raspberry Pi, alongside Ubuntu MATE and Ubuntu Core. 1 Ubuntu Server has good support compared to regular Debian. 2 The controller can run a VM with Debian or Ubuntu Server, but integrating VLANs with a different core system is challenging. 3 Ubuntu server installs can reference SGI code, indicating some SGI technology was open-sourced. 4 For Ubuntu Server minimal installs, the size can be reduced to around 300-400MB by removing unnecessary packages and setting up a custom installation script with options for package selection. 5
