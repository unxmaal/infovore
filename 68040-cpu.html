68040 CPU

Claims: 5 Part of 68040

The HP 9000 series 300 workstations used a 68040 CPU with onboard SCSI, high-resolution color video, and networking. 1 The IIfx requires a full 68040 CPU to run A/UX natively, and the Quadra 610 can run A/UX with a 68040 upgrade. 2 A 68040 CPU without an MMU is needed for a 610 upgrade. 3 The Quadra 650 has a 68040 CPU running at 33 MHz. 4 A 2.4-era desktop box had two ethernet interfaces, eth0 and eth1, which were swapped on every reboot. 5
