X11

Claims: 84 Background: 8 claims already covered by Wikipedia, see X Window System, FFmpeg, OpenGL, Wayland (protocol).

X11 is the windowing system layer in Unix or Linux, built on top of a command prompt base system; Xorg is an open source X11 implementation, and KDE is a desktop environment that includes a window manager and other tools. 1 X11 clients connect to a server to display graphics, contrary to typical expectations where servers run software and clients display it. 2 X11 applications can be run remotely with success, though not everything works. 3 X11 over network involves CPU handling interrupts, DMA, and framebuffer updates, making it inefficient for graphics streaming. 4 A display on X11 can have an independent set of input/output peripherals. 5 Under X11, multiple screens can have a single root window, while a single logical screen created from multiple physical monitors has a separate root window for each monitor. 6 X11 requires a keyboard but not a mouse for firmware. 7 UNIX systems running X11 originally required the middle mouse button, which is useful for many applications; Plan 9 does not support middle-button functionality. 8 X11 was introduced in IRIX 3.3 and is included in IRIX 3.3.2, 4D1-3.3.2, and versions 11.23 and 11.31. 91011 X11 is a client/server protocol in which most X calls go through the network, though some implementations can bypass this for local clients. 12 X11 uses resources for arbitrary configuration strings that clients can query, such as defining colors and font faces. 13 X11 is considered outdated and causes issues with some users. 14
