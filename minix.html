MINIX

Claims: 10 Background: 1 claim already covered by Wikipedia, see FreeBSD.

MINIX is an embedded operating system that never advanced beyond a research project for a college class. 1 MINIX can run on AT-class machines, though modern versions require a 386 or better processor, and the latest versions require a Pentium (i586). 23 MINIX has a port for the Atari ST. 45 MINIX shares a logical connection with Linux, as Linus studied MINIX and used its file system in early versions. 6 The Intel Management Engine is based on MINIX, with x86 Quark core-based MEs running MINIX. 78
