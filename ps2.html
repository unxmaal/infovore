PS2

Claims: 137 Background: 17 claims already covered by Wikipedia, see PlayStation 2, USB, IBM AIX, RDRAM, Floppy disk variants, MIPS architecture.

The PS2 is a retro machine prone to hardware failures, prompting interest in FPGA cores as a potential future solution. 1 The PS2 has 32MB of RAM, loud fans, and its R3000 CPU handles both PS1 emulation and input/output tasks. 234 The PS1 and PS2 have firmware and a Unix-based OS in their BIOS, and the PS2's CPU is incompatible with IRIX. 56 The PS2 can run AIX 1.3 and uses an IDE to SATA converter for its HDD. 78 The PS2 can output up to 1920x1080, and its startup screen is stored in the first 16 sectors of the disc and is encrypted. 910 PS2 discs have wobble sectors that are pressed onto them and contain the key encoded in the wobble. 11 A network adapter is required to netboot games on a PS2, though the SATA version of the network adapter does not have the Ethernet port actually connected. 1213 PS2 emulation requires a 3.2GHz C2D minimum with an 8800GT GPU to emulate a 300MHz R5900, 32MB RAM, and 150MHz GPU. 14 The PS/2 designation refers to the type of device rather than the port, as some serial number checks identify a PS/2 mouse even when the port differs. 15 The PS2 uses MIPS CPUs, continuing the architecture from the PS1, before switching to PPC for the PS3. 16 The PS2 plays PS1 games by emulating the PS1 graphics chip in software on the Emotion Engine while running PS1 code natively on the MIPS R3k core of the IOP, though only about 5% of the PS1 library is unplayable due to minor issues. 17 Retail PS2 units typically have 32 MB of RDRAM, while developer units often have double or triple that amount. 18 The PS2 has copy protection that disables modchips if a memory card is present at power-on, but plugging in the memory card after the disc starts loading can bypass the check. 1920 A debug monitor can be used to probe the entire PS2 system, and similar steps exist for debugging the graphics system. 2122 PS2 games access the CDVD drive via an RPC call from the EE to the IOP, which can be modified to read from a hard disk instead. 23 The T14K was a DVD emulation module for PS2 development. 24 The PlayStation 2 (PS2) is a game console that uses a heavily enhanced R4000-based MIPS processor with vector extensions, and it is one of only a few game systems (alongside the Nintendo 64 and PSP) to feature MIPS processors. 2526 The PS2's CPU is a variant of the R5000 with 128-bit matrix extensions, two vector units, and DMA pipelines, and it uses XDR and RD-RAM, which may have provided higher bandwidth and allowed for board cost reductions. 272829 The PS2 supports hard drives and USB devices, can use SATA drives, and supports ATAPI disc drives. 303132 The PS2 is robust and can still work even with significant damage, and service guides for PS2 revisions exist and include schematics. 3334 The PS2 was marketed as a supercomputer, and its FPU lacks support for doubles and is about half as fast as a Pentium MMX @ 233 MHz for scalar code. 3536 The PS2 runs its MIPS CPUs in little-endian mode exclusively. 37 The PS2 is Turing complete, so anything can be emulated on it. 38 It is little-endian and uses a complex scheduling mechanism to balance work between the CPU, VU, and triangle blitter, which affects its performance. 3940 The PS2 can be overclocked due to a shared base clock between the GS and EE. 41 Its configuration files are not bloat and should be editable with a standard text editor. 42
