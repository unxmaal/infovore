RTC battery

Claims: 9 Part of RTC

A failing RTC battery can cause system time issues or crashes, and if the battery is dead the system will default to serial. 12 The RTC battery is located under the CPU fan/cooler on the right side. 3 The RTC battery for O200/O2K/Onyx2 is an ST M48t35-70pc1, which is still available from Farnell/Mouser but has never been seen to run out. 4 AlphaBIOS requires a functioning RTC battery to run the ECU, while SRM is less sensitive to a dead RTC battery. 5 A replacement RTC battery is needed for powering on the machine from the front panel, and to fully functionalize the system the RTC battery needs to be modded and cosmetic touch-ups are required. 67
