ClassiCube

Claims: 19

ClassiCube is a Minecraft clone written in C that is being ported to IRIX, where it runs fairly well. 123 It can have flickering issues, possibly related to missing libraries or vsync settings, but runs without flickering on SGI Vizserver at around 30fps, flickering only when run on video out. 45 It also has audio issues with Ogg files on some SGI hardware. 6 Compiling ClassiCube requires linking against libraries in /usr/lib32 using the -Wl,--allow-shlib-undefined flag, and can link to libX11.so.1 instead of libX11.so.6 by adjusting library paths. 789 A patch to force double-buffering could improve compatibility, and a bgra bug related to ClassiCube has been fixed. 1011 Its SSL/TLS error can be resolved by using a newer OpenSSL, and the Singleplayer option can be accessed by starting it from sgugshell to ensure the correct OpenSSL is used for downloading resources. 1213 Running ClassiCube without arguments downloads resources, but the single player button in the menu does not function. 14 It requires T-RAM to run without snow cube on IRIX, and the Indy is too slow for it. 15
