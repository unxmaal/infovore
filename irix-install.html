IRIX install

Claims: 14 Part of IRIX

The hostname can be changed at any time, but it is safer to install the base IRIX OS first and add additional software such as demos afterward, since installing extras during the initial install might cause issues. 1 The SGI forums provide a guide for manually setting up an IRIX install. 2 A missing patch can cause a machine to splash to a black screen during an IRIX install, which can be resolved by applying the patch. 3 Every IRIX install can mount NFS shares as part of the base installation. 4 A Seagate drive with a newer IRIX install from an Indy will not let the user wipe the drive, and the fx version of the installer has issues creating a filesystem, stopping at 4190 blocks and making unusual noise. 5 The IRIX install can be checked with diagnostics from the PROM. 6 A fatal error and compilation terminated indicate that the compiler failed to find necessary headers, suggesting an incomplete IRIX install without development libraries. 7 The IRIX install includes the IDE diagnostics, which can be run from the hard disk or install media. 8
