efs2tar

Claims: 12 Part of EFS

efs2tar is a command-line tool that reads EFS-formatted CD image dumps, which are common for SGI CDs, and can handle .iso or .img files in the correct format. 1 It extracts EFS filesystem contents into tar files, requiring a specific path and arguments, and requires an absolute path or --help for error handling. 23 It can be installed using Go via `go get github.com/sophaskins/efs2tar` and `go install github.com/sophaskins/efs2tar`. 4 It is a usable tool for converting EFS CD images but has poor documentation, and it may not work on OpenBSD. 56 Memory issues can cause efs2tar and similar tools like efsextract to fail. 7
