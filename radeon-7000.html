Radeon 7000

Claims: 12 Part of Radeon

The Radeon 7000 lacks hardware T&L, has only one pixel pipeline, a 64-bit memory bus, and no HyperZ, and it supports OpenGL 1.3. 12 It has VGA output but not ADC. 3 Drivers exist for HP-UX (with AGP FireGL cards), Solaris on SPARCs (with Mach64 and Radeon 7000), and it is suitable for Windows or Mac OS. 456 In a G3, a Radeon 7000 runs GLQuake slightly faster than a Voodoo3 2000, can be used with a patch to enable Quartz Extreme, and the G3 300 Minitower can be overclocked to 458MHz with 768MB RAM and a Radeon 7000. 789
