CMake

Claims: 28 Background: 11 claims already covered by Wikipedia, see CMake.

CMake is a build system used to configure and build projects, with typical commands being `mkdir build && cd build`, `cmake ../`, and `make`. 1 It is useful for cross-platform builds, working on all platforms, though its design is considered inelegant and awkward. 234 CMake can be used to specify not to use system libraries like libpng, and to add linker options via TARGET_LINK_LIBRARIES. 56 It can be used with MIPSPro, and certain flags like `-fpermissive` may need to be passed through the `CMAKE_C_FLAGS` variable. 789 CMake is available on IRIX and included in RSE, but it thinks it's Linux, which can cause issues. 1011 It has IRIX support for its Linux version but not for macOS, and it is not available on SGUG or another repo. 1213 Building projects with CMake may require a high version, such as above 3.14 for ioquake3, which is not supported by IRIX. 14 Some builds require dependencies like libuv, which may not be available on vintage systems, and cmake itself may need to be installed first. 151617
