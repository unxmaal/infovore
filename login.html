.login

Claims: 7

.login is a login script that performs various tasks, while .cshrc is a configuration file for the C shell and .profile is run if the shell is /bin/sh or possibly bash. 1 Adding a 'stty rows 25 cols 80' line to .login, .profile, or .cshrc sets the terminal size, and setting TERM, MANPATH, EDITOR, and BROWSER in these files configures the environment. 2 A user changed .login to bash and set autologin with no password, allowing direct login after restart. 3 Enabling login is required for serial connection access. 4 IRIX slowdowns on boot and login can be optimized with systune. 5 In A/UX 2.0, the About box for Login displays the developer's signatures. 6 The SGI IRIX 7.1 demo is missing some files like .login, .icons, and .auxchestrc, but can still be used without them. 7
