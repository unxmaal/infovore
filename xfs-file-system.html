XFS file system

Claims: 17 Part of XFS Background: 1 claim already covered by Wikipedia, see IRIX.

XFS is a file system supported by IRIX 6.5.x that can support sizes up to 8 exbibytes. 1 Mounting an XFS file system in IRIX is done with the mount command using the appropriate device and mount point. 2 XFS can help with large disk operations, and its repair capabilities can fix corruption issues. 34 Shrinking an XFS file system is not supported; data must be backed up, a new partition or file system created, and the data copied back. 5 XFS journaling has had compatibility issues, with ext3 and ext4 journals not being compatible when ext4 was released. 6 A new disk in an O2 experiencing XFS errors after a few days may indicate issues with the power supply or power in general. 7 The USB driver supports the XFS file system and allows reading and writing to USB sticks, but the fat32 driver from user-3e2d does not mount fat32 USB sticks. 8
