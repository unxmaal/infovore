tiles

Claims: 3 Background: 1 claim already covered by Wikipedia, see Framebuffer.

Pixel buffers must contain an integral number of tiles. 1 CRIME has 3 tiled TLBs holding 64 entries each, and for 32-bit pixels, each tile is 128x128. 2 Framebuffer dimensions do not need to be aligned to tile boundaries but must require an integral number of tiles. 2 A 1920x1024 framebuffer uses 15x8 tiles (120 total), while a 1920x1080 framebuffer uses 15x9 tiles (135 total), exceeding the 128 available tiles. 3
