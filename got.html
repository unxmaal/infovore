GOT

Claims: 4

The MIPS linker uses a global offset table (GOT) for position-independent code. 1 The MIPS addressing scheme limits indexed mode to 16k entries, each 4 bytes, because GP points to the GOT. 2 The MIPS ABI requires GOT entries and small data area data to be accessible with a single instruction using a 16-bit displacement, limiting the size of .got/.sdata/.sbss to 64 KiB. 3 When GOT has more than 16k entries, the toolchain fails to produce a relocation entry for um, causing init code to fail. 4 This makes LTO inapposite. 3

Sources

  4. The toolchain fails to produce a relocation entry for um when GOT has more than 16k entries, causing init code to fail. (user-42cf, 2021-06-08, exchange 217147, check: supported)
