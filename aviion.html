AViiON

Claims: 6

The Omron Luna represents the peak of the m88k architecture, while the AViiON is a different class of machine. 1 Some AViiON versions with many CPUs were not PC-compatible, similar to the VW320/540, but were not intended for Windows or DOS. 2 The AViiON cannot receive an RARP request, possibly due to a bad SCSI cable or CDROM drives, which prevents netbooting OpenBSD. 3 A switch failure prevented network access, but replacing it restored connectivity and allowed the AViiON to download the OpenBSD kernel via TFTP. 4 To find the commit for AViiON support, check the history of the OpenBSD newvers.sh file and view the repo at that commit. 5
