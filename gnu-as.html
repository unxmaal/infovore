GNU as

Claims: 3 Part of GNU

GNU as can use Intel syntax for RISC-V and ARM, but it must be explicitly set. 1 gcc requires GNU as on HP-UX for building, but GNU ld doesn't support HP-UX due to ABI mismatches. 2 Compiling code that includes sgidefs.h with GNU as instead of IRIX as may resolve an error encountered during compilation. 3
