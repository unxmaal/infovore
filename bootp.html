bootp

Claims: 42 Background: 13 claims already covered by Wikipedia, see Bootstrap Protocol.

BOOTP works by matching a client's exact MAC (network hardware) address to a specific IP address, which it deduces from the client's network hardware address, /etc/bootptab, or /etc/ethers and /etc/hosts files. 12 It uses a broadcast domain to forward packets, similar to DHCP. 3 BOOTP is not NAT-friendly and can cause issues with convenient network setups, and people often face problems with existing DHCP servers not supporting BOOTP. 45 It can be used to boot from a network via the boot command, PROM, or the command monitor, and the MAC address may need to be obtained from the network, switch, or a bootp server logfile. 678 Xterminals used BOOTP to configure themselves, TFTP to get firmware, and XDMCP to find a login host. 9
