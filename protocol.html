protocol

Claims: 5 Background: 1 claim already covered by Wikipedia, see USB.

A generic serial mouse probably won't work on a Power Series because it expects the SGI protocol. 1 Different vendors' buttons and dials use the same protocol but may differ in connectors and signaling (RS-232 vs 422). 2 Sun workstations use a proprietary connector called 'sun protocol' for keyboard and mouse, which can be converted to PS/2 using an OEM Sun box or similar device. 3 The Intuos3 uses a protocol for communicating tool usage that is not well-documented, and serial tablets are rare and expensive. 4 The protocol is the same but uses USB for transport. 5
