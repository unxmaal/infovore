gnulib

Claims: 4

Gnulib is a portability library that fixes issues such as the missing getline function on IRIX 6.5. 1 The gnulib shim can be used for C++ porting with specific environment variable settings. 2 nano did not successfully git clone gnulib on IRIX, hanging the process. 3 Building a new Linux kernel requires tools like module-init-tools, which may be out of date or non-existent in some Ubuntu versions, as well as newer versions of gnulib. 4
