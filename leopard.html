Leopard

Claims: 24

Leopard is a version of OS X that was a significant improvement over Windows XP and Vista, but it is slower and more resource-intensive than Tiger, especially on video cards and on G4 machines. 1234 Tiger can run OS 9 software, but Leopard does not support running OS 9 applications. 15 Leopard boots up in about 15 seconds, but Tiger boots faster than Leopard on a G4 PowerBook. 67 Many packages require Leopard as a minimum, including the Tiger brew, and compiling Wings3D for ppc requires XCode and Leopard. 89 PPC packages are still being made for Tiger or Leopard, and precompiled PPC versions of basic tools are available for Leopard. 1011 Java 6 can be installed on PPC MacOS Tiger via a developer preview available on Macintosh Garden, and on Leopard through software update. 12 git worked fine on Leopard and is normally more compatible. 13 Restoring an image using Disk Utility works with Leopard but not Tiger; enabling compression and read-only in the dmg file fixes the issue in Tiger Disk Utility. 14
