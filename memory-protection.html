memory protection

Claims: 5 Part of memory Background: 1 claim already covered by Wikipedia, see PDP-11.

Classic Mac OS, up to OS X, lacked memory protection and used cooperative multitasking, which could make it flaky and require unusual restarts. 12 A/UX used memory protection for its Unix components, but few applications used the Mac toolbox library. 3 The PDP-11 has memory protection. 4 Writing code without memory protection and masking interrupts can lead to immediate crashes due to overwriting interrupt vectors or code, but running it in ROM avoids these issues. 5
