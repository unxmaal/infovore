LLVM

Claims: 28 Background: 10 claims already covered by Wikipedia, see LLVM, Dbx (debugger).

LLVM has been ported to IRIX, with work carried out by user-cd7d up to version 37, and version 14.0.6 optimized for the mips64-sgi-irix6.5-gnuabin32 target; it is seen as a future compiler for IRIX, and a full rebuild using new LLVM and clang is required to avoid ABI or GOT memory mapping issues. 1234 LLVM has a MIPS backend but not a PA-RISC or HPPA backend, and it does not support MIPS3 or MIPS4 processors directly, only the MIPS32 and MIPS64 variants. 567 LLVM can be used to cross-compile, producing ARM code, and can provide performance improvements when used with ICC on Itanium. 89 LLVM supports Rust and Go among other languages, and Apple uses clang, a frontend for LLVM, for their compiler. 1011 LLVM has poor support for certain platforms, especially embedded and S/390, and porting it to a niche 32-bit RISC took significantly more time. 12 LLVM's stricter defaults make it harder to build older software. 13
