ncurses

Claims: 17

ncurses is a library that provides text window-based user interfaces and a promptable command line, and it is a distinct library from curses (the term 'ncursed' is a joke). 12 Building ncurses often requires manual configuration: the package's Makefile needs include and library paths set manually, and using both -I/usr/people/dillera/.local/include and -I/usr/people/dillera/.local/include/curses causes issues that are resolved with -DUSE_NCURSES_H and the correct path. 34 The build script includes <curses/ncurses.h>, but the ncurses headers are located in <ncurses.h>, which causes compilation errors. 5 Wide character support (for Unicode wide characters) can be enabled with --enable-widec during configure, though this wide support is not available on IRIX. 678 ncurses is used by several applications: qodem and weechat require wide character support, mutt can link against ncurses instead of ncursesw to avoid seg faults or bus errors, and the ncurses CLI mastodon client on IRIX is called nanotodon. 6910 Building git with Didbs depends on ncurses along with diffutils, grep, bash, openssl, curl, tk, and expat, and the sgug-rse toolchain includes ncurses and other pre-built packages to simplify builds without conflicts with didbs. 1112 ncurses may not be well-supported in winterm, aterm, or other terminals and may need to be avoided in CLI projects; weechat requires proper UTF-8 support to render box-drawing characters, and aterm and mrxvt issues are related to font configuration. 1314 Calling delwin() when leaving an info panel in a ncurses application can cause a segfault upon re-opening the panel, an issue resolved in version V20240713-2134. 15
