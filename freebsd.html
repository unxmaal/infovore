FreeBSD

Claims: 81 Background: 29 claims already covered by Wikipedia, see FreeBSD, Blender (software), Common Desktop Environment, Debian, Rust (programming language), Tcsh, ZFS.

FreeBSD is a usable, friendly, modern Unix environment used for servers, network-attached storage, and Juniper switches. 12345 It supports PowerPC systems, including being the most supported BSD option for IBM PowerPC, and runs on systems with as little as 512MB of RAM. 678 FreeBSD provides ZFS, which some users prefer over Linux for storage due to better file system integrity, and its ZFS arrays can run reliably for years. 91011 However, FreeBSD can break in production, be beyond repair, and is sometimes called FreeBSOD. 1213 Its kernel compilation can fail due to missing files or malformed conditionals, and it uses lld for x64/POWER/ARM64 instead of binutils. 1415 FreeBSD does not support autofs, instead using a daemon for automounting rather than integrating it like Linux and Solaris. 1617 FreeBSD and OpenBSD share an ancestor with IRIX. 18 FreeBSD is dropping support for 32-bit x86 architectures. 19 ZFS is interoperable between Solaris and FreeBSD with careful pool version management, though migrating off ZFS or to Linux-ZFS causes pain due to the rebase from OpenSolaris to ZOL. 2021 FreeBSD has good integration between its ports system, bhyve, and containers. 22
