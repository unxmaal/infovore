vsnprintf

Claims: 5

IRIX's vsnprintf returns the number of characters actually written instead of the buffer size needed, which is incorrect. 1 Solaris 2.5.1 includes vsnprintf, but the function is not included in the system libc of some Solaris versions, as indicated by the stdio.h header file while the linker error suggests it is missing. 234 To resolve the issue, include the vsnprintf source file directly in the build process without making it a library. 5

Sources

  1. IRIX's `vsnprintf` returns the number of characters actually written instead of the buffer size needed, which is incorrect. (user-6c80, 2024-05-09, exchange 215489, check: supported)
  2. Solaris 2.5.1 includes vsNprintf, but using glibc requires setting up the path and compiling with its headers. (user-7151, 2024-08-09, exchange 153270, check: supported)
  3. The vsnprintf function is not included in the system libc of some Solaris versions. (user-b1da, 2024-08-10, exchange 185345, check: uncheckable)
  4. The stdio.h header file indicates that vsnprintf should exist in the library, but the linker error suggests it is missing, implying the library does not include vsnprintf. (user-d5ee, 2024-08-10, exchange 185342, check: uncheckable)
  5. To resolve the issue, include the vsnprintf source file directly in the build process without making it a library. (user-b1da, 2024-08-10, exchange 185342, check: uncheckable)
