RS-422

Claims: 5

Some Mac serial cables use RS232 and others RS422, with the latter used for higher transfer rates. 1 RS422 geoports can be used as RS232, and a Mac mini DIN 8 RS422 to DE9 RS232 cable can work, though not guaranteed. 2 RS-232 with selectable baud rates up to 115.2 K is supported, with optional RS-422. 3 RS-422 mode on a serial port can be set using the 'startmidi' command or by linking /dev/input/MIDI3 to /dev/tty4d3. 45
