lmhostid

Claims: 5

The lmhostid is a small string obtained from the terminal. 1 It can be used to generate a license for Maya 6.5 installed on an SGI system using software from http://www.smigt.org/m65/. 2 For Maya 4.5, the keygen should replace 'HOSTID=lmhostid' with the actual lmhostid value. 3 Changing the lmhostid requires special hardware like an L2 or Router to zero out the lmhostid on the o350, which will then take the new hostid from the router or L2. 4 lmhostid reports 393 instead of 397; reseating RAM may fix it; fast memory test passed patterns 55 and ff; issue likely in the patcher that pokes values; considering if 393 is acceptable or trying another value could be. 5
