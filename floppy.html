floppy

Claims: 28 Background: 2 claims already covered by Wikipedia, see Apple IIc, Floppy disk.

On a classic Mac, holding the mouse button down while powering on should eject any floppy or CD-ROM if the system sees the drive. 1 On a BIOS this old it doesn't have its own setup utility; you need to bootstrap it with a floppy. 2 Linux can boot from a 1.44 MB floppy. 3 The IIc is a highly integrated Apple II with a built-in floppy and the only one with a GUI. 4 The tool uses the built-in debugger to write ADFs to floppy on an Amiga via serial without needing a bootable disk. 5 An I2 with a floppy can be installed in an Octane. 6 SGI made official disk cases for floppy, DAT, and CDROM drives. 7
