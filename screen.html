screen

Claims: 27 Background: 1 claim already covered by Wikipedia, see Screen printing.

The command `xwd -screen -out file.xwd` captures the screen in X11, though conversion to a more modern format may be needed. 1 `screen` has broken attaching somewhere between 4.0.3 and latest; the latest creates the socket just fine but the attacher can't use it with `socat`. 2 GNU readline can be annoying in bash, especially with screen, requiring custom bindings to improve usability. 3 Terminal emulators like alsamixer may display line drawing characters correctly on VT101 but may fail to do so when run within screen even if $TERM is set to vt100 or vt102, showing instead a single character where a line drawing character is expected. 4 `screen` and `cu` are classic serial terminal applications on UNIX, and on macOS, 'screen' defaults to 9600 baud while 'cu' can be used as an alternative. 56 For serial console, one can start with a known-working setup and use a USB-RS232 dongle with Minicom or `screen`. 7 `screen` can be built on IRIX 4 without coredumping upon detach, though it is difficult to use on IRIX 4 without issues. 89 `screen` is available on IRIX 6.5.30, while `cu` is not included by default but can be installed. 10
