VNC

Claims: 6

You can export your entire desktop over X11 or VNC, and VNC allows any client that supports VNC to access the entire desktop, though the X protocol offers more functionality. 12 Neither X nor VNC provide good graphics acceleration or 3D frame rates. 2 SDL2 games can run over VNC at low frame rates. 3 The Octane does not support GLX, so iconsmith cannot be run via VNC. 4 An O2 can have issues with GLX applications requiring X11 setup, and VNC into the O2 for remote access was challenging. 5 To run a file server on IRIX, install VNC for remote access. 6
