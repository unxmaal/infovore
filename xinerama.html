Xinerama

Claims: 4

SGI Xinerama is compatible with some but not all modern Xinerama-expecting applications. 1 IRIX's Xinerama has limitations, requiring OpenGL multipipe for splitting apps across two displays. 2 OpenGL MultiPipe allows enabling Xinerama for a GL environment between two pipes, and can also use DMX. 3 There is a main OMP guide from prior to the release of the Prism, which has info on using DMX or Xinerama as the base for multipipe support. 4
