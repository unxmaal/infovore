CPU module

Claims: 28 Part of CPU Background: 2 claims already covered by Wikipedia, see Computer fan, Heat sink.

The CPU module is bolted to the mainboard and can be removed, but doing so risks bending pins; an alternative is to use the hinv command to check CPU speed without removing the module. 1 Each CPU module contains at least one processor board. 2 The CPU module's PROM sets the multiplier, which is not locked. 3 The CPU module's heat sink is connected to the CPU via a thermal pad, with other components in the heat sink's vicinity. 4 The +12V power connector on the motherboard goes to J502 on the CPU module, and possibly also to a connector near the back of the tray for dual CPU modules. 5 The MPX can be connected to a bootable O3x0 or configured with a CPU-module, IO9, and SCSI-backplane to become a bootable O350. 6 To isolate a faulty component, reseat the CPU module and try different pairs of matching RAM sticks in the first two banks, comparing memory errors to identify the problematic part. 7 The CPU module requires a reflow oven for repair. 8
