Java 5

Claims: 5 Part of Java

The general prerequisites for Minecraft are Java 5 or newer, OpenGL 1.1 support, LWJGL 2, and 192 MB RAM. 1 Java 5 and OpenGL 1.1 are required for a port, and the fork supports up to Java 8. 2 The Java 5 source code is available, providing a roadmap for compilation. 3 Java 6 requires Java 5 or 6 to compile and was never ported to IRIX. 4
