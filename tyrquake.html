TyrQuake

Claims: 13

TyrQuake is a fully up to date bug fixed Quake source port with OpenGL v1 support, focusing on performance on low-end systems. It supports multiple BSD sound drivers and has improved OpenGL performance, especially on low-end systems. The source and makefile for TyrQuake can be found on the TyrQuake website. 123 To compile TyrQuake, you need to install the SDL-devel package(s). The Makefile for Tyrquake is currently set to build with SDL2, but there are issues with SDL2 on IRIX; forcing SDL1 might resolve these issues. 45 Tyrquake compiles on every other Unix OS. Tyrquake requires linking against libGLcore.so, which is causing issues due to undefined references. Compiling a TyrQuake binary requires the -Wl,--allow-shlib-undefined linker flag to resolve undefined references to SGI extensions, and the binary runs after applying this flag. 678 Tyrquake is mostly functional with restored luminance lightmaps and added full texture upload and multibuffering lightmap textures to cure lightmap glitches. Explosions in TyrQuake on the O2 can drop performance to 3-4fps and cause segfaults. The TyrQuake port by Dominik runs better than other versions of Quake1, but can be chuggy and crash to desktop on the O2. 91011 Tyrquake can be compiled on IRIX with some issues remaining. http://server/distdir/file.tardist can be used to execute inst commands from a URL instead of a local file. 1213
