spacenavd

Claims: 4

spacenavd is a free software re-implementation of the 3Dconnexion driver, providing a UNIX domain socket interface and a compatibility interface for existing applications. 1 spacemice require the 3dxsrv or spacenavd driver, while spaceballs should work with xinput. 2 Controls were adjusted and work well; the game can be controlled with a spaceball/spacemouse using vendor drivers or spacenavd, with 6DOF control being more satisfying. 3 Compatibility commits have been made to allow spacenavd and libspnav to build cleanly with MIPSpro on IRIX 6.2, though gmake is still required. 4
