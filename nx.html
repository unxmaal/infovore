NX

Claims: 13

NX is a single-package CAD program that integrates many features and supports STEP files for model transfer between software. 12 NX and CATIA dominate the high-end segment of the CAD market. 3 Daimler switched from CATIA to NX for their entire company in 2015. 4 NX is more expensive than SolidWorks but not ridiculously so for a large company. 5 NX lacks a loft command, requiring users to create surfaces manually and stitch them together, despite both SolidWorks and NX using Parasolid. 6 In NX, annotations can be placed in 3D models but behave as 2D drafting features, requiring specific view settings to be visible in multiple 3D views. 7 The program remained 32-bit until NX1 or NX2, limiting memory usage on both UNIX and PC versions. 8
