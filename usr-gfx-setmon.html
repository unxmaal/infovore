/usr/gfx/setmon

Claims: 4 Background: 1 claim already covered by Wikipedia, see SGI O2.

/usr/gfx/setmon can set the screen resolution for IRIX on an O2, but it requires running on local hardware. 1 It can only be run in graphical mode, not single user mode, and requires a graphic text port or a serial terminal. 2 For an unmanaged display, it can set the resolution but requires stopping and restarting X to take effect. 3 For example, /usr/gfx/setmon -x 1280x1024_60 can be used to set the resolution. 4
