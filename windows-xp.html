Windows XP

Claims: 48 Part of Windows Background: 6 claims already covered by Wikipedia, see Windows XP, SGI Visual Workstation.

Windows XP is essentially Windows 2000 with a simpler user interface, and it brought Windows into the 'it's a real OS not a DOS GUI' phase, though it had some bad stuff, such as the absence of User Account Control and harsh forced upgrades for people who stayed on it. 12 Windows XP has been supported for a longer period than other Windows releases and was used for about 10 years in businesses, from Pentium 3 to i7 processors. 34 Windows XP source code includes full support for Itanium, x86, x86_64, and Alpha platforms, but no longer includes MIPS support. 5 Non-64-bit Windows XP could address up to ~3GB of RAM, and a configuration with 512MB RAM did not need virtual memory. 67 Windows XP can run on a variety of hardware and virtualization setups, including the Visual Workstation, UTM, Qubes VMs, Quad Xeon systems, the SunPCI III on an Ultra 60, the x86 PICMG SBC, and the VAIO VGN-AR51M after installing Vista first. 891011121314 However, HyperV does not run Windows XP because it only runs modern supported operating systems. 15 Several applications run on Windows XP, including Blender 1.60, Maya 4.5 in VirtualBox, Softimage 3D, Wordpad, and Wordpad, a text editor included with Windows XP. 16171819 Windows XP and earlier versions are prone to bit rot and require frequent reinstallation. 20 Windows XP can be run on a virtual machine in VirtualBox, where a machine such as an Octane can connect to it via bridged networking by configuring the VM and setting a static IP on the host PC's network interface. 21 Windows XP on ia64 is limited because many 32-bit x86 applications will not run on it at all. 22 The PC runs Windows XP, which is slow with OEM drivers. 23 A 133 MHz x86 clone is likely from the Win95 or NT 4.0 era and may struggle with Windows XP. 24 Rat 5.0 for Maya 4.0 can be run on Windows XP but not licensed on Irix. 25
