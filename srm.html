SRM

Claims: 14

SRM is the Alpha firmware for Unix/VMS, while ARC is for Windows; some Alphas could only run Windows. 1 SRM does not run on Alpha CPUs. 2 The 'u' in SRM denotes a Unix system, contrasting with ARC/AlphaBIOS. 3 The Multia has a cooked IC and memory issues but can boot into SRM and ARC. 4 The console for the 7000 series is built in SRM. 5 SRM supports any VT greater than 100, while Alphabios works best with ANSI terminal mode and is not ideal for serial consoles. 6 It is recommended to switch to SRM after fixing the battery, as Windows on Alpha is not ideal. 7 SRM recognizes the graphics card as 'Cateyes'. 8
