/bin/sh

Claims: 7 Background: 1 claim already covered by Wikipedia, see Bash (Unix shell).

The default shell is /bin/sh, often csh for root. 1 The bourne shell (/bin/sh) doesn't do tab completion or history. 2 Rpmbuild uses /bin/sh by default, but can be overridden with %_buildshell. 3 aterm checks the SHELL environment variable, falls back to getpwuid, and uses /bin/sh if the shell is not set, with /bin/bash as the last resort. 4 A 4.19 kernel can boot an SGI system into /bin/sh but may require device nodes to be populated in /dev. 5 mksh is a good alternative to /bin/sh for those preferring something other than bash, and an alternative shell like ksh can be used for configure scripts to work around issues with /bin/sh. 67
