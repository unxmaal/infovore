system controller

Claims: 7

The system controller monitors backplane voltages but does not monitor IP19, IP21, MC3, IO4 or SCSIBox. 1 A suspected issue with the InfiniteReality machine is dead Dallas chips on the system controller and IO4. 2 The system controller complains that all voltage rails except 48VDC are low when AC line power is applied and the key is turned, with the voltages measured at or near 0V and no error lights. 3 The system controller can be difficult to work with. 4
