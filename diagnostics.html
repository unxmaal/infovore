diagnostics

Claims: 6

Diagnostics can be run from the main menu or from a serial console, and the cable should be checked. 1 The PROM boot prompt does not support running diagnostics, indicating no memory test command is available in this configuration, and entering pod mode may be required. 2 Diagnostics can be booted from disk using ide.IP17, but this requires a correct board type value and may fail due to a 'device not ready' error. 3 When graphics are installed, the system skips diagnostics and fails with 'No SystemPartition set Unable to continue', while with graphics removed it runs diagnostics and fails with keyboard issues. 4 If an AV1 card boots and plays audio in an O2, the video inputs are likely to work, though partial functionality has been reported and diagnostics may be reliable but not guaranteed. 5 Running IDE diagnostics performs a full system diagnostic including the hard drive, which takes a long time. 6
