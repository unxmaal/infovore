Challenge S

Claims: 67 Background: 4 claims already covered by Wikipedia, see SGI Indy, Debian.

With Indy

The Challenge S is a graphics-less version of the Indy used for server purposes, sharing the same case and internal components. 12 The Indy and Challenge S each have two IO card slots, while the Indigo 2 and Challenge M have four because the graphics and mezzanine board occupy the bottom slots. 3 An Indy can be retrobrite'd using a Challenge S motherboard and graphics card. 4 A scsi2sd v6 works in both the Indy and Challenge S but is expensive, and GBscsi2 is a good alternative. 56 A cheap PlayStation 2 vertical stand fits the Challenge S and likely the Indy as well. 7

General

The Challenge S is a vintage SGI workstation that is still operational today, described variously as a 150 MHz R5k novelty server or a 200 MHz R4400 with 64 MB of RAM, and is essentially an Indy without built-in graphics. 89101112 It is multi-CPU capable, unlike the Challenge M, and can be used for simple website hosting, mail services, and compiling MIPS3 or COFF systems, though compilation is slow. 131415161718 The Challenge S can run Debian, NetBSD, and IRIX, and can function as a server, a display for an x410, or be traded for alpha or POWER hardware. 19202122 It has poor airflow and can reach 122F internal drive temperatures, and it can hardlock, lock up during file deletion, and is not fast enough for router/firewall duties. 23242526 The Challenge S has been reported running for extended periods, with uptimes of 164 days, 102 days, and over 100 days noted. 272829 The Challenge S is an SGI model that may specifically refer to an R4600PC Indy, and it uses ST connectors like CentreCOMs. 3031 It lacks a motherboard RJ45 Ethernet port and has a single SCSI controller for all SCSI devices, including those connected to the 50-pin external port. 3233 The Challenge S can be used as an install server and may need an HDD upgrade or an external storage solution. 34 It is suitable for small departments or web servers, while larger needs call for deskside models. 35 It can attempt to find a keyboard and mouse with `setenv console g` set, even without PROM muckery when adding a PS/2 and a graphics card, and can use panel mount PS/2 MiniDIN connectors for keyboard and mouse input via custom slot brackets. 3637
