SunPCi

Claims: 24 Background: 1 claim already covered by Wikipedia, see SunPCi.

SunPCI is platform-specific, with different versions for different systems. 1 The first-generation SunPCi has a CPU socket that allows the CPU to be rotated 180 degrees without bending pins due to keying. 2 A K6-III+ CPU requires a core voltage that is too high for the SunPCi. 3 The first revision of the SunPCi supports up to 128MB DIMMs, but may not recognize more. 4 The SunPCi uses an ES1869 Audiodrive chip for DOS games compatibility, while the SunPCi-2 and -3 use PCI-based sound. 5 Sun sold a SBus card called SunPC with 486 processors ranging from 33MHz to 133MHz and no RAM on the card, whereas the SunPCi has memory slots. 6 The SunPCi is less integrated and not as full-scale as the SBus SunPC card for a multi-user Unix machine. 7 A SunPCi-IIIpro card can run Solaris x86 inside a SPARC workstation running Solaris. 8
