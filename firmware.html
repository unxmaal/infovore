firmware

Claims: 88 Background: 5 claims already covered by Wikipedia, see Firmware, BIOS, PlayStation 2, Silicon Graphics.

Some systems, such as the PS1, PS2, and Alpha workstations, contain firmware in their BIOS or PROM, and certain add-in hardware is supported by allowing the PROM to load firmware from the hardware rather than hardcoding it. 123 SGI developed its own firmware for some systems, and specific cards such as the X1s and X3s require SGI-specific firmware to communicate with the custom riser, often failing to work with non-SGI firmware. 45 Firmware can be updated to improve performance, fix stability issues, or enable new features, but updates can sometimes cause problems such as disc corruption, system lockups, or boot failures. 6789101112 Firmware can be implemented independently of the OS, allowing for tasks such as secure erase or the use of standard DIMMs as NVDIMMs in case of power failure. 1314 Firmware updates can be performed using various tools and methods, including flashing via a floppy, using a custom harness, or modifying stock firmware by inserting strings at specific addresses. 151617 Firmware and microcode are typically undocumented, similar to proprietary drivers. 18 Firmware can be reflashed. 19 Updating firmware can improve saving features and booting speed. 20 Firmware can be dumped, and some Alpha firmware source is publicly available under open (but not open source) terms. 21 Firmware can be modified to allow other rebadged avocent SIPs to connect, though this requires the latest firmware and explicit IP Fragmentation per port. 2223 The latest firmware for Indigos includes fixes for SCSI2 issues. 24 The firmware which is modded is on a separate memory chip from the eMMC, which holds the Wii U Menu, other software titles and user data. 25 SGI firmware (070-xxxx-yyy) is needed for the board, as a generic 4211 might not work in IRIX. 26 X3 units can be flashed with SGI firmware, and new ones can still be obtained from eBay, though they come with HP firmware but will boot and the Prism can flash them. 27 The newest firmware for the ZULUSCSI can display status over USB and can sequentially image multiple drives. 28 A specific router with the firmware to support it is probably required for larger IP53/IP59 hardware. 29
