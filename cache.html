cache

Claims: 37 Background: 6 claims already covered by Wikipedia, see CPU cache, Central processing unit.

Cache is a small, fast memory that helps a CPU keep up with its processing speed, and good cache is important for keeping up with an overclocked CPU. 12 Modern CPUs typically have only 2MB of cache per core, which is considered small. 1 Cache can significantly improve performance, such as increasing integer performance on PowerPC processors, especially on the G3. 3 Cache can be tested by removing some or all of it, and a machine might run without cache to test it. 45 Cache can cause hardware issues, such as errors, kernel panics, and bugs. 6789 Cache is used in various systems, including CPUs, memory controllers, and network devices. 1011
