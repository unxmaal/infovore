5.15 kernel

Claims: 3

The 5.15 kernel has been reported to complain about the stack being at a wrong address when using the latest glibc built with GCC 11. 1 Kernel modules may be buggy on the rx2620 with the 5.15 kernel, in which case using a static kernel is an alternative. 2 Linux on Itanium with a 5.15 kernel supports Python, Xfce, MATE, NetSurf, and OpenGL, though with some glitches. 3

Sources

  1. The system complains about the stack being at a wrong address with a 5.15 kernel, latest glibc built with GCC 11. (user-1867, 2022-06-21, exchange 92935, check: supported)
  2. Kernel modules may be buggy on rx2620 with 5.15 kernel, using a static kernel is an alternative. (user-1867, 2022-11-22, exchange 75867, check: supported)
  3. Linux on Itanium with a 5.15 kernel supports Python, Xfce, MATE, NetSurf, and OpenGL, though with some glitches. (user-1867, 2023-05-30, exchange 215385, check: supported)
