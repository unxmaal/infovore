OpenAL

Claims: 9 Background: 1 claim already covered by Wikipedia, see IRIX.

OpenAL is an open standard for 3D audio implemented by Creative with EAX, but it was open-sourced due to demand. 1 IRIX officially supports OpenAL, and OpenAL and ESD run on top of IRIX's own audio system. 23 In nekoware for IRIX, OpenAL is available as a tardist file named neko_openal.tardist. 45 OpenAL is included when compiling LWJGL, and cen64 wants to use JACK for audio but OpenAL can be configured not to use it. 67 DS3D or OpenAL can be used to add a software renderer that surpasses old Creative cards, and DSOAL aims to do this using OpenALSoft. 8 Building a static q2pro requires UltraSPARC3 with VIS2 optimization and a static OpenAL and SDL2, and it will fail due to the absence of a static librt. 9
