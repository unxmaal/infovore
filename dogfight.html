Dogfight

Claims: 4

Dogfight is included on the General Platform Demos disc for IRIX 6.5 on O2 systems, living in /usr/demos/General_Demos on the 2-disc O2/Octane demos CDs for 6.5.30 or earlier. 12 The demos package in software manager contains source code for dogfight and related programs, though it is not installed by default. 3 Dogfight records video in .yuv format, which can be converted to a more normal format using Composer. 4
