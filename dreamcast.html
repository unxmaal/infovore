Dreamcast

Claims: 35 Background: 6 claims already covered by Wikipedia, see Dreamcast, Video games and Linux.

The Dreamcast is a Sega console whose final hardware configuration came from Sega of Japan's Project Katana. 1 It is powered by a 200 MHz SH4 CPU that rivals or beats MIPS in speed per MHz and is superior to the Windows CE machines. 23 Its release timing was poor, competing with the PS2, and it was released too late. 45 It uses a Maple bus, requiring adapters for USB/PS2 devices, and has a broadband adapter that can be expensive. 67 It can output video through VGA adapters and the DCDigital HDMI adapter, which supports RGB and VGA. 89 It runs on an ML2020 lithium battery, which can be replaced with an ML2032, and its noisy fan can be removed. 1011 Linux was ported to the Dreamcast in the early 2000s, with T2 Linux supported but unknown performance. 1213 It could run Windows CE and use DirectX for porting x86 games, but this did not succeed, and Windows CE compatibility is on the SDK level with no native hardware support. 1415
