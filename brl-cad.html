BRL-CAD

Claims: 12

BRL-CAD is not a traditional CAD program but a collection of tools, and it is considered a decent application. 12 BRL-CAD requires CMake 3.1.3 or higher. 3 CMake requires X libraries for BRL-CAD, and IRIX has most but lacks Xrender. 4 BRL-CAD is available for IRIX, but the last version was 12 years ago and no recent builds have been found. 5 BRL-CAD's compilation on IRIX is challenging due to outdated build system support, with the last relevant documentation being over a decade old. 6 To disable the XML module in BRL-CAD, set the CMake variable BRLCAD_BUNDLED_LIBS to AUTO, install libxml, libexslt, and libxslt, and clean the build directory before re-running CMake. 7 The lib utahrle is for working with rle files, likely originally for BRL-CAD. 8 Solaris can run CAD software like BRL-CAD, but licensing is an issue. 9
