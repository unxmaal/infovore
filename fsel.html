fsel

Claims: 7

fsel is a file selector specific to LightWave on IRIX, using a custom method instead of standard OS file selectors. 1 The standalone file selection widget (fsel) used by the crack is a COFF file, requiring IRIX 5.3. 2 You should have that dir in your PATH so the shell should find fsel. 3 To configure Lightwave on IRIX, you need to copy magic fsel. 4 Lightwave 3D 5.6 on an Octane 2 with IRIX 6.5.30 requires a patched fsel to save or load scenes. 5 Lightwave breaks with fsel/segfault issues after IRIX 6.5.22; a custom fsel fixes it. 6 You may get an error about fsel not being supported by architecture, possibly because it was written/compiled on MIPS4. 7
