/usr/lib32

Claims: 4

/usr/lib32 is searched before system directories by rld, which is necessary for some programs to work correctly. 1 The order of directories in LD_LIBRARY_PATH matters, with /usr/lib32 first potentially causing older libraries to be used first. 2 Setting LD_LIBRARYN32_PATH to include /usr/lib32 resolves issues with unresolvable symbols in gdb. 3 Compiling ClassiCube requires linking against libraries in /usr/lib32 and using the -Wl,--allow-shlib-undefined flag to resolve undefined references. 4
