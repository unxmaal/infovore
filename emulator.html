emulator

Claims: 63 Background: 5 claims already covered by Wikipedia, see Emulator, SGI O2.

An emulator is a program that emulates hardware, and emulators can be modular, allowing for external modules with copyright retained by the author. 1 Some emulators use software emulation, which is slower, while others can use JIT to speed up graphics and memory access. 23 Emulators are often single-threaded and slow due to the complexity of emulating all the hardware. 45 Some emulators can be overclocked to reduce load times and improve performance. 6 Emulators can support various interfaces and features, such as NFS file sharing, UltraSCSI, and single-step instruction debugging. 789 Emulators can be used to run a variety of systems and software, including IRIX, NetBSD, and arcade games. 101112 Using the release build of the emulator is recommended for actual use, as debug builds are too slow. 13 The emulator can be optimized and extended with additional render passes for post-processing effects. 14 The emulator now uses SDL_Scancode for keyboard input, allowing correct key detection for non-QWERTY layouts like de_CH. 15 A user can shim libraries to intercept OpenGL code and use local hardware, bypassing the emulator stack, by converting endianness. 16
