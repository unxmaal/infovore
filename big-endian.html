big endian

Claims: 21 Background: 2 claims already covered by Wikipedia, see Endianness.

Big-endian is a historical choice that is less intuitive than little endian, which makes accessing integers of different sizes from the same memory location simpler. 12 On a big endian system, a 16-bit load from address 0x0 gives 0xAABB, while on a little endian system it gives 0x0011. 3 Big endian is better for multimedia and 16-bit audio samples from 32-bit recordings because it avoids bit shifts, while little endian may require them. 4 The issue with big endian code on a little endian CPU involves potential cache conflicts, but swapping the byte order resolves it. 5 Bus errors indicate unhandled big endian or unaligned access issues, especially in binary data. 6 The RM7000C CPU is set to big endian by default, but can be configured to little endian. 7 Gentoo still supports big endian for PPC64, while RHEL and CentOS no longer support big endian releases. 89
