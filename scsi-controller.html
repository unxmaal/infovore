SCSI controller

Claims: 53 Part of SCSI Background: 2 claims already covered by Wikipedia, see QEMU, SGI O2.

The QLogic FAS201 is a SCSI controller, while the QLogic QLA12160 is a SCSI controller paired with a Broadcom BCM5704 Ethernet controller. 12 The Reply Sound Blaster 16 + SCSI card combines an OPL3 chip, a SCSI controller, and a Vibra 16 chip into one unit. 3 The SCSI controller on the IO3 is a WD33c93, and dksc is the SCSI controller. 45 The SCSI controller on the Indy is integrated into the main board and is set to ID 0, which is reserved for the SCSI controller on SGI systems. 67 On SGI systems the SCSI controller is set to ID 0 and the disk should be set to ID 1, whereas on PCs the controller is usually ID 7 and the disk is ID 0. 8 The SCSI controller uses ID 0, and disks should use IDs 1 and up. 9 The Indigo2 has a SCSI controller and an on-board Ethernet interface, and the O2's boot disk can be a SCSI controller for hard disks. 1011 The Onyx2 has a SCSI controller on the IO6g, not the midplane, and the white connectors on the midplane connect SCSI drives to the IO6g. 12 The Octane can boot from NVMe using a hack that involves a SCSI controller understood by PROM and modifying kernel functions to map the root using the NVMe driver as a secondary controller. 13 The challenge S has a single SCSI controller for all SCSI devices, including those connected to the 50-pin external port. 14 The SCSI controller must be registered as /hw/ql/2 or later on Octane, with a kernel hack to recognize it there, while on O2 it skips on-board controllers and looks at /hw/scsi/X in hwgraph. 15 The system has an integral SCSI controller 2 and 0, and an IOC3/IOC4 serial port. 16
