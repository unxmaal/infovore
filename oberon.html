Oberon

Claims: 8

Oberon is a system developed by professors Wirth and Gutknecht, who had unique approaches to software and user interfaces, and it is highly regarded for its elegant software design. 12 The Oberon programming language is the sequel of Pascal and Modula, and there was an operating system with the same name written in that language. 3 There are many versions of Oberon, and its UI evolved separately from other systems. 45 Oberon has a fully textual user interface and runs on multiple platforms including SGI, Windows NT, and DOS. 6 Oberon's method lookup uses a hash of method names and parameter types without collision checking, leading to bugs that can be fixed by renaming methods. 7
