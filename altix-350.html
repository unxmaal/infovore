Altix 350

Claims: 66 Part of Altix Background: 9 claims already covered by Wikipedia, see SGI Altix, Gentoo Linux.

The Altix 350 line only sold bootable base-bricks and compute bricks; MPX and PCI-X bricks were not available, and the A350 compute brick lacked the riserboard with PCI-X slots. 1 The Altix 350 requires an io9 or io10 for bootability, with the io10 board being a SATA interface. 234 An Altix 350 with a PCI riser and a BCM5704 can network boot using EFI-ELILO via the EFI Boot Maintenance Manager, requiring no IO9 or IO10. 56 The Altix 350 does not require a NUMA router in the same chassis, unlike larger configurations. 7 The Altix 350 requires at least four RAM modules for operation, and RAM can be sourced from eBay for approximately $5 per stick. 89 The Altix 350 can run Linux but not HP-UX. 10 Debian 6 runs on the Altix 350 with io9, SLES11 runs on the Altix 350, and ProPack 7 is compatible with Altix 350 gear and can enhance SLES11 support. 111213 The Altix 350 is a SGI server released before the Origin 350, and is similar to it, though the mainboard differs while expansion cards, including IO, should be the same. 141516 The Altix 350 can connect up to 8 bricks without a router, and more bricks require a router. 17 The Altix 350 uses the IO9 for SCSI/IDE and can be swapped with an IO10 for SATA/IDE, though the IO10 card only works on the Altix 350, not the Origin 350, and cannot be used to boot. 1819 The Altix 350 has a yellow door brick PCI riser with XIO connectors, and some interface boards lack Dallas chips, using a soldered button cell instead. 2021 The NL4R card is backwards compatible with the Altix 350, and some bricks use sockets prone to damage, with instances of the socket being ripped off the board during removal. 2223 The Altix 350 can overheat if the L1 cache is running without fans, and may become unresponsive to power commands and fail to boot the L1 cache after extended operation, but cooling resolves the issue. 2425 The Altix 350 can run ALE 3, boot Gentoo with kernel 3.14.79, and use a 500GB Samsung SSD. 262728 The Altix 350 with a graphics module requires special installation instructions for SLES 9, as it may not boot or install properly from DVDs without them. 29
