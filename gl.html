GL

Claims: 27 Background: 2 claims already covered by Wikipedia, see IRIS GL, Xsgi.

GL was invented by SGI, whose hardware (GE > RM > DG) changed perspectives on the technology. 1 GL validates state on every glVertex call, adding CPU overhead, and predate GL systems offer software-only rendering unless a commercial option is found. 23 To achieve perspective projection in GL, the W component of vertices must be manipulated to reflect depth, which GL uses for perspective division and texture coordinate interpolation. 4 The hardware does not run GL directly; the driver compiles shaders and converts commands to GPU-native format. 5 To disable vsync on SGI GL, set the environment variable DECOUPLE_SWAPBUF to y. 6 Xsgi supports both OpenGL and GL on SGI hardware, while Onyx4 uses XFree86 which does not support GL. 7 The sgug toolchain requires specific flags and linker options to work with SGI GL, such as -lGL -lGLcore, and may need an X11 package with fixed headers. 8 Compiling sm64ex on IRIX requires X11 libraries with GL support, which may need recompilation from the wip-testing branch to fix SDL errors. 9
