MMSC

Claims: 6

The MMSC is an x86-based embedded computer with no operating system, running a real-time OS, featuring a CPU, RAM, basic interface IC, serial ports, and a ROM IC, but no drives, networking, or BIOS. 1 The MMSC uses Ethernet for communication, which is isolated from other networks, and is limited by its hardware and the RTOS it runs. 23 MMSC is a touchscreen UI to send the same command to multiple MSC's. 4 Prom can detect and initialize the MMSC, drawing the startup background. 5
