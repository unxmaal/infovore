POST

Claims: 11

POST results vary depending on hardware configuration, such as memory module speed, where a 400MHz module fails POST while a US-I/200 does not. 1 POST can fail due to physical damage, such as cache heat sinks damaged during shipping. 1 The vast majority of boot time for a server is spent on POST rather than the OS itself. 2 To diagnose POST issues, one can enable all POST options, set the output device to ttya, and monitor serial output during booting. 3 POST can be slow on certain machines, such as the Intellistation 9114 Model 275, possibly due to a dead battery, and on RS/6000 machines after a battery replacement or in service mode. 45 POST can also be slow on SS20 machines and in serial tests, especially if the NVRAM battery has failed, leading to diag-mode and verbose POST. 67 A complete memory test via POST is useful for checking faulty DIMMs when Memtest86 cannot be used. 8 If the machine POSTed and displayed the PROM monitor, the motherboard might still be salvageable. 9

Sources

  1. Memory modules from different speeds have different POST results; a 400MHz module fails POST while a US-I/200 does not. Shipping can damage cache heat sinks, leading to POST failures. (user-7b1c, 2020-04-23, exchange 96714, check: supported)
  2. parallel init is a false gain; the vast majority of boot time for a server is POST, not the OS itself. (user-3ff5, 2020-12-10, exchange 204550, check: uncheckable)
  3. Another thing to try is to turn on all the POST shinies, set output-device to ttya and monitor serial output while booting. (user-7b1c, 2022-05-19, exchange 182032, check: uncheckable)
  4. The Intellistation 9114 Model 275 POSTs slowly, possibly due to a dead battery. (user-22f9, 2022-07-03, exchange 176237, check: supported)
  5. The RS/6000 POST and IPL can take a long time after a battery replacement or in service mode, but not once configured. (user-07ed, 2022-07-03, exchange 176237, check: supported)
  6. In serial tests, video output can take a long time, especially if the NVRAM battery has failed, leading to diag-mode and verbose POST. (user-07ed, 2022-09-22, exchange 183011, check: uncheckable)
  7. POST is slow on SS20 machines. (user-7b1c, 2022-09-22, exchange 183006, check: uncheckable)
  8. A complete memory test via POST is useful for checking faulty DIMMs when Memtest86 cannot be used. (user-baf6, 2022-09-22, exchange 239848, check: uncheckable)
  9. If the machine POSTed and displayed the PROM monitor, the motherboard might still be salvageable. (user-d492, 2025-09-14, exchange 118593, check: uncheckable)
