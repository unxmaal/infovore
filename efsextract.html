efsextract

Claims: 13

efsextract is a tool for extracting files from SGI CD images or EFS file systems, with options for listing files, creating tar archives, and extracting bootfiles. 1 It can parse ISO files to list packages for IRIX 5.2 Beta II, including version info and requirements, and can be used to extract EFS files without compiling a kernel module. 23 efsextract only supports efs and iso9660 filesystems, not the filesystem used by the Linux LiveCD or all MIPS Magnum discs. 45 It has bugs including stack corruption when buffer size is not 512 bytes, permission denied errors from creating directories without the +d mode flag, and signed/unsigned int32 offset problems when extracting IRIX filesystems. 567 Compiling efsextract requires defining functions for byte order conversion, and the fix was pushed to GitHub. 89
