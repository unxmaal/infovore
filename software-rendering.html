software rendering

Claims: 5 Part of software

Software rendering is used as a fallback in some systems, such as SI/SE, which falls back to it when it cannot support newer OpenGL versions (e.g., OpenGL 1.3 is the oldest ES version available, and the system cannot run newer OpenGL versions). 12 Software rendering works for most demos but has regressed, and it is notably slow. 23 Software rendering is CPU-intensive, as it appears to be the main source of high CPU usage. 34 In some cases, software rendering was the only rendering method used, with no special hardware involved. 5
