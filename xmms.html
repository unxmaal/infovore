xmms

Claims: 26 Background: 3 claims already covered by Wikipedia, see XMMS, SGI Octane.

It can be built using didbs with specific compiler flags and patches, requiring adjustment of plug-ins and dependencies from nekoware, which offers a Dmedia plugin and a native sound plugin version that failed on r4k due to compilation issues. 123 XMMS uses the ESD sound API for portable sound, and requires the ESD daemon to be launched for sound output, as failing to do so causes segfaults. 45678 It works with MP3s while using less CPU power than the default media player, and can play web radio and downloaded MP3s. 491011 On SGI systems, the output plugin must be set to 'sgi audio' to resolve segfaults, and a specific library for SGI output may need its paths and configuration checked. 1213 It is available from SGUG-RSE, where installation requires manually configuring the official repository and using 'tdnf install xmms', though it is specified but not yet built for tdnf on some systems. 14151617 The xmms dmedia output plugin produces noise and is difficult to diagnose, and a package may overwrite configure when unpacked atop a certain version of xmms. 1819
