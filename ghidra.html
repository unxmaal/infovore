Ghidra

Claims: 24 Background: 1 claim already covered by Wikipedia, see Ghidra.

Ghidra is a reverse engineering tool that supports MIPS code and provides a C-like decompiled view, and it can be extended with plugins for various architectures. 1234 Ghidra supports many file formats but has trouble loading SGI ECOFF files or later IRIX ELF files, and its COFF loader is limited to MS COFF assuming little-endian, requiring a Python script to parse big-endian ECOFF. 5678 Ghidra has a MIPS decompiler that IDA Pro lacks, but it misses many functions compared to IDA and cannot map variables in the decompiler. 91011 Ghidra can be used instead of IDA Pro for disassembly, though it was not as quickly adopted, and setting the $gp register value can help function analysis. 121314 Ghidra can load a file with trigram counts for string analysis, though it is undocumented and difficult to use. 15 A Ghidra MCP provides a mechanism for an AI agent to query Ghidra for code analysis, but it requires API use which is restricted. 1617
