netbooting

Claims: 23 Background: 2 claims already covered by Wikipedia, see Network booting.

Netbooting is booting a computer over a network, and it can be used as a workaround for broken CD-ROM drives, which were common on some systems. 12 Netbooting can install SLES11 on an A350 without an IO9 card, and it can free up the O2's onboard SCSI for video recording. 34 Net booting IRIX from another SGI involves bootp, tftp, and rsh, and it can use a standard ethernet cable to a modern SGI running an OS like IRIX 6.5.30. 56 Netbooting Solaris can be done with Jumpstart, which responds to client addresses via /etc/hosts and /etc/ethers, tftps the kernel, and checks a custom config file for installation, but the Ultra 5 requires bootparamd and it may not work reliably. 789 Net booting requires a compatible network setup, such as a local fiber router connecting the SGI box to Linux machines, and for netbooting, the Linux server and router should not run DHCP or should be isolated on different segments. 1011 Netbooting can involve transferring install disc contents to the Indy's disk after formatting and pointing `inst` at it, or NFS mounting a NAS, and the use cases for the NFS/DHCP server include netbooting for simple network installs and diskless operation. 121314 Netbooting may not work better than booting from CDROM, and SRM might require a 'known' NIC, but there is no need to netboot over a Gbit NIC since all machines have a supported NIC onboard. 151617
