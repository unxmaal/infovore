UFS

Claims: 9 Background: 1 claim already covered by Wikipedia, see ZFS.

UFS is used as the file system in Solaris 8 and earlier, and Solaris 10/11 still offer the option to use it. 12 ZFS setup is simpler than UFS because ZFS does not require partitioning the disk. 3 UFS is slow, has poor snapshot support, and relies on soft dependency graphs rather than journaling. 4 UFS 5.3 has limitations similar to those of the ancient 4.4BSD-lite UFS. 5 UFS is supported by Mac OS X Leopard but is not very useful for system partitions and may not be fully compatible with other systems. 6 To make bootable media, format a USB stick as UFS, copy files from a DVD, and run installgrub. 7 Oracle maintains that the SunOS 4.x floppy disk label format is read-only compatible with modern UFS for the same CPU architecture. 8
