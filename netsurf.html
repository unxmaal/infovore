Netsurf

Claims: 62 Background: 17 claims already covered by Wikipedia, see NetSurf.

NetSurf is a browser written entirely in C that is designed for portability and is used on retro machines, supporting modern CSS and encryption. 1234 It supports multiple frontends, including RiscOS, GTK2, GTK3, a raw framebuffer, and a Motif front-end that is being developed and is expected to be shippable soon. 567 It runs on older hardware such as the Amiga 600 V2, a Falcon 060, and SGI systems, where it can be used with a Motif-based front-end to create a fast modern browser. 891011 On IRIX it requires GTK2 or GTK3 and depends on toolkits and SSL libraries, and it can be compiled with GCC or, for IRIX 5.3, with MIPSPro. 5121314 It is still being developed, with ongoing porting work and issues related to glib, and a patch for IRIX introduces bugs. 151617 A setback on IRIX is a bug in the printf functions that causes snprintf to a null pointer to fail, which is used by NetSurf to determine malloc size. 1819 Netsurf is a browser available for IRIX. 20 IRIX has netsurf, dillo, and lynx. 21 Netsurf can be installed from the sgug-rse repository; updating metadata may be necessary. 22 Netsurf can be built for SGI with a 'slow ass' or 'cute & quick' interface. 23 Netsurf's Motif port uses GL and has makefile hacks to work around RSE issues, but should otherwise port cleanly. 24 Netsurf can be launched using the motif version if the GTK3 version is not found. 25 Netsurf and Netsurf-Motif give console errors when launched, indicating issues with GTK3-Motif and RANDR, respectively. 26 Netsurf requires netsurf-gtk2 or netsurf-gtk3 to launch, not netsurf-gtk3 as the desktop icon suggests. 27
