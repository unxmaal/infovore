IP7

Claims: 28

The IP7 is a Silicon Graphics PowerSeries workstation that uses two R2000A/R3000 processors in two CPU halves with minimal shared components, running at 2x33 MHz. 123 The IP7 lacks SCSI disk support and can boot with minimal components, using DIP switches to bypass diagnostics. 45 A second IP7 CPU board can be added even if the CPU frequencies differ, as long as the PROMs match. 6 The IP7 can be substituted for the IP15 or IP17 in some power series configurations. 7 The IP7 struggles with fillrate tests, causing a drop in instruction issue rate and failing autocalibration. 8 The Crimso is a power series with a different CPU board; an IP7 or IP15 can be substituted for the IP17. 7
