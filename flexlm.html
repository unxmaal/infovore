FlexLM

Claims: 53 Background: 2 claims already covered by Wikipedia, see FlexNet Publisher.

FlexLM is a software license management system that was used for license management on IRIX, AIX, HP-UX, Solaris, and Windows. 12 It is typically installed with the package that requires it, and on Unix it is usually found in /home/flexlm/. 34 FlexLM uses symmetric encryption for license validation, with different versions existing, and it may use different seeds on different platforms. 56 It was a popular licensing method for software such as Sybyl, Accelrys Cerius, Spartan, and Pro/E, which switched to FlexLM in version 20. 78 FLEXlm licensing technology has a history of weak security concepts and has been cracked for years. 9 FlexLM is a licensing system that has been around for a long time and is based on Flexera dongles. 10 It has been used to manage licensing for various products, including a version of SolidWorks, 4DDN software (which used NetLS for older IRIX and FLEXlm for newer versions), and the 5.3 software (which used NetLS, not FlexLM). 111213 The FLEXlm license file for Annotator and WorkShop on SGI systems includes evaluation features. 14 FLEXlm SDKs have restrictions that were cracked, allowing the creation of keygens for SGI applications. 15 Anything FlexLM pre 1998 or so and pre ECC keys can easily be generated, whereas version 7.x of FLEXlm uses public key cryptography, making clean keygenning impossible without a keypair. 1617 Many companies have shut down their FlexLM license servers. 18
