R720

Claims: 10

The R720 is a Sandy Bridge-EX system with a basic framebuffer. 1 It can take up to 1.5TB of RAM, and can be configured with 4x4GB kits for 16GB per CPU in quad channel. 23 It can run Proxmox and can be configured to use IPv4 or IPv6, but not inherently be IPv6 only in hardware. 45 Changes to network configuration files can affect network connectivity. 6 R210 II and R720 servers are used for hosting backups. 7
