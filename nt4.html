NT4

Claims: 45 Part of NT Background: 1 claim already covered by Wikipedia, see Windows 2000.

NT4 can be run in the PCem emulator, though performance is poor at around 3 fps. 1 NT4 is generally lighter than Windows 2000 on a classic Pentium with enough RAM, and is considered solid but less common than Windows 2000. 23 NT4 was POSIX-compliant and was used professionally until Vista was released. 45 NT4 ran on Athlons in 2001, lacked USB support, and was used in production. 6 NT4 requires significant memory to boot, with 16MB being insufficient for usable operation. 7 NT4 was not compatible with consumer software when Windows 95 and 98 were in use. 8 NT4 was great but shitty for games, being more stable than Windows 9x. 9 Third-party ATMs sometimes still run variants of NT4. 10 The MIPS NT machine booted into ARCS firmware and ran NT4 using wx86, an executable that allows running x86 applications on MIPS hardware. 11
