Onyx4

Claims: 143 Part of Onyx Background: 3 claims already covered by Wikipedia, see OpenGL, SGI Origin 3000 and Onyx 3000, SGI Tezro.

With IRIS GL

The Onyx4 is a high-performance SGI system that uses ATI FireGL graphics cards (up to FireGL X1) and supports DVI outputs for high-resolution display, but it does not support IRIS GL. 12 IRIS GL works on SGI systems with graphics cards, excluding the Onyx4, and applications such as mediarecord therefore do not work on the Onyx4. 34 The Onyx4 uses XFree86 and a different X Windows configuration, which leads to compatibility issues with many applications. 56 A third-party IRIS GL implementation for Linux exists, but it is not from SGI. 7

With Prism

The Onyx4 and Prism use the same GPU, and the Onyx4 compute node can be repurposed into a Prism by replacing the graphics card. 89 The Onyx4 is faster and more reliable than the Prism, though the Prism has been difficult to work with. 10 The only configurations with a single AGP riser were the rack Prism and Onyx4, both dual-pipe. 11 The Altix 350 has FireGL X2.1 cards which are useful for Onyx4 due to Prism compatibility issues. 12 Altix and Prism systems are not fully compatible with Onyx4 systems due to differences in hardware and firmware. 13 My Onyx4 and Prism bricks cost the better part of a grand each. 14 The CBOB can be found in different configurations, including as part of a Prism setup or with an IP badge and Onyx4 USB ports. 15 Vertex buffers (VBOs) were not available on SGI V12 systems until Onyx4 (and Prism). 16

General

The Onyx4 is a 4U tower that can be configured with or without a CPU, and adding a CPU requires specific setup, including XIO or Numalink for connection and reinstalling IRIX for graphics initialization. 1718 The Onyx4 uses ATI FireGL graphics cards, which are called graphics pipes, and has display outputs called heads. 1920 The Onyx4 and rackmount Prism use the same AGP riser, but the Prism uses FireGL X2 or X3 cards while the Onyx4 uses ATI Pro 9700 cards. 21 The FireGL X3s require a Molex power connection, and the Onyx4's AGP riser has an unpopulated header for this. 22 The Onyx4 supports OpenGL 1.4, and was planned to support 2.0. 23 The Onyx4 is more powerful than an Onyx350 but lacks XSGI, affecting some apps like Flame. 24 The Onyx4 is a modular SGI MIPS system that can be configured with up to twelve CPUs in theory using a NUMAlink router. 25 It uses AGP slots and supports ATI FireGL cards (marketed as Voyager), which make it incompatible with IRIS GL software but faster for OpenGL 1.3 geometry. 262728 The Onyx4 can support OpenGL Multipipe with up to four displays but only two sets of inputs, and it handles 2560x1440 resolution well at 2K but not 4K. 2930 It requires two bricks, one with a PCI riser for the IO9 boot device and one with AGP for the dual FireGL cards. 31 The CPU brick is referred to as an O350 until a cable is installed. 32 The Onyx4 is a modular SGI workstation that uses the same Chimera chassis as the Tezro rack, Origin/Onyx 350, with the graphics option being the main difference. 33 It uses ATI FireGL X1 cards, which can boot an x86 machine, but the X1 BIOS from an Onyx4 freezes an x86 machine when the second card is present. 34 The FireGL X1 in an Onyx4 is significantly faster than the V12 for GPU-intensive tasks. 35 The Onyx4 can only use x1 cards, and the X3 won't work in it because drivers are only for FGL 9700 and two 9800 variants. 3637 The Onyx4 uses the same Chimera chassis as the Tezro rack, Origin/Onyx 350, with the graphics option being the main difference. 33 The Onyx4 was marketed heavily for geology oil well stuff, healthcare, and had a focus on multipipe and Vizserver; it did not sell well. 38 The Onyx4 experiences issues with nvrams and snaphats during brick to brick communication, which causes a failure. 39
