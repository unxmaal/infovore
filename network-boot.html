network boot

Claims: 6 Part of network

The Sun E250 can boot from the network by default. 1 For Solaris, setting the root directory for network boot to "/share/nfs/solaris/Solaris_10/Tools/Boot" is necessary for it to find the install media. 2 A flat NVRAM will not cause SCSI errors but may cause a network boot (diag-boot). 3 You cannot boot miniroot without a drive unless you network boot, and booting fx might allow you to wipe and repartition to ensure a clean volume header and root partition scheme before copying a fresh miniroot. 4 Bootstrapping IRIX over the network is the only method, and it is not difficult. 5
