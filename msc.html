MSC

Claims: 7

The MSC is a component that can coexist with 400 MHz node boards, IR2 boards, router boards, and Octane motherboards in a system. 1 The MSC monitors the fans, and a fan tray is recommended for reliability. 2 On an Onyx2, the module ID can be queried with 'mod' and set with 'mod <2-digit hex number>', which affects address space allocation. 3 The MSC continued to receive standby power after a PSU failure, indicating not all parts were completely blown. 4 The MSC has jumpers for different levels of diagnostics, overriding nvram values. 5 The MSC is on a different bus from the SCSI one. 6 MMSC is a touchscreen UI that sends the same command to multiple MSCs. 7
