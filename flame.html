Flame

Claims: 40 Background: 2 claims already covered by Wikipedia, see Autodesk Media and Entertainment, FFmpeg.

Flame is a compositing program used on SGI machines in the mid-'90s, and earlier versions show clear signs of Quantel Paintbox/Harry influence. 12 Flame combines node-based, layer-based, and timeline-based systems, along with 3D and real-time grading, offering extensive versioning, transcoding, and media management tools. 3 Flame is the SGI equivalent of After Effects, and Effect is similar but lower-end. 4 Flame was IRIX exclusive until around the mid-2000s, and older versions can use a file for the framestore while newer versions require a dedicated disk or array. 56 Flame can run on various SGI machines, including the O2, Indigo2, Octane, and Tezro, though some versions require specific hardware or adjustments. 789101112 Flame can run without external hardware, but some setups include external video boxes and serial port cards. 1314 Flame can run on Linux, and requires specific HP Z-series workstations with certain video and graphics cards running RedHat Enterprise Linux. 1516 Installing Flame on IRIX can cause failures if the IRIX install or installed software doesn't agree with it, and it can alter the IRIX experience in an undesirable way. 1718
