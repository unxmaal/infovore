PROM code

Claims: 6 Part of PROM

PROM code is sometimes interesting despite being written more carelessly than the kernel. 1 A mini PS2 keyboard works in the Fuel PROM but not in the Indy PROM, possibly due to older PROM code. 2 There was a timing loop in the PROM code that caused issues with volume buttons, likely related to interrupt handling, and the PROM code might be blocking itself. 34 PROM code can be patched and burned to make a system Y2K compliant and boot faster by modifying checksum and MP check. 5
