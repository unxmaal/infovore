filesystem

Claims: 26 Background: 3 claims already covered by Wikipedia, see IRIX, Unix, XFS.

The filesystem is organized around the OS in the Unix style. 1 The `fx` command creates the disklabel or partition table, while `mkfs` creates the filesystem, and the latter can only be executed after booting into the installer or a minimal live version of the OS. 2 XFS is an SGI filesystem, and its Irix version uses 32-bit date stamps, so setting the clock forward will cause the filesystem to interpret the time incorrectly. 3 Reading SGI filesystems like EFS and XFS can be complicated due to disklabel and filesystem issues. 4 The SGI filesystem can be challenging to recover data from using UFS explorer. 5 XFS post Kernel 3.16 lacks dir v2 support, risking data loss, and no common filesystem is compatible with Windows, with GNU/Linux support being rare. 6 The O2 does not support mass storage for IRIX. 6 The file system operations use a global lock, leading to synchronous operations and performance issues. 7
