VirtualBox

Claims: 46 Background: 8 claims already covered by Wikipedia, see VirtualBox.

VirtualBox is open source software that emulates Intel-based systems, so it cannot run operating systems using other architectures such as IRIX or the SPARC and HPPA versions of certain systems. 12345 VirtualBox is available for Windows, Mac, and Mac/ARM64, and can be installed using Chocolatey on Windows or brew cask on macOS. 678 VirtualBox supports bridged networking, which may require the correct network card and disabling firewalls, and can boot from a second disk. 91011 VirtualBox can emulate a Soundblaster 16 and the VESA driver works in it for OPENSTEP, but its ATA driver does not support ATA33 or later or SATA. 121314 VirtualBox can run various operating systems, including SCO OpenServer, OS X El Capitan at native resolution, DOS, PC DOS 2000, and Maya 4.5 on Windows XP. 151617181920 VirtualBox can convert VHDs to .img or .iso, and can use Hyper-V when it is enabled on the host, which can cause memory issues in VMs. 212223 VirtualBox has known issues, including kernel module problems that can cause SSH failures, networking problems in containers, and failures to start VMs with exit code 1. 242526 VirtualBox is a virtualization platform that can emulate x86 PC hardware, allowing software such as an L3 controller to run under it with some configuration. 27 It can run IRIX on an Indigo by setting the host PC's network configuration to match the Indigo's defaults and bridging the virtual network interface. 28 An Octane can connect to a Windows XP VM via bridged networking by configuring the VM in VirtualBox and setting a static IP on the host PC's network interface. 29 VirtualBox supports USB passthrough for flash mode. 30
