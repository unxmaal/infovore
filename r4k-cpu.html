R4K CPU

Claims: 21

The R4K CPU was released in 1992. 1 The R4K CPU was used in various SGI machines, including the O2, N64, Origin 2K I/O module, Elan, Crimson, Indigo, Indigo2, and Onyx. 2345 The R4K CPU is fast in SGI machines, and an R4K CPU with an XL24 card is common. 62 The IP12 system uses an R4K CPU, and a Z50 has a 133 MHz R4K CPU without L2 cache. 78 The R4K CPU supported IRIX 4.0.5 on Indigo and Indigo2 models. 9 Starting from 5.3+XFS requires an R4K CPU for the first stage, and IRIX 5.3 XFS can be installed on an R4K CPU with no more than 1MB cache after applying patch sets. 101112 The R4K CPU can fail when running MIPS-4 binaries. 13 The Elan with R4K CPU experiences random display blanks after a fresh IRIX install. 14
