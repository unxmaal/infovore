cooperative multitasking

Claims: 3

Classic Mac OS, up to OS X, used cooperative multitasking and lacked memory protection. 1 Cooperative multitasking does not support symmetric multiprocessing, as it negates the benefit of a second CPU. 23 In contrast, preemptive multitasking allows background tasks to run on a second CPU. 3

Sources

  1. The Mac OS up to OS X did not have memory protection and used cooperative multitasking. (user-e0a4, 2020-05-19, exchange 204275, check: uncheckable)
  2. Classic Mac OS does not support symmetric multiprocessing due to cooperative multitasking in the CMP environment. (user-1361, 2022-03-11, exchange 233979, check: uncheckable)
  3. Cooperative multitasking negates the benefit of a second CPU, while preemptive multitasking allows background tasks to run on the second CPU. (user-baf6, 2023-01-14, exchange 222800, check: uncheckable)
