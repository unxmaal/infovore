grep

Claims: 11

grep is a Unix tool used for searching text, and it is more efficient than writing scripts in languages like Clojure for simple tasks. 1 It is a dependency for building git with Didbs, alongside diffutils, ncurses, bash, openssl, curl, tk, and expat. 2 Common uses include verifying the environment by checking for specific versions, finding instances of a string in a build tree, and locating ELF files in a directory. 345 A variant, GrepWIn, is a Windows version of grep. 6 The gmake check for grep can fail on IRIX due to missing tests or system Perl differences, and some systems lack GNU grep with the -R option. 78 pcrecpp and grep build successfully with no regressions. 9
