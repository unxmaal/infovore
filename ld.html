ld

Claims: 13 Background: 1 claim already covered by Wikipedia, see GNU Debugger.

ld is the linker used by various Unix-like systems, including IRIX, where its porting guide recommends using IRIX's ld because binutils does not support the necessary ABIs. 1 Configure scripts and makefiles use environment variables such as CC, CXX, and LD to select the compiler, but not all packages respect these variables, particularly for cross-compilation. 2 ld can crash when linking against certain libraries generated by binutils, and simplifying the link commands may resolve the problem. 3 For consistent builds, the first ld in PATH should be from GNU binutils. 4 Running ld with debugging symbols and without optimization is recommended for best results with GDB. 5 ld crashes due to alignment issues in older nekoware libraries, where newer binutils output warnings that crash instead, with a fix expected in 0.1.5. 6 Renaming ld and creating a script to transform -Wl,-R to +b can resolve the issue. 7 The LD command for Nekoware requires a slightly different -rpath invocation compared to GNU's LD, needing quotes and an extra backslash for escaping in the makefile. 8
