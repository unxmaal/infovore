single user mode

Claims: 19

Single user mode is a boot state used for system maintenance, and on most versions of Unix it can be used to change the root password by editing the /etc/passwd file. 12 Booting into single user mode can help diagnose disk issues, since shutting down to it may kill the process accessing a problematic block and allow data recovery. 34 Reinstalling an operating system may require single user mode along with mkfs to avoid installing over existing data. 5 Entering single user mode varies by system: IRIX requires typing 'single' at the PROM prompt, tru64 boot flags control whether it starts in single user mode, AIX 4.x may need 'varyonvg rootvg', and the RS/6000 running AIX 5.3 requires a password and the correct media to boot into recovery mode. 6789 Some systems require a PROM password to enter single user mode, and console access via a null modem cable or serial console can make troubleshooting easier. 1011 Single user mode is also used for other tasks, such as installing Solaris packages, booting into miniroot, and performing operations over NFS. 121314
