MAME

Claims: 273 Background: 15 claims already covered by Wikipedia, see MAME.

With Indy

MAME can emulate an Indy, which is useful for running old software on newer hardware, though performance depends on hardware and the emulation is slow and not perfect. 123 The Indy requires specific keyboard input settings in MAME, and MAME defaults to 256 MB RAM, though 16 MB is below the Indy's minimum RAM. 45 The Indy's networking might not work in MAME, and using MAME for networked IRIX on an Indy might be a bad idea. 67 The patched version of MAME allows the Indy to start up, but it crashes during framestore initialization. 8 The MAME driver for the Indy is stable but not perfect, and Indy emulation in MAME can be used for initial work. 910 plan9/9front includes an indy source port, and these specs were released to support open source development on the Indy; without them, MAME would not support the Indy. 11 Documentation for setting up an emulated Indigo 2 or Indy in MAME is available, with incomplete IRIX installation steps. 12

With IRIX

MAME provides support for IRIX emulation, though the extent of this support varies by version and hardware target. 1314 The only MAME target capable of emulating IRIX is the indy target, which emulates an R4k Indy and a version of a Personal IRIS 4D/25, and is 2D only and imperfect. 1514 MAME is considered the best emulator for IRIX, though performance may vary and it runs at about 1/3 speed, which may not be ideal for development purposes. 1516 The new R4k core in MAME does not allow installing IRIX due to issues during finalization, though disabling CPU overclocking can improve emulation performance. 1718 The files needed for emulating IRIX on MAME can be found linked from a Pinned post on the IRIXNet wiki. 19 Firefox and Netsurf run on IRIX via MAME emulation, though with known issues. 20
