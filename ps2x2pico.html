ps2x2pico

Claims: 5

The ps2x2pico project uses a Mini Pico with USB Type-C. 1 Software can bitbang USB ports on the ps2x2pico, but it lacks a USB hub chip. 2 The ps2x2pico supports USB hotplug and keeps local keyboard state across different systems. 3 The ps2x2pico can be used for both a PS/2 device and a mouse simultaneously with some soldering and a USB-C to 2 USB port mini hub. 4
