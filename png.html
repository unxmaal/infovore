PNG

Claims: 6

PNG files can be converted from other formats using the SGI image utility, which supports conversion from PIC files to PNG or TIFF. 1 Imgview, a built-in utility, is used to convert SoftImage renders to PNG. 2 Later IRIX 6.5 releases could display PNG backdrops, with system background files stored in `.backgrounds` and `/usr/lib/X11/system.backgrounds`. 3 Screenshots taken in the sginet client are automatically converted to PNG for download from the website, and the command to take a screenshot in IRIX is scrsave or sginet, which uploads to the cloud as a PNG. 45 Building with mipspro can fail due to memory corruption issues during PNG loading, while building with gcc works but requires modifying the GNUmakefile to link with -laudio and -lpthread. 6

Sources

  4. screenshots taken in the sginet client are now automatically converted to png for download from the website (user-7973, 2024-06-09, exchange 85262, check: uncheckable)

  6. Building with mipspro can fail due to memory corruption issues during PNG loading, while building with gcc works but requires modifying the GNUmakefile to link with -laudio and -lpthread. (user-21b8, 2025-07-18, exchange 215770, check: uncheckable)
