BSP

Claims: 3

The BSP is a programmable device tailored for processing bitstreams of compressed data, featuring a 16-bit RISC-like load-store architecture with instructions for manipulating tokens and performing table lookups. 1 It can be used as an RDP command parser, streaming data from main memory with DMA and processing display lists, though this requires CPU intervention for CRIME rasterizer interaction. 2 Android is pushing for a stable kernel interface (GKI) for BSP to prevent vendors from shipping modified kernel sources and abandoning the tree. 3
