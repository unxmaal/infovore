external SCSI drive

Claims: 3 Part of external SCSI Background: 1 claim already covered by Wikipedia, see SGI O2.

External SCSI drives can be used to install Tru64 on a Multia, though an appropriate Unix version such as Digital Unix v3 or 4 is recommended because the Tru64 user interface is poor and not well-maintained. 1 The O2 can use an external SCSI drive for additional storage. 2 ZapIt recommends using one external SCSI drive, one dedicated internal SCSI drive, and one via a 2940 card, all mirrored. 3

Sources
