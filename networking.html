networking

Claims: 28

Networking setups can require additional configuration, such as running Ethernet through the attic for an Octane. 1 PLIP allowed DOS and early Linux systems to use the parallel port for networking, achieving speeds of 40kbyte/s, with newer ECP/EPP ports reaching megabytes per second but being more prone to issues. 2 Parallel port networking faced issues like IRQ/DMA problems and flaky drivers/OS, especially in DOS. 3 The Altix 330 can be networked but does not follow the IP assignment guidelines in the owner's manual, and the L1 USB port's network connection is not immediately obvious from standard network tools. 4 Using networking (ftp or nfs) is quicker and easier than setting up serial ports for the Indy. 5 The motherboard chipset, graphics, and networking are usually compatible with older operating systems like Windows 2000. 6 MAME supports networking, including NFS or FTP for file transfer, though its networking can be affected by packet size issues, especially with emulated Ethernet chips. 78 IRIX 5.x supports proper networking, and to configure networking, IP and DNS are set up from within IRIX. 910
