boot chime

Claims: 9 Part of boot

An Indy can still work if it powers on and has a boot chime, whereas the Indigo2 had issues with booting when the green LED was lit but no boot chime. 12 The SGI O2 generates its boot chime using the Karplus-Strong method on uninitialized memory, leading to unpredictable results even in emulation. 3 No boot chime can indicate that no keyboard or mouse is attached, the Dallas battery is dead, or the monitor can't handle sync on green, and a serial cable can help diagnose these issues. 4 The lack of a boot chime is not a concern if the AV card is removed because it's broken. 5
