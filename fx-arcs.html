fx.ARCS

Claims: 5

fx.ARCS is one of the boot options available on 4.0.5H, alongside fx.IP5 and fx.IP17. 1 The bootp() command attempts to boot from fx.ARCS for IRIX 5.3. 2 Net installing IRIX 5.3 to an Indigo requires booting fx.ARCS software via BOOTP, but file transfer may hang due to unknown issues. 3 The Indy may require a valid boot file for bootp to work, as an error can indicate a problem with the fx.ARCS file. 4 Booterizer does not support using fx.ARCS on an Octane; fx.64 should be used instead. 5
