miniroot

Claims: 53 Background: 2 claims already covered by Wikipedia, see SATA, XFS.

Miniroot is the SGI environment used for installation and certain maintenance tasks. 1 It is available on IRIX install discs, where the Install Tools and Overlay 1 disc contains the miniroot for the installer. 2345 It can be booted from a CD, from tape (not supported in IRIX 6.2), from SCSI and handed over to SATA, or over the network. 678 Booting into miniroot allows access to the disk, such as mounting the original disk, unmounting and remounting the root disk to modify the root partition while booted, and mounting /dev/realroot at /root. 91011 It can be used to grow the root file system onto another disk with xlv, to fix the hwgraph tree with ioconfig, to edit /etc/passwd for access, and to reload root's tcsh. 12111314 It has rsh and rcp but not SCP, and lacks some commands such as tr. 1516 It can configure the IP, mounts partition 1 as swap, and may show different slice numbers for the same disk compared to a full IRIX installation. 171819 Booting into miniroot may require single-user mode, and issues with it can cause boot failures, kernel panics, and write failed errors. 2021222324 Diskless booting involves copying a miniroot to a swap partition and mounting it as root, requiring a kernel capable of mounting the root filesystem and a PROM environment that can specify the root path. 25 The miniroot is used during IRIX installation rather than for booting the system, and has been the preferred way to install IRIX since at least IRIX 3.X. 2627 The miniroot is stored on the disk's swap partition and may indicate a previous failed installation attempt. 28 Without a drive, Sash cannot load the miniroot. 29 If you have a corrupt filesystem on your disk, the miniroot may attempt to mount it and crash, so it is a good idea to format the disk before installation, especially with old disks. 30 Miniroot can be used to reset passwords on a locked out IRIX system, and the Indy can boot miniroot to reset the password, giving a warning if the root password seems changed. 3132 You can boot into miniroot from an install medium to fight with inst again. 33 XFS changes the on-disk format, making the miniroot of the original install CDROM unable to read the installed system disk. 34
