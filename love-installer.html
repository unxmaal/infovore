LOVE installer

Claims: 6 Part of LOVE

The 'love' installer requires a modern OS on x86 or MIPS, which should resolve compatibility issues. 1 An Octane can use a 300GB disk, and the love installer was used. 2 The LOVE installer is not available, and the binary requires debug DLLs. 3 To run LOVE on IRIX, configure the LABELS.UNIX file with correct paths. 4 To start the installation, netboot the LOVE installer over TFTP and load the second stage file and install media over HTTP; DHCP needs TFTP parameters set; patch 'mod_install.sh' and 'mod_palo.sh' before rebooting to use. 5 Reanimator or the LOVE installer can be used for network installation of IRIX. 6
