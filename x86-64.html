x86_64

Claims: 14 Part of X Background: 1 claim already covered by Wikipedia, see OpenVMS.

Vendors chose Itanium for true 64-bit computing with a clean room design, as there was no other x86 until AMD pioneered x86-64. 1 x86_64 extended the ISA to 16 registers and added flat addressing mode. 2 128-bit operations are less common than 64-bit operations in x86_64 architecture. 3 OpenVMS for x86_64 is available for EAKs. 4 Windows XP source code no longer includes MIPS support but has full code for Itanium, x86, x86_64, and Alpha platforms. 5 An HP executive stated that HP-UX is unlikely to be ported to X86_64 and will die when support for Itanium ends. 6
