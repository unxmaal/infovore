MVP

Claims: 4

An MVP should have up-to-date basic tools and extensions, be easy for new users to install and use, and run without performance issues or serious bugs. 1 The `videostatus=illegal_env_var` message indicates that the O2 did not accept one of the four configuration values for the MVP or did not find a video MVP at power-on. 2 If the MVP is recognized and the four environment variables are set appropriately, the system reports `videostatus=inited`. 3 If a tool can't bootstrap itself, it is not a hard blocker. 4
