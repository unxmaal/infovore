RAT

Claims: 12

RAT is a RenderMan translator and plugin for Maya and Alias software that allows scenes to be rendered using RenderMan, and there are versions of RAT for most versions of Maya and PRMan. 123 RAT allows using the RenderMan shading language and a node editor for custom shaders by connecting nodes. 4 RAT can be configured to use different versions of RenderMan, as well as the Entropy or BMRT raytrace servers, which process raytracing calls and map results onto geometry. 5637 RAT was used for rendering content for the original Final Fantasy 7 by the team at Square. 82 For IRIX, RAT 4.5b1 is for Maya 2.5, and RAT 5.0 is for Maya 4.0. 9
