General

MIPS was one of the earliest RISC architectures, was huge in embedded systems, and survived SGI, but has since declined. 12 MIPS has fewer instructions compared to x86. 3 MIPS is a meaningless indicator of processor speed. 4 MIPS gained support from a Chinese company. 5 RISC-V is a modern ISA with some advantages over MIPS. 6 Compiling for MIPS on Linux uses GCC, and LLVM has a MIPS backend. 78 Rene Rebe of T2 Linux SDE got MIPS working in mainline Linux. 9 SBCL's MIPS backend is done and already has Linux-MIPS support. 10 MIPS is a big-endian architecture that typically includes only an FPU, though the Nintendo 64's RSP is a MIPS III variant with 8-lane 16-bit vector capabilities as a coprocessor. 1112 MIPS does not support SIMD instructions, and branch comparisons are only between pairs of registers or between one register and zero, with conditional jumps supported by instructions like BEQ and BNE. 131415 MIPS processors were used in SGI systems, which ran IRIX and used ARCS firmware, as well as in the Cobalt RAQ machines, the Personal Iris, and early Ultrix machines. 161718192021 MIPS support is disappearing, as it was discontinued when the mobile and embedded markets shifted to ARM, and OpenBSD cavium support is being removed. 2223 MIPS ports of OpenJDK exist but are of the wrong endianness, and MIPS codegen works with the n32 ABI even on a poorly tested target. 2425 MIPS influences instruction set architecture design when creating a CPU on an FPGA. 26 MIPS has unusual features such as all-in-one compare-and-branch instructions and a branch delay slot, in which the instruction is executed before the branch is taken, but it is still considered a good architecture, and RISC-V is very similar to it. 2728 RISC/OS development was stopped around 1992 when SGI bought MIPS, and SGI quickly switched to using MIPS processors. 2930 RISC/os contains code for multiple architectures including MIPS and R2300, and the 3.7 source tree contains MIPS-specific code that can be compiled as SVR3 or SVR0. 3132 The best DEC machines ran MIPS, with Personal DecStation 5000s using MIPS processors before Alphas followed. 33 Some early models use i960 and Intel RISC CPUs, while others use MIPS, and they can use IBM PS/2. 34 Steve Jobs saw MIPS as better suited for computer graphics than for raw power. 35 MIPS originated as a research project at Stanford. 36 MIPS CPUs run two threads per CPU, whereas PowerPC runs a single thread per CPU. 37 MIPS licensed the R4200 to NEC, who created the R4300i variant, and MIPS created the specifications for the Nintendo 64's CPU. 3839 RISC-V is similar to MIPS but without delay slots. 40 Non-modern RISC processors like MIPS have poor code density, which is why ARM has features like Thumb. 41 MIPS changed the specification for its chips in the early 2000s, so code should be recompiled and assembly code heavily reviewed, as the results are very similar but not compatible. 42 The Open MIPS initiative was reversed in 2019, affecting MIPS's competitive position against ARM. 43 MIPS abandoned support for the MIPS architecture, but the name MIPS is still used. 44 The MIPS instruction rate is calculated every frame and varies due to cache misses, TLB lookups, and bus hits. 45 The MIPS emulation loop involves multiple steps including checking for interrupts, translating and fetching instructions, decoding, executing, handling exceptions, and advancing the instruction pointer. 46 Clock rate is not a great performance indicator for MIPS because of stronger IPC. 47 Microsoft abandoned MIPS for Windows CE. 48 NetBSD is listed as supporting MIPS, but there is no evidence of Indigo2 running it. 49 A BSD flavor runs on MIPS but not optimally. 50 The old live CD RC6 for MIPS is no longer available, and no new releases followed. 51 Gentoo does not run on MIPS machines anymore. 52
