Rosegarden

Claims: 8

Rosegarden is a GUI sequencer program that originated as an IRIX application and is distributed as a 32-bit executable requiring a 32-bit IRIX installation, such as on an O2. 12 Rosegarden version 2.1 is the latest release with a native IRIX build. 3 Rosegarden can be used for experimenting with pure data synths in a MIDI fashion. 4 On an Octane V10, Rosegarden felt a bit choppy on user input but was responsive in output, with a default response rate of 200ms that could be improved with -burn mode, which uses more resources but renders in real time. 5 Rosegarden's -burn mode uses around 35 GPU resources on an Octane V12 and around 10 on an O2, with CPU utilization around 80% on an O2. 6 Rosegarden encounters font and Petal library errors when run as root, and fails with a calloc error when run as a non-root user. 7
