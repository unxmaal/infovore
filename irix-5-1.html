IRIX 5.1

Claims: 16 Part of IRIX 5 Background: 2 claims already covered by Wikipedia, see IRIX, SGI Indy.

The Indy was launched with IRIX 5.1, which was slow, buggy, and had severe memory leaks that made it almost unusable. 123 IRIX 5.1 had a memory manager that only correctly handled contiguous physical memory, making it inefficient, and it had 40% worse performance for common operations than 4.0.5. 45 The R4000PC has 8-bit graphics, 16 MB RAM, runs IRIX 5.1, and has a 1 GB hard drive, while the 100 MHz Indy R4000 PC supports up to 32 MB of RAM and runs IRIX 5.1. 67 IRIX 5.1 does not have 4sight, and the Ultimedia sound devices aren't supported in IRIX 5.1. 89 The CD 812-0251-002 contains a patch for XL graphics, but it is only for IRIX 5.1, and Quorum Equal 1.2 supports Irix 5.1. 1011 The Indy can run IRIX 5.1, and the drive was originally 5.1. 112
