tar

Claims: 45 Background: 7 claims already covered by Wikipedia, see Tar (computing).

tar is a command used for backing up data to tape and for transferring files on and off tapes and onto hard drives. 12 tar can create archives, list their contents without extracting them, and identify whether a file is a tar archive. 34 tar can extract archives in various formats, including .tgz, .tar.xz, and XZ files, and can decompress gzip files without damaging the original. 5678 The tar command with the f option requires a single '-' to indicate stdin, with no space before it. 9 Older tar implementations, such as IRIX tar, do not automatically detect compression, unlike GNU tar, and installing GNU tar can solve this issue. 710 tar can overwrite files if not used with the correct options, and old versions might create archives with absolute paths that can overwrite the root directory when extracted. 1112 tar may encounter input/output errors when reading from a tape, and certain programs may fail if the directory contains a file with a .gz extension. 1314 tar is easier to use than dd for copying files, but dd is necessary for boot sectors and for creating exact images of tapes. 1516 The command tar -xvf /path/to/source.tar -C /destination_dir extracts a tar file to a specified directory. 17
