Windows 10

Claims: 52 Part of Windows Background: 7 claims already covered by Wikipedia, see Windows 10, Laptop, Video games and Linux.

Windows 10 supports NFSv3, with NFS client support provided through WSL, while older versions use Services for NFS. 1 Upgrading to Windows 10 broke many Java-based tools, requiring users to either use old Java versions or pay Oracle. 2 Windows 10 includes OpenSSH and NTVDM components for running 16-bit Windows programs, though the latter are not installed by default. 34 Windows 10 with WoW64 can run applications released with Windows NT RTM (1993). 5 Windows 10 updates can cause BSODs with the latest Nvidia drivers, reboots, and can destroy the system. 678 Windows 10 can run on ARM processors, including Raspberry Pi 3, through emulation. 9 Windows 10 can be made to work without bloatware and spying, and there is a tool to de-bloat it. 1011 Windows 10 has good driver support for new hardware out of the box. 12 Windows 10 is suitable for gaming and can support unusual peripherals. 13 It does not have NT4 back compatibility. 14 SimSun-ExtB comes with Windows 10. 15 An update has caused a Blue Screen of Death on many Windows 10 machines, requiring local access to fix; the incident is unclear whether it was malicious or incompetence. 16 chkconfig can be used to manage NFS services, and there are instructions for enabling NFS client on Windows 10. 17
