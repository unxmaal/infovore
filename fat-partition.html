FAT partition

Claims: 3

Using a FAT partition allows compatibility with both Windows and Mac. 1 The installer may require a larger FAT partition for the system partition. 2 A small FAT partition needs to be present, which is better on the AS800, while the AlphaStation 200 needs a special program to do it; the partition is visible and gets mounted as C, while Windows is booting from D. 3
