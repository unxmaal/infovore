Pascal

Claims: 15 Background: 1 claim already covered by Wikipedia, see C (programming language).

Pascal is a high-level programming language that uses `:=` for assignment rather than `=` or `==`, and it influenced the development of C. 1 Pascal is more verbose than C, and Mesa is similar to Pascal. 23 The Mac OS and the Lisa were built in Pascal. 4 The book 'Computer Graphics: Principles and Practice' used Pascal for examples in its first edition and switched to C in the second edition. 5 The Oberon programming language is the sequel of Pascal and Modula, and there was an operating system with the same name written in that language. 6 Pascal runs on IRIX but not on IPX because IPX is v7, and it is included in some IRIX Developer Option CDs, specifically versions 5.x and 6.x. 78 A Solaris VM can cross-compile a Pascal program from x86 to SPARC. 9
