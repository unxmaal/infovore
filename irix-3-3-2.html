IRIX 3.3.2

Claims: 27 Part of IRIX 3.3 Background: 1 claim already covered by Wikipedia, see IRIX.

IRIX 3.3.2 installs on any PI and includes 4D/35 stuff, along with most optional subsystems like development, NFS, and X11. 12 The installation process involves booting into a standalone shell and using commands to install the system from a network server, requiring specific files and folder structures to be in place. 3 The 'user-c9fb Tape Method of Non-Maintenance Installations' (STMONMI) installs IRIX 3.3.2 without maintenance tapes, using a specific sequence and a 96MB IP12 machine with a spinny HD. 4 IRIX 3.3.2 can be installed on 4D/35 with the recent update, overcoming previous swap partition issues. 5 The kernel of IRIX 3.3.0 and 3.3.2 crashes due to SCSI emulation errors when accessing the s1 partition. 6 The IRIX 3.3.2 kernel has SCSI issues with PI 25 in MAME, likely due to unemulated SCSI commands/functions required by IRIX 3.3.2 but not IRIX 4. 7 X11 forwarding works in IRIX 3.3.2/MAME, allowing copy and paste, but NeWS applications are not supported. 8 MAME emulates PI 35MHz at full speed with IRIX 3.3.2 including networking but no graphics. 9
