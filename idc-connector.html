IDC connector

Claims: 3

The front panel of the system connects to a little blue IDC connector next to the power, which contains an EEPROM with the system ID and MAC address. 1 For the 20-pin ribbon cable, the IDC connector is only 26-28awg, and the ribbon cable is already 26awg, so a single ferrule was used for crimping. 2 The Indigo VME graphics set uses an IDC connector for memory expansion up to 64MB (32MB base). 3
