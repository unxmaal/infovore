IRIS

Claims: 164 Background: 4 claims already covered by Wikipedia, see SGI IRIS, SGI Indigo, SGI O2.

The Iris is a deskside, fast 3D graphics workstation with homemade construction. 12 The Iris runs on System V, and the PI is a MIPS-based Iris model, while there are few known 68k-based Iris systems, with only a handful in collectors' hands. 34 The SCSI2SD works on Indigo1 and Iris, and an MFM emulator is needed for an Iris due to its drive pickiness. 56 The fixed disk on an Iris is ESDI off the storage card and cannot boot from 9-track, and the machine requires at least 10MB of storage. 78 The VideoFramer is a VME card inside the IRIS, and the Iris uses parallel and heatsinked 74 series logic. 910 A personal Iris power supply is complex and may contain fuses, and blown bypass capacitors can cause system failures. 1112 Professional and Personal IRIS, and Crimson systems may have capacitor issues, and every personal IRIS has rust along the expansion port slot, likely due to adhesive holding black plastic strips on. 1314 The game targets IRIS for graphics rendering, as the Indy does not support OGL, and will use an OGL renderer for newer SGI machines if IRIS is not supported. 1516 The IRIS was released in 1988 and was the first SGI system available for general purchase without a department grant. 1718 The IRIS could render 3D objects in 1983. 19 The IRISes run Unisys Unix on m68k processors with specialized graphics hardware. 20 The IRIS can generate multiple video modes, including 30/60 Hz interlaced normal RGB and NTSC composite video, depending on the PROM set installed in the DC4 board. 21 The IRIS File can hold up to five SCSI devices and was designed to extend the SCSI bus of the IRIS. 22 Schematics for some IRIS boards are available, but not for the GF2. 23 The IRIS uses a -12V rail for components like the system fan, which operates between 7 and 18 volts and is not driven by the same 12V bus as other system components; insufficient voltage can lead to overheating. 24 IRIS is a MIPS CPU emulator that supports network emulation, including DHCP, netbooting over ethernet, and NAT to allow multiple instances to communicate. 252627 It emulates MIPS CPUs with software interpreters and JIT compilation, achieving performance close to hardware, and supports serial ports via local sockets. 2829 IRIS can run OpenBSD and NetBSD to user on serial console, run OpenBSD from an IP22 kernel with a custom loader, and run a local NFS server on custom ports. 3031 It can be run in headless mode with command-line options, supports --headless, --noaudio, and port forwarding, and has default settings for easier initial setup. 323334 IRIS is multithreaded and feels responsive due to offloading rendering and other tasks to separate threads. 3536 It tops out at 160 MIPS, caps around 50 MHz on some machines, and emulates MIPS4 ISA R5K at around 150 MIPS. 373839 IRIS is available on the Mac App Store. 40 IRIS is a project aimed at creating a reasonably working SGI machine for fun, with command-line and GUI wrappers for IRIX available via cargo. 414243 IRIS is a MIPS emulator that runs instructions as fast as possible rather than being cycle-accurate, and it runs faster than MAME on more high-spec machines. 4445 The latest release of IRIS, available via GitHub or from source, is recommended for best performance. 46 IRIS has a dual-threaded architecture for register processing, rendering, and VBLANK handling, with memory accesses mostly atomic. 47 A JIT has been added to IRIS and needs testing, requiring about 4 fast cores plus a few more for JIT to run many parallel compiles. 4849 IRIS runs on a Raspberry Pi 5 at 40 MIPS, and a build for kms/libinput is needed to boot directly to an IRIX login. 5051 The goal of IRIS includes speeding up the CPU to enable O2 PROM hacking, considering CRM graphics in compute shaders, and fixing outstanding bugs in Iris IP22, with bug fixes prioritized before new features. 52 IRIS has CI for sgug. 53
