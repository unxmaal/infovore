SunOS 3

Claims: 4 Part of SunOS

SunOS 3 media contain the executables in.tftp and munix_sun3, but booting with munix_sun3 results in an incomplete process. 1 Booting with in.tftp also did not succeed, and there is no documentation for netbooting SunOS 3. 2 SunOS 3 produces serial junk before reaching a normal login prompt. 3 SunOS 3 works on a serial console, whereas SunOS 4 does not always work on one because some SunOS parts were not 8-bit clean. 4

Sources

  1. The executables in.tftp and munix_sun3 are present in SunOS 3 media, but booting with munix_sun3 results in an incomplete process. (user-9528, 2024-02-15, exchange 240248, check: supported)
  2. Booting with in.tftp also did not succeed, and there is no documentation for netbooting SunOS 3. (user-9528, 2024-02-15, exchange 240248, check: supported)
  3. sunos 3 does the same thing as waiting through serial junk to get a normal login prompt. (user-9528, 2025-10-05, exchange 186762, check: supported)
  4. SunOS 4 does not always work on serial console, while SunOS 3 does; some SunOS parts were not 8-bit clean. (user-03ad, 2025-10-05, exchange 186767, check: supported)
