rx5670

Claims: 4

The rx5670 is an Itanium upgrade for old rp54XX machines, offered as either a kit or an in-cabinet upgrade. 12 It uses L class type disk sleds rather than Netserver type sleds. 3 VMS can run on Itanium machines except for the rx5670, which might run VMS despite being unsupported. 4

Sources

  1. The rx5670 was a zx1-based machine in an old HP9000 chassis and could have an upgrade kit. (user-03ad, 2022-05-23, exchange 161967, check: uncheckable)
  2. The rx5670 is an Itanium 'upgrade' for old rp54XX machines, and an in-cabinet upgrade was also available. (user-03ad, 2024-04-09, exchange 216488, check: uncheckable)
  3. The rx5670 does not use Netserver type disk sleds; it uses L class type sleds. (user-03ad, 2025-04-09, exchange 163998, check: uncheckable)
  4. The Itanium can run VMS except for the rx5670, which might run VMS despite being unsupported. (user-03ad, 2022-05-23, exchange 161970, check: uncheckable)
