default gateway

Claims: 3

Default gateway and subnet mask are crucial for network configuration and should be determined before connecting a machine to the network. 1 Out of the box, IRIX might DHCP only the IP and not the default gateway. 2 Setting both machines to leave the default gateway blank may allow them to connect directly via Ethernet. 3
