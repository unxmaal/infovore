command line

Claims: 5 Part of command Background: 1 claim already covered by Wikipedia, see FFmpeg.

Every SGI supports command line and UNIX, with options like ksh or bash for scripting. 1 The limit for the length of a command line is not imposed by the shell, but by the operating system, and is usually in the range of hundred kilobytes. 2 MAME's configuration is primarily command-line driven. 3 Adding a user from the command line on IRIX involves many steps and can fail if the filesystem is unreliable, such as with BlueSCSI, and rebooting and checking /lost+found may help recover the home directory. 4 ffmpeg can record screen output if ported to IRIX, using command-line options for size, frame rate, and X11 input. 5
