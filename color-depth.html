color depth

Claims: 11

Color depth refers to the number of bits used to represent the color of a single pixel. 123456789 Most Unix workstations used 8-bit color depth for a long time, and 24-bit was a significant advance. 6 On SGI hardware, color depth is per-pixel rather than locked globally as on PC hardware. 8 The X server may not always honor the requested color depth, so it should be set to 24-bit mode to ensure proper color depth for graphics. 24 Setting the X server to run in 24bpp wastes more memory, provides more colors for wallpapers, and affects the color depth of applications that use CopyFromParent. 9 Software compatibility can affect color depth display, and the dithering effect in 4Dwm frames might be due to monitor settings rather than color depth. 35 Reducing color depth by greyscaling and then coloring with OpenGL can limit rendering speed at high resolutions, especially with many particles. 7 A 5/5/5/1 color depth, used by Sony on the PS2 GPU, can double color space and preserve grays. 1
