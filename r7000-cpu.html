R7000 CPU

Claims: 4

The O2 supports the R7000 CPU, and the CPU PROM sets configuration flags like clock multiplier and cache enabling. 1 The O2's R7000 CPU required PROM modifications for POST, as the BIOS did not fully support the RM7900, which was only pin-compatible but not fully command-compatible. 2 The R7000 CPU had high failure rates. 3 The O2 can use an R7000 CPU; if it is an R7000, it might be valuable. 4
