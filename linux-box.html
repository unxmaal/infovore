Linux box

Claims: 11 Part of Linux

A Linux box can serve NFS for mounting from IRIX, set up FTP for downloading files, or be used as a frontend, though X may be slow. 123 An NTFS partition can serve as the root partition for a Linux box using the new in-kernel driver. 4 A Linux box can copy files from a SGI drive, dd files using SCSI narrow, or convert EFS CD images. 56 An old Linux box with an FDDI concentrator can route between Ethernet and FDDI, while a Linux box running a DHCP server can cause conflicts that disabling resolves. 78 The network is reachable from the Linux box. 9
