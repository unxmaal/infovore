uname

Claims: 7

coreutils installs its own 'uname' which can conflict with the IRIX version. 1 The software checks if the OS is POSIX to copy libraries and tools, and this can be done by modifying the configuration process or the `uname` output. 2 The uname reported by the system may indicate IRIX vs IRIX64 as different architectures, but the binaries are compatible and should run fine. 3 The issue with uname is due to rpm confusion, not software incompatibility. 4 The uname in the second photo is 3.3 ip6. 5 The QP2TERM `uname` binary on os/400 outputs the machine's serial number with extra zeros. 6 uname can report the specific IRIX version being used. 7
