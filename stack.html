stack

Claims: 4

The stack is not resident; it is only active for the lifetime of the process using it. 1 The 'a' instruction pushes variable a onto the stack, '@' pops a variable name off the stack and pushes its value, and '2' pushes the value 2. 2 The 'z' instruction pushes the address of variable Z onto the stack, and '!' pops the first value off the stack, then the second, storing the second value in the address pointed to by the first. 3
