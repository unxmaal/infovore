R3000

Claims: 60 Background: 1 claim already covered by Wikipedia, see R3000.

With R2000

The R2000A is an R3000 core in an R2000 package, and R2000 and R3000 processors have different packages, with the R2000A being a variant. 12 The Personal IRIS IP6 was an R2000-based system, followed by the IP7 PowerSeries with R3000-based 4D/2xx and 4D/3xx systems. 3

With R4000

The SGI Indigo came in two models, the R3000 and the R4000, which used different processors and power supplies, with the R4000 supply having a higher current rating. 4 The R4000 was faster than the R3000. 56 The R3000 Indigo has model number CMNB003 (a 33 MHz machine), while the R4000 Indigo has model number CMNB003B. 7 The R3000 CPU is socketed, whereas on the R4000 it must be desoldered and replaced. 8 The R3000 can be upgraded to an R4000 CPU board, but downgrading to an R3000 is not easily possible. 9 The R4000-based system can run with an R3000 CPU board for a fully working system, though the R4000 board remains as a spare. 10 R3000 and R4000 systems use different memory modules; R3000 systems need proprietary SIMMs, while R4000 models use industry-standard 72-pin FPM SIMMs with parity. 11

General

The R3000 is a 32-bit MIPS CPU that is compatible with the R3010. 1213 The R2000A uses an R3000 MIPS core in an R2000-compatible package, while the R3000 adds multiprocessor support with an unchanged instruction set. 14 SGI reports the R2000A and R3000 together, and some workstations such as the IP12 and IP6 list both despite using an R3000 CPU. 151617 The R3000 powers a range of machines, including the Stardent 3000, Decstations, the PSP, and the PlayStation 2. 181920 The R3000 pipeline can insert stall NOPs for icache misses, affecting jump and branch operations. 21
