virtual memory

Claims: 7

Virtual memory is a system feature that can be enabled or disabled, and the system requires it to be enabled for optimal performance. 1 Virtual memory allows working with larger files than available RAM, though it can degrade performance, as seen with significant performance differences in OS 9. 2 Virtual memory can be used to simulate having a large L1 cache by using a page file. 3 The S/370 line started without virtual memory support, which was later a key feature. 4 Setting all ulimits to unlimited can cause NFS to fail on an SGI, and increasing the virtual memory limit in root's .profile resolves the issue. 5 Linker scripts handle loadable and virtual memory addresses separately, with text and data segments potentially stored in different memory locations. 6
