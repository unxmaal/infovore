vim

Claims: 30 Background: 7 claims already covered by Wikipedia, see Vim (text editor), Integrated development environment.

vi and vim are command-line text editors, and vim is an extended vi clone for the Amiga and other systems. 12 vim has commands for insert, delete, copy, paste, write, quit, and find and replace, and both `x` and `d` can be used to cut highlighted text. 34 vim shows hidden characters and line endings, and it includes the `xxd` command. 56 Vim version 5 or later is needed for Lua and Python support. 7 Vim is not available on IRIX, but the latest vim compiles fine and a package script for IRIX is available. 89 Vim has issues with timers on IRIX, requiring version 8 for use. 10
