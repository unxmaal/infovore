128 MB RAM

Claims: 11 Background: 2 claims already covered by Wikipedia, see Macintosh SE/30, SPARCstation 20.

Solaris 2.3 runs on a SPARCstation 20 with a 75 MHz SuperSPARC-II and 128 MB RAM. 1 The R4400 Indigo2 with 128 MB RAM can run LLMs, but the memory is insufficient for the largest models. 2 A 600 MHz PMC Sierra chip can be obtained for free, and 128 MB RAM sticks for an O2 can cost $132 per 10 sticks. 3 The O2 came with 128 MB RAM and had a webforce bundle for about 6k. 4
