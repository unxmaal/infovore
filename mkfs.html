mkfs

Claims: 16

The `mkfs` command creates a new filesystem, whereas the `fx` command only creates a disklabel or partition table and does not handle filesystems. 123 On IRIX, `mkfs` can be run from the `inst` admin menu to partition and format the drive, which formats the realroot and usr partitions. 456 `mkfs` is also used to clean a single partition on IRIX, and reinstalling an operating system cleanly requires running it in single user mode to avoid installing over existing data. 789 The `mkfs` command can be executed after booting into the installer or a minimal live version of the OS, and it can be run by dropping out to the shell once loaded into the installer. 103 `mkfs` is used to format drives in various contexts, including formatting a Spinny instead of using the low-level format in `fx` for convenience. 116 Unix V7 can load standalone programs like `mkfs` from fixed locations on tape, and the commands `pvcreate`, `vgcreate`, `lvcreate`, and `mkfs` are used together to create a volume group, logical volume, and format it. 1213 A Netra computer given away had issues with RAM during `mkfs` from install tool CDs, and after running `mkfs` during an install it is better to reboot, though it may still work without it. 1415
