LWJGL

Claims: 11 Background: 1 claim already covered by Wikipedia, see OpenGL.

LWJGL is a requisite library for Minecraft, which depends on native libraries for graphics, typically lwjgl, which handles GL calls through JNI, along with Paulscode dependencies. 123 The project uses LWJGL as an in-between for OpenGL and OpenAL, with existing support for x86 Solaris and claims of SPARC support. 4 LWJGL binaries are available for use with OpenGL versions 1.2 and higher, including versions 1.4 and 1.5, and OpenAL is included when compiling LWJGL. 56 Minecraft requires at least lwjgl 2.8.5 or 2.9.0 and Java 5. 7 Running Minecraft on the Pi requires LWJGL and can be done with a script; proper GPU acceleration would help but isn't supported in Minecraft even if available. 8 LWJGL was never compiled for SPARC, and porting LWJGL to IRIX will require writing IRIX-specific display handlers. 910 The Ant command for compiling lwjgl with Java 1.6 sources and target fails due to an unexpected 'import' element in the build.xml file. 11
