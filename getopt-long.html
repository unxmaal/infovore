getopt_long

Claims: 6

getopt_long is available in a GitHub project outside pkgsrc. 1 There is a getopt_long implementation for IRIX, which was added courtesy of BSDero. 23 When compiling xz with gcc 8.2.0, the configure script might pick up a local definition of getopt_long from a header file, leading to compilation errors. 4 To use getopt_long, you can include the libdicl implementation in your project via CPPFLAGS and LDFLAGS, or by adding the libdicl include and linking against it, though configure might still require tweaking. 5
