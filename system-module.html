system module

Claims: 4

The rust on the system module does not affect the motherboard, only the cage. 1 An SGI Octane with a non-working system module can be diagnosed by checking blinky lights, with the heart ASIC light being crucial. 2 If the graphics board is swapped and the system module or front plane is suspected, the symptoms suggest a problem with the system board. 3 Removing XIO cards and booting with the system module and backplane still did not boot the Octane. 4
