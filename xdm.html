XDM

Claims: 9

XDM is used to start graphical sessions on SGI systems, such as launching 4dwm via /var/X11/xdm/Xsession on an SGI X server, and it can provide a full SGI desktop on a local X server. 12 On Windows, VcXsrv can serve as an X server and PuTTY as an SSH client to run an X session on an SGI using /var/X11/xdm/Xsession. 3 To enable barrier in XDM's Xlogin, set DisplayManager*authorize to on in /var/X11/xdm/xdm-config. 4 The XDM issue is caused by a missing user image in /usr/local/lib/faces, despite expecting a generic icon to display. 5 A ~/.icons/login.icon that is a TIFF file causes crashes in fm, xdm, and imgview. 6 dtlogin segfaults when receiving an XDMCP query, but XDM works. 7 XDM and XSgi do not play nicely. 8 A JIT compiler miscompiling instructions led to processes like xdm, 4Dwm, and clogin getting stuck sleeping and unkillable, which was resolved by fixing 512K aliasing for lowmem. 9
