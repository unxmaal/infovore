Challenge

Claims: 38 Background: 1 claim already covered by Wikipedia, see NetSurf.

The Challenge is a server that runs on a regular house outlet and 24/7 without issues, and SGI called their servers 'Challenge' before 'Origin'. 1234 The Challenge has various hardware issues, including a boot problem caused by a missing pin on a Dallas chip, memory running out when compiling Net::SSLeay in Perl (prompting an order for additional 512M RAM), and a problem with the last 4 tests that requires turning off the 'direct I/O' flag to pass all tests. 5678 The Challenge's hardware includes a HVD labeled 'RED' that requires careful handling, a VME fast ethernet card that is half-duplex but significantly faster than 10 Mb half-duplex, and a deskside model with 12x R4400@250 that is the fastest IRIX 5.3 system and a deskside model with 12x R10K that is the fastest IRIX 6.2 system. 9101112 The Challenge can run nethack, netsurf (compiled for IRIX 6.5), and full RSE builds, and it can have dual Ethernet interfaces. 13141516 The dual 75MHz IP21 boards for the Challenge provide better floating-point performance than a single 150MHz R4K but similar integer performance, making them suitable for compute servers, but they do not work with IR graphics or IMPACT in the Indigo2. 1718 The Challenge has a screw in the backplane that restricts CPU slots, which can be removed with pliers, and a system controller board that restricts more slots and requires a new board for multiple CPUs. 1920 The IO4 board is an I/O board for SGI Challenge and Onyx systems, providing keyboard, mouse, serial, and SCSI for disks, and is 9U VME sized, while the C19 plug is compatible with Onyx and Challenge but not with Crimson or PowerSeries. 2122 The custom DC-DC converters on the backplane boards are prone to failure due to bad capacitors. 23
