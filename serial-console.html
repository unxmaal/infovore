serial console

Claims: 39 Part of serial

A serial console provides console access without requiring Ethernet, and can be used to install or run operating systems such as Irix, OpenBSD, NetBSD, and PPC Linux. 12345 The serial console is useful for debugging, testing RAM and video card issues, and revealing errors that might be missed in the GUI. 678 Accessing the serial console may be necessary to boot into the PROM, fix certain issues, or enter service mode, and some systems default to serial console when no keyboard and mouse are detected. 191011 The serial console can be connected via a serial port, telnet to a serial server, or a modified cable, though some systems report no serial console available or problems such as freezing on boot. 121314151617
