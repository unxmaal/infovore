mips-sgi-irix6.5

Claims: 5

The config.log shows that the configure script is unable to find the correct nm tool for the mips-sgi-irix6.5 target, resulting in an error during compilation. 1 The target binutils should be in /opt/gcc/mips-sgi-irix6.5/bin under the GCC prefix. 2 The omp.h file in /opt/gcc/lib/gcc/mips-sgi-irix6.5/4.7.4/include is the latest version used by the system, and its presence prevents rebuilding gcc unless it's missing. 3 The gcc installation includes the header fix script, whose path is ./libexec/gcc/mips-sgi-irix6.5/4.7.4/install-tools/mkheaders. 4 You may need to create a symlink such as `ln -sf /opt/local/binutils/bin /opt/local/gcc-8.2.0/mips-sgi-irix6.5`. 5
