game

Claims: 42 Background: 1 claim already covered by Wikipedia, see Amiga.

The game is a hybrid between 2D and 3D graphics, using 3D backgrounds and 2D sprites, and employs an abstracted render system for portability. 1 The game targets IRIS for graphics rendering, as the Indy does not support OGL, and will use an OGL renderer for newer SGI machines if IRIS is not supported. 23 The game's art style allows 3D backgrounds to be largely untextured, improving performance. 4 The game renders the world as round to handle distant parts falling below the horizon. 5 The picture data produced by the game should account for the display's properties to improve the end result. 6 The game originally required finding a key and opening a boss room to finish, but was changed to 'kill all enemies before time runs out' before the deadline, with enemy AI and combat mechanics added in the final sprint. 7
