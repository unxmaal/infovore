Common Lisp

Claims: 6

Common Lisp is a Lisp-2 that supports object-oriented programming via CLOS and has namespaces, making it more procedural than Scheme. 12 A common Lisp implementation with the X library fully reimplemented in Common Lisp is possible. 3 cmucl, a Common Lisp implementation, requires specific binaries for IRIX 6.5 and may not work on all systems due to differences in installed libraries. 4 Genera provides an entire environment rather than just a compiler/editor and gained support for Common Lisp in later versions. 56
