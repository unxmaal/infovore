diskperf

Claims: 15 Background: 2 claims already covered by Wikipedia, see SGI Fuel, XFS.

diskperf is a command available in IRIX for benchmarking disk performance, including SCSI cards and HDDs, with examples for RAID setup found in the diskperf man page. 123 The tool can test XFS data subvolume performance with various request sizes, and flags such as -W show XFS overhead while -D can cause errors with certain disks due to direct I/O issues. 456 The command `diskperf -D -W -r4k -m4m -c2g /mnt/diskperf` can be used to test disk performance. 7 Real-world use reportedly achieves ~75-80MB/sec, and the tool has been run on various systems including an indigo2 impact with zuluscsi. 89
