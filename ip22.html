IP22

Claims: 29 Background: 1 claim already covered by Wikipedia, see SGI Indigo2.

The IP22 is a 32-bit MIPS architecture that uses the R4400 CPU and is found in the Indigo 2, which has an IP22 CPU. 123 The IP22 has 16 Kbytes I cache, 16 Kbytes D cache, 512 Kbytes secondary cache, and 32 Mbytes of memory. 4 The IP22 with NG1 graphics requires OpenGL libraries compatible with RevA for predictable graphics output. 5 OpenBSD is not well-supported on IP22, and there is a belief that Gentoo's stages do not support the IP22 architecture. 67 OpenBSD 6.9 can be booted on IP22 via network using RAM disk kernels, and Debian Etch can be booted on an IP22 using the netboot-boot.img from the specified GitHub repository. 89 OpenBSD 7.4 for SGI IP22 boots with 256MB of RAM, using a R4400 CPU at 100 MHz, and a compressed image is available for download. 1011
