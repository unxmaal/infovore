rpmbuild

Claims: 21 Background: 4 claims already covered by Wikipedia, see RPM Package Manager, Distcc.

rpmbuild unpacks the base tar and source code, compiles it, and generates a new binary RPM, handling dependencies, build paths, and library locations to simplify package creation. 123 It tells you its direct dependencies, uses /bin/sh by default (overridable with %_buildshell, sometimes replaced by a faster shell such as dash), and can be run with a -j flag for make parallelism. 4567 It can be resumed from a failed state using -bi to build up to the install step and --short-circuit to skip install bits, though it overwrites the target rpm and can still produce wrapper scripts, indicating the build process is not idempotent. 8910 distcc works well with rpmbuild, and attic'ing rpmbuild with distcc using dual slower CPUs with higher total MHz can be more effective than one faster CPU for Irix workstations. 1112 The IRIX libc regexp implementation is slow, affecting rpmbuild through file and libmagic.so, causing significant delays in building RPM packages. 13 Building DICL from source via rpmbuild can result in missing symbols like malloc/printf, while using pre-built RPMs works fine. 14 Running rpmbuild on ninja-build can lock up during the test suite, leaving an unkillable process consuming 100% of a CPU (test 18), which prevents further build steps. 15 The rpmbuild process may require specific wip rpmbuild packages to work correctly, as of recently fixed issues. 16
