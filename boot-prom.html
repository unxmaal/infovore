boot prom

Claims: 11 Part of boot Background: 1 claim already covered by Wikipedia, see IRIX.

The boot PROM is stored in an EPROM chip and contains the initial screens, which form a menu system that runs directly on the CPU, as distinct from IRIX, which is a full operating system. 12 Device tree information is filled into boot PROM images by a utility, and the images are not usable until this is done. 3 The boot PROM allows adding a custom logo and label, as was done for the Tatung clone. 4 The Indy requires a user to run a command in the boot PROM before installing IRIX. 5 To reinstall software packages, the machine is stopped at the boot PROM, the ?sash? command is entered, and the reinstall process is started. 6 The O2 can take an R12000 CPU, and some configurations require an updated boot PROM. 7 SS1 uses an old boot PROM that predates QFE, making it incompatible with QFE or HME. 8
