sshd

Claims: 18 Background: 1 claim already covered by Wikipedia, see Heartbleed.

sshd is an option for providing SSH access, and the sl_sshd service is used instead of the default sshd. 12 sshd requires host keys, which can be generated on startup if they do not exist, though some versions require manual generation. 345 Root logins are not allowed by default in sshd. 6 sshd can be packaged into a tardist, run as a native system service, or installed via RPMs from the SGI.SH yum repo. 478 The RSE version of sshd does not work properly, has SSL issues, and does not read host RSA keys or listen on a port, requiring nekoware for now. 910 Solaris 7 with a specific patch provides a /dev/random, which is essential for sshd, but the patch is hard to find. 11 sshd does not have an init script, but one can be cobbled together from jupo's tgc_sshd init script. 12 The bootstrap.yml Ansible playbook configures sshd and should ensure it is running, though bootstrap might claim to install it without actually running it. 1314
