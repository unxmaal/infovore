HyperSPARC

Claims: 27 Background: 1 claim already covered by Wikipedia, see HyperSPARC.

HyperSPARC is a SPARC processor that is not supported by certain systems, which instead support SuperSPARC CPUs with large caches that offer better performance than HyperSPARC CPUs despite having less MHz. 12 HyperSPARC requires an updated boot PROM, and mixing SuperSPARC and HyperSPARC modules can cause failures during OBP startup depending on which is the boot CPU, requiring a patched PROM for further progress. 34 Mixing SuperSPARC and HyperSPARC modules can be done physically but may require an OS that can handle separate drivers for each CPU, and the PROM may block configurations that are physically compatible but may not boot or run reliably. 56 NetBSD crashes when booting with mixed speed or cache size HyperSPARC modules but works with mixed speeds or cache sizes of the same type. 7 A 200 MHz HyperSPARC is dual issue while UltraSPARC is quad issue, and HyperSPARC is 60% faster than UltraSPARC for compression but only 5% faster for decompression. 89
