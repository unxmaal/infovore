swmgr

Claims: 28

swmgr is a graphical package manager for IRIX used to re-examine and install software, particularly after changing virtual hardware, and it parses tardist files (though it may have trouble reading some, requiring manual extraction). 1234 It is available in IRIX 5.3, though the 5.3 patch set can cause instability during installation or updates, and swmgr is considered less reliable in later versions of IRIX. 56 To install software, open the relevant distributions in swmgr, specifying NFS paths more precisely (such as 10.0.0.250:foundation/dist), and it can download .tardist files over the web to /tmp. 789 swmgr does not automatically check boxes for patches and usually indicates if patches are old or unchanged, so applying patches one by one and checking for conflicts can help avoid issues. 1011 It can be used to reinstall impacted products to restore corrupted files, either from the single user command line or while IRIX is running. 12 Community fragmentation is partly due to tool differences, as experienced users prefer the more advanced inst, which is used for the console while swmgr is used for the GUI. 134
