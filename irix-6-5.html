IRIX 6.5

Claims: 255 Part of IRIX Background: 15 claims already covered by Wikipedia, see IRIX, SGI Indy, Dillo, NetSurf, SGI O2, XFS.

With IRIX 5.3

IRIX 5.3 is faster than IRIX 6.5, especially on low-end Indys, where the 175MHz Indy running IRIX 5.3 is significantly faster than 6.5 for desktop use and comparable to an Octane. 123 The Indigo2 R4k runs both IRIX 5.3 and 6.5 with significant speed differences, and only the Octane needs to run IRIX 6.5, while everything else can boot down to 5.3 or even 4. 45 The Indy runs IRIX versions, with 5.3 being period-appropriate and 6.5 being near the end of its life. 6 Different IRIX versions have varying software compatibility, with 5.3 potentially offering better compatibility for older software like AVID Media Suite Pro. 7 In IRIX 5.3, function names like `AFopenfile()` are used, whereas in IRIX 6.5, they are lowercase, e.g., `afOpenFile()`. 8 The FPU test fails on IRIX 5.3 but passes on IRIX 6.5, suggesting IRIX 5.3 configures the FPU differently. 9 FTP works for file transfer in IRIX 6.5 due to passive mode, but not in 5.3. 10

With IRIX 6.2

IRIX 6.2 and 6.5 can be slow, but Profile Guided Optimization can significantly improve performance when used with Link Time Optimization, especially on IRIX 6.2 and 6.5. 1112 IRIX 6.5 had issues with demo executables and strange errors, while 6.2 had missing executables for most demos. 13 IRIX 6.5 has OpenGL 1.1, while 6.2 has only OpenGL 1.0 for textures. 14 The SGI SDK for N64 development is compatible with IRIX 6.5 but works best on 6.2 or 6.3; by 2000, Nintendo stopped updating the SGI release of the SDK due to most studios moving to PCs for cheaper development tools. 15 The Onyx can run an SGI IRIX 6.2 drive and keep an SGI IRIX 6.5 install for swapping between, without Vigra. 16 Weatherstar software runs on 6.2 or 6.3, not 6.5. 17 The ZuluSCSI Blaster does not honor drive geometry from the .ini file, causing issues with the fx program in both SGI IRIX 6.2 and 6.5 versions. 18 Booting IRIX 6.2 and 6.5 can spike the CPU and cause issues in SGI emulation. 19

With Indy

The SGI Indy can run IRIX 6.5, though it may have come originally with IRIX 5.1. 20 An Indy with an R4400 CPU and 1GB of RAM can take up to three minutes to load IRIX after logging in, and CHD-equipped models require patience during boot. 2122 The Indy can be configured with an R4400 CPU and includes documentation and IRIX 6.5 media, or with an R5k 150MHz CPU, Indycam, monitor, keyboard, mouse, and IRIX 6.5 CDs. 2324 Indys with env chips have problems and cost more, but run IRIX 6.5 well with 256MB of RAM. 25 Running Alias/1 on an Indy with IRIX 6.5 is not possible, and IRIX 6.5 on a real Indy may have issues, such as showing 7 units on controller 0. 2627

General

IRIX 6.5 was released in June 1998, following IRIX 6.3, which came out in 1996; SGI invested little in the MIPS platform, and 6.5 was released late. 282930 Foundation was the base release of IRIX 6.5 and never changed throughout its run. 31 Booterizer provides a fresh base install of IRIX 6.5, and irixports quickly sets up a working GCC environment. 32 gcc 8.2.0 can compile C and C++ on IRIX 6.5. 33 Frame Maker 5.5 works on IRIX 6.5 without issues. 34 IRIX 6.5 requires at least 512 MB of RAM for Maya. 35 IRIX 6.5 was released in 1998, and support for the platform was largely abandoned soon after its release. 36 IRIX 6.5 is commonly referred to simply as 6.5, and it was preferred over versions 6.0.1 and 6.1. 3738 IRIX 6.5 is POSIX compliant, though the specification is old. 39 Maintenance stream releases for IRIX 6.5 contained only bug fixes, while feature stream releases included both bug fixes and new features, though near the end of the 6.5 cycle the feature stream releases contained only bug fixes. 40 Later 6.5 versions are required for a lot of hardware support. 41 IRIX 6.5 was the last version of IRIX released. 42 It is compliant with UNIX System V Release 4, UNIX 95, and POSIX, including 1e/2c draft 15 ACLs and Capabilities. 43 It is the most Linux-like Unix out there, and most things found on modern Linux came from IRIX. 44 The Indigo magic desktop was renamed to the IRIX interactive desktop in version 6.5. 45 It is less hardware-specific than later versions. 46 It can support up to about 8 exbibytes with XFS. 47 The 'sa' command is only in IRIX 6.5. 48 It runs well on an O2 without texture issues, and a preinstalled O2 booted correctly out of the box. 4950 IRIX 6.5 was an all-platforms release. 51 The IRIX 6.5 source code is available on GitHub and includes versions 6.5.17 and 6.5.5, with 6.5.17 being a mislabeled version from 2002 that includes PROM source for various machines. 52 The collection contains many IRIX releases but lacks some IRIX 4 and 5.x versions and some ancillary discs for IRIX 6.5. 53 For a fresh IRIX 6.5 install, one includes the foundation and development/library isos for 6.5, and the overlay isos for the target version, like 6.5.22. 54 With IRIX 6.5, it's easier to install everything first and then remove what's not needed, avoiding later pain with overlays and patches. 55 Checking CD contents in IRIX 6.5 involves looking in the dist/ folder, but finding specific package versions requires checking IDB files. 56 IRIX 6.5 is not recommended for machines older than R5000. 57 6.2 is compatible with late Indys and IMPACT I2s but not older systems that struggle with 6.5. 58 IRIX 6.5 has multiple versions, including 6.5.5 and 6.5.7. 59 Running IRIX 6.5 with the wrong cache line size can cause issues. 60 The R10K CPU has a pre-execution bug in the SCSI driver related to speculative execution that can lock a machine solid; the bug was fixed with workarounds in the 6.5 kernel source. 61 IRIX 6.5 doesn't feel very snappy on R4400. 62 The O2 with a 300 MHz R5000 CPU and 256 MB RAM can run IRIX 6.5 and starts in the rescue menu. 63
