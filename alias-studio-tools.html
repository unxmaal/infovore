Alias Studio Tools

Claims: 7 Part of Alias

Alias Studio Tools was available on multiple platforms, including Windows, macOS X, IRIX, SUN, and HP-UX, and an internal build for Linux was created but never released. 12 Alias was originally PowerAnimator, which was stripped of animation features to create Maya, leaving Alias Studio Tools for design and modeling. 3 Alias Studio Tools has animation and particles modules, and it replaced PowerAnimator for animation tasks before Maya took over that role. 45 Alias StudioTools video tutorials can help figure out how to do equivalent operations in older versions. 6 A disk image of Alias Studio Tools for IRIX can be found in someone's luggage. 7
