spec file

Claims: 17

The spec file is used to build RPM packages, typically by downloading or installing a source RPM, modifying the spec file, and running rpmbuild (with -ba, or with --nocheck to skip checks) to produce the package. 123 The spec file can be modified to resolve build issues, such as setting specific exports to fix dynamic linking, commenting out the gpgv2 line to allow the gnutls build to proceed, or replacing it with the latest version from a specific branch and applying patches. 456 The spec file can conditionally include Python 2 or 3 setup based on the Python version, apply patches using %patch followed by the patch number in the %prep section, and its change log should be updated when it is modified. 789 The Makefile calls configure and autoconf on its own, ignoring flags from the spec file, which can cause linking issues, and resolving a build error in a spec file patch may require specifying the correct file path and adjusting version checks in the Makefile.in.in. 1011 The poppler spec file is version 0.72, but the one being patched is version 0.26, used by Xpdf 3.04, and the dist directory of the GL2 source contains the entire SPEC file for 4D1-2.0. 1213
