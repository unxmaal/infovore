Windows 3.1

Claims: 15 Part of Windows

Windows 3.1 is for x86 systems, while MIPS Windows NT 3.1 requires a little endian machine with ARC firmware. 1 SoftWindows95/SoftWindows Version 2 can emulate DOS 6.22 and Windows 3.1 and allows configuring of ports such as parallel and serial. 2 SoftWindows2 gives 3.1/6.22 and installs when you launch for the first time. 3 SoftPC 3.03 running Windows 3.1 on a 4D/440 VGX with an R3K CPU emulates a 286, making it slower than SoftWindows 1.25 on a 250 MHz R4400 Indigo2. 4 The IrisVision has a Windows 3.1 driver and a technical reference for RS/6000, originally intended for AIX 4 but support was dropped. 5 newshell was available for Windows 3.1 in some preview releases. 6
