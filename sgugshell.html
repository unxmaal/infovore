sgugshell

Claims: 30

sgugshell is a bash script that acts as a wrapper for the login shell, preconfiguring environment variables for SGI tools and providing tdnf. 123 It is available from the WNA branch on git and can be used as an alternative shell. 45 Running sgugshell sets the proper environment for SGI tools and is required to use sgug-rse packages, which are installed with tdnf. 678 It can execute other programs passed to it, though this feature is not included in the default install of RSE. 9 It can be invoked for normal users but not for root. 10 Setting sgugshell as the login shell can break XWindows, so it should be launched only when needed rather than set as the shell. 11121314
