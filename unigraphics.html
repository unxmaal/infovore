Unigraphics

Claims: 20

Unigraphics was a CAD program that was merged with I-DEAS by Siemens in 2007, and the resulting product, NX, is derived from Unigraphics though it is actually based on I-DEAS. 123 Unigraphics was expensive and was used for architectural designs. 4 Unigraphics supported Alpha/NT for VMS until 1998, with Digital UNIX and NT Alpha support continuing afterward, and an Alpha NT version existed. 56 Unigraphics, along with Catia and Pro/E, runs on IRIX, and old IRIX versions of Catia and Unigraphics can be integrated into a PDM system without modern tools like ENOVIA or Windchill. 78 Running Unigraphics on IRIX requires the old xdriver setup, which includes a /dev/magellan file and its own xdriver, and at one point Unigraphics used a 2D-only X11 driver. 910 GRIP is a scripting language for Unigraphics that can interact with most aspects of the program and was used for automation, but is now a legacy feature with no new features. 11 There are user programs for Unigraphics that export and import layerlists, available as source and compiled files but may need recompilation for different OSes or UG versions, and a custom user program can split Parasolid bodies from a Siemens NX export into individual part files, useful for running Unigraphics on IRIX. 1213 The T1000 included license server software for Unigraphics, and the JetDirect allows the LJ4 to be used for printing from Unigraphics. 1415
