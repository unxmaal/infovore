IRIS 1400

Claims: 8 Part of IRIS

The IRIS 1400 was part of a series that could run standalone from April 1984, unlike the diskless IRIS 1000/1200/2000 series, which ran the V Kernel. 1 The IRIS 1400 used a ST-506 MFM disk and included a 'PM2' board, which was a SUN design running Unix based on Unisoft SVR0 with GF1 or GF2 graphics. 234 The boot tape for the IRIS 1400 includes a structure for system information, likely from SVR2 UNIX. 5 The IRIS 1400's firmware has bugs preventing booting from QIC, and the QIC interface is byte swapped. 6 The next release will include the IRIS 1400 system minus graphics. 7
