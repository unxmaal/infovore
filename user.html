user

Claims: 6

For NFS, the user either needs to be the owner of the directory or part of the group that owns it, and for write access, the user needs to be writable by that user. 1 All drivers and OS related things would have to be done there, but the more basic everyday stuff could be done in the main user. 2 The IRIX file system allowed running root, user, and home directories from different locations, sometimes with root being local or remote, and home on a server, due to expensive storage. 3
