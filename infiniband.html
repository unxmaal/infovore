Infiniband

Claims: 22 Background: 5 claims already covered by Wikipedia, see InfiniBand.

Infiniband is a high-performance networking standard used for very high throughput and low latency in computers, and it is a high-bandwidth network with lower latency than Ethernet. 123 It supports Remote Direct Memory Access (RDMA) for efficient data transfer between nodes. 4 Infiniband is the current standard for supercomputing clusters, where nodes run Linux, Windows, or possibly AIX on power systems, and most HPE high-performance computing (HPC) systems are cluster systems coupled over Infiniband or Ethernet. 56 Infiniband setups benefit high-bandwidth scenarios like video processing and render data transfer, not just HPC. 7 Infiniband outperforms Fibre Channel in many scenarios, though it is more expensive and requires TCP/IP or iSER/SRB configuration. 89
