XShmPutImage

Claims: 6 Background: 1 claim already covered by Wikipedia, see OpenGL.

XShmPutImage is an X11 function used to display graphical data in X via local shared memory, with XPutImage available as a fallback. 1 It can fill a buffer directly, which can be faster than XPutPixel, especially for large images. 2 On SGI hardware, using XShmPutImage is less efficient than DMA to video RAM. 3 Rendering into a 16-bit 565 framebuffer on SGI hardware requires an extra pixel-format conversion step when using OpenGL glDrawPixels, which is faster than XShmPutImage. 4 Using OpenGL and glDrawPixels can significantly outperform X11's XShmPutImage on the Indigo2 Elan, especially for blitting operations. 5
