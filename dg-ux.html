DG/UX

Claims: 7 Background: 1 claim already covered by Wikipedia, see XFree86.

DG/UX is a Unix variant that shares version 5.x with VMS. 1 It was used on Motorola's 88000 (88k) CPU in AViiON machines, as well as on MVME boards and PowerStack machines. 2 DG/UX requires an Aviion x86 workstation to boot. 3 It supports standard GPUs such as the ATI 3D Rage Pro through XFree86. 4 The system reports an error when it believes it has only one CPU, even though the EPROM is fine and a new one was burned. 5 Its ISOs use a non-standard format incompatible with Linux for netbooting, so OpenBSD is used as a fallback. 6 The 88k CPU is slow and operating systems like DG/UX and Motorola SVR4 are rough, making it suitable for a Unix zoo. 7
