booting

Claims: 18

Boot problems associated with booting include machines freezing and failing to boot when network drivers are installed while connected over the network, getting stuck at the root password screen when booting from CD, and having issues booting from multiple SCSI drives. 123 Boot slowness can occur for various reasons, including slow booting in general, disk tests taking about 10 minutes, and reconfiguring devices making booting slower, especially if the battery is dead. 456 Boot failures can stem from hardware or configuration issues, such as the O2ctane not booting with the enclosure connected, the Fuel requiring an ATX adapter and replacement of environment monitoring chips to boot properly, the Fuel not booting without graphics, the Fuel possibly resulting in only an L1 prompt due to a CPU board failure, and powerstack openfirmware on an MVME160 7891011 Boot behavior varies by system: the bottom device in a cluster of O300s wins the master election to boot the correct disk, passing root= to the kernel can be useful for booting, the system still boots into the OS and starts X11 and CDE fine, and the machine boots over the network but requires a hard drive. 12131415 Boot processes can involve specific steps, such as the process of booting a target involving acquiring an IP address, figuring out what to do next, acquiring a bootloader via TFTP, and booting a kernel via NFS, and the LED display showing '2' when booting, indicating some progress. 1617 Boot capabilities include systems that do not support booting from SATA but can boot from network. 18
