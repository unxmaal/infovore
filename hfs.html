HFS

Claims: 11 Background: 1 claim already covered by Wikipedia, see IRIX.

HFS support varies across operating systems: IRIX 5.3 supports HFS (though slightly speed limited), while IRIS 5.3 does not support it. 123 An SGI can identify a PowerMac G5 in TDM but does not recognize HFS. 4 To read HFS or HFS+, use `mount -t hfs` or `mount -t hfsplus` respectively, and journaling must be disabled to write. 5 The HFS journalling system has a fault where permissions differ based on random file access. 6

  3. IRIS 5.3 does not support HFS. (user-554a, 2024-12-01, exchange 51195, check: supported)
  4. An SGI can identify a PowerMac G5 in TDM but does not recognize HFS. (user-0251, 2019-08-08, exchange 203883, check: uncheckable)
  5. To read HFS or HFS+, use `mount -t hfs` or `mount -t hfsplus` respectively; journaling must be disabled to write. (user-1446, 2020-03-22, exchange 6984, check: supported)
  6. The HFS journalling system has a fault where permissions differ based on random file access. (user-17cb, 2022-10-24, exchange 82303, check: uncheckable)
