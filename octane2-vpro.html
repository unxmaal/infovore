Octane2 VPro

Claims: 3 Part of Octane

The Octane2 VPro supports up to OpenGL 1.2. 1 It does not have native DVI, whereas the DCD card does. 2 Converting an Octane2 VPRO OS install disk to an Octane1 MGRAS install disk requires running inst with -m GFX=MGRAS and keeping/reinstalling all components. 3
