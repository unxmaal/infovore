MayaMan

Claims: 17

MayaMan allows Maya to run on SGI hardware with Pixar Renderman, Entropy, or BMRT renderers. 1 It can be used with Maya 4.0 and 4.5 on IRIX, though it may not run in Maya 5. 23 BMRT and Entropy are raytracing tools, with Entropy offering more features, and both can be used with MayaMan for basic tasks. 4 Entropy handles conversions in Maya's hypershade, and MayaMan can convert shaders to RIB automatically, which is easier than learning SLIM. 56 To use MayaMan, source mayaman.env and run Maya from the same terminal, then load the plugin in the plugin manager. 7 Mayaman requires the MAYAMANROOT environment variable to point to the directory containing the MayaMan folder, and the AnimalL.dat file should be placed in /var/flexlm. 8
