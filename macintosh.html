Macintosh

Claims: 25 Background: 3 claims already covered by Wikipedia, see Atari ST, Mac (computer), Mac OS 9.

The Macintosh is a computer that is different from the Lisa, though some Lisas were converted to run Macintosh ROMs. 1 The original Macintosh models were expensive and lacked expandability, unlike the Apple II line which had more flexibility. 2 The Macintosh designs are minimalist and impressive. 3 The Macintosh had software limits, including that System 6 would not boot on 128k Macs and that some machines cannot boot system software above 7.1 due to hangs at the welcome screen. 45 The Macintosh can run OS9 on vintage hardware. 6 The Macintosh is not difficult to emulate, but performance varies, and there are emulators such as Basilisk, Basilisk II (ported to IRIX), and the official MAE for Solaris. 78910 There are accessories and software for the Macintosh, including BlueSCSI for SCSI on older models with a DB24 connector, sgirc as an IRC client, and CD-ROMs for archiving retro systems. 111213
