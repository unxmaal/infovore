L1

Claims: 41

L1 is total control of a single brick, L2 is control of a rack, and L3 is control of a network. 1 L1 is a tiny embedded computer with its own operating system and command-line interface, used for lights-out management. 2 L1 can be accessed over a serial console, which is a common method, and it can also be accessed over USB, which is simpler to set up. 3456 To access L1 over serial, connect a 9-pin serial cable to the SCSI port and hook it to a terminal with settings 38400/8/N/1, then type commands such as `env off`, `help`, and `pwr u`. 7 Control+d and control+t drop you in and out of L1, and you can use `L1` to tell the controller not to switch back to the system console until explicitly told to do so. 8910 From L1 you can run `* pwr up` to access the EFI shell, where you can use a CD drive for OS installs. 8 You send specific commands to other bricks from the master L1 using the syntax `<brick id>: <command>`. 1112 L1 boots without RAM, using serial for boot, and it does a numalink and I/O scan by default, which can be bypassed with debug commands in hex such as `debug 0x4000`. 131415
