PS/2 keyboard

Claims: 35 Background: 2 claims already covered by Wikipedia, see PS/2 port.

The USB keyboard and mouse spec includes backwards compatibility with PS/2, and adapters connecting them are 'dumb' wired straight through. 1 PS/2 keyboards and mice are cheaper options, but may not look as nice. 2 Some SGI systems require a PS/2 keyboard to boot properly: the O2 uses a PS/2 keyboard and mouse, the Indigo2 requires a PS/2 keyboard and mouse to boot properly, and the Octane requires a PS/2 keyboard to force graphics boot. 345 Booting with a PS/2 keyboard resolved a diagnostics failure, and plugging in a PS/2 keyboard may cause the machine to halt without one connected. 67 Some PS/2 keyboards may not work with certain systems: an Indigo2 may not boot if a particular PS/2 keyboard is plugged in, plugging a PS/2 keyboard into an Indigo1 may cause issues, and an O350 with an SGI PS/2 keyboard fails to be detected in the PROM but works in the OS. 8910 The PS/2 keyboard for SGI systems has a non-standard layout, with the ~ key placed to the left of the space bar, and a Compaq keyboard is an OEM rebadged version of the same PS/2 keyboard SGI used. 1112 PS/2 keyboards have several variants of the protocol, and an old Fujitsu PS/2 keyboard works great, while a granite SGI keyboard works solid for the I2. 13
