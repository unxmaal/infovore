SGUG toolchain

Claims: 3 Part of SGUG

The SGUG toolchain requires specific flags and linker options to work with SGI GL, such as -lGL -lGLcore, and may need an X11 package with fixed headers. 1 Support for Objective-C is needed in the SGUG toolchain to build a current version of Oolite for Irix. 2 An Octane machine ran early tests for gcc 8 and started SGUG toolchain work. 3
