EHCI

Claims: 3

UHCI, EHCI, xHCI, and VHCI chipsets are software-based, whereas OHCI chipsets are mostly hardware-based, and USB and Firewire support on IRIX is organized according to this hardware versus software implementation distinction. 1 These chipsets require an extensive USB software stack and a driver for each chipset or card. 2 USB support on IRIX 6.5.3 machines includes mouse and keyboard through PCI USB using uhci or ehci controllers. 3

Sources

  1. IRIX's decision to support USB and Firewire is based on Hardware vs Software implementation, with OHCI chipsets being mostly Hardware-based and UHCI, EHCI, xHCI, VHCI, chipsets being Software-based. (user-8b3c, 2020-05-30, exchange 216937, check: uncheckable)
  2. UHCI, EHCI, xHCI, VHCI, chipsets (some USB 1.x and all USB user-b4f4) require an extensive USB Software Stack and a driver for each chipset/card. (user-8b3c, 2020-05-30, exchange 216937, check: supported)
  3. USB support on IRIX 6.5.3 machines includes mouse and keyboard through PCI USB using uhci or ehci controllers. (user-5c71, 2021-03-28, exchange 215103, check: supported)
