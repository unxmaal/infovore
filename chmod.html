chmod

Claims: 5

Perl scripts require the 'x' permission to run as executables. 1 Files downloaded from the internet lack the executable bit for security reasons. 2 The chmod command can also remove permissions, such as using a-s on the sudo binary as a quick fix. 3 The chmod command can restore read permissions, such as using +r on image files to access help file screenshots. 4
