IO6

Claims: 7

The IO6 is a module that can be removed by clearing cards and blanks around it and gently guiding it out from the side. 1 The base PCB is shared between the io6 and io6g, and the ioc3 serves as the keyboard controller. 2 The PS2 position on an IO6 lacks the ASIC to the left of the Qlogic chip that is present in the IO6G, and the part identifies as IO6G, which the software checks. 3 The IRIX kernel disables PS2 ports on the IO6 unless a media daughter card is present, so an IO6 can be modified to have PS2 ports but they will not be enabled without that card. 45 You can install SE or SI graphics in an XIO slot, replace the IO6 with an IO6G to add keyboard and mouse ports, and cut sheet metal to install MXI/MXE, which is called an Onyx MXI. 6 Parts from an Origin 2000 system are available for sale, including router boards, midplane, IO6, and a CD drive/power switch with key. 7
