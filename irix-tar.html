IRIX tar

Claims: 5 Part of IRIX

IRIX tar is not a drop-in replacement for GNU tar, and it requires the R flag for root backups, whereas IRIXports allows using GNU tar, which does not need it. 12 Modern tar implementations like GNU tar may not warn when creating an empty archive, while older implementations like IRIX tar do not warn. 3 IRIX tar did not support built-in gzip decompression, so a gzip file is extracted by piping it through gunzip into tar (gunzip -c <archive> | tar -xvf -), a method that does not damage the original file. 4 GNU tar strips off the leading '/' when extracting, while IRIX tar can preserve it, and Pro/Engineer requires the old IRIX tar. 5
