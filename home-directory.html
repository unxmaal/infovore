home directory

Claims: 5

  • Root having its home directory as root is a superficially sensible but inconvenient and dumb practice. (user-b1da, exchange 217499, 2022-02-24; 1 speaker(s), 1 conversation(s))
  • Setting up home directories on IRIX-like systems can be similar to IRIX when done from the CLI. (user-7b1c, exchange 182157, 2022-05-28; 1 speaker(s), 1 conversation(s))
  • The IRIX file system allowed running root, user, and home directories from different locations, sometimes with root being local or remote, and home on a server, due to expensive storage. (user-3e2d, exchange 219619, 2026-03-31; 1 speaker(s), 1 conversation(s))
  • Logging in as root on IRIX sets the home directory to / instead of /root. (user-7973, exchange 212264, 2025-03-27; 1 speaker(s), 1 conversation(s))
  • Home directories are stored in /usr/people in IRIX, which can be inconvenient. (user-1446, exchange 10054, 2020-07-26; 1 speaker(s), 1 conversation(s))
