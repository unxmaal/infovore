REX3

Claims: 8

REX3 is a device in Newport Graphics that requires configuration options such as REX3, which has gio32/gio64 and gio32/gio32bis timing settings. 1 REX3 runs in a separate thread with an increased FIFO size for better decoupling, providing reasonable performance on a Ryzen 5900X despite some slowdown. 2 The JIT compiler for REX3 is marginally faster than the interpreter but can bog down the CPU under heavy GPU use, causing the fasttick to slow down significantly. 3 DMA GFIFO backpressure from REX3 is handled by a thread consuming hostrw from a larger gfifo. 4 The framebuffer can be accessed as points, lines, spans, or blocks, and REX3 provides autoincrementing address features for memory access in specific modes. 5
