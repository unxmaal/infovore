overlay discs

Claims: 5 Part of overlay

Overlay discs contain cumulative updates that patch the files on the foundation discs, which come from the original IRIX 6.5 release. 12 All versions of IRIX 6.5 after the original release have overlay discs that install on top of the base install, and minor version patches are located on separate overlay discs. 32 Overlay discs also contain the miniroot needed to boot into the miniroot. 4 IRIX 6.5.22 requires all 3 overlay discs, the IRIX 6.5 Foundation (2 discs), and both the Applications and Complementary Applications discs. 5

Sources

  1. Overlay discs contain cumulative updates over the base 6.5.0 install (user-e473, 2020-07-11, exchange 9540, check: supported)
  2. Foundation discs are from the original 6.5 release; all versions of 6.5 after that have overlay discs that patch the files on the foundation discs; you'd boot from the 6.5.30 overlay disc 1 (user-d903, 2022-11-13, exchange 105594, check: supported)
  3. eoe.sw.base is the base components of the OS; for IRIX 6.5, minor version patches are on separate overlay discs that install on top of the base install; adding foundation and overlay discs might resolve conflicts. (user-d903, 2022-09-13, exchange 217693, check: supported)
  4. Overlay discs contain the miniroot needed to boot into the miniroot. If you have overlay IRIX discs from Raion, you can try booting into the miniroot without setting up Booterizer. The pi version might be easier. Floptec (user-1446, 2020-09-08, exchange 10928, check: uncheckable)
  5. IRIX 6.5.22 requires all 3 overlay discs, IRIX 6.5 Foundation (2 discs), and both the Applications and Complementary Applications discs. (user-6c80, 2024-06-05, exchange 210414, check: supported)
