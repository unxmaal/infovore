ProE

Claims: 103

ProE (ProEngineer) is a CAD program that historically ran on IRIX systems such as Catia, Unigraphics, and Pro/E, and was also available for non-IRIX systems including Suns and SGIs running lean Unix versions, as well as Solaris. 123 ProE included an FEA package called Mechanica and 7 different CAM NC modules, though modules were obsoleted and replaced with new ones. 456 ProE is a CPU and geometry-intensive program requiring significant RAM, and its interface used a menu manager system that could run and manage other applications. 789 ProE's interface design was influenced by Microsoft Office, leading to a ribbon interface in later versions, though SolidWorks' Command Manager was preferred over Pro/E's toolbar system. 1011 ProE was generally cheaper than CATIA, making it a competitive option. 12 The ProE license system was weak, allowing option codes to unlock modules through simple math, and switched to FlexLM in version 20. 1314 ProE files were forwards and backwards compatible as text-based files until they switched to a binary format that was only forwards compatible. 15 ProE was the first parametric solid modeler, released in 1988 and initially available only on SGI systems, with a base seat cost of around $100,000 when bundled with hardware that came down to $20,000 in the late 90s. 16 It was the standard for a long time, its menu manager system was considered peak, and it remains powerful and comfortable to use even today. 1718 ProE uses an unusual mouse system requiring a 3-button mouse to navigate its menu structure and allows for rapid selection of items on the screen. 1920 It was the first to lay out the familiar system for pan/rotate/zoom with the 3 mouse buttons and the ctrl/alt/shift keys on the keyboard, a system used by modern CAD systems. 21 ProE uses multiple windows on X for the viewport and the menu system, which might affect how window movement is handled. 22 It can be run on an Indigo2 R10K, where it would occasionally crash but not the system, and on an Indy with the low-level MAC address in the PROM changed. 232425 An Indigo2 Extreme can run ProE release 17 very fast, faster than input commands and mouse movement, and release 20 is the easiest to get going. 262728 ProE release 20 has been figured out for a long time because it's based on FLEXlm, and its licenses are backwards compatible, so a license for version 25 works for version 20. 2930 PTC's ProE was one of the first commercially successful parametric, solid modeling software, and was the first parametric solid modeler available across all Unix platforms on standard hardware. 3132 ProE supported Alpha processors, was available for NT Alpha, and, along with SolidWorks, had Alpha NT versions. 333435 ProE was happiest on an SGI using motif, and an O2 can run ProE as can an SGI. 3637 ProE likely required an alternative renderer like PHIGS for platforms other than IRIX. 38 ProE runs on Windows using an Xtop.exe process, and can be installed by copying a live directory and running ptcsetup.exe to set up the license. 3940 ProE has its own kernel that doesn't play well with others, and newer ProE kernels broke backward compatibility, potentially causing corruption. 4142 Old ProE did not have good support for outside CAD file formats, like new ProE does. 43 ProE had good macro support and tools for customization and automation. 44
