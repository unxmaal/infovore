evwii plugin

Claims: 3

The evwii plugin is used with the Aroma environment on a Wii U to improve video output quality from the GX1 GPU core shared by the Wii and Wii U. 1 It allows changing video scaling settings for vWii on a Wii U. 2 The plugin improves video output quality but does not fully resolve color issues, which remain noticeably duller than on an original Wii with component cables. 3

Sources

  1. The GX1 GPU core in Wii and Wii U can be improved for video output quality using the evwii plugin with Aroma environment on a Wii U. (user-27ce, 2024-05-07, exchange 46094, check: uncheckable)
  2. The evwii plugin allows changing video scaling settings for the vWii on a Wii U. (user-27ce, 2024-05-07, exchange 46094, check: uncheckable)
  3. The evwii plugin improves video output quality but does not fully resolve color issues, which are noticeably duller than on an original Wii with component cables. (user-baf6, 2024-05-07, exchange 46094, check: uncheckable)
