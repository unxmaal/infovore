MIPS architecture

Claims: 16 Part of MIPS Background: 1 claim already covered by Wikipedia, see IRIX.

The MIPS architecture is a processor design that has influenced other architectures, such as the Alpha architecture, which learned many lessons from it. 1 The architecture includes features such as the $gp global pointer, which points into a 64K block of memory holding constants and global variables for quick access with a single instruction. 2 The architecture has been used in various systems, including IRIX, which requires the MIPS architecture and cannot run on Intel-based systems, and the PlayStation 1 and PlayStation 2. 345 The architecture has limitations, including never having a multicore CPU and being poorly suited for out-of-order execution. 67 SGI shifted away from the MIPS architecture to Itanium, a decision some consider a mistake, and support for the architecture was later abandoned, though the name MIPS is still used. 879
