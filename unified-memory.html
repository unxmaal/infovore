Unified memory

Claims: 6 Background: 1 claim already covered by Wikipedia, see SGI O2.

Unified memory allows all CPUs to access all RAM, whereas NUMA provides faster access to local memory and slower access to non-local memory. 1 The O2 uses a R4k-based chipset with unified memory, which necessitates 32-bit addressing. 2 Unified memory can lead to reduced performance for both GPU and CPU due to contention. 3 The Mac Studio is a not-quite-as-expensive UNIX workstation with a RISC CPU and unified memory for the CPU and GPU. 4 Unified memory reduces the viability of multiple CPU cards in the Mac Pro. 5
