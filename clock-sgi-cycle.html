CLOCK_SGI_CYCLE

Claims: 4

IRIX has a monotonic clock called CLOCK_SGI_CYCLE. 1 IRIX does not support CLOCK_MONOTONIC, but CLOCK_SGI_CYCLE can be used as an equivalent clock with 64 bits and 800ns resolution on ip35 systems. 2 CLOCK_SGI_CYCLE is not fully compatible with CLOCK_MONOTONIC, but glib tests pass with CLOCK_SGI_CYCLE. 3 The ERTS_HAVE_OS_MONOTONIC_TIME_SUPPORT macro is not correctly picked up in IRIX, which could be fixed by using CLOCK_SGI_CYCLE or bringing back a platform-specific IRIX hack. 4
