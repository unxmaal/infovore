DHCP

Claims: 35 Background: 9 claims already covered by Wikipedia, see Dynamic Host Configuration Protocol, Bootstrap Protocol.

A DHCP client must perform a DHCP request in order to receive an IP address, which requires the host to facilitate ARP requests. 12 The DHCP process can check the address and use the default netmask, and options 3 and 6 can set the gateway and resolv.conf. 34 DHCP can be used on network interfaces to allow access, and it can be combined with zeroconf (mDNS) to provide a complete network solution. 56 BOOTP and DHCP support appears in IRIX 6.5, which was a transitional period that remained flaky, and later versions such as 6.5.30 were somewhat more reliable. 78 DHCP on IRIX is unreliable and can stop working randomly, and IRIX does not automatically register its hostname with DNS when using DHCP. 91011 DHCP can cause IP conflicts, and out of the box IRIX might DHCP only the IP and not the default gateway. 1213 Static IP addressing is considered a good practice to avoid issues with DHCP. 141516
