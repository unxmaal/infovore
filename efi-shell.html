EFI shell

Claims: 5 Part of EFI

The iMacG5 uses EFI firmware that includes an EFI shell, which can be entered and exited using control+d and control+t. 12 From the L1 prompt, running `* pwr up` accesses the EFI shell, where a CD drive can be used for OS installs. 2 The EFI shell can be used to locate the bootfile, and it helped resolve an issue in one case. 34 The EFI shell is rarely used but can be crucial when needed. 5
