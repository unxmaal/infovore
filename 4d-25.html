4D/25

Claims: 12

The 4D/25 is the most common SGI that can run a news-based GUI, though the 3.3 install might be tough. 1 The 4D/20 and 4D/25 are IP6 systems, while the 4D/30 and 4D/35 are IP12. 2 The IP6.5 is a re-layout of the IP6 for speed and cost-reduction, used for both the 4D/20 and 4D/25, often underclocked to match the 4D/20's performance. 3 The 4D1-3.0 supports the 4D/25. 4 The 4D/25 can use some 60ns 4MB SIMMs, but the IP6 does not like 4MB SIMMs at all. 5 The 4D/20 and 4D/25 use 9-pin connectors, while deskside SGI systems use the DB15 connector and Onyx and Indigo use miniDIN 6; all use the same protocol and can be rewired between each other. 6 The 4D/25 supports only 8-bit color and many demos do not run, as it lacks a Z-buffer or GR1. 7 The 4D/20 and 4D/25 work well in serial console mode, but the GR1 graphics pipeline gets stuck when X launches. 8
