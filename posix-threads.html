POSIX threads

Claims: 3 Part of POSIX

POSIX threads code works, but implementations can vary and may crash. 1 lrix supports POSIX threads with the n32 architecture. 2 Version 6.2 with POSIX threads and patches is a fine platform unless you want to run some commercial software that requires 6.5. 3
