R10K CPU

Claims: 43 Background: 3 claims already covered by Wikipedia, see SGI O2, SGI Indigo2.

With O2

The O2 can use an R10K CPU, though integrating it was difficult and not originally planned. 12 The R10K CPU was installed on two different CPU modules for the O2, one with PROM and one without. 3 The R10K CPU's clock speed on the O2 is limited by the FPGA, which explains the increase from 3x60 MHz to 180 MHz. 45 An O2 with an R10K CPU typically sells for $100-$850, and one with a 250 MHz R10K is approximately half as slow as an IRIX64 250 MHz R10K. 67 An R10K CPU on an O2 is expected to be faster than an Octane2, but it runs OpenGL 3-4 times slower than an R5K CPU. 89

General

The R10K CPU is used in several SGI systems, including the Octane, Indigo 2, and O2. 101112 An Indy cannot run an R10k CPU, while an r5k system can use one but requires removing the PCI cage for installation. 1314 The R10K CPU has better floating-point performance than the R5200 300 MHz, and a system with two drive trays likely has an r5k CPU, while one tray indicates an r10k or r12k CPU. 1516 The R10k CPU is well-documented for programmers but lacks detailed schematics and microcode documentation. 17 The R10K CPU has a pre-execution bug in the SCSI driver related to speculative execution that can lock a machine solid, and this was fixed with workarounds in the 6.5 kernel source. 18 Early R10k CPUs had rendering video issues, which were resolved with later R10ks. 19 The R10K CPU was sold for around $380 on eBay in 2020, and a 195MHz R10K CPU is not suitable for modern web browsing. 2021
