VLAN

Claims: 17

A VLAN can be used to isolate IoT devices, limiting their network access to DNS/NTP only. 1 Each VLAN gets its own /24 (and /64). 2 A layer 3 switch can bridge between VLANs if the devices use TCP/IP. 3 WLAN and VLAN are separate for the alarm system. 4 The Indigo manages to communicate with the VM running on the VLAN without NAT. 5 A tagged interface to a host is only needed if you want multiple VLANs or a trunk on the interface; otherwise the switch can untag it. 6 You can run one VLAN at MTU 1500 for normal usage with the default route, and another at MTU 9000 for things like NFS, letting the switch handle the segregation. 7
