IRIX view

Claims: 3 Part of IRIX

IRIXview is a logic analyzer for software systems that collects and analyzes event data such as process creation, system calls, and interrupts. 1 It can visualize the kernel. 2 WindView for IRIX became IrixView and was rebuilt in Linux, with plans to release it as open-source in 2005. 3
