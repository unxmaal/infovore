ULTRIX 4.5

Claims: 5 Part of Ultrix

ULTRIX 4.5 requires a specific partition layout with a partition on A slice holding partition data for other slices. 1 It has a single bash script called rc and a second called rc.local, with no rc.d/XXX directories. 2 The CD/DVD drive on an ULTRIX 4.5 system can fail when attempting to write a large file system image to a CD, possibly due to block size limitations. 3 A DECstation running ULTRIX 4.5 can be used as a bootserver, and an emulated VAX with ULTRIX 4.5 is a viable alternative. 4

Sources
