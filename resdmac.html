ReSDMAC

Claims: 3

ReSDMAC is a firmware that addresses SCSI instability caused by the sdmac when used with newer accelerators. 1 It fixes motherboard SCSI issues in the AA3000+ and allows the BFG9060 to run at 50 or 100 MHz without SCSI errors. 2 ReSDMAC also resolves DSP crashes, allowing the BFG9060 to run at 100 MHz as intended. 23

Sources

  1. The sdmac is problematic and causes SCSI instability with newer accelerators; ReSDMAC aims to fix these issues. (user-2a24, 2024-08-10, exchange 233338, check: uncheckable)
  2. The ReSDMAC firmware fixes motherboard SCSI issues in AA3000+ and allows BFG9060 to run at 50 or 100 MHz without SCSI errors, also resolving DSP crashes. (user-2a24, 2024-10-26, exchange 233347, check: supported)
  3. The ReSDMAC fixes SCSI and DSP issues, allowing the BGF9060 to run at 100 MHz as intended. (user-2a24, 2024-10-31, exchange 153345, check: supported)
