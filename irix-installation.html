IRIX installation

Claims: 29 Part of IRIX

IRIX installation is the process of installing the IRIX operating system, and it is rare for some users. 1 The process involves opening CDs and from-ing others, which is a bit unusual, and it uses miniroot during installation rather than for booting the system. 23 Installation requires `su` to create and chown /usr/didbs, then untar didbs.tar there, and root has no password during installation. 45 The installation can be automated using selection files with the `inst` command, and Google Gemini can create roboinst scripts for automated installation, though a reboot after rqsall is needed. 67 The official installation guide recommends setting aside 1 or 2 hours, with faster processors speeding up the process. 8 Various tools can be used for installation, including the M-Systems U320 SCSI Flash Disk for storing the /unix kernel, Booterizer to simplify installation, and zuluscsi to clone an installation from a HDD to an SD card. 91011
