dynamic linker

Claims: 3

The dynamic linker, such as rld on IRIX and ld.so on Unix systems, determines where programs run and manages shared libraries during runtime. 1 It re-links executables on the fly based on hints left by the original linker. 2 Issues with the dynamic linker or missing debugging symbols can cause miniperl to hang at high CPU usage with stable memory. 3

Sources

  2. The dynamic linker re-links executables on the fly based on hints left by the original linker. (user-42cf, 2021-06-09, exchange 17822, check: uncheckable)
