deeprunner

Claims: 5

Deep Runner is an unorthodox Descent clone available for SGI systems. 1 It can be played as a descent-like game prototype for the O2 at http://user-21b8.mutantstargoat.com/sw/games/deeprunner/. 2 The game was made for the itch.io Retro Platform Jam #6 and requires an OpenGL runtime and development environment for IRIX 6.5.30, which may not be readily available. 3 It has issues with libGL.so not exporting symbols. 3 It can be compiled with either mipspro or gcc 3.x, with appropriate Makefiles. 4 It uses GLUT spaceball callbacks, which won't work with xinput; changing the makefile to use the system's GLUT instead will make it work. 5
