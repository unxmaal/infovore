PCDOS 7

Claims: 3

PC-DOS 7 can be installed on the Model 70 using a McIDE and BlueLightning CPU upgrade with a Zip disk. 1 The installation can be done from a DOS boot disk using a Zip drive GUEST.EXE driver and a Zip disk containing the entire PCDOS 7 CD copied to it, since the installer does not require it to be a CD. 2 The CD does not contain DISKFACT or disk images; everything is expanded. 3
