boot time

Claims: 5 Part of boot

Boot time varies widely across systems, from the O2, which takes about 40 seconds to fully boot to the desktop, to the low-end Indy, which had a 15-minute boot time. 12 The XEROX Alto was slower than the low-end Indy, and the RS/6000 has various models, some of which take a long time to boot. 23 Solaris boot time can be long, around 35 minutes, and serial communication can be challenging with the RS/6000. 43 Parallel init is considered a false gain, as the vast majority of boot time for a server is POST, not the OS itself. 5
