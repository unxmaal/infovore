NUMA

Claims: 13

NUMA stands for non-uniform memory access, where hitting memory on another host can significantly degrade performance. 1 In a multi-processor system, NUMA architecture is simpler to implement than SMP for design purposes. 2 Unified memory means all CPUs can access all RAM, while NUMA means faster access to local memory and slower to non-local memory. 3 Low traffic across a bridge can provide the benefits of both NUMA and networked clusters, but not all workloads suit this model, especially those needing fast node interconnects. 4 Irix supported NUMA for some form of asymmetrical mp. 5
