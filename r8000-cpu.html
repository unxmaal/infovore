R8000 CPU

Claims: 6 Part of R8000

The R8000 CPU can run NetBSD and is available but rare in Europe. 12 An R8000 CPU at 75MHz is equivalent to a 150MHz R4400K in integer performance and can achieve up to 300 MFlops. 3 The R8000 CPU can perform 2x FP multiply + add per cycle for matrix computations, but only if the code is optimized, making it less useful for general computing compared to the R10K. 4 The Indigo2 used at the University of California has an R8000 CPU and Extreme Graphics. 5
