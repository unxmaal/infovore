A/UX

Claims: 109 Background: 11 claims already covered by Wikipedia, see A/UX, Macintosh SE/30, QEMU.

A/UX is an ancient Unix-like operating system that runs on old Mac hardware, is notoriously difficult to set up and use, and has significant limitations even when successfully installed. 1 A/UX runs only on 68k-based Macintoshes with a floating point unit (FPU) and a paged memory management unit (PMMU); even then, it only runs on select models. 2 A/UX may require special drivers for the IIfx, but newer versions of the OS support more machines. 34 A/UX runs best on a Quadra 840, which is cheaper and faster than AV, and the Quadra 950 is the fastest A/UX machine unless the AWS95 PDS card is available, which is rare. 56 A/UX is slow even on a Quadra 950 with lots of RAM, and is slow on a 030. 78 A/UX is Unix with a Macintosh Toolbox compatibility layer; it does not run Mac OS or its descendants, but can run some old Mac m68k software and System 6 programs in compatibility mode. 91011 A/UX requires a floppy disk and a SCSI CD-ROM for installation, which can be challenging to find and use. 12 A/UX is a hybrid of Unix and Mac OS, and is an SVR2 derivative. 1314 A/UX requires specific hardware support, including an MMU, and will not boot with all Mac ROMs. 1516 The Mac II can run A/UX with an MMU, while other Macs cannot. 17 A/UX runs on Apple's Quadra 950, a powerful system for the time comparable to an Indigo or Indy SGI, and is very nearly the ideal platform for A/UX. 1819 A/UX does not support the 840AV due to its DSP, making the Q950 the fastest A/UX box. 20 A/UX does not support the PPC upgrade card for the machine it came with. 21 A/UX can run on various Macintosh models, including the IIfx (which requires a full 68040 CPU), the Quadra 610 (with a 68040 upgrade), the Centris 650 (with compatibility issues with System 7), the Maccracker (after upgrading the ROM to 32 bits), and the Radius VideoVision (though no drive is present). 22232425 A/UX can run standard System 7 and MacOS 6/7 applications, and some Mac programs that did not work on A/UX ran faster than on plain MacOS. 262728 A/UX is better in some ways because it runs the Macintosh system in its own Unix process, making it more crash-proof, and it was well integrated with the Mac environment. 2930 A/UX requires booting a specific System 7 partition, switching to Unix, and then booting System 7 again, and it requires MacOS 7.1 or earlier to boot correctly. 3132 Installing A/UX is challenging, may fail to install the kernel, requires recompiling the kernel after installation, and can be done using floppies and CD-ROM. 333435 A/UX can run on BlueSCSI but is very slow, achieving about 1.8MB/sec with overclocked firmware. 3637 Apple believed the alliance with IBM would merge A/UX, AIX, and System 7, scaling Macintosh application execution from Mac desktops to IBM's RS/6000 systems, and a third party attempted to port A/UX to PowerPC but it didn't progress far. 3839
