MIPS64

Claims: 7 Part of MIPS

The gold linker includes a patch for MIPS64 that could improve IRIX's ld/bfd, but it has issues with MIPS64 support and may contain bugs. 12 MIPS64 added a 'multiply-add' instruction and some cache control instructions, though these were previously available in MIPS implementations. 3 GCC can generate code optimized for MIPS64, which is a more modern architecture than MIPSIV. 4 MIPS3 and MIPS64 are different architectures, and MIPS64el and MIPS32el are also distinct. 5 The cnf7300 evb supports mips64 and Debian. 6 The IRIX clang compiler version is 14.0.0 targeting mips64 with POSIX thread model. 7
