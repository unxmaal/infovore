man command

Claims: 3

The `man` command provides documentation for commands, such as `man swap`, which contains instructions on adding a swapfile. 1 On IRIX, the `man` command treats some manpages as pre-formatted 'cat' entries and others as unformatted nroff source, even if `MANFMTCMD` is set, and only processes nroff if the file is not compressed. 2 Removing /usr/nekoware/bin from the PATH prevents the 'Standard text formatter package not found' error when using man. 3
