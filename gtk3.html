GTK3

Claims: 20 Background: 5 claims already covered by Wikipedia, see GTK, NetSurf, Emacs.

GTK3 is a GUI toolkit that can be built and packaged for SGI/IRIX hardware, where it is already working on SGI equipment. 12 GTK3 is software rendered by default on SGI hardware and does not ask for 24bit color depth by default, though it can support hardware rendering. 345 The likely bottleneck for GTK3 acceleration on SGI hardware is libxrender, which handles text shaping and is not part of the SGI X server, limiting its performance. 6 GTK2 is faster than GTK3, though there is no proof, and GTK2 and GTK3 have limitations on lower-end hardware while QT4 provides good performance. 78 libpurple needs gtk3, and elementary-calculator requires gtk3 on IRIX. 910 GTK3 can be used as a GUI for emacs, though Motif generally runs better, and netsurf supports multiple frontends including GTK2 and GTK3. 1112 netsurf can be launched using the motif version if the GTK3 version is not found, and ir8 is the first WebKit-based browser for IRIX, built on GTK3 and WebKitGTK. 1314 export GTK_CSD=0 disables custom client side decorations for GTK3 windows unless the app has custom buttons. 15
