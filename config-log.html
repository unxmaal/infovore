config.log

Claims: 4

The config.log file is used to diagnose why the configure script fails to find required tools or settings, such as when it cannot locate the correct nm tool for the mips-sgi-irix6.5 target, resulting in an error during compilation. 12 When configure cannot find something despite specifying its location via --with-something=/somepath or CFLAGS=-I/somewhere LDFLAGS=-L/somewhere, the config.log should be examined to see why it did not find them. 2 Running the configure step on x86 where it succeeds can provide a config.log to diagnose the bit-size test failure during crosscompilation. 3 The config.log indicates the C file attempted for the check, and compiling and running that file can provide more insight. 4
