Alias PowerAnimator

Claims: 8 Part of Alias

Alias PowerAnimator was essentially StudioTools bundled with some animation modules. 1 Alias renamed PowerAnimator to StudioTools after Alias v8, and removed the animation modules after Alias v9. 2 Alias PowerAnimator can run on Windows 10 with some UI and renderer issues, but it still renders fast. 3 It is recommended for modeling characters in the Nintendo prerender style, as it uses NURBS-spline modeling that was prevalent in the '80s and '90s. 4
