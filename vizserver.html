VizServer

Claims: 20 Background: 1 claim already covered by Wikipedia, see IRIS GL.

VizServer is an SGI OpenGL remote desktop solution for IRIX that runs on an SGI host and can send graphics over the network to clients, including Windows machines and PowerPC Macs via Rosetta up to Snow Leopard. 1234 It works off of X11, manages GPU pipe sharing, and offers compression options including MPEG, zlib, and JPEG at various quality levels. 53 It requires a topology file to start and logs errors if the file is missing or corrupted. 2 The local shared session gives the whole desktop experience when a remote user joins, otherwise it shows a blue Vizserver desktop with only the console. 6 It can export VPro over the network and allows using a second SE with the vizserver on a networked X server. 78 It can run on an Indigo2 (client only), an O2 (problematic), an O350 stack with a few V12s, and a faceless Octane that requires a BS SE in the XIO slot. 9101112 It is slow, and ElectroPaint core dumps or crashes over VizServer but works fine over normal X11. 131415
