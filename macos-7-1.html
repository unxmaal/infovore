MacOS 7.1

Claims: 3 Part of macOS

The Mac IIcx, from Astal, runs MacOS 7.1 and has the original 80MB disk (presumed working), 24MB of RAM, and a NuBus NIC. 1 A/UX requires MacOS 7.1 or earlier to boot correctly and will not work on A/UX 7.5.5. 2 The Quadra 700 running Mac OS 7.1 is not Y2K compliant. 3
