tcsh

Claims: 32 Background: 4 claims already covered by Wikipedia, see Tcsh, Bash (Unix shell).

tcsh is a shell that provides command line completion (tab autocomplete) and command history through the up arrow, features that csh lacks. 1234 tcsh is fast, simple, and portable, having run on various architectures, but it is not ideal for scripting. 56 tcsh is more usable than csh but less suitable for scripting. 7 tcsh uses a built-in cd command that is not a binary. 8 On IRIX, csh is the default shell, while tcsh is the preferred default shell and was the most popular shell among users in the mid 90s. 910 The IRIX default tcsh shell has a default .cshrc setting history=100 with no aliases by default, and uses a prompt format of sys_id \(\!\#). 11 tcsh is available on IRIX 6.20, for IRIX 4, and was compiled for IRIX 3.3.2, but it is not available on IRIX 4.0.5. 12131415 Updated versions of tcsh are available in version 0.0.6, from Mogrix, and via the SGUG repos. 161718
