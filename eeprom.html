EEPROM

Claims: 34 Background: 3 claims already covered by Wikipedia, see EEPROM.

EEPROM is a non-volatile memory type similar to CMOS. 1 EEPROMs commonly store hardware identifiers such as MAC addresses, system IDs, and serial numbers, as seen in the SGI O2 (PCI riser), the front panel system ID/MAC connector, and the OS/2 SE ES9k serial number. 234 EEPROMs can also store configuration data, including R4000 CPU settings like endianness and cache timing, IPL changes, and Video Format Combiner workspace settings. 567 A faulty or corrupted EEPROM can cause problems such as a bad Ethernet address (ff:ff:ff:ff:ff:ff), garbage output causing fallback VOP usage, mismatched DIMM errors, and difficulty using a Dell P992 CRT monitor. 891011 EEPROMs can be dumped using hardware like the TL866, and switching between R3K and R4K processors can clear or invalidate the stored MAC address values. 121314 EEPROMs are sensitive to static electricity and should be shipped using antistatic foam and a small box to avoid damaging the pins. 15
