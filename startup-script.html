startup script

Claims: 3

  • You’ll have to comment out a good portion of the startup script to get it to run on other gfx types. It has a check for a couple of IR variants and doesn’t like to run with other versions without removing it. (user-22f9, exchange 224787, 2025-03-25; 1 speaker(s), 1 conversation(s))
  • Programs often set up environment variables and run startup scripts, which can affect how software packages interact. (user-1a5a, exchange 225349, 2025-08-23; 1 speaker(s), 1 conversation(s))
  • On an onyx4, launching synergy client from the startup script allowed controlling the login screen with a Windows 10 machine. (user-b7c4, exchange 217919, 2023-02-17; 1 speaker(s), 1 conversation(s))
