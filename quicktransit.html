QuickTransit

Claims: 35 Background: 4 claims already covered by Wikipedia, see QuickTransit.

QuickTransit is an emulation or translation layer that allows running IRIX (MIPS) software on Itanium-based systems running Linux, including Altix and Prism systems with Itanium 2 processors. 12345 Silicon Graphics announced QuickTransit's first availability in October 2004 on its Prism visualization systems. 2 QuickTransit was built using technology licensed by Apple for Rosetta, and was made by the same company as Apple's CPU emulation. 356 QuickTransit uses FlexLM for licensing, which requires a license to use fully; the ISO is available on archive.org but is limited without one. 78 QuickTransit can run a set of IRIX tools without a license, but other applications require a license which can be purchased from SGI. 9 The last version available is 1.2.1-004, packaged as an IA64 RPM file named QuickTransit-1.2.1-004.ia64.rpm. 10 QuickTransit can run on non-SGI hardware but has compatibility issues with Montecito CPUs, and may run on Itanium 9xxx with an unknown performance penalty. 1112
