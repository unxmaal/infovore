/etc/network/interfaces.d/eth0

Claims: 3

The `eth0` configuration in `/etc/network/interfaces.d/eth0` is ignored if `dhcpcd` is managing the interface, and setting `eth0` in `/etc/dhcpcd.conf` resolves the issue. 1 To fix DHCP issues, change 'manual' to 'static' in `/etc/network/interfaces.d/eth0`. 2 Commenting out the gateway line in `/etc/network/interfaces.d/eth0` resolved the boot error. 3
