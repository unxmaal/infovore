N64 controller

Claims: 4 Part of N64

A user attempted to connect an N64 controller to an SGI machine using a serial port and an FPGA but found the performance to be poor due to constant polling. 1 The N64 controller is extremely ergonomic for its time. 2 The original N64 controller can interface with the O2 via RS232, but the power consumption is too high for a 16 MHz clock; an 8 MHz clock might work, but 1 MHz would be insufficient. 3
