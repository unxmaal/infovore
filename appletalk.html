Appletalk

Claims: 15

Appletalk uses the original 3-wire system and can run over both LocalTalk and EtherTalk. 12 Appletalk support for Linux/Unix required a license and was not great, and it works in HP-UX but not in Solaris. 34 IRIX had Appletalk by default for a while, with support and K-FS shipped with IRIX and available as packages like appletalk.sw. 56 Appletalk required a NetLS license for the 5.3 era. 7 Server 2003 or Server 2000 with Appletalk protocol and routing can be used for Appletalk file serving, and Appletalk can provide network access to large storage systems on Windows servers. 89 A typical booterizer install does not install eoe.sw.uucp but does install AppleTalk, which includes the AppleShare File Server and AppleTalk support. 10 Retro machines can access removable storage through Appletalk. 11
