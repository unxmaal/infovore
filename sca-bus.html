SCA bus

Claims: 3 Part of SCA

The SCA bus assumes a 1:1 mapping of SCSI IDs to physical slots, which can be problematic with multiple SCSI IDs. 1 The SCA bus can set the SCSI ID, but it is not implemented by default, so slot swapping changes the drive ID instead of the image filename. 2 Having the SCA bus set the SCSI ID is a nice-to-have feature but not essential, as the first slot gets ID 1 and is the regular boot disk while extra slots are for options disks. 3
