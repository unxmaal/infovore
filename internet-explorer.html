Internet Explorer

Claims: 7

Internet Explorer was released for Solaris and HP-UX, as well as for SPARC and PA-RISC systems. 12 Later versions of Internet Explorer Mobile, since Windows Phone 8, are based on the desktop version of Internet Explorer. 3 Tadpole CDs with a 2.6 kernel include Internet Explorer alongside DHCP and Netscape. 4 The Dell remote console for the DL360 G7 requires a one-time Java download and works with Internet Explorer but not modern browsers. 5 IE Mode in Internet Explorer can't open ActiveX plugins in other browsers. 6 Internet Explorer's dominance led to a prediction of a Microsoft-only web, which almost happened. 7
