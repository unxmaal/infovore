PXE

Claims: 6

PXE is used for netbooting, combining BOOTP/DHCP and TFTP, and can be set up using HTTP for the rootfs, which is slightly easier to set up than NFS. 12 PXE can boot a Linux VM by configuring the TFTP server and setting the PROM to the Linux box's IP. 3 The EFI bootloader in the SGI Altix350 netboot process uses an EFI loader to request DHCP, which points to a TFTP server for the next server, which can be any program, including an OS kernel leader like ELILO. 4 PXE can also be used for booting with an rsh responder that pulls files via rsh/rcp. 5 PXE is not really a pain at all, involving a simple config option in most DHCP servers and setup TFTP. 6
