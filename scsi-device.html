SCSI device

Claims: 23 Part of SCSI Background: 1 claim already covered by Wikipedia, see SCSI.

SCSI devices can be configured as separate LUNs, allowing all volumes to be seen simultaneously while periodically interrupting reads to poll other LUNs. 1 No format command is needed for any SCSI device; the device only needs to be partitioned, and a unixy filesystem will format it. 2 A SCSI device may need to be tested with an RS6k/pSeries AIX compatible HBA. 3 The SCSI device defaults to ID 0 when all jumpers are removed, which may conflict with the controller, and no terminator should be at the end of the device chain. 4 The SCSI device may not standardize for media size changes; it uses disk notches for read/write sensing, with the window notch and switch flipped between disks. 5 Adding the SCSI device for MO requires additional setup steps. 6
