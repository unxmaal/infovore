PuTTY

Claims: 14 Background: 1 claim already covered by Wikipedia, see Null modem.

PuTTY is a terminal emulator that can be used on Windows for serial communication, including during installation and for monitoring console messages via a null modem cable. 123 It emulates an xterm-style terminal rather than VT100. 4 PuTTY can be used to connect to serial ports of systems such as IRIX 3 and the SGI O2 for diagnostics, though this is not always 100% reliable. 56 It can also be compiled from source as a serial console program for Linux. 7 X forwarding can be set up using PuTTY together with Xming, which requires Xming to be installed, X forwarding enabled in PuTTY, and the DISPLAY variable set to the IP address of the Windows computer. 89 PuTTY works as a color terminal on a Linux thin client, and MAME can redirect terminal output to it. 1011
