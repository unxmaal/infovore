nfsrb2

Claims: 3

nfsrb2 is a tool for creating a root filesystem for network booting. 1 It can also be used to create filesystems for netbooting. 2 A root filesystem can alternatively be built by unpacking the sets yourself. 3 The FTP server at ftp.eu.openbsd.org hosts older versions of OpenBSD sets, while the main server only has the latest ones. 3

Sources

  1. For network booting, you can use `nfsrb2` for creating a root filesystem. (user-6e7b, 2023-11-30, exchange 42867, check: supported)
  2. For netbooting you can check my logs for my Indys on nycbug's dmesgd. You can create filesystems with nfsrb2. If you want to install on disk, I have created sgi sets up to 7.2 so far. R4600 based Indys seem more stable, (user-6e7b, 2024-03-24, exchange 240278, check: supported)
  3. You can build your root FS with NFSRB2 or unpack the sets yourself; the FTP server at ftp.eu.openbsd.org has older versions of OpenBSD sets while the main server only has the latest ones. (user-6e7b, 2026-04-26, exchange 90497, check: uncheckable)
