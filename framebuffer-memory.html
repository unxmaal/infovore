framebuffer memory

Claims: 5 Part of framebuffer Background: 1 claim already covered by Wikipedia, see Heat sink.

Frame buffer memory is additive, unlike texture memory in SGI systems, while IMPACT systems use non-additive memory that offers performance benefits. 1 A V6 cannot run 24-bit color because it lacks sufficient framebuffer memory for 24-bit visuals, requiring either a resolution reduction or a code fix. 2 The framebuffer memory may be located under a heatsink on these boards. 3 The TB board (display generator) or its path to framebuffer memory has issues, showing errors in address reads and writes on certain addresses in manufacturing mode, which affects the blueDAC. 4 Geometry speed doubles while still using 32 MB of framebuffer memory. 5
