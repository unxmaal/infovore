Wayland

Claims: 25 Background: 8 claims already covered by Wikipedia, see Wayland (protocol).

Wayland is a display server protocol that Fedora has used since Fedora 24. 1 Ubuntu 20.04 does not run Wayland by default, and the most modern Linux boxes run Wayland. 23 Wayland may handle DPI settings more effectively in some cases. 4 Wayland/NVIDIA works with recent drivers but not all Wayland environments, working with GNOME Wayland but not KDE Plasma Wayland. 56 SteamOS uses a modified version of Wayland called gamescope. 7 Wayland is not supported for IRIX. 8 Barrier does not support Wayland, and input leap, which is compatible with barrier on IRIX, has cursor visibility issues on Wayland due to security reasons. 910 Wayland had issues with Discord support in Ubuntu 22.04, but Xorg was stable; in 24.04, Xorg became unstable and took too long to open a terminal. 11
