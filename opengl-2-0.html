OpenGL 2.0

Claims: 6 Part of OpenGL

OpenGL 2.0 made programmable shaders a core feature, following the ARB extensions for shaders introduced in OpenGL 1.4. 1 Several hardware models support OpenGL 2.0, including the FireGL x3, XVR-600, and XVR-1200. 23 The FireGL x3 offers more VRAM and OpenGL 2.0 support, though GL 2.0 support may not work under IRIX. 2 OpenGL 2.0 support in IRIX would have been beneficial for long-term use. 4 The N64 graphics API compatibility layer uses OpenGL 2.0 due to shader usage. 5 The Windows version and source code are available, while the Linux version uses OpenGL 2.0. 6
