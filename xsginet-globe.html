xSGINet-globe

Claims: 4

xSGINet-globe is available as an RPM for MIPS systems. 1 It can be run with -w for wireframe or -l for low resolution texture options if TRAM is not present. 2 xSGINet-globe needs curl to talk to a REST API, which requires openssl and other dependencies. 3 First download and install SGINet-CLI to register your machine (and enable the daemon if you like to track uptime), then you can install and run xSGINet-globe to place the pin on the globe. 4 SGUG-RSE is required. 4
