CPPFLAGS

Claims: 3

CPPFLAGS is one of the environment variables, alongside CC, CXX, CFLAGS, LDFLAGS, CXXFLAGS, PERL, SHELL, SHELL_PATH, LD_LIBRARYN32_PATH, and PKG_CONFIG_PATH, that can be set to help configure scripts for autoconf packages. 1 Using CPPFLAGS=-D_SGI_SOURCE -D_SGI_REENTRANT_FUNCTIONS can help build certain software on IRIX. 2 Configure errors can be caused by the compiler, flags, environment, or tools, and using CPPFLAGS=-D_SGI_SOURCE -D_SGI_REENTRANT_FUNCTIONS together with CC=gcc --std=c99 can help. 3
