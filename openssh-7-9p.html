openssh 7.9p

Claims: 4 Part of OpenSSH

openssh 7.9p is available as a static package with no external dependencies apart from base IRIX. 1 A static tardist for openssh 7.9p works like the nekoware openssh package in terms of configuration, requiring a user account for privilege separation. 2 A static built tardist with an init script for IRIX is available at http://sudenluola.org/irix/openssh-7.9p/. 3 The init scripts for openssh 7.9p can also be used for 8.0. 4
