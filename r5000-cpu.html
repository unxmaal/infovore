R5000 CPU

Claims: 13 Part of R5000 Background: 2 claims already covered by Wikipedia, see SGI O2.

The R5000 CPU is a MIPS4 processor. 1 It has 32KB/32B L1 caches, a 512KB/32B L2 cache with 128-byte lines and 4096 entries, 48 TLB entries, and a 16MB max page size. 23 It can be used in systems that are 24-bit. 4 The O2 can use an R5000 CPU, which can be upgraded from 180 MHz to 300 MHz, and the O2 can run at 640x480 with 30-40 fps. 567 An O2 with an R5000 CPU running at 300 MHz is slower than an Indigo2 with an R10000 CPU, which is in turn slower than an Octane. 8 The R5000 CPU was faster than the geometry accelerators. 9 Blender will not run on an Indy because it requires a minimum of an R5000 CPU. 10
