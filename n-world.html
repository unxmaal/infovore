N-World

Claims: 14

N-World is a Lisp-based polygon modeler built for the Nintendo 64 development tool chain. 12 N-World for Irix shipped with a 'Wide Open World' development toolkit for 3D hacking with Lisp. 3 The Indy can run N-World, its development tools, and the N64 SDK. 4 N-World requires 2GB of memory, and running out of memory can cause it to crash. 5 It is a demanding program when every module is loaded. 6 N-World has a date limitation of 1999 and will not run on Windows NT versions past NT4. 7 There is an archived copy of N-World for Irix and for Windows, with the Windows versions having been cracked and archived. 8910
