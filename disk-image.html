disk image

Claims: 17 Part of disk Background: 1 claim already covered by Wikipedia, see IRIX.

A disk image is a copy of a disk taken to storage, typically using the 'dd' command, which can be stored on an NFS share. 12 Disk images are used to recover data from non-booting disks, such as a C8000, by creating an image and checking it for corruption. 3 Creating a disk image can be slow even on systems with modern hardware like SSDs and multiple CPUs. 4 Installing IRIX requires using fx to create partitions on a disk image, as the installation process is specific to SGI disks. 5 Booting from a disk image involves pointing the system at the desired OS configuration and the disk image, and can be done with commands like 'boot -f dksc(0.1.8)sash.ip6 DKSC(0.1.7)/unix'. 67 Running SGI emulation requires ROMs and a disk image with a recent MAME build. 8
