Ethernet MAC address

Claims: 3 Part of Ethernet

The O2 does not store its Ethernet MAC address on the RTC chip; instead, it is located on a three-pin DS2502 chip on the PCI riser, unlike some previous SGI machines such as the Indy and Indigo2. 1 The Indy's Ethernet MAC address is stored in battery-backed PRAM and is blank if unused, causing issues on first startup. 2 The PCI riser holds the Ethernet MAC address via a Dallas DS2505 IC. 3

Sources

  1. Unlike some previous SGI machines (e.g. Indy, Indigo2), the O2 doesn't store its ethernet MAC address on this chip (it is instead located on a three-pin DS2502 chip on the PCI riser), however, the RTC chip is responsible (user-bc18, 2019-08-11, exchange 2982, check: supported)
  2. The Indy's Ethernet MAC address is stored in battery-backed PRAM and is blank if unused, causing issues on first startup. (user-d903, 2020-07-14, exchange 9582, check: supported)
  3. The PCI riser holds the Ethernet MAC address via a Dallas DS2505 IC. (user-e4d0, 2025-03-28, exchange 115684, check: uncheckable)
