pthread

Claims: 9

The pthread library is sometimes required for linking, as adding `-lpthread` resolved a missing-libcrypto.a linking issue. 1 pthread usage can be affected by linking order, as a segfault during Ruby's `make install` was possibly related to pthreads or libstdc++ linking order. 2 Linking pthreads may cause the C++ `strtoll` function on MIPS to fail to clear `errno`, affecting subsequent calls. 3 The dicl library must be installed as 64-bit in /usr/sgug for proper pthread usage, otherwise a test fails. 4 Building GCC 4.7.1 on the hpux.connect.org toolchain may require a kernel patch for `p_thread` functionality. 5 std::mutex does not require pthread linkage. 6 pthread can improve performance, as pthread on a 4 CPU Origin achieved 30.794165 tok/s instead of 4.9 tok/s by launching 3 threads. 7 llama2_bigendian_pthread.c is intended for IRIX and uses pthread to distribute matmul load, with the optimal number of threads depending on the model and CPU count. 8

Sources

  1. The linking of libcrypto.a requires the pthread library, which was missing, and adding `-lpthread` resolved the issue. (user-b4f4, 2020-01-05, exchange 68252, check: supported)
  2. Running Make install on Ruby causes a segfault due to a hard-coded file path issue, possibly related to pthreads or libstdc++ linking order. (user-a0f2, 2020-02-03, exchange 68322, check: uncheckable)
  3. The `strtoll` function in C++ on MIPS may fail to clear `errno` if pthreads are linked, causing issues with subsequent calls. (user-2d09, 2020-02-17, exchange 68412, check: supported)
  4. The dicl library must be installed as 64-bit in /usr/sgug for proper pthread usage; otherwise, a test fails. (user-cd7d, 2020-06-09, exchange 214980, check: supported)
  5. The hpux.connect.org toolchain is likely broken, and building GCC 4.7.1 may require a kernel patch for `p_thread` functionality. (user-b1da, 2020-07-24, exchange 9996, check: supported)
  6. std::mutex does not require pthread linkage. (user-711b, 2021-01-12, exchange 75614, check: uncheckable)
  7. pthread on a 4 CPU Origin can achieve 30.794165 tok/s instead of 4.9 tok/s by launching 3 threads. (user-7973, 2024-03-08, exchange 71069, check: supported)
  8. llama2_bigendian_pthread.c is intended for IRIX and uses pthread to distribute matmul load; the optimal number of threads depends on the model and CPU count. (user-07ed, 2024-08-16, exchange 48445, check: uncheckable)
