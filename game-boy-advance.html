Game Boy Advance

Claims: 6 Part of game

The Game Boy Advance uses an ARM processor, as do all Nintendo handhelds released after the Game Boy Color. 1 It has a powerful PPU for 2D graphics, more capable than the SNES, with scalable and rotatable sprites. 2 Its fast memory and full-width 32-bit bus make storing code in spare video RAM a common trick, which is safe because nothing runs in the background to corrupt that memory. 3 A 5th edition UNIX has been run on the Game Boy Advance. 4 The Game Boy Advance can have its screen replaced without soldering, unlike the more involved Game Gear process. 5
