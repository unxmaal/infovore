NetBSD

Claims: 162 Background: 15 claims already covered by Wikipedia, see NetBSD, VAX, SGI O2, Amiga, FreeBSD, Tcsh.

With O2

NetBSD runs on a stock O2, though it boots with an R10K/R12K CPU and lacks full functionality. 12 NetBSD has a bug in the scsi driver for the O2, and the ZULUSCSI 1.2 has compatibility issues with NetBSD on the O2 and possibly other systems. 34 Compiling db for NetBSD on an O2 can fail due to custom mutexes treating the CPU as mips1, lacking sync instructions. 5 The O2 can boot into a graphics console, but this requires running NetBSD with specific configurations to avoid printing too much to the ARCS graphics console. 6 sigh 32-bit NetBSD on the O2 is limited to 256MB of physical RAM, even though it has 320MB, likely because the kernel code has cut corners. 7 Booting NetBSD on an O2 and expanding its memory range are challenging tasks. 8

General

NetBSD is a Unix-like operating system that runs on a wide range of hardware, from vintage machines to modern systems. 910111213 It has a VAX port that can build most pkgsrc pieces, and it is traditionally considered the best option for vintage hardware support. 1415 NetBSD also runs on other platforms including Amiga, SuperH, PPC750, Alpha, and the Z180, and it has a package manager that can be bootstrapped to other platforms. 16171819 It can netboot on some hardware, and it has been used to host web servers and the iTunes Store via WebObjects. 2021 NetBSD is a relatively small operating system with good documentation, supporting a vast amount of hardware but lacking extensive testing. 2223 NetBSD runs on a wide range of systems, including 68040-based Macs, NVAX, and old-world Mac systems. 242526 pkgsrc is a cross-platform port system originally from NetBSD that works with OpenBSD, Linux, FreeBSD, and Solaris. 27 NetBSD's quality has declined due to a lack of testing and support for a wide range of hardware. 28 The i386 port of NetBSD was based on Net/2 and later incorporated more 4.4BSD code. 29 NetBSD supports the MIPS line, Arm boards, and the R8000 CPU. 303132 NetBSD can be booted over a network, including diskless booting via TFTP or an ND server exposing raw filesystem blocks, but it is slow on 10mbps links. 33343536 NetBSD has issues booting on some systems, including crashes with mixed hyperSPARC modules, problems with X11 on Ultra 5, and booting issues in an emulator. 373839 NetBSD support for some systems may be marked as supported but may not actually work. 40 NetBSD does not ship tcsh by default but it can be installed. 41 NetBSD is a viable Unix option for old machines, but the appeal lies elsewhere. 42 NetBSD can be booted on the Indy, which provides a dedicated ISO for that purpose, and it can also be bootstrapped on the emulator for CI automation and package building. 4344 To boot NetBSD on an sgimips machine, load the ISO, boot dksc(0,4,8)ip2xboot, then boot dash f. 45 NetBSD has not been reported to boot on an Onyx1, and there is no evidence of an Indigo2 running it despite NetBSD being listed as supporting MIPS. 4647 The R3000 Indigo 1 and Indigo R3000 could run NetBSD, but modern userland is bloated, and upstream NetBSD was not fixed regarding R3K Indigos even though a fix existed but was not upstreamed. 4849 NetBSD detects the actual clock rate using real-time, while IRIX approximates it, and a 100Hz interrupt is consistently 100Hz in NetBSD's emulator. 5051 Electropaint runs at 60fps on an Indy running NetBSD but requires additional configuration, and Ctrl-C can be used to break out of the installer. 5253 The code in machdep_init and cpu_idle causes the system to enter an idle loop, which may be the cause of the boot issues with NetBSD. 54 NetBSD has a broken graphics driver that shows a black screen, but it should initialize graphics and uses UART as console if graphics fail. 5556
