MIPS NT

Claims: 7 Part of MIPS

MIPS NT runs on Siemens RM200 machines, which boot into ARCS firmware and run NT4 using wx86, an executable that allows running x86 applications on MIPS hardware. 12 MIPS NT requires specific firmware and runs in little endian mode, which SGI systems cannot do. 3 MIPS NT systems could use VLB cards. 4 QEMU can run MIPS NT, but the mouse pointer eventually goes nuts and requires a keyboard reboot. 5 MIPS NT compatible hardware is more rare than flying pigs. 6
