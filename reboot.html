reboot

Claims: 8

A reboot can be triggered by running devfsadm as root, or by using other methods such as reboot -- -r to create device nodes in /dev and /devices. 1 Certain configuration changes require a reboot to take effect, including IRIX network settings, X server settings, and reconfiguring X after swapping graphics cards (via 'touch /reconfigure && reboot'). 234 Reboots may also be used to apply changes made through automation tools, such as running an Ansible playbook and then rebooting the system. 5 A broken I1 keyboard can cause a kernel panic when plugged in, though the system may reboot with no visible damage. 6 A cronjob can be set up to ping an external IP and reboot the system upon 100% packet loss, though this approach becomes complex for better reliability. 7 After a reboot, the system works fine without errors. 8
