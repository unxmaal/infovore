Synergy

Claims: 26 Background: 6 claims already covered by Wikipedia, see Synergy (software).

Synergy is software for controlling multiple computers with one keyboard and mouse. 1 It allows a keyboard and mouse to treat another computer as an extension of the desktop over the network, and enables shared copy and paste between computers. 23 It can be used to create the effect of dual-head X locally. 4 Synergy 1.6.2 was the last freeware version, followed by a payware version with subscription requirements that was unpopular. 5 The newer versions from NekoWare have major issues, including a bug that prevents login, while an earlier version works but lacks global clipboard support. 67 Barrier, a fork of Synergy, works well for combining Linux boxes and SGI gear across multiple monitors. 8
