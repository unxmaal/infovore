bilinear filtering

Claims: 3

Bilinear filtering can serve as a blur when drawing a lower-resolution texture at full screen, eliminating the need to blur manually and requiring no additional texture memory, though it does require more sampling. 12 SGI textures support border color and can be sorted by texture if memory is insufficient. 2 UI HUD lines can appear due to oversampling with bilinear filtering, and adding a 1-pixel transparent guardband can help. 3

Sources

  1. You probably don't need to blur it manually at all. Let the bilinear filtering when drawing the lower-ressed texture at full screen be the blur for you. It's 'free'. (user-6afa, 2021-05-29, exchange 205107, check: uncheckable)
  2. SGI textures support border color and can be sorted by texture if memory is insufficient; bilinear and trilinear filtering requires more sampling but not more texture memory. (user-3e2d, 2025-07-23, exchange 72563, check: uncheckable)
  3. UI HUD lines appear due to oversampling with bilinear filtering; adding a 1-pixel transparent guardband can help. (user-21b8, 2025-07-24, exchange 215777, check: supported)
