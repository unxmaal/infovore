keygen

Claims: 13

A keygen is a program that generates license keys or auth codes, which can be produced from a CPU ID and serial number. 1 Keygens exist for SGI products, including MIPSpro, and for FLEXlm-based applications, since restrictions in the FLEXlm SDK were cracked. 23 The keygen outputs 'PROE_200' as the increment/feature name regardless of the specific software version. 4 If the keygen is an IRIX binary, it must be marked executable and run with './binary_name argument' from the directory containing the binary, and specific syntax may be required to generate a functioning license. 56 For Maya 4.5, the keygen should replace 'HOSTID=lmhostid' with the actual lmhostid value. 7 The IRIX install images include CAD software but no license keys, and the keygen source is available but not tested. 8 A potential weakness in the SecurityBuilder ECC crypto library could be exploited by generating and checking 2^64 keypairs. 9
